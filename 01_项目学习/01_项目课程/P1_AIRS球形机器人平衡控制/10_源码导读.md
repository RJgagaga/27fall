# 10 源码导读

> 范围：`项目源码/AIRS/Robot/fdilink_ahrs`、`arm_controller`。`chassis_controller`、`chassis_driver` 为空，按 CV 讲解。

## fdilink_ahrs

| 文件 | 内容 |
|---|---|
| `include/fdilink_data_struct.h` | `#pragma pack(1)` 的帧头(7B)、IMU 包(56B)、AHRS 包(48B)、INSGPS、大地位置结构 |
| `include/ahrs_driver.h` | 常量 `0xFC/0xFD`、类型 `0x40/0x41/0x42/0x5C`、`ahrsBringup` 类 |
| `src/ahrs_driver.cpp` | 构造：读参数(`port`,`baud`,`imu_topic`,`imu_frame`,`device_type`…)，建 7 个发布者，开串口(超时 20 ms，失败 `exit`)，进入 `processLoop`；`processLoop`：找帧头→类型/长度→CRC8→CRC16→帧尾→按类型发布；`checkSN`：流水号丢包统计；`magCalculateYaw`：倾斜补偿磁航向(未被调用) |
| `src/crc_table.cpp` | CRC8/CRC16 查表 |
| `src/imu_tf.cpp` | 订阅 IMU，广播 `world→imu` TF(调试用，位置参数为 int) |
| `launch/ahrs_data.launch` | 921600 baud，`imu/data`，`gyro_link`，`device_type=1` |
| `wheeltec_udev.sh` | 为 CP2102/CH9102/CH340 写 udev 别名 |

要点：IMU 包分支发布 `sensor_msgs/Imu`，姿态取自最近 AHRS 包；`device_type=1` 做 FRD/NED→FLU/NWU（第 03 章 §6.5）；`header.stamp` 为接收时间。

## arm_controller

| 文件 | 关键点 |
|---|---|
| `kinetic_compensation_node.py` | `CompensationNode`：参数 `model_path/freq/arm_joint_num/has_velocity`；`pin.buildModelFromUrdf`；`get_joint_indices_from_names` 按名取 `idx_q`；两个 JointState 回调缓存；`run` 循环写 `pin_q/pin_dq` → `pin.centerOfMass` → 发布 `/com_pos`、`/com_vel`(Pose2D x,y)。局限见第 07 章 §6.3 |
| `filters.py` | `LowPassFilter`(`alpha=dt/(dt+tau)`)、`JointStateFilter`、`Pose2DFilter`(x 分支存在未定义变量 `i`)、`TwistFilter` |
| `arm_trajectory_node.py` | 服务 `/Arm/Action`(`pcl_msgs/UpdateFilename`)，读 YAML，首末点校验，`CubicSpline(clamped)`，按 `freq`(50) 发布 `JointCommand`(臂)与手命令 |
| `arm_trajectory_node_bk.py` | 旧格式(`left/right` 键)，与 `front_raise*.yaml` 匹配 |
| `traversal_arm_node.py` | Halton 序列在关节限位内采样、贪心排序、三次样条移动、`max_speed`、每点停 2 s、退出发零命令 |
| `data_collector_node.py` | 100 Hz 记录臂位置/速度与 `/controller_pos` 到 CSV，停止条件见第 08 章 |
| `config/dual_arm_params.yaml` | 遍历关节限位(当前为"双下垂"组) |
| `config/episodes/*.yaml` | `front_raise1–6`、`greet`、`shake`、`hug`、`dish_up/down` 等 |
| `launch/*.launch` | 质心 100 Hz；轨迹 50 Hz；遍历 `max_speed=0.2`、`num_samples=50/200` |

## 缺失部分（按学习笔记的快照结构理解，非逐行源码，面试以你亲手所写为准）

回调缓存 IMU/轮/cmd_vel/com_pos → 100 Hz 定时器 → 姿态/速度估计 → 外环(XLoop/YLoop，限幅) → 内环(Roll/Pitch/Yaw PID) → 加质心前馈 → `ik` → 整体范数限幅 → 低通 → 发布电机命令；跌倒阈值检查在周期开头。参数值见 README 口径备忘。
