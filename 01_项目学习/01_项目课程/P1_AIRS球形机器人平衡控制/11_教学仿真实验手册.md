## 1. 实验准备：模型、符号、环境

**它要解决什么问题。** 实机上做实验有风险、有成本、变量多（摩擦、延迟、电池电压都在变）。模型实验让你一次只改一个量，并且能"把世界关掉"：例如把延迟设为 0，看看理论极限；再把延迟加到 0.12 s，看机器人什么时候开始发散。它不能代替实机，但能给出**预言**（应该看到什么），这就是推荐信里所说"模型作为参照"的用法。

**符号与单位（与第 04 章一致，全部取教学数值）：**

| 符号 | 含义 | 教学值 |
|---|---|---|
| $m$、$J_b$ | 球质量、球转动惯量 | 1 kg、0 |
| $R$ | 球半径 | 1 m（归一化） |
| $M$、$l$、$I$ | 机体质量、质心到球心距离、机体绕质心惯量 | 1 kg、1 m、1 kg·m² |
| $g$ | 重力加速度 | 10 m/s² |
| $x,\dot x$ | 球的位置、速度 | m、m/s |
| $\theta,\dot\theta$ | 机体倾角（相对竖直）、倾角速度 | rad、rad/s |
| $\tau$ | 球与机体之间的内力矩（控制量） | 归一化 N·m |
| $d$ | 质心偏移（手臂外伸造成） | 0.04 m |

> **注意**：参数全部归一化，是为了让数字干净，不代表真实机器人。项目实机的球半径、质量等见 [README](./README.md) 的自查表。

**环境：** Python 3.9+，NumPy。第 1 节的 LQR 用 SciPy 的 `solve_continuous_are`；如果你的 SciPy 与 NumPy 版本冲突导入失败，下面的代码里附了一个只用 NumPy 的求解函数（Hamiltonian 特征值法）。两者结果一致。

## 2. 核心代码（一次性复制）

```python
import numpy as np
from collections import deque

# ---------- 教学模型（含反作用项 -tau）----------
m, Jb, R, M, l, I, g = 1, 0, 1, 1, 1, 1, 10
A11 = m + Jb / R**2 + M
A12 = M * l
A22 = M * l * l + I
Mi = np.linalg.inv([[A11, A12], [A12, A22]])
ft = Mi @ [0, M * g * l]          # 重力项在线性化后的系数
fu = Mi @ [1 / R, -1]             # 控制项（含反作用）
A = np.array([[0, 1, 0, 0], [0, 0, ft[0], 0], [0, 0, 0, 1], [0, 0, ft[1], 0]])
B = np.array([[0], [fu[0]], [0], [fu[1]]])

def care(A, B, Q, Rm):
    """只用 NumPy 的连续代数 Riccati 求解（Hamiltonian 特征值法）。"""
    n = A.shape[0]
    Ri = np.linalg.inv(Rm)
    H = np.block([[A, -B @ Ri @ B.T], [-Q, -A.T]])
    w, V = np.linalg.eig(H)
    X = V[:, w.real < 0]                      # 稳定子空间
    P = np.real(X[n:, :] @ np.linalg.inv(X[:n, :]))
    return (P + P.T) / 2

def lqr(Q, Ru):
    Rm = np.array([[Ru]])
    P = care(A, B, Q, Rm)
    return np.linalg.solve(Rm, B.T @ P)       # K，控制律 u = -K z

# ---------- 非线性被控对象 ----------
def f(z, tau, d=0.0):
    x, xd, th, thd = z
    c, s = np.cos(th), np.sin(th)
    Mm = np.array([[A11, A12 * c], [A12 * c, A22]])
    rhs = np.array([tau / R + A12 * s * thd**2,
                    M * g * l * s - tau + M * g * d * c])   # d: 质心偏移带来的重力矩
    xdd, thdd = np.linalg.solve(Mm, rhs)
    return np.array([xd, xdd, thd, thdd])

# ---------- 通用仿真：100 Hz 控制 + 1 kHz 积分 ----------
def sim(ctrl, z0, T=6.0, dt=0.001, ts=0.01, tau_max=None, delay=0.0, bias=0.0, d=0.0):
    z = np.array(z0, float)
    u, peak = 0.0, 0.0
    nd = int(round(delay / dt))
    q = deque([0.0] * nd)                     # 延迟线
    for i in range(int(T / dt)):
        if i % int(ts / dt) == 0:             # 控制器按 ts 采样、零阶保持
            zm = z.copy(); zm[2] += bias      # 测量里叠加倾角偏置
            u = float(ctrl(zm, i * dt))
            if tau_max: u = float(np.clip(u, -tau_max, tau_max))
        if nd > 0:
            q.append(u); tau = q.popleft()
        else:
            tau = u
        peak = max(peak, abs(tau))
        z = z + f(z, tau, d) * dt
        if abs(z[2]) > 1.2 or not np.isfinite(z).all():
            return z, peak, False             # 倒了
    return z, peak, True

K = lqr(np.diag([4, 4, 100, 1.]), 0.25)
lin = lambda z, t: (-K @ z).item()
```

**代码要点：**
- `f` 是**非线性**模型（带 $\sin,\cos$ 和 $\dot\theta^2$ 项），控制器按线性模型设计，这正是"线性设计、非线性验证"的标准做法；
- 控制器 100 Hz 采样并做零阶保持，对应实机主循环 100 Hz（README 自查表第 7 行）；
- `delay` 用队列模拟"传感→命令→电机"的纯延迟；`bias` 在测量的倾角上加常数，模拟 IMU 零偏；`d` 是质心偏移；
- 倾角超过 1.2 rad 就判定倒下。

## 3. 实验 1：LQR 增益与闭环极点

```python
print("K =", K)                              # 期望 [-4.00, -10.52, -46.11, -20.73]
print("poles =", np.linalg.eigvals(A - B @ K))
z, peak, ok = sim(lin, [0, 0, 0.05, 0])      # 初始倾角 0.05 rad
print("final", z.round(4), "peak tau", round(peak, 2), ok)
```

**期望输出：**
- $K=[-4.00,\,-10.52,\,-46.11,\,-20.73]$（与第 05 章一致）；
- 极点 $-4.47\pm1.88\mathrm j$ 与 $-0.64\pm0.40\mathrm j$：前一对是**内环（倾角）模态**，约 0.76 Hz；后一对是**位置模态**，约 0.12 Hz。两者之比约 6~7，这就是"外环比内环慢数倍"的数学来源（第 06 章）；
- 6 s 后状态接近 0；峰值控制量约 2.3~2.4（积分步长与零阶保持会让第二位小数略有差异）。

**这个实验对应项目里的什么：** 项目实机的闭环带宽（外环约 0.15 Hz、内环约 1 Hz）与这里的极点同一量级，所以第 06 章把 LQR 当作"内外环增益比例"的参照。

## 4. 实验 2：权重扫描（稳定性 vs 控制力度）

```python
for qth in [10, 100, 1000]:
    Kk = lqr(np.diag([4, 4, qth, 1.]), 0.25)
    z, peak, ok = sim(lambda z, t: (-Kk @ z).item(), [0, 0, 0.05, 0])
    print(qth, Kk.round(2), "peak", round(peak, 2), ok)
```

**期望结果：**

| $q_\theta$ | $K$ | 峰值 $\lvert\tau\rvert$ |
|---|---|---|
| 10 | $[-4,\,-9.64,\,-38.75,\,-19.1]$ | 约 1.94 |
| 100 | $[-4,\,-10.52,\,-46.11,\,-20.73]$ | 约 2.31 |
| 1000 | $[-4,\,-14.22,\,-84.25,\,-27.65]$ | 约 4.21 |

**解读：** 倾角权重越大，倾角增益 $k_\theta$ 越大、峰值控制量越大——这就是"稳定性与控制力度的折中"：更紧地抓住倾角，要花更大的力矩，而项目里力矩（轮命令）是有限幅的（整体 L2 限幅约 8），所以权重不能无限加大。注意 $k_x=-4$ 基本不变，因为位置权重没动。

## 5. 实验 3：力矩限幅与最大可恢复倾角

```python
for th0 in [0.05, 0.1, 0.15, 0.2, 0.25, 0.3]:
    res = [sim(lin, [0, 0, th0, 0], tau_max=tm, T=8)[2] for tm in (2.0, 3.0, 4.0)]
    print(th0, res)
```

**期望结果：** 限幅 $\tau_{\max}=2$ 时，初始倾角到 0.2 rad 仍可恢复，0.25 rad 开始倒；限幅 3 或 4 时，0.3 rad 仍能恢复。

**解读：** 命令贴限幅会把有效增益砍掉，降到约 $0.25K$ 以下就不稳。所以"能恢复的最大倾角"由执行器余量决定，这正是第 09 章故事 4（手推后命令贴限幅、随后倒下）的模型解释：项目里把外环参考上限从 0.15 降到 0.10 rad，就是在给执行器留余量。

**扩展：** 把 `tau_max` 改成 1.5、1.0，看最大可恢复倾角怎么缩小；画出"限幅—最大倾角"曲线。

## 6. 实验 4：控制延迟与失稳边界

```python
for dl in [0.0, 0.05, 0.08, 0.10, 0.11, 0.12, 0.14]:
    z, peak, ok = sim(lin, [0, 0, 0.02, 0], delay=dl, T=8)
    print(dl, ok, abs(z[2]).round(3))
```

**期望结果：** 延迟到约 0.10 s 以内倾角衰减到几乎 0；0.11~0.12 s 出现持续振荡（边缘稳定，0.12 s 时残余倾角仍有 0.2 rad 量级）；0.14 s 发散倒下。失稳边界约 0.11~0.13 s。

**解读：** 教学模型的不稳定极点约 $\sqrt{g/l}\approx3.2$ rad/s，延迟与它的乘积接近 0.4 时就进入边缘。项目实机的端到端延迟典型约 15 ms、最坏约 25 ms（README 第 7 行、第 08 章预算表），比教学模型的边界小一个数量级，这就是为什么"陀螺不能加 0.8 Hz 低通"：那会带来约 0.2 s 的延迟，直接越过边界；0.8 Hz 的低通只能加在外环的速度估计这条慢路径上（第 03 章）。

## 7. 实验 5：IMU 倾角偏置造成的位置漂移

```python
b = np.deg2rad(1.0)                              # IMU 零偏 1 度
z, peak, ok = sim(lin, [0, 0, 0, 0], bias=b, T=10)
print("x_end =", z[0].round(3), " 预测 =", (-K[0, 2] / K[0, 0] * b).round(3))
```

**期望结果：** 约 $-0.20$ m，预测 $-0.201$ m。公式 $x_{ss}=-(k_\theta/k_x)\,b$，教学增益下 $k_\theta/k_x\approx11.5$ m/rad。

**解读：** 机器人"以为"自己在竖直位置，其实偏了 1°；为了让测量到的倾角为 0，它把自己的真实位置推到 0.2 m 外。这是第 09 章故事 1（静止缓慢爬行）的模型版本。项目取值里，外环位置增益 $K_{px}=0.08$ rad/m，偏置 $b$ 对应的漂移是 $b/K_{px}$，1° 约 0.22 m，量级一致。

**扩展：** 把偏置改为 0.5°、2°，验证线性；再在控制器里加"使能时采偏置并扣除"，看漂移消失。

## 8. 实验 6：级联控制的 1 m 阶跃（非最小相位）

```python
def run_cascade(xt, thmax, Kpx=0.08, Kdx=0.2, T=40, dt=0.001, ts=0.01):
    z = np.zeros(4); u = 0.0; xs = []
    for i in range(int(T / dt)):
        if i % int(ts / dt) == 0:
            thref = np.clip(Kpx * (xt - z[0]) + Kdx * (0 - z[1]), -thmax, thmax)   # 外环：有界倾角参考
            u = 46.1 * (z[2] - thref) + 20.7 * z[3]                                # 内环：角度 + 陀螺
        z = z + f(z, u) * dt
        xs.append(z[0])
    return np.array(xs)

for thmax in (0.02, 0.1):
    xs = run_cascade(1.0, thmax)
    print(thmax, "最小位置(反向位移)", xs.min().round(4), "终值", xs[-1].round(3))
```

**期望结果：** 参考上限 0.02 rad 时反向位移约 $-1.3$ cm，响应较慢（约 6 s 到 95%）；上限 0.1 rad 时反向位移约 $-6$ cm，约 4.6~5 s 到 95%。两种情况最终都到 1 m。

**解读：** 球要向前走，机体必须先前倾，而机体前倾要球先向后拨，所以位置会**先朝反方向走一点**。参考上限越大，这个反向位移越大、响应越快——"安全与速度的折中"。项目取 $\theta_{\max}=0.10$ rad。

> **注意**：这里的内环增益直接取 LQR 的等效值；项目实机的内环 $K_{p\theta}\approx40$、$K_{d\theta}\approx20$ 是命令单位，与教学归一化模型不是同一量纲，只借用比例关系（$K_d/K_p\approx0.45$~0.5 s）。

## 9. 实验 7：质心偏移与三种前馈

```python
for name, uff in [("无", 0.0), ("Mgd", 0.4), ("Kp*d/l", 1.84)]:
    z, _, ok = sim(lambda z, t: (-K @ z).item() + uff, [0, 0, 0, 0], T=40, d=0.04)
    print(name, "静止时球的位置偏移", z[0].round(4))
```

**期望结果：** 无前馈约 0.461 m；加物理重力矩 $Mgd=0.4$ 仅降到 0.361 m；加带标定因子的 $K_{p\theta}d/l=1.84$ 后约 0.0009 m（可以认为为 0）。

**解读：** 质心偏了 $d$，平衡点（真正的竖直）就偏成 $\theta_{eq}=-d/l$。ballbot 不能靠电机持续输出力矩去顶住重力（那会让球一直加速），只能改变倾角让重力矩自己归零，所以前馈要乘上 $K_{p\theta}/(Mgl)$ 这个因子，把姿态环的零点挪到新平衡点。项目里这个因子就是整定量 $K_{tff}\approx1.0$（归一化后），关前馈到开前馈，倾角峰值由 0.060 降到 0.026 rad（README 第 23 行）。

**扩展：** 把前馈符号反过来，看漂移变成两倍；这是第 09 章故事 3（抬臂就倒）的模型版本。

## 10. 仿真和实机怎么对应

| 仿真现象 | 实机对应 | 量级差别 |
|---|---|---|
| 极点比 6~7 | 内环约 1 Hz、外环约 0.15 Hz | 同一量级 |
| 延迟边界 0.11~0.13 s | 端到端 15~25 ms | 实机留有约 5 倍余量 |
| 偏置 1° → 0.2 m | 1° → 约 0.22 m | 同一量级 |
| 最大可恢复倾角由限幅决定 | 参考上限 0.10 rad，限幅约 8 | 量纲不同，只借逻辑 |
| 前馈带标定因子 | $K_{tff}\approx1.0$ | 仿真里 $K_{p\theta}/(Mgl)\approx4.6$，实机归一化不同 |

**诚实边界：** 仿真是归一化教学模型，没有摩擦、轮子打滑、电机动态、传感器噪声，也没有手臂的多体动力学。面试里说"在模型里看到""模型预言"，不要说"仿真证明了实机"。

## 11. 面试怎么问、怎么答

**Q1. How did you use the simulation or the model?**
> I used a four-state linearised inverted-pendulum model with LQR as a reference, not as the deployed controller. In simulation I could change one thing at a time: the state weights, the torque limit, the delay, a tilt offset. For example, a one-degree tilt offset moved the robot about 0.2 metres in the model, and I then saw the same kind of slow creep on the robot, which pointed me to the offset captured at enable.

中文：LQR 作为参照而不是部署；仿真可单变量实验；1° 偏置在模型里推 0.2 m，实机看到同类爬行，从而定位到使能时的偏置采集。
追问 L2: *Did you test on the robot with those gains?* — "No. I used the ratios, like damping to proportional, as a starting point, and tuned on the robot." L3: *Why not deploy LQR?* — "Model mismatch, limits and anti-windup, and the need to tune quickly on hardware; the cascade is easier to tune and explain."

**Q2. What does the delay experiment tell you?**
> That delay eats phase margin against the unstable pole. In the model the loop fails around 0.12 seconds of delay. On the robot the end-to-end delay was about 15 milliseconds, so there was plenty of margin, but it also tells me not to put a heavy filter on the gyro path.

**Q3. Why does the robot move backwards first when commanded forward?**
> It is non-minimum phase. To lean forward, the ball has to move back under the body. In simulation, with a tilt-reference bound of 0.1 radians the reverse displacement is about 6 centimetres, with 0.02 radians about 1.3 centimetres.

## 本章要点速记

1. 线性设计（LQR）+ 非线性验证（完整 $\sin,\cos$ 模型）是标准流程。
2. $K=[-4,-10.52,-46.11,-20.73]$（$Q=\mathrm{diag}(4,4,100,1)$、$R_u=0.25$），内外环极点比约 6~7。
3. 倾角权重↑ → 倾角增益↑、峰值力矩↑。
4. 命令限幅决定最大可恢复倾角。
5. 延迟边界约 0.11~0.13 s（教学模型）；实机延迟远小于它。
6. 偏置 $b$ 造成稳态漂移 $-(k_\theta/k_x)b$。
7. 参考上限越大，反向位移（非最小相位）越大、响应越快。
8. 前馈要带标定因子 $K_{p\theta}/(Mgl)$，不是纯物理重力矩。

## 自测题

1. 为什么仿真里控制器要用 100 Hz 采样、而积分用 1 kHz？（模拟实机离散控制 + 连续对象。）
2. 实验 5 中偏置 0.5°，漂移多少？（约 0.1 m。）
3. 限幅从 2 增到 4，最大可恢复倾角怎么变？（变大，原因是有效增益保留得更多。）
