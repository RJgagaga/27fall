# 11 教学仿真实验手册

> 用 Python(NumPy+SciPy)复现第 04–05 章的教学结论。参数为教学数值，非项目实测。

```python
import numpy as np
from scipy.linalg import solve_continuous_are

m,Jb,R,M,l,I,g = 1,0,1,1,1,1,10
A11=m+Jb/R**2+M; A12=M*l; A22=M*l*l+I
Mi=np.linalg.inv([[A11,A12],[A12,A22]])
ft=Mi@[0,M*g*l]; fu=Mi@[1/R,-1]          # 含反作用项
A=np.array([[0,1,0,0],[0,0,ft[0],0],[0,0,0,1],[0,0,ft[1],0]]); B=np.array([[0],[fu[0]],[0],[fu[1]]])
Q=np.diag([4,4,100,1.]); Ru=np.array([[0.25]])
P=solve_continuous_are(A,B,Q,Ru); K=np.linalg.solve(Ru,B.T@P)
print("K =",K, "poles =",np.linalg.eigvals(A-B@K))   # 期望 K≈[-4,-10.52,-46.11,-20.73]

def f(z,tau):                                   # 非线性模型
    x,xd,th,thd=z; c,s=np.cos(th),np.sin(th)
    Mm=np.array([[A11,A12*c],[A12*c,A22]]); rhs=np.array([tau/R+A12*s*thd**2, M*g*l*s-tau])
    xdd,thdd=np.linalg.solve(Mm,rhs); return np.array([xd,xdd,thd,thdd])

z=np.array([0,0,0.05,0.]); dt=0.001; peak=0
for i in range(6000):
    if i%10==0: tau=float((-K@z).item()); peak=max(peak,abs(tau))   # 100 Hz 控制
    z=z+f(z,tau)*dt
print("final",z,"peak tau",peak)             # 期望 峰值约 2.36
```

## 实验清单

1. 权重扫描：改 `Q`/`Ru`，对比 K、峰值力矩、位移（第 05 章表）。
2. 力矩限幅：在 `tau` 处加 `np.clip`，搜索最大可恢复初始倾角。
3. 延迟：用缓冲队列给 `tau` 加延迟，找失稳延迟(约 0.11–0.12 s)。
4. 偏置：给测量的 `th` 加 `b`，验证 $x_{ss}=-(k_\theta/k_x)b$。
5. 级联：外环 $\theta_{ref}=\text{clip}(\ldots)$，内环 $\tau=46.1(\theta-\theta_{ref})+20.7\dot\theta$，做 1 m 阶跃，观察先后退。
6. 质心扰动：在第二方程加 $Mgd$，对比无前馈、$Mgd$、$K_{p\theta}d/l$ 三种前馈。
