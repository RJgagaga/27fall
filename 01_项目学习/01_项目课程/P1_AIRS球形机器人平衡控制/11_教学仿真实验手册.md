## 1. 实验准备：模型、符号、环境、运行方法

**它要解决什么问题。** 实机上做实验有风险、有成本、变量多（摩擦、延迟、电池电压都在变）。模型实验让你一次只改一个量，并且能"把世界关掉"：例如把延迟设为 0，看看理论极限；再把延迟加到 0.12 s，看机器人什么时候开始发散。它不能代替实机，但能给出**预言**（应该看到什么），这就是推荐信里所说"模型作为参照"的用法。

**符号与单位（与第 04 章一致，全部取教学数值）：**

| 符号 | 含义 | 教学值 |
|---|---|---|
| $m$、$J_b$ | 球质量、球转动惯量 | 1 kg、0 |
| $R$ | 球半径 | 1 m（归一化） |
| $M$、$l$、$I$ | 机体质量、质心到球心距离、机体绕质心惯量 | 1 kg、1 m、1 kg·m² |
| $g$ | 重力加速度 | 10 m/s²（质心手算部分用 9.81） |
| $x,\dot x$ | 球的位置、速度 | m、m/s |
| $\theta,\dot\theta$ | 机体倾角（相对竖直）、倾角速度 | rad、rad/s |
| $\tau$ | 球与机体之间的内力矩（控制量） | 归一化 N·m |
| $d$ | 质心偏移（手臂外伸造成） | 0.04 m |
| $T_s$ | 控制周期 | 0.01 s（100 Hz），积分步长 1 ms |

> **注意**：模型参数归一化是为了让数字干净，不代表真实机器人。项目实机的球半径、质量等设计取值见 [README](./README.md) 的自查表；S1 的第二个矩阵就用了项目取值 $R=0.20$ m、$r=0.05$ m、$\beta=45^\circ$。

**环境（本机实际运行）：** Windows 11；Python 3.12.4；NumPy 2.2.6。**脚本刻意不依赖 SciPy**：本机的 SciPy 1.13.1 与 NumPy 2.2.6 版本不兼容，`import scipy.linalg` 会报 `numpy.core.multiarray failed to import`。脚本里自带了三样替代：Hamiltonian 特征值法求连续 Riccati（`care`）、缩放平方 + 泰勒的矩阵指数（`expm_np`）、迭代求离散 Riccati（`dare_iter`），再加上 clamped 三次样条（`ClampedSpline`，等价于 `CubicSpline(bc_type='clamped')`）。如果你的环境里 SciPy 正常，也可以改回 `scipy.linalg.solve_continuous_are`，结果一致。

```python
# 运行：python p1_sim_lab.py            （全部）   python p1_sim_lab.py S5   （只跑某一节）

from collections import deque

np.set_printoptions(precision=4, suppress=True, linewidth=120)
SEL = sys.argv[1:]          # 例如 ["S5"]；为空则全部运行

# ------------------------------------------------------------------ 教学模型（含反作用项 -tau）
m, Jb, R, M, l, I, g = 1.0, 0.0, 1.0, 1.0, 1.0, 1.0, 10.0
A11 = m + Jb / R**2 + M
A12 = M * l
A22 = M * l * l + I
Mi = np.linalg.inv([[A11, A12], [A12, A22]])
ft = Mi @ [0, M * g * l]
fu = Mi @ [1 / R, -1]
A = np.array([[0, 1, 0, 0], [0, 0, ft[0], 0], [0, 0, 0, 1], [0, 0, ft[1], 0]])
B = np.array([[0], [fu[0]], [0], [fu[1]]])


def care(A, B, Q, Rm):
    """只用 NumPy 的连续代数 Riccati 求解（Hamiltonian 特征值法）"""
    n = A.shape[0]
    Ri = np.linalg.inv(Rm)
    H = np.block([[A, -B @ Ri @ B.T], [-Q, -A.T]])
    w, V = np.linalg.eig(H)
    X = V[:, w.real < 0]
    P = np.real(X[n:, :] @ np.linalg.inv(X[:n, :]))
    return (P + P.T) / 2


def lqr(Q, Ru, A=A, B=B):
    Rm = np.array([[Ru]])
    P = care(A, B, Q, Rm)
    return np.linalg.solve(Rm, B.T @ P)          # u = -K z


def f(z, tau, d=0.0):
    x, xd, th, thd = z
    c, s = np.cos(th), np.sin(th)
    Mm = np.array([[A11, A12 * c], [A12 * c, A22]])
    rhs = np.array([tau / R + A12 * s * thd**2,
                    M * g * l * s - tau + M * g * d * c])
    xdd, thdd = np.linalg.solve(Mm, rhs)
    return np.array([xd, xdd, thd, thdd])


def sim(ctrl, z0, T=6.0, dt=0.001, ts=0.01, tau_max=None, delay=0.0, bias=0.0, d=0.0):
    z = np.array(z0, float)
    u, peak = 0.0, 0.0
    nd = int(round(delay / dt))
    q = deque([0.0] * nd)
    for i in range(int(T / dt)):
        if i % int(round(ts / dt)) == 0:
            zm = z.copy(); zm[2] += bias
            u = float(ctrl(zm, i * dt))
            if tau_max:
                u = float(np.clip(u, -tau_max, tau_max))
        if nd > 0:
            q.append(u); tau = q.popleft()
        else:
            tau = u
        peak = max(peak, abs(tau))
        z = z + f(z, tau, d) * dt
        if abs(z[2]) > 1.2 or not np.isfinite(z).all():
            return z, peak, False
    return z, peak, True



# ------------------------------------------------------------------ 纯 NumPy 工具（避免 SciPy 与 NumPy 版本冲突）
def expm_np(Mx, terms=30):
    """矩阵指数：缩放平方 + 泰勒展开"""
    nrm = np.linalg.norm(Mx, 1)
    k = max(0, int(np.ceil(np.log2(max(nrm, 1e-12)))) + 1)
    X = Mx / (2 ** k)
    E = np.eye(Mx.shape[0]); T = np.eye(Mx.shape[0])
    for i in range(1, terms):
        T = T @ X / i; E = E + T
    for _ in range(k):
        E = E @ E
    return E


def dare_iter(Ad, Bd, Q, Rm, iters=200000):
    """离散 Riccati 迭代求解"""
    P = Q.copy()
    for _ in range(iters):
        G = Rm + Bd.T @ P @ Bd
        Pn = Q + Ad.T @ P @ Ad - Ad.T @ P @ Bd @ np.linalg.solve(G, Bd.T @ P @ Ad)
        if np.max(np.abs(Pn - P)) < 1e-12:
            return Pn
        P = Pn
    return P


class ClampedSpline:
    """clamped 三次样条（两端一阶导数为 0），等价于 scipy CubicSpline(bc_type='clamped')"""
    def __init__(self, t, y):
        t = np.asarray(t, float); y = np.asarray(y, float); n = len(t); h = np.diff(t)
        # 对二阶导数 M_i 求解: C2 连续 + 端点斜率 0
        Am = np.zeros((n, n)); rhs = np.zeros(n)
        Am[0, 0] = 2 * h[0]; Am[0, 1] = h[0]; rhs[0] = 6 * ((y[1] - y[0]) / h[0] - 0.0)
        Am[-1, -1] = 2 * h[-1]; Am[-1, -2] = h[-1]; rhs[-1] = 6 * (0.0 - (y[-1] - y[-2]) / h[-1])
        for i in range(1, n - 1):
            Am[i, i - 1] = h[i - 1]; Am[i, i] = 2 * (h[i - 1] + h[i]); Am[i, i + 1] = h[i]
            rhs[i] = 6 * ((y[i + 1] - y[i]) / h[i] - (y[i] - y[i - 1]) / h[i - 1])
        self.t, self.y, self.h, self.M = t, y, h, np.linalg.solve(Am, rhs)

    def __call__(self, x, nu=0):
        x = np.atleast_1d(np.asarray(x, float)); out = np.zeros_like(x)
        for k, xv in enumerate(x):
            i = int(np.clip(np.searchsorted(self.t, xv, side="right") - 1, 0, len(self.h) - 1))
            h = self.h[i]; a = self.t[i + 1] - xv; b = xv - self.t[i]
            Mi_, Mj = self.M[i], self.M[i + 1]; yi, yj = self.y[i], self.y[i + 1]
            if nu == 0:
                out[k] = Mi_ * a**3 / (6 * h) + Mj * b**3 / (6 * h) + (yi / h - Mi_ * h / 6) * a + (yj / h - Mj * h / 6) * b
            elif nu == 1:
                out[k] = -Mi_ * a**2 / (2 * h) + Mj * b**2 / (2 * h) - (yi / h - Mi_ * h / 6) + (yj / h - Mj * h / 6)
            else:
                out[k] = (Mi_ * a + Mj * b) / h
        return out

    def crc16(data):
        crc = 0
        for v in data:
            crc ^= v << 8
            for _ in range(8):
                crc = ((crc << 1) ^ 0x1021) & 0xFFFF if crc & 0x8000 else (crc << 1) & 0xFFFF
        return crc

    def crc8_table(poly_r):
        t = []
        for i in range(256):
            c = i
            for _ in range(8):
                c = (c >> 1) ^ poly_r if c & 1 else c >> 1
            t.append(c)
        return t

            payload = stream[i + 7:i + 7 + ln]
            if ((stream[i + 5] << 8) | stream[i + 6]) != crc16(payload):
                errs["crc16"] += 1; i += 1; continue
            if stream[i + 7 + ln] != 0xFD:
                errs["end"] += 1; i += 1; continue
            out.append((ftype, sn, payload)); i = end
        return out, errs

    stream = b''.join(make_frame(0x41 if k % 2 else 0x40, ahrs if k % 2 else imu, k) for k in range(20))
    out, errs = parse(stream)
    print("干净流: 解析帧数 =", len(out), " 错误计数 =", errs)
    # 1) 翻转一个 payload 位 -> CRC16 错误，丢一帧
    bad = bytearray(stream); bad[7 + 5] ^= 0x01
    out, errs = parse(bytes(bad)); print("payload 翻1位: 解析帧数 =", len(out), " 错误 =", errs)
    # 2) 删掉中间 10 个字节 -> 错位后重新同步
    cut = stream[:200] + stream[210:]
    out, errs = parse(cut); print("中间丢10字节: 解析帧数 =", len(out), " 错误 =", errs)
    # 3) 序号丢失统计（复现 checkSN）
    sns = [sn for _, sn, _ in parse(stream)[0]]
    lost = 0; read_sn = sns[0] - 1
    for sn in sns:
        read_sn = (read_sn + 1) & 0xFF
        if read_sn != sn:
            lost += (sn - read_sn) % 256; read_sn = sn
    print("序号连续，丢失 =", lost)
    out_d, _ = parse(b''.join(make_frame(0x41, ahrs, k) for k in (0, 1, 2, 5, 6)))
    sns = [sn for _, sn, _ in out_d]; lost = 0; read_sn = sns[0] - 1
    for sn in sns:
        read_sn = (read_sn + 1) & 0xFF
        if read_sn != sn:
            lost += (sn - read_sn) % 256; read_sn = sn
    print("序号 0,1,2,5,6 -> 统计丢失 =", lost, "（应为 2）")
    # 解码 AHRS payload
    vals = struct.unpack('<10fq', parse(stream)[0][1][2])
    print("解码 AHRS: pitch(rad)=%.4f  Qw=%.4f Qy=%.4f  timestamp(us)=%d" % (vals[4], vals[6], vals[8], vals[10]))
```

**代码要点：**

- `f` 是**非线性**模型（带 $\sin,\cos$ 和 $\dot\theta^2$ 项），控制器按线性模型设计——这正是"线性设计、非线性验证"的标准做法；
- `sim` 里控制器按 `ts=0.01` 采样并零阶保持，对应实机主循环 100 Hz；`delay` 用队列模拟"传感→命令→电机"的纯延迟；`bias` 在测量的倾角上加常数，模拟 IMU 零偏；`d` 是质心偏移；倾角超过 1.2 rad 判定倒下；
- `sect(...)` 让每一节可以单独运行；`lin = lambda z,t: (-K@z).item()` 是 LQR 控制律（$\tau=-K\mathbf z$）；
- S8 的解析器 `parse` 是对 `ahrs_driver.cpp` 里 `processLoop` 的**逻辑复现**（不是移植），判断顺序与源码一致：头字节 → 类型 → 长度 → CRC8 → CRC16 → 帧尾，任一失败丢弃一个字节后继续找头。

- 干净流 20 帧全部解析，错误计数全 0；

## 13. 扩展练习

1. **画出限幅—最大倾角曲线：** 把 S3 的最大可恢复倾角扫描扩展到 $\tau_{\max}=0.25,\dots,6$，拟合斜率，与"粗上界 $\tau_{\max}/6.67=0.15\tau_{\max}$"对比。
2. **延迟 × 权重：** 对 $R_u=0.25$ 与 $R_u=0.025$ 分别求延迟边界，验证"增益越高延迟余量越小"。
3. **加入陀螺低通：** 在 `sim` 的测量里对 $\dot\theta$ 加 0.8 Hz 与 25 Hz 一阶低通，比较阻尼比和延迟边界，复现"陀螺不能加 0.8 Hz 低通"。
4. **偏置采样模拟：** 在测量里加 $\sigma=0.002$ rad 的高斯噪声，对 200 帧均值做 1000 次统计，验证标准误差 $\sigma/\sqrt{200}$。
5. **跌倒检测接入仿真：** 在 `sim` 里加入 0.5 rad、5 周期的判据，把倾角序列送进去，统计触发延迟；再加入 1% 概率的单帧 0.9 rad 毛刺，验证误触发率。

## 14. 面试怎么问、怎么答

**Q1. How did you use the simulation or the model?**

> I used a four-state linearised inverted-pendulum model with LQR as a reference, not as the deployed controller. In simulation I could change one thing at a time: the state weights, the torque limit, the delay, a tilt offset. For example, a one-degree tilt offset moved the robot about 0.2 metres in the model, and I then saw the same kind of slow creep on the robot, which pointed me to the offset captured at enable.

中文：LQR 作为参照而不是部署；仿真可单变量实验；1° 偏置在模型里推 0.2 m，实机看到同类爬行，从而定位到使能时的偏置采集。

- L2：*Did you test on the robot with those gains?* — "No. I used the ratios, like damping to proportional, as a starting point, and tuned on the robot."
- L3：*Why not deploy LQR?* — "Model mismatch, limits and anti-windup, and the need to tune quickly on hardware; the cascade is easier to tune and explain."

**Q2. What does the delay experiment tell you?**

> That delay eats phase margin against the unstable pole. In the model the loop fails around 0.12 to 0.14 seconds of delay. On the robot the end-to-end delay was about 15 milliseconds, so there was plenty of margin, but it also tells me not to put a heavy filter on the gyro path.

中文：延迟吃掉对不稳定极点的相位裕度；模型约 0.12～0.14 s 失稳；实机 15 ms 余量大，但提醒陀螺路径不能加重滤波。

- L2：*Why can you not quote 0.12 s as your robot's limit?* — "It is a normalised teaching model; the number tells me the scaling, not the hardware."
- L3：*How would you measure the real limit?* — "Insert an artificial delay in the command path on a gantry at low gain and watch for onset of oscillation."

**Q3. Why does the robot move backwards first when you command forward?**

> It is non-minimum phase. To lean forward, the ball has to move back under the body. In simulation, with a tilt-reference bound of 0.1 radians the reverse displacement is about 6 centimetres, with 0.02 radians about 1.3 centimetres.

中文：非最小相位；球要先后拨机体才前倾；参考上限 0.1 rad 时反向约 6 cm，0.02 rad 时约 1.3 cm。

- L2：*What does that imply for the bound?* — "A larger bound is faster but has a larger undershoot and demands more torque, so it is a safety-speed trade-off."
- L3：*Is this the same as overshoot?* — "No, overshoot is crossing the target; undershoot here is the system's own initial reverse motion."

**Q4. Can you reproduce your parsing and safety numbers without the robot?**

> Yes, in a short NumPy script. It rebuilds the controller's delay budget and CAN load, runs a fall-debounce check on synthetic tilt sequences, and re-implements the IMU frame parser to show that a flipped bit or ten missing bytes costs only one frame. They are arithmetic checks of design values, not measurements.

中文：能，用一个 NumPy 脚本重建延迟预算、CAN 负载、跌倒去抖，并复现 IMU 帧解析（翻一位或丢 10 字节只损失一帧）；这些是设计取值的算术验证，不是实测。

- L2：*Why bother?* — "It checks my reasoning and gives me expected numbers to compare with the logs."
- L3：*What is the risk?* — "Quoting teaching numbers as measurements; I label them every time."

## 本章要点速记

1. 线性设计（LQR）+ 非线性验证（完整 $\sin,\cos$ 模型）是标准流程；脚本只依赖 NumPy，自带 Riccati、矩阵指数、样条。
2. $K=[-4,-10.52,-46.11,-20.73]$（$Q=\mathrm{diag}(4,4,100,1)$、$R_u=0.25$），内外环极点比约 6.4。
3. 倾角权重↑ → 倾角增益↑、峰值力矩↑；$|k_x|=\sqrt{q_x/R_u}$ 精确成立。
4. 命令限幅决定最大可恢复倾角（约 $0.11\tau_{\max}$）；增益整体低于 $0.25$～$0.3K$ 失稳。
5. 延迟边界约 0.12～0.14 s（教学模型）；实机延迟远小于它。
6. 偏置 $b$ 造成稳态漂移 $-(k_\theta/k_x)b$，与 $b$ 成线性。
7. 参考上限越大，反向位移（非最小相位）越大、响应越快。
8. 前馈要带标定因子 $K_{p\theta}/(Mgl)$；符号反则漂移是无前馈的两倍。
9. 慢速固定轨迹的动态项约占静态的 3.6%；CAN 负载 10% 以内；去抖 5 周期防单帧毛刺。
10. IMU 帧三道校验，坏帧只丢一帧，逐字节重新同步。
