# P1 AIRS 球形机器人（ballbot）平衡控制

> **一句话定位**：CV 中 AIRS 实习（Sep 2025 – Mar 2026）。三全向轮球形机器人 + 双臂上肢，你负责平衡控制开发与实机整定：级联 PID、四状态倒立摆 + LQR 分析、URDF/Pinocchio 质心前馈、ROS+CAN 安全执行闭环。

## 一页纸

| 项 | 内容 |
|---|---|
| 对象 | 三全向轮 ballbot + 双臂；双臂沿固定轨迹运动时底盘保持动态平衡 |
| 控制主线 | IMU + 轮速 → 位置外环 → **有界**姿态参考 → 姿态内环 → 三轮运动学分配 → CAN 电机 |
| 模型分析 | 四状态线性倒立摆 + LQR，权重的稳定性/控制量折中；作为 PID 整定、状态异常、执行器饱和的**模型参照**（未上机） |
| 前馈 | URDF/Pinocchio 由臂关节角估计质心偏移 → roll/pitch 重力前馈；固定轨迹下开/关对比验证 |
| 安全 | 状态初始化、输出限幅、跌倒检测与恢复 |
| 证据 | CV、导师 Chen Dansheng 推荐信、`项目源码/AIRS/Robot/{fdilink_ahrs,arm_controller}`（底盘控制器/驱动源码缺失） |

## 符号约定

| # | 源码/资料中的情况 | 面试怎么处理 |
