## 2. 阅读顺序与要点
1. **XArmcontroller.py**：`_pack_mit`/`_parse_frame`（07 章）、`enable_all`、`default_params`。
2. **v2**：`_pack` 钳位、`MECH_LIM`、`arm_control`（插值 + 稳定阶段）、`_run_parallel`。
3. **gravity_comp.py**：`ArmDynamics`、主循环 `total = g·scale + c·0.1 + f·0.3`（06 章）。
4. **nullspace_control.py**：`compute()` 的 SVD→λ→J_null→N；`_safe_limit`；`ramp_down_tau`。
5. **URDF**：`inertial`、`axis`、`limit`（05/06 章表格来源）。
6. **底盘**：`main.c` → `controler_task.c` → `chassis_task.c` → `bsp_fdcan.c` → `drv_8030.c`（09 章）。

## 3. 证据与口径
- 可确凿引用：MIT 编码、重力补偿循环、URDF 数据、底盘固件全部逻辑。
- 只能依赖笔记/CV：Mink 求解器、VR 映射、`ROLE_LEADER/FOLLOWER`、`gravity_comp_ratio=[1,1,1,1,1,1,0.8]`、话题 `/dual_xarm/joints`。
- "函数存在 ≠ 被调用"：Coriolis/摩擦、`pid_calc`、SVD 零空间路径均要核对活动分支。
- 参考实现（Python/Pinocchio）≠ 项目实现（C++/KDL）。

## 4. 面试用法
被问"代码在哪证明"时：说明架构与关键函数，诚实区分"我实现的"与"我读懂并用于验证的"。本项目的分工（见 README 自查表 #18）：我负责 VR 相对位姿映射与 Mink 约束 IK 的配置与整定、主臂重力补偿参数与从臂跟踪增益的整定、差速运动学/轮速 PID/里程计与 ROS 2 的集成；电机 MIT 驱动封装（XArmcontroller）、STM32 底盘 CAN 框架和 VR 采集端是团队已有代码，我读懂并用于验证。
