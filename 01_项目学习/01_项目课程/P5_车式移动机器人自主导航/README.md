# P5 车式移动机器人自主导航：学习总入口

> **一句话定位**：P5 是 2025 年 6–10 月的实验室项目（傅向华教授指导）：在一辆车式（Ackermann）移动机器人上，负责从多传感器定位、避障规划到 MPC 轨迹跟踪的算法链，并在实车上实现自主导航。本目录把这条链从原理到面试口述讲成教材。

## 一页纸概要（CV 口径）

- **EKF/AMCL 定位**：融合 IMU、轮式编码器、2D LiDAR 做地图定位；处理时间、坐标系、运动方向不一致引起的漂移与位姿跳变；输出连续车辆状态。
- **Hybrid-A\* 全局规划**：把航向与运动学约束放进搜索；在车体外形、最小转弯半径、障碍代价约束下生成可行全局路径。
- **TEB 局部轨迹优化**：在全局路径与局部代价地图约束下优化时间参数化轨迹，随局部障碍变化输出连续位姿与曲率参考。
- **MPC 轨迹跟踪**：基于车式运动学模型，在位置、航向、速度、转向约束下滚动优化，在实车上闭环。

主线一句话：定位给出连续可信的状态 → Hybrid-A* 给可行大路线 → TEB 给带时间的局部轨迹 → MPC 把轨迹落到实车。

## 口径备忘（仅自查，面试按 CV 说）

- 面试一律按 CV：EKF/AMCL、Hybrid-A*、TEB、MPC 四件事；你负责"从多传感器定位到 MPC 跟踪的算法链"。
- 学习笔记中提到的、来自历史配置的线索（如某些版本使用 Navfn/RPP/L1 路径，以及设备尺度的指令数值）与 CV 的算法链描述不一致。教材不采用这些线索；面试按 CV 说，若被问到版本差异，只说你确知的事实，不确定的不说。
- 教材中的软件包参数（robot_localization、amcl、teb_local_planner、Nav2 Smac）是公开包的通用机制，不代表项目一定使用；用到哪个以你的真实情况为准。
- 正文中标为“教学示例”的数字不要当成项目数据；项目数据以上面的自查表为准，正文、自查表、99 口述三处保持一致。
