## 4. 易混概念对照

| 容易混的两个概念 | 区别 |
|---|---|
| ROS2 Action vs action-proposal | 前者是 ROS2 的异步目标接口；后者是安全链第一阶段的结构化提案 |
| 发现 vs 注册 vs 可用 | 网络上有人 / 知道它能做什么 / 状态健康且新鲜 |
| 有效期 vs 看门狗 | 命令本身何时失效 / 发送者是否还活着 |
| 提案有效期 vs 凭据有效期 | 防过期/重放 / 防校验与执行之间的状态变化 |
| 限幅 vs 修改 vs 拒绝 | 限幅是手段；修改是裁决结果之一，需告知；拒绝带原因码 |
| 陈旧 vs 无效 vs 可疑 | 旧但曾经有效 / 值本身不合法 / 值合法但行为反常 |
| 测量时间 vs 接收时间 | 采样时刻 / 软件收到时刻 |
| 单调时钟 vs 墙上时钟 | 用于间隔与超时 / 用于日志与跨设备日历时间 |
| IPC vs DDS | 同机调用并取结果 / 发布订阅与跨设备数据 |
| DSoftBus vs M-DDS | OH 的设备互联底座 / 平台的数据分发中间件 |
| 数据治理 vs 传感器融合 | 融合前的时间/坐标/有效性处理 / 估计算法本身 |
| 同步 vs 一致 | 数据送到 / 同一时间基准、坐标与单位下可比 |
| 完成 vs 发送成功 | 以状态证据为准 / 仅表示总线写成功 |
