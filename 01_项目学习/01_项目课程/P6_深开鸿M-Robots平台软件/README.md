# P6 深开鸿 M-Robots 平台软件：设备抽象、状态管理、分布式协同与安全执行链

> 一句话定位：CV 中 Shenzhen Kaihong Digital Industry Development Co., Ltd. 的在职实习（Robotics Platform Intern，2026.06 至今）。你在 M-Robots OpenHarmony 异构多机器人协同平台上，独立开发并集成了 **设备抽象、状态管理、分布式协同、安全执行链**。其中 "action-proposal → policy-check → execution → state-feedback" 链是你 PS 的开篇钩子，面试必问。

> **重要说明**：本项目的源码目录不作参考，文档只依据 CV、PS 和通用工程知识。所以：CV 写了的是**事实**；其余是"这类系统的典型设计"，面试里用 *typically / in a design like this* 措辞；专有细节全部留 `【待你补全】`（汇总在本页"实机细节自查表"）。

## 1. 一页纸：P6 是什么

**CV 原意（可直接用 "I"）**

| 线 | 做了什么 |
|---|---|
| 统一运动接口 | 在 OpenHarmony 上用 C++ 为传感器、执行器、控制器建立统一能力模型；把 ROS/ROS2 运动指令映射到底层驱动；运动控制代码可跨硬件复用 |
| 机器人状态管理 | 统一多源感知与执行器反馈的时间戳、坐标系、有效性检查，向运动控制层与任务层提供一致、可信的状态 |
| 协同与安全执行 | 在 M-DDS 上实现设备发现、能力注册、状态同步、任务分发；任务计划经"动作提案 → 策略校验 → 控制执行 → 状态回传"链才能进入物理执行 |

**一句话讲法（英文）**

> I work on the M-Robots multi-robot platform on OpenHarmony: a unified C++ capability model so ROS and ROS2 motion commands drive different hardware, standardised timestamps, frames and validity for a trusted robot state, and discovery, registration and task dispatch over M-DDS — with every task plan gated through a proposal, policy-check, execution and feedback chain.

**数据流一图**

```text
任务层 / 调度 / AI 规划
   │ 动作提案（结构化、带身份与有效期）
   ▼
策略校验 ◀──────── 可信状态（时间/坐标/有效性已标准化）
   │ 接受 / 修改 / 拒绝(原因码)
   ▼
运动接口（统一能力模型）◀── ROS/ROS2 命令映射
   │
   ▼
驱动适配器 → 底层驱动 → 硬件
   │
   └──── 反馈 → 状态管理 → 回传（M-DDS）→ 任务层
```

## 5. 口径备忘（仅自查，面试按 CV 说）

1. **职责口径**：以 CV 为准——*Robotics Platform Intern*；*independently developed and integrated device abstraction, state management, distributed coordination and the safe-execution chain*。不要说成"我设计了整个平台"，也不要说成"我只做了辅助工作"。
2. **平台名称**：面试里用 **M-Robots** 与 **M-DDS**（CV/PS 用词）。早期整理的旧材料里出现过其他名称（例如与设备接入、协议适配相关的产品名）和更偏设备驱动/协议层的描述，与 CV 的 M-Robots / M-DDS / 异构多机器人协同描述不一致；**一律不在面试中使用旧名称或旧描述**，如记忆中有这类说法，只在自查时与实习导师核对，面试按 CV 说。
3. **数值**：本项目文档中所有数值（频率、阈值、带宽、延迟等）都是教学示例，**不是项目实测**。面试中引用时必须说明是 "textbook example" 或自己的测量。
4. **"我做了"的边界**：CV 事实（统一能力模型、命令映射、时间戳/坐标/有效性标准化、M-DDS 上发现/注册/同步/分发、提案-校验-执行-回传链）可直接用 "I"；本文档中对规则清单、凭据、幂等去重等的讲解是"典型设计"，除非你确实实现了，请用 "typically / in a design like this"。
5. **时间线**：2026 年 6 月入职至今，在职实习；P2 在 2026.03–2026.05，先于 P6。成长叙事中可说"在 P2 做了单机器人的底盘链路，在 P6 做抽象与平台化"。
6. **排名与均分口径**（跨项目通用，仅供自查）：6 of 156、top 4%、均分 87.63；中文简历若写 7/156、前 5%，面试按英文 CV。
7. **ROS 与 ROS2**：CV 写的是 "ROS/ROS2"。如果被问到具体支持哪一个，按实际回答，不要都说"完整支持"。
8. **"协同"的范围**：CV 是发现、注册、状态同步、任务分发——信息与任务层面的协同；不要说成多机编队控制。
