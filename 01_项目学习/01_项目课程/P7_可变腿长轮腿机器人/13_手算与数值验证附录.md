# 手算与数值验证附录

> **一句话定位**：本目录里所有教学数值（A/B、K、拟合、J、仿真）都可由下面的脚本复现。均为教学示例，非项目实测。

## 1. 参数

$R=0.07,\ m_w=0.6,\ I_w=\frac12m_wR^2,\ m_l=0.5,\ I_l=m_lL^2/12,\ M=6,\ l=0.04,\ I_B=0.05,\ g=9.81$；$Q=\mathrm{diag}(100,1,500,100,5000,1)$，$R=\mathrm{diag}(1,0.25)$。

## 2. 六状态模型与 K(L)（Python，numpy + scipy）

```python
import numpy as np, scipy.linalg as la
R,mw,ml,M,l,IB,g = 0.07,0.6,0.5,6.0,0.04,0.05,9.81
def AB(L):
    Iw=0.5*mw*R**2; Il=ml*L**2/12
    Mm=np.array([[Iw/R**2+M+ml+mw,(M+ml/2)*L,M*l],
                 [(M+ml/2)*L,Il+(M+ml/4)*L**2,M*L*l],
                 [M*l,M*L*l,IB+M*l**2]])
    G=np.diag([0,-(M+ml/2)*g*L,-M*g*l]); Bq=np.array([[1/R,0],[-1,-1],[0,1]])
    Mi=np.linalg.inv(Mm); Aq=-Mi@G; Bd=Mi@Bq      # q=[x,theta,phi]
    A=np.zeros((6,6)); B=np.zeros((6,2)); idx=[1,0,2]  # states: theta,x,phi
    for k,qi in enumerate(idx):
        A[2*k,2*k+1]=1
        for j,qj in enumerate(idx): A[2*k+1,2*j]=Aq[qi,qj]
        B[2*k+1]=Bd[qi]
    return A,B
Q=np.diag([100,1,500,100,5000,1.]); Rm=np.diag([1,.25])
def K(L):
    A,B=AB(L); X=la.solve_continuous_are(A,B,Q,Rm); return np.linalg.solve(Rm,B.T@X)
Ls=np.linspace(.1,.3,9); Ks=np.array([K(L) for L in Ls])
coef=[[np.polyfit(Ls,Ks[:,i,j],3) for j in range(6)] for i in range(2)]
print(K(0.2))
```

预期：$K(0.2)$ 第一行 $[-35.09,-5.52,-20.88,-17.51,-32.07,-2.50]$，第二行 $[-24.62,-3.87,-16.01,-12.95,129.74,2.80]$；开环极点 $\pm18.91,\pm6.73,0,0$；三次拟合最大绝对误差约 0.14。

## 3. 五连杆 FK 与雅可比

```python
import numpy as np
L1,L2,L3,L4,L5=150.,250.,250.,150.,108.
def fk(al,be):
    A=np.array([L1*np.cos(al),L1*np.sin(al)]); C=np.array([L5+L4*np.cos(be),L4*np.sin(be)])
    d=np.linalg.norm(C-A); a=(L2**2-L3**2+d**2)/(2*d); h=np.sqrt(L2**2-a**2)
    e=(C-A)/d; n=np.array([-e[1],e[0]]); return A+a*e+h*n, A, C
def J(al,be):
    B,A,C=fk(al,be); t1=np.arctan2(*(B-A)[::-1]); t2=np.arctan2(*(B-C)[::-1])
    Mc=np.array([[np.cos(t1),np.sin(t1)],[np.cos(t2),np.sin(t2)]])
    Dc=np.diag([L1*np.sin(t1-al),L4*np.sin(t2-be)]); return np.linalg.solve(Mc,Dc)
print(fk(np.radians(135),np.radians(45))[0], J(np.radians(135),np.radians(45)))
```

预期：$B=(54,298.105)$；$J=[[-116.66,-116.66],[-97.24,97.24]]$；有限差分核对三个姿态与课程四个 $j$ 系数一致。
