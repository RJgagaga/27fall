## 1. 它要解决什么问题

前面各章的手算数字很多：增益矩阵 $K$、雅可比 $J$、腾空时的支撑力、总线占用……如果每个数字只在文中出现一次，读者无法判断它是否算对，也无法在改了参数以后重算。本附录把这些数字集中到**可执行脚本**里：

- 数字出处唯一：文中任何教学数值都能在这里找到来源；
- 可复现：换参数（质量、杆长、Q、R）重新跑，就能得到新的数；
- 可自检：脚本里带有交叉验证（有限差分对解析雅可比、闭环极点对开环极点、拟合误差对增益幅值）。

> **面试要点**：说"我用脚本复核过这个量级"比说"我估计大概是这样"可信。但要分清楚：这些是**模型推演数**，不是实机测得的数；实机的数值只能来自日志。

## 3. 脚本一：六状态模型、K(L) 与闭环验证

**推导回顾：** 取广义坐标 $q=[x,\theta,\phi]^\top$，质量阵 $M(L)$、重力阵 $G(L)$、输入阵 $B_q$ 给出 $M\ddot q+Gq=B_qu$，线性化后 $\ddot q=-M^{-1}Gq+M^{-1}B_qu$，再整理成六状态 $(A,B)$（见 [04](./04_动力学建模与状态方程.md)）。对每个腿长解连续时间代数 Riccati 方程 $A^\top X+XA-XBR^{-1}B^\top X+Q=0$，得 $K=R^{-1}B^\top X$（见 [05](./05_LQR原理与增益调度.md)）。脚本还做了三件验证：

1. 开环极点：不稳定极点应成对出现 $\pm\lambda$（倒立摆特征）；
2. 三次拟合误差：对 9 个腿长点拟合每个增益元素；
3. 闭环仿真：给初始俯仰，看峰值力矩，并加上力矩限幅看是否仍稳定；再做速度指令阶跃/斜坡对比。

```python
# S1: 六状态模型、LQR 增益、三次拟合、闭环峰值力矩（教学示例参数）
import numpy as np, scipy.linalg as la
np.set_printoptions(precision=2, suppress=True, linewidth=140)
R, mw, ml, M, l, IB, g = 0.07, 0.6, 0.5, 6.0, 0.04, 0.05, 9.81

def AB(L):
    Iw = 0.5*mw*R**2; Il = ml*L**2/12
    Mm = np.array([[Iw/R**2+M+ml+mw, (M+ml/2)*L, M*l],
                   [(M+ml/2)*L, Il+(M+ml/4)*L**2, M*L*l],
                   [M*l, M*L*l, IB+M*l**2]])
    G = np.diag([0, -(M+ml/2)*g*L, -M*g*l])
    Bq = np.array([[1/R, 0], [-1, -1], [0, 1]])
    Mi = np.linalg.inv(Mm); Aq = -Mi@G; Bd = Mi@Bq     # q=[x,theta,phi]
    A = np.zeros((6, 6)); B = np.zeros((6, 2)); idx = [1, 0, 2]  # 状态顺序 theta,x,phi
    for k, qi in enumerate(idx):
        A[2*k, 2*k+1] = 1
        for j, qj in enumerate(idx): A[2*k+1, 2*j] = Aq[qi, qj]
        B[2*k+1] = Bd[qi]
    return A, B

Q = np.diag([100, 1, 500, 100, 5000, 1.]); Rm = np.diag([1, .25])
def K(L):
    A, B = AB(L); X = la.solve_continuous_are(A, B, Q, Rm)
    return np.linalg.solve(Rm, B.T@X)

print("K(0.2) =\n", K(0.2))
A, B = AB(0.2)
print("open-loop poles(0.2) =", np.sort(np.linalg.eigvals(A).real))
Ls = np.linspace(.1, .3, 9); Ks = np.array([K(L) for L in Ls])
worst = 0
for i in range(2):
    for j in range(6):
        c = np.polyfit(Ls, Ks[:, i, j], 3)
        worst = max(worst, np.abs(np.polyval(c, Ls)-Ks[:, i, j]).max())
print("cubic fit, max abs error = %.3f, coefficients = %d" % (worst, 2*6*4))
for L in (0.10, 0.20, 0.30):
    A, B = AB(L); cl = np.linalg.eigvals(A-B@K(L))
    print("L=%.2f  slowest closed-loop real part = %.2f" % (L, cl.real.max()))
# 固定 K(0.2) 用在别的腿长
K0 = K(0.2)
for L in (0.10, 0.30, 0.40, 0.50):
    A, B = AB(L); cl = np.linalg.eigvals(A-B@K0)
    print("fixed K(0.2) at L=%.2f: slowest real part = %+.2f" % (L, cl.real.max()))
# 初始俯仰 0.05 rad 的线性闭环峰值力矩
def peak(phi0, L=0.2, lim=None, T=3.0, dt=0.001):
    A, B = AB(L); Kk = K(L); x = np.zeros(6); x[4] = phi0
    pk = np.zeros(2); ok = True
    for _ in range(int(T/dt)):
        u = -Kk@x
        if lim is not None: u = np.clip(u, -lim, lim)
        pk = np.maximum(pk, np.abs(u))
        x = x + dt*(A@x + B@u)
        if abs(x[4]) > 0.6: ok = False; break
    return pk, ok
print("phi0=0.05 linear :", peak(0.05))
print("phi0=0.10 linear :", peak(0.10))
print("phi0=0.05 limit(3,6):", peak(0.05, lim=np.array([3., 6.])))
print("phi0=0.10 limit(3,6):", peak(0.10, lim=np.array([3., 6.])))

# 速度指令：阶跃与 1 s 斜坡（误差形式 u=-K(x-x_ref)，L0=0.2）
A, B = AB(0.2); Kk = K(0.2)
def run(ramp_T, v=0.5, T=4.0, dt=0.002):
    x = np.zeros(6); xs = 0.0; pk = np.zeros(2); first = None
    for k in range(int(T/dt)):
        t = k*dt
        vs = v*min(t/ramp_T, 1.0) if ramp_T > 0 else v
        xs += vs*dt
        e = x - np.array([0, 0, xs, vs, 0, 0])
        u = -Kk@e
        if first is None: first = u.copy()
        pk = np.maximum(pk, np.abs(u))
        x = x + dt*(A@x + B@u)
    return first, pk
for rt in (0.0, 1.0):
    f, p = run(rt); print("ramp %.1f s: first-cycle (T,Tp) = (%.2f, %.2f)  peak |T|=%.2f |Tp|=%.2f" % (rt, f[0], f[1], p[0], p[1]))
```

- 速度指令：0.5 m/s 阶跃在第一个周期就要 −8.78 N·m 的轮矩，远超 3 N·m 限幅；1 s 斜坡后峰值只有 0.35 N·m。这是案例 B 的数字来源。

## 4. 脚本二：五连杆正解、雅可比与 VMC 力矩映射

**推导回顾：** 取主动关节 $A=(L_1\cos\alpha,L_1\sin\alpha)$、$C=(L_5+L_4\cos\beta,L_4\sin\beta)$，足端 $B$ 是以 $A$、$C$ 为圆心、半径 $L_2$、$L_3$ 的两圆交点（取固定解支）；雅可比由闭链约束对时间求导得到 $J=\begin{bmatrix}\cos t_1&\sin t_1\\\cos t_2&\sin t_2\end{bmatrix}^{-1}\mathrm{diag}\big(L_1\sin(t_1-\alpha),L_4\sin(t_2-\beta)\big)$，其中 $t_1,t_2$ 是两根连杆的方向角（见 [02](./02_五连杆闭链运动学.md)）。VMC 由虚功原理给出 $\tau=J^\top F$（见 [06](./06_VMC原理与关节力矩映射.md)）。

```python
# S2: 五连杆正解、雅可比、有限差分核对、VMC 力矩映射（单位 mm、rad）
import numpy as np
np.set_printoptions(precision=2, suppress=True, linewidth=140)
L1, L2, L3, L4, L5 = 150., 250., 250., 150., 108.
def fk(al, be):
    A = np.array([L1*np.cos(al), L1*np.sin(al)])
    C = np.array([L5+L4*np.cos(be), L4*np.sin(be)])
    d = np.linalg.norm(C-A); a = (L2**2-L3**2+d**2)/(2*d); h = np.sqrt(L2**2-a**2)
    e = (C-A)/d; n = np.array([-e[1], e[0]])
    return A+a*e+h*n, A, C
def J(al, be):
    B, A, C = fk(al, be)
    t1 = np.arctan2(*(B-A)[::-1]); t2 = np.arctan2(*(B-C)[::-1])
    Mc = np.array([[np.cos(t1), np.sin(t1)], [np.cos(t2), np.sin(t2)]])
    Dc = np.diag([L1*np.sin(t1-al), L4*np.sin(t2-be)])
    return np.linalg.solve(Mc, Dc)
al, be = np.radians(135), np.radians(45)
print("B =", fk(al, be)[0]); print("J =\n", J(al, be))
eps = 1e-6
Jn = np.column_stack([(fk(al+eps, be)[0]-fk(al-eps, be)[0])/(2*eps),
                      (fk(al, be+eps)[0]-fk(al, be-eps)[0])/(2*eps)])
print("finite-difference J =\n", Jn, "\nmax diff =", np.abs(Jn-J(al, be)).max())
# VMC: tau = J^T F, F in N, J in mm/rad -> N*m
F = np.array([0., 30.])
tau = J(al, be).T@F/1000
print("tau for Fy=30 N  =", tau, "N*m")
F = np.array([5., 30.])
print("tau for Fx=5,Fy=30 =", J(al, be).T@F/1000, "N*m")
for a_deg, b_deg in [(135, 45), (150, 30), (120, 60)]:
    a, b = np.radians(a_deg), np.radians(b_deg)
    Jm = J(a, b); print("alpha=%d beta=%d  yB=%.1f mm cond=%.2f" % (a_deg, b_deg, fk(a, b)[0][1], np.linalg.cond(Jm)))
```

**怎么读：**

- $B=(54,\,298.1)$ mm：$\alpha=135^\circ$、$\beta=45^\circ$ 时的对称姿态，腿高 298 mm；
- 解析 $J$ 与中心有限差分的最大差为 $1.7\times10^{-8}$，说明雅可比实现正确；
- 对称姿态下 $J$ 的第一行两列相同、第二行反号：竖直方向受力 $F_y$ 变成两个关节的**反号**力矩，水平力 $F_x$ 变成**同号**力矩；
- $F_y=30$ N 得到 $\tau=(-2.92,\,+2.92)$ N·m，量级 3 N·m——这就是 99 里"30 N 支撑力约 3 N·m 每关节"的来源；本项目关节软限幅 6 N·m，站立大约占一半；
- 条件数：腿高 244 mm 时 1.09，298 mm 时 1.20，344 mm 时 1.66；腿接近伸直（约 394 mm）时此前计算约 4.5。工作腿长应落在条件数小于 2 的区间。

# S3: 小型数值：前馈、互补滤波、卡尔曼一步、MIT 编码、CAN 负载、支撑力
import numpy as np
g = 9.81
print("--- gravity feedforward, M=6 kg")
for th in (0, 10, 30):
    print("theta=%2d deg  F_ff = %.2f N" % (th, 6*g/2/np.cos(np.radians(th))))
print("--- complementary filter (alpha=0.98, dt=5 ms)")
phi = 0.98*(2.000+10*0.005)+0.02*2.5
print("phi = %.3f deg, tau = %.3f s" % (phi, 0.98*0.005/(1-0.98)))
print("--- Kalman one step")
v, P, Q, Rm, a, dt, z = 0.5, 0.04, 0.001, 0.01, 1.0, 0.005, 0.53
vm = v+a*dt; Pm = P+Q; Kg = Pm/(Pm+Rm); v1 = vm+Kg*(z-vm); P1 = (1-Kg)*Pm
print("v-=%.3f P-=%.3f K=%.4f v=%.4f P=%.5f" % (vm, Pm, Kg, v1, P1))
print("--- MIT quantization (project ranges)")
def enc(x, lo, hi, n): 
    x = min(max(x, lo), hi); return int((x-lo)/(hi-lo)*(2**n-1))
def dec(u, lo, hi, n): return u/(2**n-1)*(hi-lo)+lo
for tor in (3.0, -1.234):
    u = enc(tor, -10, 10, 12); print("tor=%.3f -> %d -> %.4f" % (tor, u, dec(u, -10, 10, 12)))
u = enc(1.0, -12.5, 12.5, 16); print("pos=1.0 -> %d -> %.5f" % (u, dec(u, -12.5, 12.5, 16)))
print("resolution torque = %.4f N*m, position = %.6f rad" % (20/4095, 25/65535))
print("clamp: tor=12 ->", dec(enc(12, -10, 10, 12), -10, 10, 12))
print("--- CAN load, classic standard frame 8 bytes")
for bits in (111, 135):
    t = bits/1e6
    print("bits=%d  one frame = %.3f ms; 8 frames = %.3f ms; share of 2 ms cycle = %.0f %%" % (bits, t*1e3, 8*t*1e3, 8*t/0.002*100))
print("one bus, 12 frames (6 cmd + 6 fb): %.2f ms .. %.2f ms (share %.0f %% .. %.0f %%)" % (12*0.111, 12*0.135, 12*0.111/2*100, 12*0.135/2*100))
print("--- ground normal force")
F, Tp, L0, th, mw, zdd = 40., 1., 0.2, 0.1, 0.6, 0.5
P = F*np.cos(th)+Tp/L0*np.sin(th); FN = P+mw*g+mw*zdd
print("P=%.2f N  F_N=%.2f N" % (P, FN))
print("--- feedforward + PD, leg 3 cm short")
Kp, Kd = 500., 20.
print("PD force = %.1f N; plus ff 29.4 -> %.1f N" % (Kp*0.03, Kp*0.03+29.43))
print("static sag without ff: %.1f cm" % (29.43/Kp*100))
```

one bus, 12 frames (6 cmd + 6 fb): 1.33 ms .. 1.62 ms (share 67 % .. 81 %)
--- ground normal force
P=40.30 N  F_N=46.49 N
--- feedforward + PD, leg 3 cm short
PD force = 15.0 N; plus ff 29.4 -> 44.4 N
static sag without ff: 5.9 cm
```

**怎么读：**

- 前馈 $F_{ff}=Mg/(2\cos\theta)$：腿偏 30° 需要多出约 15% 的力；没有前馈，每条腿要靠 5.9 cm 的下沉才能产生 29.4 N（$K_p=500$ N/m），机器人会"坐下去"；
- 互补滤波一步：$\hat\phi=0.98\times(2.000+10\times0.005)+0.02\times2.5=2.059^\circ$，时间常数 $0.245$ s；
- 卡尔曼一步：增益 0.804，表示此刻更信轮速测量；
- MIT 编码用本项目范围：力矩 ±10 N·m、12 位，分辨率 0.0049 N·m，3.0 编码为 2661、解码 2.9963；超出范围（12 N·m）被夹到 10；位置 ±12.5 rad、16 位，分辨率 0.00038 rad；
- 总线负载：8 个 8 字节经典帧在 1 Mbps 下需要 0.89–1.08 ms，占 2 ms 周期的 44%–54%；如果 6 个电机的 12 帧都挤在一条总线上，则占 67%–81%，余量太小，这就是本项目把关节与轮分到两路 FDCAN 的原因；
- 支撑力：$P=40.30$ N，$F_N=46.49$ N，与 [09](./09_离地检测与接触切换.md) 的手算一致。

## 6. 脚本四：离地判据的滞环与去抖（合成数据）

```python
# S4: 离地检测的滞环+去抖状态机（合成数据）与速度阶跃/斜坡的轮矩需求
import numpy as np
dt = 0.002; FOFF, FON, NOFF, NON = 10., 20., 8, 5
t = np.arange(0, 1.0, dt)
FN = np.full_like(t, 38.0)
FN[(t > 0.30) & (t < 0.304)] = 6.0           # 4 ms 毛刺（颠簸），应被去抖滤掉
FN[(t >= 0.50) & (t < 0.62)] = 2.0          # 120 ms 腾空
rng = np.random.default_rng(1); FN = FN + rng.normal(0, 1.0, len(t))
air = False; cnt = 0; events = []
for k, f in enumerate(FN):
    if not air:
        cnt = cnt+1 if f < FOFF else 0
        if cnt >= NOFF: air = True; cnt = 0; events.append(("airborne", round(t[k], 3)))
    else:
        cnt = cnt+1 if f > FON else 0
        if cnt >= NON: air = False; cnt = 0; events.append(("landed", round(t[k], 3)))
print(events)
# 落地渐入：80 ms 线性斜坡
ramp = np.clip((t-0.62)/0.08, 0, 1); print("blend at 0.62+40ms = %.2f" % np.interp(0.66, t, ramp))
# 速度指令：阶跃 vs 1 s 斜坡所需的第一拍轮矩（速度增益取 K(0.2) 第一行第 4 项 -17.51）
kv = 17.51
print("step 0.5 m/s: first-cycle T = %.2f N*m" % (kv*0.5))
print("ramp 1 s, 2 ms step: per-cycle command change = %.4f m/s -> T = %.3f N*m" % (0.5*0.002, kv*0.5*0.002))
print("ramp 1 s, error after 0.1 s (0.05 m/s): T = %.2f N*m" % (kv*0.05))
```

**本地实际输出：**

```text
[('airborne', 0.514), ('landed', 0.628)]
blend at 0.62+40ms = 0.50
step 0.5 m/s: first-cycle T = 8.76 N*m
ramp 1 s, 2 ms step: per-cycle command change = 0.0010 m/s -> T = 0.018 N*m
ramp 1 s, error after 0.1 s (0.05 m/s): T = 0.88 N*m
```

**怎么读：** 数据里有一个 4 ms 的毛刺（0.300 s 附近，力降到 6 N，低于 10 N 阈值）和一次 120 ms 的真实腾空（0.50–0.62 s）。毛刺只持续 2 个周期，没有达到 8 个周期，被去抖滤掉；真实腾空在 0.514 s 判离地（0.500 s 起，8 个周期即 16 ms 后），0.628 s 判着地（0.620 s 起，5 个周期即 10 ms 后再加一拍计数）。判离地的延迟就是去抖时间，代价是这 16 ms 内仍按着地模型输出——所以去抖时间不能太长。速度指令部分另给出：阶跃 0.5 m/s 的第一拍轮矩 8.76 N·m；斜坡下每个周期指令只变化 0.001 m/s。

## 6.5 脚本五：Q 权重灵敏度（整定的"手感"从哪来）

整定 LQR 时最常见的问题是"改哪一项会怎样"。下面的脚本固定 $R$，每次只改一项 $Q$，看三个量：初始俯仰 0.05 rad 下的峰值轮矩、峰值髋矩、最慢闭环极点。这就是实车调参前应有的心理预期。

```python
# S5: Q 权重灵敏度（教学示例）——改变某一项 Q，看初始俯仰 0.05 rad 的峰值力矩与最慢闭环极点
import numpy as np, scipy.linalg as la
R, mw, ml, M, l, IB, g = 0.07, 0.6, 0.5, 6.0, 0.04, 0.05, 9.81

def AB(L):
    Iw = 0.5*mw*R**2; Il = ml*L**2/12
    Mm = np.array([[Iw/R**2+M+ml+mw, (M+ml/2)*L, M*l],
                   [(M+ml/2)*L, Il+(M+ml/4)*L**2, M*L*l],
                   [M*l, M*L*l, IB+M*l**2]])
    G = np.diag([0, -(M+ml/2)*g*L, -M*g*l]); Bq = np.array([[1/R, 0], [-1, -1], [0, 1]])
    Mi = np.linalg.inv(Mm); Aq = -Mi@G; Bd = Mi@Bq
    A = np.zeros((6, 6)); B = np.zeros((6, 2)); idx = [1, 0, 2]
    for k, qi in enumerate(idx):
        A[2*k, 2*k+1] = 1
        for j, qj in enumerate(idx): A[2*k+1, 2*j] = Aq[qi, qj]
        B[2*k+1] = Bd[qi]
    return A, B

def design(Q, Rm, L=0.2):
    A, B = AB(L); X = la.solve_continuous_are(A, B, Q, Rm)
    return A, B, np.linalg.solve(Rm, B.T@X)

def peak(A, B, K, phi0=0.05, T=3.0, dt=0.001):
    x = np.zeros(6); x[4] = phi0; pk = np.zeros(2)
    for _ in range(int(T/dt)):
        u = -K@x; pk = np.maximum(pk, np.abs(u)); x = x + dt*(A@x + B@u)
    return pk

Rm = np.diag([1, .25]); base = np.array([100, 1, 500, 100, 5000, 1.])
cases = [("baseline", {}), ("Q_phi x10", {4: 10}), ("Q_phi x0.1", {4: 0.1}),
         ("Q_v x10", {3: 10}), ("Q_x x0.1", {2: 0.1})]
for name, mult in cases:
    q = base.copy()
    for i, m in mult.items(): q[i] *= m
    A, B, K = design(np.diag(q), Rm)
    pk = peak(A, B, K); slow = np.linalg.eigvals(A-B@K).real.max()
    print("%-11s peak T=%.2f Tp=%.2f  slowest pole=%.2f" % (name, pk[0], pk[1], slow))
```

**本地实际输出：**

```text
baseline    peak T=1.60 Tp=6.49  slowest pole=-2.84
Q_phi x10   peak T=3.16 Tp=21.62  slowest pole=-2.84
Q_phi x0.1  peak T=0.83 Tp=1.83  slowest pole=-2.84
Q_v x10     peak T=2.50 Tp=5.52  slowest pole=-0.71
Q_x x0.1    peak T=1.51 Tp=6.56  slowest pole=-0.71
```

**怎么读：**

- $Q_\phi$ 放大 10 倍：峰值髋矩从 6.49 涨到 21.62 N·m，是限幅（6 N·m）的三倍多——实机会立刻贴限幅，有效增益骤降，机身"猛抽一下"（[11](./11_调试与故障手册.md) 的 F9）。所以**俯仰权重不是越大越好**；
- $Q_\phi$ 缩小到 0.1 倍：峰值力矩很小（髋矩 1.83），但最慢极点没变——说明慢极点由位置与速度项决定，俯仰项只决定"抢救俯仰误差有多凶"，调得太小则抗扰能力不足；
- $Q_v$ 放大 10 倍，或 $Q_x$ 缩小到 0.1 倍：最慢极点从 −2.84 变到 −0.71，位置回到原点变慢（约 4 倍），但峰值力矩不大；
- 整定顺序因此是：先让俯仰与腿角两个快模态稳住（$Q_\phi$、$Q_\theta$），再用 $Q_v$、$Q_x$ 决定"走偏后拉回来的速度"，同时一直盯着力矩是否贴限幅。

## 6.6 用这些脚本做自己的参数扫描

1. 换质量：把 `M` 改成 7 kg，重新跑脚本一，看 $K_{25}$ 与最慢极点的变化——这就是"整机质量不准时 LQR 输出差一个比例"的数值版本；
2. 换腿长范围：把 `Ls` 改成 0.1 到 0.4，看拟合误差是否放大、固定增益是否仍然稳定，从而决定拟合区间；
3. 换限幅：把 `lim` 改成 `(3, 4)`，看 $\phi_0=0.05$ 是否还稳定，从而知道髋矩的"最低可用限幅"；
4. 换周期：把仿真步长 `dt` 改成 0.01，观察离散化误差，感受控制周期对闭环的影响；
5. 换前馈：在脚本三里把 `M` 改成 6.3 kg，看前馈多出的 1.5 N 需要积分项吃掉多久。

每次扫描只改一个量，并把结果记入自己的调试日志，这是面试里"how do you tune"的最好素材。

> **注意**：这些脚本使用的是简化的三体线性模型（机身、两腿合并、两轮合并），没有电机动态、通信延迟、摩擦和地面接触的非线性。因此仿真结论只用来**建立量级与趋势的直觉**：哪一项权重会让哪个力矩变大、固定增益在哪里失稳。真正的稳定裕度、限幅位置和离地阈值，必须在吊起测试与落地测试中用日志确认，再回头修正脚本里的参数。面试里被问到"仿真和实机差多少"时，诚实的回答是：模型给方向，实车给数值。

## 7. 常见错误与边界

| 错误 | 后果 | 对策 |
|---|---|---|
| 把教学数值当实机数据说出口 | 面试被追问时露馅 | 一律说"teaching estimate"，实机用自查表里的量级 |
| 单位混用（mm 与 m） | $\tau=J^\top F$ 差 1000 倍 | 脚本里 $J$ 用 mm/rad，力矩除 1000 |
| 拟合区间外推 | 增益发散 | 在线 clamp 到拟合区间（0.10–0.30 m） |
| 只看线性仿真 | 忽略限幅 | 用 clip 后再仿真，观察是否仍稳定 |
| 忘了 FK 解支 | 两圆交点取错，结果翻转 | 固定法向方向（脚本中的 `n`） |

## 8. 面试怎么问、怎么答

**Q1. How did you verify your numbers?**
> I wrote small scripts: I solved the Riccati equation at a grid of leg lengths, checked the closed-loop poles, compared the analytic Jacobian with a finite-difference one, and checked the torque estimates against the motor limits. These are model numbers, not robot measurements; the robot numbers come from logs.

（中文：用脚本解 Riccati、查闭环极点、有限差分核对雅可比、核对力矩与限幅；这些是模型数而不是实测数。）

**Q2. Can you estimate the hip torque while standing?**
> About three newton-meters per joint for a thirty-newton support force, from the Jacobian transpose. Our software limit was six, so standing used about half of it.

**Q3. Why do you need gain scheduling? Do you have a number?**
> In the model, a gain designed at 0.2 meters still stabilizes the system between 0.1 and 0.3 meters, but the margin drops from about 2.8 to 1.6 per second, and at 0.4 meters it is unstable. So scheduling keeps the margin over the working range.

**Q4. How big is the CAN load?**
> Eight classic frames are about one millisecond at 1 Mbps, around half of a two-millisecond cycle, so I put the joints and the wheels on separate buses.
