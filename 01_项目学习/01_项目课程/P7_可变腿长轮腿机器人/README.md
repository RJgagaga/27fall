# P7 可变腿长轮腿机器人（Variable-Leg-Length Wheel-Legged Robot）

> 实验室项目 · Nov 2025 – Mar 2026 · 指导：傅向华教授 · 你负责：平衡控制算法与实车调试。读完本目录，你应当能从零讲清 LQR + VMC 平衡控制，并用英文答辩。

## 一页纸

**是什么**：两轮 + 两条五连杆腿 + 机身的主动平衡机器人，腿长可变。
**你做了什么（CV）**：
1. **增益调度 LQR**：用 IMU、轮速、关节反馈构造机身俯仰与运动状态，按腿长调度 LQR 增益，把平衡与运动误差变成轮毂力矩 $T$ 和髋部力矩 $T_p$；
2. **VMC 力矩控制**：闭链运动学算虚拟腿长与姿态，支撑力 $F$ 与俯仰力矩 $T_p$ 经雅可比转置映射到关节，腿长 PID + 力前馈协调伸缩；
3. **实车调试**：STM32H7/FreeRTOS + FDCAN 执行链，把平衡异常定位到状态不一致、力矩限幅、离地切换三类，整定参数。
**结果（CV）**：腿长变化时机身保持平衡并跟踪速度指令。

```text
指令 → 斜坡 → LQR(K(L0)) → T、Tp ─┐
腿长 PID + 前馈 → F ──────────────┴→ VMC(Jᵀ) → 关节力矩 ┐
IMU/关节/轮速 → 运动学+估计 → 六状态 → LQR            └→ 限幅 → FDCAN → 电机
```

**关键故障案例（与 [11](./11_调试与故障手册.md) 第 5 节一致）**

| 案例 | 现象 | 原因 | 处理 | 结果 |
|---|---|---|---|---|
| A 状态不一致 | 吊起放下后缓慢向前爬行，位置误差越积越大 | 俯仰平衡点偏置约 1.5°（质心偏前加 IMU 安装偏差）；IMU 与关节数据不同步 | 吊起读零位并标定偏置；每周期一次快照 | 静止 30 s 位移小于 3 cm |
| B 力矩限幅 | 速度指令阶跃 0.5 m/s 时倒下 | 轮矩需求约 9 N·m，贴 3 N·m 限幅，有效增益骤降 | 指令 1 s 斜坡，限加速度 0.5 m/s²，适度降 $Q_v$ | 可稳定跟踪 0.5 m/s |
| C 离地切换 | 过 3 cm 门槛后落地冲出 | 腾空时轮空转，速度估计被污染；落地位置误差大 | 支撑力判离地，腾空轮矩置 0、冻结位置；落地复位并 80 ms 渐入 | 落地无力矩尖峰 |
