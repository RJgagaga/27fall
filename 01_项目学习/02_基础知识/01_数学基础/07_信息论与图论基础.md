## 1. 问题：怎样量化"不确定"与"差异"

想象三个场景。第一，你的目标检测网络对一张图片输出"猫 0.7、狗 0.2、车 0.1"，而真实标签是"猫"。你怎么给这个输出打一个**可求导的分数**，让梯度下降把概率推向正确答案？第二，激光建图里，栅格地图的一个格子被占据的概率是 0.5 还是 0.99，哪个更"需要再观察一次"？第三，两个相邻相机位姿之间有一条里程计约束，一千个位姿之间有三千条这样的约束，你怎么存、怎么搜、怎么保证求解器跑得快？

前两个问题属于**信息论**：我们需要一个标量来描述"一个分布有多不确定"和"一个分布与另一个分布差多远"。第三个属于**图论**：对象（节点）与关系（边）怎么表示，怎么算最短路径、最小连接、最优配对。它们看似无关，却在机器人里反复同时出现，比如：用互信息选下一个探索位置（信息论），用 Dijkstra 在栅格图上找路（图论），用图优化修正累积误差（图论 + 概率）。

## 2. 符号与约定

| 符号 | 含义 | 单位 |
|---|---|---|
| $p(x),q(x)$ | 离散或连续分布（概率质量/密度） | 无量纲 |
| $H(p)$ | 熵 | bit（$\log_2$）或 nat（自然对数） |
| $H(p,q)$ | 交叉熵 | bit 或 nat |
| $D_{\mathrm{KL}}(p\Vert q)$ | KL 散度 | bit 或 nat |
| $I(X;Y)$ | 互信息 | bit 或 nat |
| $G=(V,E)$ | 图，$V$ 为节点集，$E$ 为边集 | |
| $A$ | 邻接矩阵，$A_{ij}=1$（或权重）表示 $i\to j$ 有边 | |
| $D$ | 度矩阵（对角阵），$D_{ii}=\sum_jA_{ij}$ | |
| $L=D-A$ | 图拉普拉斯 | |
| $w(i,j)$ | 边权（代价、距离、时间） | 视情况 |

**单位约定**：用 $\log_2$ 时单位是 bit，用 $\ln$ 时单位是 nat，$1\ \text{nat}=1.4427$ bit。深度学习框架默认用自然对数，所以损失值是 nat。规定 $0\log0=0$。

## 3. 信息量与熵

### 3.1 信息量

一个概率为 $p$ 的事件发生了，我们"有多惊讶"？希望满足三条：越不可能越惊讶；必然事件零惊讶；两个独立事件同时发生，惊讶相加。满足这三条的函数只有对数形式：

$$h(x)=-\log p(x).$$

事件概率为 $1/2$ 时 $h=1$ bit：恰好是"抛一次公平硬币"的信息量。

### 3.2 熵

熵是信息量的期望，度量分布的平均不确定性：

$$H(p)=-\sum_xp(x)\log p(x)=\mathbb{E}_{x\sim p}[-\log p(x)].$$

性质：$H\ge0$；确定性分布（某点概率 1）$H=0$；在 $n$ 个取值上均匀分布时最大，$H=\log n$。

### 3.3 手算：熵的"编码长度"解释

取 $p=(0.5,0.25,0.125,0.125)$（示例，非项目实测）：

$$H=0.5\cdot1+0.25\cdot2+0.125\cdot3+0.125\cdot3=1.75\ \text{bit}.$$

最优前缀码长度恰好是 $-\log_2p$：$0,10,110,111$，平均码长 $0.5\cdot1+0.25\cdot2+0.125\cdot3\cdot2=1.75$ bit。这给出熵的操作意义：**熵是无损压缩的平均码长下界**。均匀分布同样四个符号需 2 bit。

### 3.4 二元熵与占据栅格

占据栅格地图每个格子是伯努利变量，$H_b(p)=-p\log_2p-(1-p)\log_2(1-p)$。Python 复核：$p=0.5$ 时 $1.000$ bit；$p=0.9$ 时 $0.469$ bit；$p=0.99$ 时 $0.081$ bit。所以"不确定的格子"（接近 0.5）熵最大，主动探索（active exploration）会优先去观测这些格子。

## 4. 交叉熵与 KL 散度

### 4.1 定义

用分布 $q$ 去编码真实服从 $p$ 的数据，平均码长是交叉熵：

$$H(p,q)=-\sum_xp(x)\log q(x).$$

多出来的那部分"浪费"就是 KL 散度：

$$D_{\mathrm{KL}}(p\Vert q)=\sum_xp(x)\log\frac{p(x)}{q(x)}=H(p,q)-H(p).$$

### 4.2 KL 非负的证明（Gibbs 不等式）

用 $\ln t\le t-1$：

$$-D_{\mathrm{KL}}(p\Vert q)=\sum_xp(x)\ln\frac{q(x)}{p(x)}\le\sum_xp(x)\Big(\frac{q(x)}{p(x)}-1\Big)=\sum_xq(x)-1=0.$$

等号成立当且仅当 $p=q$。注意：KL **不对称**，不满足三角不等式，所以不是真正的"距离"。若某处 $q(x)=0$ 而 $p(x)>0$，则 $D_{\mathrm{KL}}=\infty$。

### 4.3 手算：交叉熵与不对称性

用上例 $p=(0.5,0.25,0.125,0.125)$，$q=(0.4,0.3,0.2,0.1)$（Python 复核）：

- $H(p,q)=1.8007$ bit；$H(p)=1.75$ bit；
- $D_{\mathrm{KL}}(p\Vert q)=1.8007-1.75=0.0507$ bit；
- $D_{\mathrm{KL}}(q\Vert p)=0.0536$ bit，不同，说明不对称。

若取 $q$ 为均匀分布 $(0.25,\dots)$：$H(p,q)=2$ bit，$D_{\mathrm{KL}}(p\Vert q)=0.25$ bit。

### 4.4 与分类损失的关系

分类时真实标签 one-hot：$p=(0,1,0)$，网络输出 softmax $q$。则

$$H(p,q)=-\log q_{\text{true}}.$$

这就是交叉熵损失。因为 $H(p)=0$，所以最小化交叉熵等价于最小化 KL。更一般地，数据集上的负对数似然 $-\frac1N\sum\log q_\theta(y_i\mid x_i)$ 就是经验分布与模型之间的交叉熵，因此**最大似然 = 最小交叉熵 = 最小化 $D_{\mathrm{KL}}(p_{\text{data}}\Vert q_\theta)$**。

**手算**：logits $z=(1,2,0)$，softmax $=(e^1,e^2,e^0)/(e+e^2+1)=(0.2447,0.6652,0.0900)$，真实类别为第 2 类，损失 $=-\ln0.6652=0.4076$ nat（Python 复核）。若真实为第 3 类，损失 $=-\ln0.09=2.408$ nat，惩罚大得多。二分类 $p=0.8$ 且真值为 1：$-\ln0.8=0.223$；若真值为 0：$-\ln0.2=1.609$。

### 4.5 前向与反向 KL 的行为差异

用简单分布 $q_\theta$ 去拟合复杂分布 $p$：最小化 $D_{\mathrm{KL}}(p\Vert q)$（前向）会让 $q$ **覆盖**所有 $p$ 有质量的地方（mass-covering），结果偏宽；最小化 $D_{\mathrm{KL}}(q\Vert p)$（反向）会让 $q$ 只贴住 $p$ 的一个峰（mode-seeking），结果偏窄。这个差别在变分推断、模仿学习、强化学习的策略约束（如 PPO 的 KL 惩罚）里经常被问到。

## 5. 互信息与信息增益

### 5.1 定义

两个随机变量 $X,Y$：

$$I(X;Y)=D_{\mathrm{KL}}\big(p(x,y)\Vert p(x)p(y)\big)=H(X)+H(Y)-H(X,Y)=H(X)-H(X\mid Y).$$

直观：知道 $Y$ 之后 $X$ 的不确定性平均减少了多少。独立时 $I=0$，$I\ge0$。

### 5.2 手算

联合分布（示例，非项目实测）：$P(0,0)=0.3,\ P(0,1)=0.1,\ P(1,0)=0.1,\ P(1,1)=0.5$。边缘 $P_X=(0.4,0.6)$，$P_Y=(0.4,0.6)$。

- $H(X)=H(Y)=0.9710$ bit；$H(X,Y)=1.6855$ bit；
- $I(X;Y)=0.9710+0.9710-1.6855=0.2564$ bit；
- $H(X\mid Y)=H(X,Y)-H(Y)=0.7145$ bit。

（Python 复核。）若 $X,Y$ 独立，联合应为 $(0.16,0.24,0.24,0.36)$，其熵为 $1.942$ bit，互信息为 0。

### 5.3 机器人里的"信息增益"

主动建图与主动感知中常见的目标函数是**期望信息增益**：选择动作 $a$，使观测 $z$ 与地图/状态 $m$ 的互信息 $I(m;z\mid a)$ 最大。实际工程里常用简化代理：统计传感器视野内未知或高熵栅格的数量（frontier 探索），本质是对互信息的粗略近似。决策树分裂也是同一思想：选择使"标签熵下降最多"的特征（信息增益）。

### 5.4 为什么互信息比相关系数更"通用"

相关系数只能捕捉线性关系：若 $Y=X^2$ 且 $X$ 关于 0 对称，二者的线性相关系数为 0，但互信息显然大于 0，因为知道 $Y$ 就几乎知道了 $\lvert X
vert$。所以互信息可用于判断"两个传感器读数是否携带关于同一状态的信息"、"某个特征对标签是否有用"等场景。它的缺点是对连续变量难以直接估计，需要分箱、核密度或神经估计器，样本少时偏差较大。机器人工程里更常见的做法是：用物理模型判断哪些量可观（见后面的可观性章节），用互信息或相关性做数据层面的事后检查，两者互补。

### 5.5 熵与滤波器的联系

对高斯状态，熵只取决于协方差行列式。卡尔曼滤波每一次更新后协方差缩小，等价于熵下降 $\Delta h=\frac12\ln\frac{\det P^-}{\det P^+}$，这就是这次观测提供的信息量。预测步协方差膨胀，熵上升。两步交替，熵保持在一个由 $Q$ 与 $R$ 平衡出来的稳态水平。用这个视角可以直观判断"某个传感器值不值得加"：它带来的熵下降是否抵得上额外的延迟、成本和失败模式。

## 6. 连续分布：高斯的熵与 KL

### 6.1 微分熵

$h(p)=-\int p(x)\ln p(x)\,dx$。一维高斯 $\mathcal N(\mu,\sigma^2)$ 的熵为 $\frac12\ln(2\pi e\sigma^2)$，$\sigma=1$ 时为 $1.4189$ nat，$\sigma=2$ 时为 $2.1121$ nat（Python 复核）；$n$ 维高斯为 $\frac12\ln\big((2\pi e)^n\det\Sigma\big)$。**协方差的行列式越大，不确定性越大**；卡尔曼滤波里协方差的"体积"缩小，就是熵在下降。

> **注意**：微分熵可以为负，且不是坐标变换不变量，只在比较、做差（如 KL、互信息）时才有稳定的意义。

### 6.2 两个高斯的 KL

一维：

$$D_{\mathrm{KL}}\big(\mathcal N(\mu_1,\sigma_1^2)\Vert\mathcal N(\mu_2,\sigma_2^2)\big)=\ln\frac{\sigma_2}{\sigma_1}+\frac{\sigma_1^2+(\mu_1-\mu_2)^2}{2\sigma_2^2}-\frac12.$$

手算：$\mathcal N(0,1)$ 对 $\mathcal N(1,2^2)$：$\ln2+\frac{1+1}{8}-0.5=0.6931+0.25-0.5=0.4431$ nat（Python 复核）。

### 6.3 VAE 里的 KL

变分自编码器（VAE）的编码器输出 $q(z\mid x)=\mathcal N(\mu,\sigma^2)$，先验为 $\mathcal N(0,1)$。令上式 $\mu_2=0,\sigma_2=1$：

$$D_{\mathrm{KL}}=\tfrac12\big(\mu^2+\sigma^2-1-\ln\sigma^2\big).$$

手算：$\mu=0.5$，$\sigma=0.8$：$\frac12(0.25+0.64-1-2\ln0.8)=\frac12(-0.11+0.4463)=0.1681$ nat（Python 复核）。损失函数为"重构误差 + KL"，即证据下界（ELBO）取负。详见 [序列模型、残差网络、ViT 与生成模型](../10_机器学习与深度学习/07_序列模型_残差网络_ViT与生成模型.md)。

## 8. 图的表示与基本概念

### 8.1 定义

图 $G=(V,E)$。边可以**有向**（有箭头）或**无向**，可以带**权**。路径是边的序列；起点终点相同的路径叫环；没有环的连通无向图叫**树**，$n$ 个节点的树恰有 $n-1$ 条边；没有环的有向图叫 DAG（有向无环图），可以拓扑排序（任务依赖、计算图、ROS2 节点启动顺序都是 DAG）。

### 8.2 两种存储

以 4 个节点、无向边 $\{1\text{-}2,1\text{-}3,2\text{-}3,3\text{-}4\}$ 为例：

```text
邻接矩阵 A (4x4)         邻接表
   1 2 3 4               1: [2, 3]
1  0 1 1 0               2: [1, 3]
2  1 0 1 0               3: [1, 2, 4]
3  1 1 0 1               4: [3]
4  0 0 1 0
```

| 对比 | 邻接矩阵 | 邻接表 |
|---|---|---|
| 空间 | $O(\lvert V\rvert^2)$ | $O(\lvert V\rvert+\lvert E\rvert)$ |
| 查 $i,j$ 是否有边 | $O(1)$ | $O(\deg i)$ |
| 遍历邻居 | $O(\lvert V\rvert)$ | $O(\deg i)$ |
| 适用 | 稠密图、矩阵运算（拉普拉斯谱） | 稀疏图（栅格地图、道路网、位姿图） |

栅格地图每个节点最多 4 或 8 个邻居，是典型的稀疏图，不会显式存邻接矩阵。举个数量级：一张 $1000\times1000$ 的栅格地图有 $10^6$ 个节点，若存稠密邻接矩阵需要 $10^{12}$ 个元素，按每个元素 1 字节也要约 1 TB，根本放不下；而邻接表只需要约 $8\times10^6$ 条有向边，几十兆字节。实际实现中连邻接表都不显式建立，而是在访问节点时根据其坐标"现算"邻居并查代价地图，这种隐式图（implicit graph）表示是栅格规划器和 Hybrid A* 的常规做法，因为状态空间可能巨大，但每次只会展开其中很小一部分。

选择有向还是无向图，取决于代价是否对称。车辆不能原地侧移、也不能倒着走上单行道，所以 Hybrid A* 的边天然是有向的；而两个相邻房间之间的拓扑图往往可以用无向边。选择有权还是无权图，取决于不同边的"代价"是否相同：无权用 BFS 即可，有权才需要 Dijkstra。这些看似琐碎的选择，决定了算法的复杂度与正确性，面试时能讲清楚就说明你真正理解了图搜索，而不是背了算法名字。

### 8.3 BFS 与 DFS

广度优先搜索（BFS）用队列，逐层扩展，在**无权图**上第一次到达某节点时的层数就是最少边数，所以 BFS 给出无权最短路。深度优先搜索（DFS）用栈或递归，适合连通分量、环检测、拓扑排序。复杂度均为 $O(\lvert V\rvert+\lvert E\rvert)$。

## 9. 搜索与最短路：BFS、Dijkstra

### 9.1 Dijkstra 的思想

边权非负时，维护每个节点的当前最短距离估计 $d[v]$，每次取未确定节点中 $d$ 最小者 $u$，**它的距离此时已经最终确定**（因为任何经过其他未确定节点绕行到 $u$ 的路径，距离都不会更短，边权非负是关键），再用 $u$ 去松弛（relax）邻居：若 $d[u]+w(u,v)<d[v]$ 则更新。用二叉堆实现，复杂度 $O((\lvert V\rvert+\lvert E\rvert)\log\lvert V\rvert)$。

### 9.2 手算

图（有向，示例）：$A\to B:4,\ A\to C:1,\ C\to B:2,\ B\to D:1,\ C\to D:5$。

- 起点 $A$：$d=\{A:0,B:\infty,C:\infty,D:\infty\}$；
- 取 $A$（0）：松弛得 $d[B]=4,\ d[C]=1$；
- 取 $C$（1）：$d[B]$ 候选 $1+2=3<4$，更新为 3；$d[D]=1+5=6$；
- 取 $B$（3）：$d[D]$ 候选 $3+1=4<6$，更新为 4；
- 取 $D$（4）：结束。

结果 $d=\{A:0,B:3,C:1,D:4\}$，前驱链 $D\leftarrow B\leftarrow C\leftarrow A$，最短路径 $A\to C\to B\to D$，代价 4（Python 复核）。注意直接边 $A\to B$ 代价 4 不是最短。

### 9.3 与 A* 的关系

A* 就是在 Dijkstra 的"取 $d$ 最小"处改成"取 $d+h$ 最小"，其中 $h$ 是对剩余代价的**启发式**估计。若 $h$ 可采纳（不高估），A* 保证最优；$h\equiv0$ 时退化为 Dijkstra。详见 [图搜索：Dijkstra 与 A*](../08_规划与导航/01_图搜索_Dijkstra_A星.md)。Hybrid A* 则把"节点"换成连续状态的离散化格子，边由车辆运动学生成。

### 9.4 负权边

Dijkstra 的正确性依赖边权非负。有负权边但无负环时用 Bellman–Ford（$O(\lvert V\rvert\lvert E\rvert)$）；位姿图里残差不是"路径长度"，这里不用此类算法。

## 10. 树与最小生成树

### 10.1 问题

给无向带权连通图，选出 $n-1$ 条边，把所有节点连起来且总权最小，称最小生成树（MST）。用途：通信网络布线、聚类（切掉最长的几条边）、RRT\* 之外的路网骨架、多机器人最小代价连通。

### 10.2 Kruskal 算法

边按权从小到大排序，依次加入，若加入后成环则丢弃（用并查集判断两端是否已连通）。正确性依赖"割性质"：连接任意一个割两侧的最轻边必在某棵 MST 中。

### 10.3 手算

边（示例）：$AB:4,\ AC:1,\ BC:2,\ BD:1,\ CD:5,\ CE:8,\ DE:3$。排序：$AC(1),BD(1),BC(2),DE(3),AB(4),CD(5),CE(8)$。

- 取 $AC$（连通 $\{A,C\}$）；取 $BD$（连通 $\{B,D\}$）；
- 取 $BC$（合并成 $\{A,B,C,D\}$）；取 $DE$（加入 $E$）；
- 此时已有 4 条边 $=n-1$，停止。总权 $1+1+2+3=7$（Python 复核）。

## 11. 二分图匹配与数据关联

### 11.1 问题

两组对象（例如上一帧的 3 个跟踪目标、本帧的 3 个检测框），要一一配对，使总代价最小。这是**二分图最小权完美匹配**，即指派问题（assignment problem）。机器人里的出现位置：多目标跟踪的数据关联、地图点与观测的关联、多机器人任务分配。

### 11.2 手算

代价矩阵（示例，行为目标，列为检测，数值可理解为 1 − IoU 的缩放）：

$$C=\begin{bmatrix}4&1&3\\2&0&5\\3&2&2\end{bmatrix}.$$

匈牙利算法的前两步：每行减去行最小值得 $\begin{bmatrix}3&0&2\\2&0&5\\1&0&0\end{bmatrix}$；再每列减去列最小值得 $\begin{bmatrix}2&0&2\\1&0&5\\0&0&0\end{bmatrix}$。覆盖所有零所需最少直线数（此处 2 条：第 2 列与第 3 行）小于 3，说明还不能直接选出 3 个独立零，需要进一步调整（取未覆盖元素最小值 1，从未覆盖元素中减去，加到被覆盖交点上），之后选出完美匹配。下一步取未被覆盖元素的最小值 1，从所有未被覆盖的元素中减去它，再加到被两条线同时覆盖的元素（第 3 行第 2 列）上，得到 $\begin{bmatrix}1&0&1\0&0&4\0&1&0\end{bmatrix}$。此时零出现在 $(1,2),(2,1),(2,2),(3,1),(3,3)$，可选出三个互不同行同列的零：$(1,2),(2,1),(3,3)$，即最优指派 $1\to2,\ 2\to1,\ 3\to3$，对应原代价 $1+2+2=5$。再用枚举全部 $3!=6$ 种排列验证，最小代价确为 5（Python 复核）。

匈牙利算法复杂度 $O(n^3)$，比穷举 $O(n!)$ 实用得多。

> **注意**：匹配只是"在给定代价下最优"，代价设计（用距离、IoU、马氏距离还是外观特征）才决定关联质量。马氏距离门限（gating）可先剔除不可能的配对，参见 [卡尔曼滤波与 EKF](../06_状态估计/03_卡尔曼滤波与EKF.md)。

## 12. 图拉普拉斯与连通性

### 12.1 定义与性质

$L=D-A$。对任意向量 $x$：$x^\top Lx=\sum_{(i,j)\in E}(x_i-x_j)^2\ge0$，所以 $L$ 半正定。最小特征值恒为 0，对应特征向量 $\mathbf 1$；**为 0 的特征值个数等于连通分量数**；第二小特征值 $\lambda_2$（Fiedler 值，又称代数连通度）越大，图越"结实"。

### 12.2 手算

前文 4 节点图的 $D=\mathrm{diag}(2,2,3,1)$，$L=D-A$ 的特征值为 $0,1,3,4$（Python 复核）。只有一个 0，故图连通；$\lambda_2=1$。若去掉边 $3\text{-}4$，节点 4 孤立，会出现第二个 0。

### 12.3 机器人里的用法

- 多机器人一致性控制：编队中每个机器人朝邻居平均位置移动，收敛速度由 $\lambda_2$ 决定；通信图不连通则无法达成一致（见规划模块的多机内容）；
- 谱聚类：用拉普拉斯的前几个特征向量对点云或地图分区；
- **位姿图**：节点是位姿，边是相对位姿约束。高斯牛顿的海森矩阵 $H=J^\top\Omega J$ 的稀疏结构与图的邻接结构完全一致：只有相邻节点对应的块非零，所以可以用稀疏 Cholesky 高效求解（见 [数值线性代数与稀疏求解](./08_数值线性代数与稀疏求解.md) 与 [SLAM问题_前端后端_位姿图优化](../07_SLAM与建图/01_SLAM问题_前端后端_位姿图优化.md)）。

## 14. 常见错误与故障现象

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 损失出现 NaN 或 inf | $\log0$：概率被舍入为 0 | 数值稳定实现：log-softmax、对概率裁剪 $\epsilon$ |
| 把 KL 当作距离使用，交换参数后结果不同 | 忽略不对称 | 明确谁是真值谁是模型；需要对称时用 JS 散度 |
| 熵单位混用 | bit 与 nat 混淆 | 注明对数底，$\ln$ 换 $\log_2$ 乘 1.4427 |
| Dijkstra 在含负代价的图上给出错误路径 | 违反非负假设 | 重新标定代价，或改用 Bellman–Ford |
| 最短路径路径"贴着障碍" | 代价只是距离，没有安全惩罚 | 在边权中加障碍代价，见代价地图 |
| 数据关联抖动，ID 切换 | 代价只用位置，没用门限和外观 | 加入马氏门限、IoU、外观特征 |
| 图优化求解慢 | 把稀疏图当稠密矩阵存储 | 用稀疏格式与稀疏 Cholesky |
| 连通性检查漏掉孤立节点 | 只看边数不看连通分量 | 用 BFS/并查集或拉普拉斯零特征值计数 |

## 15. 面试怎么问、怎么答

**Q1. What is KL divergence, and is it a distance?**

> KL divergence measures how much extra information, in bits or nats, you pay when you use distribution $q$ to model data that really comes from $p$. It is always non-negative and zero only when the two are equal, but it is not symmetric and does not satisfy the triangle inequality, so it is not a true distance. I use the direction that matches the problem: for maximum likelihood it is $D_{KL}(p_{data}\Vert q_\theta)$.

中文：KL 衡量用 $q$ 建模 $p$ 的额外代价；非负、仅 $p=q$ 为零，不对称、不满足三角不等式，所以不是距离。追问：前向与反向 KL 有什么区别？（前向覆盖全部峰，反向只贴一个峰。）

**Q2. Why do we use cross-entropy loss for classification?**

> With one-hot labels the cross-entropy is just the negative log probability of the true class. Minimising it is the same as maximum likelihood, and equivalent to minimising the KL divergence between the data distribution and the model. It also gives a clean gradient with softmax, $q-p$, which does not vanish when the model is confidently wrong, unlike squared error on probabilities.

中文：one-hot 时就是真类的负对数概率；等价于最大似然与最小 KL；配 softmax 梯度为 $q-p$，错得越离谱梯度越大。追问：为什么不用均方误差？（概率饱和时梯度消失。）

**Q3. Dijkstra versus A*: what is the difference?**

> Both expand nodes in order of a priority. Dijkstra uses the cost-so-far $g$, so it expands uniformly in all directions. A* uses $g+h$, where $h$ is a heuristic estimate of the remaining cost. If $h$ never overestimates, A* is still optimal but expands far fewer nodes. With $h=0$ it becomes Dijkstra.

中文：Dijkstra 按已走代价扩展，A* 按已走代价加启发式估计；启发式可采纳则仍最优且节点更少；$h=0$ 退化为 Dijkstra。追问：启发式不一致（inconsistent）会怎样？（可能需要重新展开节点。）

**Q4. How would you associate detections with existing tracks?**

> I build a cost matrix between tracks and detections, using for example one minus IoU or the Mahalanobis distance from the filter's prediction, set impossible pairs to a large cost with a gating threshold, and solve the assignment with the Hungarian algorithm in $O(n^3)$. Unmatched detections start new tracks and unmatched tracks age out.

中文：构造轨迹—检测代价矩阵（1−IoU 或马氏距离），门限剔除不可能配对，用匈牙利算法求最优指派；未匹配检测新建轨迹，未匹配轨迹老化删除。

**Q5. Why is a pose graph sparse, and why does it matter?**

> Each edge, an odometry or loop closure constraint, involves only two poses, so the Hessian has non-zero blocks only for connected pairs. That sparsity lets a sparse Cholesky factorisation solve thousands of poses in real time, instead of cubic cost on a dense matrix.

中文：每条约束只涉及两个位姿，海森矩阵只在相连的块非零，所以可用稀疏 Cholesky 在实时内求解而非稠密立方复杂度。

## 16. 本章要点速记

1. 信息量 $-\log p$，熵是其期望，是无损压缩的平均码长下界。
2. 均匀分布熵最大 $=\log n$；确定性分布熵为 0。
3. $H(p,q)=H(p)+D_{\mathrm{KL}}(p\Vert q)$；分类损失就是交叉熵，等价最大似然。
4. KL 非负、不对称；前向覆盖全峰，反向只追一个峰。
5. 互信息 $I=H(X)-H(X\mid Y)$，独立时为 0；信息增益用于主动探索与决策树。
6. 高斯 KL 有闭式；VAE 的 KL 为 $\frac12(\mu^2+\sigma^2-1-\ln\sigma^2)$。
7. 稀疏图用邻接表，稠密图/谱方法用邻接矩阵；$n$ 节点树有 $n-1$ 条边。
8. Dijkstra 要求非负权；A* = Dijkstra + 可采纳启发式。
9. Kruskal：排序 + 并查集，MST 总权手算为 7（示例图）。
10. 数据关联 = 指派问题，匈牙利算法 $O(n^3)$，要先做门限。
11. 拉普拉斯零特征值个数 = 连通分量数；位姿图的海森矩阵与图结构同构，所以稀疏。
