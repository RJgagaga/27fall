# 数学基础：学习顺序与前置关系

> **一句话定位**：所有后续章节的公共语言：向量与矩阵、变化率与微分方程、不确定性、最优选择、离散化与数值计算。

**本模块学完你能：**

- 读懂机器人里每一个"求逆、求特征值、求伪逆"的含义；
- 把物理量的变化写成微分方程并线性化；
- 用高斯分布描述不确定性并做融合；
- 把控制与规划问题写成最小二乘或二次规划；
- 把连续公式安全地搬到离散芯片上。

**前置知识**：无硬性前置，建议先读 [总览与学习路线](../00_总览与学习路线.md)。

## 与项目的关联

几乎所有项目；P1/P7 的 LQR 需要线性代数与 Riccati，P5 的 EKF 需要概率与高斯，P2 的 IK 需要伪逆与 QP。

## 阅读顺序建议

先读线性代数与微积分（可并行），再读概率统计；最优化依赖前两者；数值方法放在学控制和嵌入式之前读。
