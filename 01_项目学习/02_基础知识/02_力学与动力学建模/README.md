# 力学与动力学建模：学习顺序与前置关系

> **一句话定位**：把机器人写成方程：刚体力学、拉格朗日动力学、倒立摆线性化、轮式底盘运动学，以及动力学算法、接触与阻抗。

**本模块学完你能：**

- 推导小车摆与二连杆动力学；
- 把非线性模型在工作点线性化得到 A、B 矩阵；
- 写出差速、麦克纳姆、全向轮与阿克曼的运动学；
- 解释操作空间惯量、接触约束与阻抗控制。

**前置知识**：[线性代数](../01_数学基础/01_线性代数.md)、[微积分与常微分方程](../01_数学基础/02_微积分与常微分方程.md)。

牛顿欧拉 → 拉格朗日 → 倒立摆 → 车辆运动学（可独立读）→ 动力学进阶（需先读运动学雅可比章）→ 质心动力学与 LIPM（06，轮腿与平衡的物理）→ 柔性关节、摩擦与接触（07，解释带宽上限与仿真—实机差距）。
