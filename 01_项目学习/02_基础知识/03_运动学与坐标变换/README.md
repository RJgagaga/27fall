# 运动学与坐标变换：学习顺序与前置关系

> **一句话定位**：位置与姿态怎么表示、关节到末端怎么算、速度与力怎么传递，以及 URDF/KDL 动力学建模。

**本模块学完你能：**

- 在不同坐标系之间变换点和向量；
- 在旋转矩阵、欧拉角、四元数之间转换并避开万向锁；
- 推导正逆运动学与雅可比，处理奇异；
- 解释闭链五连杆与 URDF/KDL 重力补偿。

**前置知识**：[线性代数](../01_数学基础/01_线性代数.md)。
