# 信号与系统：学习顺序与前置关系

> **一句话定位**：传感器数据怎么看、滤波器怎么设计、控制器为什么稳定的共同语言：卷积、傅里叶、拉普拉斯、Z 变换、采样与滤波。

**本模块学完你能：**

- 手算卷积与 DFT；
- 读传递函数的极点零点与伯德图；
- 判断采样是否混叠；
- 设计并实现 EMA、Butterworth、陷波器和带滤波的微分。

**前置知识**：[微积分与常微分方程](../01_数学基础/02_微积分与常微分方程.md)、[数值方法与离散化](../01_数学基础/05_数值方法与离散化.md)。
