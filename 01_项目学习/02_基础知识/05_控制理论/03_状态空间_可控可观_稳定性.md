# 状态空间、可控可观与稳定性

> **一句话定位**：传递函数只描述"输入到输出"，状态空间把系统的**内部状态**也显式写出来。LQR、观测器、卡尔曼滤波、MPC 全都建立在状态空间之上；这一章为 [04 LQR](./04_LQR最优控制.md) 和 [05 MPC](./05_MPC模型预测控制.md) 铺路，并解释你在 P1 里"四状态倒立摆"到底是什么。

**本章学完你能：**

- 把一个微分方程或一个机器人系统写成 $\dot x=Ax+Bu,\ y=Cx$，说出 $x,u,y,A,B,C$ 的含义与单位；
- 做小角度线性化，求出 $A=\partial f/\partial x,\ B=\partial f/\partial u$，并说明线性化的适用范围；
- 用秩判据判断可控性和可观性，并解释"传感器没有测到某个量"在数学上意味着什么；
- 用李雅普诺夫（Lyapunov）方法判断稳定性，并解 $A^TP+PA=-Q$；
- 做极点配置（pole placement），理解 $K$ 与极点位置、控制量大小的关系；
- 设计一个龙伯格观测器（Luenberger observer），理解分离原理。

**前置知识**：[01 反馈控制与系统响应基础](./01_反馈控制与系统响应基础.md)（极点与稳定性）；[线性代数](../01_数学基础/01_线性代数.md)（矩阵乘法、特征值、秩）；[倒立摆建模与线性化](../02_力学与动力学建模/03_倒立摆建模与线性化.md)。

## 1. 为什么需要状态空间

PID 用"误差"一个量工作。但倒立摆的例子说明一个量不够：只知道倾角，不知道它是正在继续倒还是正在被扶回，无法决定怎样出力；只知道位置，不知道速度，不知道往哪边漂。**状态（state）就是"知道了它，再加上未来的输入，就能预测系统未来全部行为"的最小信息集合。** 机器人平衡的典型状态：位置、速度、倾角、角速度。

状态空间的优点：

| 优点 | 说明 |
|---|---|
| 多输入多输出自然处理 | P7 的轮子力矩 + 髋关节力矩两个输入 |
| 内部状态可见 | 不只看输出，可分析可控、可观 |
| 与最优/预测控制直接对接 | LQR、MPC、卡尔曼滤波都以 $(A,B,C)$ 为输入 |
| 适合计算机数值计算 | 矩阵运算 |

## 2. 状态空间形式与例子

### 2.1 标准形式

$$\dot x=Ax+Bu,\qquad y=Cx+Du.$$

| 符号 | 维度 | 含义 |
|---|---|---|
| $x\in\mathbb R^n$ | $n\times1$ | 状态向量 |
| $u\in\mathbb R^m$ | $m\times1$ | 控制输入 |
| $y\in\mathbb R^p$ | $p\times1$ | 测量输出 |
| $A$ | $n\times n$ | 系统矩阵：状态如何自己演化 |
| $B$ | $n\times m$ | 输入矩阵：输入如何推动状态 |
| $C$ | $p\times n$ | 输出矩阵：传感器测到了状态的哪些组合 |
| $D$ | $p\times m$ | 直通（常为 0） |

### 2.2 例 1：弹簧-质量-阻尼

$m\ddot q+c\dot q+kq=F$。取状态 $x=[q,\ \dot q]^T$，输入 $u=F$，输出 $y=q$：

$$\dot x=\begin{bmatrix}0&1\\-k/m&-c/m\end{bmatrix}x+\begin{bmatrix}0\\1/m\end{bmatrix}u,\quad y=\begin{bmatrix}1&0\end{bmatrix}x.$$

**推导思路**：把高阶微分方程降阶——引入 $x_1=q,\ x_2=\dot q$，则 $\dot x_1=x_2$（恒等式），$\dot x_2=\ddot q=(F-c\dot q-kq)/m$（原方程）。

**示例数值**：$m=1,c=3,k=2$：$A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix}$，特征值满足 $\lambda^2+3\lambda+2=0\Rightarrow\lambda=-1,-2$（过阻尼，稳定）。

### 2.3 例 2：双积分器（质量块受力）

$\ddot q=u$（$u$ 是加速度）。$x=[q,\dot q]^T$，$A=\begin{bmatrix}0&1\\0&0\end{bmatrix},\ B=\begin{bmatrix}0\\1\end{bmatrix}$。两个极点都在原点（临界稳定的最坏一类：对任何非零初速度，位置线性发散）。它是后面 LQR、MPC 手算的主角，也是"一个轮子带动车体"的最简化模型。

### 2.4 状态选择不唯一

任何可逆变换 $\tilde x=Tx$ 给出另一个等价描述 $\tilde A=TAT^{-1},\tilde B=TB,\tilde C=CT^{-1}$。**特征值、可控性、可观性、传递函数都不变**。工程上的选择原则：状态要**能测或能估**，且单位量纲清晰（位置 m，速度 m/s，角度 rad，角速度 rad/s）；不同量级的状态放在一个向量里时，需要在代价函数 Q 里考虑尺度（见 [04](./04_LQR最优控制.md)）。

### 2.5 从物理问题写出状态方程的"四步法"

面对一个新的机器人，不要一上来就套矩阵。固定做四步：

1. **画受力/受力矩图，写出每个自由度的运动方程**（牛顿-欧拉或拉格朗日，见 [牛顿欧拉与刚体力学](../02_力学与动力学建模/01_牛顿欧拉与刚体力学.md)、[拉格朗日方程与机器人动力学](../02_力学与动力学建模/02_拉格朗日方程与机器人动力学.md)）；
2. **选状态**：每个二阶自由度取"位置量 + 它的导数"。平衡机器人沿行进方向：位置 $x$、速度 $\dot x$；倾角 $\theta$、角速度 $\dot\theta$，共 4 个；
3. **选输入与输出**：输入是执行器真正能给的量（力矩、电流或速度指令，**要明确是哪一个**）；输出是传感器真正测到的量；
4. **在平衡点线性化，并整理成矩阵**，再检查量纲。

四状态平衡机器人线性化后的矩阵有典型的"结构"，了解它能帮你检查自己的矩阵：

```text
状态 x = [ p, v, th, w ]^T   (位置, 速度, 倾角, 倾角速度)

          p   v   th   w
  dp/dt [ 0   1   0    0 ]    <- 恒等式：位置的导数是速度
  dv/dt [ 0   0  a23   0 ]    <- 加速度受倾角影响（重力分量/耦合），符号取决于坐标约定
  dth/dt[ 0   0   0    1 ]    <- 恒等式：倾角的导数是角速度
  dw/dt [ 0   0  a43   0 ]    <- 角加速度受倾角影响，a43>0 表示"越倾越倒"(不稳定)

B = [ 0, b2, 0, b4 ]^T        <- 输入同时推动加速度和角加速度，且 b2 与 b4 符号相反
```

两条检查规则：(1) 第 1、3 行永远是"恒等式"，只有 1 和 0；(2) $a_{43}>0$（直立处重力使倾角发散）；$b_2$ 与 $b_4$ **异号**——驱动底座向前加速时，反作用使身体向后仰，这正是平衡的"反向耦合"。用这两条能迅速发现符号写错了。

## 3. 状态空间与传递函数、极点的关系

对 $\dot x=Ax+Bu,y=Cx$ 取拉氏变换（零初值）：$sX=AX+BU\Rightarrow X=(sI-A)^{-1}BU$，所以

$$G(s)=C(sI-A)^{-1}B+D=\frac{C\,\text{adj}(sI-A)B}{\det(sI-A)}+D.$$

因此**传递函数的分母就是 $\det(sI-A)$，极点 = $A$ 的特征值**（若无零极点对消）。这是把 [01 章](./01_反馈控制与系统响应基础.md) 的"极点决定稳定性"搬到状态空间：$\dot x=Ax$ 的解是 $x(t)=e^{At}x_0$，每个特征值 $\lambda_i$ 贡献 $e^{\lambda_it}$（若有复特征值则成对出现，产生振荡）。稳定 ⇔ 所有 $\text{Re}\,\lambda_i<0$。

**完整手算**：例 2.2 数值 $A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix}$，$C=[1\ 0]$，$B=[0\ 1]^T$。$sI-A=\begin{bmatrix}s&-1\\2&s+3\end{bmatrix}$，$\det=s(s+3)+2=s^2+3s+2$。$(sI-A)^{-1}=\dfrac{1}{s^2+3s+2}\begin{bmatrix}s+3&1\\-2&s\end{bmatrix}$，所以 $G(s)=C(sI-A)^{-1}B=\dfrac{1}{s^2+3s+2}$，与 $m\ddot q+c\dot q+kq=F$ 的传递函数 $\dfrac{1}{ms^2+cs+k}$ 一致。

## 4. 离散化

计算机每 $T$ 秒更新一次，需要离散模型 $x_{k+1}=A_dx_k+B_du_k$。在零阶保持（输入在一个周期内不变）下，精确解为

$$A_d=e^{AT},\qquad B_d=\int_0^Te^{A\tau}d\tau\,B.$$

推导：从 $x(t)=e^{At}x_0+\int_0^te^{A(t-s)}Bu\,ds$ 取 $t=T$，$u$ 在 $[0,T)$ 内为常数提出积分号。

**手算（双积分器）**：$A^2=0$，所以 $e^{AT}=I+AT=\begin{bmatrix}1&T\\0&1\end{bmatrix}$；$B_d=\int_0^T(I+A\tau)B\,d\tau=\int_0^T\begin{bmatrix}\tau\\1\end{bmatrix}d\tau=\begin{bmatrix}T^2/2\\T\end{bmatrix}$。取 $T=0.1$：$A_d=\begin{bmatrix}1&0.1\\0&1\end{bmatrix}$，$B_d=\begin{bmatrix}0.005\\0.1\end{bmatrix}$，这就是匀加速运动公式 $q_{k+1}=q_k+T\dot q_k+\tfrac12T^2u_k$。

欧拉近似 $A_d\approx I+AT,\ B_d\approx BT$ 对小 $T$ 够用，但在 $|\lambda|T$ 不小时误差很大或导致数值不稳定（详见 [08 数字控制与实时性](./08_数字控制与实时性.md) 和 [数值方法与离散化](../01_数学基础/05_数值方法与离散化.md)）。离散系统稳定 ⇔ $A_d$ 的特征值全在**单位圆内**。

## 5. 线性化

### 5.1 它要解决什么问题

真实机器人是非线性的：$\dot x=f(x,u)$。但 LQR、极点配置等线性工具需要 $\dot x=Ax+Bu$。**线性化就是在某个工作点附近用一阶泰勒展开代替非线性函数。**

### 5.2 推导

选平衡点 $(x_e,u_e)$ 满足 $f(x_e,u_e)=0$。令偏差 $\delta x=x-x_e,\ \delta u=u-u_e$。泰勒展开：
$$f(x,u)\approx f(x_e,u_e)+\underbrace{\frac{\partial f}{\partial x}\Big|_e}_{A}\delta x+\underbrace{\frac{\partial f}{\partial u}\Big|_e}_{B}\delta u,$$
故 $\dot{\delta x}=A\,\delta x+B\,\delta u$。$A_{ij}=\partial f_i/\partial x_j$（雅可比矩阵）。

### 5.3 完整手算：倒立摆

质量为 $m$ 的点质量挂在长 $l$ 的无质量杆上，铰链处输入力矩 $\tau$。以**竖直向上**为 $\theta=0$，运动方程 $ml^2\ddot\theta=mgl\sin\theta+\tau$。令 $x=[\theta,\dot\theta]^T,\ u=\tau$：

$$\dot x=\begin{bmatrix}x_2\\ \dfrac gl\sin x_1+\dfrac{u}{ml^2}\end{bmatrix}.$$

平衡点 $x_e=0,u_e=0$（$\sin0=0$）。雅可比：$\dfrac{\partial f_2}{\partial x_1}=\dfrac gl\cos x_1\big|_0=\dfrac gl$，$\dfrac{\partial f_2}{\partial u}=\dfrac1{ml^2}$：

$$A=\begin{bmatrix}0&1\\g/l&0\end{bmatrix},\quad B=\begin{bmatrix}0\\1/(ml^2)\end{bmatrix}.$$

特征值：$\lambda^2-g/l=0\Rightarrow\lambda=\pm\sqrt{g/l}$。**有一个正实根，开环不稳定**——这就是"倒立摆会倒"的数学形式。示例 $l=0.5$ m：$g/l=19.62$，$\lambda=\pm4.43$ s$^{-1}$。不稳定极点 $+4.43$ 意味着偏差以 $e^{4.43t}$ 增长，**时间常数 0.23 s**——控制闭环的带宽必须明显高于它，且延迟不能超过约这个量级的一小部分。腿越短 $g/l$ 越大，倒得越快，这就是 P7 里腿长变化时需要增益调度的物理原因（[04](./04_LQR最优控制.md) 第 8 节）。

**线性化的精度**：用 $\sin\theta\approx\theta$。$\theta=0.1$ rad 误差 0.17%；0.3 rad 误差 1.5%；0.5 rad 误差 4.3%；1 rad 误差 18.8%。所以倾角在 ±0.3 rad（约 17°）内线性模型很准，超出后偏差变大——这就是"线性控制器能救的范围有限"（吸引域）。

### 5.4 常见错误

- 在**非平衡点**线性化却忘了常数项（$f(x_e,u_e)\ne0$ 时多出一个偏置项）；
- 混用绝对量与偏差量，例如把 $u$（真实力矩）直接代入 $\delta u$ 的模型；
- 忘了线性化只在工作点附近有效：腿长变化时要在每个腿长重新线性化（增益调度）。

## 6. 可控性

### 6.1 要解决什么问题

能不能通过选择输入 $u(t)$，在有限时间内把状态从任意初值推到任意目标？若有某个状态方向输入怎么推都推不动，再强的反馈也救不了这个分量。

### 6.2 判据与推导

**可控性矩阵**：
$$\mathcal C=\begin{bmatrix}B&AB&A^2B&\cdots&A^{n-1}B\end{bmatrix}\in\mathbb R^{n\times nm}.$$
系统完全可控 ⇔ $\text{rank}\,\mathcal C=n$。

推导直觉（离散）：$x_1=A_dx_0+B_du_0$，$x_2=A_d^2x_0+A_dB_du_0+B_du_1$，……$x_n=A_d^nx_0+[B_d,\ A_dB_d,\ \dots,\ A_d^{n-1}B_d][u_{n-1},\dots,u_0]^T$。要使 $x_n$ 可以取任意值，就要求 $[B_d,A_dB_d,\dots]$ 的列张成整个 $\mathbb R^n$。Cayley–Hamilton 定理保证 $A^n$ 及更高次幂可由低次幂线性表示，所以只需到 $A^{n-1}B$。

### 6.3 完整手算

**例 1（可控）**：双积分器 $A=\begin{bmatrix}0&1\\0&0\end{bmatrix}$，$B=\begin{bmatrix}0\\1\end{bmatrix}$：$AB=\begin{bmatrix}1\\0\end{bmatrix}$，$\mathcal C=\begin{bmatrix}0&1\\1&0\end{bmatrix}$，秩 2。物理含义：加速度直接推速度，速度积分得位置。

**例 2（不可控）**：$A=\begin{bmatrix}1&0\\0&2\end{bmatrix}$，$B=\begin{bmatrix}1\\0\end{bmatrix}$：$AB=\begin{bmatrix}1\\0\end{bmatrix}$，$\mathcal C=\begin{bmatrix}1&1\\0&0\end{bmatrix}$，秩 1。第二个状态 $\dot x_2=2x_2$ 与输入完全无关，一个不稳定模态无论怎么控制都会发散。

**例 3（倒立摆）**：$A=\begin{bmatrix}0&1\\a&0\end{bmatrix}$，$B=\begin{bmatrix}0\\b\end{bmatrix}$（$a=g/l,\ b=1/(ml^2)$）：$AB=\begin{bmatrix}b\\0\end{bmatrix}$，$\mathcal C=\begin{bmatrix}0&b\\b&0\end{bmatrix}$，秩 2（$b\ne0$）。

**例 4（小车+摆，四状态）**：使用第 04 章同款模型 $M=1,m=0.5,L=0.5$（教学数值），数值计算 $\mathcal C$ 的秩为 4，即可控。但小车位置的可控性来自"摆与车的耦合"，通过倾斜摆来移动车——这是**非最小相位**特性：要让车向前移动，先要把它向后推一下让摆前倾。因此 LQR 求出的位置增益符号往往与直觉相反（见第 04 章表）。

### 6.4 工程含义

- "数学上可控"不等于"实际好控"：若 $\mathcal C$ 的最小奇异值很小（接近不可控），需要巨大控制量；还要考虑**输入饱和**——可控性是在"输入无界"假设下的结论；
- 状态量级差异大时，$\mathcal C$ 的秩判断在数值上不稳健，要缩放后再判断，或用可控性格拉姆矩阵；
- 若系统有两个输入（如 P7：轮子力矩与髋关节力矩）但某状态只被其中之一影响，需要检查每个输入的作用，而不是笼统说"可控"。

### 6.5 从模态角度理解可控性（PBH 判据）与多输入的情形

秩判据是代数形式；更直观的是**模态**视角。把 $A$ 对角化（假设特征值互异），系统分解成 $n$ 个独立的一阶模态 $\dot z_i=\lambda_iz_i+(\text{b}_i)u$，其中 $\text{b}_i$ 是 $B$ 在第 $i$ 个模态上的分量。**如果某个 $\text{b}_i=0$，输入根本推不动这个模态，它就是不可控的；如果这个模态恰好不稳定（$\lambda_i>0$），系统不可镇定。** 这就是例 2（$\dot x_2=2x_2$）的本质。PBH 判据是它的正式写法：$(A,B)$ 可控 ⇔ 对每个特征值 $\lambda$，$[\lambda I-A\ \ B]$ 行满秩。

退一步的概念是**可镇定（stabilizable）**：不可控的模态若本身稳定（$\lambda<0$），系统仍可镇定——输入虽然推不动它，但它自己会衰减。同理有**可检测（detectable）**：不可观的模态若稳定，估计误差也会自己衰减，观测器照样可用。工程上真正需要的往往是"可镇定 + 可检测"，而不是严格的完全可控可观。

**多输入情形**。P7 的轮腿机器人有两个输入：轮毂电机力矩 $T_w$ 和髋关节力矩 $T_p$（也可视为机体俯仰力矩）。$B$ 是 $n\times2$，$\mathcal C=[B\ AB\ \dots]$ 的列数更多，更容易满秩。一个常见陷阱：把两个输入当作两个独立执行器，但如果其中一个输入受到约束（例如脚离地后轮子力矩无效），$B$ 的有效列会变化——**可控性随接触状态变化**。这是 P7 里"地面接触切换"需要单独处理的原因之一（[04](./04_LQR最优控制.md) 第 8 节会进一步说明）。

**如何数值判断"接近不可控"**：对 $\mathcal C$ 做奇异值分解，最小奇异值 $\sigma_{min}$ 与最大奇异值 $\sigma_{max}$ 之比很小时（例如 $<10^{-6}$）意味着某个状态方向需要极大的输入才能移动。此时即使秩是满的，工程上也应视为"不可控"。更稳健的做法是用可控性格拉姆矩阵 $W_c=\int_0^Te^{A\tau}BB^Te^{A^T\tau}d\tau$：它的特征值就是"用单位能量输入能把状态推多远"的度量。

## 7. 可观性

### 7.1 要解决什么问题

传感器只测到 $y=Cx$，能不能从输出历史唯一地反推出全部状态？不能的话，状态反馈根本没法用（你不知道状态）。

### 7.2 判据

**可观性矩阵**：
$$\mathcal O=\begin{bmatrix}C\\CA\\CA^2\\\vdots\\CA^{n-1}\end{bmatrix},\quad\text{完全可观}\Leftrightarrow\text{rank}\,\mathcal O=n.$$
推导：$y=Cx,\ \dot y=CAx+CBu,\ \ddot y=CA^2x+\dots$——输出及其各阶导数给出方程组，未知量是 $x$（已知输入的影响可减去），要唯一解就要 $\mathcal O$ 列满秩。（可控与可观是对偶：$(A,B)$ 可控 ⇔ $(A^T,B^T)$ 可观。）

### 7.3 完整手算

**例 1**：双积分器只测位置 $C=[1\ 0]$：$CA=[0\ 1]$，$\mathcal O=\begin{bmatrix}1&0\\0&1\end{bmatrix}$，秩 2，可观——位置对时间求导就得到速度。

**例 2**：双积分器只测速度 $C=[0\ 1]$：$CA=[0\ 0]$，$\mathcal O=\begin{bmatrix}0&1\\0&0\end{bmatrix}$，秩 1，**不可观**——速度的积分只能给出位置相对初值的变化，初始位置永远无法知道。这就是为什么只有陀螺仪+加速度计的惯导会漂移，必须有位置测量（编码器、GPS、LiDAR）来"锚定"（见 [状态估计](../06_状态估计/04_里程计与传感器融合.md)）。

**例 3**：倒立摆只测角速度（陀螺仪）：$C=[0\ 1]$，$CA=[a\ 0]$，$\mathcal O=\begin{bmatrix}0&1\\a&0\end{bmatrix}$，秩 2，可观——因为倒立摆的动力学把倾角耦合进了角加速度。但实际上陀螺仪噪声和偏置使这个估计很差，所以平衡机器人用 IMU 的**姿态融合**（互补滤波/Mahony/EKF）来得到倾角。

### 7.4 在机器人里的意义

- 你的 [P1](../../01_项目课程/P1_AIRS球形机器人平衡控制/README.md) / [P7](../../01_项目课程/P7_可变腿长轮腿机器人/README.md) 描述里的"状态不一致"：位置、速度来自轮速，倾角来自 IMU，若时间戳或坐标系不一致，相当于测量方程 $C$ 被破坏，状态反馈会算出错误的控制；
- 不是所有状态都需要直接测量：测量位置，速度可以由观测器/差分得到；
- 可观性也是 EKF/AMCL 能否收敛的前提（见 [卡尔曼滤波与 EKF](../06_状态估计/03_卡尔曼滤波与EKF.md)）。

## 8. 稳定性与李雅普诺夫方法

### 8.1 它要解决什么问题

对线性系统，看特征值即可。但是：(1) 高阶矩阵求特征值不直观；(2) 非线性系统没有"特征值"；(3) 要给控制器（比如滑模）做稳定性证明。**李雅普诺夫方法的思想：不解方程，找一个类似"能量"的函数 $V(x)$，证明它沿着系统轨迹一直下降，就说明系统收敛。**

### 8.2 定义（连续系统 $\dot x=f(x)$，平衡点 $x=0$）

- **稳定（Lyapunov stable）**：从离 0 足够近出发，永远不跑远；
- **渐近稳定**：稳定且最终收敛到 0；
- **指数稳定**：$\|x(t)\|\le ce^{-\lambda t}\|x_0\|$（线性系统的稳定都是指数的）。

### 8.3 李雅普诺夫第二方法

找连续可微的 $V(x)$，满足 $V(0)=0$、$V(x)>0\ (x\ne0)$（正定），且沿轨迹
$$\dot V=\frac{\partial V}{\partial x}f(x)\le0\ (\text{稳定}),\qquad\dot V<0\ (x\ne0)\ (\text{渐近稳定}).$$
若还有 $V\to\infty$ 当 $\|x\|\to\infty$（径向无界），则全局渐近稳定。**LaSalle 不变集原理**：若只有 $\dot V\le0$，但"$\dot V\equiv0$ 的集合里除了原点没有完整轨迹"，仍可证明渐近稳定（例：带摩擦的摆，$\dot V=-bv^2$ 只在 $v=0$ 时为 0，但 $v=0$ 的点会被重力推走，所以仍收敛）。

### 8.4 线性系统：Lyapunov 方程

取 $V=x^TPx$，$P=P^T\succ0$。则 $\dot V=x^T(A^TP+PA)x$。若存在 $P\succ0$ 使
$$A^TP+PA=-Q,\qquad Q\succ0,$$
则 $\dot V=-x^TQx<0$，系统渐近稳定。**反过来**：$A$ 的特征值都在左半平面 ⇔ 对任意 $Q\succ0$ 方程有唯一的正定解 $P$。

**完整手算**：取例 2.2 的 $A=\begin{bmatrix}0&1\\-2&-3\end{bmatrix}$，$Q=I$。设 $P=\begin{bmatrix}p_1&p_2\\p_2&p_3\end{bmatrix}$。

$PA=\begin{bmatrix}-2p_2&p_1-3p_2\\-2p_3&p_2-3p_3\end{bmatrix}$，$A^TP=(PA)^T$，相加：
$$A^TP+PA=\begin{bmatrix}-4p_2&p_1-3p_2-2p_3\\p_1-3p_2-2p_3&2p_2-6p_3\end{bmatrix}=-\begin{bmatrix}1&0\\0&1\end{bmatrix}.$$

逐项：(1,1)：$-4p_2=-1\Rightarrow p_2=0.25$；(2,2)：$2p_2-6p_3=-1\Rightarrow0.5-6p_3=-1\Rightarrow p_3=0.25$；(1,2)：$p_1-0.75-0.5=0\Rightarrow p_1=1.25$。

$P=\begin{bmatrix}1.25&0.25\\0.25&0.25\end{bmatrix}$。检查正定：$\det=1.25\times0.25-0.0625=0.25>0$ 且 $p_1>0$，特征值 1.309、0.191 均正 ⇒ $P\succ0$ ⇒ 系统渐近稳定（与特征值 $-1,-2$ 一致）。$V=1.25x_1^2+0.5x_1x_2+0.25x_2^2$ 就是这个系统的"能量"，沿轨迹单调下降。

> **注意**：这里的 $P$ 是**李雅普诺夫矩阵**，与 [04 LQR](./04_LQR最优控制.md) 里的 Riccati 解 $P$ 是不同的方程，但形式相近：LQR 的 $x^TPx$ 恰好是"从 $x$ 出发最优控制的总代价"。别把它与机身质量、惯量混淆。

### 8.5 非线性例子：摆的能量

阻尼摆 $\ddot\theta=-\dfrac gl\sin\theta-b\dot\theta$，取能量 $V=\dfrac12\dot\theta^2+\dfrac gl(1-\cos\theta)$。$\dot V=\dot\theta\ddot\theta+\dfrac gl\sin\theta\,\dot\theta=-b\dot\theta^2\le0$。能量只会耗散，用 LaSalle 即得向下平衡点渐近稳定。**滑模控制的稳定性证明（[06](./06_滑模控制.md)）用的就是 $V=\tfrac12s^2$ 这一招。**

## 9. 状态反馈与极点配置

### 9.1 想法

既然 $\dot x=Ax+Bu$ 的极点由 $A$ 决定，用 $u=-Kx$（加上参考项）把闭环矩阵变成 $A-BK$，通过选 $K$ 把极点放到我们想要的位置。

**定理**：$(A,B)$ 完全可控 ⇒ 对任意一组共轭对称的期望极点，存在 $K$ 使 $A-BK$ 的特征值恰为它们。

### 9.2 手算（双积分器）

$A-BK=\begin{bmatrix}0&1\\-K_1&-K_2\end{bmatrix}$，特征多项式 $s^2+K_2s+K_1$。想要极点 $-2\pm2j$，期望多项式 $(s+2)^2+4=s^2+4s+8$。对比系数：$K_2=4,\ K_1=8$，故 $K=[8\ \ 4]$。验证 $\zeta=K_2/(2\sqrt{K_1})=4/(2\times2.83)=0.707$，$\omega_n=2.83$。

### 9.3 手算（倒立摆）

$A=\begin{bmatrix}0&1\\a&0\end{bmatrix}$，$B=\begin{bmatrix}0\\b\end{bmatrix}$，$A-BK=\begin{bmatrix}0&1\\a-bK_1&-bK_2\end{bmatrix}$，特征多项式 $s^2+bK_2s+(bK_1-a)$。取示例 $a=19.62,\ b=1$（归一化），期望极点 $-5,-10$，期望多项式 $s^2+15s+50$：$K_2=15$，$bK_1-a=50\Rightarrow K_1=69.62$。

**重要观察**：$K_1$ 必须大于 $a/b=19.62$——即使不要求任何性能，反馈刚度也必须先**克服重力倾覆项**才能让系统稳定；常数项 $bK_1-a>0$ 就是稳定的必要条件（二阶多项式系数全正）。这与 PID 里"P 增益太小救不回倒立摆"完全一致。

### 9.3b 极点快慢与控制量：定量对比

同一个倒立摆（$a=19.62,b=1$），比较两组期望极点：

| 极点 | 期望多项式 | $K_2$ | $K_1$ | 初始倾角 0.1 rad 时的初始控制量 $u_0=K_1\times0.1$ |
|---|---|---|---|---|
| $-5,-10$ | $s^2+15s+50$ | 15 | 69.62 | 6.96 |
| $-10,-20$ | $s^2+30s+200$ | 30 | 219.62 | 21.96 |

极点快一倍，控制量大约是三倍多（$K_1$ 近似随 $\omega^2$ 增长）。这有两层含义：(1) 控制量受电机力矩限制，极点不可能无限靠左，它的上限由执行器能力决定；(2) 增益越大，对传感器噪声和延迟越敏感（$K_2$ 乘角速度噪声）。**"控制量-响应速度"的权衡，在 LQR 里变成 $R$ 的取值**。

### 9.4 极点配置的局限

- **极点放多快？** 极点越靠左，$K$ 越大，控制量越大，噪声放大越严重，也更易触及饱和；
- **选极点没有指导原则**，多变量系统里同一组极点可对应无穷多个 $K$（此时还要选特征向量）；
- **鲁棒性与代价无法直接表达**；
- 这正是 LQR 的动机：用代价函数 $Q,R$ 表达"状态误差多重要、控制量多贵"，由 Riccati 方程自动给出极点（[04](./04_LQR最优控制.md)）。

## 10. 状态观测器

### 10.1 它要解决什么问题

状态反馈 $u=-Kx$ 需要全状态，但传感器常只给出一部分，或者带噪。**观测器（observer）用模型 + 测量重建状态。**

### 10.2 龙伯格观测器

$$\dot{\hat x}=A\hat x+Bu+L(y-C\hat x).$$

含义：先让估计 $\hat x$ 按模型向前演化（"预测"），再用输出误差 $y-C\hat x$ 乘增益 $L$ 去修正（"校正"）。定义估计误差 $e=x-\hat x$，相减得

$$\dot e=(A-LC)e.$$

误差动力学由 $A-LC$ 决定。若 $(A,C)$ 可观，则可任意配置 $A-LC$ 的极点（对偶于状态反馈）；选在左半平面且比控制极点快 2–5 倍，估计误差就指数衰减到 0。

### 10.3 手算：双积分器测位置

$C=[1\ 0]$，$L=[l_1\ l_2]^T$，$A-LC=\begin{bmatrix}-l_1&1\\-l_2&0\end{bmatrix}$，特征多项式 $s^2+l_1s+l_2$。要双极点 $-10$：$(s+10)^2=s^2+20s+100$，$l_1=20,\ l_2=100$。

初始估计误差 $e(0)=[1,0]^T$（位置估计偏 1，速度估计偏 0）。解析解：$e_1(t)=(1-10t)e^{-10t}$，$e_2(t)=-100t\,e^{-10t}$。数值：

| $t$（s） | $e_1$ | $e_2$ |
|---|---|---|
| 0.05 | 0.303 | −3.03 |
| 0.1 | 0 | −3.68 |
| 0.2 | −0.135 | −2.71 |
| 0.3 | −0.100 | −1.49 |
| 0.5 | −0.027 | −0.34 |

0.5 s 内位置误差降到 3% 以下，速度估计的偏差出现一个负的峰值（−3.68）再衰减。注意：**观测器极点太快（L 太大）会把传感器噪声放大**，这个"快慢折中"在卡尔曼滤波里由噪声协方差自动平衡（卡尔曼增益本质是最优的 $L$，见 [03 卡尔曼滤波与 EKF](../06_状态估计/03_卡尔曼滤波与EKF.md)）。

### 10.4 分离原理

用估计状态做反馈 $u=-K\hat x$。联合系统的特征值 = $\{A-BK\}$ 的特征值 ∪ $\{A-LC\}$ 的特征值。**即：可以独立设计 $K$ 和 $L$。** 推导：以 $(x,e)$ 为状态，$\dot x=(A-BK)x+BKe$，$\dot e=(A-LC)e$，系数矩阵是分块上三角，特征值为两个对角块特征值之并。

> **注意**：分离原理对**线性、模型准确**的系统成立。实际中，观测器引入的延迟、模型误差会降低鲁棒性（LQG 不保证 LQR 的裕度）。

### 10.5 实践里的观测器：离散实现、偏置与"估计器的估计器"

控制器跑在 MCU 上，观测器也必须离散化。最直接的做法是用第 4 节的 $(A_d,B_d)$，写成"预测-校正"两步：

$$\hat x_{k|k-1}=A_d\hat x_{k-1}+B_du_{k-1},\qquad\hat x_k=\hat x_{k|k-1}+L_d\,(y_k-C\hat x_{k|k-1}).$$

这与卡尔曼滤波的结构完全一样，区别只是 $L_d$ 是固定增益还是由噪声协方差在线计算。离散观测器的稳定条件是 $A_d-L_dC$ 的特征值在单位圆内。

实际系统里观测器常遇到三件事：

1. **传感器偏置**：陀螺仪零偏、编码器零位偏差。可以把偏置也扩展成状态（$\dot b=0$），让观测器一起估计，前提是扩展后的系统仍可观；
2. **采样不同步**：IMU 以 1 kHz 更新，轮速以 200 Hz 更新。观测器的 $C$ 在不同时刻对应不同的测量子集，本质是时变观测，需要按"到达的测量"选择校正步骤；
3. **模型误差**：模型偏差会让估计出现稳态偏移，需要靠测量校正拉回来，所以 $L$ 不能太小。

在平衡机器人里，姿态一般不是用上面这个观测器，而是用互补滤波/Mahony（固定增益）或 EKF（随状态变化的增益）来融合陀螺仪与加速度计。它们是观测器的特例，详见 [互补滤波与 Mahony AHRS](../06_状态估计/02_互补滤波与Mahony_AHRS.md)。

### 10.6 稳定性概念对照表（防止面试时混用）

| 概念 | 一句话 | 线性系统判据 | 典型对象 |
|---|---|---|---|
| 渐近稳定 | 受扰后最终回到平衡点 | 所有 $\text{Re}\,\lambda<0$ | 闭环后的平衡机器人 |
| 临界稳定 | 不发散也不衰减 | 有 $\text{Re}\,\lambda=0$ 的单根 | 无阻尼振荡器 |
| 不稳定 | 偏差越来越大 | 有 $\text{Re}\,\lambda>0$ | 开环倒立摆 |
| BIBO 稳定 | 有界输入给出有界输出 | 传递函数极点都在左半平面 | 滤波器 |
| 内部稳定 | 所有内部状态都有界 | 看 $A$ 的特征值，不是传递函数 | 有零极点对消的系统（对消的极点可能不稳定而被"藏起来"） |
| 输入输出稳定 ≠ 内部稳定 | 传递函数稳定但某内部模态发散 | 需要检查可控/可观 | 控制器想"对消"不稳定极点（绝对不要这样做） |

> **面试要点**：被问到"零极点对消为什么危险"，回答：如果被对消的极点在右半平面，输出看起来正常，但内部状态仍在发散，并且任何微小的模型误差都会使对消失败，所以只能用反馈**移动**不稳定极点，不能用前馈**抵消**它。

## 12. 常见错误

| 错误 | 后果 |
|---|---|
| 状态顺序/符号在建模和控制代码中不一致（例如模型里前倾为正，代码里前倾为负） | 反馈符号反，立即发散；排查时先核对符号约定 |
| 单位混用（mm 与 m，度与弧度） | 增益差 $10^3$ 或 $57.3$ 倍 |
| 线性化点不对 | $A,B$ 不对应真实平衡点 |
| 连续 $A,B$ 直接当离散用 | $K$ 对应错误模型，计算周期一变就失效 |
| 只检查可控、忽略可观 | 以为能反馈，其实某状态没有测量 |
| 忽略饱和 | 线性稳定性结论失效（[07](./07_前馈_增益调度_限幅与饱和.md)） |

## 13. 面试问答

**Q1. Why do we use state-space representation instead of just transfer functions?**

> A: A transfer function only describes the input-output relation of a single channel, while a state-space model exposes the internal states and handles multiple inputs and outputs naturally. For a balancing robot I need position, velocity, tilt and tilt rate together, and tools like LQR, observers and MPC all work directly on the matrices A and B. State space also lets me check controllability and observability, which transfer functions can hide through pole-zero cancellations.

（状态空间显式给出内部状态，天然多变量，LQR/观测器/MPC 都基于 A、B；能检查可控可观。）

**Q2. What do controllability and observability mean? Give an example.**

> A: Controllability asks whether inputs can drive the state to any target; observability asks whether the state can be reconstructed from the outputs. For example, a double integrator measured only by its velocity is not observable, because you can never know the initial position. That is why a gyro-only attitude estimate drifts and why we need an absolute reference such as an encoder or LiDAR.

（可控=输入能否推到任意状态，可观=输出能否反推状态；例子：只测速度不可观位置。）

**Q3. Explain what linearisation is and what its limits are.**

> A: I take the nonlinear model, pick an equilibrium and use the first-order Taylor expansion, so that A and B become Jacobians. For the inverted pendulum, replacing sin θ by θ gives an unstable pole at plus or minus the square root of g over l. The model is accurate within a small tilt angle, roughly 0.3 rad, with an error of about 1.5 percent. Outside that range the linear controller may still work, but there is no guarantee, and when parameters like leg length change I need to relinearise, which is why we schedule the gains.

**Q4. What is the separation principle?**

> A: For a linear system, I can design the state feedback gain K and the observer gain L independently. The eigenvalues of the combined closed loop are the union of those of A minus BK and A minus LC. I usually make the observer a few times faster than the controller, but not so fast that it amplifies sensor noise.

*追问方向*：separation 在非线性或模型不准时还成立吗？（不保证，LQG 没有 LQR 的鲁棒性保证。）

**Q5.（用于 P1）In P1 you modelled a four-state inverted pendulum. Why four states?** → 答案模板：Position and velocity describe where the base is and how it drifts; tilt and tilt rate describe whether the body is falling and how fast. With only tilt you know the body is leaning but not whether the base is already moving to catch it. （位置/速度描述底座漂移，倾角/倾角速度描述倒下的趋势。）具体用的 Q/R 与分析结论请见 [04 LQR](./04_LQR最优控制.md)，并以你的实际工作记录为准。

## 本章要点速记

1. 状态 = 预测未来所需的最小信息；$\dot x=Ax+Bu,\ y=Cx$；极点 = $A$ 的特征值。
2. 离散化（ZOH）：$A_d=e^{AT}$，$B_d=\int_0^Te^{A\tau}d\tau B$；稳定看是否在单位圆内。
3. 线性化：$A=\partial f/\partial x$，$B=\partial f/\partial u$ 于平衡点；倒立摆 $\lambda=\pm\sqrt{g/l}$，腿越短越不稳定。
4. 可控：$\text{rank}[B,AB,\dots,A^{n-1}B]=n$；可观：$\text{rank}[C;CA;\dots]=n$；两者对偶。
5. 李雅普诺夫：找 $V>0,\dot V<0$；线性系统解 $A^TP+PA=-Q$。
6. 极点配置：$K$ 由期望特征多项式系数比对得到；刚度必须先克服倾覆项（$bK_1>a$）。
7. 观测器：$\dot e=(A-LC)e$；分离原理：$K$ 与 $L$ 可独立设计；观测器过快会放大噪声。
8. "数学可控"不等于"实际好控"：看奇异值、输入饱和、状态一致性。

## 自测题

1. 写出 $\ddot q+4\dot q+3q=2u$ 的 $A,B,C$ 与极点。*答案*：$A=\begin{bmatrix}0&1\\-3&-4\end{bmatrix},B=\begin{bmatrix}0\\2\end{bmatrix},C=[1\ 0]$；极点 $-1,-3$。
2. 判断 $A=\begin{bmatrix}0&1\\-1&0\end{bmatrix}$，$B=\begin{bmatrix}0\\1\end{bmatrix}$ 的可控性。*答案*：$AB=[1,0]^T$，$\mathcal C$ 秩 2，可控（无阻尼振荡器，极点 $\pm j$）。
3. 倒立摆 $l=1$ m，求开环不稳定极点和发散时间常数。*答案*：$\sqrt{9.81}=3.13$ s$^{-1}$，时间常数 0.32 s。
4. 对双积分器设计极点 $-3,-3$ 的状态反馈。*答案*：$(s+3)^2=s^2+6s+9$，$K=[9\ \ 6]$。
5. 为什么只用陀螺仪积分得到的倾角会漂移？用可观性解释。*要点*：若测量只含角速度（导数），则角度的常数偏置不可观，噪声和偏置积分后漂移，需要加速度计/磁力计等绝对参考融合。
6. 解释 $A^TP+PA=-Q$ 与 LQR 的 Riccati 方程的关系。*要点*：Lyapunov 方程是 Riccati 方程在 $B=0$（无控制）时的特例，$x^TPx$ 在 Lyapunov 里是"能量"，在 LQR 里是"最优总代价"。
