# 频域设计：根轨迹、奈奎斯特、伯德图与超前滞后校正

> **一句话定位**：状态空间方法（极点配置、LQR）需要完整的模型；而工程里很多回路——电流环、速度环、云台位置环——常常只能测出一条频率响应，或者只有一个粗略的传递函数。根轨迹、奈奎斯特判据和伯德图给出一套"看图设计"的方法：看清增益加大时极点往哪走，判断闭环稳不稳，量化稳定裕度，再用超前/滞后校正器把曲线整形到想要的形状。

**本章学完你能：**

- 按规则画出开环传递函数的根轨迹草图，并手算分离点、渐近线与临界增益（劳斯判据、虚轴交点）；
- 叙述奈奎斯特判据 $Z=N+P$，用它判断含积分环节的回路在不同增益下的稳定性，并读出增益裕度、相位裕度；
- 在伯德图上从指标（稳态误差、带宽、相位裕度）反推设计要求，理解 $\mathrm{PM}\leftrightarrow\zeta$、$\omega_c\leftrightarrow$ 带宽、灵敏度峰值 $M_s$ 的关系；
- 完整设计一个超前校正器：算出 $\alpha$、$T$，验证相位裕度从 $18^\circ$ 提到约 $50^\circ$，并比较阶跃响应；
- 解释滞后校正与 PI 的关系，以及 PID 的频域含义（滞后—超前）；
- 手算延迟、外环/内环带宽比对相位裕度的影响；
- 用英文回答 "What do gain and phase margin tell you / how to design a lead compensator / root locus vs Bode" 等问题。

## 1. 问题：为什么还要学频域设计

你可能会问：我们已经有 LQR、MPC，为什么还要学这些"古典方法"？有三个现实理由。

**第一，很多回路根本没有精确的状态空间模型。** 电机电流环、速度环、云台位置环，常常是通过扫频或阶跃实验得到一个近似的传递函数；这时直接在频率响应上做设计，比先辨识一个高阶状态空间模型更快、更稳健。

**第二，稳定裕度是工程语言。** "相位裕度 45 度"、"增益裕度 6 dB"，是调试现场沟通控制器好坏的通用说法，也是你面试时说明"为什么这样调"的最自然的方式。LQR 理论上有大裕度（连续时间 $\ge60^\circ$、增益裕度无穷），但一旦加入延迟、采样、执行器饱和，实际裕度还得回到频域去核查。

**第三，它给出直觉。** 根轨迹告诉你增益加大时闭环极点往哪里跑；伯德图告诉你每个频段的增益与相位；奈奎斯特图告诉你离"临界点 $-1$"还有多远。三者合起来，让你在调 PID 时知道应该调哪个参数、预期会发生什么。

本章按"根轨迹 → 奈奎斯特 → 伯德图 → 校正器设计 → 非理想因素"的顺序展开，并全程用能手算、能验证的例子。

## 2. 符号与指标

| 符号 | 含义 | 单位 |
|---|---|---|
| $L(s)=C(s)G(s)$ | 开环传递函数（回路传递函数） | |
| $T(s)=\dfrac{L}{1+L}$ | 补灵敏度（闭环传递函数） | |
| $S(s)=\dfrac1{1+L}$ | 灵敏度函数 | |
| $K$ | 增益参数（根轨迹的变量） | |
| $\omega_c$ | 穿越频率：$\lvert L(j\omega_c)\rvert=1$ | rad/s |
| $\omega_{180}$ | 相位穿越频率：$\angle L(j\omega_{180})=-180^\circ$ | rad/s |
| $\mathrm{PM}=180^\circ+\angle L(j\omega_c)$ | 相位裕度 | 度 |
| $\mathrm{GM}=1/\lvert L(j\omega_{180})\rvert$ | 增益裕度 | 倍或 dB |
| $M_s=\max_\omega\lvert S(j\omega)\rvert$ | 灵敏度峰值 | |
| $\alpha<1$ | 超前校正器的零极点比 | |
| $T_d$ | 纯延迟时间 | s |

**常用对应关系**（经验）：$\zeta\approx\mathrm{PM}/100$（PM 小于约 $60^\circ$）；闭环带宽约为 $\omega_c$ 的 1 到 2 倍；二阶系统的超调 $M_p=\exp(-\pi\zeta/\sqrt{1-\zeta^2})$。

## 3. 根轨迹：规则与手算

### 3.1 定义

根轨迹是当增益 $K$ 从 $0$ 变化到 $\infty$ 时，闭环特征方程 $1+KG_0(s)=0$ 的根在 $s$ 平面上的轨迹。起点（$K=0$）是开环极点，终点（$K\to\infty$）是开环零点或无穷远处。

### 3.2 常用规则

1. **分支数** = 开环极点数 $n$；
2. **实轴上的轨迹**：实轴上某点右侧（开环实极点与实零点总数）为奇数，则该点在轨迹上；
3. **渐近线**：$n-m$ 条（$m$ 为零点数），夹角 $\dfrac{(2k+1)180^\circ}{n-m}$，交点（质心）$\sigma_a=\dfrac{\sum p_i-\sum z_j}{n-m}$；
4. **分离点/汇合点**：由 $\dfrac{dK}{ds}=0$ 解出，其中 $K=-1/G_0(s)$；
5. **与虚轴交点**：令 $s=j\omega$ 代入特征方程，或用劳斯判据求临界增益；
6. **出射角/入射角**：由相角条件计算。

### 3.3 手算：$G_0(s)=\dfrac1{s(s+1)(s+2)}$

特征方程 $s^3+3s^2+2s+K=0$。

- **极点**：$0,-1,-2$；$n=3,m=0$；
- **实轴轨迹**：$[-1,0]$ 与 $(-\infty,-2]$；
- **渐近线**：夹角 $\pm60^\circ$ 和 $180^\circ$，质心 $\sigma_a=(0-1-2)/3=-1$；
- **分离点**：$K=-(s^3+3s^2+2s)$，$dK/ds=-(3s^2+6s+2)=0\Rightarrow s=-1\pm0.5774$，即 $-0.4226$ 或 $-1.5774$；后者不在实轴轨迹上（它落在 $[-2,-1]$ 之间，不属于轨迹），取 $s=-0.4226$，对应 $K=0.3849$；
- **虚轴交点**：劳斯阵列 $s^1$ 行首项 $(3\times2-K)/3$，令其为零得 $K=6$；辅助方程 $3s^2+K=0\Rightarrow s=\pm j\sqrt2=\pm1.414j$（Python 复核 $K=6$ 时根为 $-3,\pm1.414j$）；
- **结论**：$0<K<6$ 稳定；$K>6$ 不稳定；$K<0.3849$ 三个实根，之后一对复根。

取 $K=3$：根为 $-2.672,\ -0.164\pm1.047j$，复根的阻尼比 $\zeta=0.156$，极弱阻尼，说明此增益下阶跃响应会有明显的长时间振荡。

### 3.4 根轨迹能给你什么

直观看到"增益 $K$ 增大会让哪些极点靠近虚轴"，以及增加一个零点/极点（校正器）会如何拉动根轨迹：加零点会把轨迹向左拉（更稳定），加极点会向右推。**但根轨迹对延迟（超越函数）不方便**——延迟需要近似，所以工程上延迟较重的回路更多用频域。

## 4. 奈奎斯特判据与稳定裕度

### 4.1 判据

对开环传递函数 $L(s)$，令 $s$ 沿奈奎斯特路径（整个虚轴加右半平面的无穷大半圆；遇到虚轴上的开环极点用小半圆绕开）走一圈，$L(s)$ 在复平面画出奈奎斯特曲线。设 $P$ 为开环右半平面极点数，$N$ 为曲线**顺时针**绕 $-1$ 点的圈数，则闭环右半平面极点数

$$\boxed{Z=N+P}.$$

闭环稳定当且仅当 $Z=0$。对 $P=0$ 的系统（最常见），稳定条件即：曲线**不绕**$-1$。

### 4.2 手算：$L(s)=\dfrac{K}{s(s+1)(s+2)}$

相位穿越频率：$\angle L=-90^\circ-\arctan\omega-\arctan(\omega/2)=-180^\circ$，解得 $\omega_{180}=\sqrt2$。此处 $\lvert L\rvert=\dfrac K{\omega\sqrt{\omega^2+1}\sqrt{\omega^2+4}}=\dfrac K{1.414\times1.732\times2.449}=\dfrac K6$。

- $K<6$：曲线在负实轴上与 $-1$ 点的距离在右侧（$\lvert L\rvert<1$），不绕 $-1$，$N=0$，$P=0$，$Z=0$ 稳定；
- $K>6$：曲线在负实轴上越过 $-1$，顺时针绕 2 圈，$Z=2$，闭环有两个右半平面极点。验证：$K=10$ 时特征方程 $s^3+3s^2+2s+10=0$ 的根为 $-3.31,\ 0.154\pm1.732j$（Python 复核），确有两个正实部的复根；
- **增益裕度**：$\mathrm{GM}=1/\lvert L(j\omega_{180})\rvert=6/K$。$K=2$ 时 $\mathrm{GM}=3$（$9.5$ dB）；$K=3$ 时 $\mathrm{GM}=2$（$6$ dB）。

### 4.3 裕度的含义

- **增益裕度**：开环增益再放大多少倍到临界；
- **相位裕度**：穿越频率处再增加多少度的相位滞后到临界；
- 两者都小时系统靠近"$-1$"，闭环响应振荡大、对参数变化敏感。仅看其中一个会被误导：例如一个二阶系统增益裕度无穷，但相位裕度可能只有十几度。**相位裕度、增益裕度要一起看，最好再看 $M_s$。**

**手算：$K=2$ 与 $K=1$。** $K=2$：$\omega_c=0.749$ rad/s，$\mathrm{PM}=32.6^\circ$，$\mathrm{GM}=3.0$（Python 复核）；$K=1$：$\omega_c=0.446$ rad/s，$\mathrm{PM}=53.4^\circ$，$\mathrm{GM}=6.0$。把增益降一半，裕度大幅改善，但带宽也降低——这是"稳定性与速度"的基本折中。

## 5. 伯德图：指标与回路整形

### 5.1 指标到频域要求

用回路增益 $L(j\omega)$ 的幅频曲线表示的设计思路（loop shaping）：

| 指标 | 对 $L$ 的要求 |
|---|---|
| 稳态误差小、扰动抑制好 | 低频段增益大（斜率 $-20$ 或 $-40$ dB/dec，积分环节个数决定系统型别） |
| 带宽/响应速度 | 穿越频率 $\omega_c$ 足够高 |
| 稳定裕度 | 穿越频率附近斜率约 $-20$ dB/dec（相位不过 $-180^\circ$），PM 在 $45$–$60^\circ$ |
| 抑制测量噪声 | 高频段增益小（陡峭下降） |
| 对高频未建模动态（共振、延迟）鲁棒 | $\omega_c$ 远低于它们的频率 |

这些要求有内在矛盾：高低频增益差得越多，斜率就越陡，而斜率越陡相位就越滞后（Bode 增益—相位关系）。设计的艺术在于**在 $\omega_c$ 附近保持约 $-20$ dB/dec 的斜率，在两侧再分别抬高低频、压低高频**。

### 5.2 相位裕度、阻尼与超调

经验关系 $\zeta\approx\mathrm{PM}/100$：$\mathrm{PM}=18^\circ\Rightarrow\zeta\approx0.18$，超调 $\approx56\%$；$\mathrm{PM}=50^\circ\Rightarrow\zeta\approx0.5$，超调 $\approx16\%$。这是二阶系统的近似，真实高阶系统偏差较大，用于快速估计。

## 6. 手算：未校正系统的问题

沿用 [反馈控制与系统响应基础](./01_反馈控制与系统响应基础.md) 的对象：$L_0(s)=\dfrac{10}{s(s+1)}$。

- 穿越频率 $\omega_c=3.08$ rad/s（解 $\omega^4+\omega^2-100=0$）；
- 相位 $\angle L_0=-90^\circ-\arctan(3.08)=-162.0^\circ$，所以 $\mathrm{PM}=18.0^\circ$；
- 闭环极点 $-0.5\pm3.12j$，$\zeta=0.158$；
- 灵敏度峰值 $M_s=3.35$，补灵敏度峰值 $M_p(T)=3.20$（Python 数值计算）；
- 阶跃超调 $60.5\%$，调整时间：2% 判据下理论约 $4/0.5=8$ s。

问题：**稳态误差（$K_v=10$）满足，但相位裕度太小，响应振荡严重**。这正是超前校正要解决的问题：不改变低频增益（保持 $K_v=10$），提高穿越频率附近的相位。

## 7. 超前校正的设计

### 7.1 超前校正器

$$C_{\text{lead}}(s)=\frac{1+Ts}{1+\alpha Ts},\quad 0<\alpha<1.$$

零点在 $1/T$，极点在 $1/(\alpha T)$，直流增益为 1，高频增益为 $1/\alpha$。最大相位超前出现在两个转折频率的几何平均处

$$\omega_m=\frac1{T\sqrt\alpha},\qquad \varphi_m=\arcsin\frac{1-\alpha}{1+\alpha},\qquad \alpha=\frac{1-\sin\varphi_m}{1+\sin\varphi_m}.$$

在 $\omega_m$ 处幅值为 $1/\sqrt\alpha$（相对低频 $+10\log_{10}(1/\alpha)$ dB 的一半）。

### 7.2 设计步骤

目标：保持 $K_v=10$（直流增益不变），$\mathrm{PM}\ge50^\circ$。

1. 现有 $\mathrm{PM}=18.0^\circ$，需要补偿 $50-18=32^\circ$，再留余量 $5^\circ$（因为加了校正器后穿越频率右移，原对象相位更滞后）：$\varphi_m=37^\circ$；
2. $\alpha=\dfrac{1-\sin37^\circ}{1+\sin37^\circ}=\dfrac{1-0.6018}{1.6018}=0.2486$（$1/\alpha=4.02$）；
3. 让校正器最大相位出现在新的穿越频率：校正器在 $\omega_m$ 处增益为 $1/\sqrt\alpha=2.006$，所以新穿越频率满足 $\lvert L_0(j\omega_m)\rvert=\sqrt\alpha=0.4986$。解 $\dfrac{10}{\omega\sqrt{\omega^2+1}}=0.4986$ 得 $\omega_m=4.42$ rad/s；
4. $T=\dfrac1{\omega_m\sqrt\alpha}=\dfrac1{4.42\times0.4986}=0.4535$ s；零点 $1/T=2.205$ rad/s，极点 $1/(\alpha T)=8.87$ rad/s。

### 7.3 验证（Python）

- 新穿越频率 $\omega_c=4.42$ rad/s，**$\mathrm{PM}=49.7^\circ$**；
- 灵敏度峰值 $M_s$ 从 $3.35$ 降到 $1.42$；补灵敏度峰值从 $3.20$ 降到 $1.25$；
- 闭环 $-3$ dB 带宽从 $4.83$ rad/s 升到 $7.25$ rad/s；
- 闭环极点 $-3.34\pm4.08j$ 和 $-3.19$（原来是 $-0.5\pm3.12j$）；
- 阶跃响应超调从 $60.5\%$ 降到 $22.4\%$，2% 调整时间约 $1.23$ s（原来数秒以上）。

校正器让极点远离虚轴，响应既更快又更稳。**代价**：高频增益放大 $1/\alpha=4$ 倍，测量噪声和高频未建模动态被放大；所以超前校正的 $\alpha$ 不宜取得太小（通常 $\alpha\ge0.1$，单级超前最多提供约 $55^\circ$）。

> **提示**：灵敏度峰值与相位裕度的下界关系：$\mathrm{PM}\ge2\arcsin\dfrac1{2M_s}$。$M_s=1.42$ 对应 $\mathrm{PM}\ge41.3^\circ$（实际 $49.7^\circ$）。这条不等式说明：**限制 $M_s$ 是比单独限制 PM 更严格的鲁棒性指标。**

## 8. 滞后校正、PI 与 PID 的频域含义

### 8.1 滞后校正

$$C_{\text{lag}}(s)=\frac{1+Ts}{1+\beta Ts},\quad\beta>1.$$

它把低频增益提高 $\beta$ 倍（直流增益为 1，高频为 $1/\beta$；通常配合整体增益使高频不变），用来**提高 $K_p$、$K_v$ 以减小稳态误差**，同时把零极点放在远低于穿越频率的位置，使其在 $\omega_c$ 处引入的相位滞后很小（几度）。

### 8.2 PI 就是特殊的滞后

$C_{PI}=K_p\Big(1+\dfrac1{T_is}\Big)=K_p\dfrac{T_is+1}{T_is}$：把 $\beta\to\infty$ 的极点放到原点。在穿越频率处引入的相位滞后为 $-\arctan\dfrac1{\omega_cT_i}$。若 $T_i=10/\omega_c$，滞后 $5.7^\circ$；$T_i=5/\omega_c$，$11.3^\circ$；$T_i=3/\omega_c$，$18.4^\circ$（Python 复核）。

**经验**：积分时间常数取 $T_i\ge(3\sim10)/\omega_c$，使其只在低频起作用，对相位裕度影响可控。

### 8.3 PD 就是特殊的超前

$C_{PD}=K_p(1+T_ds)$，加上高频滤波后就是超前。**PID = 滞后（PI 部分）+ 超前（PD 部分）**：低频区靠积分提高增益，穿越频率附近靠微分抬相位，高频靠滤波压噪声。这解释了 PID 的三个参数在伯德图上各自的"位置"，也是 Ziegler–Nichols 之外的一条更有原则的整定路径（见 [PID 控制全解](./02_PID控制全解.md)）。

### 8.4 手算：用滞后校正把速度误差常数提高 10 倍

对象 $G(s)=\dfrac1{s(s+1)}$，不加校正时 $\omega_c=0.786$ rad/s，$\mathrm{PM}=51.8^\circ$，但速度误差常数只有 $K_v=\lim_{s\to0}sG=1$，斜坡输入下的稳态误差 $1/K_v=1$ 个单位，太大。如果只是把增益乘 10，穿越频率会跳到 $3.08$ rad/s，相位裕度变成 $18^\circ$（又回到第 6 节的老问题）。改用滞后校正

$$C_{\text{lag}}(s)=\beta\,\frac{1+Ts}{1+\beta Ts},\quad\beta=10,\ \frac1T=0.08\ \text{rad/s},$$

直流增益 $\beta=10$（于是 $K_v=10$），高频增益为 1（不改变原来的穿越频率附近的幅值），零点放在 $0.08$ rad/s，约为 $\omega_c$ 的十分之一。Python 验证：新的穿越频率 $0.789$ rad/s，**$\mathrm{PM}=46.5^\circ$**，只比原来的 $51.8^\circ$ 少了约 $5^\circ$。结论：滞后校正用很小的相位代价换来了 10 倍的低频增益；**代价是响应里出现一个慢的"尾巴"**——零极点附近的慢模态使得调整时间变长，因为低频段需要一个时间常数 $\beta T=125$ s 量级的瞬态才能完全消失。如果任务要求既要快速到位又要无静差，往往需要 PID 里的积分加上前馈，而不是单靠滞后。

## 9. 延迟、内外环带宽比与相位裕度

### 9.1 延迟

纯延迟 $T_d$ 的频率响应 $e^{-j\omega T_d}$，幅值为 1，相位 $-\omega T_d$。在穿越频率处吃掉的相位裕度：

$$\Delta\mathrm{PM}=\omega_cT_d\cdot\frac{180^\circ}{\pi}.$$

**手算**：上例未校正系统 $\omega_c=3.08$，延迟 20 ms：$3.08\times0.02\times57.3=3.5^\circ$，影响很小；校正后 $\omega_c=4.42$：$5.1^\circ$。但若回路更快，如 $\omega_c=10$ rad/s，同样 20 ms 延迟吃掉 $11.5^\circ$。**穿越频率越高，延迟越致命**；设计指标时要给延迟预留相位。

### 9.2 外环/内环带宽比

级联控制（如 P1 的位置外环—姿态内环、P3 的角度—角速度环）中，外环看到的"被控对象"包含内环的闭环动态，近似一阶滞后 $\dfrac1{s/\omega_i+1}$。在外环穿越频率 $\omega_c$ 处，内环引入的相位滞后为 $\arctan(\omega_c/\omega_i)$：

| 内环/外环带宽比 | 内环引入的相位滞后（外环穿越处） |
|---|---|
| 3 倍 | $18.4^\circ$ |
| 5 倍 | $11.3^\circ$ |
| 10 倍 | $5.7^\circ$ |

这就是"内环比外环快 3–10 倍"的数学根据（第 01 章也提到）。3 倍时已经吃掉近 $18^\circ$，如果外环本身只有 $45^\circ$ 的裕度，就只剩下 $27^\circ$。工程中常取 5 倍以上。

## 10. 灵敏度函数与鲁棒性

### 10.1 定义与关系

$S=\dfrac1{1+L}$ 描述扰动/参考误差的传递，$T=\dfrac L{1+L}$ 描述参考和测量噪声的传递，$S+T=1$，所以二者不可能同时处处很小。低频希望 $\lvert S\rvert$ 小（抑制扰动），高频希望 $\lvert T\rvert$ 小（抑制噪声、对乘性不确定性鲁棒），穿越频率附近必须折中，$M_s$ 一般取 $1.2$–$2$。

### 10.2 对模型误差的鲁棒性

如果实际对象相对于名义对象有乘性误差 $\Delta(j\omega)$（$G_{\text{true}}=G(1+\Delta)$），小增益定理给出闭环稳定的充分条件 $\lvert T(j\omega)\Delta(j\omega)\rvert<1$。因此在不确定性大的高频区域，必须让 $\lvert T\rvert$ 足够小——这再次说明：穿越频率不能太高。关于鲁棒控制的更完整讨论见 [鲁棒与自适应控制](./10_鲁棒与自适应控制.md)。

## 11. 数字实现与离散化

- 校正器 $C(s)$ 设计好之后，用 Tustin（双线性）变换离散化，预畸变到关键频率（如超前的零极点或陷波点），见 [数值方法与离散化](../01_数学基础/05_数值方法与离散化.md)；
- 采样 + 零阶保持近似引入半个采样周期的延迟 $T_s/2$：$T_s=1$ ms 时在 $\omega_c=100$ rad/s 吃掉 $2.9^\circ$。经验：采样频率取穿越频率的 20 倍以上；
- 超前的微分作用对量化噪声敏感，应实现为带极点的形式（上面的 $\alpha$ 极点），而不是理想微分；
- 实现后务必在**离散闭环**上重新检查裕度，而不是只信连续设计（见 [数字控制与实时性](./08_数字控制与实时性.md)）。

## 12. 在本项目里怎么用

> 说明：CV 的控制叙述是级联 PID、增益调度 LQR、前馈、滑模与 MPC，没有写"用根轨迹/伯德图设计"。以下是这些回路在频域下的解读，用来回答"为什么这样调、怎么判断裕度"这类追问。

- **P1 / P3 / P7 级联**：位置外环—姿态内环、角度—角速度环的"内环比外环快数倍"准则，来自 §9.2 的相位滞后表；调试时若外环出现低频振荡，常见原因是内环带宽不够，或延迟吃掉了外环裕度（见 [PID 控制全解](./02_PID控制全解.md)、[数字控制与实时性](./08_数字控制与实时性.md)）。
- **P1 / P7 LQR**：LQR 设计的是状态反馈，其回路在输入端理论上有大裕度；实机加上滤波、延迟、力矩饱和后，可以通过"逐步缩放增益直到振荡"的实验估计增益裕度，这相当于现场测 GM（见 [P7 LQR 原理与增益调度](../../01_项目课程/P7_可变腿长轮腿机器人/05_LQR原理与增益调度.md) 里的稳定性与鲁棒性深挖一节）。
- **P3 云台与发射机构**：速度环的带宽要远低于传动共振（见 [柔性关节、弹性驱动、摩擦与接触建模](../02_力学与动力学建模/07_柔性关节_弹性驱动_摩擦_接触建模.md)），否则要加陷波；从 PID 到变增益 PID 再到滑模的演进，也可以看成"线性频域设计在大范围工况下失效"后的非线性补救（见 [从 PID 到变增益 PID 再到滑模控制](../../01_项目课程/P3_RoboMaster英雄机器人嵌入式控制/08_从PID到变增益PID再到滑模控制.md)）。
- **P2 轮速 PID**：编码器测速的滤波器相位滞后与 PID 积分项一起决定了轮速环的相位裕度（见 [差速底盘运动学、轮速 PID 与里程计](../../01_项目课程/P2_未来动力双臂遥操作与差速底盘/08_差速底盘运动学_轮速PID与里程计.md)）。

## 13. 常见错误与故障现象

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 阶跃响应振荡剧烈 | 相位裕度太小 | 加超前/微分，降低增益，减少延迟 |
| 低频误差大，但响应已很快 | 低频增益不足 | 加滞后/积分，保持 $T_i\ge(3\sim10)/\omega_c$ |
| 加了微分后噪声很大 | 高频增益 $1/\alpha$ 放大了噪声 | 加高频极点，限制 $\alpha\ge0.1$，滤波 |
| 仿真稳定，实机振荡 | 延迟、采样、未建模共振吃了裕度 | 测实际延迟，加到模型；加陷波；降 $\omega_c$ |
| 根轨迹设计的增益上机后饱和 | 忽略执行器限幅 | 校核控制量，加抗积分饱和 |
| 内环调好后整体变差 | 外环/内环带宽比不足 | 提高内环带宽或降低外环 |
| 只看增益裕度判断稳定 | 二阶系统 GM 无穷但 PM 小 | PM、GM、$M_s$ 同时看 |
| 离散化后性能劣化 | 没做预畸变，或采样太慢 | Tustin + 预畸变，采样频率 $\ge20\omega_c$ |

## 14. 面试怎么问、怎么答

**Q1. What do gain margin and phase margin tell you?**

> They measure how far the loop is from the critical point minus one on the Nyquist plot. Phase margin is how much extra phase lag at the gain crossover frequency the loop can tolerate before it becomes unstable; gain margin is how much the loop gain can increase at the phase crossover frequency. I aim for about 45 to 60 degrees of phase margin and at least 6 dB of gain margin, and I also look at the peak of the sensitivity function, because margins alone can hide a near miss elsewhere on the curve.

中文：二者衡量回路离奈奎斯特图上 −1 点的距离；PM 是穿越频率处还能再容忍的相位滞后，GM 是相位穿越频率处增益还能放大几倍；目标 PM 约 45–60°、GM ≥ 6 dB，并看灵敏度峰值，因为单独的裕度可能漏掉曲线其他位置的接近。

**Q2. Walk me through designing a lead compensator.**

> I find the phase margin I need and the margin I have, add a few degrees for the crossover shift, and that gives the maximum phase lead. From it I compute alpha, equal to one minus sine over one plus sine. The compensator has gain one over root alpha at its centre frequency, so I place that frequency where the plant gain equals root alpha; this becomes the new crossover. Then T is one over the centre frequency times root alpha. In my example the phase margin went from 18 to about 50 degrees and the overshoot from 60 to 22 percent, at the price of four times higher high-frequency gain.

中文：由所需 PM 与现有 PM 之差加余量得最大超前角；$\alpha=(1-\sin\varphi)/(1+\sin\varphi)$；校正器中心频率增益 $1/\sqrt\alpha$，把中心频率放在对象增益等于 $\sqrt\alpha$ 处作为新穿越频率；$T=1/(\omega_m\sqrt\alpha)$；示例 PM 18°→约 50°，超调 60%→22%，代价是高频增益放大 4 倍。

**Q3. How does a delay affect stability?**

> A pure delay has unit magnitude and phase minus omega times the delay, so it removes phase margin at the crossover frequency without changing the gain. The loss is omega-c times the delay in radians. For example 20 milliseconds at 10 radians per second costs about 11 degrees. That is why faster loops are more sensitive to latency, and why I keep the crossover well below the frequencies where delays and unmodelled dynamics matter.

中文：纯延迟幅值为 1、相位 $-\omega T_d$，只吃相位裕度；损失 $\omega_cT_d$ 弧度，例如 10 rad/s、20 ms 吃约 11°；回路越快越怕延迟，所以穿越频率要远低于延迟和未建模动态起作用的频率。

**Q4. Root locus versus Bode: when do you use which?**

> The root locus is good when the model is a rational transfer function and I want to see how poles move with gain, for example where the system becomes unstable or how a zero shifts the poles. Bode and Nyquist work directly with measured frequency responses, handle delays and resonances naturally, and give margins. In practice I use Bode for design and verification with data, and root locus for intuition.

中文：根轨迹适合有理传递函数、观察极点随增益的移动；Bode/Nyquist 直接用实测频响，自然处理延迟与共振，给出裕度；实际用 Bode 设计与验证，用根轨迹建立直觉。

**Q5. Why should the inner loop be faster than the outer loop?**

> The outer loop sees the inner loop as part of its plant. If the inner loop bandwidth is only three times the outer crossover, it adds about 18 degrees of phase lag there; at ten times it is under 6 degrees. A faster inner loop makes the simple model, where the inner loop is a gain of one, valid and protects the outer loop's phase margin.

中文：外环把内环当作被控对象的一部分；内环带宽仅为外环穿越频率 3 倍时引入约 18° 滞后，10 倍时不到 6°；内环足够快才能把它近似为 1，保住外环相位裕度。

## 15. 本章要点速记

1. 根轨迹：渐近线夹角 $(2k+1)180^\circ/(n-m)$，质心 $(\sum p-\sum z)/(n-m)$；分离点解 $dK/ds=0$；虚轴交点用劳斯。
2. $K/(s(s+1)(s+2))$：分离点 $-0.4226$，临界 $K=6$，$\omega=\sqrt2$。
3. 奈奎斯特：$Z=N+P$；GM $=1/\lvert L(j\omega_{180})\rvert$，PM $=180^\circ+\angle L(j\omega_c)$。
4. $\zeta\approx\mathrm{PM}/100$；目标 PM 45–60°，GM $\ge6$ dB，$M_s$ 取 1.2–2。
5. $L=10/(s(s+1))$：PM $18^\circ$，$M_s=3.35$，超调 60%。
6. 超前：$\varphi_m=\arcsin\frac{1-\alpha}{1+\alpha}$，$\omega_m=1/(T\sqrt\alpha)$，中心增益 $1/\sqrt\alpha$；示例 $\alpha=0.2486$，$T=0.4535$ s，PM 49.7°。
7. 超前的代价：高频增益 $1/\alpha$，放大噪声；单级超前通常不超过约 55°。
8. PI = 极低零点的滞后，$T_i\ge(3\sim10)/\omega_c$ 使相位损失 $\le18^\circ$。
9. 延迟吃相位：$\Delta\mathrm{PM}=\omega_cT_d$（弧度）；采样 + 零阶保持约 $T_s/2$ 延迟。
10. 内环带宽为外环的 3/5/10 倍时，外环穿越处滞后 $18.4^\circ/11.3^\circ/5.7^\circ$。

## 16. 自测题

1. $\varphi_m=55^\circ$ 的单级超前，$\alpha$ 是多少？（$\alpha=(1-0.819)/(1+0.819)=0.0994$，约 0.1。）
2. $L(s)=K/(s(s+1)(s+2))$ 在 $K=4$ 时增益裕度？（$6/4=1.5$，约 $3.5$ dB。）
3. 穿越频率 20 rad/s，延迟 5 ms，吃掉多少相位？（$20\times0.005\times57.3=5.7^\circ$。）
4. 外环穿越 2 rad/s，内环带宽 10 rad/s，内环引入的滞后？（$\arctan(0.2)=11.3^\circ$。）
5. 为什么 PI 的 $T_i$ 不能取得太小？（积分在 $\omega_c$ 处引入 $-\arctan\frac1{\omega_cT_i}$ 的滞后，太小会吃相位裕度。）
6. $S+T=1$ 的工程含义？（低频要 $S$ 小（扰动抑制），高频要 $T$ 小（噪声与鲁棒），穿越频率附近必须折中。）
