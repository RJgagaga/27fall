# 控制理论：学习顺序与前置关系

> **一句话定位**：让系统按要求运动：反馈、PID、状态空间、LQR、MPC、滑模、前馈与饱和、数字实现，以及非线性、鲁棒与自适应控制。

**本模块学完你能：**

- 分析一二阶系统响应并整定 PID；
- 建立状态空间模型并判断可控可观；
- 设计 LQR 与 MPC；
- 处理饱和、延迟与数字实现；
- 用 Lyapunov 论证稳定性，理解鲁棒与自适应方法。

**前置知识**：[微积分与常微分方程](../01_数学基础/02_微积分与常微分方程.md)、[倒立摆建模与线性化](../02_力学与动力学建模/03_倒立摆建模与线性化.md)、[信号与系统基础](../04_信号与系统/01_信号与系统基础_卷积_傅里叶_拉普拉斯_Z变换.md)。

## 阅读顺序建议

反馈基础 → PID → 状态空间 → LQR → 前馈/饱和 → MPC → 滑模 → 数字控制 → Lyapunov → 鲁棒/自适应；频域设计（11）可在 PID 之后插入学习；力控与阻抗（12）在动力学进阶之后读；最优控制与轨迹优化（13）接在 LQR/MPC 之后；系统辨识与参数整定（14）可与 PID 整定并行阅读。
