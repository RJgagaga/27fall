# 状态估计：学习顺序与前置关系

> **一句话定位**：带噪传感器怎样得到可信状态：传感器模型、互补滤波、卡尔曼与 EKF、里程计融合、粒子滤波与时间/坐标一致性。

**本模块学完你能：**

- 说出 IMU、编码器、激光雷达的误差来源；
- 手算互补滤波、一维与二维卡尔曼；
- 推导 EKF 并调 Q/R；
- 解释 AMCL 与 map→odom→base_link 的分工；
- 处理时间同步与数据有效性。

**前置知识**：[概率统计与高斯分布](../01_数学基础/03_概率统计与高斯分布.md)、[坐标系与齐次变换](../03_运动学与坐标变换/01_坐标系_旋转矩阵_齐次变换.md)、[数字滤波器](../04_信号与系统/02_数字滤波器_FIR_IIR_采样与混叠.md)。

P5 的 EKF/AMCL/时间同步，P1/P3/P7 的姿态估计，P6 的状态一致性。

## 阅读顺序建议

传感器 → 互补滤波 → 卡尔曼/EKF → 里程计融合 → 粒子滤波 → 时间同步；SLAM 模块在读完 EKF 与粒子滤波后阅读。进阶部分：UKF 与平滑（07）接在 EKF 之后；ESKF（09）依赖李群章；IMU 预积分与因子图（08）依赖 07 的信息形式和李群章；一致性与可观性（10）最后读，用来检验前面所有滤波器。
