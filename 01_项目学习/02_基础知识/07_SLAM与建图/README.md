# SLAM 与建图：学习顺序与前置关系

> **一句话定位**：未知环境里一边建图一边定位：问题形式、前后端、位姿图优化、视觉里程计与（后续）激光/视惯融合。

**本模块学完你能：**

- 写出 SLAM 的概率形式并区分滤波与图优化；
- 手算一维位姿图与 SE(2) 残差；
- 推导对极约束、三角化、PnP、BA 的目标；
- 解释回环、鲁棒核与评估指标 ATE/RPE。

**前置知识**：[卡尔曼滤波与EKF](../06_状态估计/03_卡尔曼滤波与EKF.md)、[粒子滤波与AMCL](../06_状态估计/05_粒子滤波与AMCL.md)、[最优化与二次规划](../01_数学基础/04_最优化与二次规划.md)、[相机模型与标定](../09_感知与视觉/01_相机模型与标定.md)。
