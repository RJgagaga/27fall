## 1. 从感知机到多层感知机

### 1.1 它要解决什么问题

线性模型只能画一条直线分类。现实问题（比如"这块像素区域是不是病斑"）需要非常弯曲的边界。神经网络通过**把很多简单的"线性+非线性"单元堆叠起来**，获得任意复杂的函数表达能力。

### 1.2 感知机

单个神经元：$\hat y=\mathrm{sign}(w^\top x+b)$，其中 $x\in\mathbb R^d$ 输入，$w$ 权重，$b$ 偏置。学习规则：若样本被分错（$y(w^\top x+b)\le0$，$y\in\{\pm1\}$），则

$$w\leftarrow w+\eta\,y\,x,\qquad b\leftarrow b+\eta\,y$$

直觉：把权重向"这个样本应有的方向"推一下。手算一步（教学示例）：$w=(0,0),b=0,\eta=1$，样本 $x=(1,1),y=+1$。$y(w^\top x+b)=0\le0$，更新得 $w=(1,1),b=1$。**感知机收敛定理**：数据线性可分时，有限步内一定收敛。

### 1.3 XOR 问题

XOR 的四个点 $(0,0)\to0,(0,1)\to1,(1,0)\to1,(1,1)\to0$ 不能被任何一条直线分开。单层感知机无能为力（Minsky 与 Papert 1969 年指出）。

加一个隐藏层就可以。手工构造（教学示例）：用阶跃函数 $\mathrm{step}(z)=1$ 当 $z>0$。

- $h_1=\mathrm{step}(x_1+x_2-0.5)$（OR）
- $h_2=\mathrm{step}(x_1+x_2-1.5)$（AND）
- $y=\mathrm{step}(h_1-h_2-0.5)$（"OR 且非 AND"）

验算：$(0,0)$：$h_1=0,h_2=0,y=\mathrm{step}(-0.5)=0$ ✓；$(0,1)$：$h_1=1,h_2=0,y=\mathrm{step}(0.5)=1$ ✓；$(1,1)$：$h_1=1,h_2=1,y=\mathrm{step}(-0.5)=0$ ✓。隐藏层把空间"折"成线性可分的形状——这就是深度学习的本质：**逐层变换表示**。

### 1.4 多层感知机（MLP）

$L$ 层网络：$a^0=x$，对 $l=1..L$：

$$z^l=W^la^{l-1}+b^l,\qquad a^l=\sigma(z^l)$$

输出 $\hat y=a^L$（最后一层的激活函数依任务而定）。$W^l\in\mathbb R^{n_l\times n_{l-1}}$ 是权重矩阵，$b^l\in\mathbb R^{n_l}$ 是偏置。参数个数例：784-256-10 的网络，参数 $=784\times256+256+256\times10+10=203{,}530$。

**通用近似定理**（Universal Approximation Theorem）：只要隐藏层足够宽，一个带非线性激活的单隐层网络可以任意精度逼近紧集上的连续函数。注意：这是存在性结论，不保证"能学到"或"需要的宽度合理"；实践中深度比宽度更高效。

### 1.5 为什么必须有非线性激活

若 $\sigma$ 是恒等映射，两层网络：$\hat y=W^2(W^1x+b^1)+b^2=(W^2W^1)x+(W^2b^1+b^2)$，仍是**一个线性映射**。任意深度的线性层堆叠 = 一层。非线性激活才让深度有意义。

## 2. 激活函数

### 2.1 总表

| 名称 | 公式 | 导数 | 优点 | 缺点 / 用途 |
|---|---|---|---|---|
| sigmoid | $\frac1{1+e^{-z}}$ | $\sigma(1-\sigma)\le0.25$ | 输出 $(0,1)$，像概率 | 饱和→梯度消失；非零中心；用在二分类输出、门控 |
| tanh | $\frac{e^z-e^{-z}}{e^z+e^{-z}}$ | $1-\tanh^2\le1$ | 零中心 | 仍会饱和；RNN 中常用 |
| ReLU | $\max(0,z)$ | $z>0$ 时 1，否则 0 | 计算便宜，不饱和（正半轴） | "死神经元"：永远负输入则梯度恒零 |
| Leaky ReLU | $\max(\alpha z,z)$，$\alpha=0.01$ | $1$ 或 $\alpha$ | 缓解死神经元 | YOLOv5 中使用 LeakyReLU/SiLU 一类 |
| SiLU/Swish | $z\,\sigma(z)$ | 光滑 | 效果好 | 现代 YOLOv5 默认激活 |
| GELU | $z\,\Phi(z)$ | 光滑 | Transformer 常用 | 计算稍重 |
| softmax | $\frac{e^{z_k}}{\sum_je^{z_j}}$ | 见第 6 节 | 多分类概率 | 输出层 |

### 2.2 关键性质与手算

- sigmoid 导数最大值在 $z=0$：$0.5\times0.5=0.25$。$z=4$ 时 $\sigma=0.982$，导数 $=0.982\times0.018=0.0177$，已经极小。
- ReLU：$z=-3\to0$，导数 0；$z=2\to2$，导数 1。
- 为什么 ReLU 让深层网络好训：正半轴导数恒为 1，梯度经过多层不被连乘缩小。

**"死 ReLU"手算**：一个神经元 $z=w\cdot x+b$，若权重更新后 $b=-5$ 而输入分量都在 $0..1$ 范围，则 $z$ 对几乎所有样本为负，输出 0，导数 0——梯度传不到它的权重，它再也不会被更新。Leaky ReLU 在负半轴保留斜率 0.01，梯度不会完全为零。

**tanh 与 sigmoid 的关系**：$\tanh(z)=2\sigma(2z)-1$，即把 sigmoid 平移缩放到 $(-1,1)$ 并零中心化。零中心的好处：下一层的输入有正有负，权重梯度不会全是同一符号（sigmoid 输出恒正，会让同一神经元所有入边权重的梯度同号，更新呈"之"字形）。

**选择指南**：隐藏层默认 ReLU 系（ReLU / LeakyReLU / SiLU）；二分类输出层 sigmoid；多分类输出层 softmax；回归输出层线性；需要 $(-1,1)$ 的有界输出（如归一化的动作）用 tanh。

> **提示**：YOLOv5 的实现里激活函数随版本变化（早期 LeakyReLU，后来 SiLU）；面试讲"原理"，具体版本以你用的权重和代码为准。

## 3. 前向传播

### 3.1 矩阵形式与批量

一个 batch 有 $B$ 个样本时，把样本按列（或按行）堆成矩阵，一次矩阵乘法并行完成。形状检查是调试第一习惯：

```text
输入 X:   (B, n0)
W1:       (n0, n1)    b1: (n1,)    Z1 = X @ W1 + b1  -> (B, n1)
A1 = act(Z1)                                          -> (B, n1)
W2:       (n1, n2)    b2: (n2,)    Z2 = A1 @ W2 + b2 -> (B, n2)
```

### 3.2 前向要保存什么

反向传播要用到每一层的 $z^l$（或 $a^l$），所以前向时要缓存它们。这也是训练时显存占用远大于推理的原因：推理可以边算边丢，训练必须保存全部中间激活。

### 3.3 参数量与显存的估算（教学示例）

以 784-256-128-10 的 MLP 为例：

| 层 | 权重 | 偏置 | 参数合计 |
|---|---|---|---|
| 784→256 | 200,704 | 256 | 200,960 |
| 256→128 | 32,768 | 128 | 32,896 |
| 128→10 | 1,280 | 10 | 1,290 |
| 合计 | | | **235,146** |

FP32 每参数 4 字节，权重约 0.94 MB。训练时 Adam 还要存一阶矩、二阶矩各一份，加上梯度，参数相关显存约为权重的 4 倍（$\approx3.8$ MB）；另外要保存 batch 内每层激活：batch=64 时激活数 $64\times(256+128+10)\approx25{,}216$ 个，约 0.1 MB——对 MLP 很小，但对卷积网络，特征图很大，**激活显存往往远大于权重显存**，这就是训练大图像模型时 batch size 受限的原因。

### 3.4 深度与宽度

通用近似定理说明足够宽的单隐层就能逼近任意连续函数，但实践中**加深比加宽更省参数**：深层网络可以逐层复用并组合低层特征（边缘→纹理→部件→物体），同样的表达能力用的神经元数量可以呈指数级减少（对某些函数族有理论结论）。代价是更难训练（梯度消失/爆炸），所以才需要 ReLU、归一化、残差等技巧（第 10 节）。

## 4. 反向传播：推导

### 4.1 它要解决什么问题

要用梯度下降，需要损失 $L$ 对**每一个参数**的偏导。网络有几百万参数，不能一个个数值差分（太慢）。反向传播用链式法则，**一次反向扫描**算出所有参数的梯度，代价和一次前向同量级。

### 4.2 符号

- $z^l, a^l$：第 $l$ 层的线性输出、激活输出；$a^0=x$。
- 误差信号（delta）$\delta^l\equiv\dfrac{\partial L}{\partial z^l}$（与 $z^l$ 同形状的向量）。
- $\odot$：逐元素相乘；$\sigma'(z)$ 逐元素求导。

### 4.3 推导

**第一步：输出层的 delta。** 对输出层 $L$，$\delta^L=\dfrac{\partial L}{\partial a^L}\odot\sigma'(z^L)$。若是 softmax+交叉熵或 sigmoid+BCE，这一步化简为 $\hat y-y$（第 6 节）。

**第二步：把 delta 向后传。** $z^{l+1}=W^{l+1}a^l+b^{l+1}$，$a^l=\sigma(z^l)$。对第 $l$ 层第 $j$ 个神经元，影响损失的路径是它的 $a_j^l$ 流入下一层所有 $z_k^{l+1}$：

$$\delta_j^l=\frac{\partial L}{\partial z_j^l}=\sum_k\frac{\partial L}{\partial z_k^{l+1}}\frac{\partial z_k^{l+1}}{\partial a_j^l}\frac{\partial a_j^l}{\partial z_j^l}=\Big(\sum_kW_{kj}^{l+1}\delta_k^{l+1}\Big)\sigma'(z_j^l)$$

写成向量：

$$\boxed{\delta^l=\big((W^{l+1})^\top\delta^{l+1}\big)\odot\sigma'(z^l)}$$

直觉：下一层的误差通过权重"转置回来"，再乘本层激活函数的斜率（斜率为零的地方，误差传不过去）。

**第三步：参数梯度。** $z^l=W^la^{l-1}+b^l$，所以

$$\frac{\partial L}{\partial W^l}=\delta^l\,(a^{l-1})^\top,\qquad \frac{\partial L}{\partial b^l}=\delta^l$$

（$W_{ji}$ 的梯度 $=\delta_j\cdot a_i$：谁的输入大、谁的误差大，谁的权重改得多。）批量时对 batch 求平均（或求和）。

**算法总结**

```text
前向：  a0 = x；对 l=1..L：z_l = W_l a_{l-1} + b_l；a_l = act(z_l)（缓存 z_l, a_l）
反向：  delta_L = dL/dz_L
        for l = L down to 1:
            dW_l = delta_l a_{l-1}^T ;  db_l = delta_l
            if l > 1: delta_{l-1} = (W_l^T delta_l) * act'(z_{l-1})
更新：  W_l -= lr * dW_l ; b_l -= lr * db_l
```

> **面试要点**：反向传播不是一种新算法，是**自动微分的反向模式**，本质是动态规划——每一层的 delta 只算一次并被所有更靠前的层复用。

## 5. 反向传播：2 层网络完整手算

### 5.1 网络与数据（教学示例数值）

结构：2 个输入 → 2 个 sigmoid 隐藏单元 → 1 个线性输出。损失 $L=\tfrac12(y-t)^2$。

- 输入 $x=(1,\ 2)^\top$，目标 $t=1$
- $W^1=\begin{bmatrix}0.1&0.2\\0.3&0.4\end{bmatrix}$，$b^1=(0,0)^\top$
- $W^2=(0.5,\ 0.6)$，$b^2=0$

### 5.2 前向

隐藏层线性输出：
$$z^1=W^1x=\begin{bmatrix}0.1\times1+0.2\times2\\0.3\times1+0.4\times2\end{bmatrix}=\begin{bmatrix}0.5\\1.1\end{bmatrix}$$

隐藏激活（sigmoid）：
- $h_1=\sigma(0.5)=1/(1+e^{-0.5})=1/(1+0.60653)=0.62246$
- $h_2=\sigma(1.1)=1/(1+e^{-1.1})=1/(1+0.33287)=0.75026$

输出：$y=0.5\times0.62246+0.6\times0.75026=0.31123+0.45016=0.76139$

损失：$L=\tfrac12(0.76139-1)^2=\tfrac12\times0.056936=0.02847$

### 5.3 反向

**输出层**（线性输出，MSE）：$\delta^2=\partial L/\partial y=y-t=-0.23861$。

**第 2 层参数梯度**：
- $\partial L/\partial W^2=\delta^2\,h^\top=(-0.23861\times0.62246,\ -0.23861\times0.75026)=(-0.14853,\ -0.17902)$
- $\partial L/\partial b^2=-0.23861$

**传回隐藏层**：
- $\partial L/\partial h=(W^2)^\top\delta^2=(0.5\times(-0.23861),\ 0.6\times(-0.23861))=(-0.11931,\ -0.14317)$
- sigmoid 斜率：$h_1(1-h_1)=0.62246\times0.37754=0.23500$；$h_2(1-h_2)=0.75026\times0.24974=0.18737$
- $\delta^1=\partial L/\partial z^1=(-0.11931\times0.23500,\ -0.14317\times0.18737)=(-0.02804,\ -0.02683)$

**第 1 层参数梯度**（$\delta^1\,x^\top$）：
$$\frac{\partial L}{\partial W^1}=\begin{bmatrix}-0.02804\times1&-0.02804\times2\\-0.02683\times1&-0.02683\times2\end{bmatrix}=\begin{bmatrix}-0.02804&-0.05608\\-0.02683&-0.05365\end{bmatrix},\quad\frac{\partial L}{\partial b^1}=(-0.02804,\ -0.02683)$$

### 5.4 数值梯度验证（gradient check）

给 $W^1_{11}$ 加一个很小的 $\epsilon=10^{-6}$ 重新算前向，损失变化 $\Delta L/\epsilon=-0.028038$，与解析梯度 $-0.02804$ 吻合。**写反向传播代码后一定要做梯度检验**，这是定位实现错误的最快办法。

### 5.5 一次参数更新（学习率 $\eta=0.5$）

$W^2\leftarrow(0.5+0.5\times0.14853,\ 0.6+0.5\times0.17902)=(0.57426,\ 0.68951)$
$W^1\leftarrow\begin{bmatrix}0.1+0.01402&0.2+0.02804\\0.3+0.01341&0.4+0.02683\end{bmatrix}=\begin{bmatrix}0.11402&0.22804\\0.31341&0.42683\end{bmatrix}$
$b^1\leftarrow(0.01402,\ 0.01341)$，$b^2\leftarrow0.5\times0.23861=0.11931$

新前向：$y\approx1.0155$，$L\approx0.00012$，损失从 $0.0285$ 降到 $0.0001$。预测从 0.761 冲到 1.015，略微越过目标，这是学习率较大的表现；换成 $\eta=0.1$ 会更平稳。

### 5.6 这个例子的教训

- 梯度逐层变小：$\delta^2=-0.239\to\delta^1\approx-0.028$，缩小了约一个数量级，因为乘了 $W^2$（0.5–0.6）和 sigmoid 斜率（≤0.25）。层数多时这就是梯度消失（第 10 节）。
- 靠近输入的权重梯度含 $x$ 的值：输入大的维度，对应权重改得多。所以输入要标准化。

### 5.6b 同一个网络换成 ReLU：完整再算一遍

把隐藏激活换成 ReLU，其余不变（$x=(1,2)$，$t=1$，$W^1,W^2$ 取 5.1 节的数值）。ReLU 是分段线性，手算反而更干净，也是检验自己是否真的会算的好练习。

- **前向**：$z^1=(0.5,\ 1.1)$ 均为正，$h=\mathrm{ReLU}(z^1)=(0.5,\ 1.1)$；$y=0.5\times0.5+0.6\times1.1=0.25+0.66=0.91$；$L=\tfrac12(0.91-1)^2=0.00405$。
- **反向**：$\delta^2=y-t=-0.09$；$\partial L/\partial W^2=\delta^2h^\top=(-0.045,\ -0.099)$；$\partial L/\partial h=W^{2\top}\delta^2=(-0.045,\ -0.054)$；ReLU 导数在 $z>0$ 处为 1，所以 $\delta^1=(-0.045,\ -0.054)$；$\partial L/\partial W^1=\delta^1x^\top=\begin{bmatrix}-0.045&-0.09\\-0.054&-0.108\end{bmatrix}$。
- **更新**（$\eta=0.1$）：$W^2=(0.5045,\ 0.6099)$，$W^1=\begin{bmatrix}0.1045&0.209\\0.3054&0.4108\end{bmatrix}$，$b^1=(0.0045,\ 0.0054)$，$b^2=0.009$。
- **新前向**：$z^1=(0.527,\ 1.1324)$，$y=0.5045\times0.527+0.6099\times1.1324+0.009=0.9655$，$L=0.00059$，从 $0.00405$ 降了约 7 倍。

对比 sigmoid 版本：这里 $\delta^1$ 与 $\delta^2$ 同量级（$-0.045$ 对 $-0.09$，只乘了 $W^2$），没有再被激活函数斜率缩小——这正是 ReLU 缓解梯度消失的数值体现。**教训**：同一个 $\eta=0.5$ 用在这个 ReLU 网络上会冲过头（$y$ 会变成 1.196，损失反而变大到 0.019），学习率必须按网络调，不能照搬。

### 5.7 计算图与自动微分（框架里 `loss.backward()` 在做什么）

上面是手工推导。PyTorch 等框架把每个运算记录成**计算图**的一个节点，调用 `loss.backward()` 时沿图反向走一遍，对每个节点应用它自己的局部导数规则并相乘，这就是**自动微分的反向模式**。

最小手算（教学示例）：$f=(x+y)\cdot z$，$x=2,\ y=3,\ z=4$。

- 前向：$u=x+y=5$，$f=u\cdot z=20$。
- 反向（从 $\partial f/\partial f=1$ 开始）：
 - $\partial f/\partial u=z=4$，$\partial f/\partial z=u=5$；
 - $u=x+y$ 是加法，局部导数都是 1：$\partial f/\partial x=4\times1=4$，$\partial f/\partial y=4$。

规则小结：加法节点把上游梯度**原样分给**各输入；乘法节点把上游梯度乘以"**另一个输入的值**"；一个变量被多处使用时，梯度**相加**。

**为什么深度学习用反向模式而不是前向模式**：损失是一个标量，参数有上百万个。反向模式一次扫描得到损失对所有参数的梯度；前向模式每次只能得到对一个输入的导数，要扫上百万次。反过来，如果输出很多、输入很少（如某些机器人雅可比计算），前向模式更合算。

**实践含义**：(1) 反向传播需要保存前向的中间结果，所以训练显存远大于推理；(2) 框架默认把每次 `backward()` 的梯度**累加**到参数的梯度缓冲里（这对梯度累积很有用），所以每步训练前必须 `optimizer.zero_grad()`，否则会把上一步的梯度混进来；(3) 推理时用 `torch.no_grad()` 不建图，省显存。

## 6. softmax 与交叉熵的梯度

### 6.1 问题与符号

多分类 $K$ 类：最后一层输出 logits $z\in\mathbb R^K$，$p_k=\dfrac{e^{z_k}}{\sum_je^{z_j}}$，标签 one-hot $y$，损失 $L=-\sum_ky_k\log p_k=-\log p_c$（$c$ 为真类）。实现时用 $z-\max z$ 保证数值稳定。

### 6.2 推导

softmax 的雅可比：$\dfrac{\partial p_k}{\partial z_j}=p_k(\delta_{kj}-p_j)$。则

$$\frac{\partial L}{\partial z_j}=-\sum_ky_k\frac1{p_k}p_k(\delta_{kj}-p_j)=-\sum_ky_k(\delta_{kj}-p_j)=-(y_j-p_j\textstyle\sum_ky_k)=p_j-y_j$$

最终仍是"预测概率 − 真实标签"。

### 6.3 手算（教学示例数值）

$z=(2.0,\ 1.0,\ 0.1)$，真类为第 0 类。

- $e^z=(7.389,\ 2.718,\ 1.105)$，和 $=11.212$
- $p=(0.659,\ 0.242,\ 0.099)$
- $L=-\ln0.659=0.417$
- 梯度 $p-y=(0.659-1,\ 0.242,\ 0.099)=(-0.341,\ 0.242,\ 0.099)$

梯度各分量之和为 0（概率守恒）；真类被推高，其余被压低。

## 7. 优化器

### 7.1 要解决什么问题

有了梯度 $g=\nabla_\theta J$，怎么更新参数？朴素 SGD 的麻烦：(1) 学习率难选；(2) 山谷里来回震荡；(3) 不同参数的梯度尺度差很多。

### 7.2 SGD 与 mini-batch

$\theta\leftarrow\theta-\eta g$，$g$ 在一个 mini-batch（常用 32–256）上估计。batch 小：梯度噪声大但便宜、有一定正则效果；batch 大：梯度稳但每步贵、泛化可能略差。**学习率是最重要的超参数。**

### 7.3 Momentum

**问题**：在狭长山谷里，梯度在陡的方向来回摆、在平缓方向缓慢前进。
**做法**：累积速度，让"一直指向同一方向"的分量越走越快，抵消来回震荡的分量：

$$v\leftarrow\beta v+g,\qquad\theta\leftarrow\theta-\eta v\quad(\beta\approx0.9)$$

手算（教学示例）：连续梯度 $g=1,1,1,-1$，$\beta=0.9$：$v_1=1$；$v_2=0.9\times1+1=1.9$；$v_3=0.9\times1.9+1=2.71$；$v_4=0.9\times2.71-1=1.439$。方向稳定时速度快速累积到接近 $g/(1-\beta)=10$ 倍；遇到反向梯度只是减速，不是立刻掉头。这就是它平滑震荡的原因。

### 7.4 RMSProp 与 Adam

**RMSProp**：对每个参数维护梯度平方的滑动平均 $s\leftarrow\rho s+(1-\rho)g^2$，更新 $\theta\leftarrow\theta-\eta\,g/(\sqrt s+\epsilon)$。梯度大的维度步长被缩小，梯度小的被放大——自适应学习率。

**Adam** = Momentum（一阶矩）+ RMSProp（二阶矩）+ 偏差修正：

$$m\leftarrow\beta_1m+(1-\beta_1)g,\quad v\leftarrow\beta_2v+(1-\beta_2)g^2$$
$$\hat m=\frac m{1-\beta_1^t},\quad\hat v=\frac v{1-\beta_2^t},\quad\theta\leftarrow\theta-\eta\frac{\hat m}{\sqrt{\hat v}+\epsilon}$$

默认 $\beta_1=0.9,\beta_2=0.999,\epsilon=10^{-8}$。**为什么要偏差修正**：$m,v$ 初始为 0，早期估计被严重低估；除以 $1-\beta^t$ 补回来。

手算（教学示例）：一个参数，$\eta=0.001$，梯度序列 $g_1=0.5,\ g_2=0.3$。

- $t=1$：$m=0.1\times0.5=0.05$；$v=0.001\times0.25=0.00025$；$\hat m=0.05/(1-0.9)=0.5$；$\hat v=0.00025/(1-0.999)=0.25$；步长 $=0.001\times0.5/\sqrt{0.25}=0.001$。**第一步步长恰好是 $\eta$，与梯度大小无关**。
- $t=2$：$m=0.9\times0.05+0.1\times0.3=0.075$；$v=0.999\times0.00025+0.001\times0.09=0.00033975$；$\hat m=0.075/(1-0.81)=0.3947$；$\hat v=0.00033975/(1-0.998001)=0.16996$，$\sqrt{\hat v}=0.4123$；步长 $=0.001\times0.3947/0.4123=0.000957$。

### 7.5 实践选择

| 优化器 | 特点 | 典型场景 |
|---|---|---|
| SGD+Momentum | 泛化常更好，需要调学习率与调度 | 视觉检测（YOLO 系列训练常见） |
| Adam | 收敛快，对学习率不太敏感 | 小数据、Transformer、原型 |
| AdamW | 把权重衰减与 Adam 解耦 | Transformer/大模型主流 |

学习率调度：warmup（前几个 epoch 从小线性升）→ 余弦退火或阶梯衰减。Warmup 防止训练初期（统计量不稳、Adam 的 $v$ 不准）震荡。

### 7.6 mini-batch 梯度与学习率调度手算

**mini-batch 梯度**：一个 batch 有 $B$ 个样本时，梯度取平均 $g=\frac1B\sum_ig_i$。教学示例：4 个样本的某权重梯度为 $-0.3,\,-0.1,\,0.2,\,-0.4$，平均 $=-0.15$；若学习率 $0.1$，权重加 $0.015$。把损失定义成"和"还是"平均"，会让等效学习率差 $B$ 倍——换 batch size 时要同步调整学习率（常见经验：batch 乘 $k$，学习率约乘 $k$，并配合 warmup）。

**余弦退火**：$\eta_t=\eta_{min}+\frac12(\eta_{max}-\eta_{min})\big(1+\cos\frac{\pi t}{T}\big)$。取 $\eta_{max}=0.01,\eta_{min}=0,T=100$：$t=0$ 时 $0.01$；$t=50$ 时 $\cos(\pi/2)=0$，$\eta=0.005$；$t=100$ 时 $\cos\pi=-1$，$\eta=0$。前期大步探索，后期小步精修。

**Warmup**：前 $W$ 步线性升高 $\eta_t=\eta_{max}\cdot t/W$。如 $W=5$，第 1、2、5 步分别是 $0.2\eta_{max},0.4\eta_{max},\eta_{max}$。

**AdamW 与 L2 的区别**：在 Adam 里把 $\lambda\|w\|^2$ 加进损失，则惩罚项的梯度 $2\lambda w$ 也会被除以 $\sqrt{\hat v}$ 缩放，不同参数的衰减强度不一致；AdamW 把权重衰减**从梯度中拆出来**，更新为 $w\leftarrow w-\eta\big(\hat m/(\sqrt{\hat v}+\epsilon)+\lambda w\big)$，衰减与梯度尺度无关。这就是现代 Transformer 训练默认用 AdamW 的原因。

## 8. 批归一化（BatchNorm）

### 8.1 它要解决什么问题

深层网络中，前面层参数一变，后面层的输入分布就跟着变（内部协变量偏移的说法有争议，但经验上归一化确实让训练更稳）。BN 对每个通道的激活做标准化，允许更大学习率、减弱对初始化的依赖，并有轻微正则效果。

### 8.2 公式

对一个 mini-batch 中某通道的值 $x_1..x_m$：

$$\mu=\frac1m\sum x_i,\quad\sigma^2=\frac1m\sum(x_i-\mu)^2,\quad\hat x_i=\frac{x_i-\mu}{\sqrt{\sigma^2+\epsilon}},\quad y_i=\gamma\hat x_i+\beta$$

$\gamma,\beta$ 是可学习参数，让网络在需要时可以"撤销"归一化。

### 8.3 手算（教学示例数值）

batch 值 $[2,4,6,8]$：$\mu=5$，$\sigma^2=(9+1+1+9)/4=5$，$\sqrt{5+10^{-5}}\approx2.236$。
$\hat x=(-1.342,\ -0.447,\ 0.447,\ 1.342)$。若 $\gamma=2,\beta=1$：$y=(-1.683,\ 0.106,\ 1.894,\ 3.683)$。

### 8.4 训练与推理的区别（高频考点）

- 训练：用当前 batch 的 $\mu,\sigma^2$，并更新滑动平均 $\mu_{run}\leftarrow(1-\alpha)\mu_{run}+\alpha\mu$。
- 推理：用滑动平均的 $\mu_{run},\sigma^2_{run}$（固定常数），样本之间互不影响。
- 推理时 BN 是一个固定的逐通道仿射变换，**可以融合进前一个卷积层**（把 $\gamma/\sqrt{\sigma^2+\epsilon}$ 乘进卷积权重，偏置同步调整）。这就是部署工具（ONNX 导出、RKNN 转换）常做的"Conv+BN 融合"，见[量化与部署章](./04_模型量化与边缘部署_RKNN.md)。
- 忘记切换 `model.eval()` 是经典 bug：推理结果依赖 batch，且小 batch 时抖动。

### 8.5 LayerNorm 对比

BN 沿 batch 维统计；LayerNorm 对**单个样本**的所有特征统计，不依赖 batch。序列模型、Transformer 用 LayerNorm，因为 batch 小或序列长度变化时 BN 不稳。检测网络 batch 小时也可用 GroupNorm。

## 9. 参数初始化

### 9.1 要解决什么问题

全 0 初始化 → 同一层所有神经元对称，梯度一样，永远学成一样（对称性无法打破）。初始化太小 → 信号层层衰减；太大 → 层层放大。

### 9.2 方差推导

设某层 $y=\sum_{i=1}^{n_{in}}w_ix_i$，$w_i,x_i$ 独立零均值，则
$$\mathrm{Var}(y)=n_{in}\,\mathrm{Var}(w)\,\mathrm{Var}(x)$$
要让信号方差逐层不变，需要 $\mathrm{Var}(w)=1/n_{in}$。反向传播同理要 $1/n_{out}$，折中得到：

- **Xavier/Glorot**（适用于 tanh/sigmoid 近线性区）：$\mathrm{Var}(w)=\dfrac{2}{n_{in}+n_{out}}$。
- **He/Kaiming**（ReLU 会把一半激活置零，方差减半，需补偿）：$\mathrm{Var}(w)=\dfrac2{n_{in}}$。

手算：$n_{in}=256$，若 $w\sim\mathcal N(0,0.01^2)$，则每层方差比 $=256\times10^{-4}=0.0256$，标准差比 $0.16$。10 层后信号标准差缩小到 $0.16^{10}\approx1.1\times10^{-8}$，几乎为零。He 初始化 $\mathrm{Var}(w)=2/256$，每层方差比为 $256\times2/256=2$，被 ReLU 砍半后为 1，信号稳定。

偏置一般初始化为 0；BN 的 $\gamma=1,\beta=0$。

## 10. 梯度消失与梯度爆炸

### 10.1 成因

反向传播中，梯度是一串因子连乘：$\delta^1\sim\prod_l\big(W^l\big)^\top\mathrm{diag}(\sigma'(z^l))\cdot\delta^L$。

- 每个因子的范数 $<1$（sigmoid 斜率 ≤0.25）→ 指数衰减。手算：10 层 sigmoid，仅斜率就是 $0.25^{10}\approx9.5\times10^{-7}$。
- 每个因子 $>1$（权重大）→ 指数增长：每层 1.5 倍，20 层是 $1.5^{20}\approx3325$。

**症状**：消失 → 靠前层几乎不更新，损失不降；爆炸 → 损失变 NaN/Inf、参数突变。

### 10.2 对策

| 对策 | 原理 |
|---|---|
| ReLU 系激活 | 正半轴斜率 1 |
| He/Xavier 初始化 | 保持各层方差稳定 |
| BatchNorm/LayerNorm | 保持各层输入分布稳定 |
| 残差连接（ResNet） | $y=x+F(x)$，反向多一条恒等通路 $\partial y/\partial x=1+\partial F/\partial x$ |
| 梯度裁剪（clipping） | 爆炸时按范数缩放：$g\leftarrow g\cdot\min(1,c/\|g\|)$ |
| LSTM/门控 | 序列模型中通路更稳（见 LLM 章背景） |

梯度裁剪手算：$g=(3,4)$，$\|g\|=5$，阈值 $c=1$，则 $g\leftarrow(3,4)\times0.2=(0.6,0.8)$，方向不变、长度限制到 1。

## 11. 训练技巧与过拟合处理

### 11.1 一份"先跑通再优化"的清单

1. **先过拟合一个小 batch**（几十个样本，损失应该降到接近 0）。做不到 → 代码或损失有 bug，别急着调超参。
2. 检查初始损失：$K$ 类分类、随机初始化时，交叉熵应约为 $\ln K$（例如 10 类约 2.30），差得远说明初始化或标签有问题。
3. 输入归一化；标签与预处理在训练和推理保持一致（部署时的 mean/std、通道顺序也是这件事，见[量化与部署章](./04_模型量化与边缘部署_RKNN.md)）。
4. 画 train/val 损失曲线，据此诊断（上一章 5.4）。
5. 一次只改一个变量；固定随机种子；记录配置。
6. 学习率：先粗搜（$10^{-4}$–$10^{-1}$ 对数网格），再精调。

### 11.1b 用损失曲线诊断

| 曲线形态 | 含义 | 行动 |
|---|---|---|
| 训练、验证都平且高 | 欠拟合或学习率太小/梯度消失 | 增大模型/学习率，检查梯度 |
| 训练降、验证先降后升 | 过拟合开始 | 早停；加正则/增强 |
| 损失锯齿剧烈震荡 | 学习率偏大或 batch 太小 | 降学习率、增大 batch |
| 损失突然飙升/NaN | 爆炸或数据异常 | 梯度裁剪、检查数据与 `log(0)` |
| 训练损失很低、验证很高且线上差 | 泄漏或分布偏移 | 回查划分与数据来源 |
| 某个 epoch 后验证指标跳变 | 学习率调度节点、BN 统计、增强关闭 | 对照调度配置 |

**超参搜索**：先固定其他项，只扫学习率（对数尺度），再调 batch、权重衰减、增强强度。随机搜索通常比网格搜索更高效（重要超参数只有少数几个）。每次实验记录：代码版本、数据版本、随机种子、超参、指标曲线，才能复现。

### 11.2 过拟合的处理手段

| 手段 | 原理 | 说明 |
|---|---|---|
| 更多/更好数据 | 直接降方差 | 最有效 |
| 数据增强 | 制造不变性 | 翻转、裁剪、色彩、马赛克等 |
| 权重衰减 | L2 | AdamW 中与梯度解耦 |
| Dropout | 随机丢弃，防共适应 | 见下 |
| 早停 | 在验证最优处停 | 保存最佳 checkpoint |
| 减小模型/迁移学习 | 降容量或借用预训练特征 | 小数据首选微调 |
| 标签平滑 | 软化 one-hot | 防过度自信 |

**Dropout（inverted dropout）**：训练时每个神经元以概率 $1-q$ 置零（$q$ 为保留概率），保留的除以 $q$，这样期望不变，推理时什么都不用做。手算（$q=0.8$）：激活 $(1,2,3,4,5)$，掩码 $(1,0,1,1,1)$ → 输出 $(1.25,0,3.75,5,6.25)$。直觉：每次训练一个随机子网络，近似多模型集成。

### 11.3 迁移学习与微调

在大数据集上预训练的特征（边缘、纹理、形状）通用。小数据任务：冻结前几层，只训练后几层（特征提取），或用较小学习率整体微调。检测里"用 COCO 预训练权重初始化再在自己数据上训练"是标准做法。

## 12. 最小 numpy 实现（教学示例，非项目源码）

用 4 个隐藏单元的 tanh 网络学 XOR，sigmoid 输出 + 二元交叉熵。可运行并复现第 4 节的每一个公式。

```python
import numpy as np

rng = np.random.default_rng(1)          # 种子 0 会卡在平台期，换种子可收敛：初始化很重要
X = np.array([[0,0],[0,1],[1,0],[1,1]], dtype=float)
Y = np.array([[0],[1],[1],[0]], dtype=float)

W1 = rng.normal(0, 1.0, (2, 4)); b1 = np.zeros((1, 4))
W2 = rng.normal(0, 1.0, (4, 1)); b2 = np.zeros((1, 1))
lr = 0.5
for step in range(2000):
    z1 = X @ W1 + b1                    # 前向
    a1 = np.tanh(z1)
    z2 = a1 @ W2 + b2
    p = 1 / (1 + np.exp(-z2))
    loss = -np.mean(Y * np.log(p) + (1 - Y) * np.log(1 - p))

    dz2 = (p - Y) / len(X)              # 反向：sigmoid + BCE 的 delta 是 p - y
    dW2 = a1.T @ dz2
    db2 = dz2.sum(axis=0, keepdims=True)
    da1 = dz2 @ W2.T
    dz1 = da1 * (1 - a1 ** 2)           # tanh 的导数
    dW1 = X.T @ dz1
    db1 = dz1.sum(axis=0, keepdims=True)

    W1 -= lr * dW1; b1 -= lr * db1      # 更新
    W2 -= lr * dW2; b2 -= lr * db2
print(loss, p.round(3).ravel())         # 损失约 0.002，预测接近 [0, 1, 1, 0]
```

读代码时对照：`dz2` 就是 $\delta^L$；`da1 = dz2 @ W2.T` 是"转置传回"；`dz1 = da1 * (1 - a1**2)` 就是乘激活导数。

## 14. 常见错误与故障现象

| 现象 | 可能原因 | 排查 |
|---|---|---|
| 损失 NaN | 学习率过大；`log(0)`；除零；爆炸 | 降学习率；加 $\epsilon$；梯度裁剪；检查数据 |
| 损失完全不降 | 学习率太小/梯度消失；标签与输出对不上；忘了清零梯度 | 过拟合小 batch；打印梯度范数 |
| 训练好验证差 | 过拟合或泄漏 | 见上一章 |
| 验证时结果随 batch 变化 | 没切 `eval()`，BN 用 batch 统计 | 切推理模式 |
| 训练推理不一致 | 预处理/归一化/通道顺序不同 | 对齐 mean/std、RGB/BGR |
| 梯度检验不通过 | 反向实现有误 | 逐层对照公式；检查转置与维度 |
| 显存爆 | batch 太大；缓存中间激活 | 减 batch、混合精度、梯度累积 |
| ReLU 大量死亡 | 学习率过大或偏置负 | 降学习率、Leaky/SiLU |

## 15. 面试问答（英文）

**Q1. Walk me through backpropagation.**

> Backpropagation computes the gradient of the loss with respect to every parameter using the chain rule. In the forward pass I store each layer's pre-activation. In the backward pass I start from the loss, compute the error signal at the output, and propagate it back: delta of layer l equals the transpose of the next layer's weights times the next delta, multiplied element-wise by the activation derivative. The weight gradient is delta times the previous layer's activation. One backward sweep gives all gradients at roughly the cost of one forward pass.

中文要点：前向缓存；输出层 delta；$\delta^l=W^{l+1\top}\delta^{l+1}\odot\sigma'$；$\partial W=\delta a^\top$；一次反扫得到全部梯度。
追问：*Why not numerical differentiation?* — 参数多，每个参数需要两次前向，太慢；仅用于梯度检验。

**Q2. What is the vanishing gradient problem and how do you mitigate it?**

> In a deep network the gradient is a product of many factors. With sigmoid, the derivative is at most 0.25, so after ten layers the gradient shrinks by about a million times and early layers barely learn. I mitigate it with ReLU-type activations, proper initialization such as He initialization, normalization layers, and residual connections that give the gradient an identity path.

**Q3. Explain Adam and why it can be better than plain SGD.**

> Adam keeps a moving average of the gradient, like momentum, and a moving average of the squared gradient to scale each parameter's step. With bias correction, the first step is about the learning rate regardless of gradient size. It adapts per-parameter step sizes and converges quickly with little tuning. SGD with momentum can generalize slightly better on some vision tasks but needs careful learning-rate scheduling.

**Q4. What does batch normalization do, and how is inference different from training?**

> It normalizes each channel using the batch mean and variance, then applies a learned scale and shift. It stabilizes and speeds up training. At inference it uses running statistics collected during training, so it becomes a fixed affine transform that can be fused into the preceding convolution. A classic bug is forgetting to switch the model to evaluation mode.

**Q5. How do you debug a network that does not learn?**

> I first try to overfit a tiny batch. If it can't, there is a bug in the data, labels, loss or gradient flow. I check the initial loss against the expected value, verify shapes, check gradients with a numerical test, and look at the learning rate. Only after it overfits a small batch do I scale up and tune.

**Q6. Why is the gradient of softmax cross-entropy just prediction minus label?**

> Cross-entropy takes the negative log of the true class probability, and the softmax Jacobian has the form p_k times delta minus p_j. When you multiply them through the chain rule, the p terms cancel, and what remains is p_j minus y_j. It is convenient numerically, and it also explains why a confidently wrong prediction produces a large gradient.

**Q7. What is the difference between L2 regularization and weight decay?**

> For plain SGD they are equivalent. For adaptive optimizers like Adam they differ, because the L2 gradient is rescaled by the adaptive denominator. AdamW decouples weight decay from the gradient update so that the decay strength is the same for all parameters.

## 16. 自测题

1. 证明没有非线性激活的 3 层网络等价于一层线性模型。
   **答案要点**：$W^3(W^2(W^1x+b^1)+b^2)+b^3$ 合并为 $Wx+b$。
2. 用第 5 节网络，若把隐藏层改为 ReLU（$z^1=(0.5,1.1)$ 均为正），求 $\partial L/\partial W^1_{11}$。
   **答案**：$h=(0.5,1.1)$，$y=0.5\times0.5+0.6\times1.1=0.91$，$\delta^2=-0.09$，$\partial L/\partial h_1=0.5\times(-0.09)=-0.045$，ReLU 斜率 1，$\delta^1_1=-0.045$，$\partial L/\partial W^1_{11}=-0.045\times x_1=-0.045$。
3. $z=(1,1,1)$，真类为第 1 类，求 softmax 交叉熵及梯度。
   **答案**：$p=(1/3,1/3,1/3)$，$L=\ln3=1.0986$，梯度 $(-2/3,1/3,1/3)$（真类位置为 $1/3-1$）。
4. Adam 第一步为什么步长约等于学习率？
   **答案**：$\hat m=g$，$\hat v=g^2$，步长 $=\eta\,g/|g|=\eta$。
5. 为什么 He 初始化的方差是 $2/n_{in}$ 而不是 $1/n_{in}$？
   **答案**：ReLU 把约一半的激活置零，输出二阶矩减半，需要乘 2 补偿。
6. 推理时 BN 用什么统计量？为什么能融合进卷积？
   **答案**：训练期滑动平均的均值与方差；此时是固定的逐通道仿射，可并入卷积的权重和偏置。
7. 梯度裁剪 $c=2$，$g=(6,8)$，裁剪后？
   **答案**：$\|g\|=10$，缩放 $0.2$，得 $(1.2,1.6)$。
8. 对 $f=(x+y)z$，$x=2,y=3,z=4$，求 $\partial f/\partial x,\ \partial f/\partial z$。
   **答案**：$\partial f/\partial x=z=4$；$\partial f/\partial z=x+y=5$。
9. 余弦退火 $\eta_{max}=0.1$，$\eta_{min}=0$，$T=10$，$t=5$ 的学习率？
   **答案**：$\eta=\frac12\times0.1\times(1+\cos(\pi/2))=0.05$。

## 本章要点速记

1. 单层感知机只能线性分类；隐藏层+非线性才能解 XOR；无非线性的深层=一层。
2. 前向：$z^l=W^la^{l-1}+b^l$，$a^l=\sigma(z^l)$，缓存中间量。
3. 反向：$\delta^l=(W^{l+1\top}\delta^{l+1})\odot\sigma'(z^l)$，$\partial W^l=\delta^l a^{l-1\top}$，$\partial b^l=\delta^l$。
4. softmax+交叉熵、sigmoid+BCE 的输出层 delta 都是 $p-y$。
5. 梯度检验用数值差分，写完反向必做。
6. Momentum 平滑震荡；Adam = 一阶矩+二阶矩+偏差修正，首步步长≈学习率。
7. BN 训练用 batch 统计、推理用滑动平均，可与卷积融合；Transformer 用 LayerNorm。
8. He 初始化 $2/n_{in}$，Xavier $2/(n_{in}+n_{out})$；全 0 初始化无法打破对称。
9. 梯度消失/爆炸来自连乘；ReLU、初始化、归一化、残差、裁剪是标准对策。
10. 调试顺序：过拟合小 batch → 看初始损失 → 梯度检验 → 再调超参。
