# 规划与导航：学习顺序与前置关系

> **一句话定位**：从 A 到 B 怎么走：图搜索、Hybrid A*、代价地图与局部规划、轨迹跟踪，Nav2（ROS2 Humble）导航系统架构，以及采样规划、机械臂运动规划、行为树与任务规划、多机器人规划和 DWA/MPPI/ORCA。

**本模块学完你能：**

- 手算 Dijkstra 与 A*；
- 解释 Hybrid A* 如何把运动学约束放进搜索；
- 说明代价地图膨胀与 TEB 的优化目标；
- 推导 Pure Pursuit/Stanley，理解 MPC 跟踪；
- 画出 Nav2 的服务器与行为树数据流，并对照 move_base；
- 手算 RRT 扩展与 RRT* 重连、配置空间障碍、行为树 tick、CBS 小例子和 DWA/MPPI/ORCA 步骤。

**前置知识**：[车辆运动学](../02_力学与动力学建模/04_差速_麦克纳姆_全向轮与车辆运动学.md)、[最优化与二次规划](../01_数学基础/04_最优化与二次规划.md)、[MPC 模型预测控制](../05_控制理论/05_MPC模型预测控制.md)。

P5 全链路（Hybrid A*、TEB、MPC、Nav2/AMCL），P2 的运动规划延伸。

## 阅读顺序建议

图搜索 → Hybrid A* → 代价地图/TEB → 轨迹跟踪 → 导航系统架构；采样规划（06）→ 机械臂运动规划（07）为一条延伸线；行为树与任务规划（08）接在导航架构之后；多机器人规划（09）与局部规划进阶（10）可在读完 TEB 和 MPC 后阅读。
