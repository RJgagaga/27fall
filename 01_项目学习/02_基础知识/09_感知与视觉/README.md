# 感知与视觉：学习顺序与前置关系

> **一句话定位**：机器人如何"看"：相机模型与标定、点云处理与配准，立体视觉与深度估计、检测分割跟踪与评价指标、3D 感知（点云检测、BEV、占据网络）、传感器融合与时空对齐，以及图像处理基础。

**本模块学完你能：**

- 手算针孔投影、反投影、视场角与畸变；
- 解释张正友标定与手眼标定；
- 手算体素滤波、RANSAC、Kabsch 与 ICP；
- 解释运动畸变与去畸变；
- 手算视差与深度误差、SGM 聚合、GIoU/DIoU、SORT 关联、柱网格尺寸、激光到图像的投影、Sobel/Otsu/形态学。

**前置知识**：[线性代数](../01_数学基础/01_线性代数.md)、[坐标系与齐次变换](../03_运动学与坐标变换/01_坐标系_旋转矩阵_齐次变换.md)。

## 阅读顺序建议

相机模型 → 点云 → 立体视觉；检测分割跟踪（04）→ 3D 感知（05）→ 传感器融合（06）；图像处理基础（07）可在读完相机模型后随时阅读，也适合作为 04 的补充；视觉里程计（07 模块）需先读相机模型。
