# 感知与视觉：学习顺序与前置关系

> **一句话定位**：机器人如何"看"：相机模型与标定、点云处理与配准，以及（后续）立体视觉、检测分割跟踪、3D 感知与传感器融合。

**本模块学完你能：**

- 手算针孔投影、反投影、视场角与畸变；
- 解释张正友标定与手眼标定；
- 手算体素滤波、RANSAC、Kabsch 与 ICP；
- 解释运动畸变与去畸变。

**前置知识**：[线性代数](../01_数学基础/01_线性代数.md)、[坐标系与齐次变换](../03_运动学与坐标变换/01_坐标系_旋转矩阵_齐次变换.md)。
