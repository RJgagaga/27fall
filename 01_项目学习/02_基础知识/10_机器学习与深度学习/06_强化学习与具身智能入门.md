## 2. MDP 与回报

### 2.1 它要解决什么问题

监督学习有"标准答案"。很多问题没有：机器人平衡、下棋、调度，你只知道**最终好不好**（得到奖励），而且当前动作会影响之后的状态。强化学习研究：智能体（agent）与环境交互，学一个策略，使**累计奖励**最大。

### 2.2 符号

马尔可夫决策过程（MDP）$(\mathcal S,\mathcal A,P,R,\gamma)$：

- $s\in\mathcal S$：状态；$a\in\mathcal A$：动作。
- 转移 $P(s'\mid s,a)$：在 $s$ 做 $a$ 后到达 $s'$ 的概率（机器人里就是动力学，可能含噪声）。
- 奖励 $r=R(s,a,s')$：标量。
- 折扣因子 $\gamma\in[0,1)$：未来奖励打折。
- 策略 $\pi(a\mid s)$：状态到动作（分布）的映射。**马尔可夫性**：下一状态只依赖当前状态和动作，不依赖更早的历史。

回报（return）：从时刻 $t$ 开始的折扣累计奖励

$$G_t=r_{t+1}+\gamma r_{t+2}+\gamma^2r_{t+3}+\cdots=\sum_{k\ge0}\gamma^kr_{t+k+1}$$

目标：找 $\pi$ 最大化 $J(\pi)=E_\pi[G_0]$。

### 2.3 手算回报

奖励序列 $[1,2,3]$，$\gamma=0.9$：$G=1+0.9\times2+0.9^2\times3=1+1.8+2.43=5.23$。$\gamma=1$：$G=6$。$\gamma$ 越小越"短视"。

### 2.4 与控制语言的对照

| RL | 控制 |
|---|---|
| 状态 $s$ | 状态 $x$（需满足马尔可夫性，否则要用历史或估计） |
| 动作 $a$ | 控制输入 $u$ |
| 奖励 $r$ | 负的代价 $-\ell(x,u)$ |
| 策略 $\pi$ | 反馈控制律 $u=\pi(x)$（如 $u=-Kx$） |
| 价值函数 $V$ | cost-to-go（代价函数的负值） |
| 折扣 $\gamma$ | 有限/无限时域代价的折扣（LQR 常取 1） |

注意符号撞车：RL 的 $Q(s,a)$ 是**动作价值函数**，LQR 的 $Q$ 是**状态权重矩阵**，同名异义。

### 2.5 奖励设计：RL 里最难、最容易出错的一环

奖励函数定义了"什么算好"。优化器会**不折不扣**地最大化你写下的奖励，而不是你心里想的目标。

**手算示例**（教学示例）：想让机器人保持直立并前进。奖励设计 A：$r=v_x$（前进速度）。策略可能学会"扑倒向前滑"，因为短期速度最高但会摔倒。设计 B：$r=v_x-0.5|\theta|-0.01\|u\|^2+1_{alive}$，其中 $\theta$ 是倾角，$u$ 是力矩，$1_{alive}$ 是存活奖励。比较两个行为（每步）：直立走 $v_x=0.5,\theta=0.05,\|u\|^2=4$：$r=0.5-0.025-0.04+1=1.435$；扑倒滑行 $v_x=1.0,\theta=1.2$（但很快终止）：$r=1.0-0.6-0.01\times4+1=1.36$ 且回合短，累计奖励低。加入姿态和能耗惩罚后，直立走才是更优解。

**设计原则与陷阱**：(1) 稀疏奖励（只有成功才给）难学，需要**奖励塑形**（shaping）给过程信号；(2) 塑形项要保证不改变最优策略（基于势函数的塑形 $F=\gamma\Phi(s')-\Phi(s)$ 有这一性质）；(3) 多项奖励加权要调；(4) 要有终止条件和存活奖励的符号意识：存活奖励为正鼓励"拖着不死"，为负鼓励"尽快结束"；(5) **奖励钻空子**：策略找到奖励的漏洞（原地抖动刷分、利用仿真器缺陷）——必须回放行为录像检查，不能只看数字曲线。

**与 LQR 权重的类比**：LQR 里你选 $Q,R$ 就是在设计"奖励"，对 P1 的 position/velocity/tilt/tilt-rate 权重的权衡分析，本质上就是这类设计问题；区别是 LQR 的代价是二次型、有解析解和稳定性结论，RL 的奖励可以是任意函数，但没有这些保证。

## 3. 价值函数与 Bellman 方程

### 3.1 定义

- 状态价值 $V^\pi(s)=E_\pi[G_t\mid s_t=s]$：从 $s$ 出发、之后一直按 $\pi$ 走，期望回报。
- 动作价值 $Q^\pi(s,a)=E_\pi[G_t\mid s_t=s,a_t=a]$：在 $s$ **先做 $a$**，之后按 $\pi$ 走。
- 优势 $A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)$：这个动作比平均水平好多少。
- 关系：$V^\pi(s)=\sum_a\pi(a\mid s)Q^\pi(s,a)$。

### 3.2 Bellman 期望方程（推导）

回报的递归：$G_t=r_{t+1}+\gamma G_{t+1}$。两边取期望：

$$V^\pi(s)=\sum_a\pi(a\mid s)\sum_{s'}P(s'\mid s,a)\big[r+\gamma V^\pi(s')\big]$$

直觉："一步奖励 + 折扣后的下一状态价值"。对 $Q$：

$$Q^\pi(s,a)=\sum_{s'}P(s'\mid s,a)\Big[r+\gamma\sum_{a'}\pi(a'\mid s')Q^\pi(s',a')\Big]$$

### 3.3 Bellman 最优方程

最优价值 $V^*(s)=\max_\pi V^\pi(s)$，满足

$$V^*(s)=\max_a\sum_{s'}P(s'\mid s,a)\big[r+\gamma V^*(s')\big],\qquad Q^*(s,a)=\sum_{s'}P(s'\mid s,a)\big[r+\gamma\max_{a'}Q^*(s',a')\big]$$

最优策略：$\pi^*(s)=\arg\max_aQ^*(s,a)$。这是动态规划的核心：把长期优化拆成"一步 + 子问题"。

### 3.4 完整手算：3 状态走廊（教学示例）

状态 $1,2,3$ 排成一排，右边是目标 G。动作：L（向左，在状态 1 撞墙留在原地）、R（向右）。进入 G 得奖励 $+1$ 并结束，其余奖励 0；$\gamma=0.9$，转移确定。

```text
 [1] <-> [2] <-> [3] --R--> [G]   (到达 G 得 +1)
```

**(a) 策略评估：随机策略**（L/R 各 0.5）。写 Bellman 期望方程：

- $V_1=0.5\cdot0.9V_1+0.5\cdot0.9V_2=0.45V_1+0.45V_2$
- $V_2=0.5\cdot0.9V_1+0.5\cdot0.9V_3=0.45V_1+0.45V_3$
- $V_3=0.5\cdot0.9V_2+0.5\cdot(1)=0.45V_2+0.5$

求解：由第一式 $0.55V_1=0.45V_2\Rightarrow V_1=0.8182V_2$。代入第二式：$V_2=0.45(0.8182V_2)+0.45V_3\Rightarrow0.6318V_2=0.45V_3\Rightarrow V_2=0.7123V_3$。代入第三式：$V_3=0.45\times0.7123V_3+0.5=0.3205V_3+0.5\Rightarrow V_3=0.7358$。回代：$V_2=0.5241$，$V_1=0.4288$。

验算第二式：$0.45\times0.4288+0.45\times0.7358=0.1930+0.3311=0.5241$ ✓。

**(b) 价值迭代求最优**：从 $V=0$ 开始，每次 $V_s\leftarrow\max_a[\,r+\gamma V_{s'}]$。

| 迭代 | $V_1$ | $V_2$ | $V_3$ |
|---|---|---|---|
| 0 | 0 | 0 | 0 |
| 1 | 0 | 0 | 1 |
| 2 | 0 | 0.9 | 1 |
| 3 | 0.81 | 0.9 | 1 |
| 4 | 0.81 | 0.9 | 1（收敛） |

所以 $V^*=(0.81,0.9,1)$，对应"一路向右"：离目标 $k$ 步，价值 $0.9^{k-1}$。最优策略在三个状态都选 R。**注意信息是从目标一步步"回传"的**，这正是 RL 中"信用分配"的直观含义。

### 3.5 三个核心难题

1. **探索与利用**（exploration vs exploitation）：一直走已知最好的路会错过更好的；一直乱试又拿不到奖励。$\varepsilon$-greedy、熵奖励、噪声注入是常见手段。
2. **信用分配**（credit assignment）：长序列最后才得到奖励，哪一步的动作功劳最大？折扣、价值函数、优势估计、奖励塑形都是在解决它（走廊例子里价值从目标一步步回传就是直观体现）。
3. **样本效率**：真实机器人上几百万次交互不现实，所以要仿真、模型法、示范预热、离线 RL。

## 4. Q-learning 与 DQN

### 4.1 它要解决什么问题

上面的价值迭代需要知道转移模型 $P$。多数真实问题不知道（或太复杂）。**无模型（model-free）**方法直接从交互样本 $(s,a,r,s')$ 学习。

### 4.2 Q-learning

维护表格 $Q(s,a)$，每得到一个样本更新：

$$Q(s,a)\leftarrow Q(s,a)+\alpha\big[\underbrace{r+\gamma\max_{a'}Q(s',a')}_{\text{TD 目标}}-Q(s,a)\big]$$

方括号里是**时序差分误差**（TD error）$\delta$。$\alpha$ 学习率。因为目标用 $\max$ 而不是实际采取的下一动作，它学的是最优策略的价值，而行动时可以用另一个探索性策略——这叫 **off-policy**。对比 **SARSA**：目标用实际执行的 $a'$，是 on-policy。

**探索—利用**：只贪心会卡在次优；常用 $\varepsilon$-greedy：以概率 $\varepsilon$ 随机动作，否则取 $\arg\max_aQ$。

### 4.3 手算（3 状态走廊，$\alpha=0.5,\gamma=0.9$，Q 初值 0，每回合按 1→2→3→G 全选 R）

只看 R 的 Q 值：

- 回合 1：$Q(1,R)$ 更新：目标 $0+0.9\times\max Q(2,\cdot)=0$，不变；$Q(2,R)$ 同理 0；$Q(3,R)$：到 G 奖励 1，终止，$Q(3,R)=0+0.5(1-0)=0.5$。
- 回合 2：$Q(1,R)=0$；$Q(2,R)=0+0.5(0+0.9\times0.5-0)=0.225$；$Q(3,R)=0.5+0.5(1-0.5)=0.75$。
- 回合 3：$Q(1,R)=0+0.5(0+0.9\times0.225-0)=0.10125$；$Q(2,R)=0.225+0.5(0.9\times0.75-0.225)=0.45$；$Q(3,R)=0.75+0.5(1-0.75)=0.875$。

价值信息每个回合向起点传一格；向 $Q^*=(0.81,0.9,1)$ 逼近。若按反向顺序更新（先更新离目标近的），传播更快——这是"经验回放按序/优先级"的动机之一。

### 4.3b 表格 Q-learning 的最小代码（教学示例，已运行验证）

```python
import random
N, GOAL = 3, 3                      # 状态 0,1,2（对应正文的 1,2,3），目标=3
gamma, alpha, eps = 0.9, 0.5, 0.2
Q = [[0.0, 0.0] for _ in range(N)]  # 动作：0=左，1=右

def step(s, a):
    s2 = min(s + 1, GOAL) if a == 1 else max(s - 1, 0)
    return s2, (1.0 if s2 == GOAL else 0.0), s2 == GOAL

for ep in range(200):
    s, done = 0, False
    while not done:
        a = random.randrange(2) if random.random() < eps else max((0, 1), key=lambda x: Q[s][x])
        s2, r, done = step(s, a)
        target = r if done else r + gamma * max(Q[s2])    # 终止状态没有后继价值
        Q[s][a] += alpha * (target - Q[s][a])
        s = s2
```

运行后 $Q(\cdot,R)\approx(0.81,0.9,1.0)$，$Q(\cdot,L)\approx(0.729,0.729,0.81)$，与价值迭代的 $V^*$ 一致：向左的动作价值恰好是 $0.9\times V^*(s')$。注意**终止状态的目标不加 $\gamma\max Q$**，漏掉这一点是常见 bug。

### 4.4 DQN

状态连续时无法用表，用神经网络 $Q_\theta(s,a)$ 近似。直接这么做不稳定（样本相关、目标随参数变化）。DQN 两个关键技巧：

- **经验回放**（replay buffer）：存储 $(s,a,r,s')$，随机小批量采样，打破时间相关性、复用数据。
- **目标网络**：用一个慢更新的网络 $Q_{\theta^-}$ 计算 TD 目标，减小"追着自己跑"的振荡。

损失 $L=\big(r+\gamma\max_{a'}Q_{\theta^-}(s',a')-Q_\theta(s,a)\big)^2$。局限：只适用于离散动作（要对动作取 max）。

## 5. 策略梯度、基线与 Actor-Critic

### 5.1 它要解决什么问题

机器人动作常常是**连续**的（关节力矩），无法对动作取 max。策略梯度直接优化参数化策略 $\pi_\theta(a\mid s)$。

### 5.2 推导（log-derivative 技巧）

轨迹 $\tau=(s_0,a_0,\dots)$，其概率 $P_\theta(\tau)=p(s_0)\prod_t\pi_\theta(a_t\mid s_t)P(s_{t+1}\mid s_t,a_t)$。目标 $J(\theta)=\sum_\tau P_\theta(\tau)R(\tau)$。

$$\nabla_\theta J=\sum_\tau\nabla_\theta P_\theta(\tau)R(\tau)=\sum_\tau P_\theta(\tau)\nabla_\theta\log P_\theta(\tau)R(\tau)$$

用 $\nabla P=P\nabla\log P$。又 $\log P_\theta(\tau)=\text{常数项}+\sum_t\log\pi_\theta(a_t\mid s_t)$——**环境转移模型 $P$ 不含 $\theta$，求梯度时消失**，这就是为什么无需知道动力学也能算梯度。结果：

$$\nabla_\theta J=E_\tau\Big[\sum_t\nabla_\theta\log\pi_\theta(a_t\mid s_t)\,G_t\Big]$$

**直觉**：回报高的动作，提高它的概率；回报低的，降低。这就是 **REINFORCE**。

### 5.3 基线与优势

梯度方差很大。减去一个与动作无关的基线 $b(s)$ 不改变期望：$E[\nabla\log\pi\cdot b(s)]=0$。取 $b=V(s)$，则权重变成优势 $A=G_t-V(s_t)$：只奖励"比平均好"的动作。

**Actor-Critic**：actor 是策略网络；critic 是价值网络 $V_\phi(s)$ 估计基线，并用 TD 误差 $\delta_t=r_{t+1}+\gamma V(s_{t+1})-V(s_t)$ 作优势的低方差估计。

手算 TD 误差：$r=1,\ V(s)=0.5,\ V(s')=0.8,\ \gamma=0.9$：$\delta=1+0.72-0.5=1.22$。

**GAE**（广义优势估计）折中偏差与方差：$A_t=\sum_{l\ge0}(\gamma\lambda)^l\delta_{t+l}$。手算：$\delta_0=1.22,\delta_1=0.5,\delta_2=-0.2$，$\gamma\lambda=0.9\times0.95=0.855$：$A_0=1.22+0.855\times0.5+0.855^2\times(-0.2)=1.22+0.4275-0.1462=1.501$。$\lambda=0$ 退化为单步 TD（低方差高偏差），$\lambda=1$ 为蒙特卡洛（高方差低偏差）。

### 5.4 softmax 策略一步更新（教学示例）

两个动作，参数 $\theta=(0,0)$，$\pi=\mathrm{softmax}(\theta)=(0.5,0.5)$。关键事实：对 softmax 策略 $\nabla_\theta\log\pi(a)=\mathrm{onehot}(a)-\pi$。

采样到动作 0，回报 $G=2$，基线 $b=1$（优势 1），学习率 $\alpha=0.1$：
$\nabla\log\pi(0)=(1,0)-(0.5,0.5)=(0.5,-0.5)$；$\theta\leftarrow(0,0)+0.1\times1\times(0.5,-0.5)=(0.05,-0.05)$；新策略 $\mathrm{softmax}(0.05,-0.05)=(0.525,0.475)$。动作 0 的概率从 0.5 升到 0.525。若优势为负，则反向。

## 6. PPO 直觉

### 6.1 它要解决什么问题

策略梯度走太大一步，策略可能崩溃（新策略采样的数据和旧策略差异大，估计失效，性能骤降且难以恢复）。希望**每次更新不要离旧策略太远**。TRPO 用约束优化做到，但实现复杂。**PPO**（Proximal Policy Optimization）用一个简单的裁剪目标近似做到。

### 6.2 目标函数

重要性比 $r_t(\theta)=\dfrac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{old}}(a_t\mid s_t)}$（新旧策略对同一动作的概率比）。

$$L^{CLIP}=E\Big[\min\big(r_tA_t,\ \mathrm{clip}(r_t,1-\epsilon,1+\epsilon)A_t\big)\Big],\quad\epsilon\approx0.2$$

通常再加价值函数损失和熵奖励（鼓励探索）。

### 6.3 手算三种情形（$\epsilon=0.2$，clip 区间 $[0.8,1.2]$）

| 情形 | $r$ | $A$ | $rA$ | clip 项 | 取 min | 梯度 |
|---|---|---|---|---|---|---|
| ① 好动作，概率已升太多 | 1.5 | +2 | 3.0 | $1.2\times2=2.4$ | 2.4 | **0**（被裁剪，不再继续推高） |
| ② 坏动作，概率已降太多 | 0.7 | −1 | −0.7 | $0.8\times(-1)=-0.8$ | −0.8 | **0**（不再继续压低） |
| ③ 坏动作，概率反而升了 | 1.5 | −1 | −1.5 | $1.2\times(-1)=-1.2$ | −1.5 | **非零**（会被拉回） |

规则：好动作可以提高概率，但提到旧概率的 1.2 倍后就不再奖励；坏动作类似；若更新方向"错了"（情形③）则不被保护，梯度照常纠正。这样一次 PPO 更新大致被限制在旧策略附近，所以稳定、实现简单。

**为什么机器人学习里 PPO 很常见**：与大规模并行仿真搭配，样本多、更新稳、调参相对容易；缺点是 on-policy，样本效率低——所以更适合仿真，不适合直接在真机上训练。

## 7. 连续控制常用算法一览

| 算法 | 类型 | 要点 |
|---|---|---|
| DDPG / TD3 | off-policy actor-critic，确定性策略 | 连续动作；TD3 用双 critic 和延迟更新缓解过估计 |
| SAC | off-policy actor-critic，最大熵 | 目标里加熵项，鼓励探索，样本效率较高、较稳定 |

## 8. Sim-to-Real

### 8.1 问题

RL 需要海量交互（常是百万到数十亿步）。真机慢、贵、会损坏、不安全，所以在仿真里训练，再部署到真实机器人。**现实差距（reality gap）**：仿真与现实的差异使策略在真机上变差甚至失败。

### 8.2 差距来源

动力学参数（质量、惯量、摩擦、阻尼）不准；接触模型简化；电机/减速器的非线性、带宽、饱和、延迟；传感器噪声、延迟、校准误差；控制周期与通信抖动；地面/环境的变化；仿真器离散化误差。你在 P1/P7 里遇到的"状态不一致、力矩限幅、接触切换"这些问题，在 sim-to-real 里同样存在，并且更突出。

### 8.3 常见对策

| 对策 | 做法 | 局限 |
|---|---|---|
| 域随机化（domain randomization） | 训练时随机化质量、摩擦、延迟、噪声、外力 | 让策略对一个"参数族"都稳健；范围太大导致保守，太小则覆盖不了现实；不是安全证明 |
| 系统辨识 | 用真实数据校准仿真参数 | 需要数据和实验 |
| 执行器网络/建模 | 用数据拟合电机响应 | 需要采集 |
| 观测里加历史/估计器 | 让策略隐式适应 | 增加复杂度 |
| 少量真机微调 | 在真机上继续训练/适配 | 安全风险、样本成本 |
| **安全层** | 动作限幅、速率限制、状态机、保护性停止、经典控制作为后备 | 必须独立于学习策略 |

### 8.4 评估要诚实

只看训练奖励上升不够：奖励可能被"钻空子"（reward hacking：得到高分但不是你想要的行为）。要看任务成功率、跟踪误差、碰撞/跌倒次数、能耗，以及在**未见过的条件**下的表现，并区分"仿真成功"和"真机验证"。

## 9. 模仿学习

### 9.1 它要解决什么问题

奖励难设计，但**示范**容易得到（人做给机器人看）。模仿学习（imitation learning）从示范 $(s,a)$ 对学策略。

### 9.2 行为克隆（BC）

最简单：把它当监督学习，$\min_\theta E_{(s,a)\sim\mathcal D}\|\pi_\theta(s)-a\|^2$（或交叉熵、或对多模态动作用生成模型）。

**问题：分布偏移（covariate shift）/ 误差累积**。训练时状态来自专家分布；部署时策略的小误差使其进入专家没覆盖的状态，那里预测更差，误差滚雪球。经典分析给出：在 $T$ 步的任务上，每步误差 $\epsilon$，总误差可以随 $T^2\epsilon$ 增长（而不是线性）。直觉算例：每步 1% 偏离，100 步后偏离已远超训练分布。

### 9.3 DAgger

让当前策略去跑，**专家在策略访问到的状态上标注动作**，把新数据并入训练集再训练，循环。这样训练分布覆盖策略真正会访问的状态，缓解分布偏移。代价：需要专家在线标注。

### 9.4 与遥操作/示教的联系

示范数据怎么来？常见入口正是**遥操作**（VR 手柄、主从臂）和**手把手示教**。你在 P2 做的 VR 遥操作与 leader–follower 示教，在系统层面就属于这类"采集高质量机器人示范"的基础设施（约束逆解、重力补偿让示教顺手、同步的主从跟踪保证记录的动作可信）。诚实地说：CV 里写的是遥操作与示教系统本身，**不是**基于这些数据训练学习策略。你可以说"I can see how this setup could be used to collect demonstrations for imitation learning"，不要说成已经做了。

本项目的情况：P2 的重点是遥操作与示教系统本身，没有把录制的示范数据用于训练学习策略；如果要做模仿学习，可以直接在这套系统上增加轨迹录制（同步记录观测与动作）。

### 9.5 当下操作任务里的模仿学习策略

公开研究里，操作任务常用"观测（图像+本体状态）→ 动作序列"的网络，并用生成式模型（如扩散策略）或动作分块（action chunking）来处理动作多模态和累积误差。这些是近年活跃的方向；细节我没有在此逐篇核对，面试时只讲概念：**用示范监督训练、输出一段动作、用生成模型处理多种可行解**。

## 10. VLA 与具身智能概览

### 10.1 具身智能是什么

具身智能（embodied intelligence）：智能体有身体（机器人），通过感知—决策—行动与物理世界交互来学习和完成任务。核心挑战是：感知不完美、动作有后果、环境不可重置、数据昂贵、安全要求。

### 10.2 VLA（Vision-Language-Action）

**思路**：以预训练的视觉—语言模型（VLM，已经具备图像理解和语言知识）为骨干，再接上"动作输出"，使模型输入"图像 + 语言指令（如把杯子放到托盘上）"，输出机器人动作。

```text
 图像(多相机) ─┐
 语言指令 ────┼─► VLM 骨干 (Transformer) ─► 动作头 ─► 动作(关节/末端增量)
 本体状态 ────┘                              ├ 离散化为 token 自回归
                                              └ 或扩散/流匹配生成连续动作块
```

动作表示的两种常见路线：把连续动作离散成 token，像语言一样自回归生成；或用扩散/流匹配头生成连续动作块。训练数据来自大规模遥操作示范和跨机器人数据集。公开讨论里常被提到的系统包括 RT-2、OpenVLA、π0 等（**我没有在此核对论文细节，面试只讲思想，不要报具体指标**）。

### 10.3 另一条路线：LLM 做高层，经典/技能库做低层

LLM 或 VLM 负责把任务拆成步骤（"先走到桌边，再抓取"），每一步映射到已有的技能（导航、抓取、你的运动控制栈）。这与你的 P6 / 本仓库[上一章](./05_Transformer_LLM与Agent_LangGraph.md)的思想一致：**高层模型只产生 proposal，低层有独立的策略检查、执行和状态反馈**。这种分层让学习到的部分与安全关键的部分隔离。

### 10.4 局限（要讲诚实）

- **数据瓶颈**：机器人示范数据远少于文本/图像，且不同机器人本体（embodiment）不通用。
- **推理延迟与控制频率**：大模型推理常在每秒几次到几十次量级，而底层平衡/力控需要百到千赫兹——所以必须有低层高频控制器兜底。
- **安全与可验证性**：端到端网络难以给出稳定性/约束满足的证明。
- **泛化的真实程度**：论文里的"泛化"常限于特定分布内的变化；离开训练分布会失败。
- **评估困难**：真机评估成本高、难复现。

## 11. 与经典控制（LQR/MPC）的关系与互补

### 11.1 LQR 是 RL 的一个可精确求解的特例

线性系统 $x_{k+1}=ax_k+bu_k$（标量示例）、二次代价 $\sum(qx^2+ru^2)$——这是一个 MDP（确定性动力学，奖励为 $-(qx^2+ru^2)$，$\gamma=1$）。价值函数猜成二次型 $V(x)=Px^2$，代入 Bellman 最优方程：

$$Px^2=\min_u\big[qx^2+ru^2+P(ax+bu)^2\big]$$

对 $u$ 求导置零：$2ru+2Pb(ax+bu)=0\Rightarrow u=-Kx,\ K=\dfrac{abP}{r+b^2P}$。代回得代数 Riccati 方程：

$$P=q+a^2P-\frac{(abP)^2}{r+b^2P}$$

**手算（教学示例）**：$a=1.2$（开环不稳定），$b=1,\ q=1,\ r=1$。方程化为 $P^2-1.44P-1=0$（推导：两边乘 $r+b^2P=1+P$ 后整理），解 $P=\dfrac{1.44+\sqrt{1.44^2+4}}2=\dfrac{1.44+2.4645}2=1.9522$。$K=\dfrac{1.2\times1.9522}{1+1.9522}=0.7935$，闭环 $a-bK=1.2-0.7935=0.4065$（$|\cdot|<1$，稳定）。我用迭代法数值验证了同一结果。

所以 LQR 就是"动力学已知且线性、代价二次"时 Bellman 方程的解析解。RL 处理的是一般情形：动力学未知或非线性、代价不规则。

### 11.2 MPC 与 RL 的对比

- MPC：每个周期**在线**用模型求解有限时域优化，施加第一步，下一周期重来。显式处理约束，可解释，模型明确。
- RL：把优化**离线摊销**到一个策略网络里，在线只做一次前向，速度快、可处理难建模的接触等，但约束满足是"软的"（靠奖励惩罚），保证弱。
- 它们也能结合：学习的价值函数作为 MPC 的终端代价；学习的动力学模型放进 MPC；MPC 作为专家产生数据去训练快速策略（"策略蒸馏"）。

### 11.3 对比表

| 维度 | PID | LQR | MPC | RL / 学习策略 |
|---|---|---|---|---|
| 需要模型 | 不需要 | 线性模型 | 预测模型 | 不一定（无模型）或学习模型 |
| 约束处理 | 靠限幅 | 无（事后饱和） | 显式 | 靠奖励/安全层 |
| 稳定性/最优性保证 | 局部、经验 | 线性系统有 | 一定条件下有 | 通常无形式保证 |
| 在线计算 | 极低 | 极低 | 高（求解优化） | 低（前向）但需 GPU/NPU 视网络 |
| 数据需求 | 无 | 无 | 少（辨识） | 大（常需仿真） |
| 可解释/调试 | 好 | 好（看权重） | 好 | 差 |
| 擅长 | 单回路、有反馈 | 多状态线性系统 | 带约束的跟踪 | 复杂接触、难建模、感知耦合 |

### 11.4 互补的几种方式

1. **残差学习**：经典控制器给基础指令，学习策略输出小的修正量（并限幅）。保留经典控制的稳定性底线。
2. **学习去调参**：用优化/RL 自动整定增益或权重（如在 P7 类系统上选择增益调度参数）。
3. **学习模型 + 经典控制**：用数据拟合难建模部分（摩擦、接触），再用 LQR/MPC。
4. **学习感知，经典控制执行**：视觉网络估计目标/状态，控制器照旧。这其实就是你 P4 的结构：学习做感知，规则与设备端闭环做执行。
5. **分层**：高层学习/LLM 决策，低层经典控制与安全层保证。

### 11.5 诚实的观点

PS 里"基于学习的控制是未来方向"是一个**趋势判断**，不是定论。目前公开成果显示，学习方法在腿足运动、灵巧操作等**难以精确建模、接触丰富**的任务上展现出强表现；但在工业与大量机器人产品中，经典控制（PID/LQR/MPC）依然是主力，因为可预测、可调试、有分析工具、实时性好、约束与安全更容易保证。更可能的未来是**两者结合**，而不是一方取代另一方。面试里表达这个立场比"学习会取代传统控制"更成熟，也更安全。

对你自己：你的优势恰恰是懂经典控制栈的每一环（状态估计、限幅、饱和、接触切换、硬件安全回路），而这些正是学习控制落地时最需要的"工程底座"；你的缺口是学习算法本身的实践，这正是想读研补的部分。

## 13. 常见错误与故障现象

| 现象 | 原因 | 对策 |
|---|---|---|
| 训练奖励高，真实行为怪 | 奖励被钻空子 | 重新设计奖励；多指标评估；人工回放检查 |
| 仿真很好，真机差 | 现实差距 | 域随机化、系统辨识、延迟建模、少量真机适配 |
| 训练不稳定、突然崩溃 | 步长过大；价值估计差 | 用 PPO 类约束；检查优势归一化 |
| 样本效率极低 | on-policy、探索不足 | off-policy、模型法、更好的探索、示范预热 |
| 行为克隆越跑越偏 | 分布偏移 | DAgger、加数据增强/噪声注入、动作分块 |
| 策略输出直接下发电机导致冲击 | 缺少限幅/低层闭环 | 输出限幅、速率限制、下层位置/力矩闭环、安全状态机 |
| 把仿真成功说成实机验证 | 表述错误 | 区分仿真/真机，报告条件 |
| 把 RL 的 Q 与 LQR 的 Q 搞混 | 同名异义 | 明确"动作价值函数 vs 状态权重矩阵" |

## 14. 面试问答（英文）

**Q1. Do you have experience with reinforcement learning?**

> Not in production. My robot work so far uses classical control: cascaded PID, LQR, VMC and MPC. I am studying reinforcement and imitation learning to move toward learning-based control. I understand the formulation, for example that LQR is the exactly solvable special case of the Bellman equation with linear dynamics and quadratic cost, and I know the main practical issues such as sim-to-real and safety.

中文要点：如实说没有生产级经验；做的是经典控制；正在学；能讲清 LQR 与 Bellman 的关系和实际问题。
追问：*Can you show me the connection?* — 价值函数猜 $Px^2$，代入 Bellman，得 Riccati 方程。

**Q2. Explain Q-learning and why it is off-policy.**

> Q-learning updates the action-value with the target reward plus gamma times the maximum Q of the next state, minus the current value, scaled by a learning rate. Because the target uses the max rather than the action the behaviour policy actually took, it learns the value of the greedy policy while it can explore with a different policy, so it is off-policy.

**Q3. What is PPO and why is it popular for robot training in simulation?**

> PPO is a policy-gradient method that limits how far the new policy moves from the old one by clipping the probability ratio in the objective. This makes updates stable and simple to implement. It pairs well with massive parallel simulation, but it is on-policy and sample-hungry, so it is mostly used in simulation rather than directly on hardware.

**Q4. What is the sim-to-real gap and how do people reduce it?**

> The simulator differs from reality in dynamics parameters, contact, actuator behaviour, delay and sensor noise. Common mitigations are domain randomization, system identification, modelling the actuators, and adding a safety layer. Randomization improves robustness over a range but is not a safety proof.

**Q5. Will learning-based control replace classical control?**

> I think they will complement each other. Learning is strong where contact or modelling is hard and where perception is involved, but classical controllers give predictability, constraint handling and analysis tools. A practical design is a learned policy or planner on top of a classical low-level controller with an independent safety layer.

**Q6. How does imitation learning suffer from distribution shift?**

> A behaviour-cloning policy is trained on states visited by the expert, but at deployment its small errors take it to states the expert never showed, where it errs more. Errors compound over time. DAgger addresses this by letting the learner run and asking the expert to label the states it actually visits.

## 15. 自测题

1. 奖励序列 $[2,0,4]$，$\gamma=0.5$，回报？
   **答案**：$2+0+0.25\times4=3$。
2. 写出 Bellman 最优方程中 $Q^*(s,a)$ 的递推形式。
   **答案**：$Q^*(s,a)=\sum_{s'}P(s'|s,a)[r+\gamma\max_{a'}Q^*(s',a')]$。
3. Q-learning：$Q(s,a)=1.0$，$r=0.5$，$\max Q(s',\cdot)=2.0$，$\gamma=0.9$，$\alpha=0.1$，新 $Q$？
   **答案**：目标 $0.5+1.8=2.3$，误差 $1.3$，新值 $1+0.13=1.13$。
4. PPO，$\epsilon=0.2$，$r=0.9$，$A=+1$，梯度是否被裁剪？$r=1.3,A=+1$ 呢？
   **答案**：$r=0.9\in[0.8,1.2]$ 未裁剪，梯度非零；$r=1.3>1.2$，$\min(1.3,1.2)=1.2$ 被裁剪，梯度为 0。
5. 为什么策略梯度不需要知道环境转移模型？
   **答案**：轨迹概率中转移项不含策略参数 $\theta$，对 $\log P_\theta(\tau)$ 求梯度时消失，只剩 $\sum\nabla\log\pi_\theta$。
6. 标量 LQR：$a=1,b=1,q=1,r=1$ 的 Riccati 方程是什么？$P$ 是多少？
   **答案**：$P=1+P-P^2/(1+P)$ → $P^2/(1+P)=1$ → $P^2-P-1=0$ → $P=(1+\sqrt5)/2=1.618$；$K=P/(1+P)=0.618$。
7. 为什么不能把 VLA 大模型直接输出的动作不经处理送到电机？
   **答案**：推理延迟和频率不满足底层闭环，输出没有安全保证；需要限幅、速率限制、低层高频控制和独立的安全检查。
8. 用一句话区分 on-policy 与 off-policy。
   **答案**：on-policy 用当前策略采集的数据更新当前策略；off-policy 可以用其他策略（或历史）采集的数据。
9. 每步奖励 $r=v_x-0.5|\theta|+b$，其中 $b$ 是存活项。若机器人稳走时每步 $v_x-0.5|\theta|=0.475$，摔倒前的最后一步为 $-0.1$ 并终止，回合最长 100 步。$b=+1$ 与 $b=-1$ 各会鼓励什么行为？
   **答案**：$b=+1$：稳走每步 $1.475$，100 步累计 $147.5$，摔倒只得 $0.9$，鼓励活得久；$b=-1$：稳走每步 $-0.525$，100 步累计 $-52.5$，摔倒一步 $-1.1$ 立即终止更划算，策略会学会"尽快摔倒"。存活项的符号会彻底改变行为，这是奖励设计的经典陷阱。
10. 为什么 Q-learning 更新终止状态时不加 $\gamma\max Q(s',\cdot)$？
   **答案**：终止后没有未来奖励，其后继价值为 0；加上会错误地把不存在的价值回传。

## 本章要点速记

1. MDP $=(\mathcal S,\mathcal A,P,R,\gamma)$；回报 $G=\sum\gamma^kr_{k+1}$；目标最大化期望回报。
2. $V,Q,A$：$V$ 状态价值，$Q$ 动作价值，$A=Q-V$ 优势。
3. Bellman：价值 = 一步奖励 + 折扣后的下一价值；最优方程把 $\sum_a\pi$ 换成 $\max_a$。
4. Q-learning 用 $\max$ 做目标，所以 off-policy；DQN 用经验回放和目标网络，仅适用离散动作。
5. 策略梯度 $E[\nabla\log\pi\cdot G]$；转移模型在梯度中消失；基线/优势降方差；GAE 折中偏差方差。
6. PPO 用 ratio 裁剪限制更新幅度，稳定易实现，但 on-policy、样本效率低。
7. Sim-to-real：现实差距来自动力学、接触、执行器、延迟、噪声；域随机化不是安全证明；安全层必须独立。
8. 行为克隆有分布偏移，DAgger 让专家标注学习者访问的状态；遥操作/示教是示范数据的入口。
9. VLA = VLM 骨干 + 动作头；受数据、延迟、安全限制，需要低层高频控制兜底。
10. LQR 是线性二次情形下 Bellman 方程的解析解（Riccati）；学习与经典控制互补：残差、调参、学习模型、学习感知、分层；诚实表述自己的经验边界。
