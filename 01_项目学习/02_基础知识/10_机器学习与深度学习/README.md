# 机器学习与深度学习：学习顺序与前置关系

> **一句话定位**：从线性回归到大模型与具身智能：机器学习基础、神经网络、CNN/检测、量化部署、Transformer/LLM/Agent、强化学习、模仿学习与 VLA。

**本模块学完你能：**

- 手算线性回归、逻辑回归、反向传播；
- 解释 CNN/检测/量化部署；
- 解释 Transformer、LLM 训练流水线、LoRA、RAG；
- 推导策略梯度与 PPO，说明 sim-to-real；
- 解释模仿学习、扩散策略与 VLA 的取舍。

**前置知识**：[概率统计与高斯分布](../01_数学基础/03_概率统计与高斯分布.md)、[最优化与二次规划](../01_数学基础/04_最优化与二次规划.md)、[线性代数](../01_数学基础/01_线性代数.md)。
