# 嵌入式与通信：学习顺序与前置关系

> **一句话定位**：代码怎样在芯片上实时跑、怎样与电机和上位机通信：STM32、FreeRTOS、CAN/FDCAN、串口/SPI/I2C/以太网、电机驱动与平台基础。

**本模块学完你能：**

- 配置时钟、GPIO、定时器、中断与 DMA；
- 解释 FreeRTOS 任务调度与同步；
- 手算 CAN 波特率与帧时间、总线负载；
- 解释编码器、驱动与力矩控制链；
- 了解 OpenHarmony/Hi3861/RK3588 平台差异。

**前置知识**：[数字控制与实时性](../05_控制理论/08_数字控制与实时性.md)。
