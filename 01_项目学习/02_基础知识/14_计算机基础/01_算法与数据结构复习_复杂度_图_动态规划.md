## 1. 要解决什么问题

面试官问算法题，真正想测的不是你背过多少题，而是三件事：

1. **你能不能估计代价**：同样是"找最近的障碍物"，遍历 $10^6$ 个栅格与用 KD 树查询，差的是几个数量级。能把"这段代码在数据变大十倍时慢多少"说出来，就是复杂度意识。
2. **你能不能给出正确性论证**：写出代码不难，难的是说明"为什么这个贪心不会错""为什么动态规划按这个顺序填表是对的"。
3. **你能不能把算法接到真实系统**：路径规划的 A\*、数据流里的优先队列、日志去重里的哈希，都是同一批基础结构。

因此本章每个算法都按"问题—不变量—代价—反例"的顺序讲，而不是只贴代码。

> **提示**：面试时先说思路和复杂度，再写代码；写完用一个小例子手动跑一遍。这个习惯本身就是考察点。

## 2. 符号与术语

| 符号 / 术语 | 含义 |
|---|---|
| $n$ | 输入规模（元素个数，或顶点数） |
| $V, E$ | 图的顶点数与边数；$G=(V,E)$ |
| $O(f)$ | 渐近上界："不比 $f$ 增长更快" |
| $\Omega(f)$ | 渐近下界 |
| $\Theta(f)$ | 紧确界：既是 $O(f)$ 又是 $\Omega(f)$ |
| 最坏 / 平均 / 均摊 | 对最糟输入 / 对输入分布取期望 / 对一串操作取平均（不涉及概率） |
| 稳定排序 | 相等键的元素排序后相对顺序不变 |
| 原地（in-place） | 额外空间 $O(1)$（或 $O(\log n)$ 的递归栈） |
| 循环不变量 | 每轮循环开始前都成立的命题，用来证明正确性 |
| 最优子结构 | 问题的最优解包含子问题的最优解 |
| 重叠子问题 | 递归中同一子问题被重复求解，是用 DP 的信号 |

注意 $O$ 只是**上界**。"快排是 $O(n^2)$"是对的（最坏情况），"快排是 $O(n\log n)$"通常指平均或期望；面试里要说明你指的是哪一种。

## 3. 复杂度分析：渐近记号、递推、均摊

### 3.1 渐近记号的定义

$f(n)=O(g(n))$ 当且仅当存在常数 $c>0$ 与 $n_0$，使得对所有 $n\ge n_0$ 有 $0\le f(n)\le c\,g(n)$。

例：证明 $3n^2+10n=O(n^2)$。取 $c=4$，当 $n\ge 10$ 时 $10n\le n^2$，所以 $3n^2+10n\le 4n^2$。这一步看起来平凡，但它说明了渐近记号**忽略常数与低次项**，所以 $O$ 不能用来比较同阶算法的实际快慢；工程上两个 $O(n)$ 算法可能差十倍（缓存行为不同，见 [体系结构一章](./04_计算机体系结构_缓存_流水线_SIMD_GPU.md)）。

常见增长阶的排序（从小到大）：

$$1 \ll \log n \ll \sqrt n \ll n \ll n\log n \ll n^2 \ll n^3 \ll 2^n \ll n!$$

给一个直观感觉（$\log$ 取以 2 为底，Python 复核）：$n=10^3$ 时 $n\log_2 n\approx 9966$，$n^2=10^6$；$n=10^6$ 时 $n\log_2 n\approx 2.0\times10^7$，而 $n^2=10^{12}$。在每秒约 $10^8\sim10^9$ 次简单操作的粗略假设下（教学估计，非实测），$n=10^6$ 的 $n\log n$ 算法是零点几秒，$n^2$ 算法是数小时。这就是为什么面试看到 $n\le10^5$ 就要想 $O(n\log n)$。

### 3.2 循环的复杂度怎么数

- 单层循环 $n$ 次，每次 $O(1)$：$O(n)$。
- 双层循环，内层 $j$ 从 $i$ 到 $n$：总次数 $\sum_{i=1}^{n}(n-i+1)=\frac{n(n+1)}{2}=\Theta(n^2)$。
- 循环变量每次翻倍（$i=1,2,4,\dots$）：次数 $\lfloor\log_2 n\rfloor+1$，复杂度 $O(\log n)$。
- 调和级数：$\sum_{i=1}^n \frac{n}{i}=n H_n=\Theta(n\log n)$，筛法（埃氏筛）复杂度的来源之一。

### 3.3 解递推：主定理

分治算法的代价满足 $T(n)=aT(n/b)+f(n)$：把规模 $n$ 的问题拆成 $a$ 个规模 $n/b$ 的子问题，合并代价 $f(n)$。令 $n^{\log_b a}$ 为"叶子总数的量级"（递归树有 $\log_b n$ 层，第 $k$ 层有 $a^k$ 个节点，叶子层有 $a^{\log_b n}=n^{\log_b a}$ 个）。比较它与 $f(n)$：

1. 若 $f(n)=O(n^{\log_b a-\varepsilon})$（叶子主导）：$T(n)=\Theta(n^{\log_b a})$；
2. 若 $f(n)=\Theta(n^{\log_b a})$（每层同阶）：$T(n)=\Theta(n^{\log_b a}\log n)$；
3. 若 $f(n)=\Omega(n^{\log_b a+\varepsilon})$ 且正则（根主导）：$T(n)=\Theta(f(n))$。

**归并排序**：$a=2,b=2,f(n)=\Theta(n)$，$n^{\log_2 2}=n$，属第 2 种，$T(n)=\Theta(n\log n)$。直观推导（不用主定理）：递归树共 $\log_2 n$ 层，每层所有节点合并代价合计 $\Theta(n)$，所以总代价 $n\log n$。

**二分查找**：$T(n)=T(n/2)+O(1)$，$a=1,b=2$，$n^{0}=1=f(n)$，属第 2 种，$T(n)=\Theta(\log n)$。

**快速选择（quickselect）平均情形**：$T(n)=T(n/2)+O(n)$，根主导，$T(n)=\Theta(n)$。

### 3.4 均摊分析：动态数组为什么 push 是 $O(1)$

动态数组（如 C++ `vector`、Python `list`）满容时把容量翻倍并复制。单次扩容代价 $O(n)$，但一连串 $n$ 次 push 的总代价：复制次数为 $1+2+4+\dots+2^{k}\le 2n$（$k=\lfloor\log_2 n\rfloor$），再加上 $n$ 次直接写入，总计不超过 $3n$，平均每次 $O(1)$。这叫**均摊 $O(1)$**，它是对操作序列的平均，不依赖输入分布，所以比"平均情况"更强。

**势能法**（简述）：定义势能 $\Phi=2\cdot\text{size}-\text{capacity}$，普通 push 实际代价 1、势能增 2，均摊 3；扩容那次实际代价 $n+1$，势能由 $n$ 降到 $2$，均摊仍为常数。工程含义：在实时控制线程里，一次扩容可能造成偶发的几十微秒到毫秒级停顿，所以实时代码要**预先 `reserve`**（见 [FreeRTOS 与实时系统](../11_嵌入式与通信/11_实时调度理论_RMS_EDF_优先级反转.md) 中对最坏情况的强调）。

## 4. 排序：三种 $O(n\log n)$ 与下界

### 4.1 归并排序

**思想**：把数组分成两半，各自排好，再把两个有序序列合并。合并时双指针取较小者。

**循环不变量**（合并步骤）：每轮开始前，输出数组已经包含左右序列中最小的 $k$ 个元素且有序。证明：两个指针指向的是各自剩余部分的最小元素，较小者必是剩余元素中的最小值，放入输出后不变量保持。

- 时间：$\Theta(n\log n)$，**最好最坏都一样**；
- 空间：需要 $O(n)$ 辅助数组；
- 稳定：合并时若 `l[i] <= r[j]` 先取左边，则相等元素保持原顺序。

### 4.2 快速排序

**思想**：选一个基准（pivot），把数组划分为小于基准和大于基准两部分，递归。

- 平均 $\Theta(n\log n)$：若每次划分得到比例 $\alpha:(1-\alpha)$ 的两部分（$\alpha$ 为常数），递归树深度为 $\log_{1/(1-\alpha)}n$，每层代价 $\Theta(n)$。
- 最坏 $\Theta(n^2)$：每次选到最小/最大值，如对已排序数组固定选首元素，递推 $T(n)=T(n-1)+\Theta(n)$，解为 $\Theta(n^2)$。
- 对策：随机选基准，或"三数取中"。随机基准下，期望比较次数约 $2n\ln n\approx1.39\,n\log_2 n$。
- 空间：原地，递归栈期望 $O(\log n)$（先递归较小的一半可保证最坏栈深 $O(\log n)$）。
- **不稳定**：划分时的远距离交换会打乱相等元素的顺序。

### 4.3 堆排序与堆

**二叉堆**是用数组表示的完全二叉树：下标 $i$ 的父节点是 $\lfloor (i-1)/2\rfloor$，左右孩子 $2i+1, 2i+2$（0 起始）。最小堆要求父节点不大于子节点。

- 插入：放到末尾，向上"上浮"，$O(\log n)$；
- 取最小：取根，把末尾元素放到根，向下"下沉"，$O(\log n)$；
- **建堆是 $O(n)$ 而不是 $O(n\log n)$**：自底向上对每个非叶节点下沉，高度为 $h$ 的节点至多有 $\lceil n/2^{h+1}\rceil$ 个，下沉代价 $O(h)$，总和 $\sum_h \frac{n}{2^{h+1}}h=O(n\sum_h h/2^h)=O(n)$，因为 $\sum_{h\ge0}h/2^h=2$。

堆排序：建堆后反复取最大放到末尾，$\Theta(n\log n)$，原地，不稳定。实际中常比快排慢（访问跳跃、缓存不友好）。

### 4.4 比较排序的下界

任何只通过比较大小决定顺序的排序算法，其执行过程可画成**决策树**：每个内部节点是一次比较，每个叶子是一种输出排列。$n$ 个互异元素有 $n!$ 种可能的输入顺序，所以至少 $n!$ 个叶子。高度为 $h$ 的二叉树至多 $2^h$ 个叶子，所以 $2^h\ge n!$，即

$$h\ge \log_2(n!)=\Theta(n\log n)$$

（用 $n!\ge (n/2)^{n/2}$ 得 $\log_2 n!\ge \frac n2\log_2\frac n2$。）所以比较排序的最坏下界是 $\Omega(n\log n)$。想突破只能**不用比较**：计数排序（键为 $[0,k]$ 的整数，$O(n+k)$）、基数排序（按位，$O(d(n+k))$）。

### 4.5 选哪个？一张表

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 | 备注 |
|---|---|---|---|---|---|---|
| 插入排序 | $n$ | $n^2$ | $n^2$ | $O(1)$ | 是 | 小数组、近乎有序时最快 |
| 归并排序 | $n\log n$ | $n\log n$ | $n\log n$ | $O(n)$ | 是 | 外部排序、链表排序 |
| 快速排序 | $n\log n$ | $n\log n$ | $n^2$ | $O(\log n)$ | 否 | 通用默认，缓存友好 |
| 堆排序 | $n\log n$ | $n\log n$ | $n\log n$ | $O(1)$ | 否 | 最坏有保证、原地 |
| 计数 / 基数 | $n+k$ | $n+k$ | $n+k$ | $O(n+k)$ | 是 | 非比较，键范围受限 |

Python 的 `sorted` 使用 Timsort（归并 + 插入的混合，对已有序片段敏感，稳定）；C++ 的 `std::sort` 通常是 introsort（快排 + 堆排 + 插入），不稳定，需要稳定用 `std::stable_sort`。这些实现细节属于"常见实现"，版本差异未核对。

## 5. 查找与基本数据结构

### 5.1 二分查找与循环不变量

在有序数组 `a[lo..hi]` 中找目标 $t$。循环不变量：**若 $t$ 存在，则它的下标位于 `[lo, hi]` 内**。每次取 `mid=(lo+hi)//2`：若 `a[mid]<t`，则 `mid` 及左侧都不可能是目标，令 `lo=mid+1`；否则令 `hi=mid-1`。区间长度每次至少减半，故 $O(\log n)$。

易错点：(1) C 语言里 `(lo+hi)/2` 可能整数溢出，应写 `lo+(hi-lo)/2`；(2) 开闭区间要统一；(3) 求"第一个 $\ge t$ 的位置"要用 lower_bound 写法，不能用判相等就返回。

二分的更一般形式是**对答案二分**：只要判定函数 $\text{ok}(x)$ 单调（假…假真…真），就能二分出临界值。比如"最小的控制周期使得某任务集可调度"。

### 5.2 哈希表

**目标**：期望 $O(1)$ 的插入、查找、删除。核心是哈希函数把键映射到下标，**冲突**不可避免（鸽巢原理：键空间远大于桶数）。

- 链地址法：每个桶一条链表；负载因子 $\lambda=n/m$，期望查找代价 $O(1+\lambda)$；$\lambda$ 超过阈值就扩容并重新哈希（均摊 $O(1)$，与动态数组同理）。
- 开放寻址：冲突时探测下一个空位（线性探测、二次探测、双重哈希）。缓存友好，但删除要用墓碑标记，$\lambda$ 接近 1 时性能急剧恶化（线性探测期望探测次数约 $\tfrac12(1+\tfrac1{(1-\lambda)^2})$，未核对具体常数时记趋势即可）。
- 最坏 $O(n)$：所有键冲突。攻击者构造冲突键可造成拒绝服务，所以某些语言运行时对字符串哈希加随机种子。

### 5.3 优先队列与堆的应用

Top-K 问题：维护大小为 $K$ 的最小堆，遍历数据，若新元素大于堆顶则替换。时间 $O(n\log K)$，空间 $O(K)$，适合流式数据。多路归并也用堆：$k$ 个有序序列合并，$O(N\log k)$。Dijkstra 与 A\* 的开放表也是优先队列。

### 5.4 并查集（Union-Find）

维护若干不相交集合，支持 `find(x)`（所在集合的代表）和 `union(x, y)`。用"父指针森林"表示，加上**路径压缩**（`find` 时让节点直接指向根）与**按秩/大小合并**，单次操作均摊 $O(\alpha(n))$，$\alpha$ 是反阿克曼函数，对任何实际输入不超过 5。应用：Kruskal 最小生成树判环、连通分量、地图聚类（把相邻占据栅格合并成障碍物）。

### 5.5 其他常见结构速览

- 栈、队列、双端队列：括号匹配、BFS、滑动窗口最大值（单调队列，$O(n)$）。
- 平衡二叉搜索树（红黑树、AVL）：查找/插入/删除 $O(\log n)$，有序遍历，C++ `std::map` 通常基于红黑树。
- B 树 / B+ 树：多路平衡树，用于磁盘索引，见 [数据库与分布式一章](./07_数据库与分布式基础_一致性_时钟.md)。
- 字典树（Trie）：前缀匹配，ROS 话题名/路径匹配的思想来源（仅类比，非 ROS 实现）。
- KD 树：k 维空间最近邻，点云配准与 ICP 常用（延伸知识，参见 [SLAM 模块](../07_SLAM与建图/README.md)）。

## 6. 图算法

### 6.1 图的表示

- 邻接矩阵：$V\times V$ 的矩阵，空间 $O(V^2)$，判断边是否存在 $O(1)$，适合稠密图。
- 邻接表：每个顶点一个邻居列表，空间 $O(V+E)$，遍历邻居 $O(\deg)$，适合稀疏图。栅格地图的每个格子至多 8 个邻居，是典型稀疏图，所以导航里用隐式邻接表（邻居由坐标计算，不真的存边）。

### 6.2 BFS 与 DFS

BFS 用队列，按"层"扩展，**在无权图中第一次到达某点的路径就是最短路**（边数最少）。证明：队列里的顶点距离非递减，按层出队。时间 $O(V+E)$。

DFS 用栈或递归，沿一条路走到底再回溯。应用：连通分量、检测环、拓扑排序、强连通分量。时间 $O(V+E)$。递归 DFS 在嵌入式环境要注意栈深度（见 [操作系统一章](./02_操作系统_进程线程_内存_调度_同步.md) 的栈内存部分）。

### 6.3 拓扑排序

有向无环图（DAG）的线性序：对每条边 $u\to v$，$u$ 排在 $v$ 之前。Kahn 算法：不断取入度为 0 的顶点，删除其出边，更新邻居入度。若最后输出的顶点数小于 $V$，说明图里有环。时间 $O(V+E)$。应用：构建系统的依赖顺序（CMake 目标依赖、ament 包的依赖顺序，见 [CMake 与 ament](../12_机器人软件/11_CMake_ament_构建系统与依赖管理.md)）、ROS2 launch 的启动顺序、行为树/任务计划的前置关系。

### 6.4 Dijkstra：单源最短路

**问题**：非负权图，求从源点 $s$ 到所有点的最短距离。

**算法**：维护距离数组 $d[v]$（初值 $d[s]=0$，其余 $\infty$）和优先队列。每次取出 $d$ 最小且未定的顶点 $u$，**松弛**其出边：若 $d[u]+w(u,v)<d[v]$，更新 $d[v]$ 并入队。

**正确性（为什么对）**：用归纳法证明——每次从队列取出的顶点 $u$ 的 $d[u]$ 就是真实最短距离。假设不然，存在更短的路径，它必须离开"已确定集合 $S$"，设路径上第一个不在 $S$ 的点是 $y$，其前驱 $x\in S$。$d[y]\le d[x]+w(x,y)\le$ 路径到 $y$ 的长度 $\le$ 真实最短距离 $\le d[u]$（因为权非负，后续路径只增不减）。但 $u$ 是队列里 $d$ 最小的，所以 $d[u]\le d[y]$，两者夹逼得 $d[u]$ 已是最短。**这一步用到了"权非负"**——有负权边时，走得更远反而可能变短，"已确定"就不可靠。

**复杂度**：二叉堆实现为 $O((V+E)\log V)$；斐波那契堆可到 $O(E+V\log V)$（理论，实际常数大）；稠密图用数组选最小 $O(V^2)$。

**负权怎么办**：Bellman-Ford，对所有边重复松弛 $V-1$ 轮，$O(VE)$，还能通过第 $V$ 轮是否仍可松弛检测负环。所有点对最短路用 Floyd-Warshall，$O(V^3)$，状态是 $d_k[i][j]$ = 只允许经过前 $k$ 个中间点时的最短距离。

### 6.5 A\*：给 Dijkstra 加方向感

A\* 对顶点按 $f(n)=g(n)+h(n)$ 排序，$g$ 是起点到 $n$ 的已知代价，$h$ 是到目标的启发式估计。Dijkstra 就是 $h\equiv0$ 的特例。

- **可采纳（admissible）**：$h(n)\le h^*(n)$（真实代价），保证找到最优解。栅格上的欧氏距离、曼哈顿距离（四邻接）都可采纳。
- **一致（consistent）**：$h(n)\le c(n,n')+h(n')$，保证每个节点只需展开一次。
- 启发式越接近真实代价，展开节点越少；$h$ 过大（不可采纳）会更快但可能不最优。

详细的代价地图、Hybrid-A\* 的车辆约束见 [图搜索 Dijkstra 与 A\*](../08_规划与导航/01_图搜索_Dijkstra_A星.md) 与 [Hybrid A\* 与车辆运动学约束](../08_规划与导航/02_Hybrid_A星与车辆运动学约束.md)。

### 6.6 最小生成树

Kruskal：边按权升序，用并查集判断是否成环，不成环就加入，$O(E\log E)$。Prim：从一点出发，每次加入连接已选集合的最小边，用堆 $O(E\log V)$。"割性质"保证正确：任何割的最小横跨边必属于某棵最小生成树。

## 7. 动态规划：四步法与三个经典

### 7.1 什么时候用 DP

满足两点：**最优子结构**（大问题的最优解由小问题的最优解组成）与**重叠子问题**（朴素递归会重复计算）。例如斐波那契 $F(n)=F(n-1)+F(n-2)$：朴素递归是 $O(2^n)$，记忆化后每个 $F(k)$ 只算一次，$O(n)$。

### 7.2 四步法

1. **定义状态**：$dp[\cdots]$ 表示什么？要把"未来决策所需的全部信息"装进状态里（无后效性）。
2. **写转移方程**：当前状态由哪些更小的状态推出，取最优或求和。
3. **确定边界**：最小子问题的值。
4. **确定计算顺序**：保证算 $dp[x]$ 时依赖的状态都已算好（自底向上），或用记忆化递归。

最后再问：答案是 $dp$ 的哪一格？能不能压缩空间？

### 7.3 0/1 背包

$N$ 件物品，重量 $w_i$、价值 $v_i$，容量 $C$，每件至多选一次，最大化总价值。

- 状态：$dp[i][c]$ = 只考虑前 $i$ 件、容量 $c$ 时的最大价值；
- 转移：$dp[i][c]=\max\big(dp[i-1][c],\ dp[i-1][c-w_i]+v_i\big)$（不选 / 选）；
- 边界：$dp[0][c]=0$；
- 空间压缩：用一维 $dp[c]$，**内层 $c$ 必须倒序**。因为 $dp[c]$ 依赖上一轮的 $dp[c-w_i]$，倒序遍历时 $c-w_i<c$ 的位置还没被本轮覆盖；若正序，就变成"可重复选"的完全背包。

### 7.4 编辑距离

字符串 $a$ 变成 $b$ 的最少操作数（插入、删除、替换各 1 次）。

- 状态：$D[i][j]$ = $a$ 前 $i$ 个字符变成 $b$ 前 $j$ 个字符的最少操作数；
- 转移：$D[i][j]=\min\big(D[i-1][j]+1,\ D[i][j-1]+1,\ D[i-1][j-1]+[a_i\ne b_j]\big)$，三项分别是删除、插入、替换/匹配；
- 边界：$D[i][0]=i$，$D[0][j]=j$；
- 复杂度 $O(mn)$ 时间；只依赖上一行，可压成 $O(\min(m,n))$ 空间。

### 7.5 最长递增子序列（LIS）

序列 `[10, 9, 2, 5, 3, 7, 101, 18]` 的最长严格递增子序列长度。朴素 DP：$dp[i]=1+\max_{j<i,a_j<a_i}dp[j]$，$O(n^2)$。优化：维护数组 $t$，$t[k]$ 是长度为 $k+1$ 的递增子序列的**最小可能末尾**，$t$ 始终严格递增，所以每个新元素用二分找位置替换，$O(n\log n)$，最终 $|t|$ 即答案（注意 $t$ 本身不一定是一个真实的子序列）。

## 8. 贪心：交换论证

贪心每步选当前看起来最好的，且不回溯。它只在问题具有**贪心选择性质**（局部最优能扩展成全局最优）时才对。证明套路是**交换论证**：假设存在一个最优解不含贪心的第一步选择，把它里面的某个选择换成贪心的选择，证明代价不会变差。

**区间调度**：给定若干活动 $[s_i,e_i)$，选尽量多的互不重叠活动。贪心：按**结束时间**升序，能选就选。交换论证：设最优解的第一个活动是 $a$，贪心选的是结束最早的 $g$，$e_g\le e_a$。把最优解中的 $a$ 换成 $g$，仍与后面的活动不重叠，且数量不变。对剩余子问题归纳即可。

注意：按**开始时间**或按**时长**贪心都有反例。例如活动 $[0,10)$、$[1,2)$、$[3,4)$ 按开始时间选了第一个就只能选 1 个，最优是 2 个。

**贪心与 DP 的分界**：0/1 背包不能按"价值/重量比"贪心（反例：容量 4，物品 $(w,v)=(3,5),(2,3),(2,3)$，比值贪心先拿 $(3,5)$ 后装不下别的，总价值 5，而取后两件是 6）；但"分数背包"（物品可切分）可以。

### 9.1 Dijkstra 手算

图（有向，带权）：$S\to A:4$，$S\to B:1$，$B\to A:2$，$B\to C:5$，$A\to C:1$，$A\to D:5$，$C\to D:3$。

| 步骤 | 取出顶点 | $d[S]$ | $d[A]$ | $d[B]$ | $d[C]$ | $d[D]$ | 说明 |
|---|---|---|---|---|---|---|---|
| 初始 | - | 0 | $\infty$ | $\infty$ | $\infty$ | $\infty$ | |
| 1 | $S$ (0) | 0 | 4 | 1 | $\infty$ | $\infty$ | 松弛 $S\to A, S\to B$ |
| 2 | $B$ (1) | 0 | 3 | 1 | 6 | $\infty$ | $1+2=3<4$，更新 $A$；$1+5=6$ |
| 3 | $A$ (3) | 0 | 3 | 1 | 4 | 8 | $3+1=4<6$；$3+5=8$ |
| 4 | $C$ (4) | 0 | 3 | 1 | 4 | 7 | $4+3=7<8$ |
| 5 | $D$ (7) | 0 | 3 | 1 | 4 | 7 | 完成 |

### 9.3 0/1 背包手算

物品 $(w,v)$：$(1,1),(3,4),(4,5),(5,7)$，容量 $C=7$。一维 dp 倒序，每处理一件物品后数组（下标 $c=0..7$）：

```text
处理 (1,1): [0,1,1,1,1,1,1,1]
处理 (3,4): [0,1,1,4,5,5,5,5]
处理 (4,5): [0,1,1,4,5,6,6,9]
处理 (5,7): [0,1,1,4,5,7,8,9]
```

### 9.4 区间调度与归并排序

区间 `(1,4),(3,5),(0,6),(5,7),(3,9),(5,9),(6,10),(8,11),(8,12),(2,14),(12,16)` 按结束时间排序后贪心，选出 `(1,4),(5,7),(8,11),(12,16)`，共 4 个。对 `[5,2,9,1,5,6,3,8]` 做归并排序，得到 `[1,2,3,5,5,6,8,9]`，数据比较次数 17（Python 计数；$n=8$ 时理论范围是 $\lceil\log_2 8!\rceil=16$ 到 $n\log_2n-n+1=17$ 之间，吻合）。

### 9.5 可运行代码

```python
# 教学示例，非项目源码：Dijkstra（带惰性删除的堆）
import heapq

def dijkstra(graph, s):
    dist = {v: float("inf") for v in graph}
    dist[s] = 0
    pq = [(0, s)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:          # 过期条目，跳过（惰性删除）
            continue
        for v, w in graph[u].items():
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist

g = {"S": {"A": 4, "B": 1}, "B": {"A": 2, "C": 5},
     "A": {"C": 1, "D": 5}, "C": {"D": 3}, "D": {}}
print(dijkstra(g, "S"))   # {'S': 0, 'A': 3, 'B': 1, 'C': 4, 'D': 7}
```

"惰性删除"是因为 Python 的 `heapq` 不支持 decrease-key：更新时直接再压入一个新条目，出堆时丢弃过期的。这使堆中最多有 $E$ 个条目，复杂度仍是 $O((V+E)\log V)$。

## 11. 常见错误

1. **把 $O$ 当作 $\Theta$**：说"快排是 $O(n\log n)$"而没有说明是平均；面试官追问最坏会卡住。
2. **二分边界错误**：死循环（`lo=mid` 而 `mid` 向下取整）、漏掉最后一个元素、整数溢出。
3. **Dijkstra 用于负权边**：结果可能错且不报错。有负权就用 Bellman-Ford。
4. **0/1 背包内层正序**：不知不觉变成完全背包。
5. **DP 状态没有无后效性**：状态里缺了影响未来决策的信息（例如"上一步是否选了某物"），转移就不成立，需要多加一维。
6. **贪心没有证明**：靠直觉写贪心，被一个小反例推翻。至少举一个最简反例检验，再尝试交换论证。
7. **忽略输入规模约束**：$n=10^5$ 却写 $O(n^2)$。
8. **递归过深**：DFS 递归在深图上栈溢出；Python 默认递归深度上限约 1000，嵌入式栈更小。改用显式栈。
9. **哈希键用浮点数或可变对象**：浮点相等判断不可靠；Python 中 list 不能作 dict 键。栅格坐标要先量化为整数。
10. **混淆稳定性与原地**：稳定排序不等于原地，反之亦然。

## 12. 英文面试问答

### Q1. Explain Dijkstra's algorithm and its time complexity.

**参考答案**：

"Dijkstra finds the shortest path from one source to all other nodes in a graph with non-negative edge weights. I keep a distance estimate for every node and a priority queue ordered by that estimate. Each time I pop the node with the smallest distance, I know its distance is final, and I relax its outgoing edges: if going through this node is shorter, I update the neighbor. With a binary heap the time is O((V plus E) log V). The proof relies on non-negative weights: once a node is the smallest in the queue, any other path to it has to go through nodes that are at least as far away, so it can't be shorter."

中文要点：单源最短路、非负权；优先队列取最小；取出即最终；二叉堆 $O((V+E)\log V)$；正确性依赖权非负。

**可能的追问**：

- *"What if there are negative edges?"* — "Dijkstra can fail, because a node that was finalized could later be improved through a negative edge. I'd use Bellman-Ford, which is O(VE), and it can also detect negative cycles."（负权用 Bellman-Ford，可检测负环。）
- *"How is A star different?"* — "A star orders the queue by g plus h, where h is a heuristic estimate to the goal. If h is admissible, meaning it never overestimates, A star is still optimal and usually expands far fewer nodes. Dijkstra is the special case where h is zero."（A\* 用 $g+h$ 排序，$h$ 可采纳则仍最优，Dijkstra 是 $h=0$ 的特例。）
- *"Which heuristic did you use in your navigation project?"* — 这里诚实回答："In Hybrid A star I used the common approach of taking the larger of a Reeds-Shepp length that ignores obstacles and a 2D grid distance that accounts for obstacles; it stays admissible." 若细节记不清："I don't have every detail in front of me, but the idea is to stay admissible."

### Q2. Why is comparison-based sorting Omega(n log n)?

"Any comparison sort can be drawn as a binary decision tree where each leaf is one possible output order. With n distinct elements there are n factorial orders, so the tree needs at least n factorial leaves. A binary tree of height h has at most 2 to the h leaves, so h is at least log of n factorial, which is order n log n by Stirling's approximation. So in the worst case you need that many comparisons. Counting sort and radix sort avoid the bound because they don't compare elements; they use the key structure."

中文要点：决策树叶子数 $\ge n!$，高度 $\ge\log_2 n!=\Theta(n\log n)$；计数/基数排序不比较。

**追问**：*"Is quicksort really O(n log n)?"* — "On average, yes; the worst case is O(n squared), for example with a fixed pivot on sorted input. Random pivots or median-of-three make the bad case very unlikely, and introsort falls back to heap sort to guarantee O(n log n)."

### Q3. How would you decide between dynamic programming and a greedy algorithm?

"I first look for optimal substructure and overlapping subproblems. If a locally optimal choice can always be extended to a global optimum, a greedy works, and I try to prove it with an exchange argument, like choosing the earliest finishing activity in interval scheduling. If I can easily find a counterexample, like the 0/1 knapsack with a value-per-weight greedy, I switch to dynamic programming, where I define the state, the transition, the base case and the evaluation order."

中文要点：先找最优子结构和重叠子问题；能用交换论证证明就用贪心；一个反例就改 DP。

**追问**：*"Can you give a counterexample for the greedy knapsack?"* — "Capacity 4, items (weight, value) = (3,5), (2,3), (2,3). The ratio greedy takes the first item for 5 and cannot add anything; the best is the two small items for 6."

### Q4. Why is building a heap O(n) and not O(n log n)?

"Most nodes are near the bottom and sift down only a short distance. There are about n over 2 to the h plus one nodes of height h, each costing O(h). Summing h over 2 to the h converges to a constant, so the total is O(n). Inserting elements one by one is different, that is O(n log n)."

中文要点：高度 $h$ 的节点数约 $n/2^{h+1}$，下沉代价 $O(h)$，$\sum h/2^h$ 收敛为常数，总计 $O(n)$；逐个插入则是 $O(n\log n)$。

3. 动态数组扩容翻倍，总代价 $\le3n$，所以 push 均摊 $O(1)$；实时代码要预留容量。
4. 比较排序下界来自决策树：$\log_2 n!=\Theta(n\log n)$。
5. 快排平均 $n\log n$、最坏 $n^2$、不稳定；归并稳定但要 $O(n)$ 空间；堆排序原地但不稳定；建堆 $O(n)$。
6. 二分的关键是循环不变量与边界统一，也可对答案二分。
7. Dijkstra 依赖非负权；A\* 是 $g+h$，$h$ 可采纳则最优，$h=0$ 即 Dijkstra。
8. DP 四步：状态、转移、边界、顺序；0/1 背包一维倒序，完全背包正序。
9. 贪心要证明，交换论证是标准套路；区间调度按结束时间排序。
10. 并查集加路径压缩与按秩合并，均摊 $O(\alpha(n))$。

### 自测题

1. 证明 $\sum_{i=1}^{n}i=\Theta(n^2)$，并说明为什么 $O(n^2)$ 双层循环在 $n=10^5$ 时不可行。
   *要点*：求和为 $n(n+1)/2$；次数约 $5\times10^9$，在每秒约 $10^8\sim10^9$ 次操作的粗估下需数秒到数十秒，且常数还会放大。
2. 用主定理分析 $T(n)=4T(n/2)+n$ 与 $T(n)=2T(n/2)+n^2$。
   *要点*：前者 $n^{\log_2 4}=n^2\gg n$，叶子主导，$\Theta(n^2)$；后者 $n^2\gg n$，根主导，$\Theta(n^2)$。
3. 在图 $S\to A:2$，$S\to B:3$，$B\to A:-2$ 上运行标准 Dijkstra（已确定的顶点不再更新），说明哪里出错。
   *要点*：先取出 $A$（距离 2）并视为最终；随后取出 $B$（3），发现经 $B\to A$ 到 $A$ 的距离是 $1<2$，但 $A$ 已被定下，真实最短距离 1 被漏掉；负权破坏"取出即最终"。
4. 为什么 0/1 背包一维 dp 内层要倒序？写出正序时实际求解的问题。
   *要点*：正序会让同一物品在本轮被多次使用，变成完全背包。
5. 区间调度按"最短时长优先"贪心的反例是什么？
   *要点*：区间 $[0,5)$、$[4,6)$、$[5,10)$ 中最短的是 $[4,6)$，它与另两个都重叠，只能选 1 个，而最优是 $[0,5)$ 和 $[5,10)$ 共 2 个。
