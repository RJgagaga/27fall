## 一、复杂度与基础结构

### Q1 时间复杂度、空间复杂度怎么算？Big-O 是什么意思？（Time/space complexity and Big-O）
**优先级：★★★**

**答案要点**
- Big-O 描述输入规模 $n$ 增大时，操作次数的**增长上界**，忽略常数和低阶项。$3n^2+5n+7 = O(n^2)$。
- 计算方法：单层循环 $O(n)$；嵌套循环相乘；每次问题规模减半 $O(\log n)$；分治用主定理。
- 主定理：$T(n)=aT(n/b)+f(n)$。归并排序 $a=2,b=2,f=n$，得 $O(n\log n)$。
- 摊还分析（amortized）：动态数组 push_back 偶尔扩容 $O(n)$，但均摊 $O(1)$。证明：每次翻倍，前 $n$ 次总拷贝量 $\le 2n$。
- 空间复杂度包括递归栈深度，如 DFS 递归是 $O(h)$。

**English short answer**
Big-O describes how the running time grows with input size in the worst case, ignoring constants. For example, a single loop is O(n), nested loops are O(n squared), and binary search is O(log n). Some operations are better described by amortized cost, like appending to a dynamic array, which is O(1) on average even though a resize costs O(n). I always also check space, including the recursion stack.

**追问方向**：最好/平均/最坏复杂度区别；快排最坏 $O(n^2)$ 怎么避免；$O$ 与 $\Theta$ 与 $\Omega$ 的区别。

### Q2 数组和链表的区别？（Array vs linked list）
**优先级：★★★**

**答案要点**
- 数组：连续内存，随机访问 $O(1)$，中间插入删除 $O(n)$（要搬移），缓存友好（cache locality）。
- 链表：节点用指针串联，插入删除（已知节点）$O(1)$，随机访问 $O(n)$，每个节点额外存指针，缓存不友好。
- 工程上多数场景数组（vector）反而更快，因为 CPU cache 预取对连续内存很有效，链表只在频繁头尾/中间插入且持有迭代器时才有优势。
- 嵌入式中链表常用于 RTOS 的任务就绪队列、内存池空闲块链。

**English short answer**
An array stores elements contiguously, so indexing is O(1) but inserting in the middle is O(n). A linked list connects nodes with pointers, so inserting or deleting at a known node is O(1) but lookup is O(n). In practice arrays are often faster because of cache locality. I would choose a linked list only when I need frequent insertions and deletions with stable iterators.

**追问方向**：为什么 std::vector 比 std::list 快；双向链表如何删除节点；数组扩容策略。

### Q3 如何判断链表有环？如何找环入口？（Detect a cycle in a linked list）
**优先级：★★★**

**答案要点**
- 快慢指针（Floyd）：slow 每次 1 步，fast 每次 2 步，若有环必相遇。
- 找入口：设头到入口距离 $a$，入口到相遇点 $b$，环长 $L$。相遇时 slow 走 $a+b$，fast 走 $2(a+b)$，差为环长整数倍：$a+b = kL$，所以 $a = kL-b$。让一个指针回头，另一个从相遇点出发，同速前进，必在入口相遇。
- 时间 $O(n)$，空间 $O(1)$；哈希表法空间 $O(n)$。

```python
def detect_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:
            p = head
            while p is not slow:
                p, slow = p.next, slow.next
            return p
    return None
```

**English short answer**
I use two pointers: a slow one moving one step and a fast one moving two steps. If there is a cycle they must meet. To find the entry, I reset one pointer to the head and move both one step at a time; they meet at the cycle entrance. It is O(n) time and O(1) space.

**追问方向**：为什么 fast 走 2 步而不是 3 步；反转链表；合并有序链表。

### Q4 栈和队列的区别与应用？（Stack vs queue）
**优先级：★★★**

**答案要点**
- 栈 LIFO：函数调用栈、括号匹配、DFS、表达式求值、撤销。队列 FIFO：BFS、任务调度、消息缓冲。
- 实现：数组或链表均可。循环队列（ring buffer）用 `head`、`tail` 取模，满/空判断要留一个空位或用计数。
- 单调栈：求下一个更大元素，$O(n)$。
- 机器人/嵌入式：串口接收缓冲常用环形队列；传感器消息队列。

```c
// 教学示例：环形缓冲区（单生产者单消费者）
typedef struct { uint8_t buf[N]; volatile uint32_t head, tail; } ring_t;
int push(ring_t *r, uint8_t v){ uint32_t n=(r->head+1)%N; if(n==r->tail) return -1; r->buf[r->head]=v; r->head=n; return 0; }
```

**English short answer**
A stack is last-in first-out, used for function calls, DFS and bracket matching. A queue is first-in first-out, used for BFS and buffering messages. In embedded work I often use a ring buffer as a queue between an interrupt and the main loop. Both can be implemented with arrays or linked lists.

**追问方向**：用两个栈实现队列；单调栈；环形队列的并发安全。

### Q5 哈希表的原理？冲突怎么解决？（Hash table and collision handling）
**优先级：★★★**

**答案要点**
- 哈希函数把 key 映射成数组下标。平均查找/插入/删除 $O(1)$，最坏 $O(n)$。
- 冲突解决：①链地址法（拉链，Java HashMap、C++ unordered_map 通常如此）；②开放寻址（线性探测、二次探测、双重哈希，Python dict 采用开放寻址变体）。
- 负载因子 $\alpha = n/m$，超阈值（如 0.75）则 rehash 扩容，均摊 $O(1)$。
- 好的哈希函数要均匀、快速、确定。攻击者可构造冲突（hash flooding）使其退化。
- 无序，不支持范围查询；需要有序用平衡树。

**English short answer**
A hash table maps keys to array indices through a hash function, giving average O(1) lookup, insertion and deletion. Collisions are handled by chaining, where each bucket holds a list, or open addressing, where we probe for the next free slot. When the load factor gets high we rehash into a bigger table. The worst case is O(n), and hash tables do not keep order.

**追问方向**：rehash 过程；为何 unordered_map 迭代器可能失效；一致性哈希。

### Q6 动态数组（vector / list）怎么扩容？（Dynamic array growth）
**优先级：★★**

**答案要点**
- 容量不够时申请 $2\times$（或 1.5×）新内存，拷贝/移动旧元素，释放旧内存。均摊 $O(1)$。
- 1.5 倍的好处：释放的旧块之和有机会被复用；2 倍则永远小于下一次需求。
- 扩容使迭代器、指针、引用全部失效。已知大小要 `reserve`。
- C++ 中若元素移动构造声明 `noexcept`，vector 才会用 move 而不是 copy。

**English short answer**
When a dynamic array is full, it allocates a larger block, usually double or 1.5 times, copies the elements over and frees the old block. That makes push_back amortized O(1). Reallocation invalidates pointers and iterators, so if I know the size in advance I call reserve.

**追问方向**：Python list 的 over-allocation；shrink_to_fit。

### Q7 如何用栈检查括号匹配？（Valid parentheses）
**优先级：★★**

**答案要点**：遇左括号入栈，遇右括号看栈顶是否匹配并弹出，最后栈空为合法。$O(n)$。

```python
def valid(s):
    pair = {')':'(', ']':'[', '}':'{'}
    st = []
    for c in s:
        if c in pair:
            if not st or st.pop() != pair[c]: return False
        else: st.append(c)
    return not st
```

**English short answer**
I push every opening bracket onto a stack. For each closing bracket I pop the stack and check that the types match. At the end the stack must be empty. It runs in linear time.

**追问方向**：最长有效括号；表达式求值。

### Q8 LRU 缓存怎么实现？（Design an LRU cache）
**优先级：★★★**

**答案要点**
- 哈希表 + 双向链表。哈希表 key → 节点，$O(1)$ 找到；链表头是最近使用，尾是最久未用。
- get：命中则移到头部；put：存在则更新并移头，不存在则插头，超容量就删尾并同时删哈希项。全部 $O(1)$。
- Python 可用 `OrderedDict.move_to_end`。

```python
from collections import OrderedDict
class LRU:
    def __init__(s, cap): s.c, s.d = cap, OrderedDict()
    def get(s, k):
        if k not in s.d: return -1
        s.d.move_to_end(k); return s.d[k]
    def put(s, k, v):
        s.d[k] = v; s.d.move_to_end(k)
        if len(s.d) > s.c: s.d.popitem(last=False)
```

**English short answer**
I combine a hash map and a doubly linked list. The map gives O(1) access to nodes, and the list keeps them in usage order, with the most recent at the head. On every access I move the node to the head, and when the cache is full I evict the tail. Both get and put are O(1).

**追问方向**：线程安全；LFU；缓存穿透击穿。

### Q9 位运算常用技巧？（Bit manipulation tricks）
**优先级：★★**

**答案要点**
- 判奇偶 `x&1`；乘除 2 `<<1 >>1`；清最低位 1 `x&(x-1)`（统计 1 的个数、判 2 的幂 `x&(x-1)==0`）；取最低位 1 `x&-x`。
- 异或：`a^a=0`，找只出现一次的数；交换不需临时变量（不推荐）。
- 嵌入式中置位清位翻转，见 [C语言与嵌入式八股](./04_C语言与嵌入式八股.md)。

**English short answer**
Useful tricks are: x and 1 checks parity, x and (x minus 1) clears the lowest set bit, which also tests for a power of two, and XOR cancels equal values so it finds the single non-repeating number. Bit operations are also essential for register manipulation in embedded code.

**追问方向**：汉明权重；位图（bitmap）去重；布隆过滤器。

### Q10 布隆过滤器是什么？（Bloom filter）
**优先级：★**

**答案要点**：用 $m$ 位位数组和 $k$ 个哈希函数；插入时把 $k$ 个位置置 1；查询时全 1 才"可能存在"。有假阳性无假阴性，不支持删除（计数布隆可）。空间极省。

**English short answer**
A Bloom filter is a compact probabilistic set. It uses a bit array and several hash functions. It can say an item is definitely absent or possibly present, so it has false positives but no false negatives.

**追问方向**：假阳性率公式；使用场景（缓存穿透）。

## 二、树与堆

### Q11 二叉树的遍历方式及非递归实现？（Binary tree traversals）
**优先级：★★★**

**答案要点**
- 前序（根左右）、中序（左根右）、后序（左右根）、层序（BFS）。
- 递归简单；非递归用显式栈。中序：一路向左入栈，弹出访问，转右子树。
- 二叉搜索树中序遍历是**升序**。
- 复杂度 $O(n)$，空间 $O(h)$。

```python
def inorder(root):
    st, res, cur = [], [], root
    while cur or st:
        while cur: st.append(cur); cur = cur.left
        cur = st.pop(); res.append(cur.val); cur = cur.right
    return res
```

**English short answer**
There are four classic orders: preorder, inorder, postorder using DFS, and level order using BFS. For the iterative version I use an explicit stack: go left as far as possible, pop to visit, then move to the right child. Inorder traversal of a binary search tree gives sorted output. All are O(n) time.

**追问方向**：Morris 遍历 $O(1)$ 空间；由前序+中序重建树；最近公共祖先。

### Q12 二叉搜索树（BST）的性质与退化？（BST properties）
**优先级：★★★**

**答案要点**：左子树所有值 < 根 < 右子树所有值。查找/插入/删除平均 $O(\log n)$，插入有序序列会退化成链，$O(n)$。删除分三种：叶子、单孩子、双孩子（用后继或前驱替换）。所以需要平衡树。

**English short answer**
A binary search tree keeps smaller keys on the left and larger keys on the right, so search, insert and delete take O(height). If you insert sorted data it degenerates into a linked list with O(n) operations. That is why we use self-balancing trees such as AVL or red-black trees.

**追问方向**：验证 BST（区间法）；删除双孩子节点。

### Q13 AVL 树与红黑树？（AVL vs red-black tree）
**优先级：★★★**

**答案要点**
- AVL：任意节点左右子树高度差 $\le 1$，严格平衡。失衡时用 LL/RR/LR/RL 四种旋转修复。查询最快，但插入删除旋转更多。
- 红黑树：节点红/黑，性质：根黑；红节点孩子必黑；任意路径黑节点数相同。由此最长路径 $\le$ 2 倍最短路径，近似平衡，插入最多 2 次旋转，删除最多 3 次。
- 工程选择：红黑树用于 `std::map/set`、Linux CFS 调度器、epoll 的就绪事件；AVL 适合读多写少。
- 直觉：红黑树是 2-3-4 树的二叉表示。

**English short answer**
AVL trees keep the height difference between subtrees at most one, so they are very strictly balanced and fast for lookup, but updates may need more rotations. Red-black trees use color rules to guarantee the longest path is at most twice the shortest, so they need fewer rotations on insert and delete. That is why std::map and the Linux scheduler use red-black trees. Both give O(log n) operations.

**追问方向**：旋转手画；为什么 map 不用哈希；跳表对比。

### Q14 B 树和 B+ 树？为什么数据库用 B+ 树？（B-tree vs B+ tree）
**优先级：★★★**

**答案要点**
- B 树：多路平衡搜索树，一个节点存多个 key，高度低，适合磁盘（一次 IO 读一页）。
- B+ 树：数据只存叶子，内部节点只做索引；叶子用链表串联。优点：①内部节点更小，扇出更大，树更矮；②范围查询顺序扫叶子链表；③每次查询路径长度稳定。
- 假设页 16KB，key 8B + 指针 6B，扇出约 1000，3 层可存约 $10^9$ 条（量级估算）。
- 见 [数据库与系统设计基础](./09_数据库与系统设计基础.md)。

**English short answer**
A B-tree is a balanced multi-way tree where each node holds many keys, which keeps the tree shallow and suits disk page reads. A B-plus tree stores all data in the leaves and keeps only keys in internal nodes, with leaves linked in a list. This gives a higher fan-out and makes range queries fast, which is why databases use it for indexes.

**追问方向**：节点分裂过程；LSM 树对比。

### Q15 堆（优先队列）的实现与建堆复杂度？（Heap and priority queue）
**优先级：★★★**

**答案要点**
- 完全二叉树存在数组里，节点 $i$ 的父 $\lfloor (i-1)/2\rfloor$，孩子 $2i+1, 2i+2$。
- 插入：放末尾上浮 $O(\log n)$；弹出堆顶：末尾元素放顶下沉 $O(\log n)$。
- 建堆自底向上 sift-down 是 $O(n)$：高度为 $h$ 的节点最多下沉 $h$ 层，总和 $\sum_h \frac{n}{2^{h+1}} h = O(n)$；逐个插入则 $O(n\log n)$。
- Top-K 问题：维护大小为 $K$ 的小顶堆，$O(n\log K)$。

```python
import heapq
def topk(nums, k):
    h = []
    for x in nums:
        heapq.heappush(h, x)
        if len(h) > k: heapq.heappop(h)
    return h  # k largest
```

**English short answer**
A heap is a complete binary tree stored in an array where each parent is smaller than its children for a min-heap. Push and pop cost O(log n) by sifting up or down. Building a heap from an array bottom-up is O(n), not O(n log n). I use a heap of size k for top-k problems, and priority queues in algorithms like Dijkstra and A star.

**追问方向**：堆排序；中位数数据流（双堆）；合并 K 个有序链表。

### Q16 Trie（前缀树）是什么？（Trie）
**优先级：★★**

**答案要点**：每个节点存子节点映射，路径表示字符串前缀。插入/查询 $O(L)$，$L$ 为串长。用于自动补全、拼写检查、路由表最长前缀匹配。空间可能大，可用压缩 Trie。

**English short answer**
A trie stores strings along tree paths, so inserting or searching a word takes time proportional to its length, independent of how many words are stored. It is great for prefix queries such as autocomplete.

**追问方向**：与哈希表对比；IP 路由 LPM。

### Q17 并查集（Union-Find）？（Disjoint set union）
**优先级：★★**

**答案要点**：支持 find 和 union。路径压缩 + 按秩合并后，近似 $O(\alpha(n))$（反阿克曼函数，实际可视为常数）。应用：连通分量、Kruskal 最小生成树、判环。

```python
def find(p, x):
    while p[x] != x:
        p[x] = p[p[x]]; x = p[x]
    return x
```

**English short answer**
Union-find tracks which elements belong to the same set. With path compression and union by rank, each operation is nearly constant time. I use it for connected components and for Kruskal's minimum spanning tree.

**追问方向**：Kruskal vs Prim；栅格地图连通域。

### Q18 如何求二叉树的最近公共祖先（LCA）？（Lowest common ancestor）
**优先级：★★**

**答案要点**：递归：若当前节点为 p 或 q 返回自身；左右子树都返回非空则当前节点是 LCA；否则返回非空的一侧。$O(n)$。BST 可利用大小关系 $O(h)$。

**English short answer**
I recurse down the tree. If the current node is one of the targets, I return it. If both the left and right recursion return something, the current node is the LCA; otherwise I pass up whichever side is non-null.

**追问方向**：倍增法多次查询；Tarjan 离线。

### Q19 二叉树的深度、直径、是否平衡？（Depth, diameter, balanced）
**优先级：★★**

**答案要点**：最大深度 = 1 + max(左,右)。直径 = 每个节点左深+右深的最大值，后序遍历顺便更新全局答案。判平衡时后序返回高度，不平衡返回 -1 以剪枝，整体 $O(n)$ 而不是每节点重复算高度的 $O(n^2)$。

**English short answer**
I use a post-order traversal where each call returns the height of its subtree. For the diameter I update a global maximum with left height plus right height. For a balance check I return minus one as soon as a subtree is unbalanced, so the total is O(n).

**追问方向**：路径和；序列化二叉树。

### Q20 跳表（Skip list）是什么？（Skip list）
**优先级：★**

**答案要点**：多层有序链表，上层是下层的"快速通道"，每个节点以概率 1/2 晋升。查找/插入/删除期望 $O(\log n)$。比红黑树实现简单，范围查询方便，Redis 有序集合使用。

**English short answer**
A skip list is a layered linked list where upper levels skip over many nodes, giving expected O(log n) search. It is simpler than a balanced tree and supports range queries, so Redis uses it for sorted sets.

**追问方向**：层数如何随机；并发友好性。

## 三、图与搜索

### Q21 图的存储方式？（Graph representations）
**优先级：★★★**

**答案要点**
- 邻接矩阵：空间 $O(V^2)$，判边 $O(1)$，适合稠密图。
- 邻接表：空间 $O(V+E)$，遍历邻居高效，适合稀疏图（现实多数图）。
- 边列表：Kruskal、Bellman-Ford 用。
- 栅格地图本身隐式为图：4/8 邻接，不需要显式存边。

**English short answer**
An adjacency matrix uses V squared space and checks an edge in constant time, so it suits dense graphs. An adjacency list uses V plus E space and is better for sparse graphs. A grid map is an implicit graph where each cell connects to its four or eight neighbours.

**追问方向**：有向图/无向图；加权边。

### Q22 BFS 与 DFS 的区别与应用？（BFS vs DFS）
**优先级：★★★**

**答案要点**
- BFS 用队列，按层扩展，**无权图**最短路；空间 $O(V)$ 或最宽层。DFS 用栈/递归，空间 $O(h)$，适合连通性、拓扑排序、找环、回溯。
- 复杂度均为 $O(V+E)$。
- 网格最短路径用 BFS；岛屿数量用 DFS/BFS 均可。

```python
from collections import deque
def bfs(grid, s, t):
    q, seen = deque([(s,0)]), {s}
    while q:
        (x,y), d = q.popleft()
        if (x,y) == t: return d
        for dx,dy in ((1,0),(-1,0),(0,1),(0,-1)):
            n = (x+dx, y+dy)
            if 0<=n[0]<len(grid) and 0<=n[1]<len(grid[0]) and grid[n[0]][n[1]]==0 and n not in seen:
                seen.add(n); q.append((n,d+1))
    return -1
```

**English short answer**
BFS uses a queue and explores layer by layer, so it finds the shortest path in an unweighted graph. DFS uses a stack or recursion and goes deep first, which suits connectivity, cycle detection and topological sorting. Both run in O(V plus E).

**追问方向**：双向 BFS；迭代加深；岛屿问题。

### Q23 Dijkstra 算法原理与复杂度？（Dijkstra）
**优先级：★★★**

**答案要点**
- 贪心：每次从未确定节点中取距离源点最小者，确定其最短距离，并松弛其邻边。要求**边权非负**（负权时已确定节点可能被更优路径推翻）。
- 小根堆实现 $O((V+E)\log V)$；数组实现 $O(V^2)$。
- 可附带 `parent` 数组重建路径。

```python
import heapq
def dijkstra(g, s):
    dist = {s: 0}; pq = [(0, s)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist.get(u, float('inf')): continue
        for v, w in g[u]:
            nd = d + w
            if nd < dist.get(v, float('inf')):
                dist[v] = nd; heapq.heappush(pq, (nd, v))
    return dist
```

**English short answer**
Dijkstra repeatedly picks the unvisited node with the smallest known distance, fixes it, and relaxes its outgoing edges. It requires non-negative weights. With a binary heap it runs in O((V plus E) log V). It is the base of A star, which adds a heuristic.

**追问方向**：为何不能有负权；Bellman-Ford；Floyd-Warshall。

### Q24 A* 算法与 Dijkstra 的关系？启发函数要求？（A star）
**优先级：★★★**

**答案要点**
- $f(n)=g(n)+h(n)$：$g$ 已走代价，$h$ 到目标的估计。$h=0$ 退化为 Dijkstra。
- 可采纳（admissible）：$h(n)\le$ 真实代价，保证最优；一致（consistent）：$h(n)\le c(n,n')+h(n')$，保证每个节点最多展开一次。
- 栅格 4 邻接用曼哈顿距离，8 邻接用对角距离（octile），连续空间用欧氏距离。
- open list 用优先队列，closed set 用哈希表。
- 机器人应用：见 [图搜索_Dijkstra_A星](../../02_基础知识/08_规划与导航/01_图搜索_Dijkstra_A星.md)，P5 的 Hybrid A* 在此基础上加入航向与运动学约束（[Hybrid_A星](../../02_基础知识/08_规划与导航/02_Hybrid_A星与车辆运动学约束.md)）。

**English short answer**
A star orders the search by f equals g plus h, where g is the cost so far and h is a heuristic estimate to the goal. If h is admissible, meaning it never overestimates, the result is optimal. With h equal to zero it becomes Dijkstra. It usually expands far fewer nodes, and I use a priority queue for the open list.

**追问方向**：启发函数过大会怎样（不最优但更快，weighted A*）；tie-breaking；JPS。

### Q25 拓扑排序怎么做？（Topological sort）
**优先级：★★**

**答案要点**：Kahn 算法：反复取入度为 0 的节点入队，删边并更新入度；若处理节点数 < V 则有环。DFS 法：后序逆序。应用：任务依赖、编译顺序、课程表。$O(V+E)$。

**English short answer**
For a directed acyclic graph I repeatedly remove nodes with zero in-degree and update their neighbours. If I cannot process all nodes, there is a cycle. It is used for dependency ordering such as build systems.

**追问方向**：检测有向图环；ROS 节点启动顺序类比。

### Q26 最小生成树 Kruskal 与 Prim？（MST）
**优先级：★★**

**答案要点**：Kruskal：边按权排序，并查集避免成环，$O(E\log E)$，适合稀疏图。Prim：从一点扩展，每次加最小跨割边，堆实现 $O(E\log V)$，适合稠密图。依据是割性质（cut property）。

**English short answer**
Kruskal sorts edges and adds the cheapest one that does not create a cycle, using union-find. Prim grows a tree from a start node by always adding the cheapest edge leaving the tree. Both give a minimum spanning tree.

**追问方向**：MST 唯一性；与最短路的区别。

### Q27 Bellman-Ford 与 Floyd 的适用场景？（Bellman-Ford, Floyd）
**优先级：★**

**答案要点**：Bellman-Ford 支持负权，松弛 $V-1$ 轮，$O(VE)$，可检测负环。Floyd-Warshall 多源最短路 $O(V^3)$，三重循环，DP 思想 `d[i][j]=min(d[i][j], d[i][k]+d[k][j])`。

**English short answer**
Bellman-Ford handles negative edge weights and can detect negative cycles in O(VE). Floyd-Warshall computes all-pairs shortest paths in O(V cubed) using dynamic programming.

**追问方向**：SPFA；负环意义。

### Q28 网格图中如何数岛屿 / 求连通区域？（Number of islands）
**优先级：★★**

**答案要点**：遍历每格，遇到陆地计数并 DFS/BFS 把整片标记为已访问。$O(RC)$。递归 DFS 深度可能爆栈，大图用显式栈或 BFS。与机器人栅格地图的连通域分析、障碍物聚类同构。

**English short answer**
I scan the grid, and every time I find unvisited land I count one island and flood-fill it with BFS or DFS. The cost is linear in the number of cells. The same flood fill is used on occupancy grids to find connected free space.

**追问方向**：并查集解法；最大岛屿面积。

## 四、排序与查找

### Q29 常见排序算法的复杂度与稳定性？（Sorting overview）
**优先级：★★★**

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
|---|---|---|---|---|
| 冒泡/插入 | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 稳定 |
| 选择 | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 不稳定 |
| 快速 | $O(n\log n)$ | $O(n^2)$ | $O(\log n)$ | 不稳定 |
| 归并 | $O(n\log n)$ | $O(n\log n)$ | $O(n)$ | 稳定 |
| 堆 | $O(n\log n)$ | $O(n\log n)$ | $O(1)$ | 不稳定 |
| 计数/基数 | $O(n+k)$ | 同左 | $O(k)$ | 稳定 |

- 基于比较的排序下界 $\Omega(n\log n)$（决策树有 $n!$ 个叶子，高度 $\ge \log_2 n! \approx n\log n$）。
- 稳定：相等元素相对次序不变。插入排序在近乎有序时 $O(n)$；标准库（introsort/timsort）混合使用。

**English short answer**
Quicksort, mergesort and heapsort are O(n log n) on average; quicksort can degrade to O(n squared) with bad pivots, mergesort needs extra O(n) memory but is stable, and heapsort is in place but not stable. Comparison sorting cannot beat n log n. Insertion sort is great for small or nearly sorted data, which is why real libraries mix algorithms.

**追问方向**：为什么 timsort 稳定；外部排序。

### Q30 快速排序的实现与优化？（Quicksort）
**优先级：★★★**

**答案要点**：选基准（pivot），分区使左 ≤ 基准 < 右，递归。优化：随机/三数取中选基准；小区间切插入排序；三路划分处理大量重复；先递归小的一侧保证栈 $O(\log n)$。最坏情况在已排序且固定选首元素时出现。

```python
import random
def qsort(a, lo=0, hi=None):
    if hi is None: hi = len(a) - 1
    if lo >= hi: return
    p = a[random.randint(lo, hi)]
    i, j = lo, hi
    while i <= j:
        while a[i] < p: i += 1
        while a[j] > p: j -= 1
        if i <= j: a[i], a[j] = a[j], a[i]; i += 1; j -= 1
    qsort(a, lo, j); qsort(a, i, hi)
```

**English short answer**
Quicksort picks a pivot, partitions the array so smaller elements go left and larger go right, then recurses on both sides. Average time is O(n log n). To avoid the worst case I choose a random pivot or median of three, and use a three-way partition when there are many duplicates.

**追问方向**：快速选择 $O(n)$ 找第 K 大；荷兰国旗。

### Q31 归并排序与逆序对？（Merge sort and inversions）
**优先级：★★**

**答案要点**：分治：拆半、递归排序、合并。$T(n)=2T(n/2)+O(n)$。合并时若右边元素先于左边元素被取出，则产生 `mid - i + 1` 个逆序对，可 $O(n\log n)$ 统计。链表排序首选归并（无需随机访问）。

**English short answer**
Mergesort splits the array in half, sorts each half and merges them in linear time, which gives O(n log n) with stable behaviour. It is the natural choice for linked lists, and a small tweak during merging counts inversions.

**追问方向**：自底向上归并；外部排序。

### Q32 二分查找的写法与易错点？（Binary search）
**优先级：★★★**

**答案要点**
- 前提：有序（或单调）。每次砍半，$O(\log n)$。
- 易错：`mid=(lo+hi)//2` 在 C/C++ 可能溢出，用 `lo+(hi-lo)/2`；循环条件 `<=` 与 `<` 配合边界更新。
- 找第一个 ≥ target 的下标（lower_bound）模板最通用。
- 进阶：在**答案**上二分（单调性判定函数），如最小化最大值。

```python
def lower_bound(a, x):
    lo, hi = 0, len(a)         # [lo, hi)
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if a[mid] < x: lo = mid + 1
        else: hi = mid
    return lo
```

**English short answer**
Binary search halves the search range each step on sorted data, giving O(log n). The usual bugs are integer overflow when computing the middle and off-by-one errors in the loop bounds. I use a half-open interval and a lower-bound template, which also works for finding the first position satisfying a monotone condition.

**追问方向**：旋转有序数组；浮点二分；答案二分。

### Q33 如何找第 K 大元素？（Kth largest）
**优先级：★★**

**答案要点**：①大小为 K 的小顶堆 $O(n\log K)$；②快速选择（quickselect）平均 $O(n)$，最坏 $O(n^2)$；③中位数的中位数保证最坏 $O(n)$。海量数据用分治 + 堆。

**English short answer**
I can keep a min-heap of size k, which is O(n log k), or use quickselect, which partitions like quicksort but only recurses into one side and gives average O(n).

**追问方向**：数据流中位数；海量数据 Top-K。

### Q34 排序算法稳定性有什么用？（Why stability matters）
**优先级：★**

**答案要点**：多关键字排序时，先按次要关键字排、再按主要关键字稳定排，结果正确。基数排序依赖稳定性。数据库 ORDER BY 多列也如此。

**English short answer**
Stability means equal keys keep their original order, which lets us sort by multiple keys in passes. Radix sort relies on it.

**追问方向**：如何让不稳定排序变稳定（加原下标）。

## 五、算法范式

### Q35 动态规划的思路？怎么识别 DP 题？（Dynamic programming）
**优先级：★★★**

**答案要点**
- 条件：最优子结构 + 重叠子问题。步骤：①定义状态；②写转移方程；③确定初始值和遍历顺序；④是否可滚动数组压缩。
- 例：爬楼梯 $f(n)=f(n-1)+f(n-2)$；最长公共子序列 $dp[i][j]=dp[i-1][j-1]+1$（相等）否则 $\max(dp[i-1][j], dp[i][j-1])$。
- 自顶向下（记忆化递归）与自底向上（迭代）等价。

**English short answer**
Dynamic programming applies when a problem has optimal substructure and overlapping subproblems. I define the state, write the recurrence, set the base cases and decide the iteration order, then optimize space if possible. It turns exponential recursion into polynomial time by storing sub-results.

**追问方向**：DP 与贪心区别；状态压缩 DP。

### Q36 0-1 背包与完全背包？（Knapsack）
**优先级：★★★**

**答案要点**：$dp[j]$ 表示容量 $j$ 的最大价值。0-1 背包：物品只能用一次，**容量倒序**遍历：`for j in range(W, w-1, -1): dp[j]=max(dp[j], dp[j-w]+v)`。完全背包：可重复，**正序**。时间 $O(nW)$，是伪多项式。

```python
def knap01(ws, vs, W):
    dp = [0]*(W+1)
    for w, v in zip(ws, vs):
        for j in range(W, w-1, -1):
            dp[j] = max(dp[j], dp[j-w] + v)
    return dp[W]
```

**English short answer**
In the 0-1 knapsack, dp of j is the best value with capacity j. Iterating the capacity backwards ensures each item is used at most once; iterating forwards allows unlimited use, giving the unbounded version. It runs in O(nW), which is pseudo-polynomial.

**追问方向**：为什么倒序；恰好装满；NP 完全。

### Q37 最长递增子序列（LIS）怎么做到 $O(n\log n)$？（LIS）
**优先级：★★**

**答案要点**：维护 `tails[k]` = 长度为 $k+1$ 的递增子序列的最小结尾。对每个数二分找第一个 ≥ 它的位置替换，若超出则追加。长度即 `len(tails)`。$O(n\log n)$；朴素 DP $O(n^2)$。

**English short answer**
I keep an array where entry k is the smallest possible tail of an increasing subsequence of length k plus one. For each number I binary-search its position and replace, or append if it is larger than all. The array length is the LIS length, in O(n log n).

**追问方向**：还原序列；最长公共子序列。

### Q38 编辑距离？（Edit distance）
**优先级：★★**

**答案要点**：$dp[i][j]$ 为前 $i$ 个与前 $j$ 个字符的最小操作数。相等取 $dp[i-1][j-1]$，否则 $1+\min(\text{插入, 删除, 替换})$。$O(mn)$，可滚动压缩到 $O(n)$。

**English short answer**
Edit distance uses a 2D table where each cell is the minimum number of insertions, deletions or substitutions to convert prefixes. If the characters match we copy the diagonal, otherwise we take one plus the minimum of the three neighbours.

**追问方向**：回溯得到操作序列。

### Q39 贪心算法与证明方法？（Greedy）
**优先级：★★**

**答案要点**：每步选局部最优，要求贪心选择性质 + 最优子结构。证明：交换论证（exchange argument）或归纳。例：区间调度按结束时间排序；Huffman；Dijkstra。反例：硬币面额 {1,3,4} 凑 6，贪心 4+1+1=3 枚，最优 3+3=2 枚，需 DP。

**English short answer**
A greedy algorithm makes the locally best choice at each step. It is correct only when a greedy choice property holds, which is usually proved by an exchange argument. Interval scheduling by earliest finish time is a classic example, while coin change with arbitrary denominations needs DP.

**追问方向**：如何举反例；哈夫曼编码。

### Q40 双指针与滑动窗口？（Two pointers, sliding window）
**优先级：★★★**

**答案要点**：对撞指针（有序数组两数之和、盛水容器）、快慢指针（链表环、去重）、滑动窗口（最长无重复子串）。窗口右端扩张、左端在违反条件时收缩，每个元素最多进出一次，$O(n)$。

```python
def longest_unique(s):
    last, l, best = {}, 0, 0
    for r, c in enumerate(s):
        if c in last and last[c] >= l: l = last[c] + 1
        last[c] = r; best = max(best, r - l + 1)
    return best
```

**English short answer**
With two pointers I scan from both ends or at different speeds to avoid nested loops. A sliding window expands on the right and shrinks on the left when a constraint breaks, so each element is processed at most twice, giving O(n).

**追问方向**：最小覆盖子串；三数之和。

### Q41 回溯法与剪枝？（Backtracking）
**优先级：★★**

**答案要点**：枚举所有候选，走不通就撤销（choose → explore → unchoose）。典型：全排列、子集、N 皇后、数独。剪枝：提前判断不可行，排序去重。复杂度指数级，需要剪枝。

**English short answer**
Backtracking builds a solution step by step, and when a partial choice fails the constraints it undoes the choice and tries another. Pruning invalid branches early is what makes it practical for permutations, subsets and N-queens.

**追问方向**：回溯与 DP 区别；去重技巧。

### Q42 单调栈 / 前缀和 / 差分有什么用？（Monotonic stack, prefix sum, difference array）
**优先级：★★**

**答案要点**：前缀和 $S_i=\sum_{k\le i}a_k$，区间和 $S_r-S_{l-1}$ 为 $O(1)$。差分数组使区间加变为两点修改。单调栈解决"下一个更大元素""柱状图最大矩形"。二维前缀和（积分图）与图像处理中的 integral image 同理。

**English short answer**
A prefix sum array turns any range sum query into a subtraction, and a difference array turns a range update into two point updates. A monotonic stack finds the next greater element in linear time.

**追问方向**：二维前缀和；树状数组。

## 六、机器人相关

### Q43 A* 里为什么要用优先队列？栅格地图规划有哪些工程细节？（Priority queue in A star and grid planning）
**优先级：★★★**

**答案要点**
- open list 每次要取 $f$ 最小的节点：优先队列（二叉堆）取出 $O(\log n)$。更新已有节点的 $g$ 时，堆不支持高效 decrease-key，常见做法是**惰性删除**：重复入堆，弹出时检查是否已过期。
- 栅格：障碍物膨胀（inflation）把机器人当质点；8 邻接对角步长 $\sqrt2$；tie-breaking 防止大量等价路径。
- 栅格坐标 ↔ 世界坐标：`ix = floor((x - origin_x)/resolution)`。
- 实际规划栈见 P5 相关文档（只依 CV）：[P5 README](../../01_项目课程/P5_车式移动机器人自主导航/README.md)。

**English short answer**
A star must repeatedly extract the node with the lowest f value, so the open list is a priority queue, normally a binary heap. Since a heap has no cheap decrease-key, I usually push duplicates and skip stale entries when popped. On a grid I also inflate obstacles by the robot radius and use octile distance as the heuristic.

**追问方向**：Hybrid A* 的状态是什么（x, y, theta 离散化）；D* Lite 重规划。

### Q44 KD 树是什么？点云里怎么用？（KD-tree）
**优先级：★★**

**答案要点**
- 二叉空间划分树：每层轮流按某一维（x, y, z...）取中位数切分。建树 $O(n\log n)$，最近邻查询平均 $O(\log n)$，高维退化（维度灾难，一般 $d \lesssim 20$ 才有效）。
- 机器人用途：ICP 点云配准中找最近点；激光点云去噪、半径搜索；PCL/Open3D 都有实现。
- 查询：先下降到叶子得到候选，回溯时若切分平面到查询点的距离 < 当前最优半径，才检查另一侧。
- 替代：八叉树（octree）、体素哈希、栅格直接索引。

**English short answer**
A KD-tree recursively splits space along alternating axes at the median, so a nearest-neighbour query takes about O(log n) on average. In robotics it is used in point cloud registration such as ICP, to find closest points quickly, and for radius searches. It degrades in high dimensions, where other structures are used.

**追问方向**：为什么回溯要比较距离；与八叉树区别；ANN。

### Q45 占据栅格地图（occupancy grid）的数据结构怎么设计？（Occupancy grid design）
**优先级：★★**

**答案要点**：二维数组存每格占据概率或 log-odds；log-odds 更新是加法 $l_t = l_{t-1} + \log\frac{p}{1-p}$，数值稳定。内存 $O(W\cdot H)$，大地图用分块（tile）或稀疏哈希；ROS 的 `nav_msgs/OccupancyGrid` 用 int8 表示 -1 未知 / 0–100 概率。射线投射（Bresenham）更新沿线空闲格。

**English short answer**
An occupancy grid is a 2D array where each cell stores the probability of being occupied, usually as log-odds so updates are simple additions. For large maps I split the grid into tiles or use a sparse hash. Bresenham's line algorithm marks the cells along each laser beam as free.

**追问方向**：分辨率权衡；代价地图的膨胀层。

### Q46 机器人实时系统中怎么选数据结构？（Choosing data structures for real-time code）
**优先级：★★**

**答案要点**：避免运行期动态内存分配（延迟不确定、碎片）；预分配固定容量的环形缓冲、对象池；避免 `std::map` 在控制环里做插入；用 `reserve`；中断与主循环间用无锁单生产者单消费者环形队列。见 [并发多线程与实时系统八股](./07_并发多线程与实时系统八股.md)。

**English short answer**
In control loops I avoid dynamic allocation at runtime because its timing is unpredictable. I preallocate fixed-size buffers, object pools and ring buffers, and use lock-free single-producer single-consumer queues between interrupts and tasks.

**追问方向**：内存池实现；为什么 malloc 不适合中断。

## 本章要点速记
1. Big-O 看增长上界；动态数组 push_back 均摊 $O(1)$。
2. 数组缓存友好；链表只适合频繁已知位置插删。
3. 哈希表平均 $O(1)$，靠拉链或开放寻址解冲突，扩容靠 rehash。
4. BST 会退化，AVL/红黑树保证 $O(\log n)$；数据库用 B+ 树（扇出大、叶子链表）。
5. 堆建堆 $O(n)$；Top-K 用大小 K 的堆。
6. BFS 无权最短路；Dijkstra 非负权；A* = Dijkstra + 可采纳启发。
7. 快排平均 $n\log n$、最坏 $n^2$；基于比较的排序下界 $n\log n$。
8. DP 三问：状态、转移、边界；0-1 背包容量倒序。
9. 机器人：A* 用优先队列，点云用 KD 树，栅格用 log-odds。
