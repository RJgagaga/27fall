## 一、数组与双指针

### Q1 数组题的通用解题顺序是什么？（How do you approach an array problem?）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 先问约束：数据规模 $n$（$10^5$ 以内可接受 $O(n\log n)$，$10^3$ 可接受 $O(n^2)$）、是否有序、是否有负数、是否允许修改原数组、元素是否重复。
- 写出暴力解（通常两层循环 $O(n^2)$），再问"哪一步在重复计算？能否用排序、哈希、前缀和、双指针消除？"
- 常见降复杂度手段：排序后双指针（$O(n\log n)$）、哈希表以空间换时间（$O(n)$）、前缀和（区间求和 $O(1)$）、单调栈/队列（找下一个更大元素）。
- 最后检查边界：空数组、单元素、全相同、溢出（C/C++ 中 `int` 求和）。

**English short answer**
I start by asking about constraints, then state the brute-force solution and its complexity. Next I look for repeated work that sorting, a hash map, prefix sums or two pointers can remove. Before coding I walk through a small example, and at the end I check edge cases like empty input and overflow.

（译：先问约束，说暴力解与复杂度；再找重复计算，用排序、哈希、前缀和或双指针消除；写代码前用小例子走一遍，最后检查空输入、溢出等边界。）

**追问方向**：如何证明你的优化是正确的；空间能否进一步压缩。

### Q2 两数之和怎么做？有序与无序数组的区别？（Two-sum）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 无序：一次遍历 + 哈希表，存"值 → 下标"，对每个 `x` 查 `target - x` 是否已出现，$O(n)$ 时间、$O(n)$ 空间；先查后插，避免同一元素用两次。
- 有序：双指针 `l=0, r=n-1`，和大了 `r--`、和小了 `l++`，$O(n)$ 时间、$O(1)$ 空间。正确性：每次移动都排除了不可能的候选（若 `a[l]+a[r] > target`，则 `a[r]` 与任何 `a[l..]` 之和都过大）。
- 三数之和：排序后固定一个数，对剩余部分做双指针，$O(n^2)$；注意跳过重复值去重。

```python
def two_sum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return seen[target - x], i
        seen[x] = i
```

**English short answer**
For an unsorted array I use a hash map from value to index, and for each number I look up its complement, which is O(n) time and space. For a sorted array I use two pointers from both ends and move the one that fixes the sum, which is O(n) time and O(1) space. For three-sum I sort, fix one number and run two pointers on the rest.

（译：无序用哈希表查补数，$O(n)$；有序用首尾双指针，$O(1)$ 空间；三数之和是排序后固定一个数再双指针。）

**追问方向**：返回所有不重复组合怎么去重；数组很大放不进内存怎么办。

### Q3 双指针有哪几种形态？（Two-pointer patterns）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- **对撞指针**：首尾向中间，用于有序数组求和、回文判断、盛水容器（每次移动较短的那根板）。
- **快慢指针**：同向不同速，用于链表找环（Floyd）、找中点、原地删除重复/移动零（慢指针指向"已处理区的末尾"）。
- **同向双指针（滑窗）**：见滑窗章节。
- 判断信号：数组有序或可排序、要求原地 $O(1)$ 空间、涉及"成对"或"区间"。
- 盛水容器正确性：面积 = 较短板 × 宽度，移动较长板只会让宽度变小且高度不增，所以必须移动较短板。

**English short answer**
There are opposing pointers for sorted or palindrome problems, fast and slow pointers for cycles and in-place compaction, and same-direction pointers for windows. I use them when the data is sorted or I need O(1) extra space. In container-with-most-water I always move the shorter side, because moving the taller one can only shrink the area.

（译：对撞、快慢、同向三种；数据有序或要 $O(1)$ 空间时使用；盛水容器移动较短板，因为移动较长板面积只会更小。）

**追问方向**：链表环入口怎么求；原地去重的不变量。

### Q4 链表常见操作与易错点？（Linked list pitfalls）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 反转链表：三个指针 `prev, cur, next`，循环中先保存 `next`，再 `cur->next = prev`，再整体前移，$O(n)$、$O(1)$。递归写法空间 $O(n)$（栈）。
- 虚拟头结点（dummy node）：统一处理"删除头结点"和"插入头部"，避免特判。
- 找倒数第 k 个：快指针先走 k 步，再一起走。
- 合并两个有序链表：dummy + 尾指针，比较后接上较小者，$O(m+n)$。
- 找环：快慢指针相遇后，把一个指针放回头，两个都每次走一步，再相遇即环入口（利用 $a = (n-1)(b+c)+c$ 的距离关系）。
- 易错：空链表、只有一个结点、断链前忘记保存 `next`、C/C++ 中释放结点后仍访问。

**English short answer**
To reverse a list I keep prev, cur and next pointers and flip each link while walking forward. A dummy head removes special cases for the first node. For cycles I use fast and slow pointers, and for the k-th from the end I advance one pointer k steps first. The classic bugs are null lists and losing the next pointer before relinking.

（译：反转用三个指针逐个翻转；虚拟头结点省去头部特判；找环与倒数第 k 个用快慢指针；常见错误是空链表和断链前未保存 next。）

**追问方向**：K 个一组反转；链表排序为什么常用归并。

### Q5 前缀和与差分的用途？（Prefix sum and difference array）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 前缀和 `S[i]=a[0]+...+a[i-1]`，区间和 `sum(l,r)=S[r+1]-S[l]`，预处理 $O(n)$，查询 $O(1)$。二维前缀和用容斥：`S[i][j]=S[i-1][j]+S[i][j-1]-S[i-1][j-1]+a`。
- "和为 k 的子数组个数"：遍历时维护前缀和出现次数的哈希表，当前前缀和为 `s`，答案累加 `cnt[s-k]`，$O(n)$。
- 差分数组 `d[i]=a[i]-a[i-1]` 把"区间加常数"变成两个端点的修改，最后再做一次前缀和还原，适合大量区间更新、最后一次查询。
- 机器人类比：累积里程、积分项（PID 的 I 项）本质是前缀和；差分对应数值微分。

**English short answer**
A prefix sum array lets me answer any range sum in constant time after linear preprocessing. For counting subarrays with sum k, I keep a hash map of how many times each prefix sum has appeared. A difference array does the reverse: a range update becomes two point updates, and one prefix sum at the end rebuilds the array.

（译：前缀和线性预处理后区间和 $O(1)$；统计和为 k 的子数组用前缀和计数哈希；差分把区间更新变成两个端点修改，最后前缀和还原。）

**追问方向**：二维前缀和；有负数时为什么滑窗不适用而前缀和适用。

## 二、滑动窗口与单调结构

### Q6 什么时候用滑动窗口？模板是什么？（Sliding window）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 信号：求"满足某条件的最长/最短连续子数组/子串"，且窗口性质可单调维护（扩张使条件更易/更难满足）。
- 模板：右指针扩张，把元素加入窗口状态；当窗口不合法（或可以收缩）时左指针收缩；每步更新答案。每个元素最多进出一次，$O(n)$。
- 例：无重复字符的最长子串——用哈希表记录字符最近下标，遇重复则 `left = max(left, last[c]+1)`。
- 例：最小覆盖子串——用计数表和 `need` 计数，满足时收缩。
- 注意：含负数的"和 ≥ k"最短子数组不能直接用滑窗（窗口性质不单调），需用前缀和 + 单调队列。

```python
def longest_unique(s):
    last, left, best = {}, 0, 0
    for r, c in enumerate(s):
        if c in last and last[c] >= left:
            left = last[c] + 1
        last[c] = r
        best = max(best, r - left + 1)
    return best
```

**English short answer**
I use a sliding window for the longest or shortest contiguous segment satisfying a condition. The right pointer expands the window and the left pointer shrinks it whenever the condition breaks, so each element enters and leaves once and the total is O(n). It does not work directly when negative numbers make the condition non-monotonic.

（译：求满足条件的最长/最短连续段时用滑窗；右指针扩张、左指针按条件收缩，整体 $O(n)$；含负数导致条件不单调时不能直接用。）

**追问方向**：为什么滑窗是 $O(n)$ 而不是 $O(n^2)$；字符串排列检测怎么用定长窗口。

### Q7 单调栈解决什么问题？（Monotonic stack）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 典型：下一个更大元素、每日温度、柱状图最大矩形、接雨水。
- 做法：栈中保持单调（如递减）；遇到比栈顶大的元素，就不断弹栈并"结算"被弹出元素的答案（它的下一个更大元素就是当前元素）。每个元素入栈出栈各一次，$O(n)$。
- 柱状图最大矩形：对每根柱子找左右第一个更矮的位置，宽度 = 右 - 左 - 1，面积 = 高 × 宽。
- 栈里存下标而不是值，才能计算距离。

**English short answer**
A monotonic stack keeps its elements in sorted order so that when a new element arrives, I can pop every element it dominates and resolve their answers at once. It solves next-greater-element, daily temperatures and largest rectangle in a histogram in O(n), because each element is pushed and popped only once.

（译：单调栈保持栈内有序，新元素到来时弹出被它"支配"的元素并结算答案；每个元素只进出一次，$O(n)$。）

**追问方向**：接雨水的双指针解法与栈解法比较；环形数组怎么处理。

### Q8 单调队列与滑动窗口最大值怎么做？（Sliding window maximum）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 双端队列存下标，队内对应的值单调递减；队首永远是当前窗口最大值。
- 每步：①队尾比新元素小的全部弹出；②新下标入队尾；③若队首下标已滑出窗口则弹队首；④窗口形成后记录队首值。
- 复杂度 $O(n)$，空间 $O(k)$。对比大根堆 $O(n\log n)$（需延迟删除）。
- 机器人类比：对传感器流做滑动窗口最大/最小滤波（如峰值保持、范围检测）可用该结构实时完成。

**English short answer**
I keep a deque of indices whose values are decreasing. For each new element I pop smaller values from the back, push the new index, and drop the front if it left the window. The front is always the window maximum, so the whole pass is O(n), better than the O(n log n) heap approach.

（译：用下标双端队列保持值递减，队首即窗口最大值，整体 $O(n)$，优于堆的 $O(n\log n)$。）

**追问方向**：如何同时求最大与最小；在线数据流版本。

### Q9 Top-K 问题有哪些解法？如何选择？（Top-K problem）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 全排序：$O(n\log n)$，最简单。
- 大小为 $k$ 的**小根堆**：遍历数据，堆满后只在新元素大于堆顶时替换，$O(n\log k)$，空间 $O(k)$，适合流式数据与海量数据。
- 快速选择（quickselect）：划分后只递归包含第 $k$ 位的一侧，平均 $O(n)$，最坏 $O(n^2)$（可随机化枢轴），会改变原数组。
- 桶/计数：值域小时（如频率）用桶排序 $O(n)$。
- 海量数据：先哈希分片到多个文件，每片局部 Top-K，再合并。
- 选择：流式或内存紧用堆；一次性内存数组用 quickselect；值域小用桶。

**English short answer**
For top-k I would use a min-heap of size k, which costs O(n log k) and works on streams. If all data is in memory I can use quickselect for average O(n). When the value range is small, bucket counting is even better. For huge data I hash-partition into shards, find top-k in each, and merge.

（译：流式/大数据用大小为 k 的小根堆 $O(n\log k)$；内存数组用快速选择平均 $O(n)$；值域小用桶；超大数据先分片再合并。）

**追问方向**：为什么求最大 k 个用小根堆；第 k 大元素的堆与 quickselect 对比。

## 三、二分与排序

### Q10 二分查找的万能模板与边界怎么写？（Binary search template）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 关键是**固定不变量**。推荐"左闭右开 `[l, r)`"：循环条件 `l < r`，`mid = l + (r-l)/2`（避免 `l+r` 溢出）；若 `check(mid)` 为真则 `r = mid` 否则 `l = mid+1`，结束时 `l` 为第一个满足条件的位置（lower_bound）。
- `lower_bound`：第一个 ≥ target；`upper_bound`：第一个 > target；个数 = 两者之差。
- 不要求"等于"，而是对**单调谓词**二分：把问题改写成"找第一个使 `check` 为真的位置"。
- 常见 bug：死循环（`l=mid` 且 `mid` 向下取整）、整数溢出、边界不闭合。
- 复杂度 $O(\log n)$。

```cpp
int lower_bound(const vector<int>& a, int t) {
    int l = 0, r = a.size();          // [l, r)
    while (l < r) {
        int m = l + (r - l) / 2;
        if (a[m] >= t) r = m; else l = m + 1;
    }
    return l;                          // 可能等于 a.size()
}
```

**English short answer**
I fix an invariant: the answer lies in the half-open range [l, r). While l is less than r, I compute mid without overflow, and move r to mid if the predicate holds, or l to mid plus one otherwise. At the end l is the first position that satisfies the condition. This gives lower_bound, and it generalizes to any monotonic predicate.

（译：固定"答案在 $[l,r)$"这一不变量，谓词成立则 $r=mid$，否则 $l=mid+1$，结束时 $l$ 即第一个满足位置；可推广到任意单调谓词。）

**追问方向**：旋转数组中搜索；浮点数二分的终止条件。

### Q11 "二分答案"是什么？举例。（Binary search on the answer）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 当"答案的可行性"关于答案值单调（答案越大越容易/越难可行），就对**答案值域**二分，每次用一个 $O(n)$ 的检查函数判断可行性。
- 例：分割数组使最大子段和最小（check：贪心划分段数是否 ≤ m）；运送包裹的最低运力；爱吃香蕉的珂珂；开方 $\sqrt{x}$。
- 总复杂度 $O(n \log(\text{值域}))$。
- 浮点答案：循环固定次数（如 100 次）或精度阈值；注意不要用 `==` 比较。
- 机器人类比：在 MPC 或标定中对某个参数（如最大速度）二分搜索可行性边界。

**English short answer**
When feasibility is monotonic in the answer, I binary search over the answer value and use a linear check function to test each candidate. Examples are minimizing the largest subarray sum, the minimum shipping capacity, or computing a square root. The total cost is O(n log range).

（译：当可行性随答案单调时，对答案值域二分并用线性检查函数验证；例如最小化最大段和、最小运力、开方。）

**追问方向**：怎样证明单调性；浮点二分如何设置终止条件。

### Q12 旋转有序数组如何二分？（Search in rotated sorted array）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 旋转后数组分成两段各自有序。每次取 `mid`，必有一半 `[l,mid]` 或 `[mid,r]` 是有序的。
- 判断哪半有序：若 `a[l] <= a[mid]` 则左半有序；再看 target 是否落在该有序半区内，决定丢弃哪一半。
- 无重复元素 $O(\log n)$；有重复时 `a[l]==a[mid]==a[r]` 无法判断，只能 `l++`、`r--`，最坏退化到 $O(n)$。
- 找最小值：比较 `a[mid]` 与 `a[r]`，`a[mid] > a[r]` 则最小值在右侧。

**English short answer**
After rotation one half around mid is always sorted. I check which half is sorted by comparing the endpoints, then see whether the target lies within that range to decide which half to keep. This is O(log n) with distinct values; with duplicates it can degrade to O(n).

（译：旋转后总有一半有序，判断目标是否落在有序半区来决定舍弃哪一半；无重复 $O(\log n)$，有重复最坏 $O(n)$。）

**追问方向**：为什么重复元素破坏二分；找旋转点的另一种写法。

### Q13 手写快速排序与常见优化？（Quicksort implementation）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 思路：选枢轴 → 划分（小于枢轴的放左、大于的放右）→ 递归两侧。平均 $O(n\log n)$，最坏 $O(n^2)$（已排序且枢轴取端点），原地，不稳定。
- 优化：随机枢轴或三数取中；小区间（约 16 个元素以下）改插入排序；三路划分处理大量重复键；先递归较小一侧，循环处理较大一侧，使递归深度 $O(\log n)$。
- Lomuto 划分更易写，Hoare 划分交换更少。
- 工业实现（如 C++ `std::sort`）通常是 introsort：快排 + 堆排（深度超限时）+ 插入排序。

```python
def quicksort(a, lo, hi):
    while lo < hi:
        p = partition(a, lo, hi)          # 返回枢轴最终位置
        if p - lo < hi - p:
            quicksort(a, lo, p - 1); lo = p + 1
        else:
            quicksort(a, p + 1, hi); hi = p - 1
```

**English short answer**
Quicksort picks a pivot, partitions the array around it, and recurses on both sides. It is O(n log n) on average and O(n squared) in the worst case, so I randomize or use median-of-three pivots. I switch to insertion sort for small ranges and recurse on the smaller side first to bound the stack depth. Standard libraries use introsort, which falls back to heapsort.

（译：选枢轴、划分、递归；平均 $n\log n$、最坏 $n^2$，用随机/三数取中枢轴，小区间用插入排序，先递归小侧控制栈深；标准库用 introsort。）

**追问方向**：为什么快排比归并在实践中更快（缓存友好）；稳定性如何实现。

### Q14 归并排序与逆序对？（Merge sort and inversion count）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 归并：分治，递归排好两半，再双指针合并；稳定，$O(n\log n)$ 最坏也成立，需要 $O(n)$ 额外空间。适合链表（合并无需额外空间）、外部排序（磁盘上多路归并）。
- 逆序对：在合并时，若右半当前元素小于左半当前元素，则左半剩余元素全部与它构成逆序对，计数 `mid - i + 1`。总 $O(n\log n)$。
- 相关：求"右侧小于当前元素的个数"可用归并或树状数组/线段树。

**English short answer**
Merge sort splits the array, sorts both halves recursively, and merges them with two pointers. It is stable and always O(n log n), but needs O(n) extra space. While merging, whenever an element from the right half goes first, all remaining left elements form inversions with it, so I can count inversions in the same time.

（译：归并稳定、始终 $O(n\log n)$，额外空间 $O(n)$；合并时右半元素先出，则左半剩余元素均与其构成逆序对，可同时统计逆序数。）

**追问方向**：自底向上归并；外部排序的做法。

### Q15 排序算法如何选择？稳定性是什么？（Choosing a sorting algorithm）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 稳定性：相等键排序后相对顺序不变。稳定：归并、插入、冒泡、计数、基数；不稳定：快排、堆排、选择。多键排序（先按 A 再按 B）依赖稳定性。
- 小规模或近乎有序：插入排序（$O(n)$ 最好）；一般内存数据：快排/introsort；要稳定或链表：归并；整数且值域小：计数/基数/桶 $O(n)$；内存紧、要最坏保证：堆排。
- 比较排序下界 $\Omega(n\log n)$（决策树有 $n!$ 个叶子）。
- Python 的 `sorted` 用 Timsort（归并 + 插入，利用已有序片段，稳定）。

**English short answer**
For small or nearly sorted data I use insertion sort, in general I use quicksort or introsort, and when I need stability or I sort linked lists I use merge sort. For small integer ranges, counting or radix sort is linear. A sort is stable if equal keys keep their order, which matters for multi-key sorting. Comparison sorts cannot beat n log n.

（译：小规模/近有序用插入；通用用快排；要稳定或链表用归并；整数小值域用计数/基数；稳定性指相等键相对顺序不变；比较排序下界 $n\log n$。）

**追问方向**：Timsort 的核心想法；为什么堆排缓存不友好。

### Q16 回溯的模板与剪枝思路？（Backtracking）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 回溯 = 在决策树上做 DFS：**选择 → 递归 → 撤销选择**。用于排列、组合、子集、N 皇后、数独、括号生成。
- 模板：`dfs(path, choices)`：满足结束条件则记录答案（注意拷贝 `path`）；否则遍历每个可选项：做选择、递归、撤销。
- 去重：排序后跳过同层相同元素（`i>start and a[i]==a[i-1]`）；用 `used` 数组避免排列重复使用。
- 剪枝：越界、剩余和已超目标、可行性提前判断（如 N 皇后用列/对角线集合 $O(1)$ 判冲突）。
- 复杂度通常指数级：排列 $O(n\cdot n!)$，子集 $O(n\cdot 2^n)$。

```python
def subsets(nums):
    res, path = [], []
    def dfs(start):
        res.append(path[:])               # 拷贝
        for i in range(start, len(nums)):
            path.append(nums[i]); dfs(i + 1); path.pop()
    dfs(0); return res
```

**English short answer**
Backtracking is depth-first search over a decision tree: choose, recurse, then undo the choice. I record a copy of the path when it is complete, skip duplicates by sorting and checking neighbors, and prune branches that can no longer succeed. The cost is exponential, for example O(n times n!) for permutations, so pruning is what makes it practical.

（译：回溯是决策树上的 DFS：选择、递归、撤销；完成时拷贝路径，排序后跳过同层重复，尽早剪枝；复杂度指数级，剪枝决定可行性。）

**追问方向**：回溯与 DP 的区别；如何用位运算优化 N 皇后。

### Q17 DFS 与 BFS 的选择与实现要点？（DFS vs BFS）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- BFS：队列，按层扩展；**无权图最短路径**、最少步数、层序遍历。空间与最宽一层成正比。
- DFS：栈或递归；连通分量、拓扑排序、环检测、回溯、路径存在性。空间与深度成正比。
- 网格题要点：方向数组 `dirs`、越界判断、`visited`（入队时标记，避免重复入队）。
- 递归 DFS 在深度很大时可能栈溢出，改成显式栈。
- 多源 BFS：把所有起点一起入队（如腐烂的橘子、离障碍最近距离图）——机器人里的距离变换（distance transform）就是它。

**English short answer**
BFS uses a queue and expands level by level, so it gives shortest paths in unweighted graphs. DFS uses a stack or recursion and suits connectivity, cycle detection, topological sort and backtracking. In grids I mark cells visited when I enqueue them. Multi-source BFS starts with all sources in the queue, which is how a distance map to obstacles is computed.

（译：BFS 用队列按层扩展，求无权最短路；DFS 用栈/递归，适合连通性、环检测、拓扑排序、回溯；网格入队时标记已访问；多源 BFS 可计算到障碍物的距离图。）

**追问方向**：为什么要在入队而非出队时标记；岛屿数量的 DFS/BFS/并查集三种写法。

### Q18 拓扑排序怎么做？能检测环吗？（Topological sort）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 适用于**有向无环图（DAG）**：任务依赖、课程安排、构建系统（CMake/ament 的包依赖顺序）。
- Kahn 算法（BFS）：统计入度，入度为 0 的入队；出队时把后继入度减 1，变为 0 则入队；最后若输出的结点数小于总数，说明有环。$O(V+E)$。
- DFS 法：三色标记（未访问/访问中/完成），遇到"访问中"的结点说明有环；完成时压栈，逆序即拓扑序。
- 拓扑序不唯一；需要字典序最小可用优先队列。

**English short answer**
Topological sort orders a directed acyclic graph so that every edge goes forward. With Kahn's algorithm I repeatedly remove nodes with zero in-degree; if I cannot remove all nodes, the graph has a cycle. It runs in O(V plus E) and is how build systems and task schedulers decide a valid order.

（译：拓扑排序为 DAG 给出所有边向前的顺序；Kahn 算法反复移除入度为 0 的结点，若无法移除全部则有环，复杂度 $O(V+E)$，构建系统和任务调度常用。）

**追问方向**：如何输出所有拓扑序；动态加边怎么维护。

### Q19 并查集的原理与优化？（Union-Find）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 维护不相交集合：`find` 查根，`union` 合并。用于连通分量、Kruskal 最小生成树、判环、账户合并。
- 两个优化：**路径压缩**（find 时把沿途结点直接挂到根）与**按秩/大小合并**（小树挂大树）。两者结合后单次操作均摊 $O(\alpha(n))$（反阿克曼函数，实际可视为常数）。
- 路径压缩可写成迭代，避免深递归。
- 可带权：维护到根的偏移（差分约束、"除法求值"）。

```python
class DSU:
    def __init__(self, n): self.p = list(range(n)); self.sz = [1]*n
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]; x = self.p[x]
        return x
    def union(self, a, b):
        a, b = self.find(a), self.find(b)
        if a == b: return False
        if self.sz[a] < self.sz[b]: a, b = b, a
        self.p[b] = a; self.sz[a] += self.sz[b]; return True
```

**English short answer**
Union-find keeps disjoint sets as trees. Find walks to the root and compresses the path, and union attaches the smaller tree to the larger one. With both optimizations each operation is almost constant, specifically inverse-Ackermann amortized. I use it for connected components, cycle detection and Kruskal's minimum spanning tree.

（译：并查集用树表示不相交集合，find 做路径压缩、union 做按大小合并，均摊近似常数；用于连通分量、判环和 Kruskal。）

**追问方向**：如何支持删除/撤销（可回滚并查集）；带权并查集的例子。

### Q20 最短路算法如何选择？（Shortest path algorithms）
**优先级：★★★** · 对应基础知识：[图搜索_Dijkstra_A星](../../02_基础知识/08_规划与导航/01_图搜索_Dijkstra_A星.md)

**答案要点**
- 无权图：BFS，$O(V+E)$。
- 非负权单源：Dijkstra，堆优化 $O((V+E)\log V)$；稠密图用数组版 $O(V^2)$。
- 有负权（无负环）：Bellman-Ford $O(VE)$，也可检测负环；SPFA 是其队列优化，最坏仍 $O(VE)$。
- 全源：Floyd-Warshall $O(V^3)$，适合 $V$ 几百以内。
- DAG：按拓扑序松弛，$O(V+E)$。
- 有启发信息、单目标：A*，启发函数可采纳（不高估）则最优，一致（consistent）则每个结点最多扩展一次。
- 机器人：全局规划用 A*/Hybrid A*，栅格地图常配 8 邻域 + 欧氏/八方向启发。

**English short answer**
For unweighted graphs I use BFS, for non-negative weights Dijkstra with a heap, and for negative edges Bellman-Ford, which also detects negative cycles. For all pairs on a small graph I use Floyd-Warshall. A star adds an admissible heuristic to Dijkstra to focus the search toward the goal, which is why navigation planners use it.

（译：无权用 BFS；非负权用堆优化 Dijkstra；有负权用 Bellman-Ford（可测负环）；小图全源用 Floyd；A* 在 Dijkstra 上加可采纳启发以朝目标搜索，导航规划常用。）

**追问方向**：Dijkstra 为什么不能处理负权；A* 的启发函数一致性。

### Q21 最小生成树的两种算法？（MST: Kruskal vs Prim）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 生成树：连通所有结点且无环，边权和最小。
- Kruskal：边按权升序，用并查集判断是否成环，加入 $V-1$ 条边为止；$O(E\log E)$，适合稀疏图。
- Prim：从一点出发，每次选连接已选集合与未选集合的最小边（优先队列），$O(E\log V)$，适合稠密图。
- 正确性来自**割性质**：横跨任一割的最小权边一定属于某棵 MST。
- 应用：网络布线、聚类（Kruskal 提前停止 = 单链接层次聚类）、机器人多点覆盖的近似。

**English short answer**
Kruskal sorts edges and adds each one that does not create a cycle, using union-find; it suits sparse graphs. Prim grows one tree by repeatedly adding the cheapest edge leaving it, using a priority queue. Both rely on the cut property, and Kruskal stopped early gives single-linkage clustering.

（译：Kruskal 按边权排序并用并查集防环；Prim 从一点扩张并每次加最小外连边；两者基于割性质，Kruskal 提前停止即单链接聚类。）

**追问方向**：边权相同的唯一性；次小生成树怎么求。

### Q22 如何识别并设计一个 DP？（DP design steps）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 识别：①最优子结构；②重叠子问题；常见问法"最大/最小/方案数/是否可行"。
- 设计四步：**状态**（dp 数组下标和含义）→ **转移方程** → **初始值与边界** → **遍历顺序**（保证转移依赖的状态已算好）。
- 优化：滚动数组降空间；记忆化搜索（自顶向下，只算需要的状态）与递推（自底向上）等价；有时可用单调队列/斜率优化降时间。
- 调试方法：先写暴力递归，再加记忆化，最后改递推；用小输入手算验证 dp 表。
- 状态含义要写成一句完整的话，如 `dp[i][j] = 前 i 个物品、容量 j 时的最大价值`。

**English short answer**
I check for optimal substructure and overlapping subproblems, then define the state in one precise sentence, write the transition, set the base cases, and choose a fill order that respects dependencies. I often start from a recursive brute force, add memoization, and then convert it to a table with a rolling array if memory matters.

（译：先确认最优子结构与重叠子问题，用一句话定义状态，写转移与边界，确定遍历顺序；常从暴力递归到记忆化再到递推并用滚动数组省空间。）

**追问方向**：自顶向下与自底向上的取舍；如何还原方案（记录前驱）。

### Q23 0-1 背包与完全背包的写法差异？（Knapsack variants）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 0-1 背包：每件物品最多取一次。一维压缩时**容量倒序**遍历：`for j in range(W, w-1, -1): dp[j]=max(dp[j], dp[j-w]+v)`。倒序保证 `dp[j-w]` 仍是上一轮（未用当前物品）的值。
- 完全背包：每件可无限次取。容量**正序**遍历，使 `dp[j-w]` 已包含当前物品。
- 组合数与排列数：求"方案数"时，外层物品、内层容量得到组合数；外层容量、内层物品得到排列数（如爬楼梯、零钱兑换 II 与 Combination Sum IV 的区别）。
- 变形：恰好装满（初值 `dp[0]=0`，其余 `-inf`）、分组背包、多重背包（二进制拆分）。
- 复杂度 $O(nW)$，伪多项式。

**English short answer**
In 0-1 knapsack each item is used at most once, so with a one-dimensional table I iterate capacity backwards to avoid reusing the item. In unbounded knapsack I iterate forwards so the item can be reused. For counting ways, looping items outside gives combinations, and looping capacity outside gives permutations. The complexity is O(nW), which is pseudo-polynomial.

（译：0-1 背包一维时容量倒序避免重复使用；完全背包正序允许重复；计数时外层物品得组合数、外层容量得排列数；复杂度 $O(nW)$ 为伪多项式。）

**追问方向**：为什么说是伪多项式；多重背包的优化。

### Q24 最长递增子序列怎么做到 $O(n\log n)$？（LIS）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- $O(n^2)$ DP：`dp[i]` = 以 `a[i]` 结尾的 LIS 长度，`dp[i]=max(dp[j]+1)`（`j<i, a[j]<a[i]`）。
- $O(n\log n)$：维护数组 `tails[k]` = 长度为 `k+1` 的递增子序列的最小可能末尾。对每个 `x`，在 `tails` 中二分找第一个 ≥ x 的位置替换（严格递增用 `lower_bound`，非严格用 `upper_bound`）；若超出末尾则追加。`len(tails)` 即 LIS 长度。
- 注意 `tails` 本身不是真正的 LIS，只用于长度；还原序列需额外记录前驱。
- 变形：俄罗斯套娃信封（按宽升序、高降序再对高求 LIS）。

**English short answer**
The simple DP is O(n squared). The faster method keeps, for each length, the smallest possible tail of an increasing subsequence, and for every new number I binary-search the first tail that is not smaller and replace it, or append if none exists. The size of that array is the LIS length, and the total cost is O(n log n).

（译：朴素 DP 为 $O(n^2)$；更快的做法维护"每个长度的最小末尾"，对每个新数二分替换或追加，数组长度即 LIS 长度，$O(n\log n)$。）

**追问方向**：如何还原具体序列；为什么 tails 单调递增。

### Q25 编辑距离与最长公共子序列的 DP？（Edit distance and LCS）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- LCS：`dp[i][j]` = `s[:i]` 与 `t[:j]` 的 LCS 长度；若 `s[i-1]==t[j-1]`，`dp=dp[i-1][j-1]+1`，否则 `max(dp[i-1][j], dp[i][j-1])`。$O(mn)$。
- 编辑距离（Levenshtein）：插入、删除、替换代价均为 1；`dp[i][j] = dp[i-1][j-1]`（字符相同）否则 `1+min(替换 dp[i-1][j-1], 删除 dp[i-1][j], 插入 dp[i][j-1])`。边界 `dp[i][0]=i`，`dp[0][j]=j`。
- 空间可用两行滚动；还原操作序列需保留整张表。
- 应用：拼写纠错、语音识别评价（词错率 WER = 编辑距离 / 参考词数）、序列比对。

**English short answer**
Both use a two-dimensional table over prefixes. For LCS, a match extends the diagonal value and a mismatch takes the better of the left and upper cells. For edit distance, a mismatch takes one plus the minimum of replace, delete and insert. Both are O(mn) in time and can be reduced to two rows of memory. Word error rate in speech recognition is an application.

（译：两者都是前缀二维表。LCS 匹配则取对角加一，否则取左/上较大者；编辑距离不匹配则取替换/删除/插入的最小值加一；$O(mn)$，可用两行滚动；词错率是应用之一。）

**追问方向**：只要 LCS 长度时空间怎么降；带权编辑距离。

### Q26 打家劫舍、股票买卖这类线性 DP 怎么想？（Linear DP and state machines）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 打家劫舍：`dp[i]=max(dp[i-1], dp[i-2]+a[i])`，只依赖前两项，可用两个变量；环形版本拆成"不偷首"与"不偷尾"两次求最大。
- 股票买卖：用**状态机**——每天有"持有 / 不持有（冷冻期）"等状态，写出状态间的转移；限制交易次数 $k$ 时加一维。
- 最大子数组和（Kadane）：`cur = max(a[i], cur+a[i])`，`ans = max(ans, cur)`，$O(n)$。
- 技巧：把"选/不选""持有/不持有"明确成状态维度，转移就自然出来。

**English short answer**
For linear DP I make the decision at each position an explicit state, such as taking or skipping the house, or holding or not holding a stock. The transition then only depends on the previous few states, so I can use a few variables instead of a table. Kadane's algorithm for the maximum subarray is the simplest example and runs in O(n).

（译：线性 DP 把每个位置的决策写成显式状态（偷/不偷、持有/不持有），转移只依赖前几个状态，可用几个变量代替表；Kadane 是最简例子，$O(n)$。）

**追问方向**：k 次交易的状态定义；环形问题的拆分为什么正确。

### Q27 区间 DP 与树形 DP 是什么？（Interval DP and tree DP）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 区间 DP：状态是区间 `[i,j]`，由更短区间转移，按**区间长度**从小到大遍历。例：戳气球、矩阵链乘、最长回文子序列、合并石子。通常 $O(n^3)$。
- 树形 DP：在树上后序遍历，父结点的状态由子结点汇总。例：打家劫舍 III（每个结点两个状态：偷/不偷）、树的直径（每个结点返回向下最长链，同时更新全局答案）、二叉树最大路径和。
- 要点：树形 DP 的"返回值"与"全局答案"分开，因为经过某结点的最优路径不一定能继续向上延伸。

**English short answer**
Interval DP defines the state on a range and builds longer ranges from shorter ones, iterating by length; typical examples are matrix chain multiplication and burst balloons. Tree DP runs a post-order traversal where each node combines its children's results, for example house robber on a tree. In tree problems I separate what a node returns upward from the global answer I update.

（译：区间 DP 以区间为状态、按长度递增转移；树形 DP 后序遍历、父结点汇总子结点；注意把"向上返回值"与"全局答案"分开。）

**追问方向**：戳气球为什么要考虑"最后戳"；树的直径的两次 BFS 解法。

### Q28 贪心算法如何证明正确？与 DP 的区别？（Greedy vs DP）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 贪心：每步选当前最优，期望得到全局最优；需要证明**贪心选择性质**与最优子结构。
- 常用证明：交换论证（把最优解中不同于贪心的选择换成贪心选择，值不变差）、归纳法、"领先"论证。
- 经典：区间调度（按结束时间排序选最多互不重叠区间）、哈夫曼编码、活动选择、跳跃游戏、分发糖果（两遍扫描）。
- 反例：0-1 背包按价值密度贪心不一定最优，需要 DP；零钱兑换在非规范面值（如 1,3,4 凑 6）下贪心失败。
- 区别：DP 考虑所有子问题并保证最优；贪心更快但需要证明。

**English short answer**
A greedy algorithm makes the locally best choice at each step, and I prove it with an exchange argument showing any optimal solution can be transformed to use the greedy choice. Interval scheduling by earliest finish time is the classic example. If I cannot prove it, as in 0-1 knapsack or coin change with odd denominations, I fall back to dynamic programming.

（译：贪心每步取局部最优，用交换论证证明；区间调度按最早结束时间是经典例子；无法证明（如 0-1 背包、特殊面值零钱）时改用 DP。）

**追问方向**：哈夫曼为什么是最优前缀码；区间调度的反例变体（带权区间调度用 DP）。

### Q29 字符串匹配：KMP 的思想是什么？（KMP）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 朴素匹配最坏 $O(mn)$，失配后文本指针回退。KMP 利用模式串自身的**最长相等前后缀**（`next` / `lps` 数组），失配时模式指针跳到 `lps[j-1]`，文本指针不回退，$O(m+n)$。
- `lps[i]`：`pattern[0..i]` 的真前缀与真后缀的最长相等长度。预处理本身也是 KMP 式自匹配，$O(m)$。
- 其他：Rabin-Karp（滚动哈希，期望 $O(m+n)$，易做多模式）、Z 算法、AC 自动机（多模式）、后缀数组。
- 工程中 `strstr` 常用优化的朴素/双向算法，因为常数小。

**English short answer**
KMP avoids moving the text pointer backwards. It precomputes, for each prefix of the pattern, the length of its longest proper prefix that is also a suffix; on a mismatch the pattern pointer jumps to that length instead of restarting. This gives O(m plus n) time. Rabin-Karp with rolling hashes is another option, especially for multiple patterns.

（译：KMP 预处理模式串每个前缀的最长相等前后缀，失配时模式指针跳转而文本指针不回退，$O(m+n)$；Rabin-Karp 用滚动哈希，适合多模式。）

**追问方向**：lps 数组怎么构造；AC 自动机适用场景。

### Q30 哈希表题的常用套路？（Hash map patterns）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 计数：字母异位词分组（排序后的字符串或 26 维计数元组作键）、出现次数最多元素。
- 去重与存在性：`set` 判断是否见过；最长连续序列（把数放进集合，只从"连续段起点"出发向后数，$O(n)$）。
- 前缀和 + 哈希：和为 k 的子数组、连续子数组和为 k 的倍数（余数相同）。
- 缓存与映射：LRU、记忆化。
- 注意：自定义类型作键要有稳定的哈希与相等语义（Python 中可变对象不可哈希；C++ 需自定义 `hash`）；最坏情况哈希冲突退化为 $O(n)$。

**English short answer**
Hash maps help with counting, de-duplication, fast lookup of complements, and prefix-sum tricks. For the longest consecutive sequence I put numbers into a set and only start counting from numbers that have no predecessor, which is O(n). I keep in mind that keys must be hashable and that collisions can degrade the worst case.

（译：哈希表用于计数、去重、查补数、配合前缀和；最长连续序列把数放入集合，只从无前驱的数开始数，$O(n)$；键须可哈希，冲突会让最坏情况退化。）

**追问方向**：哈希冲突如何处理；一致性哈希适用的场景。

### Q31 位运算的常用技巧？（Bit manipulation tricks）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- `x & (x-1)` 清除最低位的 1，可用于统计 1 的个数、判断 2 的幂（`x>0 and x&(x-1)==0`）；`x & -x` 取最低位的 1。
- 异或：`a^a=0`、`a^0=a`，可找"只出现一次的数"、不借助临时变量交换；异或还用于校验和与简单加密。
- 位掩码：用整数表示子集，状态压缩 DP、枚举子集 `for s=(s-1)&mask`。
- 移位：`x<<k` 乘 $2^k$，`x>>k` 除（有符号数右移是算术移位，C 中为实现定义）。
- 机器人嵌入式：寄存器操作的置位/清零/翻转 `reg |= (1<<n); reg &= ~(1<<n); reg ^= (1<<n);`，协议帧中的标志位解析。

**English short answer**
The key tricks are x and x minus one to clear the lowest set bit, x and negative x to isolate it, and XOR to cancel pairs, which finds the single non-duplicated number. Bitmasks represent small subsets for state-compression DP. In embedded code I use shifts and masks to set, clear and toggle register bits and to parse flag fields.

（译：`x&(x-1)` 清最低位、`x&-x` 取最低位、异或抵消成对数；位掩码表示小集合做状态压缩；嵌入式用移位与掩码操作寄存器与标志位。）

**追问方向**：负数右移的行为；为什么交换两数的异或法不推荐。

### Q32 最长回文子串有哪些解法？（Longest palindromic substring）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 中心扩展：对每个中心（奇数 $n$ 个、偶数 $n-1$ 个）向两侧扩展，$O(n^2)$、$O(1)$ 空间，面试首选。

**English short answer**
The simplest approach expands around each of the 2n minus 1 possible centers, which is O(n squared) time and constant space. A DP table also works but uses O(n squared) memory. Manacher's algorithm reuses palindrome radii by mirroring around the current center and achieves linear time.

（译：中心扩展 $O(n^2)$ 时间、$O(1)$ 空间；DP 需 $O(n^2)$ 内存；Manacher 利用镜像复用回文半径，达到线性。）

**追问方向**：Manacher 为什么是线性；统计回文子串个数。

### Q33 手写 LRU 缓存怎么设计？（Implement an LRU cache）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 需求：`get`、`put` 均摊 $O(1)$，容量满时淘汰最久未使用项。
- 结构：**哈希表 + 双向链表**。哈希表 `key → 链表结点`，链表头为最近使用，尾为最久未用。`get` 命中则把结点移到头；`put` 已存在则更新并移头，否则插头，超容量则删尾并从哈希表删除对应 key。
- 为什么双向：删除任意结点需要前驱指针，单链表要 $O(n)$。用哨兵头尾结点简化边界。
- Python 可用 `OrderedDict.move_to_end` 和 `popitem(last=False)`；C++ 用 `std::list` + `unordered_map<key, list::iterator>`。
- 多线程：加互斥锁，或分片（sharded）降低锁竞争。

```python
from collections import OrderedDict
class LRU:
    def __init__(self, cap): self.cap, self.d = cap, OrderedDict()
    def get(self, k):
        if k not in self.d: return -1
        self.d.move_to_end(k); return self.d[k]
    def put(self, k, v):
        self.d[k] = v; self.d.move_to_end(k)
        if len(self.d) > self.cap: self.d.popitem(last=False)
```

**English short answer**
I combine a hash map from key to node with a doubly linked list ordered by recency. Get moves the node to the front; put inserts at the front and evicts the tail when full. Both operations are O(1) because the map finds the node and the doubly linked list can unlink it without scanning. For concurrency I add a lock or shard the cache.

（译：哈希表指向双向链表结点，链表按最近使用排序；get 移到头，put 插头并在满时删尾；两者均 $O(1)$；并发时加锁或分片。）

**追问方向**：LFU 怎么做；分布式缓存的淘汰策略。

### Q34 手写二叉堆（优先队列）要点？（Implement a binary heap）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 用数组存完全二叉树：下标 `i` 的父结点 `(i-1)/2`，子结点 `2i+1, 2i+2`。
- `push`：加到末尾再**上浮**（sift up）；`pop`：取堆顶，把末尾元素放到根再**下沉**（sift down，与较小/较大的子结点交换），均 $O(\log n)$。
- 建堆：从最后一个非叶结点向前逐个下沉，总 $O(n)$。
- 支持 `decrease-key` 需要额外的位置索引（Dijkstra 常用"懒删除"替代：重复入堆，出堆时跳过过期项）。
- C++ `priority_queue` 默认大根堆；Python `heapq` 为小根堆（取负实现大根堆）。

**English short answer**
A binary heap is an array representation of a complete binary tree. Push appends and sifts up; pop swaps the last element into the root and sifts down, both in O(log n). Building a heap bottom-up is O(n). Dijkstra's algorithm often uses lazy deletion instead of decrease-key, pushing duplicates and skipping stale entries.

（译：堆用数组存完全二叉树；push 上浮、pop 把末尾放根后下沉，均 $O(\log n)$；自底向上建堆 $O(n)$；Dijkstra 常用懒删除代替 decrease-key。）

**追问方向**：堆排序的原地实现；多路归并用堆的例子。

### Q35 手写线程安全的有界阻塞队列？（Bounded blocking queue）
**优先级：★★★** · 对应基础知识：[操作系统_进程线程_内存_调度_同步](../../02_基础知识/14_计算机基础/02_操作系统_进程线程_内存_调度_同步.md)

**答案要点**
- 组件：互斥锁 + 两个条件变量（`not_full`、`not_empty`）+ 队列。生产者在队满时等待 `not_full`，消费者在队空时等待 `not_empty`。
- 必须用 `while` 检查条件而不是 `if`，因为存在虚假唤醒与多个等待者竞争。
- 入队/出队后 `notify_one` 对方；关闭队列时 `notify_all` 并让等待者退出。
- 替代：信号量实现（`empty` 与 `full` 两个计数信号量 + 互斥）；单生产者单消费者可用无锁环形缓冲区。

```cpp
template<class T> class BQ {
    std::mutex m; std::condition_variable ne, nf; std::queue<T> q; size_t cap;
public:
    explicit BQ(size_t c): cap(c) {}
    void push(T v){ std::unique_lock l(m); nf.wait(l,[&]{return q.size()<cap;});
                    q.push(std::move(v)); ne.notify_one(); }
    T pop(){ std::unique_lock l(m); ne.wait(l,[&]{return !q.empty();});
             T v=std::move(q.front()); q.pop(); nf.notify_one(); return v; }
};
```

**English short answer**
I protect a queue with a mutex and use two condition variables, one for not-full and one for not-empty. Producers wait while the queue is full and consumers wait while it is empty, and each side notifies the other after changing the queue. The wait must be in a loop or use a predicate because of spurious wakeups.

（译：互斥锁保护队列，用 not_full / not_empty 两个条件变量；队满生产者等待、队空消费者等待，操作后通知对方；因虚假唤醒必须用谓词/循环等待。）

**追问方向**：如何优雅关闭；为什么 notify 前不一定要持锁。

### Q36 手写线程池的核心结构？（Implement a thread pool）
**优先级：★★★** · 对应基础知识：[操作系统_进程线程_内存_调度_同步](../../02_基础知识/14_计算机基础/02_操作系统_进程线程_内存_调度_同步.md)

**答案要点**
- 组成：固定数量的工作线程、任务队列（受互斥锁与条件变量保护）、停止标志。
- 工作线程循环：等待"队列非空或停止"；取任务；解锁后执行（执行任务时不能持锁）。
- `submit` 返回 `future`：用 `packaged_task` 包装，使调用方可以拿结果或异常。
- 关闭：置停止标志、`notify_all`、`join` 全部线程；决定是否执行完队列中剩余任务。
- 设计取舍：线程数（CPU 密集 ≈ 核数，IO 密集可更多）；队列有界以做背压；任务异常不能让工作线程退出；避免任务里再提交并等待同一线程池的任务（死锁）。
- 实时系统中线程池的任务延迟不确定，控制回路通常不放在通用线程池里。

**English short answer**
A thread pool has worker threads that loop waiting on a condition variable for tasks, a protected queue, and a stop flag. Workers pop a task, release the lock, and run it. Submit wraps the task in a packaged task and returns a future. Shutdown sets the flag, wakes everyone, and joins. A bounded queue gives back-pressure, and I avoid tasks that wait on the same pool because that can deadlock.

（译：线程池含循环等待条件变量的工作线程、受保护的任务队列和停止标志；取任务后解锁再执行；submit 返回 future；关闭时置标志、唤醒并 join；有界队列提供背压，避免任务在同一池中等待自身依赖以免死锁。）

**追问方向**：任务窃取；控制回路为什么不放线程池。

### Q37 手写无锁单生产者单消费者环形缓冲区？（Lock-free SPSC ring buffer）
**优先级：★★★** · 对应基础知识：[操作系统_进程线程_内存_调度_同步](../../02_基础知识/14_计算机基础/02_操作系统_进程线程_内存_调度_同步.md)

**答案要点**
- 结构：固定大小数组（容量取 2 的幂，用位与取模）、`head`（消费者读位置）、`tail`（生产者写位置），各自只被一方写入。
- 写：若 `(tail+1)&mask == head` 则满；否则写数据，再用 **release** 语义更新 `tail`。读：若 `head==tail` 则空；用 **acquire** 读 `tail` 后读数据，再 release 更新 `head`。
- 正确性：数据写入先于 `tail` 发布（release），消费者看到新 `tail` 时也能看到数据（acquire）。
- `head` 与 `tail` 放在不同缓存行，避免伪共享（false sharing）。
- 典型用途：中断到任务的数据传递、传感器数据流、日志；在 STM32 上通常把 ISR 当生产者、任务当消费者，并注意 `volatile` 并不能代替内存序（Cortex-M 单核时编译器屏障通常足够，多核需原子指令）。

**English short answer**
An SPSC ring buffer has a fixed array with a head index written only by the consumer and a tail index written only by the producer. The producer writes the element and then publishes the tail with release semantics; the consumer reads the tail with acquire semantics. No locks are needed because each index has a single writer. I put head and tail on separate cache lines to avoid false sharing.

（译：SPSC 环形缓冲区的 head 仅消费者写、tail 仅生产者写；生产者写数据后以 release 发布 tail，消费者以 acquire 读 tail；每个索引单写者故无需锁；head 与 tail 分缓存行避免伪共享。）

**追问方向**：多生产者怎么办；Cortex-M 上 ISR 与任务通信的内存屏障。

### Q38 手写字典树（Trie）与应用？（Trie）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 每个结点保存子结点映射（数组 26 个或哈希表）和"是否单词结尾"标志；插入/查找/前缀查询均 $O(L)$（词长），与词典大小无关。
- 空间换时间：字符集大时用哈希表存子结点；可压缩为基数树（radix tree）。
- 应用：自动补全、拼写检查、IP 路由最长前缀匹配、敏感词过滤（配合 AC 自动机）、命令行补全。
- 异或最大值问题：把整数按二进制位建 01-Trie。

**English short answer**
A trie stores strings as paths where each node maps characters to children and marks word endings. Insert, search and prefix queries cost O(L) for a word of length L regardless of dictionary size. It powers autocomplete, longest-prefix routing, and with failure links, multi-pattern matching in the Aho-Corasick automaton.

（译：Trie 把字符串存成路径，插入/查找/前缀查询均 $O(L)$，与词典大小无关；用于自动补全、最长前缀路由，加失败指针即 AC 自动机。）

**追问方向**：内存占用如何压缩；01-Trie 求最大异或对。

### Q39 手写二叉树的遍历（迭代版）？（Iterative tree traversals）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 递归遍历深度大时有栈溢出风险，面试常要求迭代。
- 中序：用栈，不断向左压栈；弹出访问；转向右子树。先序：弹出即访问，先压右后压左。后序：先序变体（根-右-左）再反转，或用 `prev` 指针判断右子树是否已访问。
- 层序：队列，按层处理（记录每层大小）。
- Morris 遍历：利用空闲的右指针做线索，$O(1)$ 额外空间，会临时修改树结构。
- 二叉搜索树的中序遍历是升序，用来验证 BST 或求第 k 小。

```python
def inorder(root):
    st, cur, out = [], root, []
    while cur or st:
        while cur: st.append(cur); cur = cur.left
        cur = st.pop(); out.append(cur.val); cur = cur.right
    return out
```

**English short answer**
For iterative inorder I push nodes while going left, pop and visit, then move to the right child. Preorder visits on pop, and postorder is easiest as a reversed root-right-left pass. Level order uses a queue. Morris traversal gets O(1) extra space by temporarily threading null right pointers. Inorder on a BST is sorted, which helps validate it.

（译：迭代中序先一路向左压栈，弹出访问再转右子树；先序弹出即访问；后序可用反转的根-右-左；层序用队列；Morris 借空右指针做线索达到 $O(1)$ 空间；BST 中序有序。）

**追问方向**：最近公共祖先怎么求；序列化与反序列化二叉树。

### Q40 如何分析一段代码的时间与空间复杂度？（Complexity analysis）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 循环：嵌套循环相乘；每次折半的循环 $O(\log n)$；调和级数 $\sum n/i = O(n\log n)$。
- 递归：用递归树或主定理 $T(n)=aT(n/b)+f(n)$；归并 $2T(n/2)+O(n)=O(n\log n)$；二分 $T(n/2)+O(1)=O(\log n)$。
- 均摊：动态数组扩容 2 倍，$n$ 次 `push_back` 总成本 $O(n)$，均摊 $O(1)$。
- 空间：递归栈也算空间（深度 $d$ 则 $O(d)$）；输出结果是否计入要说明。
- 区分最好、平均、最坏；明确输入规模变量（图问题常用 $V,E$，二维数组 $m,n$）。

**English short answer**
I count how often the innermost statement runs: nested loops multiply, halving loops give log n, and recursion is analyzed with a recursion tree or the master theorem. For amortized cost, I use aggregate counting, like doubling a dynamic array. I also count the recursion stack as space and say which input variables the bound depends on.

（译：数最内层语句执行次数：嵌套相乘、折半得对数、递归用递归树或主定理；均摊用聚合分析（如数组倍增）；递归栈计入空间，并说明复杂度对应哪些变量。）

**追问方向**：主定理三种情形；为什么 `push_back` 倍增而不是每次加固定量。

### Q41 如何在白板题中沟通和测试？（Communicating during coding interviews）
**优先级：★★★**

**追问方向**：被面试官提示后如何表现；时间不够时先交付什么。

### Q42 如何把算法题与机器人问题联系起来？（Linking algorithms to robotics）
**优先级：★★** · 对应基础知识：[图搜索_Dijkstra_A星](../../02_基础知识/08_规划与导航/01_图搜索_Dijkstra_A星.md)

**答案要点**

（译：最短路对应全局规划；优先队列是 A* 的 open 表；多源 BFS 得到代价地图的距离变换；KD 树/八叉树加速点云最近邻；并查集做连通区域标记；二分用于按时间戳查找最近帧。）

### Q43 合并区间与区间类问题的统一做法？（Merge intervals）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 先按起点排序，再线性扫描：当前区间起点 ≤ 结果末区间终点则合并（更新终点为较大者），否则开新区间。$O(n\log n)$。
- 相关题：插入区间、会议室（最多同时开会数 = 扫描线：起点 +1、终点 -1，排序后累加取最大；或最小堆存结束时间）、无重叠区间（按终点排序贪心）、用最少箭射气球。
- 扫描线思想：把区间转成事件点，排序后维护计数；机器人里类似"多传感器时间窗口求交集/并集"。
- 边界：端点相接是否算重叠，需与面试官确认。

**English short answer**
I sort intervals by start and sweep once, merging when the next start is not past the current end. For meeting rooms I either use a min-heap of end times or a sweep line with start events plus one and end events minus one. Sorting dominates, so the cost is O(n log n). I always ask whether touching endpoints count as overlap.

（译：按起点排序后一次扫描，起点不超过当前终点就合并；会议室问题用小根堆或扫描线；排序主导复杂度 $O(n\log n)$；需确认端点相接是否算重叠。）

**追问方向**：在线插入区间怎么做（平衡树）；二维矩形并集面积。

### Q44 矩阵与网格题的常见技巧？（Matrix and grid problems）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 遍历：方向数组 `dirs=[(1,0),(-1,0),(0,1),(0,-1)]`，统一越界判断；螺旋遍历用四个边界收缩。
- 原地旋转 90°：先转置再每行反转；原地置零用首行首列做标记。
- 搜索：岛屿数量（DFS/BFS/并查集）、最短路径（BFS）、单词搜索（回溯 + 访问标记）。
- DP：不同路径、最小路径和、最大正方形（`dp[i][j]=min(上,左,左上)+1`）。
- 二维前缀和与二分：有序矩阵搜索可从右上角出发，每步排除一行或一列，$O(m+n)$。
- 机器人：占据栅格就是 0/1/概率矩阵，膨胀（inflation）等价于对障碍做卷积/距离阈值。

**English short answer**
For grids I use a directions array with a single bounds check, BFS for shortest paths, DFS or union-find for connected regions, and DP for path counting or the largest square. To search a row- and column-sorted matrix I start at the top-right corner and discard a row or column each step, which is O(m plus n).

（译：网格题用方向数组与统一越界检查，BFS 求最短路，DFS/并查集求连通区域，DP 做路径计数与最大正方形；行列有序矩阵从右上角出发每步排除一行或一列，$O(m+n)$。）

**追问方向**：原地算法的状态编码；占据栅格膨胀的复杂度。

### Q45 设计题"数据流中位数/滑动统计"怎么做？（Median of a data stream）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 双堆：大根堆存较小的一半，小根堆存较大的一半，保持两堆大小差 ≤ 1；中位数为较大堆堆顶或两堆顶平均。插入 $O(\log n)$，查询 $O(1)$。
- 若数值范围小：计数桶 + 累加定位，$O(1)$ 近似。
- 滑动窗口中位数：双堆 + 延迟删除，或有序容器（C++ `multiset` 加迭代器维护中位指针）。
- 机器人类比：中值滤波（median filter）抑制尖峰噪声，窗口小时直接排序即可；窗口大时用上述结构。

**English short answer**
I keep two heaps: a max-heap for the lower half and a min-heap for the upper half, balanced to differ in size by at most one. The median is the top of the larger heap or the mean of both tops. Insert is O(log n) and query is O(1). A median filter on sensor data is the same idea over a sliding window.

（译：用大根堆存较小一半、小根堆存较大一半并保持平衡，中位数取堆顶；插入 $O(\log n)$、查询 $O(1)$；传感器中值滤波是滑动窗口版本。）

**追问方向**：窗口中位数的删除怎么处理；近似分位数（t-digest、直方图）。

### Q46 如何判断一个二叉树是 BST、平衡树或对称树？（Tree property checks）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 验证 BST：不能只比较父子，必须传递上下界 `(lo, hi)`；或中序遍历检查严格递增。
- 平衡二叉树：后序求高度，同时判断左右高度差 ≤ 1，不平衡时返回特殊值（如 -1）提前终止，$O(n)$。
- 对称树：同时递归比较 `left.left` 与 `right.right`、`left.right` 与 `right.left`。
- 最近公共祖先：递归，左右都找到则当前结点为 LCA；BST 可利用大小关系 $O(h)$。
- 共性：树题多用"后序返回信息 + 全局变量"的结构。

**English short answer**
To validate a BST I pass down lower and upper bounds, or check that the inorder sequence is strictly increasing; comparing only parent and child is wrong. For balance, I compute heights in post-order and abort early on imbalance. For symmetry, I compare mirrored children recursively. These all follow the pattern of returning information from subtrees.

（译：验证 BST 要传递上下界或检查中序严格递增；平衡性用后序算高度并在失衡时提前返回；对称性递归比较镜像子树；都是"子树返回信息"的模式。）

**追问方向**：红黑树的五条性质；如何在 $O(1)$ 空间验证 BST。

### Q47 随机化算法与蓄水池抽样？（Randomized algorithms and reservoir sampling）
**优先级：★★** · 对应基础知识：[概率统计与高斯分布](../../02_基础知识/01_数学基础/03_概率统计与高斯分布.md)

**答案要点**
- 蓄水池抽样：从长度未知的数据流中等概率选 1 个：第 $i$ 个元素以 $1/i$ 的概率替换当前样本。归纳证明每个元素最终被选中概率均为 $1/n$。选 $k$ 个：前 $k$ 个先放入，之后第 $i$ 个以 $k/i$ 概率随机替换一个。
- Fisher-Yates 洗牌：从后向前，第 $i$ 位与 $[0,i]$ 随机位置交换，$O(n)$，得到均匀排列；常见错误是每次从全范围随机交换，产生非均匀分布。
- 随机化快排、随机枢轴避免最坏情况；Bloom filter 用于概率性成员检测（可能误报，不会漏报）。
- 机器人：粒子滤波的重采样（低方差重采样）、RRT 的随机采样、数据增强。

**English short answer**
Reservoir sampling picks k uniform items from a stream of unknown length: the i-th item replaces a random reservoir slot with probability k over i, and induction shows each item ends up with equal probability. Fisher-Yates shuffles in place in linear time with a uniform result. Randomization also appears in quicksort pivots, RRT sampling and particle filter resampling.

（译：蓄水池抽样对未知长度数据流均匀抽 k 个，第 $i$ 个以 $k/i$ 概率替换，归纳可证等概率；Fisher-Yates 线性原地均匀洗牌；随机化也用于快排枢轴、RRT 采样、粒子滤波重采样。）

**追问方向**：为什么"每次全范围随机交换"不均匀；Bloom filter 的误报率。

### Q48 外部排序与海量数据处理的思路？（External sorting and big-data tricks）
**优先级：★★** · 对应基础知识：[操作系统_进程线程_内存_调度_同步](../../02_基础知识/14_计算机基础/02_操作系统_进程线程_内存_调度_同步.md)

**答案要点**
- 数据大于内存：**分块排序 + 多路归并**。把数据切成内存能容纳的块，各自排序写盘；再用最小堆做 $k$ 路归并，顺序读写磁盘。
- 海量去重/统计：哈希分片到多个小文件，同值必入同一文件，再分别统计；或位图（bitmap）、布隆过滤器节省空间。
- 找中位数：按值域分桶计数，定位中位数所在桶后再细分；或分治思想。
- 两个大文件求交集：对其中一个建布隆过滤器或哈希，另一个流式扫描。
- 先估算：$10^9$ 个 32 位整数约 4 GB；位图只需 $2^{32}/8=512$ MB，估算内存是方案选择的出发点。

**English short answer**
When data does not fit in memory I sort chunks that do fit, write them to disk, and merge them with a k-way merge using a min-heap. For counting or de-duplication I hash-partition into small files so equal keys land together. Bitmaps and Bloom filters trade exactness for memory. I always start by estimating the data size.

（译：数据超内存时分块排序再用最小堆多路归并；去重统计先哈希分片使同值落在同文件；位图和布隆过滤器以精确度换内存；先估算数据规模。）

**追问方向**：布隆过滤器参数如何选；归并时磁盘 IO 的优化。

### Q49 栈的典型应用：括号匹配与表达式求值？（Stack applications）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 括号匹配：遇左括号入栈，遇右括号弹栈并检查类型是否配对；结束时栈必须为空。$O(n)$。
- 表达式求值（Dijkstra 双栈法）：一个数栈、一个运算符栈；遇运算符时，若栈顶运算符优先级不低于当前，就先弹出计算；括号按优先级最高处理。也可转为后缀表达式（逆波兰）后用单栈求值。

**English short answer**
For bracket matching I push opening brackets and pop on closing ones, checking the types, and the stack must be empty at the end. For expressions I use two stacks, one for operands and one for operators, applying operators when precedence says so, or I convert to postfix. A min-stack keeps a parallel stack of minima to answer in constant time.

（译：括号匹配用栈，结束时须为空；表达式求值用数栈+符号栈或转后缀；最小栈用辅助栈同步记录最小值，$O(1)$ 取最小。）

**追问方向**：两个栈实现队列的均摊分析；带函数调用的表达式。

### Q50 接雨水有哪些解法？（Trapping rain water）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 某位置能存的水 = `min(左侧最高, 右侧最高) - 高度`。
- 预处理左右最高数组，$O(n)$ 时间 $O(n)$ 空间；双指针：维护 `left_max/right_max`，哪边的最高较小就结算哪边，$O(n)$、$O(1)$；单调栈：遇到更高的柱子时弹栈，按"凹槽"逐层累计宽度×高度差。
- 正确性：较小一侧的水位由自身一侧的最高柱决定，另一侧一定不低于它。
- 面试中三种解法的联系：都在回答"每个位置的水位由谁限制"。

**English short answer**
The water above a bar equals the minimum of the tallest bars on its left and right minus its own height. I can precompute prefix and suffix maxima, or use two pointers that always process the side with the smaller maximum, which is O(n) time and O(1) space. A monotonic stack computes it layer by layer.

（译：每格水量 = 左右最高柱较小者 − 自身高度；可预处理前后缀最大值，或用双指针处理最高值较小一侧，$O(n)$ 时间 $O(1)$ 空间；单调栈按层累计。）

**追问方向**：二维接雨水（优先队列从边界向内）。

### Q51 线段树与树状数组有什么区别？（Segment tree vs Fenwick tree）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 问题：数组上频繁做"单点修改 + 区间查询"（和、最值），前缀和修改是 $O(n)$，不适合。
- 树状数组（BIT）：代码短，利用 `lowbit(i)=i&-i` 管理区间，单点更新与前缀查询均 $O(\log n)$，只适合可逆运算（和、异或）。
- 线段树：每个结点管一段区间，支持区间最值、区间加（配合懒标记 lazy propagation）、区间赋值等更复杂操作，$O(\log n)$，空间约 $4n$。
- 选择：只需前缀和/区间和 → 树状数组；需区间最值或区间更新 → 线段树。

**English short answer**
Both give logarithmic point updates and range queries. A Fenwick tree is short and uses lowbit, but supports only invertible operations like sums. A segment tree handles minima, maxima and range updates with lazy propagation, at the cost of more code and memory.

（译：二者点更新与区间查询均 $O(\log n)$；树状数组代码短但只支持可逆运算；线段树可处理最值、区间更新（懒标记），代价是代码和内存更多。）

**追问方向**：懒标记如何下推；离线+树状数组求逆序对。

### Q52 快速幂、最大公约数与素数筛？（Number theory basics）
**优先级：★★** · 对应基础知识：[数值方法与离散化](../../02_基础知识/01_数学基础/05_数值方法与离散化.md)

**答案要点**
- 快速幂：$a^n$ 通过平方折半，$O(\log n)$；取模时每次乘后取模；矩阵快速幂可加速线性递推（斐波那契 $O(k^3\log n)$）。
- 欧几里得：`gcd(a,b)=gcd(b,a%b)`，$O(\log\min(a,b))$；扩展欧几里得求模逆元；`lcm=a/gcd*b`（先除后乘防溢出）。
- 埃氏筛：从小到大把素数的倍数标记为合数，$O(n\log\log n)$；线性筛每个合数只被最小质因子筛一次，$O(n)$。
- 判断单个数是否素数：试除到 $\sqrt n$。
- 溢出：C/C++ 中 `a*b` 取模前可能超过 64 位，需 `__int128` 或快速乘。

**English short answer**
Fast exponentiation squares the base and halves the exponent, giving O(log n), and the same trick works on matrices for linear recurrences. Euclid's algorithm computes the gcd in logarithmic time. The sieve of Eratosthenes marks multiples of each prime in O(n log log n). I watch for overflow before taking a modulus.

（译：快速幂平方折半 $O(\log n)$，矩阵版可加速线性递推；欧几里得算法对数时间求 gcd；埃氏筛 $O(n\log\log n)$；取模前注意溢出。）

**追问方向**：模逆元的求法；线性筛的实现。

### Q53 二分图判定与图着色？（Bipartite graph check）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 二分图：顶点可分成两个集合，边只连接不同集合；等价于图中没有奇数长度环。
- 判定：BFS/DFS 染两种颜色，相邻点必须异色，遇到同色相邻则不是二分图；并查集（维护"敌人"关系）也可。$O(V+E)$。
- 应用：任务与机器分配（匈牙利算法求最大匹配）、课程冲突、传感器–目标数据关联（数据关联用匈牙利算法求最小代价匹配，多目标跟踪中常见）。
- 最大匹配：匈牙利算法 $O(VE)$，Hopcroft–Karp $O(E\sqrt V)$。

**English short answer**
A graph is bipartite exactly when it has no odd cycle, and I test it by two-coloring with BFS or DFS and failing on a conflict. Maximum matching in a bipartite graph uses the Hungarian algorithm or Hopcroft-Karp. In multi-object tracking, assigning detections to tracks is a bipartite matching problem.

（译：二分图等价于无奇环，BFS/DFS 双色染色，冲突则否；最大匹配用匈牙利或 Hopcroft–Karp；多目标跟踪中的检测–轨迹关联就是二分图匹配。）

**追问方向**：最小代价匹配与匈牙利算法的关系；KM 算法。

### Q54 强连通分量与桥/割点有什么用？（SCC and bridges）
**优先级：★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 强连通分量（SCC）：有向图中互相可达的极大顶点集。Tarjan 算法用 DFS 序 `dfn` 与低点 `low`，栈中弹出一个 SCC；Kosaraju 做两次 DFS（原图 + 反图）。$O(V+E)$。缩点后得到 DAG。
- 桥与割点：删除后增加连通分量数的边/点；用 `low` 值判断（边 `(u,v)` 是桥当 `low[v] > dfn[u]`）。
- 应用：依赖环检测与合并、网络可靠性（单点故障）、2-SAT。
- 面试中一般只需说出思路，不要求默写。

**English short answer**
A strongly connected component is a maximal set of nodes that can all reach each other. Tarjan's algorithm finds them in linear time using DFS discovery times and low-link values, and condensing them gives a DAG. The same low-link idea finds bridges and articulation points, which indicate single points of failure in a network.

（译：SCC 是互相可达的极大顶点集，Tarjan 用 DFS 序和 low 值线性求解，缩点得 DAG；同样思想可找桥与割点，对应网络单点故障。）

**追问方向**：Kosaraju 与 Tarjan 的区别；用 SCC 检测服务依赖环。

### Q55 最近公共祖先（LCA）怎么求？（LCA）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 二叉树递归：若当前结点是 `p` 或 `q`，返回它；在左右子树分别递归，若两边都返回非空，则当前结点是 LCA。$O(n)$。
- BST：从根出发，`p,q` 都小于当前则向左，都大于则向右，否则当前即 LCA，$O(h)$。
- 多次查询：倍增（预处理 $2^k$ 级祖先，$O(n\log n)$ 预处理，$O(\log n)$ 查询）；Euler 序 + RMQ（稀疏表）$O(1)$ 查询；Tarjan 离线。
- 机器人类比：坐标系树（TF tree）中两个坐标系的变换，沿到最近公共祖先的路径拼接变换链。

**English short answer**
In a binary tree, recursion returns a node if it is p or q, and the first node whose left and right subtrees both return non-null is the LCA. For many queries I use binary lifting or an Euler tour with a sparse table. A TF tree uses the same idea: to transform between two frames you go up to their common ancestor and back down.

（译：二叉树递归，左右子树都返回非空的结点即 LCA；多次查询用倍增或 Euler 序+稀疏表；TF 树中两坐标系的变换就是沿到公共祖先的路径拼接。）

**追问方向**：倍增表的构造；TF 查找的复杂度。

### Q56 手写 Dijkstra 与 A*（带优先队列）？（Implement Dijkstra and A*）
**优先级：★★★** · 对应基础知识：[图搜索_Dijkstra_A星](../../02_基础知识/08_规划与导航/01_图搜索_Dijkstra_A星.md)

**答案要点**
- Dijkstra：`dist` 初始化为无穷，起点 0；最小堆存 `(dist, node)`；弹出后若 `d > dist[u]` 跳过（懒删除）；松弛邻居 `dist[v]>dist[u]+w` 则更新并入堆。$O((V+E)\log V)$。
- A*：堆的键改为 `f=g+h`；`h` 可采纳（不超过真实代价）保证最优；一致性保证关闭表中的结点不会被重新打开。栅格上 4 邻域用曼哈顿距离，8 邻域用对角距离/八方向距离，连续空间欧氏距离。
- 记录 `parent` 数组回溯路径；`closed` 集合避免重复扩展。
- 优化：启发权重 $w>1$（加权 A*）牺牲最优性换速度；双向搜索；跳点搜索（JPS）在均匀栅格上加速。

```python
import heapq
def dijkstra(adj, s):
    dist = {s: 0}; pq = [(0, s)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist.get(u, float('inf')): continue
        for v, w in adj[u]:
            nd = d + w
            if nd < dist.get(v, float('inf')):
                dist[v] = nd; heapq.heappush(pq, (nd, v))
    return dist
```

**English short answer**
Dijkstra keeps a min-heap of distance and node, skips stale entries, and relaxes neighbors. A star is the same with the heap keyed by cost-so-far plus a heuristic estimate to the goal. If the heuristic never overestimates, the path is optimal. I keep a parent map to reconstruct the path, and I choose the heuristic to match the grid connectivity.

（译：Dijkstra 用最小堆、跳过过期项并松弛邻居；A* 的键为已走代价加启发估计，启发不高估则最优；用 parent 回溯路径，启发函数要匹配栅格连通性。）

**追问方向**：加权 A* 的次优界；JPS 的原理。

### Q57 用数据结构设计：O(1) 增删与随机取元素？（Insert/delete/getRandom in O(1)）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 需求：`insert`、`remove`、`getRandom` 全部平均 $O(1)$。
- 方案：动态数组存元素 + 哈希表存"元素 → 下标"。删除时把要删元素与数组末尾元素交换，更新被交换元素的下标，再弹出末尾；随机取则 `arr[rand(0, n-1)]`。
- 关键点：为何不能直接在数组中间删除（$O(n)$ 搬移）；有重复元素时哈希表值改为下标集合。
- 同类设计题：LFU、最小栈、带过期时间的缓存（堆 + 哈希）、时间戳键值存储（二分）。

**English short answer**
I keep elements in a dynamic array and a hash map from value to index. To delete, I swap the target with the last element, update its index in the map, and pop the end, so everything stays constant time on average. Random selection just picks a random array index.

（译：动态数组存元素、哈希表存元素到下标；删除时与末尾元素交换并更新下标再弹出，保持平均 $O(1)$；随机取直接随机数组下标。）

**追问方向**：允许重复元素的版本；带权随机选择（前缀和 + 二分）。

### Q58 如何用有限的随机数发生器构造另一个？（Rejection sampling）
**优先级：★** · 对应基础知识：[概率统计与高斯分布](../../02_基础知识/01_数学基础/03_概率统计与高斯分布.md)

**答案要点**
- 由 `rand5()` 构造 `rand7()`：用 `5*(rand5()-1)+rand5()` 得到 1..25 均匀分布，若结果 > 21 则丢弃重来，否则对 7 取模加 1；这是**拒绝采样**。
- 期望尝试次数有限，每次接受概率 $21/25$。
- 一般原理：要得到均匀分布，需保证被接受区域能被均匀划分，丢弃多余部分，不能直接取模（会引入偏差）。
- 应用：从圆内均匀采样（拒绝正方形外的点）、粒子滤波/蒙特卡洛中的重要性采样思想。

**English short answer**
To build a uniform one-to-seven from a uniform one-to-five, I combine two calls into a uniform value from one to twenty-five, reject values above twenty-one, and take the rest modulo seven. Rejection keeps the result unbiased, whereas taking a modulus of an uneven range would not.

（译：两次 rand5 组合成 1..25 的均匀值，丢弃大于 21 的，其余取模得 rand7；拒绝采样保证无偏，直接对不均匀范围取模会有偏。）

**追问方向**：从圆盘均匀采样；期望调用次数。

### Q59 排列与组合的生成：下一个排列、组合数的递推？（Next permutation and combinatorics）
**优先级：★★** · 对应基础知识：[概率统计与高斯分布](../../02_基础知识/01_数学基础/03_概率统计与高斯分布.md)

**答案要点**
- 下一个排列：①从右向左找第一个升序对 `a[i]<a[i+1]`；②从右向左找第一个大于 `a[i]` 的 `a[j]`，交换；③反转 `i+1` 之后的部分。$O(n)$，原地。若不存在升序对则整体反转（回到最小排列）。
- 组合数 $C(n,k)=C(n-1,k-1)+C(n-1,k)$，帕斯卡三角 $O(nk)$；避免直接算阶乘（溢出），用逐项乘除或取模逆元。
- 子集枚举：位掩码 $0..2^n-1$。
- 卡特兰数：合法括号序列、二叉树形态计数。

**English short answer**
For the next permutation I find the rightmost ascent, swap it with the next larger element from the right, and reverse the suffix, all in place and in linear time. Binomial coefficients follow Pascal's recurrence, and I avoid factorials to prevent overflow. Subsets can be enumerated with bitmasks.

（译：下一个排列：找最右升序对、与右侧下一个更大者交换、反转后缀，原地线性；组合数用帕斯卡递推避免阶乘溢出；子集用位掩码枚举。）

**追问方向**：第 k 个排列的康托展开；去重全排列。

### Q60 最小覆盖子串与字符计数类滑窗？（Minimum window substring）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 目标：在 `s` 中找包含 `t` 全部字符（含重复次数）的最短子串。
- 做法：`need` 计数表 + `missing` 变量（尚缺字符个数）。右指针扩张：若加入字符使其不再缺，则 `missing--`；当 `missing==0` 时尽量收缩左指针并更新最短答案；收缩时若字符变得短缺则 `missing++` 并结束收缩。$O(|s|+|t|)$。
- 要点：用"差值计数"而不是每次比较两个表（那样是 $O(26n)$）。
- 变形：字符串排列检测、字母异位词查找（定长窗口）、最多 K 个不同字符的最长子串。

**English short answer**
I count the characters needed and track how many are still missing. The right pointer expands, decrementing the missing count when a needed character is covered. Once nothing is missing, the left pointer shrinks as far as possible while recording the shortest window. Each pointer moves once, so the total is linear.

（译：用 need 计数表和"尚缺数量"，右指针扩张补齐，补齐后左指针尽量收缩并记录最短窗口，两个指针各走一遍，线性。）

**追问方向**：如何同时返回起止下标；Unicode 字符集如何处理。

### Q61 循环队列（环形缓冲）怎么区分满和空？（Circular queue full vs empty）
**优先级：★★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 问题：`head==tail` 既可能是空也可能是满。
- 三种办法：①牺牲一个存储单元，`(tail+1)%N==head` 为满；②额外维护 `count`；③让 `head/tail` 单调递增不取模，用 `tail-head` 表示元素数，下标时再 `& (N-1)`（N 取 2 的幂，无符号回绕仍正确）。
- 单生产者单消费者无锁时，方法①/③各自只被一方写入，天然无竞争；方法②的 `count` 被两方写，需要原子。
- 用途：串口接收缓冲、日志缓冲、传感器数据队列。

**English short answer**
When head equals tail the buffer could be empty or full. I either sacrifice one slot, keep a separate count, or let head and tail increase monotonically and mask the index, using the difference as the size. The first and third options need no shared counter, which suits lock-free single-producer, single-consumer queues such as UART receive buffers.

（译：head==tail 可能空也可能满；可牺牲一个单元、维护 count，或让指针单调递增、取下标时掩码并用差值表示元素数；前后两种无共享计数，适合无锁 SPSC，如串口接收缓冲。）

**追问方向**：无符号回绕的正确性；DMA 循环模式如何配合。

### Q62 判断链表是否回文、复制带随机指针的链表？（Palindrome list and random pointer copy）
**优先级：★★** · 对应基础知识：[算法与数据结构复习_复杂度_图_动态规划](../../02_基础知识/14_计算机基础/01_算法与数据结构复习_复杂度_图_动态规划.md)

**答案要点**
- 回文链表：快慢指针找中点，反转后半段，与前半段逐一比较，（可选）再反转恢复。$O(n)$ 时间、$O(1)$ 空间；用数组/栈则 $O(n)$ 空间。
- 复制随机指针链表：①哈希表映射原结点到新结点，两遍遍历；②O(1) 空间：把每个新结点插到原结点后面，设置 `random`（`cur.next.random = cur.random.next`），最后拆分两个链表。
- 重点：在复杂指针操作中画图、保持循环不变量，防止断链。

**English short answer**
For a palindrome list I find the middle with fast and slow pointers, reverse the second half, and compare the halves, which is O(n) time and O(1) space. For copying a list with random pointers I either use a hash map from old to new nodes, or interleave new nodes after originals so that random pointers can be set and the lists split without extra memory.

（译：回文链表：快慢指针找中点、反转后半段并比较，$O(n)$ 时间 $O(1)$ 空间；随机指针链表复制：用哈希映射，或把新结点插到原结点后以 $O(1)$ 空间设置 random 再拆分。）

**追问方向**：如何恢复被反转的链表；多线程下链表的并发修改。

## 本章要点速记
1. 题型识别：有序/成对 → 双指针；连续段条件 → 滑窗；单调谓词 → 二分（含二分答案）；下一个更大 → 单调栈。
2. 二分写法先固定不变量（左闭右开），避免溢出与死循环。
3. 回溯三步：选择、递归、撤销；去重靠排序 + 同层跳过；剪枝决定效率。
4. DP 四步：状态、转移、边界、顺序；0-1 背包倒序、完全背包正序。
5. 最短路：BFS（无权）、Dijkstra（非负）、Bellman-Ford（负权）、A*（有启发）。
6. 手写组件：LRU = 哈希 + 双向链表；堆 = 数组 + 上浮下沉；线程池/阻塞队列 = 锁 + 条件变量。
7. 沟通流程：复述 → 暴力 → 优化 → 编码 → 用例走查 → 复杂度。
