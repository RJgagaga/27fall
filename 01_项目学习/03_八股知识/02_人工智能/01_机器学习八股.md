## 一、学习理论与泛化

### Q1. 偏差-方差分解（Bias-Variance Decomposition）★★★
**答案要点**
设真实函数 $f(x)$，观测 $y=f(x)+\varepsilon$，噪声 $E[\varepsilon]=0,\ Var(\varepsilon)=\sigma^2$。在不同训练集上训练得到预测器 $\hat f(x;D)$，对某固定点 $x$ 的期望平方误差为：

$$E_{D,\varepsilon}\big[(y-\hat f)^2\big]=\underbrace{\big(E_D[\hat f]-f\big)^2}_{\text{Bias}^2}+\underbrace{E_D\big[(\hat f-E_D[\hat f])^2\big]}_{\text{Variance}}+\underbrace{\sigma^2}_{\text{不可约噪声}}$$

推导思路：把 $y-\hat f=(f-E\hat f)+(E\hat f-\hat f)+\varepsilon$，三项两两交叉项期望为零（噪声与训练集独立、$E[\hat f - E\hat f]=0$），平方展开即得。
- 偏差：模型族本身够不够灵活（线性模型拟合正弦就是高偏差）；
- 方差：对训练集扰动有多敏感（深树、高阶多项式高方差）。
模型越复杂，偏差下降、方差上升，测试误差呈 U 形。正则化、早停、bagging 降方差；增加模型容量、boosting 降偏差。注意：该分解对平方损失严格成立，对 0-1 损失只有类比。

**English short answer**
> Expected test error splits into bias squared, variance, and irreducible noise. Bias is how far the average model is from the truth; variance is how much the model changes when I resample the training set. A simple model has high bias and low variance, a complex model is the opposite. Regularization or bagging reduces variance, while a richer model or boosting reduces bias.

**追问方向**：深度学习里"双下降（double descent）"怎么解释？为什么随机森林降方差不降偏差？

### Q2. 如何判断欠拟合与过拟合，怎么处理？（Overfitting vs Underfitting）★★★
**答案要点**
看学习曲线（训练误差、验证误差随样本量或迭代的变化）：
- 欠拟合：训练误差和验证误差都高且接近 → 高偏差。对策：更复杂模型、增加特征、减弱正则、训练更久；
- 过拟合：训练误差低、验证误差高，间隙大 → 高方差。对策：更多数据、数据增强、正则化（L1/L2/dropout）、早停、降低模型容量、集成、特征选择。
过拟合本质是模型记住了训练集的噪声。诊断时先排除"数据问题"：标签噪声、训练/验证分布不一致、数据泄漏都会造成类似现象。

**English short answer**
> I look at the learning curves. If both training and validation errors are high, it's underfitting, so I add capacity or features. If training error is low but validation error is high, it's overfitting, so I add data, regularization, early stopping or simplify the model. I also check for label noise and data leakage before blaming the model.

**追问方向**：验证集误差比训练集还低是怎么回事（dropout 只在训练时开、数据划分偏差、泄漏）？

### Q3. L1 与 L2 正则化的区别（L1 vs L2 Regularization）★★★
**答案要点**
目标 $J(w)=L(w)+\lambda R(w)$，L2：$R=\|w\|_2^2$，L1：$R=\|w\|_1$。
- 梯度视角：L2 的梯度 $2\lambda w$ 与权重成比例，使权重按比例衰减（weight decay），很难精确到零；L1 的次梯度 $\lambda\,\mathrm{sign}(w)$ 是常数大小的推力，容易把小权重推到精确的 0，产生稀疏解（特征选择）。
- 几何视角：约束形式 $\min L(w)$ s.t. $\|w\|_p\le C$。L1 的约束区域是带尖角的菱形，损失等高线最先碰到的往往是坐标轴上的角点，所以稀疏；L2 是球，没有角。
- 贝叶斯视角（见 Q11）：L2 对应高斯先验，L1 对应拉普拉斯先验。
- L2 有闭式解（岭回归 $w=(X^TX+\lambda I)^{-1}X^Ty$）且解唯一、数值稳定；L1 不可导需用坐标下降或近端梯度。
- Elastic Net 同时用二者，处理相关特征成组时比单独 L1 稳定。
注意：用 Adam 时"L2 正则"与"weight decay"不等价，AdamW 把二者解耦（见深度学习八股）。

**English short answer**
> Both penalize large weights. L2 shrinks all weights smoothly toward zero, L1 pushes many weights exactly to zero, so it gives sparse models and does feature selection. Geometrically the L1 ball has corners on the axes, which is where the loss contours tend to touch. In Bayesian terms L2 is a Gaussian prior and L1 is a Laplace prior.

**追问方向**：为什么 L1 在零点不可导还能优化？（次梯度、软阈值 soft-thresholding）

### Q4. 交叉验证与数据集划分（Cross-Validation）★★★
**答案要点**
划分为训练集（拟合参数）、验证集（选超参、早停）、测试集（只用于最终一次评估）。K 折交叉验证：数据分 K 份，轮流取 1 份作验证、其余训练，取平均，降低单次划分的随机性，适合小数据；代价是训练 K 次。
要点：
- 分类用分层（stratified）保持类别比例；
- 时间序列不能随机划分，要按时间前向切分（walk-forward），否则泄漏未来；
- 同一个体/同一视频的多帧图像必须放在同一折（group k-fold），否则相邻帧高度相似，验证虚高；
- 预处理（标准化、特征选择）必须只在训练折上 fit，再 transform 验证折。
测试集一旦用来调参就不再是无偏估计。

**English short answer**
> I split data into train, validation and test sets. The validation set is for tuning, and the test set is touched only once at the end. With small data I use k-fold cross-validation and average the scores. I'm careful to stratify for classification, split by time for time series, and keep correlated samples, like frames from the same video, in the same fold.

**追问方向**：视频帧随机划分会怎样？留一法的方差与计算量？

### Q5. 维度灾难（Curse of Dimensionality）★★
**答案要点**
维度 $d$ 增大时：(1) 为保持相同的样本密度，所需数据量随 $d$ 指数增长；(2) 距离集中现象：高维空间中任意两点距离的相对差异趋于 0，$\frac{d_{max}-d_{min}}{d_{min}}\to 0$，使 KNN、K-means 等依赖距离的方法失效；(3) 单位超球体积占外接立方体比例趋于 0，数据大多落在"角落"。对策：降维（PCA）、特征选择、正则化、用先验结构（卷积的局部性）、流形假设（真实数据位于低维流形）。

**English short answer**
> As dimension grows, data becomes extremely sparse and distances between points become almost the same, so distance-based methods like KNN break down, and you'd need exponentially more samples. We fight it with dimensionality reduction, feature selection, regularization, or by using models with structural priors like convolutions.

**追问方向**：深度学习为什么在高维图像上仍然有效？（流形假设、归纳偏置）

### Q6. 没有免费午餐、归纳偏置与 VC 维（No Free Lunch / Inductive Bias / VC Dimension）★
**答案要点**
NFL 定理：对所有可能的问题取平均，任何两个算法性能一样，所以必须针对具体问题引入归纳偏置（对函数形式的假设，如线性、局部平滑、平移不变）。VC 维衡量假设类的容量：能被打散（shatter）的最大点数。泛化界形如 $R(h)\le \hat R(h)+O\!\left(\sqrt{\tfrac{d_{VC}\log(N/d_{VC})+\log(1/\delta)}{N}}\right)$：容量越大、样本越少，泛化差距越大。这个界对深度网络太松，实际中用来说明"控制容量"的直觉即可。

**English short answer**
> No free lunch says no learner beats all others on all problems, so every model needs an inductive bias, like convolution assuming translation invariance. VC dimension measures a hypothesis class's capacity, and the generalization gap grows with capacity and shrinks with more data. The bound is loose for deep nets, but it gives the right intuition.

**追问方向**：为什么大参数量网络反而泛化？（隐式正则、SGD 偏好平坦极小值）

## 二、损失函数与概率视角

### Q7. 回归损失：MSE、MAE、Huber 的比较（Regression Losses）★★★
**答案要点**
- MSE $=\frac1N\sum(y-\hat y)^2$：对应高斯噪声的最大似然；对离群点敏感（二次放大）；处处可导，梯度随误差变大，收敛快；最优预测是条件均值。
- MAE $=\frac1N\sum|y-\hat y|$：对应拉普拉斯噪声；对离群点稳健；零点不可导，梯度幅值恒定，接近最优时不衰减，需降学习率；最优预测是条件中位数。
- Huber：误差小于 $\delta$ 用二次、大于 $\delta$ 用线性：
$$L_\delta(r)=\begin{cases}\tfrac12 r^2 & |r|\le\delta\\ \delta(|r|-\tfrac12\delta) & |r|>\delta\end{cases}$$
兼顾可导与稳健。目标检测中的 Smooth L1 就是 Huber 的特例（$\delta=1$）。

**English short answer**
> MSE corresponds to Gaussian noise, it's smooth but very sensitive to outliers, and it predicts the conditional mean. MAE corresponds to Laplace noise, it's robust, and it predicts the median, but its gradient doesn't shrink near the optimum. Huber loss is quadratic near zero and linear for large errors, so it combines both. Smooth L1 in detectors is a Huber variant.

**追问方向**：分位数损失（pinball loss）？Smooth L1 为什么用于框回归？

### Q8. 从最大似然推导交叉熵（Cross-Entropy from MLE）★★★
**答案要点**
二分类：模型输出 $p=\sigma(z)=P(y=1|x)$，样本 $(x_i,y_i),y_i\in\{0,1\}$ 的似然 $\prod p_i^{y_i}(1-p_i)^{1-y_i}$。取负对数得
$$L=-\frac1N\sum_i\big[y_i\log p_i+(1-y_i)\log(1-p_i)\big]$$
多分类 softmax：$p_k=\dfrac{e^{z_k}}{\sum_j e^{z_j}}$，$L=-\sum_k y_k\log p_k$（$y$ 为 one-hot）。最小化交叉熵等价于最小化真实分布 $q$ 与预测分布 $p$ 的 KL 散度（因为 $H(q,p)=H(q)+D_{KL}(q\|p)$，$H(q)$ 对模型是常数）。
关键性质：softmax+交叉熵对 logits 的梯度为 $\partial L/\partial z_k=p_k-y_k$，简洁且不会梯度消失。

**English short answer**
> Cross-entropy is just the negative log-likelihood of the labels under the model's predicted distribution. Minimizing it is the same as minimizing the KL divergence between the true and predicted distributions. With softmax, the gradient with respect to the logits is simply prediction minus label, which is why it trains well.

**追问方向**：softmax 的数值稳定写法（减去最大值，log-sum-exp）？label smoothing 改了什么？

### Q9. 为什么分类不用 MSE？（Why not MSE for classification）★★★
**答案要点**
以 sigmoid 输出为例：MSE 损失对 $z$ 的梯度为 $(p-y)\,p(1-p)$，当预测严重错误（$p\to 0$ 而 $y=1$）时 $p(1-p)\to0$，梯度几乎为零，学得很慢（饱和）；而交叉熵梯度为 $(p-y)$，错得越离谱梯度越大。另外，MSE 配 sigmoid 的损失面对参数是非凸的，交叉熵配 logistic 回归是凸的。从概率角度，分类的噪声模型是伯努利/类别分布而不是高斯。

**English short answer**
> With a sigmoid output, the MSE gradient includes a factor p times one minus p, which vanishes when the model is confidently wrong, so learning stalls. Cross-entropy's gradient is just prediction minus label, so big mistakes give big gradients. Cross-entropy is also the right likelihood for a Bernoulli label, and it keeps logistic regression convex.

**追问方向**：回归任务用交叉熵可以吗？（可以把目标离散化，如分布式回归/DFL）

### Q10. 逻辑回归（Logistic Regression）原理与梯度 ★★★
**答案要点**
$P(y=1|x)=\sigma(w^Tx+b)$，$\sigma(z)=1/(1+e^{-z})$，决策边界 $w^Tx+b=0$ 是线性超平面。$\sigma'(z)=\sigma(1-\sigma)$。损失为交叉熵，梯度
$$\nabla_w L=\frac1N\sum_i (p_i-y_i)x_i$$
形式与线性回归的 MSE 梯度相同（只是 $p$ 换成 $\sigma$）。损失是凸函数，无闭式解，用梯度下降/牛顿法（IRLS）。特征线性可分时权重趋于无穷，需要 L2 正则。它是判别模型，系数的指数 $e^{w_j}$ 可解释为 odds ratio。多分类扩展为 softmax 回归。

**English short answer**
> Logistic regression passes a linear score through a sigmoid to get a probability, and trains with cross-entropy. The loss is convex and its gradient is the average of prediction error times the input. If the data is perfectly separable the weights blow up, so we add L2 regularization. It's a strong baseline and easy to interpret.

**追问方向**：和线性回归 + 阈值有何不同？逻辑回归为何是广义线性模型？

### Q11. 最大似然（MLE）与最大后验（MAP）★★★
**答案要点**
MLE：$\hat\theta=\arg\max_\theta \sum_i\log p(x_i|\theta)$。MAP：$\hat\theta=\arg\max_\theta[\log p(D|\theta)+\log p(\theta)]$，多了先验项。
- 高斯先验 $\theta\sim\mathcal N(0,\tau^2I)$：$-\log p(\theta)=\frac{1}{2\tau^2}\|\theta\|^2+c$，对应 L2，且 $\lambda=\sigma^2/\tau^2$（线性回归噪声方差与先验方差之比）；
- 拉普拉斯先验 $p(\theta)\propto e^{-|\theta|/b}$：对应 L1。
数据多时似然主导，MAP→MLE；数据少时先验起正则作用。完全贝叶斯则保留整个后验分布而不是点估计。

**English short answer**
> MLE picks parameters that maximize the data likelihood. MAP adds a prior, so it maximizes likelihood times prior. A Gaussian prior on the weights gives L2 regularization, and a Laplace prior gives L1. With lots of data they agree; with little data the prior matters more.

**追问方向**：线性回归 MSE 与高斯 MLE 的关系？

### Q12. 生成模型与判别模型（Generative vs Discriminative）★★
**答案要点**
判别模型直接建模 $P(y|x)$ 或决策边界（逻辑回归、SVM、神经网络、CRF）；生成模型建模联合分布 $P(x,y)=P(x|y)P(y)$，再用贝叶斯公式得后验（朴素贝叶斯、GMM、HMM、VAE、扩散模型、GPT 类自回归语言模型）。判别模型在数据多时通常分类精度更高；生成模型可采样、处理缺失数据、少样本时更稳（先验强）、可做异常检测。

**English short answer**
> Discriminative models learn the conditional probability of the label given the input, or the boundary directly. Generative models learn the joint distribution, so they can also generate data. Discriminative ones usually classify better with lots of data, while generative ones can handle missing data and work with less data.

**追问方向**：LLM 属于哪类？（自回归生成模型，也可当判别器用）

## 三、优化

### Q13. 梯度下降的三种形式（GD / SGD / Mini-batch）★★★
**答案要点**
更新 $\theta\leftarrow\theta-\eta\nabla_\theta L$。批量 GD 用全部样本，梯度准但每步贵；SGD 每次一个样本，噪声大，但便宜且噪声有助于逃离鞍点/尖锐极小值；mini-batch 折中，利用 GPU 并行，是实践标准。学习率 $\eta$ 过大震荡发散，过小收敛慢；常用 warmup+衰减（cosine、step）。对强凸二次函数，GD 收敛需要 $\eta<2/L$（$L$ 为梯度 Lipschitz 常数，即 Hessian 最大特征值），条件数 $\kappa=L/\mu$ 越大越慢，这就是特征标准化的意义。batch size 增大时学习率通常线性放大（linear scaling rule）。

**English short answer**
> Batch gradient descent uses all the data per step, SGD uses one sample, and mini-batch uses a small chunk, which is what we always use in practice. The noise from SGD is actually helpful for escaping saddle points. The learning rate is the key knob: too large and it diverges, too small and it crawls, so we usually use warmup and decay.

**追问方向**：为什么特征不标准化会慢？（条件数、等高线呈狭长椭圆）

### Q14. 动量与自适应学习率：Momentum、RMSProp、Adam ★★★
**答案要点**
- Momentum：$v\leftarrow\beta v+g,\ \theta\leftarrow\theta-\eta v$，累积历史梯度，抑制震荡，沿一致方向加速。
- RMSProp：$s\leftarrow\rho s+(1-\rho)g^2,\ \theta\leftarrow\theta-\eta g/(\sqrt s+\epsilon)$，按参数调节步长。
- Adam：一阶矩 $m=\beta_1m+(1-\beta_1)g$，二阶矩 $v=\beta_2v+(1-\beta_2)g^2$，偏置修正 $\hat m=m/(1-\beta_1^t),\hat v=v/(1-\beta_2^t)$，更新 $\theta\leftarrow\theta-\eta\hat m/(\sqrt{\hat v}+\epsilon)$。默认 $\beta_1=0.9,\beta_2=0.999,\epsilon=10^{-8}$。偏置修正是因为 $m,v$ 初始为 0，早期估计偏小。
Adam 收敛快、对学习率较不敏感；SGD+momentum 在视觉任务上泛化常更好。细节见 [02_深度学习八股](./02_深度学习八股.md)。

**English short answer**
> Momentum accumulates past gradients to smooth out oscillations. RMSProp scales each parameter's step by the running average of its squared gradient. Adam combines both, with bias correction because the moving averages start at zero. Adam is fast and robust to learning rate, while SGD with momentum often generalizes slightly better in vision.

**追问方向**：Adam 的偏置修正为什么必要？AdamW 改了什么？

### Q15. 凸优化、局部极小与鞍点（Convexity, Local Minima, Saddle Points）★★
**答案要点**
凸函数任一局部极小即全局极小；线性/逻辑回归、SVM、岭回归损失都是凸的，神经网络损失非凸。高维非凸问题中，驻点大多数是鞍点而非局部极小（Hessian 特征值正负混合，所有特征值同为正的概率随维度指数减小）；实验表明大网络的局部极小值质量相近。逃离鞍点靠噪声（SGD）与动量。二阶方法（牛顿法 $\theta\leftarrow\theta-H^{-1}g$）收敛快但 $O(d^2)$ 存储与 $O(d^3)$ 求逆，深度学习中不可行，用 L-BFGS、K-FAC 等近似。

**English short answer**
> For convex losses, like logistic regression or SVM, any local minimum is global. Neural nets are non-convex, but in high dimensions most critical points are saddle points, and SGD noise and momentum help escape them. Newton's method converges fast but needs the Hessian, which is too expensive for large models.

**追问方向**：Hessian 特征值如何判别极小/鞍点？

### Q16. 学习率调度与梯度裁剪 ★★
**答案要点**
常用：step decay、指数衰减、cosine annealing $\eta_t=\eta_{min}+\frac12(\eta_{max}-\eta_{min})(1+\cos\frac{t\pi}{T})$、warmup（初期线性升高，避免 Adam 二阶矩估计未稳时的大步）、OneCycle。梯度裁剪按范数 $g\leftarrow g\cdot\min(1,c/\|g\|)$，防止梯度爆炸（RNN、Transformer 训练常用）。

**English short answer**
> A common recipe is a short linear warmup followed by cosine decay. Warmup avoids unstable big steps early on, when adaptive optimizers have poor statistics. Gradient clipping rescales the gradient when its norm exceeds a threshold, which prevents exploding gradients.

**追问方向**：裁剪按值与按范数的区别？

## 四、评价指标

### Q17. 混淆矩阵与 Precision / Recall / F1 ★★★
**答案要点**
二分类混淆矩阵：TP、FP、FN、TN。
$$P=\frac{TP}{TP+FP},\quad R=\frac{TP}{TP+FN},\quad F_1=\frac{2PR}{P+R},\quad F_\beta=\frac{(1+\beta^2)PR}{\beta^2P+R}$$
Precision 关心"报出来的有多少是真的"，Recall 关心"真的有多少被找到"。调整阈值使二者此消彼长。F1 是调和平均，对低值更敏感。多分类的 macro（各类平均，重视少数类）、micro（全局统计，受大类主导）、weighted 平均。场景：垃圾邮件看 Precision，癌症筛查看 Recall。

**English short answer**
> Precision is the fraction of predicted positives that are correct, and recall is the fraction of real positives we found. Moving the threshold trades one for the other. F1 is their harmonic mean. Which one matters depends on cost: for cancer screening I'd favor recall, for spam filtering I'd favor precision.

**追问方向**：为什么用调和平均而不是算术平均？macro 与 micro 的差别？

### Q18. ROC、AUC 与 PR 曲线 ★★★
**答案要点**
ROC：横轴 $FPR=FP/(FP+TN)$，纵轴 $TPR=Recall$，遍历阈值得到曲线。AUC 的概率解释：随机抽一个正样本和一个负样本，模型给正样本打分更高的概率。AUC 对类别比例不敏感，因为 TPR 和 FPR 分别在各自类内归一化。极度不平衡时，TN 极大使 FPR 很小，ROC 看起来很漂亮，而 PR 曲线（Precision 受 FP 数量直接影响）更能暴露问题，所以不平衡、关注正类时优先看 PR / AP。

**English short answer**
> The ROC curve plots true positive rate against false positive rate over all thresholds, and AUC is the probability that a random positive is scored above a random negative. It's insensitive to class ratio. But with severe imbalance the huge number of negatives keeps the false positive rate small, so ROC looks too good, and I prefer the precision-recall curve.

**追问方向**：AUC 如何计算（排序法/ Mann-Whitney U）？AUC=0.5 意味着什么？

### Q19. 回归指标：RMSE、MAE、R² ★★
**答案要点**
$RMSE=\sqrt{\frac1N\sum(y-\hat y)^2}$（与目标同量纲，惩罚大误差），$MAE$（稳健），$R^2=1-\frac{\sum(y-\hat y)^2}{\sum(y-\bar y)^2}$，表示相对"总预测均值"基线提升了多少；$R^2$ 可为负（比用均值还差）。MAPE 对接近 0 的真值不稳定。

**English short answer**
> RMSE is in the same units as the target and penalizes large errors, MAE is more robust to outliers, and R squared tells how much better the model is than always predicting the mean. R squared can be negative when the model is worse than that baseline.

**追问方向**：怎样选择指标与业务代价对应？

### Q20. 分类阈值选择与概率校准（Threshold & Calibration）★★
**答案要点**
默认阈值 0.5 仅在类别均衡、代价对称时最优。可在验证集上按 F1 或代价最小选阈值。校准指预测概率与真实频率一致：用可靠性图（reliability diagram）和 ECE 评估；方法有 Platt scaling（对 logit 拟合 sigmoid）、isotonic regression、temperature scaling（除以温度 $T$ 再 softmax，现代深度网络通常过度自信）。过采样/类权重改变了先验，需要校正后验概率。

**English short answer**
> The default 0.5 threshold is only optimal when classes are balanced and costs are symmetric, so I tune it on the validation set. Calibration is about whether a predicted 0.8 really means 80 percent. Modern deep nets are usually overconfident, and temperature scaling is a simple fix.

**追问方向**：什么场景必须校准？（风控、医疗、机器人决策的置信度阈值）

### Q21. 排序与检索指标：Top-k、MRR、NDCG、mAP 概念 ★
**答案要点**
Top-k 准确率：正确答案是否在前 k 个。MRR=首个正确结果排名倒数的平均。NDCG：$DCG@k=\sum_{i=1}^k\frac{2^{rel_i}-1}{\log_2(i+1)}$，除以理想排序的 DCG 归一化，考虑位置折扣和分级相关性。检测用的 mAP 见 [03_计算机视觉与目标检测八股](./03_计算机视觉与目标检测八股.md)；RAG 检索指标见 [07_Agent与RAG八股](./07_Agent与RAG八股.md)。

**English short answer**
> Top-k checks whether the correct answer is among the first k results. MRR averages the inverse rank of the first correct result. NDCG gives graded relevance with a logarithmic position discount and is normalized by the ideal ranking.

**追问方向**：检索与检测里的 AP 有何异同？

### Q22. 离线指标好但线上差的原因 ★★
**答案要点**
数据泄漏；训练/线上分布漂移（covariate shift、label shift、concept drift）；采样偏差（只在被选中的样本上有标签）；指标与业务目标不一致；特征线上线下计算不一致（training-serving skew）；测试集被反复调参而过拟合。对机器人：仿真到真机（sim2real）、传感器噪声和延迟差异是典型来源。对策：线上监控、影子模式（shadow mode）、A/B 测试、持续重训练。

**English short answer**
> Common causes are data leakage, distribution shift between training and deployment, training-serving skew in features, and metrics that don't match the real goal. In robotics, the sim-to-real gap and sensor latency are classic examples. I'd run shadow mode and monitor the input distribution before trusting the offline number.

**追问方向**：如何检测分布漂移？（PSI、KS 检验、对抗验证）

## 五、线性模型、KNN、朴素贝叶斯

### Q23. 线性回归：正规方程与岭回归 ★★★
**答案要点**
模型 $\hat y=Xw$，损失 $\frac12\|y-Xw\|^2$，令梯度 $X^T(Xw-y)=0$ 得正规方程 $w=(X^TX)^{-1}X^Ty$。当 $X^TX$ 奇异（特征共线、$d>N$）时不可逆；岭回归加 $\lambda I$：$w=(X^TX+\lambda I)^{-1}X^Ty$，保证可逆并缩小方差。用 SVD $X=U\Sigma V^T$，岭回归对应把奇异值 $\sigma_i$ 的作用缩放为 $\sigma_i^2/(\sigma_i^2+\lambda)$，小奇异值方向被强烈压制，这就是它抑制共线噪声的机制。求解时避免显式求逆，用 QR/Cholesky。

**English short answer**
> Setting the gradient of the squared error to zero gives the normal equation, w equals X transpose X inverse times X transpose y. If features are collinear the matrix is singular, so ridge regression adds lambda times identity, which makes it invertible and shrinks directions with small singular values. In practice I'd use QR or SVD rather than an explicit inverse.

**追问方向**：线性回归的高斯-马尔可夫假设？多重共线性怎么检测（VIF）？

### Q24. KNN（K-Nearest Neighbors）★★
**答案要点**
惰性学习：训练时只存数据，预测时找 $k$ 个最近邻，分类投票、回归求平均。$k$ 小则方差大（过拟合），$k$ 大则偏差大。距离度量（欧氏、曼哈顿、余弦）与特征尺度敏感，须标准化。预测复杂度 $O(Nd)$，用 KD-tree（低维）、Ball-tree、HNSW/LSH（高维近似）加速。高维下距离失效（Q5）。1-NN 的渐近错误率不超过贝叶斯错误率的 2 倍。

**English short answer**
> KNN stores the training set and classifies a point by majority vote among its k nearest neighbors. Small k gives low bias and high variance; large k does the reverse. It needs feature scaling and suffers in high dimensions. For speed we use KD-trees or approximate nearest neighbor indexes like HNSW.

**追问方向**：如何选 k？加权 KNN？

### Q25. 朴素贝叶斯（Naive Bayes）★★
**答案要点**
贝叶斯定理 $P(y|x)\propto P(y)\prod_jP(x_j|y)$，"朴素"指假设特征在给定类别下条件独立。参数用计数估计，拉普拉斯平滑 $\frac{n_{jk}+\alpha}{n_k+\alpha V}$ 防零概率。优点：训练快、小样本好、可处理高维稀疏（文本）。缺点：独立假设常不成立，概率输出不准（过度极端），但分类排序常常仍然有效。实现时用对数概率相加避免下溢。

**English short answer**
> Naive Bayes applies Bayes' rule and assumes features are conditionally independent given the class, so the likelihood factorizes. It's very fast, works well on text, and uses Laplace smoothing to avoid zero probabilities. The independence assumption is usually wrong, so the probabilities are poorly calibrated, but the ranking can still be good.

**追问方向**：为什么违反独立假设仍有效？

### Q26. 多分类策略：OvR、OvO、Softmax ★★
**答案要点**
OvR（一对多）训练 $K$ 个二分类器，取分数最高者；OvO 训练 $K(K-1)/2$ 个，投票；softmax 回归直接建模 $K$ 类，共享归一化，概率可比。SVM 原生二分类，常用 OvO（libsvm）。多标签（multi-label）则对每类独立 sigmoid + 二元交叉熵，与多分类互斥的 softmax 不同。

**English short answer**
> One-vs-rest trains K binary classifiers, one-vs-one trains a classifier for each pair and votes, and softmax models all classes jointly. For multi-label problems, where classes aren't mutually exclusive, I use independent sigmoids with binary cross-entropy instead of softmax.

**追问方向**：目标检测中的类别预测用 softmax 还是 sigmoid？（YOLOv5 用 sigmoid，见 CV 章）

### Q27. 广义线性模型与 sigmoid/softmax 的统一视角 ★
**答案要点**
指数族分布 $p(y|\eta)=h(y)\exp(\eta^TT(y)-A(\eta))$，高斯→线性回归、伯努利→逻辑回归、类别分布→softmax 回归、泊松→泊松回归。各自的"自然链接函数"使得损失对线性预测量的梯度统一为 $(\hat y-y)$。这解释了为什么这些模型的梯度形式一致。

**English short answer**
> Generalized linear models cover linear, logistic and softmax regression in one family. The target follows an exponential-family distribution, and with the canonical link the gradient with respect to the linear score is always prediction minus target.

**追问方向**：为什么选 canonical link？

## 六、SVM

### Q28. 硬间隔 SVM 与对偶（Hard-margin SVM and Dual）★★★
**答案要点**
线性可分，$y_i\in\{-1,+1\}$，超平面 $w^Tx+b=0$。点到平面距离 $\frac{y_i(w^Tx_i+b)}{\|w\|}$，缩放使最近点 $y_i(w^Tx_i+b)=1$，则间隔 $=2/\|w\|$。最大化间隔等价于：
$$\min_{w,b}\ \tfrac12\|w\|^2\quad \text{s.t. } y_i(w^Tx_i+b)\ge1$$
拉格朗日：$\mathcal L=\tfrac12\|w\|^2-\sum\alpha_i[y_i(w^Tx_i+b)-1]$。令 $\partial_w=0\Rightarrow w=\sum\alpha_iy_ix_i$，$\partial_b=0\Rightarrow\sum\alpha_iy_i=0$，代回得对偶：
$$\max_\alpha\ \sum_i\alpha_i-\tfrac12\sum_{i,j}\alpha_i\alpha_jy_iy_jx_i^Tx_j\quad\text{s.t. }\alpha_i\ge0,\ \sum\alpha_iy_i=0$$
KKT 互补松弛 $\alpha_i[y_i(w^Tx_i+b)-1]=0$：只有间隔边界上的点（支持向量）$\alpha_i>0$，所以解是稀疏的。对偶形式只含内积 $x_i^Tx_j$，为核技巧铺路。

**English short answer**
> SVM finds the hyperplane with the largest margin, which is two over the norm of w, so we minimize half the squared norm subject to every point being on the correct side with margin one. The dual form depends only on dot products between samples, and only the support vectors have non-zero multipliers. The dot product form is what lets us use kernels.

**追问方向**：为什么最大化间隔能提高泛化？KKT 条件有哪些？

### Q29. 软间隔与 Hinge Loss ★★★
**答案要点**
允许违反约束：$\min\tfrac12\|w\|^2+C\sum\xi_i$ s.t. $y_i(w^Tx_i+b)\ge1-\xi_i,\xi_i\ge0$。等价于无约束：$\min\tfrac12\|w\|^2+C\sum\max(0,1-y_if(x_i))$，其中 $\max(0,1-yf)$ 是 hinge loss。$C$ 大→惩罚违规重→间隔窄、偏差小方差大；$C$ 小→间隔宽、正则强。对偶中约束变为 $0\le\alpha_i\le C$。三类点：$\alpha=0$（间隔外正确）、$0<\alpha<C$（恰在边界）、$\alpha=C$（间隔内或误分）。

**English short answer**
> Soft-margin SVM allows slack for points inside or across the margin, and the objective becomes margin regularization plus C times the hinge loss. A large C punishes violations heavily, giving a narrow margin and risking overfitting; a small C gives a wider margin and a smoother boundary.

**追问方向**：Hinge loss 与交叉熵损失的比较？

### Q30. 核技巧（Kernel Trick）★★★
**答案要点**
把 $x$ 映射到高维特征空间 $\phi(x)$，在其中线性可分。对偶中只需内积，定义核 $K(x,z)=\phi(x)^T\phi(z)$，无需显式计算 $\phi$。常用核：线性、多项式 $(x^Tz+c)^p$、RBF $\exp(-\gamma\|x-z\|^2)$（对应无穷维特征空间）。Mercer 条件：核矩阵对称半正定。预测 $f(x)=\sum_i\alpha_iy_iK(x_i,x)+b$。RBF 的 $\gamma$ 大→每个支持向量影响范围小→过拟合；$\gamma$ 小→接近线性。训练 $O(N^2)\sim O(N^3)$，大数据下不如线性 SVM 或神经网络。

**English short answer**
> The kernel trick computes inner products in a high-dimensional feature space without ever building the features. Since the SVM dual only needs inner products, I can swap the dot product for a kernel like RBF. A large gamma makes the model very local and prone to overfitting. The downside is that kernel methods scale badly with the number of samples.

**追问方向**：核函数合法性？手算多项式核对应的显式映射？

### Q31. SVM 与逻辑回归的比较 ★★
**答案要点**
损失：hinge（正确且间隔≥1 就零损失，只依赖支持向量）vs 交叉熵（所有样本都有贡献）。输出：SVM 给的是间隔分数，无概率（需 Platt 校准），LR 直接给概率。特征多样本少、可用核时 SVM 好；大规模稀疏数据 LR 更方便。二者在线性情形性能常接近。

**English short answer**
> The main difference is the loss. SVM uses hinge loss, so only support vectors matter, while logistic regression uses log loss and every point contributes. LR outputs probabilities directly; SVM needs calibration. Linear versions often perform similarly.

**追问方向**：何时选哪个？

## 七、树模型与集成学习

### Q32. 决策树：信息增益、增益率、基尼系数 ★★★
**答案要点**
熵 $H(D)=-\sum_kp_k\log_2p_k$，信息增益 $IG=H(D)-\sum_v\frac{|D_v|}{|D|}H(D_v)$（ID3，偏向取值多的特征）；增益率 $IG/H_A(D)$（C4.5，修正偏向）；基尼 $Gini=1-\sum_kp_k^2$，CART 选使加权基尼下降最大的二分切分，回归树则用平方误差。手算示例（教学示例）：10 个样本 6 正 4 负，$H=-0.6\log_20.6-0.4\log_20.4\approx0.971$；若按某特征切成 (4 正 0 负) 与 (2 正 4 负)，子集熵为 0 与 $0.918$，加权 $=0.6\times0.918=0.551$，$IG\approx0.42$。树的构建是贪心递归，直到纯度或深度/样本数限制。

**English short answer**
> A decision tree greedily picks the split that most reduces impurity. ID3 uses information gain based on entropy, C4.5 uses gain ratio to avoid favoring features with many values, and CART uses the Gini index and makes binary splits. For regression we minimize the squared error in each child.

**追问方向**：连续特征怎么切分？缺失值怎么处理？

### Q33. 决策树的过拟合与剪枝 ★★
**答案要点**
不加限制的树会把训练集拟合到零误差。预剪枝：限制最大深度、最小叶样本、最小增益；后剪枝：先长满再用验证集或代价复杂度 $R_\alpha(T)=R(T)+\alpha|T|$（CART）剪掉。树对特征尺度不敏感、可处理类别与缺失，但边界为轴平行、不平滑，单树方差大，所以实践中几乎都用集成。

**English short answer**
> A fully grown tree memorizes the training set. We control it with pre-pruning, like limiting depth and minimum leaf size, or post-pruning, which trims branches using a complexity penalty. A single tree has high variance, which is why we usually ensemble them.

**追问方向**：为什么树不需要归一化？

### Q34. Bagging 与随机森林（Random Forest）★★★
**答案要点**
Bagging：对数据做自助采样（bootstrap，有放回抽 $N$ 个，每个样本被抽到的概率 $1-(1-1/N)^N\to1-1/e\approx63.2\%$），训练多个基学习器，分类投票/回归平均。若 $n$ 个基学习器方差 $\sigma^2$、两两相关系数 $\rho$，平均后方差为 $\rho\sigma^2+\frac{1-\rho}{n}\sigma^2$。所以要降低相关性：随机森林在每个节点只从随机 $m$ 个特征（常取 $\sqrt d$）里选最优切分。未被抽中的约 36.8% 样本做袋外（OOB）评估，无需单独验证集。降方差，基本不降偏差，所以基学习器要选低偏差高方差的深树。

**English short answer**
> Bagging trains many models on bootstrap samples and averages them, which reduces variance. Random forest adds feature subsampling at each split to decorrelate the trees, because the variance of the average depends on their correlation. Roughly a third of samples are left out of each bootstrap, so we get a free out-of-bag validation estimate.

**追问方向**：为什么 $\rho$ 越小越好？随机森林特征重要性如何算（置换重要性）？

### Q35. Boosting 与 AdaBoost ★★
**答案要点**
Boosting 串行训练弱学习器，后者关注前者的错误。AdaBoost：样本权重 $w_i$ 初始均匀；第 $t$ 轮训练弱分类器 $h_t$，加权错误率 $\epsilon_t$，权重 $\alpha_t=\tfrac12\ln\frac{1-\epsilon_t}{\epsilon_t}$；更新 $w_i\leftarrow w_i\exp(-\alpha_ty_ih_t(x_i))$ 并归一化；最终 $H(x)=\mathrm{sign}(\sum\alpha_th_t(x))$。它等价于前向分步加法模型最小化指数损失 $e^{-yf}$。降偏差为主，对噪声和离群点敏感。

**English short answer**
> Boosting trains weak learners sequentially, each one focusing on the mistakes of the previous ones. In AdaBoost, misclassified samples get higher weights, and each learner is weighted by how accurate it is. It mainly reduces bias, and can be sensitive to noisy labels.

**追问方向**：AdaBoost 为什么等价于指数损失？

### Q36. GBDT（梯度提升树）★★★
**答案要点**
函数空间的梯度下降：$F_m(x)=F_{m-1}(x)+\eta\,h_m(x)$，其中 $h_m$ 拟合当前损失的负梯度（伪残差）$r_i=-\partial L(y_i,F)/\partial F\big|_{F_{m-1}}$。平方损失时伪残差就是真残差 $y-F$；对数损失时为 $y-p$。每轮用一棵小回归树（深度 3–8）拟合残差，叶子值可再做线搜索优化。学习率（shrinkage）$\eta$ 小+树数多是降过拟合的主要手段，另有子采样（stochastic GB）。

**English short answer**
> Gradient boosting does gradient descent in function space. At each round we fit a small regression tree to the negative gradient of the loss, called the pseudo-residual, and add it to the model with a small learning rate. With squared loss, that's just fitting the residuals.

**追问方向**：为什么拟合负梯度？与 AdaBoost 的联系？

### Q37. XGBoost / LightGBM 的改进 ★★★
**答案要点**
XGBoost 对损失做二阶泰勒展开：$L\approx\sum[g_if(x_i)+\tfrac12h_if(x_i)^2]+\Omega(f)$，$\Omega=\gamma T+\tfrac12\lambda\sum w_j^2$。叶子 $j$ 的最优权重 $w_j^*=-\frac{G_j}{H_j+\lambda}$，分裂增益
$$Gain=\tfrac12\Big[\tfrac{G_L^2}{H_L+\lambda}+\tfrac{G_R^2}{H_R+\lambda}-\tfrac{(G_L+G_R)^2}{H_L+H_R+\lambda}\Big]-\gamma$$
（$G,H$ 为一二阶梯度和）。工程上有稀疏感知（缺失值默认方向）、列块并行、直方图近似。LightGBM：直方图算法、leaf-wise 生长（按增益最大的叶子分裂，更深但易过拟合，需限 `num_leaves`）、GOSS 单边梯度采样、EFB 互斥特征捆绑，更快。CatBoost：对类别特征做有序目标统计，减少目标泄漏。表格数据上常常优于深度学习。

**English short answer**
> XGBoost uses a second-order Taylor expansion of the loss and adds regularization on the number of leaves and leaf weights, which gives a closed-form optimal leaf value and split gain. LightGBM speeds things up with histogram binning and leaf-wise growth. On tabular data, gradient boosted trees are still a very strong baseline.

**追问方向**：XGBoost 如何处理缺失值？leaf-wise 与 level-wise 的区别？

### Q38. Bagging 与 Boosting 对比 ★★★
**答案要点**
| 维度 | Bagging / RF | Boosting / GBDT |
|---|---|---|
| 训练方式 | 并行、独立 | 串行、依赖前序 |
| 主要降低 | 方差 | 偏差（也降方差） |
| 基学习器 | 深树（低偏差高方差） | 浅树（弱学习器） |
| 对噪声 | 较稳健 | 较敏感，需正则 |
| 样本 | 自助采样 | 重加权或拟合残差 |
调参：RF 主要调树数、`max_features`；GBDT 调学习率、树数、深度、子采样。

**English short answer**
> Bagging trains independent deep models in parallel and mostly reduces variance. Boosting trains shallow models sequentially, each correcting the last, and mostly reduces bias. Random forests are robust and easy to tune; boosted trees are usually more accurate but need more careful regularization.

**追问方向**：能否并行 boosting？（树内部的特征并行/直方图并行）

### Q39. Stacking 与模型融合 ★
**答案要点**
Stacking：第一层多个异质基模型用交叉验证产生"袋外预测"，作为第二层元模型（常为线性/逻辑回归）的输入特征；必须用 OOF 预测，否则元模型会在基模型已见过的样本上学到虚假的信心，造成泄漏。融合效果取决于基模型多样性（误差不相关）。

**English short answer**
> Stacking feeds the out-of-fold predictions of several different base models into a meta-model. It's important to use out-of-fold predictions, otherwise the meta-model sees overfit outputs and leaks information. Diversity among base models is what makes the ensemble better.

**追问方向**：与 blending 的区别？

### Q40. 特征重要性的计算方式 ★★
**答案要点**
树模型：split 次数/总增益（偏向高基数特征）；置换重要性（permutation importance）：打乱某特征，看验证指标下降多少，模型无关但相关特征会互相稀释；SHAP：基于 Shapley 值给出一致、局部可加的归因。线性模型看标准化后的系数。注意重要性只反映相关性，不代表因果。

**English short answer**
> For trees you can use split gain, but it favors high-cardinality features. Permutation importance shuffles a feature and measures the drop in validation score. SHAP gives consistent per-prediction attributions based on Shapley values. None of them imply causality.

**追问方向**：相关特征为何使置换重要性失真？

## 八、无监督：聚类与降维

### Q41. K-means 算法与目标函数 ★★★
**答案要点**
目标：$\min\sum_{k}\sum_{x\in C_k}\|x-\mu_k\|^2$。迭代：(1) 分配步：每点归最近中心；(2) 更新步：中心设为簇均值。每步目标不增，且有限状态，故收敛到局部极小（可视为 EM 的硬分配特例，GMM 方差趋于 0 的极限）。局限：需预设 $k$、对初始化敏感（用 k-means++ 按距离平方概率选初始中心）、假设球形等大簇、对离群点敏感、需标准化。选 $k$：肘部法、轮廓系数 $s=\frac{b-a}{\max(a,b)}$、Gap statistic。YOLO 用 k-means（以 1−IoU 作距离）聚类先验框，见 [03_计算机视觉与目标检测八股](./03_计算机视觉与目标检测八股.md)。

**English short answer**
> K-means alternates between assigning each point to its nearest centroid and recomputing each centroid as the mean of its cluster. Each step lowers the within-cluster squared distance, so it converges, but only to a local minimum, hence k-means++ initialization. It assumes roughly spherical clusters of similar size and you must choose k.

**追问方向**：为什么更新步取均值是最优？K-means 收敛性证明？

### Q42. 高斯混合模型与 EM 算法 ★★★
**答案要点**
GMM：$p(x)=\sum_k\pi_k\mathcal N(x|\mu_k,\Sigma_k)$，隐变量 $z$ 表示所属分量。直接最大化 $\sum_i\log\sum_k(\cdot)$ 含"和的对数"，无闭式解。EM：
- E 步：责任度 $\gamma_{ik}=\dfrac{\pi_k\mathcal N(x_i|\mu_k,\Sigma_k)}{\sum_j\pi_j\mathcal N(x_i|\mu_j,\Sigma_j)}$；
- M 步：$N_k=\sum_i\gamma_{ik}$，$\mu_k=\frac1{N_k}\sum\gamma_{ik}x_i$，$\Sigma_k=\frac1{N_k}\sum\gamma_{ik}(x_i-\mu_k)(x_i-\mu_k)^T$，$\pi_k=N_k/N$。
原理：用 Jensen 不等式得到对数似然的下界 ELBO，E 步令下界在当前参数处紧贴，M 步最大化下界，故似然单调不减，收敛到局部极大。奇异性问题：某分量塌缩到单点时似然发散，需对协方差加正则。

**English short answer**
> A Gaussian mixture models data as a weighted sum of Gaussians with a hidden component label. EM alternates between computing each point's soft responsibility for each component, and re-estimating means, covariances and weights using those responsibilities. Each iteration increases the likelihood, because EM maximizes a lower bound, but it can land in a local optimum.

**追问方向**：EM 与 K-means 关系？EM 为什么保证似然不降？

### Q43. DBSCAN 与层次聚类 ★★
**答案要点**
DBSCAN：参数 $\epsilon$、`minPts`；核心点（邻域内点数≥minPts）、边界点、噪声点；密度可达的核心点连成簇。优点：不需预设簇数、可发现任意形状、自带噪声识别；缺点：密度不均、高维下 $\epsilon$ 难选。层次聚类：凝聚式自底向上合并（single/complete/average/ward linkage），输出树状图，复杂度 $O(N^2)$ 以上。

**English short answer**
> DBSCAN groups points that are densely connected, so it can find clusters of arbitrary shape and label sparse points as noise without needing the number of clusters. It struggles when density varies across clusters. Hierarchical clustering repeatedly merges the closest clusters and gives a dendrogram, but it's quadratic in cost.

**追问方向**：点云地面分割后的障碍物聚类常用 DBSCAN/欧氏聚类，为什么？

### Q44. PCA 的推导 ★★★
**答案要点**
目标：找单位方向 $u$ 使投影方差最大。数据中心化后协方差 $S=\frac1NX^TX$，投影方差 $u^TSu$，加约束 $u^Tu=1$，拉格朗日 $u^TSu-\lambda(u^Tu-1)$，令梯度为零得 $Su=\lambda u$：$u$ 是协方差矩阵的特征向量，方差即特征值 $\lambda$，所以取最大的 $k$ 个特征值对应的特征向量。第 $i$ 个主成分的方差贡献率 $\lambda_i/\sum\lambda_j$，据此选 $k$（如累计 95%）。等价视角：最小化重建误差 $\sum\|x-UU^Tx\|^2$。
手算示例（教学示例）：$S=\begin{bmatrix}2&1\\1&2\end{bmatrix}$，特征方程 $(2-\lambda)^2-1=0\Rightarrow\lambda=3,1$，主方向 $(1,1)/\sqrt2$，方差贡献 $3/4=75\%$。
实现用 SVD：$X=U\Sigma V^T$，主方向是 $V$ 的列，$\lambda_i=\sigma_i^2/N$，数值上比显式求协方差稳定。前提：线性、方差大的方向有信息、先标准化尺度不同的特征。

**English short answer**
> PCA finds the direction that maximizes the variance of the projected data. Using a Lagrange multiplier for the unit-norm constraint, you get the eigenvalue equation for the covariance matrix, so the principal components are its top eigenvectors and the variance along each is the eigenvalue. In practice we compute it with SVD of the centered data. It's the best linear reconstruction in the least squares sense.

**追问方向**：PCA 前为何要中心化？白化（whitening）是什么？

### Q45. PCA 与 SVD、LDA、t-SNE、UMAP、自编码器 ★★
**答案要点**
SVD 是 PCA 的计算工具，也用于低秩近似（Eckart–Young：截断 SVD 是最优秩 $k$ 近似）。LDA（线性判别分析）有监督，最大化类间散度与类内散度之比 $\frac{w^TS_Bw}{w^TS_Ww}$，至多降到 $C-1$ 维。t-SNE：用高斯构造高维相似度，低维用 t 分布，最小化 KL，保持局部结构，只用于可视化，不保持全局距离，不能直接对新样本变换。UMAP 更快且较好保持全局。自编码器是非线性 PCA（线性激活加 MSE 时等价 PCA 子空间）。

**English short answer**
> SVD is how we compute PCA, and truncated SVD is the best low-rank approximation. PCA is unsupervised and maximizes variance, while LDA is supervised and maximizes class separation. t-SNE and UMAP are non-linear and mainly for visualization, they preserve local neighborhoods but distances between far clusters aren't meaningful.

**追问方向**：t-SNE 图里簇的大小和距离能解读吗？

### Q46. 异常检测简述（Anomaly Detection）★
**答案要点**
统计方法（3σ、马氏距离 $\sqrt{(x-\mu)^T\Sigma^{-1}(x-\mu)}$）、Isolation Forest（随机切分，异常点路径短）、One-class SVM、自编码器重建误差、基于密度的 LOF。机器人上可用于传感器故障检测：滤波器的新息（innovation）卡方检验即是马氏距离的应用。

**English short answer**
> Anomalies can be found by statistical distance like Mahalanobis, by isolation forests where outliers are isolated with few random splits, or by reconstruction error of an autoencoder. In robotics, the innovation test in a Kalman filter is essentially a Mahalanobis distance check on sensor data.

**追问方向**：无标签时如何评估异常检测？

### Q47. 半监督、自监督与迁移学习概念 ★★
**答案要点**
半监督：少量标签+大量无标签（伪标签、一致性正则）。自监督：从数据自身构造监督信号（掩码预测、对比学习 SimCLR/MoCo，对比损失 InfoNCE：$-\log\frac{e^{s(q,k^+)/\tau}}{\sum_ke^{s(q,k)/\tau}}$）。迁移学习：预训练+微调，数据少时冻结骨干只训头，数据多时全量微调且用小学习率。域适应处理源/目标分布差异。

**English short answer**
> Self-supervised learning creates labels from the data itself, such as predicting masked tokens or pulling together two augmented views of the same image. Transfer learning starts from a pretrained model and fine-tunes it, which is how I'd handle a small dataset: freeze the backbone, train the head, then optionally unfreeze with a small learning rate.

**追问方向**：对比学习的负样本为什么重要？

## 九、概率图模型简述

### Q48. 贝叶斯网络与马尔可夫随机场 ★★
**答案要点**
概率图用图结构表达变量间的条件独立。有向图（贝叶斯网）：联合分布 $P(x_1..x_n)=\prod_iP(x_i|\mathrm{pa}(x_i))$；无向图（MRF）：联合 $\frac1Z\prod_c\psi_c(x_c)$，$Z$ 为配分函数，$\psi_c$ 为团势函数。条件独立判定：有向图用 d-分离，无向图看分离集。推断：变量消元、信念传播（树上精确，带环图近似）、MCMC、变分推断。

**English short answer**
> Probabilistic graphical models use a graph to encode conditional independence. A Bayesian network is a directed graph where the joint factorizes into each variable given its parents. A Markov random field is undirected and factorizes into clique potentials with a normalizing constant. Inference can be exact by variable elimination or belief propagation on trees, or approximate.

**追问方向**：朴素贝叶斯、HMM 在图上各是什么结构？

### Q49. 隐马尔可夫模型 HMM：前向、Viterbi ★★
**答案要点**
隐状态序列 $z_{1:T}$ 马尔可夫，观测 $x_t$ 只依赖 $z_t$；参数：初始 $\pi$、转移 $A$、发射 $B$。三类问题：评估（前向算法 $\alpha_t(j)=[\sum_i\alpha_{t-1}(i)a_{ij}]b_j(x_t)$，复杂度 $O(TN^2)$）、解码（Viterbi：把求和换成最大化，回溯最优路径）、学习（Baum-Welch，即 EM）。与卡尔曼滤波关系：线性高斯连续状态的 HMM 就是卡尔曼滤波的结构，滤波本质都是"预测+更新"的递推贝叶斯估计，见 [03_概率统计与高斯分布](../../02_基础知识/01_数学基础/03_概率统计与高斯分布.md)。

**English short answer**
> An HMM has hidden states that evolve as a Markov chain, and each state emits an observation. The forward algorithm computes the likelihood in order T N squared by dynamic programming, Viterbi finds the best state sequence by replacing sums with max, and Baum-Welch learns parameters with EM. A Kalman filter has the same structure, just with continuous Gaussian states.

**追问方向**：Viterbi 与前向算法的区别？

### Q50. 条件随机场 CRF 与判别式序列模型 ★
**答案要点**
CRF 直接建模 $P(y|x)=\frac1{Z(x)}\exp(\sum_k w_kf_k(y_t,y_{t-1},x))$，是判别式的，没有 HMM 的观测独立假设，可使用任意重叠特征，克服标注偏置（相比 MEMM）。NER/分词里常见 BiLSTM-CRF。如今多被 Transformer 取代，但在分割后处理（DenseCRF）和结构化输出里仍有出现。

**English short answer**
> A CRF models the label sequence conditionally on the whole input, so it can use arbitrary overlapping features and avoids HMM's independence assumption. BiLSTM-CRF was the standard for sequence tagging before Transformers.

**追问方向**：CRF 的训练为何需要前向后向？

## 十、特征工程与数据问题

### Q51. 归一化与标准化 ★★★
**答案要点**
Min-max：$x'=\frac{x-x_{min}}{x_{max}-x_{min}}$，对离群点敏感；Z-score：$x'=\frac{x-\mu}{\sigma}$。需要缩放的：基于梯度的模型（加速收敛）、基于距离的模型（KNN、K-means、SVM）、带正则的模型（使惩罚公平）、PCA。不需要：树模型。$\mu,\sigma$ 只由训练集计算并原样用于验证/测试/线上，否则泄漏。含长尾分布可先取 log。

**English short answer**
> Standardization subtracts the mean and divides by the standard deviation; min-max scaling squeezes values into a fixed range. Gradient-based, distance-based and regularized models need it, tree models don't. The statistics must be computed on the training set only and reused at test time.

**追问方向**：为什么特征缩放能加速梯度下降？

### Q52. 类别特征与缺失值处理 ★★
**答案要点**
类别编码：one-hot（无序、低基数）、ordinal（有序）、目标编码（target encoding，需折外计算防泄漏）、embedding（高基数）、哈希。缺失值：先判断机制（MCAR/MAR/MNAR）；处理：删除、均值/中位数/众数填补、模型填补（KNN、迭代）、加"是否缺失"指示列；树模型（XGBoost/LightGBM）可原生处理。

**English short answer**
> For categorical variables I'd use one-hot for low cardinality, embeddings or target encoding for high cardinality, with target encoding computed out-of-fold to avoid leakage. For missing values I impute with median or a model and add a missingness indicator, because the fact that a value is missing can itself be informative.

**追问方向**：one-hot 对树模型的问题？

### Q53. 类别不平衡（Class Imbalance）★★★
**答案要点**
问题：多数类主导损失，模型倾向全部预测多数类，准确率虚高。方案分层：
1. 指标：用 PR-AUC、F1、召回，不用准确率；
2. 数据层：欠采样多数类、过采样少数类、SMOTE（在少数类近邻间线性插值合成新样本，$x_{new}=x+\delta(x_{nn}-x),\delta\in[0,1]$）；先划分再采样，只对训练集操作；
3. 算法层：类权重（权重∝1/频率）、Focal Loss $FL=-(1-p_t)^\gamma\log p_t$ 降低易分样本权重、阈值移动、代价敏感学习；
4. 集成：BalancedBagging、EasyEnsemble。
目标检测中背景框远多于前景框，是同一问题（RetinaNet 提出 Focal Loss）。

**English short answer**
> First I change the metric to precision-recall or F1 instead of accuracy. Then I can resample, using oversampling like SMOTE or undersampling, but only on the training split. Or I can reweight the loss by class, or use focal loss to down-weight easy examples. Finally I adjust the decision threshold. Detection has the same problem because most anchors are background.

**追问方向**：SMOTE 的缺点？过采样后概率如何校正？

### Q54. 数据泄漏（Data Leakage）★★★
**答案要点**
定义：训练时用到了预测时拿不到的信息。常见：先在全量数据上标准化/PCA/特征选择再划分；目标编码未折外；时间序列打乱；重复样本跨训练/测试；特征里含未来或标签的衍生量（如"是否已退款"预测欺诈）。信号：验证指标好得离谱。防治：用 Pipeline 把预处理封装进交叉验证、按组/时间划分、去重、特征上线可得性审查。

**English short answer**
> Leakage means the model sees information in training that it won't have at prediction time, for example fitting a scaler on the whole dataset before splitting, or random-splitting a time series. A too-good validation score is the warning sign. I prevent it by putting preprocessing inside a pipeline fitted only on training folds and splitting by time or group.

**追问方向**：举一个你遇到或可能遇到的泄漏例子（视频连续帧）。

### Q55. 特征选择方法 ★★
**答案要点**
过滤法（方差阈值、相关系数、互信息、卡方）：快、与模型无关；包裹法（递归特征消除 RFE）：用模型反复评估子集，贵；嵌入法（L1、树重要性）：训练过程中选择。注意相关特征冗余、多重共线性（VIF>10 常被视为严重）。

**English short answer**
> Filter methods score features independently, like correlation or mutual information. Wrapper methods such as recursive feature elimination train models on subsets. Embedded methods, like L1 regularization or tree importances, select during training. I'd start with filter plus embedded because they're cheap.

**追问方向**：L1 选择的稳定性问题？

### Q56. 超参数搜索与训练监控 ★★
**答案要点**
网格搜索（维度灾难）、随机搜索（Bergstra & Bengio 观点：当只有少数超参真正重要时，随机搜索比网格更高效，这一结论来自该论文，面试可简述为"未核对原文细节"）、贝叶斯优化（高斯过程/TPE 建代理模型，采集函数如 EI）、Hyperband（早停低效配置）。学习率用对数尺度采样。训练监控：loss 曲线、梯度范数、验证指标、学习曲线；固定随机种子保证可复现。

**English short answer**
> Random search is usually better than grid search because only a few hyperparameters really matter, and I sample the learning rate on a log scale. Bayesian optimization builds a surrogate model to pick promising settings, and Hyperband stops bad runs early. I always log curves and fix the seed for reproducibility.

**追问方向**：学习率为何对数采样？

## 本章要点速记
1. 测试误差 = 偏差² + 方差 + 噪声；正则化与 bagging 降方差，更强模型与 boosting 降偏差。
2. L2 = 高斯先验，L1 = 拉普拉斯先验；L1 出稀疏解，L2 平滑缩小。
3. 交叉熵 = 负对数似然 = KL（差常数）；softmax+CE 梯度为 $p-y$。
4. 评价：不平衡看 PR/F1，不看准确率；AUC 是排序概率。
5. SVM 最大间隔，对偶只含内积，支持向量稀疏，核技巧靠 Mercer 条件。
6. 树：信息增益/基尼；RF 降方差靠去相关；GBDT 拟合负梯度；XGBoost 用二阶信息。
7. K-means 与 EM 交替优化，只到局部最优；PCA = 协方差特征分解 = 中心化 SVD。
8. 数据泄漏防线：预处理只 fit 训练集、按时间/分组划分、特征上线可得。
9. 类别不平衡：换指标、重采样/类权重/Focal Loss、调阈值。

1. 推导为什么 sigmoid + MSE 在严重错误时梯度小，而 sigmoid + 交叉熵不会。（要点：MSE 梯度含 $p(1-p)$，CE 抵消它，梯度为 $p-y$。）
2. 随机森林有 100 棵树，单树方差 $\sigma^2$，两两相关 $\rho=0.3$，平均后方差是多少？（$0.3\sigma^2+0.7\sigma^2/100=0.307\sigma^2$，说明相关性是瓶颈。）
3. 为什么 L1 容易产生稀疏解？分别用几何和次梯度两种方式解释。
4. 数据集 1000 样本，990 负 10 正，模型全预测负，准确率、Recall 分别是多少？（99%，0。）
5. 说出 PCA 与 LDA 的目标差异，并写出 PCA 的特征值方程。（PCA 最大化方差，无监督；LDA 最大化类间/类内比；$Su=\lambda u$。）
