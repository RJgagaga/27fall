## 一、基础与反向传播

### Q1. 通用逼近定理与为什么要"深" （Universal Approximation & Depth）★★
**答案要点**
通用逼近定理：带非线性激活的单隐层前馈网络，只要隐层足够宽，就能在紧集上以任意精度逼近任意连续函数。但它不保证"需要多宽"以及能否学到。深度的价值：某些函数用深层网络需要的神经元数量是多项式的，而浅层需要指数级（组合性、层次化特征）；深层网络把简单特征逐层组合（边缘→纹理→部件→物体）。没有非线性激活，多层线性映射等价于一层：$W_2(W_1x)=(W_2W_1)x$。

**English short answer**
> The universal approximation theorem says a one-hidden-layer network with enough neurons can approximate any continuous function. But it says nothing about how many neurons you need or whether training finds it. Depth helps because many functions are compositional, so a deep network can represent them with exponentially fewer units, building features hierarchically. Without nonlinear activations, stacked layers collapse to a single linear map.

**追问方向**：为什么宽网络也能很好？近年的"过参数化"理论怎么说？

### Q2. 手推全连接网络的反向传播（Backpropagation）★★★
**答案要点**
前向：$z^{(l)}=W^{(l)}a^{(l-1)}+b^{(l)}$，$a^{(l)}=\sigma(z^{(l)})$，损失 $L$。定义误差项 $\delta^{(l)}=\partial L/\partial z^{(l)}$。
- 输出层：$\delta^{(L)}=\nabla_{a^{(L)}}L\odot\sigma'(z^{(L)})$（softmax+CE 时直接 $=p-y$）；
- 反向递推：$\delta^{(l)}=\big((W^{(l+1)})^T\delta^{(l+1)}\big)\odot\sigma'(z^{(l)})$；
- 梯度：$\partial L/\partial W^{(l)}=\delta^{(l)}(a^{(l-1)})^T$，$\partial L/\partial b^{(l)}=\delta^{(l)}$。
本质是链式法则从输出向输入逐层复用中间结果，代价与一次前向同阶（动态规划避免重复求导）。
手算示例（教学示例）：单神经元 $z=wx+b,\ a=\sigma(z),\ L=\frac12(a-y)^2$，取 $x=1,w=0.5,b=0,y=1$：$z=0.5,a=\sigma(0.5)\approx0.622$；$\partial L/\partial a=a-y=-0.378$；$\sigma'(z)=a(1-a)\approx0.235$；$\delta=-0.378\times0.235\approx-0.0888$；$\partial L/\partial w=\delta x\approx-0.0888$，学习率 0.1 时 $w$ 增至约 0.509。

**English short answer**
> Backprop is the chain rule applied layer by layer from the output back to the input. I compute an error term for each layer's pre-activation, propagate it backward by multiplying with the transposed weights and the activation derivative, and the weight gradient is that error times the previous layer's activation. It costs about the same as one forward pass because intermediate results are reused.

**追问方向**：为什么前向要缓存激活值？（显存占用来源，激活重计算 checkpointing）

### Q3. 自动微分：前向模式与反向模式 ★★
**答案要点**
自动微分把程序分解为基本操作的计算图，对每个操作用已知的局部导数应用链式法则，既不是符号微分也不是数值微分。前向模式一次传播一个输入方向的导数（适合输入少、输出多）；反向模式一次得到一个标量输出对所有输入的梯度（适合参数多、损失为标量，深度学习用它）。PyTorch 动态图：运算时记录 `grad_fn`，`loss.backward()` 沿图反向。梯度默认累加，所以每步要 `optimizer.zero_grad()`。

**English short answer**
> Autodiff breaks a program into primitive operations and applies the chain rule exactly. Reverse mode computes the gradient of one scalar loss with respect to all parameters in one backward pass, which is why deep learning uses it. PyTorch builds the graph dynamically as operations run, and gradients accumulate, so we zero them each step.

**追问方向**：`detach()` 与 `no_grad()` 区别？

### Q4. 梯度消失与梯度爆炸的成因与对策 ★★★
**答案要点**
反向传播中 $\delta^{(1)}=\prod_{l}\big(\mathrm{diag}(\sigma'(z^{(l)}))W^{(l+1)T}\big)\delta^{(L)}$ 是 $L$ 个矩阵的连乘。若每个因子范数 $<1$，指数衰减（消失）；$>1$ 则指数增长（爆炸）。sigmoid 导数最大 0.25，十层后至多 $0.25^{10}\approx10^{-6}$。对策：
- 激活函数：ReLU 族（正区间导数 1）；
- 初始化：Xavier/He 保持各层方差；
- 归一化：BN/LN；
- 残差连接：提供恒等梯度通道；
- 门控结构：LSTM；
- 梯度裁剪（针对爆炸）；
- 合理学习率与 warmup。
诊断：监控各层梯度范数，爆炸表现为 loss 出现 NaN/Inf。

**English short answer**
> The gradient to early layers is a product of many Jacobians. If each is smaller than one the gradient shrinks exponentially, and if larger than one it explodes. Sigmoid is a classic cause, since its derivative is at most 0.25. We fix it with ReLU-type activations, careful initialization, normalization, residual connections, and gradient clipping for explosion.

**追问方向**：RNN 为何更容易？（同一矩阵连乘 $T$ 次，谱半径决定）

### Q5. 损失函数在深度学习中的选择 ★★
**答案要点**
分类：交叉熵（可加 label smoothing：目标变为 $(1-\epsilon)y+\epsilon/K$，防过度自信）；类别不平衡/检测：Focal Loss；回归：MSE、L1、Smooth L1、Huber；度量学习：Contrastive、Triplet $\max(0,d(a,p)-d(a,n)+m)$、InfoNCE；分割：Dice $1-\frac{2|A\cap B|}{|A|+|B|}$；框回归：IoU/GIoU/CIoU（见 [03_计算机视觉与目标检测八股](./03_计算机视觉与目标检测八股.md)）。

**English short answer**
> For classification I use cross-entropy, sometimes with label smoothing. For imbalanced dense prediction, focal loss or Dice loss. For regression, L1 or Huber. For embeddings, contrastive, triplet or InfoNCE losses. The loss should match the metric and the noise assumptions of the task.

**追问方向**：label smoothing 对校准的影响？

### Q6. 参数量与计算量（Params & FLOPs）的计算 ★★★
**答案要点**
全连接：$(d_{in}+1)d_{out}$ 参数，约 $2d_{in}d_{out}$ FLOPs（乘加各算一次）。卷积：参数 $(K_hK_wC_{in}+1)C_{out}$，MACs $=K_hK_wC_{in}C_{out}H_{out}W_{out}$。示例（教学示例）：输入 $64\times64\times3$，$3\times3$ 卷积 32 个、stride 1、same padding，参数 $(27+1)\times32=896$，MACs $=27\times32\times64\times64\approx3.5\text{M}$。显存估算：参数 + 梯度 + 优化器状态（Adam 为参数的 2 倍）+ 激活。FP32 下 Adam 训练一个 $P$ 参数的模型，权重+梯度+Adam 状态约 $16P$ 字节。

**English short answer**
> A conv layer has kernel height times width times input channels times output channels parameters, plus biases, and its multiply-accumulate count is that times the output spatial size. For training memory, with Adam in FP32 you need roughly sixteen bytes per parameter for weights, gradients and optimizer states, plus the activations.

**追问方向**：为什么推理延迟不等于 FLOPs 成比例？（访存带宽、算子并行度）

## 二、激活函数与初始化

### Q7. 常见激活函数比较 ★★★
**答案要点**
| 激活 | 公式 | 优点 | 缺点 |
|---|---|---|---|
| Sigmoid | $1/(1+e^{-x})$ | 输出 (0,1)，可作概率/门 | 饱和梯度消失、非零中心、指数贵 |
| Tanh | $\tanh x$ | 零中心 | 仍饱和 |
| ReLU | $\max(0,x)$ | 计算简单、正区间无饱和、稀疏 | 神经元死亡（负区间梯度为 0） |
| Leaky ReLU/PReLU | $\max(\alpha x,x)$ | 缓解死亡 | 需选 $\alpha$ |
| GELU | $x\Phi(x)$ | 平滑，Transformer 常用 | 计算稍贵 |
| SiLU/Swish | $x\sigma(x)$ | 平滑，YOLOv5 使用 | 同上 |
| Softmax | $e^{z_i}/\sum e^{z_j}$ | 多分类概率 | 仅用于输出层 |
YOLOv5 主体用 SiLU；Transformer 的 FFN 早期用 ReLU，后来是 GELU，LLaMA 类用 SwiGLU（门控）。

**English short answer**
> Sigmoid and tanh saturate, which causes vanishing gradients. ReLU is cheap and doesn't saturate for positive inputs, but neurons can die. Leaky ReLU fixes that, and smooth versions like GELU and SiLU are common in Transformers and modern detectors. Softmax is only used at the output for multi-class probabilities.

**追问方向**：为什么 ReLU 不可导还能用？（次梯度，零点测度为零）

### Q8. Dying ReLU 是什么？怎么避免？ ★★
**答案要点**
若某神经元的预激活长期为负（如学习率过大把偏置推到很负），ReLU 输出恒 0、梯度恒 0，参数不再更新。对策：较小学习率、He 初始化、BN、Leaky/PReLU/GELU、合理的偏置初始化（如小正值）。

**English short answer**
> A ReLU unit dies when its input is always negative, so both its output and gradient are zero and it never recovers. It's often caused by a too-large learning rate. Using a smaller learning rate, He initialization, batch norm, or Leaky ReLU helps.

**追问方向**：如何检测死神经元比例？

### Q9. Xavier 与 He 初始化的推导 ★★★
**答案要点**
目标：让前向激活方差和反向梯度方差跨层大致保持。设 $y=\sum_{i=1}^{n}w_ix_i$，$w,x$ 独立、均值 0，则 $Var(y)=n\,Var(w)Var(x)$。要 $Var(y)=Var(x)$ 需 $Var(w)=1/n_{in}$。同时考虑反向得 $1/n_{out}$，折中 Xavier：$Var(w)=\dfrac{2}{n_{in}+n_{out}}$（适合 tanh/sigmoid，近似线性区）。ReLU 把一半输出置零，使二阶矩减半，所以需要 $Var(w)=\dfrac{2}{n_{in}}$（He/Kaiming）。均匀分布版本上界 $\sqrt{6/(n_{in}+n_{out})}$ 等。偏置一般初始化为 0；全零权重会导致同层神经元对称、梯度相同而无法分化。

**English short answer**
> The goal is to keep the variance of activations and gradients stable across layers. For a layer with n inputs, the output variance is n times the weight variance times the input variance, so the weight variance should be one over n. Xavier balances forward and backward, giving two over fan-in plus fan-out. He initialization uses two over fan-in because ReLU zeroes half of the activations.

**追问方向**：为什么不能全零初始化？正交初始化？

### Q10. 权重共享与参数初始化在 Transformer 中的特殊处理 ★
**答案要点**
Transformer 常用截断正态 $\mathcal N(0,0.02^2)$ 初始化，残差分支输出层按 $1/\sqrt{2N}$（$N$ 层数）缩放，避免残差累加使方差随深度增长；Pre-LN 结构更稳定。可见 [04_Transformer与大模型八股](./04_Transformer与大模型八股.md)。

**English short answer**
> Transformers typically use a small normal initialization, and scale the output projections of residual branches by one over the square root of twice the layer count, so the residual stream's variance doesn't grow with depth.

**追问方向**：Post-LN 与 Pre-LN 稳定性差异？

### Q11. 激活函数的导数与饱和：Softmax 的数值稳定 ★★
**答案要点**
$\mathrm{softmax}(z)_i=\dfrac{e^{z_i-m}}{\sum_je^{z_j-m}},\ m=\max_jz_j$，减最大值不改变结果但避免 $e^{z}$ 溢出。log-softmax 用 $z_i-m-\log\sum_je^{z_j-m}$（log-sum-exp 技巧）。框架里 `CrossEntropyLoss` 接收 logits，内部做 log-softmax，不要先手动 softmax 再喂入。softmax 的 Jacobian：$\partial p_i/\partial z_j=p_i(\delta_{ij}-p_j)$。

**English short answer**
> Softmax is computed after subtracting the maximum logit, which gives the same result but avoids overflow. Cross-entropy implementations take raw logits and use the log-sum-exp trick internally, so you shouldn't apply softmax yourself before the loss.

**追问方向**：温度 $T$ 对 softmax 分布的影响（蒸馏、采样）？

### Q12. 通道、特征的"死/饱和"诊断与可视化 ★
**答案要点**
训练前先做"过拟合小批量"测试：用 10 个样本训练，loss 应降到近 0；若不行，多半是代码/数据/学习率问题。监控每层激活均值方差与梯度范数、权重更新比 $\|\Delta w\|/\|w\|$（经验值约 $10^{-3}$）。

**English short answer**
> A good sanity check is to overfit a tiny batch: if the loss won't go near zero, something is wrong in the code, labels, or learning rate. I also monitor activation statistics, gradient norms, and the ratio of update size to weight size.

**追问方向**：loss 不降的排查顺序？（见 Q47）

## 三、归一化

### Q13. Batch Normalization 原理与作用 ★★★
**答案要点**
对一个 mini-batch 的每个通道：$\mu_B=\frac1m\sum x_i,\ \sigma_B^2=\frac1m\sum(x_i-\mu_B)^2,\ \hat x_i=\dfrac{x_i-\mu_B}{\sqrt{\sigma_B^2+\epsilon}},\ y_i=\gamma\hat x_i+\beta$。$\gamma,\beta$ 可学习，使网络能恢复原分布。CNN 中对 $(N,H,W)$ 维度统计，每通道一组 $\mu,\sigma,\gamma,\beta$。作用：允许更大学习率、缓解梯度问题、对初始化不敏感、有轻微正则（batch 噪声）。原论文解释为减少内部协变量偏移（internal covariate shift），后续研究认为主要作用是使损失面更平滑，这一争论在面试时可简述。
训练 vs 推理：训练用当前 batch 统计量，同时维护滑动平均 $\mu_{run}\leftarrow(1-\alpha)\mu_{run}+\alpha\mu_B$；推理用滑动平均，输出与 batch 无关。推理时 BN 是逐通道线性变换，可融合进前一层卷积（见 [06_模型部署与量化八股](./06_模型部署与量化八股.md)）。

**English short answer**
> Batch norm normalizes each channel using the mean and variance of the current mini-batch, then applies a learned scale and shift. It lets us use larger learning rates and makes training less sensitive to initialization. At inference it uses running averages collected during training, so it becomes a fixed per-channel affine transform that can be folded into the previous conv.

**追问方向**：BN 为什么在小 batch 下差？BN 放在激活前还是后？

### Q14. BN 的训练/推理差异带来的坑 ★★★
**答案要点**
(1) 忘记 `model.eval()`：推理仍用 batch 统计，结果随 batch 抖动；(2) 微调时 batch 太小（如 detection 里每卡 2 张），统计噪声大，常冻结 BN 或改用 SyncBN/GN；(3) 训练与测试分布不同，滑动平均统计量失配；(4) 动量 $\alpha$ 默认 0.1，样本少时统计不稳。(5) 部署量化时 BN 要先折叠。

**English short answer**
> The classic mistakes are forgetting to switch to eval mode, using very small batches so the statistics are noisy, and fine-tuning on data whose distribution differs from the running stats. In those cases I freeze BN, use SyncBN across GPUs, or switch to group norm.

**追问方向**：SyncBN 的通信代价？

### Q15. LayerNorm、GroupNorm、InstanceNorm 的区别 ★★★
**答案要点**
统计的维度不同（张量 $N\times C\times H\times W$）：
- BN：对 $(N,H,W)$，每个通道一组；依赖 batch；
- LN：对单个样本的 $(C,H,W)$（Transformer 中对隐藏维 $d$）；与 batch 无关，适合变长序列和小 batch；
- IN：对单个样本单个通道的 $(H,W)$，风格迁移；
- GN：把通道分为 $G$ 组，组内归一化，对 batch 不敏感，检测/分割小 batch 常用。
Transformer 选 LN 的原因：序列长度可变、padding 使 batch 统计不合理、自回归推理时 batch 为 1。

**English short answer**
> They differ in which dimensions they compute statistics over. Batch norm uses the batch and spatial dimensions per channel. Layer norm normalizes across the features of a single sample, so it doesn't depend on the batch, which is why Transformers use it. Group norm splits channels into groups and works well with small batches. Instance norm normalizes each channel of each sample.

**追问方向**：RMSNorm 去掉了什么？（去掉减均值与偏置，只除以均方根，更省，LLaMA 采用）

### Q16. Pre-LN 与 Post-LN ★★
**答案要点**
Post-LN：$x_{l+1}=\mathrm{LN}(x_l+F(x_l))$，原始 Transformer；深层时梯度在底层较小，需 warmup。Pre-LN：$x_{l+1}=x_l+F(\mathrm{LN}(x_l))$，残差通路干净、梯度更稳，几乎不需要 warmup，现代 LLM 普遍采用，但最终表示质量有时略逊，常在最后再加一个 LN。

**English short answer**
> Post-LN puts the normalization after the residual addition, as in the original Transformer, and it's harder to train deep, needing warmup. Pre-LN normalizes the input of each sub-layer and keeps a clean identity path, so gradients are more stable. Most modern LLMs use Pre-LN, or RMSNorm in the same position.

**追问方向**：为何干净的恒等通路有利于梯度？

### Q17. 权重归一化、谱归一化与 Dropout 的联系（简述）★
**答案要点**
权重归一化把 $w=g\,v/\|v\|$ 解耦长度和方向；谱归一化将权重除以最大奇异值，约束 Lipschitz 常数，用于 GAN 判别器稳定训练。归一化类方法的共同目的：控制尺度，使优化条件数更好。

**English short answer**
> Weight normalization separates a weight's magnitude from its direction, and spectral normalization divides by the largest singular value to bound the Lipschitz constant, which stabilizes GAN discriminators. All of these control scale to make optimization better conditioned.

**追问方向**：Lipschitz 约束对机器人策略有何意义？（平滑性与鲁棒性）

## 四、优化与正则化

### Q18. SGD、Momentum、Nesterov ★★★
**答案要点**
SGD+Momentum：$v_t=\beta v_{t-1}+g_t,\ \theta_t=\theta_{t-1}-\eta v_t$。直观：沿稳定方向累积速度，在峡谷状损失面抑制横向震荡。Nesterov：先按动量走一步再算梯度 $g(\theta-\eta\beta v)$，具有"前瞻"修正。有效步长在持续同向梯度下放大 $1/(1-\beta)$ 倍。

**English short answer**
> Momentum keeps a running velocity of gradients, so steps accumulate along consistent directions and oscillations across steep directions cancel out. Nesterov momentum evaluates the gradient at the look-ahead position, which corrects overshoot slightly.

**追问方向**：momentum 与 Adam 的 $\beta_1$ 的关系？

### Q19. Adam 与 AdamW 的区别 ★★★
**答案要点**
Adam 更新见 [01_机器学习八股](./01_机器学习八股.md) Q14。若把 L2 项加进梯度 $g\leftarrow g+\lambda\theta$，则它会被 $\sqrt{\hat v}$ 缩放，不同参数的实际衰减不同，与 SGD 里 L2 等价于 weight decay 的结论不再成立。AdamW 将权重衰减解耦：$\theta\leftarrow\theta-\eta\big(\hat m/(\sqrt{\hat v}+\epsilon)+\lambda\theta\big)$，衰减不受自适应缩放影响，泛化更好。LLM 训练典型设置：$\beta_1=0.9,\beta_2=0.95$ 或 0.999、weight decay 0.1、cosine 衰减+warmup（通用做法，具体数值因模型而异）。

**English short answer**
> In Adam, if you add L2 to the gradient, the penalty gets rescaled by the adaptive denominator, so it's no longer true weight decay. AdamW decouples weight decay and applies it directly to the weights. That generalizes better and is the default for Transformers.

**追问方向**：哪些参数不该做 weight decay？（bias、LayerNorm 参数）

### Q20. SGD 与 Adam 谁泛化更好？ ★★
**答案要点**
经验：视觉任务（ResNet 分类）SGD+momentum 调好后测试精度常略高于 Adam；NLP/Transformer 上 Adam 系几乎必需（梯度尺度在参数间差异大、稀疏）。解释假说：SGD 偏向平坦极小值，Adam 的自适应步长可能收敛到较尖锐的区域，但这仍有争议，不是定论。Adam 优点：对学习率鲁棒、收敛快。

**English short answer**
> In practice, SGD with momentum often generalizes slightly better on CNN image classification, while Adam-style optimizers are much better for Transformers and sparse gradients. The flat-minima explanation is popular, but it's still debated.

**追问方向**：如何判断极小值平坦？（Hessian 最大特征值、SAM）

### Q21. Dropout 原理与实现细节 ★★★
**答案要点**
训练时以概率 $p$ 随机把神经元输出置零，相当于对指数多个子网络做近似集成，并阻止神经元共适应（co-adaptation）。Inverted dropout：训练时保留的单元除以 $(1-p)$，使期望不变 $E[\tilde a]=a$，推理时不做任何处理。卷积层空间相关性强，常用 Spatial/DropBlock；Transformer 中用在注意力权重和残差分支，大模型预训练常设 0。与 BN 同用有"方差偏移"问题（训练推理方差不同），一般只在全连接层末端使用。

**English short answer**
> Dropout randomly zeroes activations during training, which prevents co-adaptation and acts like averaging many sub-networks. With inverted dropout we scale the kept activations by one over keep probability during training, so inference needs no change. It's less used in modern conv nets with batch norm and in large-scale pretraining.

**追问方向**：Dropout 的贝叶斯解释（MC dropout 估计不确定性）？

### Q22. 其他正则化手段 ★★
**答案要点**
权重衰减；早停（监控验证集，patience 次不提升则停，等价于对权重范数的隐式约束）；数据增强（最有效的正则之一，见 [03_计算机视觉与目标检测八股](./03_计算机视觉与目标检测八股.md)）；Label smoothing；Mixup $\tilde x=\lambda x_i+(1-\lambda)x_j,\tilde y=\lambda y_i+(1-\lambda)y_j,\ \lambda\sim\mathrm{Beta}(\alpha,\alpha)$；CutMix；随机深度（stochastic depth）；对抗训练；模型集成/EMA（权重滑动平均）。

**English short answer**
> Besides weight decay and dropout, the most effective regularizers are data augmentation and early stopping. Others include label smoothing, mixup which blends pairs of images and labels, stochastic depth, and keeping an exponential moving average of the weights.

**追问方向**：EMA 权重为何更稳？

### Q23. Batch size 的影响 ★★
**答案要点**
大 batch：梯度估计噪声小、吞吐高、硬件利用率好，但每步更新少，泛化可能变差（倾向尖锐极小值，经验现象），需线性放大学习率 $\eta\propto B$ 加 warmup；小 batch：噪声大，起正则作用，BN 统计不稳。显存不足时用梯度累积模拟大 batch：累计 $k$ 次梯度再更新一次（注意 loss 要除以 $k$，BN 统计仍按小 batch 算）。

**English short answer**
> Larger batches give less noisy gradients and better hardware throughput, but may generalize worse, and you need to scale the learning rate and use warmup. Small batches add noise that regularizes, but make batch norm unstable. When memory is limited, I use gradient accumulation to emulate a large batch.

**追问方向**：梯度累积与真正大 batch 在 BN 下有何不同？

### Q24. 学习率的选择与 LR range test ★★
**答案要点**
学习率是最重要的超参。做法：在对数区间上逐步增大学习率、记录 loss，选 loss 下降最快区间的偏小值（LR range test）。Adam 常见初值 $10^{-4}\sim10^{-3}$，SGD $10^{-2}\sim10^{-1}$（经验量级，非规则）。迁移学习：骨干用更小学习率（差分学习率），新头用较大学习率。

**English short answer**
> I find a good learning rate with a range test: increase it exponentially over a short run and pick a value a bit below where the loss starts to blow up. For fine-tuning I use a smaller rate for the pretrained backbone and a larger one for the new head.

**追问方向**：loss 突然变 NaN 的常见原因？

### Q25. 过拟合时的完整处理清单 ★★★
**答案要点**
按性价比：1) 更多数据/数据增强；2) 预训练迁移；3) 早停；4) weight decay、dropout；5) 缩小模型/减少训练轮数；6) Label smoothing、Mixup；7) 集成、EMA；8) 检查数据泄漏和标签噪声。用验证集曲线对照，每次只改一个变量。

**English short answer**
> I'd first add data or augmentation and start from a pretrained model, then early stopping and weight decay, and then reduce capacity or use mixup and label smoothing. Throughout I change one thing at a time and watch the validation curve.

**追问方向**：为什么先数据后模型？

## 五、CNN

### Q26. 卷积的原理、输出尺寸与感受野 ★★★
**答案要点**
2D 卷积（实为互相关）：$y_{i,j}=\sum_{c}\sum_{u,v}w_{c,u,v}\,x_{c,i+u,j+v}+b$。优势：局部连接、权重共享、平移等变（equivariance），参数大幅减少。输出尺寸
$$H_{out}=\left\lfloor\frac{H+2p-d(k-1)-1}{s}+1\right\rfloor$$
（$k$ 核大小、$p$ 填充、$s$ 步长、$d$ 空洞率）。示例（教学示例）：$H=224,k=3,p=1,s=2\Rightarrow\lfloor(224+2-3)/2\rfloor+1=112$。感受野递推：$r_l=r_{l-1}+(k_l-1)\prod_{i<l}s_i$。两个 $3\times3$ 卷积的感受野为 $5\times5$，参数 $18C^2$ 少于一个 $5\times5$ 的 $25C^2$，且多一次非线性，这是 VGG 的思路。

**English short answer**
> A convolution slides a small kernel across the image, sharing weights, so it has local connectivity and translation equivariance with far fewer parameters than a dense layer. The output size is input plus twice padding minus kernel, divided by stride, plus one. Stacking two three-by-three convs gives a five-by-five receptive field with fewer parameters and an extra nonlinearity.

**追问方向**：卷积为什么是"等变"而不是"不变"？池化带来不变性。

### Q27. 池化层与全局平均池化 ★★
**答案要点**
最大池化保留最强响应、提供小范围平移不变性；平均池化平滑。全局平均池化（GAP）把每个通道 $H\times W$ 取平均得一个数，替代大型全连接层，参数少且支持任意输入尺寸（NIN、ResNet）。步长卷积也能下采样，现代网络常用 stride-2 卷积代替池化。

**English short answer**
> Max pooling keeps the strongest activation and gives small translation invariance. Global average pooling collapses each channel to one number, so it replaces big fully connected layers, reduces parameters, and works with any input size. Many modern networks downsample with strided convolutions instead.

**追问方向**：分割/检测为什么要谨慎下采样？（定位精度）

### Q28. 1×1 卷积、深度可分离卷积、空洞卷积、转置卷积 ★★★
**答案要点**
- $1\times1$ 卷积：通道间线性组合，用于升降维（bottleneck）、跨通道信息融合，不改变空间尺寸；
- 深度可分离（MobileNet）：depthwise（每通道独立 $k\times k$）+ pointwise（$1\times1$）。计算量比标准卷积的比例 $\dfrac{1}{C_{out}}+\dfrac{1}{k^2}$，$k=3$ 时约降至 1/8–1/9；
- 空洞卷积：核元素间插入空洞，不增参数而扩大感受野，用于分割（DeepLab），注意 gridding 效应；
- 转置卷积：上采样，会出现棋盘格伪影，常改为"最近邻/双线性上采样+卷积"。
- 分组卷积：通道分组各自卷积，ResNeXt。

**English short answer**
> A one-by-one conv mixes channels and is used for bottlenecks. A depthwise separable conv factorizes a standard conv into a per-channel spatial conv and a one-by-one conv, cutting computation by about eight to nine times for three-by-three kernels. Dilated convs enlarge the receptive field without more parameters, and transposed convs upsample but can produce checkerboard artifacts.

**追问方向**：深度可分离卷积在 NPU 上一定更快吗？（访存受限，不一定）

### Q29. 经典 CNN 演进 ★★
**答案要点**
LeNet（1998，手写数字）→AlexNet（2012，ReLU、Dropout、GPU、数据增强）→VGG（2014，小卷积堆叠）→GoogLeNet/Inception（多尺度并行、$1\times1$ 降维）→ResNet（2015，残差）→DenseNet（密集连接）→MobileNet/ShuffleNet/EfficientNet（轻量、复合缩放）→ViT/ConvNeXt（见 [04_Transformer与大模型八股](./04_Transformer与大模型八股.md)）。每一步解决的核心问题：能训练得更深、更省参数、更适合部署。

**English short answer**
> AlexNet showed deep CNNs work with ReLU, dropout and GPUs. VGG stacked small kernels, Inception used multi-scale branches with one-by-one reductions, and ResNet introduced skip connections to train very deep nets. MobileNet and EfficientNet then focused on efficiency for deployment.

**追问方向**：EfficientNet 的复合缩放是什么？（同时按固定比例放大深度、宽度、分辨率）

### Q30. 卷积神经网络的归纳偏置与 CNN vs Transformer ★★
**答案要点**
CNN：局部性、平移等变、层次化——小数据下样本效率高；Transformer（ViT）：全局注意力、几乎无空间先验，需要大数据或强增强预训练，但上限高、易扩展、多模态统一。混合方案：卷积 stem + Transformer。

**English short answer**
> CNNs bake in locality and translation equivariance, so they are data efficient. Vision Transformers have weaker priors and need more data or pretraining, but they scale well and handle global context and multimodal inputs naturally.

**追问方向**：为什么 ViT 在小数据上差？

### Q31. 数据格式与卷积实现（im2col、Winograd）★
**答案要点**
im2col 把卷积转为大矩阵乘（GEMM），便于用高度优化的 BLAS；Winograd 减少乘法次数（$3\times3$ 小核有效）；FFT 卷积适合大核。内存布局 NCHW 与 NHWC，GPU/NPU 偏好不同。

**English short answer**
> Frameworks often implement convolution by unrolling patches into a matrix with im2col and calling a fast matrix multiplication. Winograd reduces the number of multiplications for small kernels. The tensor layout, NCHW or NHWC, matters for hardware efficiency.

**追问方向**：RKNN 里为什么要关注 layout？

### Q32. 卷积反向传播与步长/填充的影响 ★
**答案要点**
对输入的梯度是对输出梯度与翻转核做"全卷积"（等价转置卷积）；对权重的梯度是输入与输出梯度的相关。池化反向：max pool 只把梯度传给最大值位置，avg pool 平均分配。

**English short answer**
> The gradient with respect to the input is a convolution of the output gradient with the flipped kernel, and the gradient with respect to the weights is the correlation of the input with the output gradient. Max pooling routes the gradient only to the arg-max position.

**追问方向**：为何转置卷积叫"反卷积"不严格？

## 六、残差与经典网络

### Q33. 残差网络为什么有效？（ResNet）★★★
**答案要点**
残差块 $y=x+F(x)$。动机：深层"退化"问题——更深的普通网络训练误差反而更高（不是过拟合），说明优化困难；若 $F=0$ 则为恒等映射，网络至少不会更差，学习 $F$ 比学习完整映射更容易。梯度角度：$\dfrac{\partial y}{\partial x}=I+\dfrac{\partial F}{\partial x}$，反向时
$$\frac{\partial L}{\partial x_l}=\frac{\partial L}{\partial x_L}\Big(1+\frac{\partial}{\partial x_l}\sum_{i=l}^{L-1}F(x_i)\Big)$$
存在一条恒等梯度通路，不会因连乘而消失。另一种视角：ResNet 像许多不同深度路径的集成。维度不同时用 $1\times1$ 卷积投影（shortcut projection）。Bottleneck：$1\times1$ 降维→$3\times3$→$1\times1$ 升维，降计算。

**English short answer**
> A residual block outputs the input plus a learned residual. This gives gradients an identity path from the loss to early layers, so they don't vanish, and the block can easily learn an identity mapping, so adding layers shouldn't hurt. That solved the degradation problem where plain deeper networks trained worse. It can also be seen as an ensemble of many paths of different depths.

**追问方向**：残差连接在 Transformer 中的作用？（同样原理，且形成"残差流"）

### Q34. U-Net、FPN 中的跳连与特征融合（概念）★★
**答案要点**
U-Net：编码器-解码器，对应层 concat，恢复细节；FPN 横向连接 + 自上而下，见 [03_计算机视觉与目标检测八股](./03_计算机视觉与目标检测八股.md)；DenseNet 拼接而非相加。相加（ResNet）要求维度一致且更省，拼接（concat）保留更多信息但通道数增长。

**English short answer**
> U-Net concatenates encoder features into the decoder to recover spatial detail, and FPN adds top-down paths with lateral connections to fuse semantics with resolution. Addition is cheaper and keeps dimensions fixed; concatenation keeps more information but grows channels.

**追问方向**：为什么分割需要多尺度融合？

### Q35. 网络深度、宽度、分辨率的权衡 ★
**答案要点**
加深提升表达但难训练、延迟增加；加宽提升并行度和每层容量；提高分辨率利于小目标但计算量按平方增长。部署时受延迟与内存约束，要在精度-速度曲线（Pareto 前沿）上选点，不看单一指标。

**English short answer**
> Depth increases expressiveness but hurts latency and trainability, width improves parallelism, and resolution helps small objects but cost grows quadratically. For deployment I choose a point on the accuracy-latency Pareto frontier under the hardware budget.

**追问方向**：为什么 FLOPs 低不一定快？

## 七、RNN / LSTM / GRU

### Q36. RNN 与 BPTT ★★★
**答案要点**
$h_t=\tanh(W_hh_{t-1}+W_xx_t+b)$，$y_t=W_yh_t$，参数跨时间共享。BPTT：把网络沿时间展开后做反向传播，
$$\frac{\partial L}{\partial h_k}=\frac{\partial L}{\partial h_T}\prod_{t=k+1}^{T}\mathrm{diag}(\tanh'(\cdot))\,W_h$$
连乘 $W_h$：谱半径 $<1$ 梯度消失（学不到长依赖），$>1$ 爆炸。对策：梯度裁剪（爆炸）、LSTM/GRU（消失）、截断 BPTT、正交初始化。RNN 的缺点还有：无法并行（串行依赖）、长距离信息被压缩进固定长度向量。

**English short answer**
> An RNN reuses the same weights at every time step and carries a hidden state. Training unrolls it over time, which is backprop through time. The gradient involves repeated multiplication by the recurrent matrix, so it vanishes or explodes with long sequences. Clipping handles the explosion, and gated units like LSTM handle the vanishing part. RNNs also can't be parallelized across time.

**追问方向**：Transformer 为何取代 RNN？（并行、直接长程连接）

### Q37. LSTM 的结构与为什么缓解梯度消失 ★★★
**答案要点**
状态：细胞状态 $c_t$ 与隐状态 $h_t$。门（输入 $[h_{t-1},x_t]$）：
$$f_t=\sigma(W_f[h_{t-1},x_t]+b_f),\ i_t=\sigma(W_i[\cdot]+b_i),\ \tilde c_t=\tanh(W_c[\cdot]+b_c),\ o_t=\sigma(W_o[\cdot]+b_o)$$
$$c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t,\qquad h_t=o_t\odot\tanh(c_t)$$
遗忘门决定保留多少旧记忆，输入门决定写入多少新信息，输出门决定暴露多少。关键：$c_t$ 的更新是加法形式，$\partial c_t/\partial c_{t-1}=f_t$（忽略间接项），当 $f_t\approx1$ 时梯度可无衰减传播，类似残差的"恒等通路"。常把遗忘门偏置初始化为 1，使初期倾向记忆。参数量 $4\times(d_h(d_h+d_x)+d_h)$。

**English short answer**
> An LSTM keeps a cell state that is updated additively: the forget gate scales the old memory and the input gate adds new content. Because the derivative of the cell state with respect to the previous cell state is the forget gate, gradients can flow across many steps when the gate is near one. That's the same idea as a residual connection. The output gate decides what part of the memory is exposed as the hidden state.

**追问方向**：LSTM 参数量怎么算？peephole 是什么？

### Q38. GRU 与 LSTM 的对比 ★★
**答案要点**
GRU 合并细胞状态和隐状态，只有更新门 $z_t$ 与重置门 $r_t$：$h_t=(1-z_t)\odot h_{t-1}+z_t\odot\tilde h_t$，$\tilde h_t=\tanh(W[r_t\odot h_{t-1},x_t])$。参数约为 LSTM 的 3/4，训练更快，效果常相近；数据极大或需要精细记忆时 LSTM 稍占优势。

**English short answer**
> A GRU merges the cell and hidden state and uses just an update gate and a reset gate. It has fewer parameters and trains faster than an LSTM, and the performance is often similar.

**追问方向**：双向 RNN 的适用场景？（离线序列标注，不适用实时控制）

### Q39. Seq2Seq 与注意力机制的起源 ★★
**答案要点**
编码器-解码器把源序列压缩成固定向量，长句信息瓶颈。Bahdanau 注意力：解码步 $t$ 对编码器所有隐状态打分 $e_{ti}=v^T\tanh(W_s s_{t-1}+W_h h_i)$，softmax 得权重 $\alpha_{ti}$，上下文 $c_t=\sum_i\alpha_{ti}h_i$。后来 Transformer 去掉循环，只保留（自）注意力，见 [04_Transformer与大模型八股](./04_Transformer与大模型八股.md)。Teacher forcing：训练时解码器输入真实上一词，推理用自身输出，造成 exposure bias。

**English short answer**
> Early seq2seq models squeezed the whole input into one vector, which was a bottleneck. Attention lets the decoder look at all encoder states with learned weights at each step, building a context vector as a weighted sum. Transformers kept attention and dropped recurrence.

**追问方向**：exposure bias 是什么？如何缓解？

### Q40. 时序模型在机器人中的使用与限制 ★
**答案要点**
状态估计和控制中常用的递推结构（卡尔曼滤波）与 RNN 有对应：都维护隐状态。学习型策略用 GRU/LSTM 处理部分可观测（POMDP）；实时性要求下需考虑推理延迟与确定性。更多见 [06_强化学习与具身智能入门](../../02_基础知识/10_机器学习与深度学习/06_强化学习与具身智能入门.md)。

**English short answer**
> A recurrent network keeps a hidden state much like a Kalman filter keeps a belief, so GRUs are used in learned policies for partially observable settings. For real robots I'd also care about inference latency and determinism.

**追问方向**：部分可观测时为何需要记忆？

## 八、训练工程：混合精度、分布式、排错

### Q41. 混合精度训练（Mixed Precision）★★★
**答案要点**
浮点格式：FP32（8 位指数、23 位尾数）；FP16（5 位指数、10 位尾数，范围小，约 $6\times10^{-5}$ 到 65504）；BF16（8 位指数、7 位尾数，范围与 FP32 同，精度低）。AMP 做法：前向/反向用 FP16/BF16 算矩阵乘（Tensor Core 加速、省显存带宽），维护一份 FP32 主权重（master weights）做更新，避免小更新被舍入掉；某些算子（softmax、归约、loss）保持 FP32。FP16 的梯度容易下溢到 0，故用损失缩放（loss scaling）：把 loss 乘 $S$（如 $2^{15}$）再反传，更新前梯度除以 $S$；动态缩放遇到 inf/NaN 时跳过本步并减小 $S$。BF16 范围大，通常无需 loss scaling，是 LLM 的首选。

**English short answer**
> Mixed precision runs matrix multiplies in half precision for speed and memory, but keeps FP32 master weights for the update so tiny updates aren't lost. FP16 has a narrow range, so gradients can underflow, and we use loss scaling to prevent that. BF16 has the same exponent range as FP32, so it usually needs no scaling, which is why it's popular for large models.

**追问方向**：为什么要保留 FP32 主权重？哪些算子要留 FP32？

### Q42. 梯度检查点与显存优化 ★★
**答案要点**
显存大头是激活。激活重计算（gradient checkpointing）：只保存部分层的激活，反向时重算其余，用约 33% 额外计算换取激活显存近似 $O(\sqrt{L})$ 或更低。其他：梯度累积、混合精度、ZeRO（切分优化器状态/梯度/参数）、FlashAttention（避免存 $N\times N$ 注意力矩阵）、LoRA（只训少量参数）。

**English short answer**
> Most training memory goes to activations, so gradient checkpointing stores only some of them and recomputes the rest in the backward pass, trading about a third more compute for much less memory. Other options are gradient accumulation, mixed precision, ZeRO sharding, and parameter-efficient methods like LoRA.

**追问方向**：ZeRO 三个阶段分别切分什么？

### Q43. 数据并行与分布式训练 ★★
**答案要点**
DataParallel（单进程多线程，已不推荐）vs DistributedDataParallel（DDP，每卡一个进程，各自前向反向，梯度 all-reduce 求平均后同步更新，保证参数一致）。Ring all-reduce 通信量与卡数近似无关（每卡约 $2\frac{N-1}{N}$ 倍参数量）。模型并行：张量并行（切矩阵）、流水线并行（切层）。

**English short answer**
> In distributed data parallel, each GPU holds a model replica, runs forward and backward on its own mini-batch, then the gradients are averaged with an all-reduce so all replicas stay identical. For models that don't fit on one GPU we add tensor or pipeline parallelism.

**追问方向**：all-reduce 为什么用 ring？

### Q44. 迁移学习与微调策略 ★★★
**答案要点**
预训练模型已学到通用特征。数据量小且与预训练域相近：冻结骨干仅训分类头（特征提取）；数据较多：解冻全部，小学习率（比头小 10 倍）；逐层解冻、差分学习率。目标检测里骨干常用 ImageNet/COCO 预训练权重。域差异大时需更多层微调。检查：预处理必须与预训练一致（均值方差、输入尺寸、颜色通道顺序 RGB/BGR），这是部署中最常见的静默错误。

**English short answer**
> With little data close to the pretraining domain I freeze the backbone and train only the head. With more data I unfreeze everything and use a smaller learning rate for the backbone. I always match the preprocessing of the pretrained model, such as normalization and channel order, since mismatches silently hurt accuracy.

**追问方向**：灾难性遗忘如何缓解？

### Q45. 训练不收敛 / loss 不降的排查流程 ★★★
**答案要点**
按顺序：(1) 数据：标签是否对齐、可视化若干样本、预处理是否正确、有无 NaN；(2) 过拟合 1 个 batch：能否把 loss 降到近 0；(3) 初始 loss 是否合理（$K$ 类分类应约 $\ln K$）；(4) 学习率（过大震荡/NaN，过小不动）；(5) 梯度：范数是否为 0 或爆炸，是否忘 `zero_grad`、梯度被 `detach`；(6) 模型：激活函数/初始化/BN 模式；(7) 损失与输出对应（logits vs prob，label 类型）；(8) 逐步增加复杂度（先去掉增强与正则）。NaN 常见：除零、log(0)、学习率大、FP16 溢出。

**English short answer**
> I start with the data: visualize inputs and labels. Then I try to overfit a single small batch, check that the initial loss is near log K, and sweep the learning rate. I look at gradient norms for zeros or explosions, and make sure the loss gets the right inputs, like logits instead of probabilities. I add augmentation and regularization back only after the basic loop works.

**追问方向**：初始 loss 远大于 $\ln K$ 说明什么？（输出层初始化过大/标签错误）

### Q46. 可复现性与随机性 ★
**答案要点**
固定 Python/NumPy/框架随机种子、DataLoader worker 种子；cuDNN 的非确定性算法需 `deterministic` 模式（牺牲速度）；记录代码版本、数据版本、配置。多次种子取均值±标准差报告结果，而不是挑最好的一次。

**English short answer**
> I fix all random seeds, including data loader workers, and enable deterministic kernels if needed. More importantly, I report the mean and standard deviation over several seeds instead of one lucky run, and I log code, data and config versions.

**追问方向**：为何同样种子在不同 GPU 上结果仍可能不同？

### Q47. 评估与实验设计的常见错误 ★★
**答案要点**
在测试集上调参；用训练集指标汇报；基线太弱或调参不公平；没有消融实验；指标选错（不平衡数据看准确率）；忽略方差。做消融：每次只去掉一个组件，说明贡献。

**English short answer**
> Common mistakes are tuning on the test set, comparing against an under-tuned baseline, skipping ablations, and ignoring variance across seeds. Good practice is to change one thing at a time and report confidence intervals.

**追问方向**：如何设计公平的基线比较？

## 九、生成模型简述

### Q48. GAN 的目标与训练难点 ★★
**答案要点**
生成器 $G$ 与判别器 $D$ 的极小极大博弈：$\min_G\max_D\ E_{x\sim p_{data}}[\log D(x)]+E_{z}[\log(1-D(G(z)))]$。最优判别器 $D^*=\frac{p_{data}}{p_{data}+p_g}$，此时生成器目标等价于最小化 $p_g$ 与 $p_{data}$ 的 JS 散度。难点：模式崩塌（mode collapse）、训练不稳定、分布支撑集不重叠时梯度消失（WGAN 用 Wasserstein 距离+Lipschitz 约束改善）。实际常用非饱和损失 $\max_G\log D(G(z))$。

**English short answer**
> A GAN trains a generator and a discriminator in a minimax game. At the optimal discriminator, the generator is minimizing the Jensen-Shannon divergence between the real and generated distributions. Training is unstable and can suffer from mode collapse, and WGAN improves it by using the Wasserstein distance.

**追问方向**：为什么用非饱和损失？

### Q49. VAE 与 ELBO ★★
**答案要点**
隐变量模型 $p_\theta(x)=\int p_\theta(x|z)p(z)dz$ 难积分，引入近似后验 $q_\phi(z|x)$，得证据下界：
$$\log p_\theta(x)\ge E_{q_\phi}[\log p_\theta(x|z)]-D_{KL}(q_\phi(z|x)\|p(z))$$
第一项重建，第二项正则隐空间。重参数化技巧 $z=\mu+\sigma\odot\epsilon,\ \epsilon\sim\mathcal N(0,I)$ 使采样可微。高斯编码时 KL 有闭式：$\frac12\sum(\mu^2+\sigma^2-\log\sigma^2-1)$。VAE 生成较模糊（MSE 重建）。

**English short answer**
> A VAE learns an encoder that outputs a distribution over latent codes and a decoder that reconstructs. It maximizes the evidence lower bound, which is the reconstruction term minus the KL divergence to the prior. The reparameterization trick moves the randomness into a noise variable so gradients can flow through sampling.

**追问方向**：β-VAE 的 β 控制什么？

### Q50. 扩散模型（Diffusion）简述 ★★
**答案要点**
前向过程逐步加噪：$x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon,\ \epsilon\sim\mathcal N(0,I)$；训练一个网络 $\epsilon_\theta(x_t,t)$ 预测噪声，损失 $E\|\epsilon-\epsilon_\theta(x_t,t)\|^2$；采样从纯噪声开始逐步去噪。相比 GAN 训练稳定、覆盖模式好，但采样需多步（DDIM、蒸馏加速）。在机器人中，Diffusion Policy 用它建模多模态动作分布（引用相关工作需先核对原文，这里仅概念性提及）。

**English short answer**
> Diffusion models gradually add Gaussian noise to data and train a network to predict that noise, then generate by starting from pure noise and denoising step by step. Training is stable and covers modes well, but sampling takes many steps. In robotics, diffusion is used to model multimodal action distributions.

**追问方向**：为何多模态动作分布对 MSE 回归是个问题？（均值落在两个模态之间）

## 本章要点速记
1. 反向传播 = 链式法则 + 缓存中间量：$\delta^{(l)}=(W^{T}\delta^{(l+1)})\odot\sigma'$，$\nabla W=\delta a^T$。
2. 梯度消失/爆炸来自雅可比连乘；对策是 ReLU 族、He/Xavier、BN/LN、残差、门控、裁剪。
3. He 初始化 $2/n_{in}$（ReLU）；Xavier $2/(n_{in}+n_{out})$。
4. BN 沿 batch+空间统计，训练/推理不同；LN 沿特征维，与 batch 无关，Transformer 用它。
5. AdamW 解耦权重衰减；SGD+momentum 在 CNN 上泛化常好，Transformer 用 AdamW。
6. 残差 $y=x+F(x)$ 提供恒等梯度通路，解决退化问题。
7. LSTM 的细胞状态加法更新使梯度可远距离传播；RNN 不能并行是被 Transformer 取代的原因。
8. 混合精度：半精度计算 + FP32 主权重 + FP16 的 loss scaling；BF16 范围大。
9. 排错：过拟合一个 batch、检查初始 loss $\approx\ln K$、扫学习率、看梯度范数。
