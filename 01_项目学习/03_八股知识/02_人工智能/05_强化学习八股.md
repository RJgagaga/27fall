## 一、基础：MDP 与 Bellman

### Q1. RL 与监督学习的区别 ★★★
**答案要点**
监督学习：有标注的 $(x,y)$，样本独立同分布，损失直接给出"正确答案"。RL：智能体与环境交互，只有标量奖励（延迟、稀疏），没有"正确动作"标签；数据由当前策略产生（分布随策略变化，非平稳）；动作影响后续状态（序列决策），存在信用分配（credit assignment）与探索-利用权衡问题。

**English short answer**
> In supervised learning we have labeled examples that are independent. In reinforcement learning the agent interacts with the environment and only gets a scalar reward, often delayed. Its actions change the future data it sees, so the data distribution is non-stationary, and it has to solve credit assignment and balance exploration with exploitation.

**追问方向**：模仿学习属于哪一边？（把序列决策转成监督学习，但有分布偏移问题）

### Q2. MDP 的定义 ★★★
**答案要点**
马尔可夫决策过程 $(\mathcal S,\mathcal A,P,R,\gamma)$：状态集、动作集、转移概率 $P(s'|s,a)$、奖励 $R(s,a)$ 或 $r(s,a,s')$、折扣因子 $\gamma\in[0,1)$。马尔可夫性：$P(s_{t+1}|s_t,a_t,s_{t-1},\dots)=P(s_{t+1}|s_t,a_t)$，即当前状态包含全部决策所需信息。目标：找策略 $\pi(a|s)$ 最大化期望折扣回报
$$G_t=\sum_{k=0}^\infty\gamma^kr_{t+k+1},\quad J(\pi)=E_\pi[G_0]$$
折扣的作用：保证无穷和收敛（$|G|\le R_{max}/(1-\gamma)$）、表达对近期奖励的偏好、降低方差。部分可观测时是 POMDP，状态用历史或循环网络近似（信念状态）。

**English short answer**
> An MDP consists of states, actions, transition probabilities, rewards and a discount factor. The Markov property says that the next state depends only on the current state and action. The goal is a policy that maximizes the expected discounted return. The discount keeps the sum finite and favors near-term reward.

**追问方向**：机器人状态不满足马尔可夫性怎么办？（加入历史/速度、使用 RNN、POMDP）

### Q3. 状态价值与动作价值 ★★★
**答案要点**
$V^\pi(s)=E_\pi[G_t|s_t=s]$；$Q^\pi(s,a)=E_\pi[G_t|s_t=s,a_t=a]$。关系：$V^\pi(s)=\sum_a\pi(a|s)Q^\pi(s,a)$；$Q^\pi(s,a)=\sum_{s'}P(s'|s,a)[r+\gamma V^\pi(s')]$。优势函数 $A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)$，表示动作 $a$ 比平均水平好多少，期望为 0。

**English short answer**
> The state value is the expected return starting from a state under a policy, and the action value is the expected return after taking a specific action first. The advantage is the difference between them, so it tells how much better an action is than the policy's average.

**追问方向**：为什么用优势而不是 Q 做策略更新？（降方差）

### Q4. Bellman 期望方程与最优方程 ★★★
**答案要点**
期望方程（对固定策略）：
$$V^\pi(s)=\sum_a\pi(a|s)\sum_{s'}P(s'|s,a)\big[r(s,a,s')+\gamma V^\pi(s')\big]$$
推导：$G_t=r_{t+1}+\gamma G_{t+1}$，两边取条件期望并用马尔可夫性。最优方程：
$$V^*(s)=\max_a\sum_{s'}P(s'|s,a)[r+\gamma V^*(s')],\quad Q^*(s,a)=\sum_{s'}P(s'|s,a)\big[r+\gamma\max_{a'}Q^*(s',a')\big]$$
最优策略 $\pi^*(s)=\arg\max_aQ^*(s,a)$。Bellman 最优算子是 $\gamma$-压缩映射（在 $\infty$-范数下），由 Banach 不动点定理，值迭代收敛到唯一不动点。
手算（教学示例）：两状态 A→B（奖励 1）、B 终止（奖励 0），$\gamma=0.9$：$V(B)=0$，$V(A)=1+0.9\times0=1$。若 B→终止奖励 2：$V(B)=2$，$V(A)=1+0.9\times2=2.8$。

**English short answer**
> The Bellman equation says that the value of a state equals the immediate reward plus the discounted value of the next state, averaged over actions and transitions. It follows from writing the return recursively. The optimality equation replaces the average over actions by a max. The optimality operator is a contraction, so value iteration converges to a unique fixed point.

**追问方向**：压缩映射的证明思路？

### Q5. 动态规划：策略迭代与值迭代 ★★★
**答案要点**
需要已知模型 $P,R$。策略迭代：(1) 策略评估：反复用 Bellman 期望方程更新直到收敛 $V^\pi$（或解线性方程 $V=(I-\gamma P_\pi)^{-1}R_\pi$）；(2) 策略改进：$\pi'(s)=\arg\max_a Q^\pi(s,a)$；交替直到策略稳定；保证单调改进且有限步收敛。值迭代：每次直接用最优方程更新 $V\leftarrow\max_a\sum P[r+\gamma V]$，等价于只做一步评估的策略迭代。复杂度每次扫描 $O(|S|^2|A|)$，状态空间大时不可行（维度灾难），这是需要函数逼近与采样的原因。

**English short answer**
> Policy iteration alternates between evaluating the current policy and improving it greedily, and it converges in finitely many steps. Value iteration directly applies the Bellman optimality update. Both need a known model and sweep over all states, so they don't scale to large state spaces.

**追问方向**：LQR 的 Riccati 递推与值迭代有何关系？（线性二次下的动态规划，见 Q54）

### Q6. 同策略与异策略（On-policy vs Off-policy）★★★
**答案要点**
行为策略（采样用）与目标策略（被评估/改进的）是否相同。On-policy：相同（SARSA、REINFORCE、PPO 近似），数据用后即弃，样本效率低但稳定。Off-policy：不同（Q-learning、DQN、DDPG、SAC），可重用回放缓冲区中的旧数据，样本效率高，但需要处理分布偏差（重要性采样或直接用 max 算子绕过）。

**English short answer**
> On-policy methods learn about the same policy that generates the data, so old data must be discarded. Off-policy methods learn about a target policy from data produced by a different behavior policy, so they can reuse a replay buffer and are more sample-efficient, but they can be less stable.

**追问方向**：为什么 Q-learning 是 off-policy？（目标用 max，与实际行为无关）

### Q7. 模型基与无模型 ★★
**答案要点**
无模型：不学转移模型，直接学值或策略（DQN、PPO、SAC），通用但样本效率低。模型基：学习或利用 $\hat P,\hat R$，用于规划或生成想象数据（Dyna、MBPO、World Models、Dreamer 系），样本效率高，但模型误差累积（compounding error）。MPC 是已知/辨识模型 + 滚动优化，可视作模型基控制。

**English short answer**
> Model-free methods learn values or policies directly from experience. Model-based methods learn or use a dynamics model for planning or for generating imagined data, which is more sample-efficient but suffers from model errors that compound over the horizon. MPC is a model-based approach that plans with a model at every step.

**追问方向**：模型误差怎么处理？（短视野、集成、不确定性）

### Q8. 值函数方法与策略方法的比较 ★★★
**答案要点**
| | 值基（DQN） | 策略基（PG） | Actor-Critic |
|---|---|---|---|
| 学什么 | $Q$，策略隐含为 argmax | 直接学 $\pi_\theta$ | 两者 |
| 动作空间 | 离散为主 | 连续/离散皆可 | 皆可 |
| 随机策略 | 否（需 $\epsilon$） | 可 | 可 |
| 方差/偏差 | 偏差大 | 方差大 | 折中 |
| 样本效率 | 高（off-policy） | 低 | 视实现 |

**English short answer**
> Value-based methods learn Q and derive a greedy policy, which works well for discrete actions and is sample-efficient. Policy-gradient methods optimize the policy directly, handle continuous actions and stochastic policies, but have high variance. Actor-critic combines both by using a learned value as a baseline.

**追问方向**：连续动作下 argmax Q 怎么办？（DDPG/SAC 用 actor 近似）

## 二、无模型值方法

### Q9. 蒙特卡洛与时序差分（MC vs TD）★★★
**答案要点**
MC：等回合结束，用实际回报 $G_t$ 更新：$V(s)\leftarrow V(s)+\alpha(G_t-V(s))$；无偏，方差大，只适用于回合制。TD(0)：用自举（bootstrap）目标 $r+\gamma V(s')$：
$$V(s)\leftarrow V(s)+\alpha\big[r+\gamma V(s')-V(s)\big]$$
括号为 TD 误差 $\delta$。TD 偏差有（目标依赖当前估计）但方差小，可在线逐步更新，不要求回合结束。n 步回报和 TD($\lambda$) 在两者间插值，$\lambda$-回报 $G^\lambda_t=(1-\lambda)\sum_{n}\lambda^{n-1}G^{(n)}_t$。

**English short answer**
> Monte Carlo waits until the end of the episode and uses the actual return, which is unbiased but high variance. Temporal-difference learning bootstraps from the current estimate of the next state's value, which is biased but lower variance and can learn online at every step. TD-lambda interpolates between the two.

**追问方向**：偏差-方差如何体现？为什么长时序任务更倾向 TD？

### Q10. SARSA 与 Q-learning ★★★
**答案要点**
SARSA（on-policy）：$Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma Q(s',a')-Q(s,a)]$，$a'$ 是实际按 $\epsilon$-贪心选的动作。Q-learning（off-policy）：$Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma\max_{a'}Q(s',a')-Q(s,a)]$。经典悬崖行走（cliff walking）：Q-learning 学到贴着悬崖的最短路径（但探索时会掉下去），SARSA 因为把探索风险算进去，学到更安全的远路径。表格 Q-learning 在访问所有 $(s,a)$ 无限次、学习率满足 Robbins-Monro 条件下收敛到 $Q^*$。

**English short answer**
> SARSA updates with the next action actually taken, so it learns the value of the exploring policy, and it's on-policy. Q-learning updates with the max over next actions, so it learns the optimal value regardless of how it explores, and it's off-policy. In the cliff-walking example, Q-learning learns the risky shortest path while SARSA learns the safer one.

**追问方向**：Expected SARSA 是什么？

### Q11. DQN 的核心：经验回放与目标网络 ★★★
**答案要点**
用神经网络 $Q_\theta(s,a)$ 逼近 Q。损失：
$$L(\theta)=E_{(s,a,r,s')\sim\mathcal D}\Big[\big(r+\gamma\max_{a'}Q_{\theta^-}(s',a')-Q_\theta(s,a)\big)^2\Big]$$
- 经验回放（replay buffer）：存储转移并随机小批量采样，打破时间相关性，让数据更接近 i.i.d.，并重复利用样本；
- 目标网络 $\theta^-$：目标值使用延迟更新的参数（每隔 $C$ 步复制，或软更新 $\theta^-\leftarrow\tau\theta+(1-\tau)\theta^-$），避免"追着自己的尾巴"导致发散。
其他：奖励裁剪、帧堆叠（处理部分可观测）、Huber 损失。

**English short answer**
> DQN approximates the Q function with a neural network and trains it with a squared TD error. Two tricks make it stable. A replay buffer samples random past transitions to break temporal correlation, and a slowly updated target network provides the bootstrapped target so that the target doesn't move with every gradient step.

**追问方向**：为什么没有这两项会发散？（致命三角）

### Q12. DQN 的改进：Double、Dueling、PER、Rainbow ★★
**答案要点**
- Double DQN：用在线网络选动作、目标网络评估：$y=r+\gamma Q_{\theta^-}(s',\arg\max_{a'}Q_\theta(s',a'))$，缓解 max 引起的过估计（max 作用于有噪声的估计会产生正偏）；
- Dueling：网络分成 $V(s)$ 与 $A(s,a)$ 两个流，$Q=V+A-\overline A$，对许多动作无关紧要的状态学得更快；
- 优先经验回放（PER）：按 TD 误差大小优先采样，需重要性权重校正偏差；
- Noisy Nets、分布式 RL（C51）、多步回报；Rainbow 把以上组合。

**English short answer**
> Double DQN decouples action selection from action evaluation to reduce overestimation caused by the max operator. Dueling DQN separates state value and advantage streams. Prioritized replay samples transitions with large TD error more often. Rainbow combines these and more.

**追问方向**：为什么 max 会导致过估计？（Jensen：$E[\max X]\ge\max E[X]$）

### Q13. 致命三角（Deadly Triad）★★
**答案要点**
函数逼近 + 自举 + 异策略三者同时存在时，值估计可能发散（Baird 反例）。DQN 的经验回放和目标网络是在工程上缓解它。对策略的梯度方法（on-policy + MC 回报）避免了其中的元素。

**English short answer**
> The deadly triad is the combination of function approximation, bootstrapping, and off-policy learning, which can make value estimates diverge. DQN's replay buffer and target network are practical measures that make it work.

**追问方向**：这在连续控制（DDPG）中如何体现？

### Q14. 离散与连续动作空间 ★★
**答案要点**
离散：DQN 可直接 argmax；连续：argmax 需优化，故用确定性策略梯度（DDPG/TD3）或随机策略（SAC/PPO，高斯输出 $\mu,\sigma$）。也可离散化动作（粗但可行）。机器人关节力矩/速度天然连续。

**English short answer**
> With discrete actions I can take an argmax over Q-values. With continuous actions, argmax is an optimization problem, so I use an actor network that outputs the action, as in DDPG, TD3 and SAC, or a Gaussian policy as in PPO.

**追问方向**：高斯策略的动作如何限幅？（tanh squashing 并修正对数概率）

### Q15. 值函数逼近的收敛性与稳定技巧 ★★
**答案要点**
奖励尺度归一化、梯度裁剪、Huber 损失、较小学习率、较大回放缓冲、Layer/Batch Norm 谨慎使用、目标网络软更新（$\tau\sim0.005$ 量级，经验值）、观测标准化。

**English short answer**
> To stabilize value learning I normalize observations and rewards, clip gradients, use a Huber loss, soft-update the target network, and keep a large replay buffer.

**追问方向**：为什么奖励尺度会影响训练？

### Q16. 学习率与折扣因子的选择 ★
**答案要点**
$\gamma$ 接近 1 看得更远，但方差大、收敛慢；有效视野约 $1/(1-\gamma)$（$\gamma=0.99\to100$ 步）。控制频率高（50–200 Hz）时同样 $\gamma$ 对应的物理时间更短，要随控制频率调整。

**English short answer**
> The effective horizon is about one over one minus gamma. If the control rate is high, the same gamma covers less physical time, so it needs to be tuned together with the control frequency.

**追问方向**：回合有时间上限时的终止处理？（区分 terminated 与 truncated）

### Q17. 回合终止：terminated 与 truncated ★★
**答案要点**
真终止（摔倒、到达目标）：目标 $y=r$；因时间上限截断（truncated）并非 MDP 终止，应继续自举 $y=r+\gamma V(s')$。混淆二者会引入偏差，是常见的实现 bug。

**English short answer**
> If an episode ends because the robot fell or reached the goal, the target has no bootstrap term. If it's only cut off by a time limit, I must still bootstrap from the next state value. Mixing these up introduces bias.

**追问方向**：时间步数是否应作为观测？

## 三、策略梯度与 Actor-Critic

### Q18. 策略梯度定理的推导 ★★★
**答案要点**
目标 $J(\theta)=E_{\tau\sim p_\theta}[R(\tau)]=\int p_\theta(\tau)R(\tau)d\tau$。对数导数技巧 $\nabla p=p\,\nabla\log p$：
$$\nabla_\theta J=E_\tau\big[R(\tau)\nabla_\theta\log p_\theta(\tau)\big]$$
轨迹概率 $p_\theta(\tau)=p(s_0)\prod_t\pi_\theta(a_t|s_t)P(s_{t+1}|s_t,a_t)$，环境项与 $\theta$ 无关，故
$$\nabla_\theta J=E_\tau\Big[\sum_t\nabla_\theta\log\pi_\theta(a_t|s_t)\,R(\tau)\Big]$$
因果性：时刻 $t$ 的动作不影响之前的奖励，用"未来回报"$G_t$ 替代 $R(\tau)$ 降低方差：
$$\nabla_\theta J=E\Big[\sum_t\nabla_\theta\log\pi_\theta(a_t|s_t)\,G_t\Big]$$
关键优点：不需要知道环境动力学 $P$，只需对策略可微。

**English short answer**
> We differentiate the expected return using the log-derivative trick. The gradient is the expectation of the return times the gradient of the log-probability of the trajectory. The environment transition terms don't depend on the policy parameters and drop out, leaving a sum of log-policy gradients weighted by the return. By causality we can use the reward-to-go instead of the full return to reduce variance. The nice part is it needs no model of the dynamics.

**追问方向**：为什么这个估计量方差大？

### Q19. REINFORCE 与基线（Baseline）★★★
**答案要点**
REINFORCE：采样轨迹，用蒙特卡洛回报 $G_t$ 作权重做梯度上升。方差大，学得慢。减去与动作无关的基线 $b(s_t)$ 不改变期望（无偏）：
$$E_a\big[\nabla\log\pi(a|s)\,b(s)\big]=b(s)\nabla\sum_a\pi(a|s)=b(s)\nabla1=0$$
常取 $b(s)=V(s)$，则权重变为 $G_t-V(s_t)$ 即优势估计，降低方差。

**English short answer**
> REINFORCE uses Monte Carlo returns to weight the log-probability gradients. Its variance is high. Subtracting a state-dependent baseline doesn't change the expected gradient, because the baseline multiplies the gradient of a probability distribution that sums to one, but it greatly reduces variance. Using the value function as the baseline gives the advantage.

**追问方向**：为什么基线不能依赖动作？

### Q20. Actor-Critic ★★★
**答案要点**
Actor（策略 $\pi_\theta$）与 Critic（值函数 $V_\phi$）：Critic 用 TD 学习，Actor 用 Critic 提供的优势更新：
$$\nabla_\theta J\approx E\big[\nabla_\theta\log\pi_\theta(a_t|s_t)\,\hat A_t\big],\quad \hat A_t=r_t+\gamma V_\phi(s_{t+1})-V_\phi(s_t)$$
TD 误差即一步优势估计。相比纯策略梯度：方差更小、可在线逐步更新；代价：引入 critic 偏差。A2C/A3C 为同步/异步并行版本。

**English short answer**
> In actor-critic methods the actor is the policy and the critic estimates the value function. The critic is trained by temporal difference, and its TD error serves as the advantage that tells the actor whether an action was better than expected. This lowers variance compared to REINFORCE at the cost of some bias.

**追问方向**：actor 与 critic 共享网络的利弊？

### Q21. GAE（广义优势估计）★★★
**答案要点**
n 步优势有偏差-方差权衡。TD 误差 $\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)$，
$$\hat A_t^{GAE(\gamma,\lambda)}=\sum_{l=0}^\infty(\gamma\lambda)^l\delta_{t+l}$$
递推实现 $\hat A_t=\delta_t+\gamma\lambda\hat A_{t+1}$。$\lambda=0$ 为一步 TD（低方差高偏差），$\lambda=1$ 为 MC（无偏高方差），常用 $\lambda=0.95$。

**English short answer**
> GAE takes an exponentially weighted sum of TD errors, with a parameter lambda that interpolates between a one-step TD estimate, which is low variance but biased, and a Monte Carlo estimate, which is unbiased but noisy. A value around 0.95 is common, and it's computed with a backward recursion over the trajectory.

**追问方向**：如何在截断轨迹末尾处理？

### Q22. 策略的参数化：高斯策略与离散策略 ★★
**答案要点**
离散：softmax 输出；连续：对角高斯 $\pi(a|s)=\mathcal N(\mu_\theta(s),\mathrm{diag}(\sigma^2))$，$\log\pi=-\frac12\sum\big[\frac{(a-\mu)^2}{\sigma^2}+2\log\sigma+\log2\pi\big]$。$\sigma$ 可以是状态无关的可学习参数（PPO 常用）或网络输出。熵 $H=\sum(\log\sigma_i+\frac12\log(2\pi e))$ 反映探索程度。

**English short answer**
> For discrete actions the policy is a softmax over logits. For continuous actions it's usually a diagonal Gaussian whose mean comes from a network, and the standard deviation is either a learned parameter or a network output. The entropy of the policy measures how much it explores.

**追问方向**：为何训练后期要让 $\sigma$ 变小？

### Q23. 确定性策略梯度（DPG/DDPG）★★
**答案要点**
确定性策略 $a=\mu_\theta(s)$，策略梯度：
$$\nabla_\theta J=E\big[\nabla_aQ(s,a)|_{a=\mu_\theta(s)}\nabla_\theta\mu_\theta(s)\big]$$
即沿 critic 的动作梯度方向调整 actor（链式法则）。DDPG = DQN 技巧（回放、目标网络）+ 确定性 actor-critic；探索通过往动作加噪声（高斯或 OU）。缺点：对超参敏感、Q 过估计。

**English short answer**
> With a deterministic policy, the gradient flows through the critic: we adjust the actor in the direction that increases the Q-value of its own action, using the chain rule. DDPG applies this with a replay buffer, target networks and noise for exploration. It's sample-efficient but sensitive to hyperparameters.

**追问方向**：TD3 的三个改进是什么（见 Q31）？

### Q24. 重要性采样与异策略策略梯度 ★★
**答案要点**
用行为策略 $\mu$ 的数据估计目标策略 $\pi$ 的期望：权重 $\rho_t=\pi(a_t|s_t)/\mu(a_t|s_t)$。PPO 中旧策略 $\pi_{old}$ 采样、新策略更新时用比率 $r_t(\theta)=\pi_\theta/\pi_{old}$ 校正。比率偏离 1 越远方差越大，需约束（裁剪/KL）。

**English short answer**
> Importance sampling reweights samples collected under one policy to estimate expectations under another using the probability ratio. The ratio's variance explodes if the policies differ too much, so methods like PPO restrict how far the new policy can move from the old one.

**追问方向**：Retrace/V-trace 是什么？

### Q25. 策略梯度的方差来源与降方差手段 ★★
**答案要点**
来源：轨迹随机性、奖励尺度、长视野。手段：基线/优势、奖励到达回报（causality）、GAE、归一化优势（batch 内减均值除标准差）、大 batch、多环境并行、熵正则。

**English short answer**
> The variance comes from random trajectories and long horizons. I reduce it with a baseline, reward-to-go, GAE, normalizing the advantages in each batch, running many environments in parallel, and a larger batch size.

**追问方向**：为什么 PPO 要对优势归一化？

## 四、PPO、TRPO、DDPG/TD3、SAC

### Q26. TRPO 的思想 ★★
**答案要点**
策略更新步长太大会使性能崩溃。TRPO 最大化代理目标 $E\big[\frac{\pi_\theta}{\pi_{old}}\hat A\big]$，约束平均 KL 散度 $\bar D_{KL}(\pi_{old}\|\pi_\theta)\le\delta$（信赖域）。求解用共轭梯度 + 线搜索，涉及 Fisher 矩阵，实现复杂、计算贵。

**English short answer**
> TRPO maximizes a surrogate objective while constraining the KL divergence between the old and new policy, a trust region, so that an update can't change the policy too drastically. It gives monotonic-improvement-style guarantees but needs second-order methods like conjugate gradient, which makes it complex.

**追问方向**：为什么 KL 约束而不是参数空间距离？

### Q27. PPO 的裁剪目标 ★★★
**答案要点**
比率 $r_t(\theta)=\dfrac{\pi_\theta(a_t|s_t)}{\pi_{old}(a_t|s_t)}$。PPO-Clip 目标：
$$L^{CLIP}(\theta)=E_t\Big[\min\big(r_t\hat A_t,\ \mathrm{clip}(r_t,1-\epsilon,1+\epsilon)\hat A_t\big)\Big]$$
解读：$\hat A>0$ 时，鼓励增大该动作概率，但比率超过 $1+\epsilon$ 后梯度为零；$\hat A<0$ 时，鼓励减小概率，比率低于 $1-\epsilon$ 后梯度为零。取 min 使目标是真实目标的悲观下界。$\epsilon$ 常取 0.1–0.3。用一阶优化代替 TRPO 的二阶约束。总损失 $L=L^{CLIP}-c_1L^{VF}+c_2H[\pi]$（价值损失与熵奖励）。典型流程：并行环境采集 $T$ 步 → 计算 GAE 优势 → 对同一批数据做 $K$ 个 epoch 的小批量更新 → 丢弃数据。
手算（教学示例）：$\epsilon=0.2$，$\hat A=2$，$r=1.5$：未裁剪 $3$，裁剪 $1.2\times2=2.4$，取 min 为 $2.4$，该样本梯度为 0；若 $r=0.8$：未裁剪 $1.6$，裁剪项 $0.8\times2=1.6$，取 1.6 有梯度。

**English short answer**
> PPO takes the probability ratio between the new and old policy and multiplies it by the advantage, but clips the ratio to a small interval around one and takes the minimum of the clipped and unclipped terms. Once the ratio moves outside the interval in the direction that helps, the gradient vanishes, so the policy can't be pushed far in a single update. It achieves the stability of a trust region with a simple first-order method, and that's why it's the default for robot locomotion and for RLHF.

**追问方向**：PPO 的常见实现细节（优势归一化、值函数裁剪、学习率退火、观测归一化）？

### Q28. PPO 的实践要点与调参 ★★★
**答案要点**
并行环境数多（几千个，GPU 仿真）使数据多样；GAE $\lambda=0.95$，$\gamma=0.99$；每批做 3–10 个 epoch，小批量；KL 过大时提早停止或自适应学习率；动作 std 初始较大并随训练下降；观测归一化（running mean/std）；奖励缩放；网络小（如 3 层 MLP）。症状诊断：熵过快下降→探索不足；KL 爆炸→学习率过大；价值损失不降→奖励尺度问题或 critic 容量。以上为通用经验，具体数值依任务而定。

**English short answer**
> In practice I run many parallel environments, normalize observations and advantages, use GAE, and do a few epochs of minibatch updates per batch. I monitor the policy entropy, the KL to the old policy and the value loss: collapsing entropy means too little exploration, and a large KL means the step size is too big.

**追问方向**：为什么 PPO 在 GPU 并行仿真里这么流行？

### Q29. SAC（Soft Actor-Critic）与最大熵 RL ★★★
**答案要点**
目标在奖励之外加熵：
$$J(\pi)=\sum_tE\big[r(s_t,a_t)+\alpha H(\pi(\cdot|s_t))\big]$$
鼓励探索、学到多种近似最优行为、对扰动更鲁棒。软 Bellman 备份：$y=r+\gamma\big(\min_{i=1,2}Q_{\bar\theta_i}(s',a')-\alpha\log\pi(a'|s')\big),\ a'\sim\pi$。Actor 最小化 $E[\alpha\log\pi(a|s)-Q(s,a)]$，使用重参数化 $a=\tanh(\mu+\sigma\epsilon)$ 使梯度可通过采样。双 Q 取 min 抑制过估计；温度 $\alpha$ 可自动调节使熵逼近目标熵。Off-policy，样本效率高，连续控制强基线。

**English short answer**
> SAC maximizes reward plus an entropy bonus, which encourages exploration and robust behavior. It's an off-policy actor-critic with a stochastic policy trained by the reparameterization trick, two Q networks with a minimum to reduce overestimation, and an automatically tuned temperature. It's sample-efficient and a strong baseline for continuous control.

**追问方向**：熵项如何改变值函数目标？温度自动调节怎么做？

### Q30. TD3 的三个改进 ★★
**答案要点**
(1) 截断双 Q：两个 critic 取最小值作目标，抑制过估计；(2) 延迟策略更新：critic 更新多次再更新一次 actor 与目标网络；(3) 目标策略平滑：目标动作加截断噪声，使 Q 对动作更平滑。

**English short answer**
> TD3 improves DDPG with clipped double Q-learning to reduce overestimation, delayed policy updates so the actor learns from a more stable critic, and noise added to target actions to smooth the value estimate.

**追问方向**：为什么延迟更新 actor 有帮助？

### Q31. PPO、SAC、TD3、DQN 如何选 ★★★
**答案要点**
| 场景 | 推荐 |
|---|---|
| 离散动作、较低维 | DQN 系 / PPO |
| 大规模并行仿真、足式运动 | PPO（简单稳定） |
| 真实机器人少量数据 | SAC / TD3（样本效率高） |
| 需要稳健探索、稀疏奖励 | SAC |
| 离线数据 | CQL/IQL 等 |
没有"绝对最优"，要看数据获取成本。

**English short answer**
> For massively parallel simulation, like legged locomotion, PPO is a simple and stable default. When real-world samples are expensive, off-policy methods like SAC or TD3 are preferred. For discrete actions, DQN variants or PPO. If only a fixed dataset is available, I'd use offline RL.

**追问方向**：样本效率与稳定性的权衡？

### Q32. 熵正则与温度的作用 ★★
**答案要点**
熵奖励防止策略过早确定性塌缩，保持探索；系数太大则策略过于随机，不能收敛。PPO 的熵系数常设 0.0–0.01；SAC 通过目标熵（如 $-|\mathcal A|$）自动调节。

**English short answer**
> An entropy bonus prevents the policy from collapsing to a deterministic one too early. Too large a coefficient keeps behavior random, so many implementations tune it automatically toward a target entropy.

**追问方向**：部署时是否使用随机策略？（通常取均值动作）

### Q33. 多环境并行与 GPU 仿真 ★
**答案要点**
Isaac Gym/Isaac Lab、MuJoCo MJX、Genesis 等把仿真放到 GPU 上并行数千环境，使 PPO 数分钟训练出行走策略。注意：并行环境数 × 步数 = batch，学习率需相应调整；仿真精度与接触模型影响 sim2real。（工具名称为通用背景，未核对各自具体版本。）

**English short answer**
> GPU-based simulators run thousands of environments in parallel, so PPO can collect enormous amounts of data quickly. The fidelity of contact modeling then becomes the main factor for transfer to the real robot.

**追问方向**：MuJoCo 在你的 P2 里怎么用？（IK 求解，非 RL）

## 五、探索与奖励设计

### Q34. 探索-利用权衡 ★★★
**答案要点**
利用已知最优动作 vs 尝试未知动作。方法：$\epsilon$-贪心（概率 $\epsilon$ 随机）；Boltzmann/softmax；UCB（$Q+c\sqrt{\ln t/N}$，乐观面对不确定）；Thompson 采样；参数/动作噪声（OU、高斯）；熵正则；好奇心/内在奖励（预测误差 RND、ICM）；计数型奖励。多臂赌博机是最简形式，遗憾（regret）衡量。

**English short answer**
> Exploration means trying actions whose value is uncertain, and exploitation means choosing the best-known action. Simple methods are epsilon-greedy and noise injection; principled ones include UCB, which adds an optimism bonus for rarely tried actions, and Thompson sampling. In deep RL, entropy bonuses and intrinsic curiosity rewards are common.

**追问方向**：稀疏奖励下 ε-贪心为何不够？

### Q35. 稀疏奖励与奖励塑形 ★★★
**答案要点**
稀疏奖励（仅成功时 +1）难以探索。塑形：加入稠密引导奖励。势函数塑形 $F(s,s')=\gamma\Phi(s')-\Phi(s)$ 保证不改变最优策略（Ng 等经典结论）；随意设计的奖励可能改变最优解。其他：课程学习、示教初始化、事后经验回放 HER（把未达目标的轨迹重标为达到的目标）。

**English short answer**
> With sparse rewards the agent rarely sees any signal. Reward shaping adds denser guidance, and potential-based shaping, where the bonus is a difference of a potential function, is guaranteed not to change the optimal policy. Other approaches are curricula, demonstrations, and hindsight experience replay.

**追问方向**：HER 为什么有效？

### Q36. 机器人任务的奖励设计原则 ★★★
**答案要点**
典型组成（以足式/轮式机器人为例）：任务项（速度跟踪 $\exp(-\|v-v_{cmd}\|^2/\sigma)$）、存活项、能耗/力矩惩罚、动作平滑（$\|a_t-a_{t-1}\|^2$）、关节限位惩罚、姿态惩罚、接触/足端滑移惩罚。原则：各项量纲与尺度平衡；使用有界项（指数型）避免被单项主导；逐项加权消融；评估指标与奖励分开（不能只看奖励值）。这些项恰好对应控制里的"跟踪误差 + 控制代价"，与 LQR 的 $Q,R$ 权重类似：见 [LQR最优控制](../../02_基础知识/04_控制理论/04_LQR最优控制.md)。

**English short answer**
> A typical robot reward combines a task term, like tracking a velocity command, with penalties for energy, jerky actions, joint limits and bad contacts. I keep each term bounded and balanced in scale, and tune the weights by ablation. It's analogous to choosing the Q and R matrices in LQR: tracking error versus control effort.

**追问方向**：奖励项互相冲突怎么办？

### Q37. 奖励黑客（Reward Hacking）与规格博弈 ★★★
**答案要点**
策略找到了最大化奖励但违背设计者意图的漏洞（如原地打转刷"前进"奖励、利用仿真物理 bug）。对策：检查行为视频、加入约束项、多指标评估、对抗性测试、限制动作空间、人类反馈。与 LLM 的 RLHF 中奖励模型被钻空子是同一类问题。

**English short answer**
> Reward hacking happens when the agent finds an unintended way to get high reward, like exploiting a simulator glitch. I watch the actual behavior rather than only the reward curve, add constraints, test with multiple metrics, and restrict the action space. The same issue appears in RLHF when the policy exploits the reward model.

**追问方向**：如何设计更难被钻空子的奖励？

### Q38. 课程学习与域随机化的联系 ★★
**答案要点**
课程学习：从简单到困难逐步提高任务难度（地形、速度指令、扰动强度），避免一开始学不到信号。自适应课程根据成功率调整。

**English short answer**
> A curriculum starts with easy versions of the task and gradually increases difficulty, for example terrain roughness or push strength, based on the agent's success rate. It avoids the case where the early task is too hard to get any learning signal.

**追问方向**：自动课程如何避免遗忘？

### Q39. 分层强化学习与技能 ★
**答案要点**
高层选择子目标/技能，低层执行（Options、HIRO、FeUdal）。与机器人分层架构天然契合：高层规划 + 低层控制。LLM 规划 + 低层控制器的 Agent 架构也属于这种思路（见 [07_Agent与RAG八股](./07_Agent与RAG八股.md)）。

**English short answer**
> Hierarchical RL has a high-level policy choose subgoals or skills and a low-level policy execute them. It mirrors the classic robot stack of planning on top of control, and it's also how LLM-based task planners are combined with low-level controllers.

**追问方向**：时间抽象有什么好处？

## 六、模型基方法、离线 RL、模仿学习

### Q40. 模型基 RL：Dyna、MBPO、Dreamer ★★
**答案要点**
Dyna：用真实数据学模型，再用模型生成虚拟转移训练值函数/策略。MBPO：短视野 rollouts 避免误差累积。Dreamer：在学到的隐空间世界模型里"想象"轨迹训练 actor-critic。PETS：概率集成模型 + MPC 规划。

**English short answer**
> Model-based methods learn a dynamics model and then use it to generate imagined experience or to plan. To control compounding model error, they use short rollouts or ensembles. Some methods plan online with the learned model using MPC.

**追问方向**：学习到的模型 + MPC 与第一性原理模型 + MPC 的差别？

### Q41. 离线强化学习（Offline RL）★★
**答案要点**
只用固定数据集学习，不与环境交互。核心难点：分布偏移——值函数在数据未覆盖的动作上外推过估计，策略会利用这些虚高的值。方法：策略约束（BCQ、BEAR、TD3+BC）、保守 Q（CQL 压低未见动作的 Q）、隐式 Q 学习（IQL，用期望分位数避免查询未见动作）。适合真实机器人（交互昂贵）。

**English short answer**
> Offline RL learns from a fixed dataset without interacting. The main issue is distribution shift: the Q-function can be wildly optimistic for actions not in the data, and the policy exploits that. Methods constrain the policy to stay near the data, or make the Q-function conservative for unseen actions.

**追问方向**：为什么在线 RL 没有这个问题？

### Q42. 行为克隆（Behavior Cloning）★★★
**答案要点**
把示教数据 $(s,a)$ 当监督学习：$\min_\theta E[\|\pi_\theta(s)-a\|^2]$（或交叉熵/最大似然）。优点：简单、稳定、无需奖励。缺点：**协变量偏移/复合误差**：学生策略微小误差把状态带到示教分布之外，进入从未见过的状态，误差累积，长度 $T$ 的任务误差可达 $O(T^2\epsilon)$（Ross 等经典结论，面试可简述）。多模态示教（同一状态多种合理动作）使 MSE 回归取平均而失败，需用混合高斯、扩散、离散化等。

**English short answer**
> Behavior cloning treats demonstrations as a supervised dataset of state-action pairs. It's simple and stable, but small errors move the robot into states that never appeared in the demonstrations, where it makes bigger errors, and the errors compound over the horizon. Also if demonstrations are multimodal, plain regression averages the modes.

**追问方向**：如何缓解？（DAgger、数据增强、动作分块、扩散策略）

### Q43. DAgger ★★
**答案要点**
迭代：(1) 当前策略（混合专家）在环境中执行并收集访问到的状态；(2) 请专家对这些状态标注正确动作；(3) 聚合到数据集，重新训练。使训练分布覆盖学生自己会遇到的状态，把误差从 $O(T^2)$ 降到 $O(T)$。代价：需要专家在线标注。

**English short answer**
> DAgger lets the learner drive, asks the expert to label the states the learner actually visits, aggregates those into the dataset and retrains. That makes the training distribution match what the learner will see, which fixes the compounding error of plain behavior cloning, at the cost of needing expert queries.

**追问方向**：VR 遥操作采集示教数据与 DAgger 的关系？（遥操作可作为专家接口，见 P2）

### Q44. 逆强化学习与 GAIL ★★
**答案要点**
IRL：从示教反推奖励函数（最大熵 IRL 解决歧义）。GAIL：用 GAN 思想，判别器区分专家与学生的 (s,a)，判别器输出作为奖励训练学生策略，无需显式奖励，但需与环境交互且训练不稳定。

**English short answer**
> Inverse RL infers a reward function from demonstrations. GAIL skips the explicit reward: a discriminator tries to distinguish expert from learner state-actions, and its output serves as the reward for the learner's policy. It needs environment interaction and can be unstable.

**追问方向**：模仿学习与 RL 结合（BC 预训练 + RL 微调）？

### Q45. 动作分块与扩散策略（概念）★★
**答案要点**
一次预测未来 $k$ 步动作序列（action chunk），减少高频决策次数与复合误差，使动作更平滑；扩散策略用去噪过程建模多模态动作分布。属于近年的模仿学习方向，细节论文未逐篇核对，面试以概念表述。

**English short answer**
> Instead of predicting one action per step, the policy outputs a chunk of future actions, which reduces the effective decision frequency and compounding error, and makes the motion smoother. Diffusion policies model multimodal action distributions by denoising.

**追问方向**：动作分块如何与高频低层控制衔接？

### Q46. 从示教到部署：数据来源与质量 ★
**答案要点**
示教质量（平滑性、一致性）决定上限；遥操作采集（VR、主从臂）可得到同步的图像-状态-动作数据；需对齐时间戳与坐标系，见 [06_时间同步_坐标系一致性与数据有效性](../../02_基础知识/05_状态估计/06_时间同步_坐标系一致性与数据有效性.md)。

**English short answer**
> The quality and consistency of the demonstrations set the ceiling. Teleoperation setups can record synchronized images, robot states and actions, and getting timestamps and frames aligned is critical for good training data.

**追问方向**：示教数据清洗有哪些手段？

## 七、sim2real 与安全

### Q47. Sim2Real 的差距与域随机化 ★★★
**答案要点**
差距来源：动力学参数（质量、摩擦、电机特性、延迟）、接触模型、传感器噪声与延迟、渲染差异。方法：(1) 域随机化（Domain Randomization）：训练时随机化物理参数、外观、噪声、延迟、外力，使策略对分布鲁棒；(2) 系统辨识/校准仿真；(3) 域适应、真实数据微调；(4) 执行器网络（actuator net）建模电机；(5) 观测加噪、历史输入；(6) 低层使用经典控制（PD）+ 策略只输出目标，降低 sim2real 难度。随机化范围太小→不鲁棒，太大→保守或学不会。

**English short answer**
> The sim-to-real gap comes from imperfect dynamics, contact models, actuator behavior, latency and sensor noise. The standard remedy is domain randomization: randomize physical parameters, noise and delays in simulation so the policy learns to be robust. Other tools are system identification, actuator models, and fine-tuning with real data. If the randomization is too narrow the policy fails, and if too wide it becomes overly conservative.

**追问方向**：你在真机调试里遇到的"仿真与实物不一致"例子？（可联系 P7 轮腿的接地切换与状态不一致，仅作类比，不是 RL）

### Q48. 延迟与控制频率在 RL 部署中的问题 ★★
**答案要点**
策略以 $f_\pi$（如 50 Hz）输出目标，低层以更高频率（如 1 kHz）跟踪（分层）。观测/动作延迟若训练时未建模，会导致振荡。对策：训练时随机化延迟、把上一动作加入观测、策略输出平滑。推理时间需小于控制周期，用 ONNX/TensorRT 等部署（见 [06_模型部署与量化八股](./06_模型部署与量化八股.md)）。

**English short answer**
> The policy typically runs at a lower rate and outputs targets, while a high-rate low-level controller tracks them. If latency isn't modeled during training, the closed loop can oscillate. So I randomize delays in training, include the previous action in the observation, and make sure inference fits within the control period.

**追问方向**：为什么 RL 策略常输出 PD 目标位置而非力矩？

### Q49. 安全强化学习 ★★★
**答案要点**
约束 MDP（CMDP）：最大化回报同时满足代价期望 $E[\sum c_t]\le d$；方法：拉格朗日松弛（PPO-Lagrangian）、CPO、安全层/盾（shield）：在策略输出与执行器之间加一个基于模型的过滤器，如控制屏障函数（CBF）投影、MPC 安全滤波，保证动作满足安全约束。实际机器人部署几乎总有硬编码安全层（限幅、限位、急停、跌倒保护），RL 只是在安全包络内优化。

**English short answer**
> Safe RL maximizes return subject to cost constraints, using Lagrangian methods or constrained policy optimization. In practice, robots also use a safety layer between the policy and actuators, for example action clipping, a control barrier function projection, or an MPC-based filter, so the learned policy can only act inside a verified safe envelope.

**追问方向**：这与 P6 的"提案-校验-执行"链有何类比？（学习/LLM 输出是提案，校验层是安全过滤，见 07 章）

### Q50. 评估 RL 策略 ★★
**答案要点**
多随机种子（RL 方差大）、报告均值与置信区间；与固定基线（如 PID/MPC）对比；在分布外扰动下测试；记录失败案例；真机评估要有急停和保护。奖励曲线不等于任务成功率，需独立的任务指标。

**English short answer**
> RL results have high variance, so I report mean and confidence intervals over several seeds, compare with a classical baseline, and test under out-of-distribution disturbances. Reward isn't the same as task success, so I also track task-level metrics and failure cases.

**追问方向**：为什么 RL 论文里种子数很重要？

### Q51. RL 在 LLM 中的应用（RLHF/GRPO）简述 ★★
**答案要点**
把生成过程看作 MDP：状态 = prompt + 已生成 token，动作 = 下一个 token，奖励 = 序列结束时的奖励模型分数（稀疏，序列级），再加每步 KL 惩罚。PPO 需要 critic；GRPO 用同一 prompt 的多个采样的组内相对奖励作基线，省掉 critic。见 [04_Transformer与大模型八股](./04_Transformer与大模型八股.md) Q33–Q37。

**English short answer**
> RLHF treats text generation as an MDP where each token is an action and the reward comes at the end from a reward model, with a KL penalty to the reference model. PPO needs a critic, while group-based methods use the relative rewards within several samples of the same prompt as the baseline.

**追问方向**：为什么 LLM 的 RL 奖励稀疏？

## 八、RL 与 MPC/LQR 的对比

### Q52. RL 与 MPC 的对比 ★★★
**答案要点**
| 维度 | MPC | RL |
|---|---|---|
| 模型 | 需要显式动力学模型 | 无模型方法不需要（或学习模型） |
| 优化时机 | 在线，每个周期求解有限视野问题 | 离线训练，在线只做前向推理 |
| 约束处理 | 显式约束（输入/状态不等式），可证明可行 | 隐式（惩罚或安全层），难保证 |
| 在线计算 | 重（QP/NLP 求解），与视野/状态维度相关 | 轻（一次网络前向） |
| 数据需求 | 低（模型辨识） | 高（大量交互） |
| 可解释/可验证 | 较强（稳定性、可行性分析） | 弱（黑盒） |
| 适应复杂接触/高维 | 难（非凸、混合） | 强（足式、灵巧手） |
| 调参 | 权重矩阵、视野、约束 | 奖励设计、超参、随机化 |
结论：模型准确、约束重要、需要可验证安全 → MPC（如 P5 的车辆轨迹跟踪，见 [MPC](../../02_基础知识/04_控制理论/05_MPC模型预测控制.md)）；模型难以精确建模、接触丰富、高维 → RL；实践中常组合：RL 学高层或残差，MPC/PD 做底层与安全约束。

**English short answer**
> MPC plans online with an explicit model and handles constraints directly, but it needs a good model and enough computation per cycle. RL does the optimization offline and only runs a network forward pass online, handles complex contact-rich dynamics without a precise model, but needs lots of data and offers weaker guarantees. In practice they're combined, for example RL for high-level or residual actions with MPC or a PD controller and safety layer underneath.

**追问方向**：你的 P5 为什么用 MPC 而不是 RL？（车辆运动学模型清晰、约束重要、需要可解释和可验证，是合理的工程理由）

### Q53. LQR 是 RL 的特例吗？ ★★★
**答案要点**
LQR 问题：线性动力学 $x_{t+1}=Ax_t+Bu_t$，二次代价 $\sum x^TQx+u^TRu$。值函数是二次的 $V(x)=x^TPx$，Bellman 方程化为离散 Riccati 方程：
$$P=Q+A^TPA-A^TPB(R+B^TPB)^{-1}B^TPA$$
最优策略线性 $u=-Kx$，$K=(R+B^TPB)^{-1}B^TPA$。这正是已知模型下的动态规划（值迭代）的闭式解。把奖励取为 $-(x^TQx+u^TRu)$，LQR 就是线性二次 MDP 的最优控制，可用 RL（策略梯度、Q-learning）在未知 $A,B$ 时学习（"LQR 作为 RL 的基准问题"）。P1 与 P7 里的 LQR 增益即这个 $K$，见 [LQR最优控制](../../02_基础知识/04_控制理论/04_LQR最优控制.md)。

**English short answer**
> LQR is exactly dynamic programming for linear dynamics and quadratic cost. The value function is quadratic, the Bellman equation becomes the Riccati equation, and the optimal policy is a linear state feedback. So you can view it as the model-based, closed-form special case of optimal control that RL tries to approximate when the model is unknown or nonlinear.

**追问方向**：RL 在 LQR 问题上能比 Riccati 更好吗？（已知模型时不会）

### Q54. 什么时候不该用 RL？ ★★★
**答案要点**
模型已知且简单（倒立摆小角度）；约束必须严格满足；缺乏仿真或交互代价高；需要可解释与认证；样本稀缺；经典方法（PID/LQR/MPC）已满足要求。你的七个项目都以经典控制解决，原因是系统可建模、实时性强、可验证；RL 适合作为未来在复杂接触任务（轮腿/足式越障、灵巧操作）上的补充。

**English short answer**
> I wouldn't use RL when the model is known and simple, when hard constraints must be guaranteed, when interaction data is expensive, or when I need interpretability and certification. In my projects, classical control was the right tool because the systems were modelable, real-time, and verifiable. RL is interesting for contact-rich tasks where models are hard to write down, which is what I want to study more.

**追问方向**：你想在研究生阶段怎么把 RL 与你的控制背景结合？（残差 RL、RL 调参、学习型状态估计）

### Q55. 残差学习与混合架构 ★★
**答案要点**
$u=u_{classical}+u_{RL}$：经典控制器（PID/LQR/MPC）提供基线，RL 学习补偿未建模动力学；好处：安全下限、更少数据、更容易调试。也可用学习方法辨识模型、调增益（学习型自适应）。

**English short answer**
> In a residual setup, a classical controller provides a safe baseline and an RL policy learns a correction for unmodeled dynamics. This needs less data, starts from a working controller, and is easier to debug and to bound for safety.

**追问方向**：如何限制残差幅值保证稳定？

## 本章要点速记
1. MDP $(S,A,P,R,\gamma)$；$G_t=r+\gamma G_{t+1}$ 推出 Bellman 方程；最优算子是 $\gamma$-压缩。
2. MC 无偏高方差；TD 有偏低方差；SARSA on-policy，Q-learning off-policy（max）。
3. DQN = 回放 + 目标网络；Double 缓解过估计；致命三角 = 逼近+自举+异策略。
4. 策略梯度：$\nabla J=E[\nabla\log\pi\,G_t]$；基线不改期望降方差；优势 + GAE。
5. PPO：裁剪比率 $\min(rA,\mathrm{clip}(r,1\pm\epsilon)A)$；SAC：最大熵 + 双 Q + 重参数化。
6. 稀疏奖励用势函数塑形/HER/课程；奖励项类似 LQR 的 $Q,R$；警惕奖励黑客。
7. BC 的复合误差 $O(T^2\epsilon)$；DAgger 降为线性；多模态动作用扩散/混合。
8. sim2real：域随机化、延迟建模、执行器网络、低层 PD；安全层兜底。
9. RL vs MPC：数据 vs 模型、离线 vs 在线、隐式 vs 显式约束；LQR = 线性二次下的 DP 闭式解。
