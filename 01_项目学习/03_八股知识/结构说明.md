# 八股知识结构说明：新旧对照与新增清单

> **一句话定位**：八股知识从"3 个目录、23 个文件"重构为"10 个模块目录"，按机器人 / AI / CS 硕士面试的覆盖面划分，不再只围绕七个项目；与 [基础知识](../02_基础知识/00_总览与学习路线.md) 分工为"基础知识讲透原理，八股做问答速查 + 英文速答"。

**本页回答**：旧 23 个文件现在在哪里？新增了哪些文件？为什么这样分？每题多了什么？

---

## 1. 设计原则

1. **按面试官会问的领域分模块，而不是按"我做过什么项目"分**。七个项目只是挂钩线索，通用知识（数据结构、操作系统、概率、软技能……）单独成模块。
2. **与基础知识一一对应**。每个新增条目带一行"对应基础知识"链接，旧条目的头部有前置知识链接；想看推导回基础知识，想快速刷题留在八股。
3. **统一条目格式**：题目（中英）→ 优先级 → 答案要点（有原理、有例子，不是一句话）→ English short answer + 中文译文 → 追问方向。
4. **每个文件目标 ≥ 60 题**。旧文件题数不足的，用"补充"章节扩到 60 题以上；缺口用新文件补齐。
5. **不编造外部事实**：涉及具体版本号、标准条款编号、厂商参数的地方标"未核对"或只写通用说法；数值型例子标"教学示例"。

## 5. 每题新增的信息

- **对应基础知识章节**：新增条目在优先级后附基础知识链接，便于"遇到不会的回去读推导"。
- **中文译文**：新增条目的 English short answer 之后附中文译文，用于核对理解。旧条目保留原有英文速答（未逐条补译文）。
- **优先级**：沿用 ★★★ / ★★ / ★。

## 6. 维护约定

- 增加条目时，条目编号接在文件内最大编号之后；每个文件题数以 `### Q` 标题数为准。
- 每个模块 README 记录题数、学习顺序、与基础知识的对应；总 README 汇总。
- 外部事实（版本号、标准编号、厂商参数）不确定时标"未核对"。
