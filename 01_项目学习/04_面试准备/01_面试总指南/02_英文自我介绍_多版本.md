# 英文自我介绍：多版本全稿与逐句讲解

> **一句话定位**：这是你的“门面”。一套按时长（30 秒 / 45 秒 / 60 秒 / 90 秒 / 2 分钟）和方向（AI / 机器人 / CS）设计的英文自我介绍，每一版都有英文全文、中文译文、发音停顿重音提示，以及逐句“为什么这样说”。

**本章学完你能……**

- 在任何时长要求下（“30 秒”“一分钟”“两分钟”“随便介绍一下”）给出一个结构完整、事实准确的开场；
- 根据申请项目是 AI、机器人还是 CS，调整自我介绍的**第一句话和结尾**，而不是重写；
- 用停顿和重音让 6.5 的口语听起来清楚自信；
- 解释自己每一句话为什么出现在介绍里，从而在被追问时知道往哪里展开；
- 避免常见的三种自我介绍错误：流水账、夸大、没有“我想要什么”。

## 1. 自我介绍的结构与原则

### 1.1 为什么自我介绍最重要

自我介绍是面试里**唯一一个你完全掌控内容和节奏的环节**，也是评委形成第一印象、决定追问方向的环节。你介绍里提到的每个项目，评委都可能追问。因此：

- **提到什么 = 邀请追问什么**。只提你准备得最好的内容。
- **介绍里不要出现你无法解释的词**。如果提了 “Kalman filter”，就要能讲 Kalman filter。

### 1.2 四段结构

```text
  ① 身份（我是谁）            Name + 学校 + 专业 + 年级 + 亮点（排名）
  ② 主线（我做过什么）        2–3 个最能代表主线的经历（不是全部）
  ③ 缺口与目的（我想要什么）   我缺什么、为什么读这个硕士
  ④ 目标（我去向何方）        职业目标，一句话
```

不同时长只是各段的**详略**不同：

| 版本 | ①身份 | ②主线 | ③缺口 | ④目标 |
|---|---|---|---|---|
| 30 秒 | 1 句 | 1 句（概括） | 1 句 | 半句 |
| 45 秒 | 1–2 句 | 2 句 | 1 句 | 1 句 |
| 60 秒 | 2 句 | 4 句（含一个小故事） | 1–2 句 | 1 句 |
| 90 秒 | 2 句 | 6–7 句 | 2 句 | 1–2 句 |
| 2 分钟 | 2–3 句 | 9–10 句（三个阶段） | 2–3 句 | 2 句 |

### 1.3 五个原则

1. **用动词讲经历**：“I built…”“I tuned…”“I designed…”。避免 “I was responsible for…” 反复出现。
2. **一个故事胜过十个名词**：每个版本至少有一个“具体动作 + 结果”的小细节（如级联 PID 加 LQR 分析）。
3. **团队成绩说团队**：RoboMaster 三等奖是团队成绩，你的角色是云台、发射、底盘控制环。
4. **缺口要诚实、不卑微**：“My machine-learning experience is mostly practical, and I want to build the foundations.” 这是自知，不是自贬。
5. **结尾一定落在“目标”**：评委要记住的是“这个人知道自己要什么”。

### 1.4 哪些事实是红线

- 学校：Shenzhen Technology University；专业：Computer Science and Technology；预计 Jun 2027 毕业，现为大四（final-year）。
- 排名：**6 of 156**（top 4%）。均分 87.63/100。雅思 6.5。
- 实习：AIRS（Sep 2025 – Mar 2026）、Future Power（Mar 2026 – May 2026）、Kaihong（Jun 2026 – **Present**，仍在进行）。
- 项目：P1–P7，名称与职责以 [CV 事实基线](../../00_申请画像/04_口径与事实基线.md) 为准。
- 奖项：RoboMaster 2025 University Championship National Final — Third Prize（团队）。
- **不要说**：论文、专利、具体性能数字（如误差、频率、成功率），除非你自己在 CV/材料里有并能解释。

## 3. 记号说明（停顿、重音）

为了让你在练习时“看得见”节奏，英文稿用这些记号（正式说的时候当然不说出来）：

| 记号 | 含义 | 怎么读 |
|---|---|---|
| `/` | 短停顿（约半拍到一拍） | 意群之间换气 |
| `//` | 长停顿（约一到两拍） | 段落转换，给听众消化 |
| **大写字母词** | 重音词 | 音量略大、拉长元音 |
| ↗ | 句调上扬（列举未完成） | 列举的前几项 |
| ↘ | 句调下降（句子结束） | 陈述句末 |

> 练习时先逐句念，再整体念。最后把记号全部擦掉，只留下节奏感。

## 4. 通用版

### 4.1 30 秒版（约 75 词）

**英文**

> Hello, / I'm Yongyi LAI. // I'm a final-year Computer Science student at Shenzhen Technology University, / ranked SIXTH out of 156. ↘ // Over the past two years, / I've worked on real ROBOTS: ↗ / balance control, ↗ / navigation, ↗ / and dual-arm teleoperation. ↘ // I'm now an intern on a robot-platform team at Kaihong. // I'd like to do a master's / to build a stronger foundation in learning and optimisation, / and then work as a robotics algorithm engineer / in the Greater Bay Area. ↘

**中文译文**

你好，我是赖咏怡。我是深圳技术大学计算机科学与技术专业大四学生，年级排名 156 人中的第 6 名。过去两年我在真实机器人上做过平衡控制、导航和双臂遥操作。我现在是深开鸿机器人平台团队的实习生。我希望读硕士，在学习与最优化方面打牢基础，之后在大湾区做机器人算法工程师。

**发音与节奏提示**

- “Shenzhen” 读作 /ʃenˈʒen/（shen-JEN），“Technology” 重音在第二音节 tech-NOL-o-gy。
- “sixth out of 156” 读作 “sixth out of one hundred and fifty-six”（不要读成 “one five six”）。
- 列举 “balance control, navigation, and dual-arm teleoperation” 前两项上扬，最后一项下降。
- 最后一句三个意群：to build… / and then work… / in the Greater Bay Area。

**逐句“为什么这么说”**

| 句子 | 为什么 |
|---|---|
| Hello, I'm Yongyi Lai. | 简单礼貌，说清名字。名字放慢一点，让评委听清。 |
| …final-year Computer Science student… ranked sixth out of 156. | 身份 + 最硬的客观亮点（排名）。使用 “sixth” 而非 “6th”，因为是说出来。 |
| Over the past two years, I've worked on real robots… | “real robots” 是你的核心区分点：实践在真实硬件上。时间“两年”来自 2024.09 起的 P3 到现在，概括但不夸大。 |
| …balance control, navigation, and dual-arm teleoperation. | 三个关键词分别对应 P1/P7、P5、P2，一句话覆盖主线，不陷入细节。 |
| I'm now an intern on a robot-platform team at Kaihong. | 说明“现在”仍在做事（Present），显得连续、可信。 |
| I'd like to do a master's to build a stronger foundation… | 明确“缺口 = 学习与最优化”，与 PS 一致。 |
| …robotics algorithm engineer in the Greater Bay Area. | 职业目标，收束。 |

**英文**

> Hello, / my name is Yongyi LAI. // I'm a final-year Computer Science student at Shenzhen Technology University, / ranked SIXTH out of 156. // My focus is robotics ALGORITHMS. ↘ // I've interned at AIRS, / Future Power, / and now Kaihong, / where I've worked on ballbot balance control, / dual-arm teleoperation, / and a multi-robot platform. // I've also built / a wheel-legged robot controller, / a navigation system for a car-like robot, / and the gimbal, launcher and chassis control for a RoboMaster hero robot / that won THIRD prize at the national final. // What I want next / is a SYSTEMATIC foundation / in optimisation, / learning-based control and perception, / so I can move from tuning controllers / to DESIGNING algorithms. // My goal is to become a robotics algorithm engineer / in the Greater Bay Area.

你好，我叫赖咏怡。我是深圳技术大学计算机科学大四学生，排名 156 人中第 6。我专注于机器人算法。我先后在 AIRS、未来动力和现在的深开鸿实习，做过球形机器人平衡控制、双臂遥操作和多机器人平台。我还做过轮腿机器人控制器、车式机器人的导航系统，以及 RoboMaster 英雄机器人的云台、发射和底盘控制——该机器人在全国总决赛中获得三等奖。我接下来想要的是在最优化、基于学习的控制与感知方面建立系统的基础，从“调控制器”走向“设计算法”。我的目标是成为大湾区的机器人算法工程师。

**发音与节奏提示**

- “gimbal” 读 /ˈɡɪmbəl/（GIM-bal，g 为硬 g）。
- “RoboMaster” 读 ROH-boh-MAS-ter。
- “ballbot” 读 BALL-bot。
- “AIRS” 读作 “airs”（像单词 airs），或逐字母 A-I-R-S，保持一致即可；第一次可说全称 Shenzhen Institute of Artificial Intelligence and Robotics for Society。如果你不想说全称，说 “AIRS” 时加半句 “a robotics research institute in Shenzhen”。

**逐句“为什么这么说”**

| 句子 | 为什么 |
|---|---|
| My focus is robotics algorithms. | 单句定位，让评委知道如何“归类”你，同时与 CV 抬头 “Robotics Algorithms · Motion Control · Autonomous Navigation” 一致。 |
| I've interned at AIRS, Future Power, and now Kaihong… | 用时间顺序罗列三段实习，“and now” 强调 Present。 |
| …ballbot balance control, dual-arm teleoperation, and a multi-robot platform. | 三段实习分别对应 P1、P2、P6，顺序与前一句相同，听众容易对应。 |

| My goal is to become… | 目标收束。 |

### 4.3 60 秒版（约 150 词，推荐默认版）

**英文**

> Hello, / I'm Yongyi LAI, / a final-year Computer Science student at Shenzhen Technology University. // I'm ranked SIXTH out of 156, / and I added control theory courses / to my CS curriculum. ↘ // My main focus is robotics algorithms. ↘ // At AIRS, / I worked on balance control / for a ballbot with a dual-arm upper body. // I deployed a CASCADED PID controller, / then modelled the system as an inverted pendulum / and used LQR / to understand how the gains trade off / STABILITY against CONTROL EFFORT. // Since then, / I've worked on a wheel-legged robot, / a car-like navigation system, / and, at Future Power, / VR teleoperation of a dual-arm robot. // Right now, / I'm an intern at Kaihong, / working on a multi-robot platform. // What I've realised / is that I can make these systems WORK, / but I want a stronger foundation / in optimisation and LEARNING. // After the degree, / I want to be a robotics algorithm engineer / in the Greater Bay Area.

**中文译文**

你好，我是赖咏怡，深圳技术大学计算机科学大四学生，排名 156 人中第 6，并在计算机课程之外修读了控制理论课程。我主要专注于机器人算法。在 AIRS，我负责带双臂上半身的球形机器人的平衡控制：部署了级联 PID 控制器，然后把系统建模为倒立摆，用 LQR 去理解各增益在稳定性与控制量之间如何权衡。此后我做过轮腿机器人、车式导航系统，以及在未来动力做双臂机器人的 VR 遥操作。现在我在深开鸿实习，做多机器人平台。我意识到自己能让这些系统跑起来，但我想要在最优化和学习方面有更强的基础。毕业后我想在大湾区做机器人算法工程师。

**逐句“为什么这么说”**

| 句子 | 为什么 |
|---|---|
| I added control theory courses to my CS curriculum. | 来自 CV 的 Relevant courses（自动控制原理、现代控制理论）。回答 “为什么 CS 的人做控制”。 |
| At AIRS, I worked on balance control for a ballbot with a dual-arm upper body. | 选 P1 作为“故事”，因为它同时有工程（PID）与建模（LQR）两个层次，也有推荐信支持。 |
| I deployed a cascaded PID controller, then modelled… | “先部署、后建模”的顺序，正是推荐信里的“返回模型分析”。 |
| …how the gains trade off stability against control effort. | 这是 LQR 权重分析的正确一句话解释，评委会追问 Q/R 权重，你应能回答。见 [P1 99 文件](../../01_项目课程/P1_AIRS球形机器人平衡控制/99_英文面试口述与深挖问答.md)。 |
| Since then, I've worked on… | 用一句话带过三个项目；“Since then” 是时间过渡。 |
| What I've realised is that I can make these systems work, but… | 全稿的“转折句”，从“做过”转向“想学”。听众的注意力会在此处集中。 |
| …stronger foundation in optimisation and learning. | “optimisation” 对应 LQR/MPC/IK 里用到的优化；“learning” 对应 PS 里的学习型感知与控制。 |

**发音提示**：“LQR” 读 “L-Q-R”（三个字母）；“PID” 读 “P-I-D”。“cascaded” /kæsˈkeɪdɪd/（cas-KAY-did）。“inverted” /ɪnˈvɜːtɪd/，重音第二音节。“trade off” 名词用 TRADE-off，动词短语用 trade OFF，这里作动词，后者。

### 4.4 90 秒版（约 220 词）

**英文**

> Hello, / my name is Yongyi LAI. // I'm a final-year Computer Science student / at Shenzhen Technology University, / ranked SIXTH out of 156. // I added Automatic Control and Modern Control Theory / to my CS courses, / because my robot projects needed them. ↘ // My first big robot project / was the embedded control of a RoboMaster hero robot, / where I built the gimbal, launcher and chassis control loops. // The team reached the national final / and won third prize. ↘ // Then, / at AIRS, / I worked on balance control for a ballbot / with a dual-arm upper body. // I designed a cascaded PID controller, / then used a four-state inverted-pendulum model with LQR / to understand the gains and actuator SATURATION. // I also fed forward the centre-of-mass shift of the arms / using URDF and Pinocchio. // In laboratory projects, / I implemented gain-scheduled LQR and virtual model control / on a wheel-legged robot, / and built a navigation chain / from EKF and AMCL localisation, / through Hybrid-A* and TEB planning, / to MPC tracking / on a car-like robot. // At Future Power, / I worked on VR teleoperation / of a dual-arm robot. // And now, / at Kaihong, / I'm building device abstraction, / robot state management / and a safe-execution chain / for a multi-robot platform. // These projects taught me / that I can make controllers work on real hardware. // What I want now / is the mathematical and learning foundation / to design them more systematically. // My goal is to work as a robotics algorithm engineer / in the Greater Bay Area.

**逐句“为什么这么说”**

| 句子 | 为什么 |
|---|---|
| I added Automatic Control and Modern Control Theory… because my robot projects needed them. | 把“课程选择”与“项目需要”连起来（HKUST(GZ) 版 PS 有同样的因果表述）。CV 课程名是 Principles of Automatic Control 与 Modern Control Theory；口语化缩写为 “Automatic Control”，也可以说全称。 |

| The team reached the national final and won third prize. | 准确表述为团队；回避 “I won”。 |
| I designed a cascaded PID controller, then used a four-state inverted-pendulum model with LQR to understand the gains and actuator saturation. | 推荐信的核心语句；“understand” 而非 “design”，因为 CV 写的是 “analyse”（分析、作为模型参考），不要说成 “LQR 控制了机器人”。 |

| And now, at Kaihong, I'm building… | “I'm building”（现在进行时）对应 Present；三项来自 CV P6：device abstraction、state management、safe-execution chain。 |

### 7.1 “不要重复 CV”的回答

**英文**

> “I think what my CV doesn't show is how I learn. / When I meet a new topic, / I try to work through a small example by hand, / then connect it to a real system. // For instance, / when I learnt LQR, / I first thought of the cost as a trade between being off balance / and spending effort, / and only then looked at the matrices. // I find that if I can explain a method in plain words, / I really understand it. // That habit has helped me move between different robots / in a short time.”

## 8. 练习方法与自检

### 8.1 五步练习法

1. **分块记忆**：把每版分成 4 块（身份 / 主线 / 缺口 / 目标），先记块的“开头词”，再记块内容。
2. **逐块朗读**：每块朗读 5 遍，注意停顿。
3. **整段计时**：用手机计时，30/45/60/90 秒版分别练习，目标误差 ±5 秒。
4. **录音回听**：看有无拖尾、吞音、语速过快。
5. **“擦除练习”**：去掉标记和逐字稿，只看事实卡 F1–F11，自己重新组织一遍。这样才能在真实面试里灵活。

### 8.2 自检清单

| 检查项 | 是 / 否 |
|---|---|
| 名字、学校、排名读得清楚 | |

| RoboMaster 的成绩说成了团队成绩 | |
| 提到 Kaihong 时用了现在时（Present） | |
| 提到 LQR 时用 “analyse/understand”，而不是“用 LQR 控制了球形机器人” | |
| 有“缺口”，并且措辞积极 | |
| 最后一句是职业目标 | |

| 流水账 | 七个项目逐个念 | 选 2–3 个，按主线串联 |
| 夸大 | “I led the team” / “I achieved 99% accuracy” | 只说有依据的；团队成绩说团队 |
| 无目标 | 讲完经历就停 | 缺口 + 目标至少各一句 |

---

## 本章要点速记

1. 四段结构：身份 → 主线 → 缺口 → 目标；时长只改变详略。
2. 默认用 60 秒版；短时用 30/45 秒；要求按 CV 讲则用 90 秒时间线版。
3. 三个方向版只改“钩子”和“强调的项目”，不改事实。
4. 排名读作 “sixth out of 156”，写作 6 of 156（top 4%）。
5. RoboMaster 是团队成绩；P1 的 LQR 是分析，部署的是级联 PID。
6. Kaihong 用现在时：“I'm currently an intern…”。
7. 缺口要诚实而积极：“more practical than systematic”。
8. 擦除练习：用事实卡重新组织，避免背稿。

## 自测题

1. 用一句话说出自我介绍的四段结构。（身份、主线、缺口、目标）
2. 为什么 AI 方向版从“软件决策如何变成物理动作”开头？（要点：与 AI 类 PS 主线一致，以 P6 安全执行链和 P4 为证据）
3. 说 P1 时，哪个词不能说成“用 LQR 控制了机器人”？应该怎么说？（要点：LQR 用于分析稳定性与控制量权衡，作为 PID 调参参考；说 analyse/understand）
4. 如果面试官说“别重复 CV”，你说什么？（要点：我如何学习——手算小例子、连接真实系统、用白话解释）
5. 把 60 秒版压缩成 30 秒，应保留哪些信息？（要点：身份 + 排名；三类经历关键词；缺口；目标）
