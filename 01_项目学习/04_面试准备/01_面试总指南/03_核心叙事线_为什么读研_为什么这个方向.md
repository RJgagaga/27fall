# 核心叙事线：为什么读研、为什么这个方向

> **一句话定位**：你的 11 份申请材料看似针对不同专业，但背后只有一条叙事线。本章把这条线讲清楚、拆成可口述的英文答案，并保证它与你各校个人陈述（PS）一致。

**本章学完你能……**

- 用一句话概括你的主线，并用三个层次展开：为什么读研、为什么 AI/机器人/具身智能、为什么大湾区；
- 讲清“从 control 到 learning”的成长线——每一步做了什么、发现了什么缺口、下一步为什么是学习与最优化；
- 对 14 个“动机类”核心问题，分别给出 30 秒 / 60 秒 / 90 秒英文版本；

- 知道哪些话不能说（夸大 learning 经验、贬低现有工作等）。

**前置知识**：已读 [面试形式、流程与评分维度](./01_面试形式_流程与评分维度.md) 与 [英文自我介绍](./02_英文自我介绍_多版本.md)。相关背景：[PS 与推荐信主线](../../00_申请画像/02_PS与推荐信主线.md)、[七个项目总览与技能矩阵](../../00_申请画像/03_七个项目总览与技能矩阵.md)。

## 1. 主线：一句话与三个层次

### 1.1 一句话

> **中文**：我做过让机器人在真实硬件上稳定运转的控制、导航与平台软件；下一步，我要补上让这些系统“被设计、而不仅是被调出来”的数学与学习基础，并回到大湾区做机器人算法。
>
> **English**：*I've made control, navigation and platform software work on real robots. Now I want the mathematical and learning foundations to design these systems, not just tune them, and then bring that back to robotics in the Greater Bay Area.*

### 1.2 三个层次

```text
      层次 3  目标    robotics algorithm engineer（感知、导航、基于学习的控制），大湾区
         ▲
      层次 2  缺口    优化 / 学习 / 操作 / 系统安全  的系统化基础（“只会调，不够会设计”）
         ▲
      层次 1  证据    七个项目：真机上的控制、估计、规划、遥操作、边缘 AI、平台软件
```

任何一个问题——为什么读研、为什么 AI、为什么这所学校——都是在这三层之间选择一个切面回答。**你只需要保证三层都是真的**：

| 层 | 真实性依据 |
|---|---|
| 证据 | CV 中 P1–P7 的 bullet，推荐信 |
| 缺口 | PS：“I can implement a controller and make it run, but I now need a more rigorous understanding of why it works and how to design it systematically”；“my experience with machine learning has so far been mainly practical” |
| 目标 | PS：robotics algorithm engineer in the Greater Bay Area；“in time to lead the algorithm side of a robot product” |

### 1.3 AI 版 / 机器人版 / CS 版的三种“重心”

| 版本 | 重心 | 证据项目 |
|---|---|---|
| AI | AI 决策如何变成物理动作；学习的基础与失效模式 | P6、P4，辅以 P1/P5 |
| 机器人 | 控制 + 导航 + 操作的严谨化；优化与学习 | P1、P7、P5、P2 |
| CS | 机器人软件系统的可靠性（接口、状态、时序、安全执行） | P6、P4、P2 |

## 2. 成长线：从 control 到 learning

这是你最有力的一条“叙事资产”：它显示的不是一堆项目，而是**能力的演进和每一次的发现**。

### 2.1 时间线与每一步学到什么

| 阶段 | 时间（CV） | 项目 | 做了什么（CV 依据） | 学到的认识 | 暴露的缺口 |
|---|---|---|---|---|---|
| ① 系统闭环入门 | 2024.05–2024.08 | P4 智能园艺 | RK3588 上 YOLOv5/RKNN INT8 推理；LangGraph 决策链 + 规则快速通道；Hi3861 水泵状态机 | 模型输出需要上下文、校验与明确的执行边界 | 不懂模型为什么这样输出；评估方法 |
| ② 嵌入式闭环 | 2024.09–2025.05 | P3 RoboMaster 英雄 | 云台级联 PID；发射机构 PID → 变增益 PID → 滑模；底盘功率控制 | 实时闭环的约束；迭代控制律 | 为什么滑模比 PID 更合适——缺理论支持 |
| ③ 感知—规划—控制链 | 2025.06–2025.10 | P5 车式导航 | EKF/AMCL，Hybrid-A*，TEB，MPC | 输入不一致（时间、坐标系）会毁掉再好的算法 | 优化（MPC 求解）与概率（滤波）的系统学习 |
| ④ 模型驱动的平衡 | 2025.09–2026.03（P1）；2025.11–2026.03（P7） | P1 球形机器人；P7 轮腿 | 级联 PID → 线性化倒立摆 + LQR 分析；增益调度 LQR + VMC | 模型能解释调参现象；线性模型有边界 | 非线性、学习型方法；最优化 |
| ⑤ 操作与遥操作 | 2026.03–2026.05 | P2 双臂 | 带约束逆运动学（MuJoCo/Mink）；主从示教 + 重力补偿；差速 PID | 奇异性、约束、人机交互 | 没有正式的操作与优化课程 |
| ⑥ 平台与安全执行 | 2026.06–至今 | P6 Kaihong | 统一能力模型；状态管理；M-DDS 协调；动作提议→策略检查→执行→状态反馈 | AI/任务决策必须经过检查才能变成动作 | 学习型决策的失效模式与系统保障 |

```text
    │         │                              │
    ▼         ▼                              ▼

         \_____________ 从“让它跑起来” _____________/        \__ 到“让它可靠、可设计” __/

```

### 2.3 “从 control 到 learning”应该怎样说才不夸大

你的 CV 里没有“基于学习的控制”的训练或部署经历。所以这条线**不是**“我从控制走到了学习”，而是：

> **我一直在做控制与系统，在这个过程中我逐渐认识到：固定管线（手调增益、固定滤波器、假设相对静态环境的规划器）有边界；学习型感知、状态估计与控制是我想系统学习的方向。**

英文版本（可直接使用）：

> “So far my work has been model-based control and system integration. / I tuned parameters by hand, / fused states with fixed filters, / and used planners that assume a mostly static environment. // That works well when the assumptions hold, / but real robots often break them. // That's why I want to study learning-based perception, estimation and control — / with a proper understanding of the mathematics and the failure modes. // I haven't trained a policy on a robot yet, / and that's exactly what I want to learn.”

**中文译文**：到目前为止，我的工作主要是基于模型的控制和系统集成。我手动调参、用固定滤波器融合状态、用假设环境基本静态的规划器。当假设成立时这些方法很好用，但真实机器人经常打破这些假设。所以我想学习基于学习的感知、状态估计与控制，并且对数学基础与失效模式有扎实理解。我还没有在机器人上训练过策略，这正是我想学的。

> **面试要点**：把“我还没做过”说在前面，评委反而会觉得你可信。PS 里的原话是：*“I have not yet had a formal course in manipulation, optimisation as a design tool or reinforcement learning”*（CUHK-SZ AIR 版）与 *“my experience with machine learning has so far been mainly practical”*（AI 版）。

## 4. 十四个核心问题与英文答案

每个问题给出：**意图 → 30 秒版 → 60 秒版 → 90 秒版（可选）→ 追问方向**。

### Q1 为什么读硕士？（Why do you want to do a master's degree?）

**面试官的意图**：你是否想清楚了目标与缺口；是不是“随大流”。

**30 秒版**

> “I can make controllers work on real robots, / but I often rely on hand tuning and linear models. // I want a master's to learn the mathematics and learning methods / that let me DESIGN these systems more systematically, / and then work as a robotics algorithm engineer.”

**中文**：我能让控制器在真实机器人上运行，但常依赖手调和线性模型。我想读硕士，学习让我能更系统地设计这些系统的数学与学习方法，之后做机器人算法工程师。

**60 秒版**

> “Over the last two years, / I've worked on a hero robot, a ballbot, a wheel-legged robot and a navigation vehicle. // Each time I could make the system run, / but the more complex the robot became, / the more I felt the limits of what I knew. // For example, / on the ballbot I used a linearised model and LQR to understand my gains, / but I couldn't go further than a linear model. // I also haven't had formal training in optimisation, manipulation, / or reinforcement learning. // A master's gives me the time and structure to learn these properly, / and to test them in a real project.”

**中文**：过去两年，我做过英雄机器人、球形机器人、轮腿机器人和导航车。每一次我都能让系统运行，但机器人越复杂，我越感到自己所知的边界。比如在球形机器人上，我用线性化模型和 LQR 理解增益，但无法超出线性模型。我也没有接受过最优化、操作或强化学习的正式训练。读硕士给我时间和结构去系统学习这些，并在真实项目中检验。

**90 秒版**（在 60 秒版后加）

> “There's also a practical reason. // At Kaihong, I'm seeing how a robot platform has to handle safety, state and coordination, / and I realise that algorithm quality alone isn't enough. // I want to learn how to design the algorithm and its safeguards together. // So for me, a master's isn't a break from engineering; / it's a way to make my engineering more rigorous.”

**中文**：还有一个实际原因。在深开鸿，我看到机器人平台必须处理安全、状态与协调，仅有算法质量是不够的。我想学习如何把算法及其保障一起设计。所以对我来说，读硕士不是离开工程，而是让我的工程更严谨。

**追问方向**：Which specific gap? → 回答“LQR 以外的优化方法 / RL”；Have you tried self-study? → 见 [弱项应对](./05_弱项与敏感问题应对.md)。

### Q2 为什么现在读，而不是先工作？（Why study now rather than work first?）

> 本题详细多版本在 [05 弱项与敏感问题应对](./05_弱项与敏感问题应对.md)，这里给叙事线版。

**60 秒版**

> “I've already worked as an intern for three organisations, / so I know the work well enough to see what I'm missing. // The gaps I found are theoretical: / optimisation, learning and manipulation. // It's difficult to fill them while delivering a product, / because deadlines favour what already works. // A master's lets me study these foundations in a structured way / while I can still try them on real robots. // After that, / I'd return to industry as a stronger algorithm engineer.”

**中文**：我已经在三个机构实习过，对工作足够了解，所以看得出自己缺什么。我发现的缺口是理论性的：最优化、学习和操作。在交付产品的同时很难补这些，因为工期偏向已有的成熟方案。读硕士让我以结构化的方式学习这些基础，同时还能在真实机器人上尝试。之后我会回到产业，成为更强的算法工程师。

### Q3 为什么 AI？（Why artificial intelligence?）

**30 秒版**

> “Because I want to understand the part I've only deployed. // I ran a YOLOv5 model on an edge device and built a decision chain, / but I couldn't fully explain why the model behaves as it does or when it fails. // I want to learn that, / and use it to make robots more capable and safe.”

**中文**：因为我想理解自己只是部署过的那一部分。我在边缘设备上跑过 YOLOv5 并搭了决策链，但无法完整解释模型为什么这样表现、何时会失败。我想学习这些，让机器人更有能力、更安全。

**60 秒版（AI 项目版）**

> “My interest in AI starts at a very practical point: / how does a software decision become a physical action? // At Kaihong, a task plan from a high-level planner cannot go to a robot directly. // It goes through an action proposal, a policy check, execution and state feedback. // Designing that chain showed me that a model's output is only a proposal; / the system has to decide what to trust. // To do that well, / I need to understand how models learn, how they fail, / and how to evaluate them. // That's why I'm applying for an AI master's.”

**中文**：我对 AI 的兴趣从一个很实际的点开始：软件的决策如何变成物理动作？在深开鸿，高层规划器给出的任务计划不能直接发给机器人，它要经过动作提议、策略检查、执行和状态反馈。设计这条链让我明白，模型输出只是一个提议，系统必须决定信任什么。要把这做好，我需要理解模型如何学习、如何失效，以及如何评估。这就是我申请 AI 硕士的原因。

> **面试要点**：这一版来自 PS 主线。注意 “Designing that chain” 是 CV P6 的内容（*gated task plans through an action-proposal, policy-check, execution and state-feedback chain*），不要把它说成“我训练了大模型”。

**追问方向**：What is your AI experience exactly? → 答 P4：YOLOv5/RKNN INT8、LangGraph、规则快速通道。What would you study? → Q10。

### Q4 为什么机器人？（Why robotics?）

**30 秒版**

> “In robotics, / an algorithm doesn't just produce a number, / it produces motion. // I like that every assumption is tested by the real world, / and I like that it combines control, perception, planning and software.”

**中文**：在机器人领域，算法产出的不只是一个数，而是运动。我喜欢每个假设都被真实世界检验，也喜欢它把控制、感知、规划与软件结合在一起。

**60 秒版**

> “What attracts me to robotics is the feedback from reality. // On the ballbot, / when the centre of mass moved because the arms moved, / my controller had to cope immediately. // When it didn't, / the cause could be a model assumption, / a timing issue, / or a torque limit — / and I had to find out which. // That kind of debugging teaches me more than any simulation. // It also showed me that robotics isn't one skill: / it's control, estimation, planning and software working together. // I enjoy that breadth, / and that's why I want to make it my career.”

**中文**：吸引我的是现实的反馈。在球形机器人上，手臂移动导致质心移动，控制器必须立即应对。若不行，原因可能是模型假设、时序问题或力矩限制，我得找出是哪一个。这种调试比任何仿真都教我更多。它也让我明白机器人不是单一技能：它是控制、估计、规划和软件的协作。我喜欢这种广度，所以想以此为职业。

> 注：“cause could be a model assumption, a timing issue, or a torque limit” 来自 P7 CV（*traced balance anomalies to state inconsistency, torque limits and ground-contact transitions*）和 P5（时序、坐标系不一致）的综合表述；若被问“在哪个项目遇到”，答 P7 或 P1，并按 CV 的说法讲，不要编造具体故障。

### Q5 为什么具身智能 / 学习型机器人？（Why embodied intelligence?）

**30 秒版**

> “Because the next step for my kind of work is learning. // Hand-designed controllers and fixed pipelines work under assumptions, / and learning methods may help robots handle what those assumptions miss. // But they must be tested on a body, in the real world, / and that's what embodied intelligence is about.”

**中文**：因为我这类工作的下一步是学习。手工设计的控制器和固定管线依赖假设，学习方法也许能帮助机器人处理这些假设遗漏的部分。但它们必须在真实身体上、真实世界里检验，这就是具身智能关心的。

**60 秒版（HKUST(GZ) 具身智能版）**

> “I've built perception, planning and control modules for several robots, / but I treated them as separate pieces. // In embodied intelligence, / these are designed together around one body and one task. // That's what interests me. // I'd like to learn how learning methods can connect perception to action, / and how to validate them outside simulation. // My hardware experience helps me ask practical questions, / like timing, safety and state consistency, / and I want the training to answer them with more rigour.”

**中文**：我为多个机器人搭过感知、规划和控制模块，但把它们当成相互独立的部件。在具身智能里，这些围绕同一个身体和任务共同设计。这是我感兴趣的。我想学习学习方法如何把感知连接到动作，以及如何在仿真之外验证。我的硬件经验让我能提出实际问题，比如时序、安全与状态一致性，我希望训练能更严谨地回答它们。

> 注：HKUST(GZ) PS 中确有 “study how perception, planning, control and learning can be designed as one embodied system” 的意思；此处为口语化表达。

### Q6 为什么读 CS（而不是 EE / ME / 控制）？

**30 秒版**

> “My background is Computer Science, / and in robotics I keep finding that the first serious problems are in the software: / timestamps, coordinate frames, interfaces and safe execution. // I want to build those foundations properly, / while keeping robotics as my application area.”

**中文**：我的背景是计算机科学，而在机器人上我不断发现最先出现的严重问题在软件：时间戳、坐标系、接口与安全执行。我想扎实地建立这些基础，同时把机器人作为应用方向。

**60 秒版**

> “At Kaihong, / motion-control code could not be reused across hardware / until the timestamps, coordinate frames and validity checks / were standardised across sensors and actuators. // That showed me that inconsistent state leads directly to unreliable control. // A computer science degree is broader than a robotics-only one, / and software principles transfer across platforms. // I chose it on purpose: / it's the area where my training is least systematic, / relative to how much I rely on it.”

**中文**：在深开鸿，在传感器和执行器间统一时间戳、坐标系和有效性检查之前，运动控制代码无法跨硬件复用。这让我看到状态不一致会直接导致控制不可靠。计算机科学比纯机器人专业更宽，软件原则可以跨平台迁移。我是有意选择它：在这一块，我的训练相对于我对它的依赖程度是最不系统的。

> 此版本几乎对应 CityU 东莞/CUHK-SZ CS 的 PS 论点；CV P6 第二条 bullet（*standardised timestamps, coordinate frames and validity checks*）支持第一部分。

### Q7 为什么大湾区 / 港澳 / 东莞？

**30 秒版**

> “I've done all my internships in Shenzhen, / at a research institute and two companies, / so I know the robotics community here. // I want to work in the Greater Bay Area after the degree, / and studying in the region helps me build connections and keep the industry in view.”

**中文**：我所有实习都在深圳，在一个研究院和两家公司，所以我了解这里的机器人生态。我毕业后想在大湾区工作，在本地区学习能帮我建立联系，并持续关注产业。

**60 秒版**

> “My internships at AIRS, Future Power and Kaihong were all in Shenzhen, / so I've seen the region's robotics industry up close — / from research to products to platforms. // My goal is to be a robotics algorithm engineer in the Greater Bay Area. // A programme in this region lets me study while staying close to that ecosystem, / for example through projects with local companies or by attending industry events. // And at a university like yours, / I can also learn in an international, English-taught environment, / which will help me work with global teams later.”

**中文**：我在 AIRS、未来动力和深开鸿的实习都在深圳，所以近距离见过这个区域从研究到产品到平台的机器人产业。我的目标是在大湾区做机器人算法工程师。在这个区域读书让我在学习的同时贴近产业生态，例如通过与本地企业的项目或参加产业活动。而在贵校这样的大学，我还能在国际化、英文授课的环境中学习，对今后与全球团队合作有帮助。

> **注意**：“projects with local companies” 是一种**可能性**的说法；若你不确定该项目是否提供，改为 “I hope to…”，并在 [反问面试官](./06_反问面试官的问题.md) 中求证。港澳与东莞的具体特点见各校文件。

### Q8 为什么这个项目？（Why this programme?）模板

回答 “Why this programme” 的公式：

```text
  1. 我的缺口（一句，来自主线）
  2. 该项目的两个具体特征（课程/方向/平台，需要你核对官方页面）
  3. 它们如何对应我的缺口
  4. 我能带来什么（可选）
```

**模板（60 秒）**

> “My main gap is [GAP: e.g. optimisation and learning-based control]. // I looked at your curriculum, / and two things stand out: / first, [FEATURE 1: a specific course or area]; / second, [FEATURE 2: a lab, a project requirement or a direction]. // The first matches [MY PROJECT], / and the second would let me [GOAL]. // I'd also bring [WHAT I BRING: e.g. real-robot experience].”

**中文**：我的主要缺口是【缺口】。我研究了你们的课程，有两点很突出：第一【特征 1】；第二【特征 2】。第一点对应我的【项目】，第二点让我能【目标】。我也能带来【贡献】。

**已有的完整示例（据 PS 中对 CUHK-SZ 的课程提法）**

> “My gap is that I haven't had formal training in manipulation, optimisation or reinforcement learning. // On your programme, / Robot Manipulation and Math Fundamentals for Robotics address exactly that, / and the electives in Mobile Robotics and Reinforcement Learning / link to my navigation and control work. // I'd bring real-robot experience with balance control, / navigation and dual-arm teleoperation.”

**中文**：我的缺口是没有受过操作、最优化或强化学习的正式训练。贵项目的 Robot Manipulation 与 Math Fundamentals for Robotics 正好覆盖，Mobile Robotics 和 Reinforcement Learning 选修则连接到我的导航与控制工作。我能带来平衡控制、导航和双臂遥操作的真实机器人经验。

> 课程名称出自你的 CUHK-SZ（AI 与机器人）PS。对其他学校，**必须去官网核对课程名**再使用；已写好的学校专属内容在 [各校面试准备](../02_各校面试准备/README.md)。`【待你补全：目标学校的 2 个具体课程或方向，来自官网】`

### Q9 职业目标（Where do you see yourself in 5 years / career goals?）

**短期（毕业后 1–3 年）**：robotics algorithm engineer in the Greater Bay Area；方向：感知、导航、基于学习的控制。
**长期**：能主导机器人产品的算法栈（PS 原句：*grow into someone who can own the algorithm stack of a robot product*）。

**60 秒版**

> “In the short term, / I want to work as a robotics algorithm engineer in the Greater Bay Area, / on perception, navigation and learning-based control. // In the longer term, / I'd like to grow into someone who can own the algorithm stack of a robot product, / and understand how algorithms, software and hardware fit together. // I think my background in control and platform software, / plus a stronger foundation in learning and optimisation, / is a good preparation for that.”

**中文**：短期，我想在大湾区做机器人算法工程师，从事感知、导航和基于学习的控制。长期，我想成长为能够主导机器人产品算法栈的人，并理解算法、软件与硬件如何配合。我认为控制与平台软件的背景，加上更扎实的学习与最优化基础，是很好的准备。

**CS 版的变体**

> “…I want to work as a software engineer for robot platforms and motion algorithms, / and in time lead the software side of a robot product.”

**追问方向**：Would you consider a PhD? → 见下文 Q14 之后的补充；Would you work outside the Greater Bay Area? → 诚实答“主要目标在大湾区，但对好机会保持开放”。

### Q10 想学哪些课程 / 方向？

**30 秒版**

> “Three areas. // First, the foundations: machine learning, optimisation and probabilistic methods. // Second, learning for robots: perception and reinforcement learning. // Third, manipulation and system design, / so that I can build and test a complete robot project.”

**中文**：三方面。第一，基础：机器学习、最优化和概率方法。第二，面向机器人的学习：感知与强化学习。第三，操作与系统设计，使我能搭建并测试一个完整的机器人项目。

**60 秒版（AI 项目版）**

> “I want to strengthen three areas. // First, the foundations of machine learning and deep learning, / so I understand why a model learns and why it fails. // Second, evaluation: how to choose data, compare against a baseline, / and test behaviour under changing conditions. // Third, reinforcement learning and its role in robot decision-making or control. // I'd connect these in a focused project, / starting with a manageable problem / and evaluating it carefully before considering physical deployment.”

**中文**：我想加强三个方面。第一，机器学习与深度学习的基础，理解模型为何学习、为何失败。第二，评估：如何选择数据、与基线比较、测试变化条件下的行为。第三，强化学习及其在机器人决策或控制中的作用。我会在一个聚焦的项目里把它们连起来，从可控的问题入手，先仔细评估，再考虑物理部署。

> 此版本与 CityU 东莞 AI 面试准备文档的方向一致，我已改写成更适合你的口吻。

### Q11 你能为项目带来什么？（What can you contribute?）

**60 秒版**

> “I'd bring three things. // First, hands-on experience: I've carried algorithms through hardware validation on several robots, / so I can contribute in lab and project work. // Second, a habit of checking the whole system, / not just the algorithm — timing, frames, limits and safety. // Third, I like to explain things in plain language, / which helps in group work. // And I'm honest about what I don't know, / so I ask questions early and learn quickly from classmates and faculty.”

**中文**：我能带来三点。第一，动手经验：我在多个机器人上把算法推进到硬件验证，可以在实验和项目工作中贡献。第二，检查整个系统的习惯，而不仅是算法：时序、坐标系、限制与安全。第三，我喜欢用平白的语言解释，这有助于小组合作。而且我坦诚面对未知，会及早提问并向同学和教授快速学习。

> 注意避免空话。每一点后面都应准备一个 [STAR 故事](./04_行为面试_STAR与常见问题.md)。

### Q12 你的研究兴趣？（What are your research interests?）

**诚实框架**：你没有论文，所以不要假装有成熟的研究方向。应给出“兴趣 + 动机 + 想验证的问题”。

**60 秒版**

> “I don't have a fixed research topic yet, / but I do have questions that come from my projects. // One is how to combine a model-based controller with learning, / so the robot keeps the stability guarantees I understand / while handling what the model misses. // Another is how to make perception and state estimation robust to timing and frame errors, / which I met a lot in navigation. // I'd like to explore these under the guidance of a supervisor, / starting with a small, well-defined problem.”

**中文**：我还没有固定的研究课题，但有来自项目的问题。一个是如何把基于模型的控制器与学习结合，让机器人在保留我所理解的稳定性的同时，处理模型遗漏的部分。另一个是如何让感知与状态估计对时序与坐标系误差更鲁棒，这在导航中我遇到很多。我希望在导师指导下，从一个小而明确的问题开始探索。

> 注：第一个问题是研究兴趣的陈述，不是已做成果。第二个来自 P5 CV（*handled drift and pose jumps from inconsistent timing, frames and motion direction*）。

### Q13 你怎么看机器人 / 具身智能的未来？

这是开放观点题。建议结构：**观察 → 挑战 → 我的看法 → 我会做什么**，并避免预言和绝对化。

> “I think robots will keep moving from fixed, structured settings to more open environments. // Learning methods will probably play a bigger role in perception and in handling variation. // But the challenge I see is reliability: / how do we know a learned component is safe enough to drive an actuator? // I think systems will need clear checks and fallback behaviour around learned parts, / like the policy-check step in the platform I work on at Kaihong. // So my view is that learning and engineering safeguards will grow together.”

**中文**：我认为机器人会不断从固定、结构化的场景走向更开放的环境，学习方法在感知和处理变化方面可能发挥更大作用。但我看到的挑战是可靠性：我们怎么知道一个学习得到的部件足够安全，可以驱动执行器？我认为系统需要围绕学习部件设置清晰的检查与回退行为，就像我在深开鸿的平台上的策略检查步骤。所以我的看法是学习与工程保障会一起发展。

### Q14 如果没被录取怎么办？（What if you aren't admitted?）

**诚实框架**：不要表现出“只有这里”，也不要说“随便”。表达认真、有备用路径，仍然坚持目标。

> “I'd be disappointed, / but my goal wouldn't change. // I would continue working in robotics software and keep studying the foundations, / probably through online courses and my own projects, / and consider applying again or other programmes. // But this programme is a very good fit for my goal, / which is why I'm putting a lot into this interview.”

**中文**：我会失望，但目标不会变。我会继续做机器人软件，并通过在线课程和自己的项目继续学习基础，也会考虑再次申请或申请其他项目。但这个项目与我的目标非常匹配，所以我很重视这次面试。

> **注意**：不要说出“我有几个 offer”或“这是我的备选”。如果被问 “Which is your first choice?”，见 [弱项与敏感问题应对](./05_弱项与敏感问题应对.md)。

### 补充：PhD 问题

“Would you consider a PhD after the master's?”

> “I'm open to it. / My immediate plan is to work in industry, / but if I find during the master's that I enjoy research questions enough, / and I have a supervisor to work with, / I'd seriously consider a PhD. // At the moment I don't want to commit before I've done a real research project.”

**中文**：我持开放态度。我的近期计划是进入产业，但如果在硕士期间发现自己足够喜欢研究问题，并有导师合作，我会认真考虑读博。现在我不想在做过真正的研究项目之前下承诺。

## 5. 叙事线的“防护栏”：哪些不能说

| 不要说 | 原因 | 改成 |
|---|---|---|
| “I have a lot of AI experience.” | CV 里是部署与集成，没有训练/RL | “My AI experience is mostly practical: deployment and integration.” |
| “My projects are not good enough, so I need a master's.” | 贬低自己 | “These projects showed me what I want to learn next.” |
| “I want to switch from control to AI because control is boring.” | 贬低过去，也不诚实 | “Control taught me the problems I want learning methods to help with.” |
| “I will definitely do a PhD / definitely work.” | 绝对化 | “I'm open to…, and my immediate plan is…” |
| “I want a Hong Kong/Macau degree because it's easier / for a visa / for a future in…” | 动机不当 | 用产业贴近、教学内容、语言环境 |
| “I want to publish papers.” | 与无论文的现实冲突，但并非不能说；说成“learn how to do research” | “I want to learn how to do rigorous research.” |
| “The algorithms I built are better than others.” | 夸大 | “They worked on our robot under our constraints.” |

> 学校对比、学校排名、其他申请的情况，一律不要主动提。

## 6. 把答案写成自己的话：改稿步骤

上面的英文是示范。要让它变成你的，按以下步骤：

1. **读一遍中文译文**，确认“这是我真的想说的”。如果不是，直接改中文。
2. **用你的话重写英文**，保持 12–20 个词的短句。
3. **补一个具体细节**：能指向一个项目、一个现象、一个选择。
4. **标出可被追问的词**（如 LQR、AMCL、policy check），保证你能解释。
5. **朗读 + 计时**，30/60/90 秒各一版。
6. **和自我介绍交叉检查**：同一个事实在不同地方说法一致。

改稿检查表：

| 检查项 | 是 / 否 |
|---|---|
| 每个事实能在 CV/PS/推荐信找到 | |
| 没有未标注的数字 | |
| 没有夸大 learning 经验 | |
| 有“缺口”和“目标” | |
| 与自我介绍、PS 没有冲突 | |
| 可以在 60 秒内说完 | |

## 本章要点速记

1. 主线：做过真机上的控制/导航/平台软件，现在要补设计所需的数学与学习基础，回大湾区做机器人算法。
2. 三层：证据（七个项目）→ 缺口（优化、学习、操作、系统保障）→ 目标（robotics algorithm engineer）。
3. “从 control 到 learning”是**方向**，不是已完成的经历；诚实说明“还没训练过策略”。
4. 回答与 PS 一致，但换学校的“钩子”：AI 版用 P6 的安全执行链，机器人版用三个机器人，CS 版用软件先暴露问题。
5. 读研的理由是缺口具体（optimisation、manipulation、RL、ML 理论），而不是泛泛的“提升自己”。
6. 为什么大湾区：三段实习都在深圳；目标岗位在本地区。
7. 为什么这个项目：缺口 + 两个具体特征 + 对应关系，课程名必须核对官网。
8. 未来观点题：先观察，再挑战（可靠性），再看法（学习 + 工程保障一起发展）。

## 自测题

1. 用一句话说出你的主线。（要点：真机上的控制与平台经验 + 补设计所需的数学与学习基础 + 大湾区机器人算法）
2. “从 control 到 learning”怎样说才不夸大？（要点：说是方向；明确没训练过策略；说固定管线的边界）
3. AI 版与 CS 版的钩子有什么不同？（要点：AI 版从 AI 决策→物理动作与 P6 安全执行链；CS 版从软件先暴露问题与统一时间戳/坐标系）
4. 回答 “Why this programme?” 的四步是什么？（缺口、两个具体特征、对应关系、能带来什么）
5. 被问 “If you are rejected?” 应避免哪两种极端？（要点：说“只有这里”显得无备选；说“随便”显得不认真）
