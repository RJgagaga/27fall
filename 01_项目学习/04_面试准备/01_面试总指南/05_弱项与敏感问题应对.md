**本章学完你能……**

- 面对“没有论文”“机器学习偏实践”“学校与排名”“实习较短”“雅思 6.5”“为什么不直接工作”“Kaihong 在职为何还申请读研”“保密边界”“为什么从 CS 走向机器人”等问题时，不防御、不辩解、不夸大，而是诚实、有分寸、有证据；

- 把弱项转化为“选择这个硕士的理由”。

## 1. 总原则：四步公式与“三不”

### 1.1 四步公式

```text
  ① 承认   一句话，直接，不绕：“That's true. / You're right that…”
  ② 证据   一两个事实说明你已有的东西：项目、排名、实习、能力
  ③ 计划   你怎么补：具体、可信（课程、项目、自学）
  ④ 回到目标  这个弱项与我选择这个项目的关系
```

**为什么有效**：评委问弱项，不是要你否认，而是看你**是否自知**、是否**有计划**、是否**诚实**。承认之后给证据，会让承认变成“冷静”，而不是“示弱”。

### 1.2 “三不”

1. **不防御**：不要说 “But that's not important.” 或 “That's unfair.”
2. **不夸大**：不要把应用经验说成理论成果；不要把团队成绩说成个人。
3. **不贬低别人/别的学校/雇主**：不管是自己的本科院校，还是其他项目。

### 1.3 篇幅

弱项题的回答 **30–45 秒**。越短越稳。说完停住，不要自己补充更多弱点。

## 2. 问题清单与评委的真实担心

| 问题 | 评委真正担心 | 你的核心回应 |
|---|---|---|
| 没有论文 | 研究潜力、学术严谨度 | 授课型硕士；我有严谨的工程验证习惯；想在硕士中学习研究方法 |
| ML 偏实践 | 能否跟上理论课程 | 承认；有数学底子（线性代数、概率统计）；有具体补法 |

| 平均分 | 学业能力 | 87.63 与排名一起讲 |
| 英语 6.5 | 能否授课听讲 | 达标；用实践和准备证明沟通；有提升计划 |
| 实习较短 | 稳定性、深度 | 每段的交付内容与跨度 |
| 项目太多太散 | 缺乏焦点 | 一条主线 |
| 团队贡献 | 诚信、个人能力 | 明确职责边界 |

| CS 转机器人 | 背景匹配 | 软件系统是机器人的关键层 |
| 数学基础 | 跟课能力 | 课程+项目+复习计划 |

## 3. 逐题应对

> 每题格式：评委的担心 → 原则 → 版本 A（短，30 秒内）→ 版本 B（标准，45 秒）→ 版本 C（展开，60–75 秒，可选）→ 不要说。

### 3.1 没有论文 / 没有科研发表

**问法**：*Do you have any publications?* / *Have you done any research?* / *What is your research experience?*

**原则**：诚实说“没有发表”，不要用“项目”硬套“研究”；强调**工程验证与模型分析**的方法，并说明想在硕士阶段**学习研究方法**。

**版本 A（短）**

> “No, I don't have publications yet. / My experience is in engineering and validation on real robots. / I'd like to learn how to do research properly in this programme.”

**中文**：没有，我还没有发表。我的经验是真实机器人上的工程与验证。我希望在这个项目里学习如何规范地做研究。

**版本 B（标准）**

> “I don't have publications. // My work has been in applied robotics: / building controllers and navigation systems and validating them on real hardware. // Some of it has a research flavour — / for example at AIRS, / I went back to a model and used LQR to analyse how the gains trade off stability and control effort, / and I checked my feedforward by toggling it under the same arm trajectories. // That's the kind of careful comparison I want to learn to do in a more formal, rigorous way. // So I see the master's as where I learn the research method.”

**中文**：我没有论文。我的工作是应用型机器人：搭建控制器和导航系统并在真机上验证。其中有一点研究的味道，比如在 AIRS 我回到模型，用 LQR 分析增益如何在稳定性和控制量间权衡，并在相同手臂轨迹下开关前馈来检验。这就是我想以更正式、更严谨的方式学习的那种细致对比。所以我把硕士视为学习研究方法的地方。

**版本 C（展开）**

> “…I know that research also means reading the literature, / defining a hypothesis and designing a fair evaluation. // I've done parts of that informally, / but not at the level a research project requires. // If I have the chance, / I'd like to join a research project during the programme, / maybe starting with a small, well-defined question.”

**中文**：……我知道研究还包括阅读文献、提出假设和设计公平的评估。我非正式地做过其中一部分，但没有达到研究项目所要求的水平。如果有机会，我想在项目期间参加一个研究项目，也许从一个小而明确的问题开始。

**不要说**：“I did research on …”（若无正式研究）；“Papers are not important.”

### 3.2 机器学习偏实践，理论不系统

**问法**：*Your ML experience seems practical. How strong is your theory?* / *Can you explain how backpropagation works?*

**原则**：这是你 PS 里已承认的点，评委读过。**承认→证据（数学课程）→计划→回到项目**。同时要真的能回答基础问题（见 [八股知识](../../03_八股知识/README.md)、[机器学习基础](../../02_基础知识/10_机器学习与深度学习/01_机器学习基础.md)）。

**版本 A**

> “That's fair. / My machine-learning experience is mostly practical — / deploying a YOLOv5 model on an RK3588 board and building a decision chain with LangGraph. / I want to study the theory behind it, which is one of my reasons for this degree.”

**中文**：您说得对。我的机器学习经验主要是实践的：在 RK3588 上部署 YOLOv5，并用 LangGraph 搭决策链。我想学习背后的理论，这是我读这个学位的原因之一。

**版本 B**

> “My experience with machine learning has been mainly practical, / and I'm clear about that. // I've deployed an INT8-quantised YOLOv5 model on RK3588 / and built a decision workflow around it, / so I understand the engineering side: / inputs, outputs, confidence and latency. // What I need is the foundations: / why a model learns, how to evaluate it, and how it fails. // I do have the mathematical base — / linear algebra, probability and statistics — / and I plan to connect them with the learning methods step by step.”

**中文**：我的机器学习经验主要偏实践，我对此很清楚。我在 RK3588 上部署过 INT8 量化的 YOLOv5 并围绕它搭决策流程，所以我理解工程层面：输入、输出、置信度与延迟。我需要的是基础：模型为何学习、如何评估、如何失效。我有数学基础——线性代数、概率统计——并计划把它们与学习方法逐步连接。

**版本 C（被追问理论时）**

> “If I explain it in simple terms: / training adjusts the parameters to reduce a loss, / and backpropagation uses the chain rule to compute how the loss changes with each parameter. // I can explain that at a basic level, / but I know I haven't worked through the derivations and the theory in depth, / and that's what I want to do.”

**中文**：用简单的话说：训练是调整参数以减小损失，反向传播用链式法则计算损失对每个参数的变化。我能在基础层面解释，但我知道自己还没有深入推导和学习理论，这正是我想做的。

> 注：版本 C 中的对 backpropagation 的解释为通用知识；若被追问深入，请学习 [神经网络与反向传播](../../02_基础知识/10_机器学习与深度学习/02_神经网络与反向传播.md)。

**不要说**：“I know deep learning very well.”

### 3.3 没有强化学习 / 深度学习训练经验

**问法**：*Have you trained any neural networks?* / *Have you used reinforcement learning?*

**原则**：CV 里没有训练经验。**不要含糊**。可说“我部署过，没训练过”，并说清想怎么入门。

**版本 A**

> “I haven't trained a policy or a network from scratch for a project. / My experience is deployment and integration. / I'd like to learn training and evaluation properly.”

**中文**：我没有为项目从零训练过策略或网络。我的经验是部署与集成。我想系统学习训练与评估。

**版本 B**

> “No, not for a robot. // What I've done is deploy a detection model and connect its output to decisions and actuators. // That showed me that a model's output is only one input to the system. // For reinforcement learning, / I understand the idea — learn a policy from reward — / and I can see how it relates to the controllers I've tuned by hand: / a policy is like a controller that's learned. // But I haven't trained one, / and I'd start with a simple simulated task and compare it against a baseline controller.”

**中文**：没有，没为机器人做过。我做的是部署一个检测模型并把输出连到决策和执行器。这让我明白模型的输出只是系统的一个输入。强化学习我理解思想——从奖励中学习策略——也能看出它和我手调的控制器的关系：策略像是学出来的控制器。但我没训练过，我会从一个简单的仿真任务开始，并与基线控制器比较。

**不要说**：“I did RL in my project.”（除非真有。）

### 3.4 本科院校与排名

**问法**：*Your university is not among the top-ranked... Why should we believe you can keep up?* / *Tell me about your university.*

**原则**：**不防御，不贬低母校，不攀比**。用可验证的事实：排名、竞赛、实习、推荐信。语气平静。

**版本 A**

> “I'm proud of my university. / Within my major I'm ranked 6th out of 156, / and I've worked on real robotics projects and internships alongside my studies.”

**中文**：我为我的大学感到自豪。在我的专业里我排名 156 人中的第 6，并在学习之外参与了真实的机器人项目和实习。

**版本 B**

> “Shenzhen Technology University is a young, application-oriented university, / and it gave me strong access to practical work. // I'm ranked 6th among 156 students in my major, / with an average score of 87.63. // I also took the opportunity to work on RoboMaster, / where our team reached the national final, / and to do internships at a research institute and two companies. // I think a master's is where I can add depth to that practical base.”

**中文**：深圳技术大学是一所年轻的、应用型的大学，它给了我接触实践工作的机会。我在专业 156 人中排名第 6，平均分 87.63。我还参与了 RoboMaster，团队进入全国总决赛，也在一个研究院和两家公司实习。我认为硕士是在这个实践基础上增加深度的地方。

> 事实依据：CV 排名、均分、奖项、实习。“young, application-oriented” 是对学校特点的一般描述，如果你不确定请删去，保留事实部分。想谈学校特色时只说有依据的一点：学校给了我进入 RoboMaster 战队和校内实验室做项目的机会（P3、P7、P5 都在校内完成），其余不展开。例句："My university gave me access to the RoboMaster team and the lab where I did my navigation and wheel-legged projects."（中文：学校让我有机会参加 RoboMaster 战队，并在实验室做导航和轮腿项目。）

**不要说**：“My university isn't famous but…”（自贬）；“Other students are weaker.”

### 3.5 平均分（GPA）

**问法**：*What's your GPA?* / *Your grades—how do you rank?*

**原则**：给出你的**真实口径**：平均分 87.63/100，排名 6 of 156（top 4%）。**不要自己换算 GPA**，除非你有官方换算。若被要求 4.0 制，说 “I'd have to check the official conversion”。

**版本 A**

> “My average is 87.63 out of 100, / and I'm ranked 6th among 156 students in my major.”

**中文**：我的平均分是 87.63（满分 100），在专业 156 人中排名第 6。

**版本 B**

> “My average score is 87.63 out of 100, / which puts me 6th out of 156, in the top 4%. // I don't have an official four-point GPA conversion, / so I'd rather use the percentage and the rank. // I can send the official transcript if you need it.”

**中文**：我的平均分是 87.63（满分 100），排名 156 人中的第 6，前 4%。我没有官方的 4 分制换算，所以更愿意用百分制和排名。如果需要我可以提供成绩单。

> **注意**：口径检查——英文 CV 为 87.63 和 6 of 156（top 4%）。你的材料中曾出现过别的数字（中文简历与个别文档），**以 CV 为准**，面试里只用这一套。如果面试官问 GPA 换算，可以说："My CV gives the average score, 87.63 out of 100, and my rank, 6 of 156. I can provide the official transcript if you need a GPA conversion."（中文：CV 上是均分 87.63/100 和排名 6/156；如需 GPA 换算，我可以提供官方成绩单。）

### 3.6 英语 6.5

**问法**：*Your IELTS is 6.5. Are you confident about studying in English?*

**原则**：6.5 通常满足入学要求；不要把它说成“不好”，也不要说成“很好”。**用当下的表现证明**，并给提升计划。

**版本 A**

> “I think so. / My IELTS is 6.5, which meets the requirement, / and I've been practising technical English every day, / including today's conversation.”

**中文**：我认为可以。我的雅思是 6.5，达到要求，而且我每天练习技术英语，包括今天的对话。

**版本 B**

> “My IELTS score is 6.5. // I'm comfortable discussing technical topics because I've studied and read in English for my projects: / documentation, tools, and papers. // I know that fast, unfamiliar conversation is harder for me, / so if I don't catch something, I'll ask politely. // I've been preparing by speaking about my projects out loud and recording myself, / and I'll keep improving through the programme.”

**中文**：我的雅思分数是 6.5。我能自如地讨论技术话题，因为为了项目我一直在读英文文档、工具和论文。我知道快速、陌生的对话对我更难，所以没听清我会礼貌询问。我通过大声讲项目和录音来准备，并将在项目中继续提高。

> “read papers” 若你的确读过再说；否则改为 “documentation and technical materials”。

**不要说**：“My English is bad.” / “English is not important in robotics.”

### 3.7 实习较短

**问法**：*Your internships are quite short. What did you really achieve?*

**原则**：诚实说“时间不长”，然后讲**交付内容和上机验证**。注意 CV 时长：AIRS（Sep 2025 – Mar 2026，约 6–7 个月，推算）、Future Power（Mar 2026 – May 2026，约 3 个月，推算）、Kaihong（Jun 2026 – Present）。

**版本 A**

> “They were short, that's true. / But in each one I delivered something that ran on real hardware — / balance control at AIRS, / teleoperation at Future Power, / and a platform module at Kaihong.”

**中文**：确实不长。但每一段我都交付了在真机上运行的东西——AIRS 的平衡控制、未来动力的遥操作、深开鸿的平台模块。

**版本 B**

> “The Future Power internship was about three months, / and the AIRS one about six months, / so yes, they're not long. // I used the time to take a focused piece of work all the way to the robot. // At AIRS, / I deployed a cascaded PID controller and added LQR analysis and a feedforward. // At Future Power, / I built VR dual-arm teleoperation and the leader–follower teaching, / validated through the ROS2-CAN chain. // And Kaihong is still ongoing. // So for me, the key point is the depth of what I could finish in each period.”

**中文**：未来动力的实习大约三个月，AIRS 大约六个月，所以确实不长。我利用这段时间把一块聚焦的工作做到机器人上。在 AIRS，我部署了级联 PID，并加入 LQR 分析和前馈。在未来动力，我做了 VR 双臂遥操作和主从示教，并通过 ROS2-CAN 链验证。深开鸿还在进行。所以对我来说，关键是每段时间里我能完成的深度。

> 推算：Sep 2025→Mar 2026 为 6 个月（跨 7 个自然月）；Mar→May 2026 约 3 个月。口述时用 “about”。

**不要说**：“I did everything in the company.”

### 3.8 项目太多太散

**问法**：*You have many different projects. What's your focus?*

**原则**：用一条线串联：**让算法在真实硬件上可靠地运行**。再说 “如果让我选最深入的”。

**版本 A**

> “The thread is the same: / making algorithms reliable on real hardware. / The robots differ, but the loop is the same — / state, model, control, and safety.”

**中文**：主线是一致的：让算法在真实硬件上可靠运行。机器人不同，但回路相同——状态、模型、控制和安全。

**版本 B**

> “They look different, but I see one progression. // I began with embedded closed-loop control on RoboMaster, / moved to model-based balance on the ballbot and the wheel-legged robot, / then to navigation and manipulation, / and now to platform software and safe execution at Kaihong. // The common question is: / how do you make an algorithm survive real timing, noise and limits? // If you ask for my deepest work, it's the balance control at AIRS and on the wheel-legged robot, / where I did both the controller and the analysis.”

**中文**：它们看起来不同，但我看到的是一条递进线。我从 RoboMaster 上的嵌入式闭环控制开始，到球形机器人与轮腿机器人的基于模型的平衡，再到导航与操作，现在是深开鸿的平台软件与安全执行。共同的问题是：如何让算法经受真实的时序、噪声和限制？若问我最深的工作，是 AIRS 与轮腿机器人上的平衡控制，在那里我既做了控制器又做了分析。

### 3.9 团队项目里你的贡献是什么

**问法**：*RoboMaster is a team achievement. What exactly did you do?*

**原则**：先承认团队，再明确自己的三项：云台、发射、底盘控制环（CV）。

**版本 A**

> “It was a team result. / My part was the control loops of the hero robot: / the gimbal, the launcher and the chassis.”

**中文**：这是团队成绩。我的部分是英雄机器人的控制环：云台、发射机构和底盘。

**版本 B**

> “Yes, the third prize belongs to the whole team. // I was responsible for the embedded control loops on the hero robot. // On the gimbal, / a cascaded PID for pitch and yaw using IMU and motor feedback. // On the launcher, / friction-wheel speed loops and a feeder position–velocity loop, / which I iterated from PID to variable-gain PID to sliding-mode control. // On the chassis, / velocity allocation to four Mecanum wheels with power-aware scaling. // Vision, mechanics and strategy were handled by teammates.”

**中文**：是的，三等奖属于整个团队。我负责英雄机器人的嵌入式控制环。云台方面，用 IMU 和电机反馈做俯仰/偏航的级联 PID。发射机构方面，摩擦轮速度环和拨弹位置—速度环，并从 PID 迭代到变增益 PID 再到滑模控制。底盘方面，把速度分配到四个麦克纳姆轮并按功率缩放。视觉、机械和策略由队友负责。

> “Vision, mechanics and strategy were handled by teammates” 属于对团队分工的合理表述（CV 提到 “vision targets” 作为输入）；具体化的说法：视觉组负责识别和给出目标角度，机械组负责结构和装配，指挥与策略由队长和操作手负责；我的部分是把视觉给出的目标角度变成云台的连续姿态指令，并保证发射与底盘回路稳定。

### 3.10 为什么不直接工作

**问法**：*You already have good experience. Why not just work?*

**原则**：不要说“工作没意思”或“工作找不到”。强调：缺口是**系统化的理论**，在工作中难补；硕士后回到产业。

**版本 A**

> “Because the gaps I want to fill are foundations — / optimisation, learning and manipulation. / It's hard to study those systematically while delivering product work. / A master's lets me do that, and then I'll go back to industry.”

**中文**：因为我想补的是基础——最优化、学习和操作。在做产品工作的同时很难系统学习。硕士让我做到这一点，然后我会回到产业。

**版本 B**

> “I've already worked as an intern for three organisations, / and I enjoyed it. // That's how I found what I'm missing. // In a company, / the focus is on what works within the deadline, / so I used methods like cascaded PID and LQR, / but I couldn't always explore why or what's better. // I want a period where I can study the theory properly / and try ideas on a real robot with supervision. // My plan is still to work in industry afterwards — / in the Greater Bay Area — / but as a stronger algorithm engineer.”

**中文**：我已经在三个机构实习过，并且喜欢。正因如此我发现了自己缺什么。在公司里，重点是在期限内能用的方案，所以我用级联 PID 和 LQR，但不总能探索为什么或有什么更好。我想要一段能系统学习理论、并能在监督下在真机上尝试想法的时间。我的计划仍然是之后进入产业——在大湾区——但成为更强的算法工程师。

> 与 [核心叙事线](./03_核心叙事线_为什么读研_为什么这个方向.md) Q2 保持一致。

**不要说**：“I couldn't find a job.” / “Everyone does a master's.”

### 3.11 Kaihong 仍在职，为什么申请读研

**问法**：*You're currently working at Kaihong. Why are you applying for a master's? Will you leave? Will your employer support you?*

**原则**：这是**实习**，不是长期雇佣；坦诚说明它是你发现缺口的地方。**不要承诺你不能保证的**（比如“公司支持”“毕业回公司”）。入学时间安排这样说：实习计划在入学前结束，并完成工作交接；在此之前不承诺任何未确认的事。

**版本 A**

> “It's an internship that began in June 2026. / It's actually what made me want to study further: / it showed me the foundations I still need.”

**中文**：这是一份 2026 年 6 月开始的实习。正是它让我想继续深造：它让我看到自己仍需要的基础。

**版本 B**

> “My role at Kaihong is an internship, / which started in June 2026 and is still ongoing. // I work on device abstraction, state management, / and the safe-execution chain of the platform. // That work made the gap clear to me: / I can build the platform pieces, / but I need stronger foundations in AI and in designing safeguards around learned components. // That's why I'm applying. // My plan is to complete my responsibilities properly before the programme starts. I will hand over my work to the team before then.”

**中文**：我在深开鸿的角色是实习，2026 年 6 月开始，仍在进行。我负责设备抽象、状态管理和平台的安全执行链。这份工作让我看清了缺口：我能构建平台组件，但需要在 AI 以及围绕学习部件设计保障上有更强基础。这就是我申请的原因。我的计划是在项目开始前妥善完成我的职责。

**版本 C（被问“公司是否支持/你会回去吗”）**

> “I haven't made any commitment about that. // My long-term goal is to work in robotics in the Greater Bay Area, / and I'm open to different options after the master's. // For now, / I'm focused on doing my current internship well.”

**中文**：我对此没有做任何承诺。我的长期目标是在大湾区做机器人工作，硕士后对不同选择持开放态度。目前我专注于做好现在的实习。

**不要说**：贬低雇主；承诺“毕业一定回公司”；透露薪资、合同。

### 3.12 保密边界

**问法**：*Can you tell me the details of the algorithm / the parameters / the code of the platform at Kaihong?* / *Can you share your controller gains?*

**原则**：专业人士的保密意识是**加分项**。说清三层：**我可以讲什么**（职责、架构思路、通用原理）、**我不能讲什么**（专有代码、客户信息、具体参数）、**我可以怎么继续帮您理解**（用通用例子）。

**版本 A**

> “I'm happy to explain the design ideas and my role, / but I can't share proprietary code, parameters or customer information. / I can show you the general principle with a simple example instead.”

**中文**：我很乐意解释设计思路和我的角色，但不能分享专有代码、参数或客户信息。我可以改用一个简单例子展示一般原理。

**版本 B**

> “I'm careful about confidentiality with my employer's work. // What I can say is the structure and my part: / a unified capability model for sensors, actuators and controllers, / consistent state with timestamps and frames, / and a chain where a task proposal is checked before execution. // I can't share the code, specific parameters or product details. // But if you're interested in how I'd design something like a policy check, / I can walk through it in general terms.”

**中文**：对雇主的工作我注意保密。我能说的是结构与我的部分：面向传感器、执行器和控制器的统一能力模型，带时间戳和坐标系的一致状态，以及任务提议在执行前经过检查的链路。代码、具体参数或产品细节不能分享。但如果您对我如何设计策略检查这类东西感兴趣，我可以用一般性的方式讲一遍。

**版本 C（被追问到边界时）**

> “I understand why you'd like more detail, / but I think it's the right thing to protect the company's information. // I hope you see that as part of how I work professionally.”

**中文**：我理解您希望了解更多细节，但我认为保护公司信息是正确的做法。我希望您将此视为我职业素养的一部分。

> **提示**：对 AIRS 与 Future Power 的内部细节同样适用。对公开课程代码、你自己的个人项目（P4）和 RoboMaster，通常没有同样的保密约束；但如果有协议，同样遵守。通常的范围是：不透露公司内部的接口名、协议细节、客户和未公开的产品计划；可以讲设计原则、自己的思路和公开技术。AIRS 与 Future Power 同理，不展示内部代码和数据。

### 3.13 为什么从 CS 走向机器人（专业背景问题）

**问法**：*Your major is Computer Science, but you are applying for robotics. Why? Do you have enough mechanical or electrical background?* 以及反过来：*You are doing robotics, why apply for CS/AI?*

**原则**：CS 是机器人的**关键层**，不是弯路。承认机械/电气的缺口（尤其对 PolyU 这类机械系项目），并说明你已有的控制/嵌入式补偿。

**版本 A（申请机器人时）**

> “I see robotics as a software and algorithm problem on top of hardware. / My CS background gave me the programming and algorithms, / and I added control theory courses and a lot of embedded and ROS work.”

**中文**：我把机器人看作建立在硬件之上的软件和算法问题。CS 背景给了我编程和算法，我又补修了控制理论，并做了大量嵌入式和 ROS 工作。

**版本 B（申请机器人时，被问机械/电气缺口）**

> “That's a fair concern. // My coursework is in computer science, / but my projects have forced me to learn the hardware side: / motors, CAN buses, IMUs, torque limits. // I've also taken Principles of Automatic Control and Modern Control Theory. // What I haven't had is structured training in mechanisms and sensing, / and that's something a robotics programme can give me. // I don't think my CS background is a weakness, / because many of the hardest robot problems turn out to be software — / state, timing and interfaces.”

**中文**：这是个合理的担心。我的课程是计算机科学，但项目迫使我学习硬件方面：电机、CAN 总线、IMU、力矩限制。我也修了自动控制原理和现代控制理论。我缺的是机构与传感的结构化训练，这正是机器人项目能给我的。我不认为 CS 背景是弱点，因为许多最难的机器人问题其实是软件：状态、时序和接口。

> 呼应 PolyU PS：“would give me the structured training in mechanisms and sensing that I lack”。

**版本 C（申请 CS/AI 时，被问“你的经历是机器人，为什么不读机器人”）**

> “I did consider a robotics programme. // But what I keep finding is that the first serious problems appear in the software and data layers — / timestamps, interfaces, safe execution — / and, for AI, in understanding and evaluating models. // I want to build those foundations deliberately, / and apply them to robotics. // So I'm not leaving robotics; / I'm strengthening the part I rely on most.”

**中文**：我考虑过机器人项目。但我不断发现最先出现的严重问题在软件和数据层——时间戳、接口、安全执行——对 AI 来说则是理解和评估模型。我想有意地建立这些基础并应用于机器人。所以我不是离开机器人，而是在加强我最依赖的那一部分。

### 3.14 数学基础够吗

**问法**：*Do you think your math is strong enough for this programme?*

**原则**：有课程 + 有应用 + 有复习计划。**不要说“很强”**。

**版本 A**

> “I believe it's solid for starting: / linear algebra, probability and statistics, / and control theory, which uses a lot of linear algebra. / I'll keep reviewing as I go.”

**中文**：我相信对于起步是扎实的：线性代数、概率统计，以及大量使用线性代数的控制理论。我会边学边复习。

**版本 B**

> “I have the foundation from my courses — / linear algebra, probability and statistics, and two control courses — / and I've used it in practice: / state-space models, LQR, Kalman-type filtering and optimisation in inverse kinematics and MPC. // What I need is more depth in optimisation and probabilistic methods. // Before the programme starts, / I plan to review convex optimisation basics and probability, / so I can follow the courses from the first week.”

**中文**：我有课程提供的基础——线性代数、概率统计和两门控制课——并在实践中用过：状态空间模型、LQR、卡尔曼类滤波，以及逆运动学和 MPC 里的优化。我需要的是在最优化和概率方法上更深。在项目开始前，我计划复习凸优化基础和概率，以便第一周就能跟上课程。

> 如果面试官追问具体数学题，请阅读 [线性代数](../../02_基础知识/01_数学基础/01_线性代数.md)、[最优化与二次规划](../../02_基础知识/01_数学基础/04_最优化与二次规划.md) 等。

### 3.15 “你还申请了哪些学校？这里是第一志愿吗？”

**问法**：*Which other universities did you apply to?* / *Is our programme your first choice?*

**原则**：这是**不可答好、只可答稳**的题。原则：不泄露具体名单（尤其不要列出排名高低），不说“备选”，不撒谎。可以说“我申请了几个相关项目”，并强调**这个项目的匹配点**。

**版本 A**

> “I've applied to a few programmes in this region that match my goals. / This one is a very good fit because [SPECIFIC REASON]. / If I'm admitted, I'd be very happy to join.”

**中文**：我申请了该区域几个符合我目标的项目。这个项目非常匹配，因为【具体理由】。如果被录取，我会很乐意加入。

**版本 B（被追问是否第一志愿）**

> “I don't want to rank programmes in a way that isn't fair to any of them. // What I can say honestly is that the features of this programme — [FEATURE 1] and [FEATURE 2] — / are exactly what I'm looking for, / and I've prepared carefully for this interview.”

**中文**：我不想以对任何项目都不公平的方式排序。我能诚实地说，这个项目的特点——【特点1】和【特点2】——正是我在寻找的，我也为这场面试做了认真准备。

**不要说**：“This is my safety school.” / “I have an offer from XX.”（除非真有，且被直接问到；即使有也不必主动）

### 3.16 个人项目是不是只是 demo（针对 P4）

**问法**：*Your smart-gardening project sounds like a demo. What's the real engineering depth?*

**原则**：承认规模；强调**闭环与边界设计**（置信度、时间戳、规则快速通道、状态机、手动优先）；不夸大成产品。

**版本 A**

> “It's a personal project and small in scale, / but I built the whole loop myself: / vision, decision and device-side control. / What I care about is the boundaries between them.”

**中文**：这是个规模不大的个人项目，但整条闭环是我自己搭的：视觉、决策和设备端控制。我关心的是它们之间的边界。

**版本 B**

> “Yes, it's a small personal project, not a product. // But it forced me to make engineering decisions: / the vision output carries a confidence and a timestamp; / the agent decision chain has a rule-based fast path for extreme states; / and on the Hi3861, / the pump state machine has separate start and stop thresholds / and a manual-priority override. // So even if the model or the agent is wrong, / the local loop stays stable. // Those design choices are what I took into my later robot work.”

**中文**：是的，这是个小型个人项目，不是产品。但它迫使我做工程决策：视觉输出带置信度和时间戳；Agent 决策链对极端状态有规则快速通道；在 Hi3861 上，水泵状态机有独立的启停阈值和手动优先覆盖。所以即使模型或 Agent 错了，本地回路也保持稳定。这些设计选择被我带到后来的机器人工作中。

## 4. 红线清单：绝对不能说的话

| 类别 | 不要说 | 原因 |
|---|---|---|
| 编造 | 任何 CV 里没有的数字（精度、帧率、延迟、成功率、误差） | 一追问就露馅，直接伤诚信分 |
| 夸大 | “I led…”“I invented…”“state-of-the-art” | CV 无依据 |
| 混淆 | “我用 LQR 控制了球形机器人” | CV 写 P1 的 LQR 是分析工具；P7 才是部署的增益调度 LQR |
| 混淆 | 把“推荐/命令请求”说成“已确认的物理执行” | P4/P6 的链路区别 |
| 保密 | 公司代码、参数、客户名、产品细节 | 职业素养 |
| 贬低 | 贬低母校、雇主、其他项目、同学 | 显得不成熟 |
| 绝对化 | “Definitely”“never”“always” | 过于绝对 |
| 功利 | “For immigration/for the label/to find a job easier” | 动机不当 |
| 纠结 | 无休止自我批评 | 影响自信 |
| 他校 | 主动列出他校名单和 offer | 无益 |

## 5. 练习方式与自检

### 5.1 练习

1. 每个弱项题**各自录音**：A 版（20 秒）、B 版（45 秒）。
2. 让朋友用最“刁”的语气问，并追问一次（“Really? Can you give an example?”）。
3. 练习“说完就停”：回答完，不要补充别的弱点。

### 5.2 自检表

| 检查项 | 是 / 否 |
|---|---|
| 第一句是否直接承认？ | |
| 是否给出了一个具体证据？ | |
| 是否有可信的补救计划？ | |
| 是否回到了目标？ | |
| 是否在 45 秒内？ | |
| 是否有任何未经 CV 支持的数字？ | |
| 是否贬低了任何人或机构？ | |
| 所有细节是否已对照你自己的真实情况核对？ | |

## 本章要点速记

1. 四步公式：承认 → 证据 → 计划 → 回到目标；“三不”：不防御、不夸大、不贬低。
2. 没有论文：直说；用“严谨验证习惯”作证据；愿意学研究方法。
3. ML 偏实践：直说；部署经验 + 数学底子 + 学习计划。
4. 学校与排名：不防御；用 6 of 156、87.63、竞赛与实习。
5. 英语 6.5：达标，用技术话题的熟悉度和主动澄清来证明。
6. 实习较短：诚实说时长，讲交付与上机验证。
7. 为什么不直接工作：缺口是需要系统学习的基础。
8. Kaihong 仍在职：它是实习，也是发现缺口的地方；不做未确认的承诺。
9. 保密边界：讲职责和原理，不讲专有细节；这是职业素养。
10. CS 转机器人：软件是机器人的关键层；承认机构与传感缺口。

## 自测题

1. 用四步公式回答“你没有论文”。（要点：承认没有；LQR 分析/开关对比验证；想学研究方法；回到硕士目标）
2. 面试官问你 GPA 的 4.0 制换算，你没有官方换算，怎么说？（要点：用 87.63/100 与 6 of 156；不自行换算；可提供成绩单）
3. 哪两件事在 Kaihong 的问题里不能承诺？（要点：公司是否支持；毕业是否回公司）
4. “我用 LQR 控制了球形机器人”错在哪里？（要点：CV 的 P1 里 LQR 是分析；部署的是级联 PID）
5. 被问“这是不是第一志愿”，哪些话不能说？（要点：备选/保底；他校 offer；贬低他校）
