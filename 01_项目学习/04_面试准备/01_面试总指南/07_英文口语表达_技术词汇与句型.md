## 1. 使用说明：发音提示怎么读

### 1.1 发音提示的格式

本章用**简化拼读**，不用国际音标，以便你直接读出：

- **大写字母**表示重音音节：`feed-BAK` 重音在第二个音节；
- 连字符 `-` 分隔音节；
- `uh` 表示弱化元音（schwa，像 “about” 里的 a）；
- `ee` 如 “see”，`ay` 如 “day”，`eye/y` 如 “my”，`oh` 如 “go”，`oo` 如 “food”，`ur` 如 “her”。
- 缩写（PID、LQR、IMU）用字母逐个读：`P-I-D`。

> **提示**：简化拼读只是帮助你找到重音和节奏。**最终请用在线词典或语音工具核对**；以词典为准。

### 1.2 为什么重音最重要

英语是“重音计时”语言。重音错了，听者即使听到所有音素也可能不懂。例如 `kuh-LIB-ruh-shun`（calibration）和 `kal-ih-BRAY-shun` 的区别——后者是正确的。中国学习者常常把重音放在词尾或每个音节同样重读。

**练习方法**：把一个长词拆成三步读——先读重音音节（`BRAY`），再读前面的弱音节（`kal-ih`），最后读后面的（`shun`）。

## 2. 技术口述通用句型

> 每个句型都配有中文。**只记 1–2 个你最顺口的，不要全背。**

### 2.1 开场与定位（先说结论）

| 用途 | 英文 | 中文 |
|---|---|---|
| 一句话定位 | “In short, this project is about…” | 简而言之，这个项目是关于…… |
| 先给结论 | “The main idea is…” | 主要思路是…… |
| 说明目标 | “The goal was to…, so that…” | 目标是……，以便…… |
| 说明背景 | “The background is that…” | 背景是…… |
| 说明我的角色 | “My part was…” / “I was responsible for…” | 我的部分是…… / 我负责…… |
| 区分团队 | “My teammate handled…, and I handled…” | 我的队友负责……，我负责…… |
| 设定框架 | “I'll explain it in three steps.” | 我分三步来讲。 |

### 2.2 过渡与结构

| 用途 | 英文 | 中文 |
|---|---|---|
| 顺序 | “First…, then…, finally…” | 首先……然后……最后…… |
| 补充 | “On top of that, …” / “In addition, …” | 此外…… |
| 转折 | “However, …” / “But the problem was…” | 然而…… / 但问题是…… |
| 因果 | “Because of that, …” / “As a result, …” | 因此…… / 结果…… |
| 对比 | “Compared with…, this approach…” | 与……相比，这种方法…… |
| 转到下一点 | “Let me move on to…” | 我接着讲…… |
| 回到主题 | “Coming back to your question, …” | 回到您的问题…… |
| 小结 | “To sum up, …” | 总结一下…… |
| 举例 | “For example, …” / “A concrete example is…” | 例如…… / 一个具体例子是…… |

### 2.3 解释原理

| 用途 | 英文 | 中文 |
|---|---|---|
| 直觉 | “The intuition is that…” | 直觉上是…… |

| 说明直观效果 | “Increasing this weight makes the controller care more about…” | 增大这个权重，控制器会更在意…… |

| 用途 | 英文 | 中文 |
|---|---|---|

### 2.7 澄清问题

|---|---|---|
| 请重复 | “Could you repeat the question, please?” | 请重复一下问题好吗？ |

|---|---|---|

### 2.9 画图与指示（配合白板/纸）

| 用途 | 英文 | 中文 |
|---|---|---|

### 2.10 结束与确认

| 用途 | 英文 | 中文 |
|---|---|---|
| 询问是否清楚 | “Does that make sense?” | 这样说清楚吗？ |
| 邀请追问 | “I can go into more detail on any part.” | 任何部分我都可以展开。 |

## 5. 同义替换与“简单而准确”原则

### 5.1 原则

> **在雅思 6.5 的水平上，最稳的是用“简单而准确”的词，而不是“高级但不稳”的词。**
> 如果一个高级词你不能稳定发音、不能确定用法，宁可用简单的。

### 5.2 常用动词替换（口语）

| 想说 | 简单 | 稍正式 | 注意 |
|---|---|---|---|
| 做 | make, build | develop, implement | implement 用于“实现算法/功能” |
| 用 | use | apply, employ | apply 用于“应用方法” |
| 检查 | check | verify, validate | verify = 核实正确；validate = 在真实条件下确认有效 |
| 解决 | fix, solve | resolve, address | 工程问题常用 fix/solve |
| 改进 | improve | refine, enhance | refine 常用于调参 |
| 找到原因 | find the cause | diagnose, trace | trace…to… 追溯到 |
| 帮助 | help | support, enable | enable 表示“使……成为可能” |
| 让…稳定 | keep…stable | stabilise | stabilise 是动词 |
| 减少 | reduce | suppress, mitigate | suppress 用于“抑制”（如速度放大） |
| 学习 | learn | study, pick up | pick up 偏口语 |
| 负责 | be responsible for | own, handle | own 表示全权负责 |

### 6.1 单位

### 6.2 公式口述（示例，教学用）

| 公式 | 读法 |
|---|---|
| $u = -Kx$ | “u equals minus K times x”：状态反馈 |
| $e = r - y$ | “e equals r minus y”：误差等于参考减输出 |
| $J = \int (x^T Q x + u^T R u)\,dt$ | “J is the integral of x transpose Q x plus u transpose R u”：LQR 代价 |
| $\dot{x} = Ax + Bu$ | “x dot equals A x plus B u”：状态方程 |
| $\dot{q} = J^{+}\dot{x}$ | “q dot equals J pseudo-inverse times x dot”：用雅可比伪逆求关节速度 |

> 口述时可以**不读符号**，而是读意义：*“The cost has two parts: how far the state is from zero, and how much control effort we use.”*

### 6.3 说“约等于 / 量级”的表达

| 用途 | 英文 |
|---|---|
| 大约 | about, roughly, around |
| 数量级 | on the order of… |
| 不到 / 超过 | less than / more than |
| 示例数 | “Just as an illustration, suppose…” |

## 7. 练习方法

1. **词汇卡片**：从第 3 节挑出你**最不熟的 40 个**词，做成正反面卡片（正面英文，背面中文 + 发音 + 例句）。每天复习 10 个。
2. **句型替换练习**：取一个句型，换 5 个不同内容各说一遍。例如 “The trade-off is… ” 换成：稳定性与控制量；实时性与精度；精度与算力……
3. **“三句话讲一个词”**：对任何一个词，用三句话解释：它是什么 → 为什么需要 → 我在哪里用过。例：*“A Jacobian maps joint velocities to end-effector velocities. We need it for inverse kinematics. I used it in the VR teleoperation to compute joint motion for a target.”*
4. **影子跟读**：找一段技术英文讲解（公开课或会议的演讲，注意是正规来源），逐句跟读并录音比较。
5. **每日 5 分钟自言自语**：用第 2 节的句型描述今天做的事。

## 本章要点速记

1. 简化拼读用大写表示重音；**重音比单个音素更重要**。
2. 技术口述的骨架：结论先行 → 分步 → 举例 → 局限 → 邀请追问。
3. 承认不确定要有模板：“I'm not 100% sure, but my understanding is…”。
4. 常见重音陷阱：calibration、optimisation、kinematics、Jacobian、singularity、covariance、odometry、hysteresis、quaternion、heuristic。
5. 词尾辅音与 -ed/-s 要读出来；13/30、15/50 要区分重音。
6. 简单而准确胜过高级而不稳。
7. 公式可以读“意义”而不是符号。
8. 对任何一个词，能用三句话讲：是什么 → 为什么需要 → 我在哪里用。
