#### Q7. A detector reports confidence 0.9. Can you trust it?

**中文：** 检测器给出 0.9 的置信度，可以信任吗？

> **参考回答（English）**
>
> Not automatically. A softmax or objectness score is not necessarily a calibrated probability: a model can be overconfident, especially on inputs that differ from the training data. Calibration means that among predictions with confidence 0.9, about 90 percent are correct, which can be checked with a reliability diagram. For a decision, I also need context: when the image was taken, whether the object is relevant, and what happens if the detection is wrong. That is why, in my gardening project, I attached a confidence and a timestamp to each observation, and did not let a visual prediction alone drive the pump.
>
> **中文译文：** 不一定。softmax 或 objectness 分数不一定是校准过的概率：模型可能过度自信，尤其是输入与训练数据不同时。校准的含义是：在置信度为 0.9 的预测中，大约 90% 是对的，可以用可靠性图检验。做决策时还需要上下文：图像是什么时候拍的、目标是否相关、检测错了会怎样。所以在园艺项目里，我给每个观测附上置信度和时间戳，也没有让视觉预测单独驱动水泵。

#### Q9. How would you decide whether a model is good enough to deploy on a robot?

**中文：** 你如何判断一个模型是否足够好、可以部署到机器人上？

> **参考回答（English）**
>
> I start with the task and the cost of each type of error. Then I compare against a clear baseline on representative data, including conditions where failure is likely, such as different lighting. For a robot I also measure latency, memory and power, and look at how errors propagate downstream, for example how a missed detection changes navigation. A high average score is not enough if the model fails in an important condition. Finally, I decide where it may be used and what extra checks are needed, such as a fallback rule.
>
> **中文译文：** 我先明确任务和各类错误的代价。然后在有代表性的数据上与清晰的基线比较，包括容易失败的条件（如不同光照）。对机器人而言，还要测延迟、内存和功耗，并观察错误如何向下游传播，比如漏检如何影响导航。平均分高并不够，如果模型在重要条件下失效。最后我决定它可以用在哪里、还需要哪些额外检查（如回退规则）。

For extreme states, for example very dry soil, a rule-based fast path acts directly without waiting for the agent. #### Q12. Describe the irrigation state machine on the Hi3861.

**中文：** 讲讲 Hi3861 上的灌溉状态机。

> **参考回答（English）**
>
> It is a soil-moisture-driven pump state machine with independent start and stop thresholds, plus a manual-priority override. Independent thresholds create hysteresis, so the pump does not chatter around one single threshold. Manual priority means a user command wins over automatic logic. The result is a stable local closed loop that still works if the decision layer is uncertain. The two thresholds are kept apart by a margin so that sensor noise does not toggle the pump. I will not claim extra protections, such as a maximum run time, unless I can confirm them.
>
> **中文译文：** 这是一个由土壤湿度驱动的水泵状态机，启动和停止阈值相互独立，并带有手动优先覆盖。两个独立阈值形成滞回，避免水泵在单一阈值附近反复开关。手动优先意味着用户指令高于自动逻辑。结果是一个稳定的本地闭环，即使决策层不确定也能工作。 两个阈值之间留有间隔，传感器噪声就不会让水泵来回切换。像最长运行时间这类额外保护，没有把握确认我就不说有。


#### Q13. Explain the action-proposal, policy-check, execution and state-feedback chain.

**中文：** 讲讲“动作提议、策略检查、执行、状态反馈”这条链。

> **参考回答（English）**
>
> A high-level task plan, for example from a planner or an AI model, is never sent straight to the robot. First it becomes an action proposal. Then a policy check decides whether the action is allowed in the current state. Only if it passes does it go to execution. Finally, the state feedback tells the system what actually happened, which closes the loop. The idea is that an AI decision and a physical action are different things, and the checks sit between them. Typical checks in such a chain cover the speed limit, the allowed area, the device state and the permission of the requester. If a proposal fails, it is rejected, the reason is reported back through state feedback, and nothing moves.
>
> **中文译文：** 高层任务计划（例如来自规划器或 AI 模型）绝不会直接发给机器人。它先成为一个动作提议；然后由策略检查判断在当前状态下是否允许；通过后才进入执行；最后状态反馈告诉系统实际发生了什么，闭合回路。思想是：AI 的决策和物理动作是两回事，检查就放在它们之间。 这类链条里典型的检查包括速度限制、允许的区域、设备状态和请求方的权限。提议未通过时会被拒绝，原因通过状态反馈返回，执行器不会动。

I modelled the ballbot as a linearised four-state inverted pendulum, with position, velocity, tilt and tilt rate, and used LQR to study how the state weights trade stability against control effort. To be clear, the deployed controller was the PID cascade; the LQR analysis was my model reference. It helped me interpret the gains I had deployed, spot abnormal states, and locate actuator saturation instead of just turning gains up and down. The way I used it: when the output sat at its limit, the LQR weights showed that the tuning was asking for more control effort than the actuators could give, so I looked at saturation instead of raising the gains again. >
> **中文译文：** 因为手工调参已经解释不了机器人上看到的现象。我把球形机器人建成线性化的四状态倒立摆（位置、速度、倾角、倾角速度），用 LQR 研究各状态权重如何在稳定性和控制量之间权衡。需要说清楚：实际部署的是 PID 级联，LQR 是我的模型参照。它帮助我解释已部署的增益、发现异常状态、定位执行器饱和，而不是盲目地调大调小增益。 我的用法是：当输出长时间贴着限幅时，LQR 权重的分析说明当前调参要求的控制量超过了执行器能给的，于是我去查饱和，而不是再加大增益。具体数值我不报。

### D. 机器学习与 AI 数学基础

#### Q16. What is overfitting, and how do you detect and reduce it?

**中文：** 什么是过拟合？如何发现并缓解？

> **参考回答（English）**
>
> Overfitting means the model fits the noise and quirks of the training data, so it does well on training data and badly on new data. I detect it by comparing training error with validation error: when training error keeps falling and validation error starts rising, the model is overfitting. To reduce it, I can use more or more varied data, data augmentation, regularisation such as weight decay or dropout, a simpler model, or early stopping. The related idea is the bias-variance trade-off: a very simple model underfits (high bias), a very flexible one overfits (high variance).
>
> **中文译文：** 过拟合是指模型拟合了训练数据中的噪声和特殊性，所以在训练集上表现好、在新数据上表现差。我通过比较训练误差和验证误差来发现它：训练误差持续下降而验证误差开始上升，就是过拟合。缓解的办法包括更多或更多样的数据、数据增强、权重衰减或 dropout 等正则化、更简单的模型、提前停止。相关概念是偏差-方差权衡：过于简单的模型欠拟合（高偏差），过于灵活的模型过拟合（高方差）。


#### Q17. How do you evaluate an object detector? Explain precision, recall, IoU and mAP.

**中文：** 如何评价目标检测器？请解释 precision、recall、IoU 和 mAP。

> **参考回答（English）**
>
> IoU, intersection over union, measures how much a predicted box overlaps a ground-truth box. A prediction counts as a true positive if its IoU is above a threshold and the class is right. Precision is the fraction of predictions that are correct; recall is the fraction of real objects that were found. Changing the confidence threshold trades one against the other, which gives a precision-recall curve. Average precision is the area under that curve for one class, and mAP is the mean over classes, sometimes over several IoU thresholds. For a robot, I would also look at latency and at the cost of each error type.
>
> **中文译文：** IoU（交并比）衡量预测框与真值框的重叠程度。如果 IoU 超过阈值且类别正确，预测算作真正例。Precision 是预测中正确的比例；recall 是真实目标中被找到的比例。调整置信度阈值会在两者之间权衡，得到 P-R 曲线。AP 是某一类别该曲线下的面积，mAP 是各类别的平均，有时还对多个 IoU 阈值取平均。对机器人而言，我还会看延迟，以及不同错误类型的代价。


#### Q18. Explain backpropagation in simple terms.

**中文：** 请用简单的话解释反向传播。

> **参考回答（English）**
>
> A neural network is a chain of functions, and training means adjusting parameters to reduce a loss. Backpropagation computes the gradient of the loss with respect to every parameter efficiently by applying the chain rule backwards, layer by layer, reusing the intermediate values from the forward pass. Then an optimiser such as gradient descent or Adam uses those gradients to update the parameters. A known difficulty is vanishing or exploding gradients in deep networks, which is why we use careful initialisation, normalisation, residual connections and suitable activations such as ReLU.
>
> **中文译文：** 神经网络是一串函数的复合，训练就是调整参数以降低损失。反向传播利用链式法则，从后向前逐层高效地计算损失对每个参数的梯度，并复用前向传播中的中间值。然后梯度下降或 Adam 等优化器用这些梯度更新参数。深层网络的已知难点是梯度消失或爆炸，所以要用合适的初始化、归一化、残差连接和 ReLU 等激活函数。


#### Q19. Why is cross-entropy used for classification? Relate it to maximum likelihood.

**中文：** 分类为什么用交叉熵？请与最大似然联系。

> **参考回答（English）**
>
> A classifier with softmax outputs defines a probability p(y | x; theta) for each class. Given a dataset, maximum likelihood chooses theta to maximise the product of probabilities of the observed labels, or equivalently to minimise the negative log-likelihood, which is the cross-entropy between the one-hot label distribution and the predicted distribution. So cross-entropy training is maximum likelihood. A convenient result is that, for softmax with cross-entropy, the gradient with respect to the logits is simply (predicted probability minus one-hot label), which is stable and easy to compute. Mean squared error corresponds to maximum likelihood with Gaussian noise for regression.
>
> **中文译文：** 带 softmax 输出的分类器为每个类别定义概率 p(y | x; θ)。给定数据集，最大似然选择 θ 使观测标签概率的乘积最大，等价于最小化负对数似然，也就是独热标签分布与预测分布之间的交叉熵。所以交叉熵训练就是最大似然。一个方便的结果是：softmax 加交叉熵时，对 logits 的梯度就是「预测概率减独热标签」，稳定且容易计算。均方误差对应于回归中高斯噪声下的最大似然。


#### Q20. Compare SGD, momentum and Adam. How do you choose a learning rate?

**中文：** 比较 SGD、动量和 Adam。如何选学习率？

> **参考回答（English）**
>
> SGD updates parameters along the negative gradient of a mini-batch, which is noisy but cheap. Momentum accumulates a moving average of past gradients, which smooths the noise and speeds progress along consistent directions. Adam also keeps a running estimate of the squared gradient and scales each parameter's step, so it adapts the step size per parameter and is often a good default. The learning rate is the most sensitive setting: too large makes the loss oscillate or diverge, too small makes training slow or stuck. Practical approaches are a short learning-rate range test, warm-up, and decay schedules, with validation loss as the judge.
>
> **中文译文：** SGD 沿小批量梯度的负方向更新参数，噪声大但成本低。动量累积过去梯度的移动平均，既平滑噪声，又在一致方向上加快进展。Adam 还维护梯度平方的滑动估计，并按参数缩放步长，因此对每个参数自适应步长，常是不错的默认选择。学习率是最敏感的设置：太大使损失振荡或发散，太小则训练缓慢或停滞。实用方法有短时学习率范围测试、预热和衰减调度，并以验证损失为准。


#### Q21. Explain PCA and how it relates to the SVD.

**中文：** 解释 PCA 及其与 SVD 的关系。

> **参考回答（English）**
>
> PCA finds orthogonal directions of maximum variance in centred data. Mathematically, these are the eigenvectors of the covariance matrix, ordered by eigenvalue, and the eigenvalue tells how much variance each direction captures. Equivalently, if we take the SVD of the centred data matrix X = U S V^T, the columns of V are the principal directions and S squared over (n - 1) gives the eigenvalues, so PCA can be computed stably via SVD without forming the covariance matrix. We use it for dimensionality reduction, denoising and visualisation, keeping enough components to retain most of the variance.
>
> **中文译文：** PCA 在中心化数据中寻找方差最大的正交方向。数学上，它们是协方差矩阵的特征向量，按特征值排序，特征值表示每个方向捕获的方差。等价地，对中心化数据矩阵 X = U S V^T 做 SVD，V 的列就是主方向，S 的平方除以 (n − 1) 给出特征值，所以可以通过 SVD 稳定地计算 PCA，而不必构造协方差矩阵。它用于降维、去噪和可视化，保留足够多的成分以保留大部分方差。


#### Q22. Compare CNNs and Transformers for vision.

**中文：** 比较一下 CNN 和 Transformer 在视觉上的应用。

> **参考回答（English）**
>
> A CNN has strong built-in assumptions: local connectivity and weight sharing, so it is data-efficient and fast, which is why YOLO-style detectors run well on edge devices. A Vision Transformer splits an image into patches and uses self-attention, which can model long-range relations, but it has fewer built-in assumptions and usually needs more data or pretraining, and attention cost grows with the number of tokens. For an embedded robot with tight latency and power budgets, a CNN detector is usually the practical choice today, while Transformers become attractive when there is large-scale pretraining. I should say that I have deployed a CNN detector, not trained a Transformer.
>
> **中文译文：** CNN 有很强的内置假设：局部连接和权重共享，因此数据效率高、速度快，这也是 YOLO 类检测器在边缘设备上表现好的原因。ViT 把图像切成块并使用自注意力，可以建模长距离关系，但内置假设少，通常需要更多数据或预训练，且注意力的代价随 token 数增长。对延迟和功耗都很紧的嵌入式机器人，目前 CNN 检测器通常是实用选择；有大规模预训练时 Transformer 更有吸引力。需要说明：我部署过 CNN 检测器，没有训练过 Transformer。

## 六、5 道模拟题

第 1 题建议在纸上推导；第 4 题练习「没做过但有计划」的表达。

**模拟题 1.** Derive the gradient of the softmax cross-entropy loss with respect to the logits.

**中文：** 推导 softmax 交叉熵损失对 logits 的梯度。（要点：p − y；简洁步骤；与最大似然联系）

**模拟题 2.** A detector has 0.9 mAP on your test set but fails in a new room. Why, and what would you do?

**中文：** 检测器在测试集上 mAP 为 0.9，但在新房间失效。为什么？你怎么做？（要点：分布偏移、数据覆盖、评估设置、增强、监控）

**模拟题 3.** What is INT8 quantisation, and how would you check that accuracy is preserved?

**中文：** 什么是 INT8 量化？如何检查精度是否保持？（要点：缩放与零点、PTQ/QAT、校准集、对比基线、真实场景）

**模拟题 4.** You have not trained a model yourself. How would you start in the first month here?

**中文：** 你自己没有训练过模型，在这里第一个月怎么开始？（要点：小数据集、基线、可复现、评估；如实）

**模拟题 5.** How should an AI decision be allowed to move an actuator?

**中文：** AI 决策应当如何被允许驱动执行器？（要点：提议→检查→执行→反馈；规则快速通道；日志）
