# 各校面试准备总览

> **一句话定位：** 把你申请的项目按「AI 类 / CS 类 / 机器人类」分开准备：同一套项目事实（以 CV 为准），在不同学校讲不同的侧重。

**本章学完你能：**

- 一眼看出每所学校的面试形式（已知与未知）、侧重和最大风险。
- 知道每所学校该先复习哪些文档，以及哪份面试稿对应哪所学校。
- 按统一流程做通用准备，避免把一所学校的课程名、日期带到另一所。

## 二、通用准备建议

1. **先定一条主线，再分学校换重心。** AI 类讲「AI 决策如何变成物理动作」（P4、P6）；CS 类讲「机器人先暴露的是软件问题」（P6、P5）；机器人类讲「能让控制器跑起来，想知道为什么有效」（P1、P7、P5）。
2. **口径以 CV 为准。** P1 部署的是 PID 级联，LQR 是分析参照；P4 没有训练声明；强化学习、SLAM、GPU 编程均未做过。
3. **数字不编。** 增益、频率、误差等 CV 没有的，用【待你补全】核对，没有就讲方法与现象。
4. **每所学校做三轮练习：** 第一轮读文件第二章并朗读；第二轮不看稿答 25 题；第三轮计时答第六章模拟题并录音。
5. **形式未知时两手准备：** 技术口试 + 基础概念（数学 / CS）。
6. **学校信息只用有依据的。** 没读过教授论文就不要说读过。

## 本章要点速记

1. 九份文件按 AI / CS / 机器人分类，主线不同、事实相同。
2. 面试形式大多未确认，邮件为准。
3. 先核对「待官网确认」，再背回答。
4. 诚实缺口：训练、RL、SLAM、GPU、机构学、安全模型。
