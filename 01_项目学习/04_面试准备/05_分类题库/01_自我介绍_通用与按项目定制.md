# 分类题库 01：自我介绍（通用时长版、11 个项目定制版、三种场景版）与 20 个常见追问

> **一句话定位**：面试的第一分钟决定追问的方向。本文件把自我介绍按"时长""申请项目""面试场景"三个维度做成可直接背诵的英文稿，每一版都配中文翻译和口语节奏提示，并列出自我介绍之后最常被问到的 20 个追问。

**本章学完你能……**

- 在 30 秒、1 分钟、2 分钟、3 分钟四种时限下，给出结构完整、事实准确的英文自我介绍；
- 针对 11 个申请项目，在 1 分钟内说出"这个项目为什么适合我"，而不是一套话通用到底；
- 区分"技术导师""招生官""AI 视频面试限时作答"三种场景，调整内容的重心和语速；
- 对自我介绍里提到的每一个词，都准备好追问时的第二层、第三层回答。

## 1. 本文件怎么用

1. **先背通用 1 分钟版**。这是你的"保底稿"：任何学校、任何场景，听到 "Tell me about yourself" 都能说出来。
2. **面试前一天，换成对应项目的定制版**。定制版只改三处：第一句话的钩子、突出的项目、最后一句的"为什么是这里"。其余事实不变。
3. **知道自己要用哪一种场景版**。收到邀请邮件后，看是真人（技术导师或招生官）还是 AI 录制式视频，再选第 5 节的稿子。
4. **每一版都附中文翻译**。中文只是帮你核对意思，不要在脑子里"先想中文再翻译"。练习时直接看英文，用节奏符号（见下）读出来。
5. **提到什么，就等于邀请追问什么**。第 6 节的 20 个追问，就是你自我介绍里每个词的"第二层"。练习时每说完一版介绍，随机抽 3 个追问回答。
6. **所有事实以 [CV 事实基线](../../06_维护说明/CV事实基线.md) 为准**：排名 6 of 156（top 4%）、均分 87.63、IELTS Academic 6.5；P1 的 LQR 是分析工具而非部署控制器；RoboMaster 三等奖是团队成绩；Kaihong 仍在进行（用现在时）。
7. 带"安全表述"的地方（例如对学校课程的了解）只说有依据的方向，不说没有核对过的课程名。官方信息的核对清单见 [各校面试准备](../02_各校面试准备/README.md)。

> **注意**：各校 2027 轮次的面试形式、课程名单多数尚未公布。本文件的定制版只引用 PS 和官方核对表里有依据的内容；凡写"我了解到"的句子，面试前请到官网再核对一遍。

### 2.2 口语节奏记号

| 记号 | 含义 |
|---|---|
| `/` | 短停顿，换气，约半拍 |
| `//` | 长停顿，一到两拍，段落转换 |
| 大写词 | 重音，稍慢、稍重 |
| `↗` `↘` | 列举未完（升调）、句子结束（降调） |

语速建议：你的目标语速是**每分钟 120–130 个词**（比母语者慢，但清楚）。所以 30 秒版约 65 词，1 分钟版约 135 词，2 分钟版约 260 词，3 分钟版约 390 词。AI 视频面试要留 3–5 秒余量，不要把 60 秒塞满。

## 3. 通用版

### 3.1 30 秒版（约 75 词）

**English**

> Hello, / I'm Yongyi LAI. // I'm a final-year Computer Science student at Shenzhen Technology University, / ranked SIXTH out of 156. ↘ // For two years I've worked on REAL robots: ↗ / balance control, ↗ / navigation, ↗ / and dual-arm teleoperation. ↘ // I'm now an intern on a robot-platform team at Kaihong. // I can make controllers work on hardware. / Now I want the optimisation and learning foundations / to DESIGN algorithms, / not only tune them. ↘ // My goal is to be a robotics algorithm engineer / in the Greater Bay Area.

**中文翻译**：你好，我是赖咏怡，深圳技术大学计算机科学大四学生，专业排名 156 人中第 6。两年来我在真实机器人上做过平衡控制、导航和双臂遥操作。我现在在深开鸿的机器人平台团队实习。我能让控制器在硬件上跑起来，现在想补上最优化和学习的基础，从而能"设计"算法而不只是"调"算法。我的目标是在大湾区做机器人算法工程师。

**节奏提示**

- 三个关键词 balance control / navigation / dual-arm teleoperation：前两个升调，最后一个降调。
- "DESIGN" 和 "not only tune them" 是全稿的转折，放慢，中间停半拍。
- 全程约 30 秒，如果超时，删掉 "I'm now an intern..." 一句，不要加快语速。

## 4. 11 个申请项目的定制版（各 1 分钟）

每个定制版的结构一样：**钩子（1 句）→ 与该项目最匹配的 2–3 个经历 → 我的缺口 → 为什么是这里 → 目标**。长度约 130–145 词。凡是写到课程或方向的地方，只用 PS 和官方核对表里有依据的词；没有核对过的细节不报。

### 4.1 PolyU — MSc in Intelligent Robotics Engineering

**匹配点**：机器人系统工程、机构 + 控制 + 规划 + 具身智能；PS 主线是"三台真实机器人，想系统理解为什么有效"，并写了 dissertation 路线。重点 P1、P7、P5。详见 [港理工面试准备](../02_各校面试准备/03_港理工_智能机器人工程.md)。

**English**

> Hello, / I'm Yongyi LAI, / a final-year Computer Science student at Shenzhen Technology University, / ranked SIXTH out of 156. // Over two years I've worked on three robots / that had to be validated on real hardware: / a RoboMaster hero robot, / a ballbot with two arms, / and a wheel-legged robot. // On the ballbot, / I deployed a cascaded PID controller, / then used an inverted-pendulum model and LQR / to understand the gains and the saturation. // I also built a navigation chain for a car-like robot, / up to MPC tracking. // I can implement a controller and make it run. / But I want to understand more rigorously WHY it works, / and how to design it systematically. // That's why I'm interested in advanced control, / motion planning / and robotic mechanisms, / which I've only met through projects. // I'd like to do a dissertation on balance or navigation control. // After the degree, / I want to be a robotics algorithm engineer / in the Greater Bay Area.

> Hello, / I'm Yongyi LAI, / a final-year Computer Science student at Shenzhen Technology University. // I've worked on a ballbot, / a wheel-legged robot, / a car-like navigation vehicle / and a dual-arm teleoperation system. // On each one, / perception, planning and control / were separate modules, / and I spent most of my time / making them work together on real hardware. // For example, / on the ballbot, / the arms moved the centre of mass, / so I added a feedforward from the arm joints / to the balance controller. // I'd like to study how perception, planning, control and learning / can be designed as ONE embodied system, / and how to keep such algorithms reliable / outside simulation. // I haven't trained a policy on a robot yet, / and that's what I want to learn. // My goal is to work on mobile, legged / and humanoid platforms / as a robotics algorithm engineer / in the Greater Bay Area.

**中文翻译**：你好，我是赖咏怡，深圳技术大学计算机科学大四学生。我做过球形机器人、轮腿机器人、车式导航车和双臂遥操作系统。在每一个上，感知、规划和控制都是独立模块，我大部分时间在让它们在真机上协同工作。比如在球形机器人上，手臂会移动质心，所以我把来自手臂关节的前馈加到平衡控制器里。我想学习感知、规划、控制和学习如何被设计成一个具身系统，以及如何让这样的算法在仿真之外保持可靠。我还没有在机器人上训练过策略，这正是我想学的。我的目标是作为机器人算法工程师，在大湾区做移动、足式和人形平台。

**节奏提示**："ONE embodied system" 的 ONE 重读。"I haven't trained a policy on a robot yet" 语气坦然，说完停半拍，让面试官自然接下去问。

## 5. 三种场景版

### 5.1 场景 A：技术导师（教授或研究员，想判断你能不能做研究和项目）

**这类面试官关心**：你真的懂不懂、边界在哪、能不能和他讨论。介绍里要放"一个具体技术判断"，让他有东西可追问，但这个判断必须是你能守住的。

**时长**：约 90 秒、约 195 词。

**English**

> Good morning, Professor. // I'm Yongyi LAI, / a final-year Computer Science student at Shenzhen Technology University. // Let me describe the work I know best. // At AIRS, / I was responsible for the balance control of a ballbot / with a dual-arm upper body. // I deployed a cascaded PID controller: / a position outer loop gave BOUNDED attitude references / to an attitude inner loop, / and the outputs were allocated to three wheels. // Later, / tuning alone could not explain what I saw on the robot. // So I derived a four-state inverted-pendulum model, / linearised it, / and used LQR as an ANALYSIS tool, / not as the deployed controller. // It showed me how the weights on position, velocity, tilt and tilt rate / trade stability against control effort, / and it helped me find actuator saturation. // I also estimated the centre-of-mass offset from the arm joints, / and checked the feedforward by switching it on and off / under the same arm trajectories. // In a wheel-legged project, / I used gain-scheduled LQR and virtual model control. // My limit is clear: / my models are linear and per-robot, / and my gains were tuned by hand. // I'd like to learn the general theory, / so I can design these controllers / rather than rediscover them each time. // Thank you.

**中文翻译**：早上好，教授。我是赖咏怡，深圳技术大学计算机科学大四学生。让我讲我最熟悉的工作。在 AIRS，我负责带双臂上身的球形机器人的平衡控制。我部署了级联 PID：位置外环给姿态内环提供有界的姿态参考，输出分配到三个轮子。后来，单靠调参已经无法解释我在机器人上看到的现象，所以我推导了四状态倒立摆模型，线性化后用 LQR 作为分析工具（不是部署的控制器）。它让我看清位置、速度、倾角、倾角速率的权重如何在稳定性与控制量之间权衡，并帮我发现执行器饱和。我还从手臂关节估计质心偏移，并在相同手臂轨迹下通过开关来检验前馈。在轮腿项目里，我用了增益调度 LQR 和虚拟模型控制。我的边界很清楚：模型是线性的、针对具体机器人的，增益靠手调。我想学习一般性的理论，以便设计这些控制器，而不是每次重新发现它们。谢谢。

**节奏提示**

- 这一版故意把三个可追问的钩子摆出来：bounded attitude references（为什么有界？）、LQR as analysis（Q、R 是什么？）、switching it on and off（怎么对比？）。三个你都要能答，见第 6 节 Q3、Q6、Q13。
- 面对教授，语速可以略慢，句子之间留出让对方插话的空隙。
- 如果教授中途问 "What's your A matrix?"，不要慌，回答："Let me sketch it" 然后在纸上画四状态，见 [P1 99 文档](../../01_项目课程/P1_AIRS球形机器人平衡控制/99_英文面试口述与深挖问答.md)。

### 5.2 场景 B：招生官（想判断你是否匹配、是否会英语授课、是否可靠）

**这类面试官关心**：动机是否真实、对项目是否有了解、沟通是否清楚、会不会中途退学。介绍里少用公式，多讲"为什么""学到了什么""怎么与人合作"。

**时长**：约 75 秒、约 160 词。

**English**

> Hello, / thank you for meeting me. // I'm Yongyi LAI, / a final-year Computer Science student at Shenzhen Technology University. // I'm ranked SIXTH out of 156. // Alongside my courses, / I've worked on real robots for two years, / at a robotics institute, / and at two companies, / all in Shenzhen. // I also joined my university's RoboMaster team, / where we won third prize at the national final. // These projects taught me / that robots fail in unexpected places: / in timing, / in data, / in limits. // I learned to find the cause step by step, / and to explain it clearly to teammates. // I also learned what I still lack: / a systematic foundation in optimisation and learning. // I read your programme page, / and I think it fits that goal, / and the Greater Bay Area is where I want to build my career. // I know my English is not perfect, / but I read technical documents in English every day, / and I'm practising speaking. // I'm motivated, / and I'm ready to work hard. // Thank you.

**中文翻译**：你好，感谢和我见面。我是赖咏怡，深圳技术大学计算机科学大四学生，专业排名 156 人中第 6。除了课程，我在一个机器人研究院和两家公司做了两年真实机器人工作，都在深圳。我也加入了学校的 RoboMaster 战队，我们在全国总决赛获得三等奖。这些项目教会我，机器人会在意想不到的地方出问题：时序、数据、限制。我学会一步步找原因，并向队友讲清楚。我也知道自己还缺什么：最优化和学习的系统基础。我读了贵项目的介绍，认为它符合这个目标，而大湾区是我想建立职业生涯的地方。我知道我的英语不完美，但我每天读英文技术文档，并且在练习口语。我有动力，也准备好努力。谢谢。

**节奏提示**

- "a robotics institute, and two companies" 指 AIRS（研究院）、Future Power 和 Kaihong；时间是"two years of real-robot work"：2024.09 的 P3 起算，口语取整，被追问时不要说成"全职两年"。
- "I read your programme page" 必须真实：面试前一定读一遍官方页面。
- "I know my English is not perfect" 一句是策略性诚实：招生官会听出你的口语水平，先说出来更稳。后面要紧跟具体做法，不要停在道歉。
- 招生官场景不用专业缩写（LQR、AMCL），除非对方先问。

### 5.3 场景 C：AI 视频面试，限时 60 秒

**场景特点**：系统出题，没有追问；通常有短暂准备时间和限时作答，只录一次或次数有限（以邀请邮件为准，见 [AI 视频面试模拟脚本](../04_模拟与冲刺/02_模拟面试脚本_AI视频面试.md)）。所以回答要**自成结构**：一句结论 → 一个具体例子 → 一句收束。

**中文翻译**：你好，我是赖咏怡，深圳技术大学计算机科学大四学生，专业排名 156 人中第 6。一句话：我让机器人算法在真实硬件上工作。例如，在 AIRS，我在带双臂的球形机器人上部署了级联 PID，并用四状态模型和 LQR 理解增益和饱和。我还做了车式机器人的导航链，现在在深开鸿做多机器人平台。我缺的是最优化和学习的系统基础，这就是我想读这个硕士的原因。之后，我想在大湾区做机器人算法工程师。谢谢。

**节奏提示（按时间轴）**

| 时间 | 内容 | 提示 |
|---|---|---|
| 0–8 秒 | 姓名、学校、排名 | 看镜头，不要读题目，开头不重复题目 |

## 6. 自我介绍之后的 20 个常见追问

> 使用方法：每道题先看"考察点"，再大声读英文答案；追问 1、追问 2 是面试官的第二、第三层问题。答案里的数字全部取自各项目 README 的实机细节自查表（统一设计取值）；若与你的实机记忆不同，以实机为准，并改用 "about" 说法。

### Q1. You said you're ranked sixth out of 156. How did you balance your grades with so many projects?

**中文题意**：你说排名 156 人中第 6，怎么在这么多项目之外保持成绩？

**考察点**：时间管理与成绩的真实性。

**English answer**：I treated the projects and the courses as supporting each other. Modern Control Theory gave me the language to model the ballbot, and the ballbot made the course concrete. For time, I planned around fixed dates. Exams and assignments come first, and robot work uses the remaining time. My supervisors also reviewed progress every week, which kept me on schedule. It was not always easy. During the RoboMaster season I had less free time, so I kept my study plan simple and did not take on extra things. I think the ranking shows that the projects did not replace my studies.

**中文翻译**：我把项目和课程看成互相支撑。现代控制理论给了我给球形机器人建模的语言，而球形机器人让这门课变得具体。时间上，我围绕固定日期来安排：考试和作业优先，机器人工作用剩下的时间。导师每周也会检查进度，这让我保持节奏。这并不总是容易，RoboMaster 赛季里空闲时间更少，所以我把学习计划保持简单，不再额外揽事。我认为排名说明项目没有取代学习。

**追问 1**
- Q: Which course helped your projects the most?
- A: Modern Control Theory, because state-space models and LQR came directly from it. Principles of Automatic Control helped with PID and loop thinking.
- 中文：哪门课对项目帮助最大？——现代控制理论，状态空间和 LQR 直接来自它；自动控制原理帮助我理解 PID 和回路。

**追问 2**
- Q: Was there a time you had to give something up?
- A: Yes. In the competition season I gave up other activities. I prefer to say no early than to do two things badly.
- 中文：有没有不得不放弃的时候？——有。比赛季我放弃了其他活动。我宁愿早点拒绝，也不愿两件事都做不好。

**关键词与易错点**：fixed dates、supporting each other、weekly review。不要说 "I don't sleep" 或 "I study 20 hours a day"，也不要把排名说成 "top 3%"（6/156 约 3.8%，口径是 top 4%）。

### Q2. Which of the projects you mentioned are you proudest of, and why?

**中文题意**：你提到的项目里最自豪哪一个，为什么？

**考察点**：能否挑出一个有深度、有证据的项目，并说清个人贡献。

**English answer**：I'm proudest of the ballbot work at AIRS. The reason is a change in how I worked. At first I tuned a cascaded PID controller by hand. Later, tuning alone could not explain why a larger tilt gain made the robot worse. So I went back to a model. I derived a four-state inverted-pendulum model, linearised it, and used LQR as an analysis tool. It showed me that a larger tilt weight needs much more control effort, so the problem was actuator saturation, not lack of gain. That moment taught me that a model can explain what tuning cannot.

**中文翻译**：我最自豪的是 AIRS 的球形机器人工作，原因是我的工作方式发生了变化。起初我手动调级联 PID。后来单靠调参无法解释为什么加大倾角增益反而更差。于是我回到模型：推导了四状态倒立摆，线性化，用 LQR 作分析工具。它让我看到倾角权重更大需要多得多的控制量，所以问题是执行器饱和而不是增益不足。那一刻我明白，模型能解释调参解释不了的现象。

**追问 1**
- Q: Did you deploy the LQR controller on the robot?
- A: No. The deployed controller was the cascaded PID. LQR was a model reference for interpreting gains and diagnosing saturation. I want to be clear about that.
- 中文：LQR 控制器上机了吗？——没有，部署的是级联 PID；LQR 是解释增益和诊断饱和的模型参考。

**追问 2**
- Q: How did the analysis change what you did?
- A: Two things. I raised the derivative gain to about half of the proportional gain, and I lowered the tilt reference limit from 0.15 to 0.10 radians.
- 中文：这个分析怎样改变了你的做法？——两点：把微分增益提到比例增益的约一半，并把倾角参考上限从 0.15 降到 0.10 rad。

**关键词与易错点**：model reference、actuator saturation、tilt weight。不要说 "I used LQR to balance the ballbot"（红线）。数字（0.15 到 0.10、Kd 约为 Kp 一半）来自 P1 自查表第 26 项，说的时候加 "about"。

### Q3. You said you used LQR "to understand the gains". What does that mean exactly?

**中文题意**：你说用 LQR "理解增益"，具体什么意思？

**考察点**：对 LQR 的真正理解，以及是否会夸大。

**English answer**：LQR minimises a cost made of state errors and control effort. The matrix Q weights the states, and R weights the input. For my four states, position, velocity, tilt and tilt rate, I could change the weights and see how the optimal gain changes. That told me which direction is "more aggressive" and when the control effort becomes too large for the motors. I then compared the structure of the LQR gain with my PID gains. For example, the ratio between the tilt-rate gain and the tilt gain was close to the ratio I needed in my inner loop. So the model gave me a reference, not a replacement.

**中文翻译**：LQR 最小化一个由状态误差和控制量组成的代价。Q 给状态加权，R 给输入加权。对我的四个状态——位置、速度、倾角、倾角速率——我可以改变权重，看最优增益怎么变。这告诉我哪个方向更"激进"，以及控制量何时超出电机能力。然后我把 LQR 增益的结构与我的 PID 增益比较。比如倾角速率增益与倾角增益的比例，和我内环需要的比例接近。所以模型给我的是参考，不是替代。

**追问 1**
- Q: What happens if you increase the weight on tilt?
- A: The gain on tilt grows, the response is stronger, and the control effort rises. On a real robot, that can push the motor command to its limit.
- 中文：加大倾角权重会怎样？——倾角增益变大，响应更强，控制量上升；真机上可能让电机指令顶到限幅。

**追问 2**
- Q: What are your Q and R values?
- A: In my analysis model, Q was diagonal, 4, 4, 100, 1, and R was 0.25. These are on a normalised model, and I used them only as a reference.
- 中文：Q 和 R 取多少？——分析模型里 Q 对角为 4、4、100、1，R 为 0.25，是归一化模型上的取值，只作参考。

**关键词与易错点**：cost function、Q and R、tilt rate、model reference。不要背 Riccati 方程的推导假装熟练，被问到时说 "the optimal gain comes from solving the Riccati equation; I used a solver"。

### Q4. You are a Computer Science student. Why did you take control courses?

**中文题意**：你是计算机专业，为什么去修控制课？

**考察点**：学习动机和主动性。

**English answer**：Because my robot projects needed them. In the RoboMaster team I used PID loops, and I wanted to understand why a loop is stable or not. So I took Principles of Automatic Control and Modern Control Theory. They were not required for my degree. The first course gave me the basics of feedback and PID. The second gave me state-space models and the idea of optimal control. Later I used both at AIRS. I think it shows how I learn: I find a problem in a project, then I look for the theory that explains it.

**中文翻译**：因为我的机器人项目需要。在 RoboMaster 战队里我用 PID 回路，想知道为什么回路稳定或不稳定。于是我修了自动控制原理和现代控制理论。它们不是我学位的必修课。第一门给了我反馈和 PID 的基础，第二门给了我状态空间模型和最优控制的概念。后来我在 AIRS 两门课都用上了。这体现了我的学习方式：先在项目里发现问题，再去找解释它的理论。

**追问 1**
- Q: What is the difference between those two courses?
- A: Principles of Automatic Control is mostly classical, with transfer functions and PID. Modern Control Theory uses state-space, controllability and optimal control.
- 中文：两门课区别？——前者偏经典（传递函数、PID），后者用状态空间、可控性和最优控制。

**追问 2**
- Q: Do you wish you had studied Automation instead?
- A: Not really. Computer science helped me with software, which became the hardest part of many robots. I only wish I had more optimisation and learning courses.
- 中文：想过读自动化吗？——不太。计算机让我掌握了软件，而软件常常是机器人最难的部分；我只是希望有更多最优化和学习的课。

**关键词与易错点**：feedback、state-space、optimal control。"not required for my degree" 这一点来自推荐信里 "额外修读" 的表述；如果你的课程计划里它们其实是选修，改成 "were electives for me"。

### Q5. What exactly was your role in the RoboMaster team?

**中文题意**：你在 RoboMaster 战队里具体负责什么？

**考察点**：个人贡献与团队成绩的区分。

**English answer**：Our team won third prize at the national final, so the result belongs to the whole team. My role was embedded control of the hero robot, on an STM32F407 with FreeRTOS and CAN. I was responsible for three control loops. The gimbal used a cascaded PID for pitch and yaw. The launcher had friction-wheel speed loops and a feeder position and velocity loop. On the chassis, I allocated velocity to four Mecanum wheels and scaled the speeds under the power limit. Vision, mechanics and strategy were handled by my teammates, and I defined the target interface with the vision side.

**中文翻译**：全国总决赛三等奖是团队成绩。我的角色是英雄机器人的嵌入式控制，平台是 STM32F407、FreeRTOS 和 CAN。我负责三类控制回路：云台用俯仰/偏航级联 PID；发射机构有摩擦轮速度环和拨弹位置—速度环；底盘把速度分配到四个麦克纳姆轮，并在功率限制下缩放轮速。视觉、机械和策略由队友负责，我负责与视觉组定义目标接口。

**追问 1**
- Q: Why did you change the launcher controller from PID to sliding-mode control?
- A: With continuous firing, the wheel speed dropped each time a projectile passed. PID took about 120 milliseconds to recover. Sliding-mode control shortened it to about 60 to 80 milliseconds.
- 中文：为什么发射机构从 PID 换成滑模？——连发时每发弹丸经过都会让转速下跌，PID 恢复约 120 ms，滑模缩短到约 60–80 ms。

**追问 2**
- Q: What was the control frequency?
- A: The control task ran at roughly 3 milliseconds, so around 330 hertz. I won't call it 1 kilohertz, because it was not.
- 中文：控制频率多少？——控制任务约 3 ms，大约 330 Hz；不能说 1 kHz。

- A: With the feedforward on, the tilt peak was about 0.026 radians instead of about 0.060, and the position drift was smaller. I repeated each condition five times.
- 中文：开关对比显示了什么？——开前馈时倾角峰值约 0.026 rad，关闭时约 0.060 rad，位置漂移也更小；每种状态重复 5 次。

**追问 2**
- Q: What would your dissertation be about, if you do one?
- A: A systematic comparison of balance or navigation controllers on a platform I already know, with a clear metric and repeatable tests.
- 中文：若做 dissertation 会做什么？——在我熟悉的平台上，用明确指标和可重复测试，系统比较平衡或导航控制器。

**关键词与易错点**：engineering projects、fair evaluation、no publications。不要说 "I did research on balance control"。数字取自 P1 自查表第 23 项，说 "about"。

### Q17. In the navigation project, what did you build yourself, and what came from open-source packages?

**中文题意**：导航项目里哪些是你自己做的，哪些来自开源包？

**考察点**：个人边界与诚信。

**English answer**：I was responsible for the algorithm chain, but I used open-source building blocks where that was sensible. For localisation, I configured and tuned the EKF and AMCL, and the main work was making the inputs consistent: timestamps, coordinate frames and motion direction. For planning, I worked on the Hybrid-A* and TEB parameters and their interface with the vehicle constraints. The MPC tracker I modelled, implemented and tuned on the real vehicle. The mechanical structure and low-level motor firmware were done by lab colleagues, and Professor Fu reviewed my progress every week.

**中文翻译**：我负责算法链，但在合理的地方用了开源模块。定位上，我配置并调参 EKF 和 AMCL，主要工作是让输入一致：时间戳、坐标系和运动方向。规划上，我做 Hybrid-A* 和 TEB 的参数以及它们与车辆约束的接口。MPC 跟踪器是我建模、实现并在真车上调参的。机械结构和底层电机固件由实验室同事完成，傅老师每周评审我的进度。

**追问 1**
- Q: What caused the pose jumps?
- A: Three inconsistencies: laser timestamps arrived about 60 milliseconds late, reverse speed lost its sign, and some static transforms were wrong. I fixed each one, then smoothed the map-to-odom correction.
- 中文：位姿跳变的原因？——三类不一致：激光时间戳约晚 60 ms、倒车速度丢了符号、部分静态变换有误；逐一修复后再对 map→odom 修正做平滑。

**追问 2**
- Q: How did the vehicle perform?
- A: At 0.5 metres per second, the mean lateral error was about 6 centimetres. In 22 recorded runs, 20 succeeded, and I know why the other two failed.
- 中文：车的表现如何？——0.5 m/s 下横向误差均值约 6 cm；记录的 22 次运行成功 20 次，另 2 次的失败原因我清楚。

**关键词与易错点**：consistent inputs、EKF/AMCL、Hybrid-A*、TEB、MPC。开源包名称按"典型实现"说，不要断言用了哪个具体版本；P5 用 ROS2（Humble）。不要说"我写了整个导航栈"。

### Q18. What would your supervisors say about you?

**中文题意**：你的导师会怎么评价你？

**考察点**：自我认知，是否与推荐信一致。

**English answer**：I can only say what I hope, and what I think they have seen. At AIRS, my mentor saw that when tuning no longer explained the robot, I went back to a model. My mentor also saw that I asked precise questions and worked independently once the direction was clear. Professor Fu supervised my navigation and wheel-legged projects. I think Professor Fu would say that when balance failed, I looked for the cause step by step, in state consistency, torque limits and contact. I also try to treat documentation and hardware safety as part of the design.

**中文翻译**：我只能说我希望的和我认为他们看到的。在 AIRS，我的导师看到的是：当调参不再能解释机器人时，我会回到模型；我会提精准的问题，方向明确后能独立工作。傅老师指导了我的导航和轮腿项目，我想他会说，平衡失败时我会一步步找原因，从状态一致性、力矩限幅和接触里找。我也尽量把文档和硬件安全当作设计的一部分。

**追问 1**
- Q: What would they say you need to improve?
- A: Theory. I recognise that I arrived at models robot by robot, and tuned gains on the machine, without a general theory.
- 中文：他们会说你需要改进什么？——理论。我是逐台机器人推出模型、在机器上调增益，缺少一般理论。

**追问 2**
- Q: Who are your two referees?
- A: Professor Fu Xianghua, Associate Dean of the School of Artificial Intelligence at my university, and Chen Dansheng, a robot development engineer at AIRS.
- 中文：两位推荐人是谁？——傅向华老师（学校人工智能学院副院长）和 AIRS 的机器人开发工程师陈丹盛。

**关键词与易错点**：precise questions、work independently、go back to a model。不要替推荐人说他们没写的话；可以引用的句子见 [PS 与推荐信主线](../../00_申请画像/02_PS与推荐信主线.md) 第 4、5 节。

### Q19. Can you give me a one-sentence version of your introduction?

**中文题意**：能用一句话总结你的自我介绍吗？

**考察点**：提炼能力、清晰度。

**English answer**：I'm a hands-on robotics engineer who closes loops on real hardware, who knows where my intuition and hand-tuning stop, and who wants to build the systematic theory in a master's. If you want it even shorter: I make robot algorithms work, and now I want to learn how to design them properly. I think this sentence also explains why I am applying to this programme. I want to be an engineer who can say not only that it works, but also why it works, and when it will not.

**中文翻译**：我是一个在真实硬件上闭环的实战型机器人工程师，清楚自己直觉和手调的边界，想通过硕士建立系统的理论。如果要更短：我让机器人算法跑起来，现在想学会如何把它们设计好。我想这句话也解释了我为什么申请这个项目。我想成为一个不仅能说"能用"，还能说"为什么能用、何时不能用"的工程师。

**追问 1**
- Q: Which word in that sentence matters most?
- A: "Systematic". I have practice and intuition, and I want a systematic foundation.
- 中文：这句话里最重要的词？——"systematic"。我有实践和直觉，想要系统的基础。

**追问 2**
- Q: Can you say it in simple words for a non-expert?
- A: I make robots keep their balance and find their way, and I want to learn the science behind it.
- 中文：能给外行讲吗？——我让机器人保持平衡和找到路，我想学习背后的科学。

**关键词与易错点**：hands-on、closes loops、systematic。这句话是 PS 的"人设"句，保持与 PS 一致。

### Q20. Is there anything you would like to add that we have not discussed?

**中文题意**：还有什么想补充的吗？

**考察点**：收尾的主动性，是否有备而来。

**English answer**：Yes, one thing. In my projects I treat safety as part of the design, not something added at the end. At AIRS, I added state initialisation, output limiting and fall-recovery safeguards, so the balance loop could be tested again and again without damaging the robot. At Kaihong, the same idea appears in the safe-execution chain. I think this habit will help me in a lab, because shared hardware needs it. Thank you for the chance to talk. I would also like to ask one question about the programme, if there is time.

**中文翻译**：有一点。在我的项目里，我把安全当作设计的一部分，而不是最后补上的东西。在 AIRS，我加了状态初始化、输出限幅和跌倒恢复保护，让平衡回路可以反复测试而不损坏机器人。在深开鸿，同一个思想体现在安全执行链里。我想这个习惯在实验室会有用，因为共享硬件需要它。感谢这次交流的机会。如果有时间，我也想问一个关于项目的问题。

**追问 1**
- Q: What does the fall-recovery safeguard do?
- A: When roll or pitch exceeds a threshold for several cycles, the output goes to zero and the controller locks into a fault state. A person recovers it manually.
- 中文：跌倒恢复保护做什么？——当横滚或俯仰超过阈值并持续数个周期，输出归零，控制器锁定为故障状态，由人工恢复。

**追问 2**
- Q: Why not restart automatically?
- A: An automatic restart can be dangerous if the robot is on its side or someone is near it.
- 中文：为什么不自动重启？——机器人侧倒或旁边有人时，自动重启可能很危险。

**关键词与易错点**：safety as design、state initialisation、output limiting、fall recovery。口径：这些是 CV 写到的保护措施，具体阈值取自 P1 自查表（0.5 rad、连续 5 个周期），细节可说 "in my design"，不要说"保证绝不会带病使能"。

## 7. 自测与练习安排

### 7.1 自测清单

| 检查项 | 通过标准 |
|---|---|
| 30 秒版、1 分钟版 | 看着计时器各说 3 遍，误差 ±5 秒，无停顿卡壳 |
| 对应学校定制版 | 面试前一天用手机录音，听一遍，确认没有说错课程名或学校名 |
| 三种场景版 | 技术导师版能在被打断后接着往下说；AI 版 58 秒内说完 |
| 红线句 | 不说 "LQR controlled"、"I won third prize"、"1 kHz"、"I built M-Robots" |
| 追问 | 随机抽 5 题，每题 40 秒内答完，并能说出追问 1、2 |

### 7.2 一周练习安排

| 天 | 内容 | 时间 |
|---|---|---|
| 第 1 天 | 背通用 30 秒和 1 分钟版，逐句读，标注节奏 | 40 分钟 |
| 第 2 天 | 2 分钟版和 3 分钟版各读 3 遍；练习"被打断后接上" | 40 分钟 |
| 第 3 天 | 对应学校的定制版，重点练钩子句和最后一句 | 30 分钟 |
| 第 4 天 | 三种场景版各录音一次，回听语速 | 40 分钟 |
| 第 5 天 | 追问 Q1–Q10，随机顺序，计时 40 秒 | 40 分钟 |
| 第 6 天 | 追问 Q11–Q20，随机顺序，计时 40 秒 | 40 分钟 |
| 第 7 天 | 完整模拟：自我介绍 + 3 个追问，找朋友或对着录像 | 30 分钟 |

### 7.3 练习注意

1. 不要把稿子背成一模一样的声音，面试官能听出来；背下结构和关键词，让句子每次略有不同。
2. 听不懂追问时，用 "Sorry, could you repeat the question?" 或 "Do you mean ...?"，见 [英语能力与沟通题库](./05_题库_英语能力与沟通.md)。
3. 自我介绍后的答题风格：先一句结论，再一个例子，最后一句收束。
4. 相关题库：[为什么这个项目/学校/地区](./02_题库_为什么这个项目_学校_地区.md)、[职业规划与研究兴趣](./03_题库_职业规划与研究兴趣.md)、[个人特质与压力题](./04_题库_个人特质_优缺点_压力题.md)。
