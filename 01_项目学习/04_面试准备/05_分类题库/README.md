# 分类题库总索引：把“所有可能被问到的问题”变成可练的英文问答

> **一句话定位**：这个目录是港澳硕士面试的“题库层”。每一道题都有英文题目、英文回答、中文翻译、追问和易错点，覆盖自我介绍、动机、职业规划、个人特质、英语沟通、行为、工程化、数学、控制、运动学与估计、规划与感知、机器学习、嵌入式与 CS 基础、AI 视频限时作答、各校专属问答和整场模拟。本页是索引：告诉你每个文件有多少题、做什么用、先练什么后练什么，以及四周怎么练完。

**本章学完你能……**

- 在 10 秒内找到任何一类问题所在的文件和题号范围；
- 按自己收到的面试形式和学校，选出必练的文件，而不是从头读到尾；
- 按“四周练习路线图”把约 1350 道题、14 个复杂案例和 4 套整场演练练成肌肉记忆；
- 知道题库和 `07_英语学习`、项目 `99_` 文件、`02_各校面试准备`、`04_模拟与冲刺` 的分工，缺什么去哪里补。

**前置知识**：先读 [面试准备总入口](../README.md) 的第 1–3 节；事实口径以 [CV 事实基线](../../06_维护说明/CV事实基线.md) 为准；[港硕面试真题调研](../00_港硕面试真题调研.md) 说明了哪些题有公开来源、哪些是按考点扩写的训练题。

## 2. 推荐练习顺序（三个阶段）

### 阶段一：开口（先能说，再追求深）

1. [01 自我介绍](./01_自我介绍_通用与按项目定制.md)：脱稿说 30 秒与 1 分钟版；
2. [20 AI 视频面试](./20_题库_AI视频面试与限时作答.md) 第 2–6 节：模板、检查表、翻车点；
3. [05 英语能力与沟通](./05_题库_英语能力与沟通.md)：听不懂、卡壳、请对方重复的句子；
4. [02 为什么这个项目](./02_题库_为什么这个项目_学校_地区.md) 通用题与你首选项目的 6 道专属题；
5. [03 职业规划与研究兴趣](./03_题库_职业规划与研究兴趣.md)：把规划说成 60 秒。

### 阶段二：讲清（行为与项目故事）

1. [06 行为面试](./06_题库_行为面试与团队合作.md)：先练 P3、P5、P7 三个故事；
2. [04 个人特质与压力题](./04_题库_个人特质_优缺点_压力题.md)：优缺点、敏感题；
3. [07 工程化实践](./07_题库_工程化实践与问题解决.md) 与 [08 案例包](./08_复杂问题解决案例包.md)：每个项目至少一个能讲满三分钟的案例；
4. [20 号](./20_题库_AI视频面试与限时作答.md) Q9–Q30：限时版项目与行为题。

### 阶段三：讲深（技术、学校与整场）

1. 技术题库按你的首选项目的方向挑：机器人类先 [11](./11_题库_控制理论与机器人控制.md)、[12](./12_题库_运动学_动力学_状态估计_SLAM.md)、[13](./13_题库_规划_导航_感知.md)；CS 类先 [15](./15_题库_嵌入式_RTOS_通信_软件_CS基础.md)、[10](./10_题库_数学_优化_概率.md)；AI 类先 [14](./14_题库_机器学习_深度学习_强化学习_大模型.md)、[10](./10_题库_数学_优化_概率.md)；
2. 学校专属：[21](./21_题库_各校专属问答_港科大系与港中深港中文.md) 或 [22](./22_题库_各校专属问答_港城大港理工澳门.md) 里你收到邀请的项目的 25 题；
3. 整场演练：[23](./23_模拟面试整套_按学校形式编排.md) 里对应形式的一套，计时、录音、自评。

> **面试要点**：不要从 01 读到 23。题库的价值是“被问到时你已经说过一遍”，所以必须出声练。每天 10–15 题，每题说一遍，比读一整个文件有效。

## 6. 四周练习路线图

假设每天 90–120 分钟，面试前至少有四周。时间更少时，取每周的“必练”项，其余略过。

## 7. 统一的题目格式与使用规则

每个题库条目都是这样：

```text
### Qn. <English question>
中文题意 / 考察点
English answer（口语，约 90–150 词）
中文翻译
追问 1 / 追问 2（英文问题 + 简答 + 中文翻译）
关键词与易错点
```

使用规则：

1. **先出声说，再对照**。先用自己的话回答，录音，再看范例；
2. **范例是示范不是台词**。背稿的痕迹在面试里很明显；
3. **数字与自查表一致**：回答里的数字取自各项目 README 的“实机细节自查表”，用 about / roughly；记不清就用诚实模板：“I don't remember the exact number, but roughly …”；
4. **统一口径**：P1 的 LQR 是分析工具而非部署；P3 控制任务约 3 ms，不说 1 kHz；3V3 二等奖和全国赛三等奖是团队成绩；P5 用 ROS2 Humble；P7 是经典 CAN；P6 的 IMU 为 100 Hz；P4 是 YOLOv5 / RKNN INT8；读码发现的隐患不是你的贡献；
5. **官方信息**：课程名、学分、日期、费用、面试形式不确定处，说“我了解到 / 面试前以官网核对”，不编造课程名或教授名。

## 8. 自测与练习安排

### 8.1 自测

1. 不看本页，说出题库的三个阶段，以及你当前处在哪一阶段；
2. 说出你的首选项目对应的“动机题”“专属 25 题”“各校准备文件”三个位置；
3. 说出 LQR、3V3 二等奖、P3 控制周期、P6 IMU 频率这四条口径；
4. 抽 5 道题（每个阶段至少 1 道），限时回答并录音；
