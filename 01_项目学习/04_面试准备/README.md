# 面试准备总入口：从“会做项目”到“能用英文讲清楚”

> **一句话定位**：这是整套港澳 11 个硕士项目英文面试准备的地图。项目怎么做、基础怎么懂、八股怎么答，分别在 `01_项目课程`、`02_基础知识`、`03_八股知识`；本目录负责最后一步——**把它们变成面试官听得懂、评分表上拿得到分的英文表达**。

**本章学完你能……**

- 说清整个面试体系由哪四块组成，每一块解决什么问题，遇到某一种面试形式时先读哪几份文件；
- 按自己剩下的时间（3 天 / 7 天 / 14 天）选一条不浪费的备考路线；
- 知道“通用能力”（自我介绍、叙事线、行为题、弱项应对、口语表达、技术口述）和“学校专属”（各校面试准备）、“项目口述”（七个项目的 30 秒/90 秒/3 分钟版本）、“模拟与冲刺”之间的关系；
- 避开最常见的三种备考误区：背稿、只刷技术不练口语、把 11 个学校当成 11 套全新内容。

**前置知识**：无。建议先通读本页，再按路线走。如果你还没读过自己的 CV 与个人陈述，请先读 [CV 逐条拆解](../00_申请画像/01_CV逐条拆解.md) 和 [PS 与推荐信主线](../00_申请画像/02_PS与推荐信主线.md)；事实口径以 [口径与事实基线](../00_申请画像/04_口径与事实基线.md) 为准。

## 1. 面试准备体系：四块拼图

你要面对的是 11 个项目、至少四种面试形式。但**你的素材只有一份**：同一份 CV、同一条申请主线、同样七个项目。所以备考的逻辑是“一份素材，四次加工”：

```text
        素材层（你到底做过什么、懂什么）
   01_项目课程 (P1..P7)   02_基础知识   03_八股知识
                         │
                         ▼
   ┌───────────────────────────────────────────────┐
   │ 01_面试总指南  —— 通用能力：怎么介绍自己、怎么讲故事、 │
   │                    怎么答行为题、怎么处理难题、怎么说技术 │
   └───────────────────────────────────────────────┘
                         │
          ┌──────────────┼───────────────┐
          ▼              ▼               ▼
   02_各校面试准备   03_项目口述总览    04_模拟与冲刺
   (每校的侧重、     (七个项目的       (高频100问、
    形式、问题)       30秒/90秒/3分钟)   模拟脚本、清单)
```

| 板块 | 解决的问题 | 什么时候读 |
|---|---|---|
| `01_面试总指南`（本目录第一部分） | 面试是什么形式、怎么评分；英文自我介绍；为什么读研；行为面试；弱项；提问；口语；技术口述方法 | **第一遍就读**，它决定你的“说话方式” |
| `02_各校面试准备` | 每所学校的专业侧重、可能的形式、与你 PS 的呼应点 | 知道自己要面哪所学校之后，按学校读 |
| `03_项目口述总览` | 七个项目分别用 30 秒/90 秒/3 分钟怎么讲；CV 每句话的英文展开；跨项目对比 | 总指南读完后，项目口述是“主体素材” |
| `04_模拟与冲刺` | 高频 100 问、AI 视频面试与技术面试的模拟脚本、一周冲刺、当天清单 | 面试前 1–2 周开始，最后阶段占主要时间 |

> **面试要点**：评委从来不会因为你“背得流畅”而给高分。他们给分的依据是：你的回答是不是**直接回答了问题**、**有具体例子**、**讲得清楚**、**诚实**。本体系的所有英文答案都是“示范”，不是“台词”。

## 4. 三条备考路线

先确认三件事：**①最近一场面试的日期；②形式（AI 视频还是真人）；③是否只面一所学校**。然后选择路线。路线里的文件都是上面的精确链接。

### 4.1 路线 A：3 天急救（只有 72 小时）

目标：能稳定做出一份合格的 AI 视频面试，不出大错。**不追求覆盖所有技术细节。**

## 5. 每天怎么练：一个可重复的“练习回路”

不管哪条路线，**每天 90–120 分钟**用同一个回路，比一次学 6 小时有效：

```text
 读一小段  →  口头复述（不看稿）  →  录音/录像  →  回听挑 3 个问题  →  改稿  →  再说一次
  (10 分钟)      (10 分钟)            (同时)          (15 分钟)        (10 分钟)   (10 分钟)
```

挑问题的三个固定角度：

1. **内容**：有没有直接回答问题？有没有具体例子？有没有一个自己的判断？
2. **结构**：开头是不是一句话给出结论？结尾有没有收束？
3. **声音**：语速、停顿、重音、结尾句调；有没有大量 “um”、“you know”。

> **面试要点**：英语 6.5 的同学最需要的不是“更高级的词”，而是**更短的句子 + 更清楚的结构 + 更稳的语速**。每个回答控制在 3–5 句话为一个意思，句子长度尽量在 12–20 个英文词。

## 6. 四个原则：怎么使用这些材料

1. **事实只有一个来源**：英文 CV。文档里出现的所有“你做了 X”都要能在 CV/PS/推荐信里找到依据；找不到依据的细节，标成了 `【待你补全】`。**请务必自己补全，或者决定不说。**
2. **不背全文，背骨架**：每个答案记住“开头一句 + 两个要点 + 一个例子 + 一句收尾”。
3. **说你确实做过的，而且说清你负责的那一部分**：团队项目要区分“team”与“I”。RoboMaster 的成绩是团队成绩，你的贡献是云台/发射/底盘的控制环。
4. **诚实是策略，不是道德装饰**：被问到不会的，承认并展示你如何推理，比编一个答案更能得分，且不会被追问击穿。

## 8. 常见误区

| 误区 | 为什么不好 | 正确做法 |
|---|---|---|
| 背全文 | 一旦卡词，整个回答崩溃；语气像朗读 | 背骨架与关键句，其余即时组织 |
| 只准备技术，不练口语 | 技术正确但听不懂，评委无法给分 | 每天至少一半时间出声练习 |
| 夸大成果 | 追问一层就露馅，最伤诚信分 | 说清你的职责边界；不知道的说不知道 |
| 对每所学校都编一套新故事 | 容易前后矛盾，也浪费时间 | 一条主线 + 每校不同的“为什么这里” |
| 回答过长 | AI 视频面试被截断；真人面试被打断 | 先给结论，再展开，30–90 秒一个意思 |
| 不练“被打断” | 真实面试几乎一定被打断 | 用 [应急句型](./01_面试总指南/01_面试形式_流程与评分维度.md) 练习接话 |
| 不准备反问 | 显得被动 | 备好 3–5 个与学校相关的问题 |

## 本章要点速记

1. 面试体系 = 通用能力（01）+ 学校定制（02）+ 项目口述（03）+ 模拟冲刺（04），底层素材同一份。
2. 先判断面试形式，再选文件；形式以邀请邮件为准。
3. 3 天只保 AI 视频的“基本盘”；7 天做到全覆盖；14 天做到被追问不慌。
4. 练习回路：读—复述—录音—回听—改稿—重说。
5. 句子短、结构清、诚实，比词汇高级更重要。
6. 事实只有一个来源（CV），补全所有 `【待你补全】`。
7. 团队项目区分“team”与“I”。
8. 每个回答先给结论，再给例子，最后一句收束。

## 自测题

1. 说出“一份素材，四次加工”里的四次加工分别是什么。（要点：通用能力、学校定制、项目口述、模拟冲刺）
2. 你只有 3 天，最先练哪三样？（要点：自我介绍、叙事线、最强三个项目 + 一次完整模拟）
3. 为什么不建议背全文？（要点：卡词即崩、不自然、被打断后无法衔接）
4. 技术面试和 AI 视频面试在准备重点上有什么不同？（要点：前者重追问与口述，后者重结构与镜头表达）
5. 面试通知里的时长/次数与本文描述冲突时，听谁的？（要点：以通知为准）
