# 03 目录结构与文件职责

> **一句话定位**：新目录树（设计稿）、实际文件清单（自动生成）和命名约定。补写或新增文档时，先对照这里，保证路径、编号、链接一致。

## 1. 设计思路

按"读者怎么学"分层，而不是按"材料从哪来"分：

```text
00_申请画像   → 先弄清楚"我是谁、材料怎么说、面试官会抓什么"（事实边界，后面所有文档服从这里）
01_项目课程   → 七个项目逐个讲透（每个项目一个目录）
02_基础知识   → 项目背后的数学、力学、控制、估计、规划、感知、嵌入式、软件（从零讲起）
03_八股知识   → 计算机 / AI / 机器人学的问答速查（中文要点 + 英文速答）
04_面试准备   → 英文表达、各校画像、项目口述、模拟与冲刺
05_学习笔记归档 → 用户自己的疑惑问答原稿（只读）
06_维护说明   → 本目录：如何继续补充和优化
```

项目编号与 CV 对应：P1 AIRS 球形机器人平衡、P2 未来动力（VR 遥操作/主从/底盘）、P3 RoboMaster 英雄、P4 OpenHarmony 智能园艺、P5 车式机器人自主导航、P6 深开鸿 M-Robots 平台、P7 可变腿长轮腿。编号沿用用户学习笔记里的 P1–P7，不要改。

## 3. 路径与链接约定

- 从 `01_项目课程/Px_*/xx.md` 链到基础：`../../02_基础知识/04_控制理论/02_PID控制全解.md`
- 从 `02_基础知识/aa/bb.md` 链到项目：`../../01_项目课程/P1_AIRS球形机器人平衡控制/README.md`
- 同目录互链：`./02_PID控制全解.md`
- 笔记归档：`../../05_学习笔记归档/P1/P1_本对话问答逐字稿.md`
- 从 `02_基础知识/00_总览与学习路线.md`（根下）链项目：`../01_项目课程/...`
- 重构时曾有一个笔误：给部分写作任务的 prompt 里写成了 `../../../01_项目课程/`，实际应为 `../../`。各任务已按正确路径写，检查脚本验证过无断链。

## 4. 项目目录内的固定文件

每个 `01_项目课程/Px_*/` 目录必须有：

| 文件 | 内容 |
|---|---|
| `README.md` | 项目一页纸；阅读顺序（列全文件）；基础文档依赖链接；**`## 实机细节自查表`**（精确标题，被其他文档锚点链接）；**口径备忘（仅自查，面试按 CV 说）** |
