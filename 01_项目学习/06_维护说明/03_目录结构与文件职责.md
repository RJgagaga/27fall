# 03 目录结构与文件职责

> **一句话定位**：新目录树（设计稿）、实际文件清单（自动生成）和命名约定。补写或新增文档时，先对照这里，保证路径、编号、链接一致。

## 1. 设计思路

按"读者怎么学"分层，而不是按"材料从哪来"分：

```text
00_申请画像   → 先弄清楚"我是谁、材料怎么说、面试官会抓什么"（事实边界，后面所有文档服从这里）
01_项目课程   → 七个项目逐个讲透（每个项目一个目录）
02_基础知识   → 14 个知识模块：数学、力学、运动学、信号、控制、估计、SLAM、规划、感知、机器学习、嵌入式、软件、系统工程、计算机基础（项目 + 通用知识，从零讲起）
03_八股知识   → 计算机 / AI / 机器人学的问答速查（中文要点 + 英文速答）
04_面试准备   → 英文表达、各校画像、项目口述、模拟与冲刺
05_学习笔记归档 → 用户自己的疑惑问答原稿（只读）
06_维护说明   → 本目录：如何继续补充和优化
```

项目编号与 CV 对应：P1 AIRS 球形机器人平衡、P2 未来动力（VR 遥操作/主从/底盘）、P3 RoboMaster 英雄、P4 OpenHarmony 智能园艺、P5 车式机器人自主导航、P6 深开鸿 M-Robots 平台、P7 可变腿长轮腿。编号沿用用户学习笔记里的 P1–P7，不要改。
