## 2. 新会话启动指令（可直接粘贴）

```text
你在仓库 RJgagaga/27fall 里工作（用户：赖咏怡，准备港澳硕士英文面试）。
请先按顺序读 01_项目学习/06_维护说明/ 下的：README.md、01_项目背景与原始需求.md、写作规范.md、CV事实基线.md、待补充清单与补写Prompt.md（其余文件按需读）。
读完后，用 3–5 句话复述：目标、硬性约束（以 CV 为准；P5/P6 源码禁用；不得编造实机数据；面试英文并附中文译文）、以及你准备做的任务。
然后执行任务：<在这里写要补的内容，例如“按 待补充清单与补写Prompt.md 的 7.1，补写 P2 的 99_英文面试口述与深挖问答.md”>。
完成后运行 python -I 01_项目学习/06_维护说明/工具/check_all.py（必须无问题），更新相关 README 的自查表与阅读顺序，git add -A && git commit && git push -u origin HEAD（main 分支）。回复里列出：改动文件、汉字数/英文词数、新增 `【待你补全】` 数量、发现的 CV 与源码出入。
```

## 4. 用户自己要做的事（AI 做不了）

1. 对照真实经历核对各项目 README "## 实机细节自查表"里的设计取值（占位已全部清零，约 1200 处已替换为具体取值，不是实测），面试可信度的关键是取值与你记得的一致。
2. 把各项目 `99_` 里的 STAR 案例、行为面试里的故事换成真实经历。
3. 核对"口径备忘"里的出入，确认真机/真实代码是哪种情况（尤其 P2 的轮速 PID 在哪一层、P3 的控制周期与功率控制、P4 的预处理与接口适配、P7 的状态向量与增益来源）。
4. 面试前对照官方文档核对标"未核对"的规格、API 与文献。
5. 确认申请材料里的版本：87.63 还是 87.66、港城大 P53 的 PS 长版还是 v2、港理工早轮（2026-10-20）是否已提交。
