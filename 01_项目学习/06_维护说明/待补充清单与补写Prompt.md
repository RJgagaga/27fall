# 待补充清单与补写 Prompt

> **一句话定位**：重构时为了赶进度，一批文档写得比计划短、比计划浅，另有几篇没写。本页完整列出这些文档，给出补写顺序，并为每一组配了可以直接粘贴的 prompt。
> 统计口径：汉字数 = 去掉代码块后的汉字个数；英文词数 = 去掉代码块后的英文单词个数。英文为主的文件（`99_`、面试脚本）汉字数低是正常的，要看英文词数。

## 0. 使用方法

1. 先看第 1–5 节的清单，按第 6 节的顺序挑要补的。
2. 每次开新会话，先让它读本目录的 `README.md`（索引）、`写作规范.md`、`CV事实基线.md`，再贴第 7 节对应的 prompt。
3. 一次只补一组，补完让它做链接检查（第 8 节），再提交推送。
4. 以下规则对所有补写任务都成立（prompt 里已包含）：以 CV 为准；没有依据的实机数据不得当作实测事实写，用“本项目取值约…/我们的做法是…”写成具体设计取值，教学数值标"教学示例"；文档中不再保留任何占位标记；面试英文答案后附中文译文。
