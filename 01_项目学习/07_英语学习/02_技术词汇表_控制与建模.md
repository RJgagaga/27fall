## 1. 使用说明

- 音标采用国际音标（IPA），以美式发音为主；`ˈ` 标主重音，`ˌ` 标次重音。`ə` 是弱读元音（像 about 里的 a）。
- 词性缩写：*n.* 名词，*v.* 动词，*adj.* 形容词，*adv.* 副词，*phr.* 短语。
- 每条例句都与 CV 中的项目一致，不出现 CV 没有的数值；需要数字时写 about / roughly，或写在"教学示例"里。
- 学习顺序：先看英文和中文，再读音标，最后把例句大声读三遍，再遮住英文看中文回译。

## 2. 反馈控制基础

### 1. controller /kənˈtroʊlər/ *n.* 控制器
- 搭配：design a controller / tune a controller / a cascade controller / the deployed controller
- 例句：I designed a cascade controller and tuned it on the real robot.
  - 中文：我设计了一个级联控制器，并在真机上整定了它。
- 易错：重音在第二音节 -TROL-，不是 CON-troller。词尾 -er 轻读。

### 2. plant /plænt/ *n.* 被控对象
- 搭配：the plant model / plant dynamics / an unstable plant
- 例句：In control theory, the robot itself is called the plant.
  - 中文：在控制理论里，机器人本身叫被控对象。
- 易错：这里不是"植物"，也不是"工厂"（虽然 power plant 是电厂）。口语里常直接说 "the system"。

### 3. feedback /ˈfiːdbæk/ *n.* 反馈
- 搭配：feedback loop / sensor feedback / state feedback / negative feedback
- 例句：The controller uses IMU and wheel-speed feedback to keep the chassis upright.
  - 中文：控制器用 IMU 和轮速反馈让底盘保持直立。
- 易错：重音在第一音节 FEED-。作动词时写成 feed back（分开）：The measurement is fed back to the controller.

### 4. feedforward /ˈfiːdfɔːrwərd/ *n.* 前馈
- 搭配：feedforward term / gravity feedforward / a feedforward compensation
- 例句：We add a gravity feedforward term so that the feedback loop does not have to fight the arm's weight.
  - 中文：我们加入重力前馈项，这样反馈回路就不必去对抗手臂的重量。
- 易错：feed 与 forward 连读，重音在 FEED-。不要说成 "feed-for-word"。

### 5. closed loop /kloʊzd luːp/ *n.* 闭环
- 搭配：closed-loop control / close the loop / closed-loop response
- 例句：Using encoder feedback, I closed the PID loop on each wheel.
  - 中文：我用编码器反馈在每个轮子上闭合了 PID 回路。
- 易错：closed 的 -ed 读 /d/，不要读成 "close-id"。

### 6. open loop /ˈoʊpən luːp/ *n.* 开环
- 搭配：open-loop command / run open loop / open-loop test
- 例句：Before closing the loop, I ran the motor open loop to check the direction of rotation.
  - 中文：闭环之前，我先开环运行电机来确认旋转方向。
- 易错：open 读 /ˈoʊpən/，不是 /ˈoʊpɪn/，后一音节很轻。

### 7. setpoint /ˈsetpɔɪnt/ *n.* 设定值
- 搭配：speed setpoint / track the setpoint / change the setpoint
- 例句：The friction-wheel speed loop tracks a speed setpoint from the upper layer.
  - 中文：摩擦轮速度环跟踪上层给出的速度设定值。
- 易错：也可说 reference 或 target。setpoint 是一个词，重音在 SET-。

### 8. reference /ˈrefrəns/ *n.* 参考值（给定）
- 搭配：attitude reference / reference trajectory / bounded reference
- 例句：The position loop outputs a bounded attitude reference to the inner loop.
  - 中文：位置环向内环输出有界的姿态参考值。
- 易错：常被读成三音节 "ref-er-ence"；母语者常读两音节 REF-rəns。

### 9. error /ˈerər/ *n.* 误差，偏差
- 搭配：tracking error / steady-state error / error signal / reduce the error
- 例句：The PID controller acts on the error between the setpoint and the measurement.
  - 中文：PID 控制器作用于设定值与测量值之间的误差。
- 易错：两个 r 都要发卷舌，但 er-ror 不要加重第二个音节。与 deviation、residual 的区别见第 15 章。

### 10. gain /ɡeɪn/ *n.* 增益
- 搭配：proportional gain / controller gain / gain scheduling / increase the gain
- 例句：Raising the proportional gain makes the response faster but can cause oscillation.
  - 中文：提高比例增益会让响应更快，但可能引起振荡。
- 易错：gain 与 parameter 不同：gain 是起放大作用的系数；parameter 是更泛的"参数"。读音为 /ɡeɪn/，不是 /ɡɛn/。

### 11. proportional /prəˈpɔːrʃənəl/ *adj.* 比例的
- 搭配：proportional term / proportional gain / proportional control
- 例句：The proportional term responds to the current error.
  - 中文：比例项响应当前误差。
- 易错：重音在 -POR-。四个音节 pro-POR-tion-al。-tion 读 /ʃən/。

### 12. integral /ˈɪntɪɡrəl/ *adj./n.* 积分的；积分
- 搭配：integral term / integral action / integral windup / the integral of the error
- 例句：The integral term removes the steady-state error but can wind up when the actuator saturates.
  - 中文：积分项能消除稳态误差，但执行器饱和时会积分饱和。
- 易错：名词/形容词都读 INT-ə-grəl，重音在第一音节；不要读成 in-TEG-ral（那是动词 integrate 的相近重音）。integrate 读 /ˈɪntɪɡreɪt/。

### 13. derivative /dɪˈrɪvətɪv/ *n./adj.* 微分；导数
- 搭配：derivative term / derivative action / the derivative of the error
- 例句：The derivative term adds damping, but it also amplifies measurement noise.
  - 中文：微分项增加阻尼，但也会放大测量噪声。
- 易错：重音在 -RIV-，de-RIV-a-tive。不要把重音放在第一个音节。

### 14. cascade /kæsˈkeɪd/ *n./v.* 串级，级联
- 搭配：a cascade controller / cascaded PID / cascade structure
- 例句：The gimbal uses a cascaded PID with an angle loop outside and a rate loop inside.
  - 中文：云台用串级 PID，外面是角度环，里面是角速度环。
- 易错：重音在第二音节 -CADE。cascade 和 cascaded 常通用，CV 用 cascaded PID / PID cascade。

### 15. inner loop /ˈɪnər luːp/ *n.* 内环
- 搭配：inner-loop bandwidth / the inner loop is faster than the outer loop
- 例句：The inner loop should be several times faster than the outer loop.
  - 中文：内环应该比外环快好几倍。
- 易错：inner 读 /ˈɪnər/。相对词 outer loop /ˈaʊtər luːp/（外环）。

### 16. saturation /ˌsætʃəˈreɪʃən/ *n.* 饱和
- 搭配：actuator saturation / torque saturation / output saturation / saturate
- 例句：I used the LQR model to check whether the motor torque was close to saturation.
  - 中文：我用 LQR 模型检查电机力矩是否接近饱和。
- 易错：重音在 -RAY-。动词 saturate /ˈsætʃəreɪt/ 重音在第一音节。

### 17. limit /ˈlɪmɪt/ *n./v.* 限制；限幅
- 搭配：output limit / current limit / limit the output / torque limit
- 例句：Output limiting is one of the safeguards in the hardware safety loop.
  - 中文：输出限幅是硬件安全环里的保护措施之一。
- 易错：limit 不是 "limite"；末尾 /t/ 要有。

### 18. disturbance /dɪˈstɜːrbəns/ *n.* 扰动
- 搭配：external disturbance / disturbance rejection / a step disturbance
- 例句：When the arms move, the shift of the centre of mass acts as a disturbance on the balance loop.
  - 中文：手臂运动时，质心的移动对平衡回路来说就是扰动。
- 易错：重音在 -STUR-。别和 interference（干扰，多指信号）混用。

### 19. compensation /ˌkɑːmpənˈseɪʃən/ *n.* 补偿
- 搭配：gravity compensation / friction compensation / compensate for
- 例句：The leader arm uses gravity compensation so that it feels light in the operator's hand.
  - 中文：主臂使用重力补偿，所以操作者手里感觉很轻。
- 易错：动词 compensate /ˈkɑːmpənseɪt/，后面接 for。重音在名词的 -SA-。

### 20. tuning /ˈtuːnɪŋ/ *n.* 整定，调参
- 搭配：on-robot tuning / PID tuning / tune the gains / manual tuning
- 例句：Most of my time in P7 went into on-robot tuning and tracing balance anomalies.
  - 中文：P7 里我大部分时间花在真机调参和追查平衡异常上。
- 易错：tune 是 /tuːn/，不要读成 /tjuːn/（英式可读，美式通常 /tuːn/）。"调参" 口语常说 tune the parameters/gains。

## 3. 性能指标与稳定性

### 21. stability /stəˈbɪləti/ *n.* 稳定性
- 搭配：closed-loop stability / stability margin / stable and unstable
- 例句：LQR gave me a way to reason about stability instead of tuning blindly.
  - 中文：LQR 让我能从稳定性角度分析，而不是盲目调参。
- 易错：重音在 -BIL-。-ity 词重音在 -ity 之前一个音节。形容词 stable /ˈsteɪbəl/。

### 22. overshoot /ˈoʊvərʃuːt/ *n.* 超调
- 搭配：percent overshoot / limit the overshoot / large overshoot
- 例句：A large integral gain caused overshoot when the target changed quickly.
  - 中文：积分增益太大，目标快速变化时就出现了超调。
- 易错：重音在第一音节 O-，不要读成 over-SHOOT。

### 23. rise time /raɪz taɪm/ *n.* 上升时间
- 搭配：short rise time / rise time and settling time
- 例句：Increasing the gain shortens the rise time but may increase the overshoot.
  - 中文：增大增益会缩短上升时间，但可能增大超调。
- 易错：rise 的 s 读浊音 /z/。

### 24. settling time /ˈsetlɪŋ taɪm/ *n.* 调节时间
- 搭配：settling time within a band / long settling time
- 例句：The response was fast, but the settling time was longer than I wanted.
  - 中文：响应很快，但调节时间比我想要的长。
- 易错：settling 的 t 在美式中常闪音 /ˈsetlɪŋ/，注意不要读成 "sit-ling"。

### 25. steady-state error /ˈstedi steɪt ˈerər/ *n.* 稳态误差
- 搭配：eliminate the steady-state error / non-zero steady-state error
- 例句：Without the integral term, the wheel speed kept a small steady-state error.
  - 中文：没有积分项，轮速会保持一个小的稳态误差。
- 易错：steady /ˈstedi/，不是 /ˈstɪdi/。

### 26. oscillation /ˌɑːsɪˈleɪʃən/ *n.* 振荡
- 搭配：sustained oscillation / oscillate / damp the oscillation
- 例句：When the derivative gain was too small, the pitch angle showed a slow oscillation.
  - 中文：微分增益太小时，俯仰角出现缓慢振荡。
- 易错：重音在 -LAY-；开头 os- 读 /ɑːs/。

### 27. damping /ˈdæmpɪŋ/ *n.* 阻尼
- 搭配：add damping / damping ratio / under-damped / over-damped
- 例句：The derivative term acts like electronic damping on the joint.
  - 中文：微分项在关节上起到类似电子阻尼的作用。
- 易错：damp /dæmp/ 是"潮湿"也是"抑制"。damping ratio 读 /ˈdæmpɪŋ ˈreɪʃioʊ/。

### 28. bandwidth /ˈbændwɪdθ/ *n.* 带宽
- 搭配：loop bandwidth / limited bandwidth / high-bandwidth
- 例句：The inner loop has a higher bandwidth than the outer loop, which is why the cascade works.
  - 中文：内环带宽比外环高，所以级联结构才有效。
- 易错：结尾 -dth 是 /dθ/，舌尖放在上下齿间。

### 29. robustness /roʊˈbʌstnəs/ *n.* 鲁棒性
- 搭配：robust to disturbances / robust against model error / robustness margin
- 例句：Gain scheduling improves robustness when the leg length changes.
  - 中文：腿长变化时，增益调度提高了鲁棒性。
- 易错：重音在 -BUST-。robust 读 /roʊˈbʌst/。

### 30. response /rɪˈspɑːns/ *n.* 响应
- 搭配：step response / fast response / transient response
- 例句：The step response of the wheel-speed loop was smooth and well damped.
  - 中文：轮速环的阶跃响应平滑，阻尼良好。
- 易错：重音在第二音节；名词和动词 respond /rɪˈspɑːnd/ 同重音。

### 31. transient /ˈtrænʃənt/ *adj./n.* 瞬态（的）
- 搭配：transient response / a short transient
- 例句：Ground-contact transitions produce short transients in the torque command.
  - 中文：与地面接触状态切换会在力矩指令里产生短暂的瞬态。
- 易错：读 /ˈtrænʃənt/ 或 /ˈtrænziənt/，两种都可。

### 32. deadband /ˈdedbænd/ *n.* 死区
- 搭配：a deadband on the joystick / apply a deadband
- 例句：We apply a small deadband to the remote-control input to avoid drift when the stick is released.
  - 中文：我们对遥控输入加一个小死区，避免摇杆松开时漂移。
- 易错：dead 读 /ded/，不要读成 /diːd/。也可写作 dead zone。

### 33. hysteresis /ˌhɪstəˈriːsɪs/ *n.* 迟滞
- 搭配：hysteresis band / add hysteresis / start and stop thresholds
- 例句：The pump state machine uses independent start and stop thresholds, which gives it hysteresis.
  - 中文：水泵状态机使用独立的启动和停止阈值，这就是迟滞。
- 易错：重音在 -REE-。很多人读成 "his-ter-ISS-is"，应为 his-tuh-REE-sis。

### 34. threshold /ˈθreʃhoʊld/ *n.* 阈值
- 搭配：start threshold / stop threshold / exceed the threshold
- 例句：The pump turns on when soil moisture drops below the start threshold.
  - 中文：土壤湿度低于启动阈值时，水泵开启。
- 易错：只有两个音节 THRESH-hold，不要读成三音节。th- 为清音 /θ/。

## 4. 状态空间、LQR 与最优控制

### 35. state /steɪt/ *n.* 状态
- 搭配：state variable / state vector / state estimate / robot state
- 例句：The four states of the linearised model are position, velocity, tilt angle and tilt rate.
  - 中文：线性化模型的四个状态是位置、速度、倾角和倾角速度。
- 易错：state 作名词动词都读 /steɪt/。口语里 "the state of the robot" 很常用。

### 36. state-space model /steɪt speɪs ˈmɑːdl/ *n.* 状态空间模型
- 搭配：a linear state-space model / write the model in state-space form
- 例句：I wrote the inverted pendulum in state-space form so that I could apply LQR.
  - 中文：我把倒立摆写成状态空间形式，以便应用 LQR。
- 易错：model 读 /ˈmɑːdl/，不要读成 "mo-del"。

### 37. state feedback /steɪt ˈfiːdbæk/ *n.* 状态反馈
- 搭配：full state feedback / u = −Kx
- 例句：LQR produces a state-feedback law of the form u equals minus K x.
  - 中文：LQR 给出形如 u 等于负 K x 的状态反馈律。
- 易错：读公式 u = −Kx 时说 "u equals minus K times x"。

### 38. linearisation /ˌlɪniərəˈzeɪʃən/ *n.* 线性化（美式拼写 linearization）
- 搭配：linearise around the equilibrium / small-angle approximation
- 例句：Linearisation around the upright equilibrium is only valid for small tilt angles.
  - 中文：围绕直立平衡点线性化，只在倾角较小时有效。
- 易错：重音在 -ZAY-。动词 linearise /ˈlɪniəraɪz/。CV 用英式拼写 -ise，说话时不用区分。

### 39. equilibrium /ˌiːkwɪˈlɪbriəm/ *n.* 平衡点
- 搭配：unstable equilibrium / equilibrium point / around the equilibrium
- 例句：An upright inverted pendulum is an unstable equilibrium.
  - 中文：直立的倒立摆是不稳定的平衡点。
- 易错：重音在 -LIB-。注意与 balance（平衡，日常）区分：equilibrium 是数学/物理含义。

### 40. inverted pendulum /ɪnˈvɜːrtɪd ˈpendʒələm/ *n.* 倒立摆
- 搭配：a four-state inverted pendulum / cart-pole / wheeled inverted pendulum
- 例句：I modelled the ballbot as a linearised four-state inverted pendulum.
  - 中文：我把 ballbot 建模为线性化的四状态倒立摆。
- 易错：pendulum 读 /ˈpendʒələm/，中间 -dʒ- 是 "j" 的音。

### 41. cost function /kɔːst ˈfʌŋkʃən/ *n.* 代价函数
- 搭配：quadratic cost / minimise the cost / cost over a horizon
- 例句：LQR minimises a quadratic cost made of state error and control effort.
  - 中文：LQR 最小化由状态误差和控制量组成的二次代价。
- 易错：function 读 /ˈfʌŋkʃən/，-tion 音 /ʃən/。

### 42. weight matrix /weɪt ˈmeɪtrɪks/ *n.* 权重矩阵
- 搭配：state weight Q / control weight R / increase the weight on tilt
- 例句：Increasing the weight on the tilt angle makes the controller react more strongly to a lean.
  - 中文：增大倾角的权重，控制器会对倾斜反应更强烈。
- 易错：matrix 读 /ˈmeɪtrɪks/，复数 matrices /ˈmeɪtrɪsiːz/。

### 43. control effort /kənˈtroʊl ˈefərt/ *n.* 控制量（代价）
- 搭配：reduce control effort / the trade-off between stability and control effort
- 例句：LQR makes the trade-off between tilt error and control effort explicit.
  - 中文：LQR 把倾斜误差与控制量之间的权衡明确表达出来。
- 易错：effort 读 /ˈefərt/，不是 "ef-fort" 两个 f 重读。

### 44. optimal /ˈɑːptɪməl/ *adj.* 最优的
- 搭配：optimal control / optimal gain / optimal under the model
- 例句：LQR is optimal for the linear model, but the real robot is not exactly linear.
  - 中文：LQR 对线性模型是最优的，但真实机器人并不完全线性。
- 易错：重音在第一音节 OP-。

### 45. eigenvalue /ˈaɪɡənˌvæljuː/ *n.* 特征值
- 搭配：closed-loop eigenvalues / negative real part
- 例句：For a stable system, all closed-loop eigenvalues have negative real parts.
  - 中文：对稳定系统，所有闭环特征值的实部都为负。
- 易错：eigen- 读 /ˈaɪɡən/（"艾根"），不是 "ee-gen"。

### 46. controllability /kənˌtroʊləˈbɪləti/ *n.* 可控性
- 搭配：check controllability / controllable pair
- 例句：Before designing LQR, I checked that the pair was controllable.
  - 中文：设计 LQR 之前，我检查了系统对是可控的。
- 易错：重音在 -BIL-，共六个音节，读慢一点分段：con-TROL-la-BIL-i-ty。

### 99. system identification /ˈsɪstəm aɪˌdentɪfɪˈkeɪʃən/ *n.* 系统辨识
- 搭配：identify the model parameters
- 例句：System identification fits a model to measured input and output data.
  - 中文：系统辨识用测量的输入输出数据去拟合模型。
- 易错：identification 重音在 -CA-。

### 100. dynamics /daɪˈnæmɪks/ *n.* 动力学
- 搭配：robot dynamics / plant dynamics
- 例句：The dynamics describe how forces and torques change the motion of the robot.
  - 中文：动力学描述力和力矩如何改变机器人的运动。
- 易错：重音在 -NAM-；dynamic 形容词，dynamically 副词。

### 101. nominal /ˈnɑːmɪnəl/ *adj.* 标称的
- 搭配：nominal model / nominal value
- 例句：The LQR was computed for the nominal model, so we still tune on the robot.
  - 中文：LQR 是按标称模型算的，所以我们仍要在机器人上调参。
- 易错：nominal 重音在第一音节；与 nominate 区分。

### 102. trade-off /ˈtreɪd ɔːf/ *n.* 权衡
- 搭配：a trade-off between speed and smoothness
- 例句：There is always a trade-off between response speed and noise sensitivity.
  - 中文：响应速度和噪声敏感度之间总要权衡。
- 易错：重音在 TRADE；复数 trade-offs。

### 103. rate limit /reɪt ˈlɪmɪt/ *n.* 速率限制（斜率限制）
- 搭配：a rate limit on the command
- 例句：A rate limit on the wheel command prevents sudden jumps when the robot is re-enabled.
  - 中文：对轮命令加速率限制，可以避免重新使能时的突变。
- 易错：也叫 slew-rate limit；动词 limit the rate of change。

### 104. ramp /ræmp/ *n./v.* 斜坡；斜坡变化
- 搭配：ramp the setpoint / a ramp reference
- 例句：We ramp the velocity command over about one second instead of stepping it.
  - 中文：我们把速度指令在约一秒内斜坡变化，而不是阶跃。
- 易错：ramp 发 /ræmp/，m 与 p 都要发。

### 105. smoothing /ˈsmuːðɪŋ/ *n.* 平滑
- 搭配：smooth the output / smoothing filter
- 例句：Smoothing the target avoids abrupt torque changes.
  - 中文：对目标做平滑可以避免力矩突变。
- 易错：smooth 末尾 th 为 /ð/：/smuːð/。

### 106. integral clamp /ˈɪntɪɡrəl klæmp/ *n.* 积分钳位
- 搭配：clamp the integral term
- 例句：The integral clamp keeps the integral term inside a fixed range.
  - 中文：积分钳位让积分项保持在固定范围内。
- 易错：clamp 读 /klæmp/，不是 "clap"。

### 107. output allocation /ˈaʊtpʊt ˌæləˈkeɪʃən/ *n.* 输出分配
- 搭配：allocate the output to three wheels
- 例句：The controller output is allocated to the three wheels through the kinematics.
  - 中文：控制器输出通过运动学分配给三个轮子。
- 易错：allocation 重音在 -CA-。

### 108. decoupling /diːˈkʌplɪŋ/ *n.* 解耦
- 搭配：decouple the axes
- 例句：Decoupling lets us tune the pitch loop and the roll loop separately.
  - 中文：解耦让我们能分别整定俯仰环和横滚环。
- 易错：de- 读 /diː/，重音在 -COUP-。

### 109. steady state /ˈstedi steɪt/ *n.* 稳态
- 搭配：reach steady state
- 例句：At steady state the tilt should stay very close to zero.
  - 中文：在稳态下，倾角应非常接近零。
- 易错：steady 是 /ˈstedi/，不是 "stay-dy"。

### 110. sensitivity /ˌsensəˈtɪvəti/ *n.* 灵敏度，敏感性
- 搭配：sensitivity to noise / low sensitivity
- 例句：The derivative term gives a fast response but a high sensitivity to noise.
  - 中文：微分项响应快，但对噪声很敏感。
- 易错：重音在 -TIV-。

### 111. convergence /kənˈvɜːrdʒəns/ *n.* 收敛
- 搭配：convergence speed / converge to zero
- 例句：The error shows fast convergence once the gains are tuned properly.
  - 中文：增益整定合适后，误差收敛得很快。
- 易错：动词 converge /kənˈvɜːrdʒ/。

### 112. divergence /daɪˈvɜːrdʒəns/ *n.* 发散
- 搭配：the estimate diverges / divergent
- 例句：If the integral keeps growing, the loop diverges and the robot falls.
  - 中文：如果积分一直增长，回路就会发散，机器人就会倒下。
- 易错：diverge 重音在 -VERGE。

### 113. stiffness /ˈstɪfnəs/ *n.* 刚度
- 搭配：joint stiffness / stiffness gain
- 例句：A low stiffness gain makes the follower arm soft and easy to push.
  - 中文：较低的刚度增益使从臂柔顺、容易被推动。
- 易错：stiffness 结尾 -ss 读 /nəs/。

### 114. impedance /ɪmˈpiːdns/ *n.* 阻抗
- 搭配：impedance control / virtual spring
- 例句：Impedance control makes a joint behave like a spring and a damper.
  - 中文：阻抗控制让关节表现得像弹簧加阻尼器。
- 易错：重音在 -PEE-；与 resistance 区分。

### 115. gravity feedforward /ˈɡrævəti ˈfiːdfɔːrwərd/ *n.* 重力前馈
- 搭配：a gravity feedforward term
- 例句：Gravity feedforward cancels the predictable part of the load before feedback acts.
  - 中文：重力前馈在反馈起作用前抵消可预测的那部分负载。
- 易错：gravity /ˈɡrævəti/，第一音节重音。

### 116. anti-windup clamp /ˈænti ˈwɪndʌp klæmp/ *n.* 抗饱和钳位
- 搭配：stop integrating at the limit
- 例句：When the output hits the limit, we stop accumulating the integral.
  - 中文：输出碰到限幅时，我们停止累加积分。
- 易错：windup 读 /ˈwɪndʌp/，w 开头 wind 在此读 /wɪnd/ 不是 /waɪnd/。

### 117. reference model /ˈrefrəns ˈmɑːdl/ *n.* 参考模型
- 搭配：use as a model reference
- 例句：The linear model is a reference for tuning, not a replacement for tuning.
  - 中文：线性模型是整定的参照，而不是整定的替代。
- 易错：reference 常读两个音节 /ˈrefrəns/。

### 118. gain schedule /ɡeɪn ˈskedʒuːl/ *n.* 增益表（调度表）
- 搭配：schedule by leg length
- 例句：We schedule the LQR gain by leg length using a fitted polynomial.
  - 中文：我们用拟合的多项式按腿长调度 LQR 增益。
- 易错：schedule 美式 /ˈskedʒuːl/，英式 /ˈʃedjuːl/。

### 119. polynomial fit /ˌpɑːliˈnoʊmiəl fɪt/ *n.* 多项式拟合
- 搭配：fit a cubic polynomial
- 例句：A cubic polynomial fit keeps the scheduled gain smooth between design points.
  - 中文：三次多项式拟合让调度增益在设计点之间保持平滑。
- 易错：polynomial 重音在 -NO-。

### 120. symmetric /sɪˈmetrɪk/ *adj.* 对称的
- 搭配：a symmetric matrix
- 例句：The weight matrices in LQR are symmetric and positive semi-definite.
  - 中文：LQR 中的权重矩阵是对称的半正定矩阵。
- 易错：重音在 -MET-。

### 121. positive definite /ˈpɑːzətɪv ˈdefɪnət/ *adj.* 正定的
- 搭配：a positive definite matrix
- 例句：R must be positive definite so that the control effort has a real cost.
  - 中文：R 必须正定，这样控制量才有真实代价。
- 易错：definite 末音节弱读 /ˈdefɪnət/。

### 122. penalise /ˈpiːnəlaɪz/ *v.* 惩罚（加权抑制）
- 搭配：penalise the tilt error
- 例句：A large weight penalises the tilt error more heavily than the control effort.
  - 中文：较大的权重对倾角误差的惩罚比对控制量更重。
- 易错：美式 penalize，英式 penalise；peˈ 读 /ˈpiː/。

### 123. bounded /ˈbaʊndɪd/ *adj.* 有界的
- 搭配：a bounded reference
- 例句：The outer loop outputs a bounded tilt reference so the inner loop is never asked for too much.
  - 中文：外环输出有界的倾角参考，内环就不会被要求过多。
- 易错：bound 读 /baʊnd/，别和 bond 混。

### 124. transient response /ˈtrænʃənt rɪˈspɑːns/ *n.* 瞬态响应
- 搭配：improve the transient response
- 例句：Feedforward improves the transient response without changing the steady-state gain.
  - 中文：前馈改善瞬态响应而不改变稳态增益。
- 易错：transient 读 /ˈtrænʃənt/，类似 "tran-shent"。

## 7. 小练习：用这些词说一段话

**任务**：不看稿，用 8 个以上本表词汇，说一段关于 P1 的 45 秒小介绍。参考版本如下，先读、再遮住自己改写。

> I worked on balance control for a ballbot with a dual-arm upper body. First, I built a cascade controller: the position loop gives a bounded attitude reference to the attitude loop, and the output is allocated to three wheels. Then I went back to the model. I linearised the system as a four-state inverted pendulum and used LQR to see how the weights trade off stability against control effort. That model helped me understand the deployed gains and diagnose actuator saturation. Finally, I added a gravity feedforward term from the arm joint states.
>
> 中文：我做的是带双臂上半身的 ballbot 的平衡控制。首先搭了级联控制器：位置环给姿态环一个有界的姿态参考，输出再分配给三个轮子。然后我回到模型，把系统线性化为四状态倒立摆，用 LQR 看权重如何在稳定性与控制量之间取舍。这个模型帮助我理解已部署的增益并诊断执行器饱和。最后，我根据手臂关节状态加入重力前馈项。

## 本章要点速记

1. 控制三件套的词：controller（控制器）、plant（被控对象）、feedback（反馈）。
2. PID 三个形容词：proportional / integral / derivative，重音分别在 -POR-、INT-、-RIV-。
3. 性能指标四件：overshoot、rise time、settling time、steady-state error。
4. saturation（饱和）和 windup（积分饱和）经常一起出现，务必会读会拼。
5. LQR 的核心句：minimises a quadratic cost of state error and control effort。
6. gain scheduling = 按工作点（如腿长）切换增益；sliding-mode 的副作用是 chattering。
7. MPC 三词：receding horizon、prediction horizon、constraint。
8. -tion 读 /ʃən/，但 equation 读 /ʒən/；-ity 词重音在 -ity 前一个音节（stability）。

## 自测题

1. "Integral windup" 指什么？答：执行器饱和时积分项持续累积，造成饱和解除后大超调；用积分钳制或抗饱和处理。
2. gain 与 parameter 的区别？答：gain 是起放大作用的系数；parameter 更泛指任何参数。
3. 怎么读 u = −Kx？答：u equals minus K x（或 minus K times x）。
4. hysteresis 的重音在哪？答：第三音节 -REE-：his-tuh-REE-sis。
5. 用 "trade-off" 造一个关于 LQR 的句子。参考：LQR makes the trade-off between tilt error and control effort explicit.
