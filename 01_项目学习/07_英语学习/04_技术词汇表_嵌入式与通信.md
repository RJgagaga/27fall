## 1. 使用说明

- 音标采用国际音标（IPA），以美式发音为主；`ˈ` 标主重音，`ˌ` 标次重音，`ə` 是弱读元音（像 about 里的 a）。
- 词性缩写：*n.* 名词，*v.* 动词，*adj.* 形容词，*adv.* 副词。
- 每个词条固定五行：词头（英文、音标、词性、中文）→ 搭配 → 例句 → 中文译文 → 易错读音或易混点。
- 例句都与 CV 中的项目一致；需要数字时只写 about / roughly 这类量级措辞，具体设计取值以各项目 README 的「实机细节自查表」为准。
- 学习顺序：先看英文与中文，再读音标，最后把例句大声读三遍，遮住英文看中文回译。每天 15–20 个词即可，不要一次读完。

## 2. 微控制器与实时系统

### 1. microcontroller /ˈmaɪkroʊkənˌtroʊlər/ *n.* 微控制器
- 搭配：an STM32 microcontroller
- 例句：The control loops of the hero robot run on an STM32F407 microcontroller.
  - 中文：英雄机器人的控制回路运行在 STM32F407 微控制器上。
- 易错：micro- 读 /ˈmaɪkroʊ/；重音在 MI-，后半部分 -troller 次重音。

### 2. STM32 /ˌes tiː em ˈθɜːrti tuː/ *n.* STM32 系列单片机
- 搭配：STM32H7 / STM32F4
- 例句：I wrote the balance control firmware for an STM32H7 board.
  - 中文：我为一块 STM32H7 板写了平衡控制固件。
- 易错：读 "S-T-M thirty-two"，不要读 "S-T-M-three-two"。

### 3. firmware /ˈfɜːrmwer/ *n.* 固件
- 搭配：flash the firmware / firmware update
- 例句：Firmware is the software that runs directly on the microcontroller.
  - 中文：固件是直接运行在微控制器上的软件。
- 易错：重音在 FIRM-，不是 "fer-ware"。

### 4. embedded system /ɪmˈbedɪd ˈsɪstəm/ *n.* 嵌入式系统
- 搭配：embedded software
- 例句：An embedded system has limited memory and must meet timing deadlines.
  - 中文：嵌入式系统内存有限，并且必须满足时间截止要求。
- 易错：embedded 重音在 -BED-。

### 5. real-time /ˈriːəl taɪm/ *adj.* 实时的
- 搭配：a real-time system
- 例句：In a real-time system, a late answer can be as bad as a wrong answer.
  - 中文：在实时系统里，迟到的答案和错误的答案一样糟糕。
- 易错：real 读 /ˈriːəl/，不是 "ri-al"。

### 6. RTOS /ˌɑːr tiː oʊ ˈes/ *n.* 实时操作系统
- 搭配：run an RTOS
- 例句：An RTOS lets us split the firmware into tasks with priorities.
  - 中文：RTOS 让我们把固件拆成带优先级的任务。
- 易错：读 "R-T-O-S" 或 "are-toss"。

### 7. FreeRTOS /ˌfriː ɑːr tiː oʊ ˈes/ *n.* FreeRTOS 实时系统
- 搭配：FreeRTOS task
- 例句：We used FreeRTOS to schedule the IMU, control and communication tasks.
  - 中文：我们用 FreeRTOS 调度 IMU、控制和通信任务。
- 易错：读 "free R-T-O-S"。

### 8. task /tæsk/ *n.* 任务
- 搭配：create a task / task priority
- 例句：Each control loop runs as a separate FreeRTOS task.
  - 中文：每个控制回路都作为独立的 FreeRTOS 任务运行。
- 易错：task 读 /tæsk/，sk 同时发音。

### 9. priority /praɪˈɔːrəti/ *n.* 优先级
- 搭配：high priority / priority level
- 例句：The control task has a higher priority than the logging task.
  - 中文：控制任务的优先级比日志任务高。
- 易错：重音在 -OR-，/praɪˈɔːrəti/。

### 10. scheduler /ˈskedʒuːlər/ *n.* 调度器
- 搭配：the RTOS scheduler
- 例句：The scheduler decides which ready task runs next.
  - 中文：调度器决定下一个运行哪个就绪任务。
- 易错：sch 读 /sk/（美式）。

### 11. preemption /priˈempʃən/ *n.* 抢占
- 搭配：preemptive scheduling
- 例句：With preemption, a high-priority task interrupts a lower one immediately.
  - 中文：有了抢占，高优先级任务会立刻打断低优先级任务。
- 易错：重音在 -EMP-，词中 p 要发。

### 12. tick /tɪk/ *n.* 系统节拍
- 搭配：the system tick / tick rate
- 例句：The RTOS tick is the heartbeat that drives time delays and scheduling.
  - 中文：RTOS 节拍是驱动延时和调度的心跳。
- 易错：tick 读 /tɪk/，不要和 "tech" 混。

### 13. interrupt /ˈɪntərʌpt/ *n.* 中断
- 搭配：an interrupt handler
- 例句：A timer interrupt triggers the control loop at a fixed rate.
  - 中文：定时器中断以固定频率触发控制回路。
- 易错：名词重音在 IN-，动词在 -RUPT。

### 14. ISR (interrupt service routine) /ˌaɪ es ˈɑːr/ *n.* 中断服务程序
- 搭配：keep the ISR short
- 例句：Keep the ISR short and defer heavy work to a task.
  - 中文：让中断服务程序保持简短，把重活交给任务。
- 易错：读 I-S-R。

### 15. DMA (direct memory access) /ˌdiː em ˈeɪ/ *n.* 直接内存访问
- 搭配：use DMA for SPI
- 例句：DMA moves the IMU data into memory without using the CPU.
  - 中文：DMA 不占用 CPU 就能把 IMU 数据搬进内存。
- 易错：读 D-M-A。

### 16. peripheral /pəˈrɪfərəl/ *n.* 外设
- 搭配：configure a peripheral
- 例句：The CAN controller is a peripheral of the microcontroller.
  - 中文：CAN 控制器是微控制器的外设。
- 易错：重音在 -RIPH-。

### 17. register /ˈredʒɪstər/ *n.* 寄存器
- 搭配：write to a register
- 例句：Configuring the sensor means writing values into its registers.
  - 中文：配置传感器就是向它的寄存器写值。
- 易错：读 /ˈredʒɪstər/，g 读 /dʒ/。

### 18. GPIO /ˌdʒiː piː aɪ ˈoʊ/ *n.* 通用输入输出口
- 搭配：toggle a GPIO pin
- 例句：A GPIO pin switches the relay that powers the pump.
  - 中文：一个 GPIO 引脚控制给水泵供电的继电器。
- 易错：读 G-P-I-O。

### 19. timer /ˈtaɪmər/ *n.* 定时器
- 搭配：a hardware timer
- 例句：A hardware timer gives a precise control period.
  - 中文：硬件定时器给出精确的控制周期。
- 易错：重音在 TI-，-er 轻读；不要读成 "time-er" 的两个重读音节。

### 20. clock /klɑːk/ *n.* 时钟
- 搭配：the system clock
- 例句：The monotonic clock is the right choice for measuring loop periods.
  - 中文：测量回路周期时，单调时钟才是正确选择。
- 易错：clock 读 /klɑːk/，不是 "kluck"。

### 21. monotonic clock /mɑːnəˈtɑːnɪk klɑːk/ *n.* 单调时钟
- 搭配：use a monotonic clock
- 例句：A monotonic clock never jumps backward when the system time is adjusted.
  - 中文：单调时钟在系统时间被调整时也不会倒退。
- 易错：monotonic 重音在 -TON-。

### 22. watchdog /ˈwɑːtʃdɔːɡ/ *n.* 看门狗
- 搭配：a watchdog timer
- 例句：A watchdog resets the board or stops the output when the software hangs.
  - 中文：软件卡死时，看门狗会复位板子或停止输出。
- 易错：watch 读 /wɑːtʃ/，dog 读 /dɔːɡ/。

### 23. timeout /ˈtaɪmaʊt/ *n.* 超时
- 搭配：a communication timeout
- 例句：If no frame arrives before the timeout, the motor is set to a safe state.
  - 中文：如果超时前没收到帧，电机就被置为安全状态。
- 易错：重音在 TIME-。

### 24. heartbeat /ˈhɑːrtbiːt/ *n.* 心跳
- 搭配：send a heartbeat
- 例句：Each node sends a heartbeat so that its peers know it is still alive.
  - 中文：每个节点发送心跳，让对方知道它还活着。
- 易错：heart 读 /hɑːrt/，不是 "hurt"；两个音节都有清晰的 t。

### 25. mutex /ˈmjuːteks/ *n.* 互斥锁
- 搭配：lock a mutex
- 例句：A mutex protects shared data from being written by two tasks at once.
  - 中文：互斥锁保护共享数据不被两个任务同时写入。
- 易错：读 /ˈmjuːteks/，像 "mew-tex"。

### 26. semaphore /ˈseməfɔːr/ *n.* 信号量
- 搭配：give a semaphore
- 例句：A semaphore lets an interrupt wake up a waiting task.
  - 中文：信号量可以让中断唤醒一个等待的任务。
- 易错：重音在 SEM-。

### 27. queue /kjuː/ *n.* 队列
- 搭配：a message queue
- 例句：A queue passes messages between tasks safely.
  - 中文：队列在任务之间安全地传递消息。
- 易错：queue 只读 /kjuː/，后面的字母不发音。

### 28. race condition /reɪs kənˈdɪʃən/ *n.* 竞态条件
- 搭配：avoid a race condition
- 例句：A race condition appears when two tasks touch the same data without protection.
  - 中文：两个任务无保护地访问同一数据时就会出现竞态条件。
- 易错：race 读 /reɪs/。

### 29. deadlock /ˈdedlɑːk/ *n.* 死锁
- 搭配：prevent deadlock
- 例句：Deadlock happens when two tasks each wait for a lock the other holds.
  - 中文：死锁指两个任务各自等待对方持有的锁。
- 易错：dead 读 /ded/，lock 读 /lɑːk/，两个音节都重读；不要和 "dead end" 混用。

### 30. priority inversion /praɪˈɔːrəti ɪnˈvɜːrʒən/ *n.* 优先级反转
- 搭配：priority inheritance
- 例句：Priority inversion can delay a high-priority task through a shared mutex.
  - 中文：优先级反转可能通过共享互斥锁拖延高优先级任务。
- 易错：inversion 的 -sion 读 /ʒən/。

### 31. stack overflow /stæk ˈoʊvərfloʊ/ *n.* 栈溢出
- 搭配：check the stack size
- 例句：A stack overflow is a classic reason for a random crash in a task.
  - 中文：栈溢出是任务里随机崩溃的典型原因。
- 易错：overflow 重音在 O-，/ˈoʊvərfloʊ/；stack 读 /stæk/。

### 32. interrupt latency /ˈɪntərʌpt ˈleɪtənsi/ *n.* 中断延迟
- 搭配：measure the interrupt latency
- 例句：Interrupt latency is the time from the event to the first line of the handler.
  - 中文：中断延迟是从事件发生到处理程序第一行执行的时间。
- 易错：latency 重音在 LA-；整词里 interrupt 的 -rupt 的 p、t 要发全。

### 33. determinism /dɪˈtɜːrmɪnɪzəm/ *n.* 确定性
- 搭配：deterministic timing
- 例句：Deterministic timing matters more than raw speed in a control loop.
  - 中文：在控制回路里，确定的时序比单纯的速度更重要。
- 易错：重音在 -TER-。

### 34. blocking call /ˈblɑːkɪŋ kɔːl/ *n.* 阻塞调用
- 搭配：avoid blocking calls
- 例句：We avoid blocking calls inside the control loop.
  - 中文：我们在控制回路里避免阻塞调用。
- 易错：block 读 /blɑːk/，不是 "bloc"；call 读 /kɔːl/。

### 35. polling /ˈpoʊlɪŋ/ *n.* 轮询
- 搭配：poll the sensor
- 例句：Polling checks a flag in a loop, while an interrupt reacts to the event.
  - 中文：轮询在循环里查标志位，而中断对事件做出反应。
- 易错：poll 读 /poʊl/，不是 "pole" 以外的音。

### 36. debounce /diːˈbaʊns/ *v.* 消抖
- 搭配：debounce the switch
- 例句：We debounce the signal so that a noisy edge counts only once.
  - 中文：我们对信号消抖，使带噪的边沿只计一次。
- 易错：重音在 -BOUNCE。

### 37. brownout /ˈbraʊnaʊt/ *n.* 欠压掉电
- 搭配：a brownout reset
- 例句：A brownout reset happens when the supply voltage dips too low.
  - 中文：供电电压降得太低时会发生欠压复位。
- 易错：brown 读 /braʊn/，与 out 连读，重音在 BROWN-。

### 38. HAL (hardware abstraction layer) /hæl/ *n.* 硬件抽象层
- 搭配：use the HAL library
- 例句：The HAL library hides the register details of the STM32 peripherals.
  - 中文：HAL 库隐藏了 STM32 外设的寄存器细节。
- 易错：读作单词 "hal"。

### 39. bootloader /ˈbuːtloʊdər/ *n.* 引导程序
- 搭配：enter the bootloader
- 例句：The bootloader lets us update the firmware over a cable.
  - 中文：引导程序让我们通过线缆更新固件。
- 易错：boot 读 /buːt/，不是 "but"；loader 读 /ˈloʊdər/。

### 40. flash memory /flæʃ ˈmeməri/ *n.* 闪存
- 搭配：store parameters in flash
- 例句：Calibration values are stored in flash memory so they survive a power cycle.
  - 中文：标定值存放在闪存里，断电后不会丢失。
- 易错：memory 读三个音节 /ˈmeməri/。

## 3. 总线与通信

### 41. CAN (controller area network) /kæn/ *n.* CAN 总线
- 搭配：CAN bus / CAN frame
- 例句：The motors and the controller talk over a CAN bus.
  - 中文：电机和控制器通过 CAN 总线通信。
- 易错：读作单词 "can"，不要逐字母读。

### 42. FDCAN /ˌef diː ˈkæn/ *n.* 灵活数据速率 CAN 外设
- 搭配：an FDCAN peripheral
- 例句：On the STM32H7, the FDCAN peripheral can also run in classic CAN mode.
  - 中文：在 STM32H7 上，FDCAN 外设也可以工作在经典 CAN 模式。
- 易错：读 "F-D-CAN"。

### 43. SocketCAN /ˈsɑːkɪt kæn/ *n.* Linux 的 CAN 接口
- 搭配：bring up can0 with SocketCAN
- 例句：On Linux, SocketCAN presents a CAN device as a network interface.
  - 中文：在 Linux 上，SocketCAN 把 CAN 设备呈现为网络接口。
- 易错：Socket 读 /ˈsɑːkɪt/。

### 44. bus /bʌs/ *n.* 总线
- 搭配：a shared bus
- 例句：Several devices share one bus, so the bus load must be kept low.
  - 中文：多个设备共用一条总线，所以总线负载必须保持较低。
- 易错：bus 读 /bʌs/，复数 buses。

### 45. bus load /bʌs loʊd/ *n.* 总线负载
- 搭配：keep the bus load below 50 percent
- 例句：We estimated the bus load from the frame size and the frame rate.
  - 中文：我们根据帧长度和帧率估算总线负载。
- 易错：load 读 /loʊd/，d 要发；不要读成 "road"，l 与 r 要分清。

### 46. bit rate /bɪt reɪt/ *n.* 位速率
- 搭配：a bit rate of 1 Mbit/s
- 例句：Both ends of the CAN bus must use the same bit rate.
  - 中文：CAN 总线两端必须使用相同的位速率。
- 易错：bit 读 /bɪt/，rate 读 /reɪt/；bit 与 byte 不同，1 byte = 8 bits。

### 47. baud rate /bɔːd reɪt/ *n.* 波特率
- 搭配：set the baud rate
- 例句：The UART link between the two boards runs at a fixed baud rate.
  - 中文：两块板之间的 UART 链路以固定的波特率运行。
- 易错：baud 读 /bɔːd/，不读 "bode" 或 "bowed"。

### 48. frame /freɪm/ *n.* 帧（通信）
- 搭配：a CAN frame / frame ID
- 例句：A classic CAN frame carries up to eight bytes of data.
  - 中文：经典 CAN 帧最多携带八个字节数据。
- 易错：通信里的 frame 与坐标系的 frame 同形不同义，要看上下文。

### 49. identifier /aɪˈdentɪfaɪər/ *n.* 标识符（ID）
- 搭配：an 11-bit identifier
- 例句：The identifier tells which message a CAN frame carries and what its priority is.
  - 中文：标识符说明 CAN 帧携带哪条消息，以及它的优先级。
- 易错：重音在 -DEN-。

### 50. payload /ˈpeɪloʊd/ *n.* 有效载荷
- 搭配：an eight-byte payload
- 例句：The payload of a frame holds the actual command or feedback values.
  - 中文：帧的有效载荷放的是实际的指令或反馈值。
- 易错：payload 还指机器人的负载，上下文区分。

### 51. arbitration /ˌɑːrbɪˈtreɪʃən/ *n.* 仲裁
- 搭配：CAN arbitration
- 例句：On a CAN bus, arbitration lets the frame with the lowest identifier win.
  - 中文：在 CAN 总线上，仲裁让标识符最小的帧获胜。
- 易错：重音在 -TRA-。

### 52. CRC (cyclic redundancy check) /ˌsiː ɑːr ˈsiː/ *n.* 循环冗余校验
- 搭配：append a CRC
- 例句：A CRC at the end of each frame lets the receiver detect corrupted data.
  - 中文：每帧末尾的 CRC 让接收方能发现损坏的数据。
- 易错：读 C-R-C。

### 53. checksum /ˈtʃeksʌm/ *n.* 校验和
- 搭配：compute a checksum
- 例句：A checksum is a simple way to check that the message arrived intact.
  - 中文：校验和是检查消息完整到达的简单方法。
- 易错：check 读 /tʃek/。

### 54. termination resistor /ˌtɜːrmɪˈneɪʃən rɪˈzɪstər/ *n.* 终端电阻
- 搭配：a 120 ohm termination
- 例句：A 120 ohm termination resistor at each end of the CAN bus prevents signal reflections.
  - 中文：CAN 总线两端各一个 120 欧终端电阻，防止信号反射。
- 易错：resistor 重音在 -SIS-。

### 55. differential signal /ˌdɪfəˈrenʃəl ˈsɪɡnəl/ *n.* 差分信号
- 搭配：CAN high and CAN low
- 例句：CAN uses a differential signal on two wires, which resists noise.
  - 中文：CAN 在两根线上用差分信号，抗噪声。

## 5. 小练习：用这些词说一段话

**任务**：不看稿，用 8 个以上本表词汇，说一段关于 P3 或 P7 嵌入式链路的 45 秒介绍。参考版本如下，先读、再遮住自己改写。

> The control software runs on an STM32 microcontroller under FreeRTOS. Each loop is a task with its own priority: the IMU task has the highest priority, then the control task, then communication. The motors are connected over a CAN bus, and each frame carries a short payload with the command or the feedback. If a feedback frame does not arrive before the timeout, the corresponding mechanism goes to a safe state with zero output.
>
> 中文：控制软件在 FreeRTOS 下运行于 STM32 微控制器。每个回路是一个有自己优先级的任务：IMU 任务优先级最高，其次是控制任务，再是通信。电机通过 CAN 总线连接，每帧带一个很短的有效载荷，装着指令或反馈。如果反馈帧在超时前没到，对应机构就进入输出为零的安全状态。

## 本章要点速记

1. 微控制器上的实时系统：task 有 priority，scheduler 决定谁先运行，interrupt 要短。
2. mutex 保护共享数据，semaphore 用来通知；race condition 与 deadlock 是常见 bug。
3. CAN 靠 identifier 仲裁，帧最多 8 字节（经典 CAN），两端各一个 120 Ω 终端电阻。
4. FDCAN 是外设名，可以工作在经典 CAN 模式；不要把它和“CAN FD 数据段提速”混为一谈。
5. baud rate 是符号速率，bit rate 是比特速率；口语里常混用，面试里用 bit rate 更稳。
6. timeout、watchdog、heartbeat、safe state 是安全兜底的四个词。
7. TCP 是字节流，要自己处理 framing 和 sticky packet；协议要有 header、length、CRC。
8. ROS 2 的 QoS：命令话题 best effort + depth 1，状态话题 reliable。
9. P6 的核心句：device discovery, capability registration, state synchronisation, task dispatch, policy check。

## 自测题

1. baud rate 与 bit rate 的区别？答：baud 是每秒符号数，bit rate 是每秒比特数；二值信号时二者相等。
2. mutex 与 semaphore 有什么区别？答：mutex 用于互斥访问共享资源（有持有者）；semaphore 更多用于事件通知或计数资源。
3. 请用英文解释 watchdog。参考：A watchdog resets the system or forces a safe output if the software stops feeding it in time.
4. 怎么读 STM32H7？答：S-T-M thirty-two H seven。
5. idempotent 的意思是什么？答：同一命令执行多次与执行一次结果相同；对重传机制很重要。
