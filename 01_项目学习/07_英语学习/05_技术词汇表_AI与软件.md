## 1. 使用说明

- 音标采用国际音标（IPA），以美式发音为主；`ˈ` 标主重音，`ˌ` 标次重音，`ə` 是弱读元音（像 about 里的 a）。
- 词性缩写：*n.* 名词，*v.* 动词，*adj.* 形容词，*adv.* 副词。
- 每个词条固定五行：词头（英文、音标、词性、中文）→ 搭配 → 例句 → 中文译文 → 易错读音或易混点。
- 例句都与 CV 中的项目一致；需要数字时只写 about / roughly 这类量级措辞，具体设计取值以各项目 README 的「实机细节自查表」为准。
- 学习顺序：先看英文与中文，再读音标，最后把例句大声读三遍，遮住英文看中文回译。每天 15–20 个词即可，不要一次读完。

## 2. 深度学习与视觉基础

### 1. machine learning /məˈʃiːn ˈlɜːrnɪŋ/ *n.* 机器学习
- 搭配：a machine learning model
- 例句：My experience in machine learning is mostly practical, and I want to build the theory.
  - 中文：我在机器学习上的经验以实践为主，我想补上理论。
- 易错：machine 里的 ch 读 /ʃ/。

### 2. deep learning /diːp ˈlɜːrnɪŋ/ *n.* 深度学习
- 搭配：deep learning for vision
- 例句：Deep learning models learn features from data instead of using hand-written rules.
  - 中文：深度学习模型从数据中学习特征，而不是用手写规则。
- 易错：deep 读 /diːp/ 长元音，不是 "dip"；learning 里 ear 读 /ɜːr/。

### 3. neural network /ˈnʊrəl ˈnetwɜːrk/ *n.* 神经网络
- 搭配：a convolutional neural network
- 例句：A neural network is a stack of layers that transform the input step by step.
  - 中文：神经网络是一叠逐步变换输入的层。
- 易错：neural 读 /ˈnʊrəl/。

### 4. layer /ˈleɪər/ *n.* 层
- 搭配：a hidden layer
- 例句：Each layer takes the output of the previous layer as its input.
  - 中文：每一层以前一层的输出作为输入。
- 易错：layer 读 /ˈleɪər/，像 "lay-er"。

### 5. weights /weɪts/ *n.* 权重
- 搭配：pretrained weights
- 例句：We start from pretrained weights and fine-tune them on our own images.
  - 中文：我们从预训练权重出发，在自己的图像上微调。
- 易错：weights 与 waits 同音。

### 6. activation function /ˌæktɪˈveɪʃən ˈfʌŋkʃən/ *n.* 激活函数
- 搭配：a ReLU activation
- 例句：An activation function adds the nonlinearity that makes a network expressive.
  - 中文：激活函数引入非线性，使网络有表达能力。
- 易错：重音在 -VA-。

### 7. convolution /ˌkɑːnvəˈluːʃən/ *n.* 卷积
- 搭配：a convolution layer
- 例句：A convolution layer slides a small filter over the image to detect local patterns.
  - 中文：卷积层让小滤波器在图像上滑动，检测局部模式。
- 易错：重音在 -LU-。

### 8. backbone /ˈbækboʊn/ *n.* 主干网络
- 搭配：the backbone network
- 例句：The backbone extracts features, and the head predicts the boxes.
  - 中文：主干网络提取特征，检测头预测框。
- 易错：重音在 BACK-。

### 9. feature /ˈfiːtʃər/ *n.* 特征
- 搭配：feature map
- 例句：The early layers extract simple features such as edges.
  - 中文：前几层提取边缘之类的简单特征。
- 易错：重音在 FEA-，/ˈfiːtʃər/；-ture 读 /tʃər/。

### 10. training /ˈtreɪnɪŋ/ *n.* 训练
- 搭配：training data / train a model
- 例句：We trained the detector on a PC with a GPU, not on the board.
  - 中文：我们在带 GPU 的电脑上训练检测器，而不是在板子上。
- 易错：train 读 /treɪn/，-ing 要发；注意 training（训练）与 trading（交易）区分。

### 11. fine-tuning /faɪn ˈtuːnɪŋ/ *n.* 微调
- 搭配：fine-tune a pretrained model
- 例句：Fine-tuning a pretrained model needs far fewer images than training from scratch.
  - 中文：微调预训练模型所需图像比从头训练少得多。
- 易错：fine 读 /faɪn/，tuning 读 /ˈtuːnɪŋ/；不是 "fine-turning"。

### 12. dataset /ˈdeɪtəset/ *n.* 数据集
- 搭配：build a dataset
- 例句：We collected our own dataset of plant leaf images.
  - 中文：我们自己采集了一套植物叶片图像数据集。
- 易错：重音在 DA-。

### 13. annotation /ˌænəˈteɪʃən/ *n.* 标注
- 搭配：annotate the images
- 例句：Annotation means drawing a box around each object and giving it a label.
  - 中文：标注就是给每个物体画框并给出标签。
- 易错：重音在 -TA-；动词 annotate。

### 14. label /ˈleɪbəl/ *n.* 标签
- 搭配：class label
- 例句：Each box has a class label such as normal or wilting.
  - 中文：每个框有一个类别标签，比如 normal 或 wilting。
- 易错：重音在 LA-，/ˈleɪbəl/；不要读成 "la-BEL"。

### 15. epoch /ˈepək/ *n.* 训练轮次
- 搭配：train for 100 epochs
- 例句：One epoch is one full pass over the training set.
  - 中文：一个 epoch 是对训练集完整过一遍。
- 易错：读 /ˈepək/，美式也可读 /ˈiːpɑːk/。

### 16. batch size /bætʃ saɪz/ *n.* 批大小
- 搭配：a batch size of 16
- 例句：A larger batch size gives smoother gradients but needs more memory.
  - 中文：批大小越大，梯度越平滑，但需要更多显存。
- 易错：batch 读 /bætʃ/。

### 17. loss function /lɔːs ˈfʌŋkʃən/ *n.* 损失函数
- 搭配：minimise the loss
- 例句：The loss function measures how wrong the predictions are.
  - 中文：损失函数衡量预测有多错。
- 易错：loss 读 /lɔːs/。

### 18. gradient descent /ˈɡreɪdiənt dɪˈsent/ *n.* 梯度下降
- 搭配：stochastic gradient descent
- 例句：Gradient descent updates the weights in the direction that reduces the loss.
  - 中文：梯度下降沿着降低损失的方向更新权重。
- 易错：gradient 读 /ˈɡreɪdiənt/。

### 19. learning rate /ˈlɜːrnɪŋ reɪt/ *n.* 学习率
- 搭配：lower the learning rate
- 例句：A learning rate that is too high makes the loss oscillate.
  - 中文：学习率太高会使损失振荡。
- 易错：learning 的 -ear- 读 /ɜːr/；rate 读 /reɪt/，不是 "rat"。

### 20. overfitting /ˌoʊvərˈfɪtɪŋ/ *n.* 过拟合
- 搭配：avoid overfitting
- 例句：Overfitting means the model memorises the training images and fails on new ones.
  - 中文：过拟合指模型记住了训练图像，在新图像上失败。
- 易错：重音在 -FIT-。

### 21. generalisation /ˌdʒenrəlaɪˈzeɪʃən/ *n.* 泛化
- 搭配：generalise to new scenes
- 例句：Generalisation is how well the model works on data it has not seen.
  - 中文：泛化是模型在没见过的数据上的表现。
- 易错：美式 generalization。

### 22. validation set /ˌvælɪˈdeɪʃən set/ *n.* 验证集
- 搭配：evaluate on the validation set
- 例句：We split the images into a training set and a validation set at a ratio of eight to two.
  - 中文：我们把图像按八比二划分成训练集和验证集。
- 易错：重音在 -DA-。

### 23. augmentation /ˌɔːɡmenˈteɪʃən/ *n.* 数据增强
- 搭配：data augmentation
- 例句：Data augmentation flips, crops and re-colours the images to make the model more robust.
  - 中文：数据增强通过翻转、裁剪和变色让模型更鲁棒。
- 易错：重音在 -TA-。

### 24. object detection /ˈɑːbdʒekt dɪˈtekʃən/ *n.* 目标检测
- 搭配：an object detector
- 例句：Object detection finds what is in the image and where it is.
  - 中文：目标检测找出图像里有什么、在哪里。
- 易错：名词 object 重音在 OB-。

### 25. YOLO /ˈjoʊloʊ/ *n.* YOLO 检测算法
- 搭配：YOLOv5
- 例句：YOLO predicts boxes and classes in a single forward pass, which makes it fast.
  - 中文：YOLO 一次前向传播就预测框和类别，所以很快。
- 易错：读 /ˈjoʊloʊ/，像 "yo-lo"。

### 26. bounding box /ˈbaʊndɪŋ bɑːks/ *n.* 边界框
- 搭配：draw a bounding box
- 例句：Each detection is a bounding box with a class and a confidence score.
  - 中文：每个检测结果是一个带类别和置信度的边界框。
- 易错：bounding 读 /ˈbaʊndɪŋ/。

### 27. confidence /ˈkɑːnfɪdəns/ *n.* 置信度
- 搭配：a confidence threshold
- 例句：The confidence score says how sure the model is about a detection.
  - 中文：置信度表示模型对一次检测有多确定。
- 易错：重音在 CON-。

### 28. threshold /ˈθreʃhoʊld/ *n.* 阈值
- 搭配：set a threshold
- 例句：We keep only detections whose confidence is above the threshold.
  - 中文：我们只保留置信度高于阈值的检测。
- 易错：th 读 /θ/，h 要发。

### 29. IoU (intersection over union) /ˌaɪ oʊ ˈjuː/ *n.* 交并比
- 搭配：an IoU threshold
- 例句：IoU measures how much a predicted box overlaps the ground-truth box.
  - 中文：IoU 衡量预测框与真值框重叠多少。
- 易错：读 I-O-U。

### 30. NMS (non-maximum suppression) /ˌen em ˈes/ *n.* 非极大值抑制
- 搭配：apply NMS
- 例句：NMS removes duplicate boxes that cover the same object.
  - 中文：NMS 去掉覆盖同一物体的重复框。
- 易错：读 N-M-S。

### 31. anchor box /ˈæŋkər bɑːks/ *n.* 锚框
- 搭配：anchor sizes
- 例句：Anchor boxes are prior shapes that the network adjusts to fit each object.
  - 中文：锚框是网络用来调整贴合物体的先验形状。
- 易错：anchor 读 /ˈæŋkər/。

### 32. precision (metric) /prɪˈsɪʒən/ *n.* 精确率
- 搭配：high precision
- 例句：Precision is the share of detections that are correct.
  - 中文：精确率是检测结果中正确的比例。
- 易错：在检测里不是“精度”，是 TP/(TP+FP)。

### 33. recall /ˈriːkɔːl/ *n.* 召回率
- 搭配：improve recall
- 例句：Recall is the share of real objects that the model finds.
  - 中文：召回率是真实物体中被模型找到的比例。
- 易错：名词重音在 RE-，动词 recall /rɪˈkɔːl/。

### 34. mAP /ˌem eɪ ˈpiː/ *n.* 平均精度均值
- 搭配：mAP at IoU 0.5
- 例句：The mAP summarises precision and recall over all classes in a single number.
  - 中文：mAP 把所有类别的精确率和召回率概括成一个数。
- 易错：读 "M-A-P" 或 "mean average precision"。

### 35. false positive /fɔːls ˈpɑːzətɪv/ *n.* 误检
- 搭配：reduce false positives
- 例句：A false positive is a detection of something that is not there.
  - 中文：误检是检测出了并不存在的东西。
- 易错：false 读 /fɔːls/，结尾 s 清音；positive 重音在 POS-。

### 36. false negative /fɔːls ˈneɡətɪv/ *n.* 漏检
- 搭配：a false negative
- 例句：A false negative is a real object that the model misses.
  - 中文：漏检是模型没找到的真实物体。
- 易错：negative 重音在 NEG-，/ˈneɡətɪv/；注意 g 是硬 g。

### 37. ground truth /ɡraʊnd truːθ/ *n.* 真值
- 搭配：compare with the ground truth
- 例句：We compare each prediction with the ground truth to compute the metrics.
  - 中文：我们把每个预测与真值比较来计算指标。
- 易错：truth 读 /truːθ/。

## 3. 边缘推理与量化

### 38. edge inference /edʒ ˈɪnfərəns/ *n.* 边缘推理
- 搭配：run edge inference
- 例句：Edge inference runs the model on the device, close to the camera.
  - 中文：边缘推理在靠近摄像头的设备上运行模型。
- 易错：edge 读 /edʒ/。

### 39. inference /ˈɪnfərəns/ *n.* 推理
- 搭配：inference time
- 例句：Inference means using a trained model to make predictions.
  - 中文：推理指用训练好的模型做预测。
- 易错：重音在 IN-，不是 in-FER-ence。

### 40. quantisation /ˌkwɑːntɪˈzeɪʃən/ *n.* 量化（模型）
- 搭配：post-training quantisation
- 例句：Quantisation turns 32-bit floating point weights into 8-bit integers.
  - 中文：量化把 32 位浮点权重变成 8 位整数。
- 易错：美式 quantization。

### 41. INT8 /ɪnt eɪt/ *n.* 8 位整型
- 搭配：an INT8 model
- 例句：An INT8 model is smaller and faster but can lose some accuracy.
  - 中文：INT8 模型更小更快，但可能损失一点精度。
- 易错：读 "int eight"。

### 42. floating point /ˈfloʊtɪŋ pɔɪnt/ *n.* 浮点数
- 搭配：FP32
- 例句：The original model uses 32-bit floating point numbers.
  - 中文：原始模型使用 32 位浮点数。
- 易错：float 读 /floʊt/，注意 -ing 前 t 要发；缩写 FP32 读 "F-P thirty-two"。

### 43. calibration set /ˌkælɪˈbreɪʃən set/ *n.* 校准集
- 搭配：choose a calibration set
- 例句：The calibration set tells the quantiser the typical range of the activations.
  - 中文：校准集告诉量化器激活值的典型范围。
- 易错：calibration 重音在 -BRA-；set 读 /set/，不是 "sit"。

### 44. RKNN /ˌɑːr keɪ en ˈen/ *n.* 瑞芯微神经网络格式
- 搭配：convert to RKNN
- 例句：We converted the model to the RKNN format to run it on the NPU.
  - 中文：我们把模型转成 RKNN 格式，以便在 NPU 上运行。
- 易错：读 "R-K-N-N"。

### 45. toolkit /ˈtuːlkɪt/ *n.* 工具包
- 搭配：the RKNN toolkit
- 例句：The toolkit converts a trained model into a format the board can run.
  - 中文：工具包把训练好的模型转成板子能运行的格式。
- 易错：tool 读 /tuːl/ 长元音；kit 读 /kɪt/，不是 "kid"。

### 46. latency (vision) /ˈleɪtənsi/ *n.* 延迟
- 搭配：per-frame latency
- 例句：The per-frame latency of the NPU is only a part of the end-to-end delay.
  - 中文：NPU 的单帧延迟只是端到端延迟的一部分。
- 易错：与嵌入式的 latency 同一个词，重音在第一音节 LA-。

### 47. frame rate /freɪm reɪt/ *n.* 帧率
- 搭配：about 15 frames per second
- 例句：The frame rate is limited by the slowest stage of the pipeline.
  - 中文：帧率受流水线最慢环节限制。
- 易错：frame 读 /freɪm/，rate 读 /reɪt/；两个词都是长元音 /eɪ/。

### 48. FPS /ˌef piː ˈes/ *n.* 每秒帧数
- 搭配：15 FPS
- 例句：The pipeline runs at roughly 15 FPS on the board.
  - 中文：该流水线在板子上约跑 15 FPS。
- 易错：读 "F-P-S" 或 "frames per second"。

### 49. pipeline /ˈpaɪplaɪn/ *n.* 流水线
- 搭配：a vision pipeline
- 例句：The pipeline captures a frame, pre-processes it, runs the model and decodes the output.
  - 中文：流水线采集一帧、预处理、跑模型、解码输出。
- 易错：重音在 PIPE-，/ˈpaɪplaɪn/；两个 /aɪ/ 都是长元音。

### 50. preprocessing /ˌpriːˈproʊsesɪŋ/ *n.* 预处理
- 搭配：image preprocessing
- 例句：Preprocessing resizes the image and converts the colour order.
  - 中文：预处理缩放图像并转换颜色顺序。
- 易错：pre- 读 /priː/；process 此处美式 /ˈprɑːses/，英式 /ˈprəʊses/。

### 51. letterbox /ˈletərbɑːks/ *n.* 等比缩放加填边
- 搭配：apply letterbox
- 例句：Letterbox keeps the aspect ratio by padding the borders with grey.
  - 中文：letterbox 通过灰色填边保持长宽比。
- 易错：letter 读 /ˈletər/，美式 t 常闪音 /ˈledər/；box 读 /bɑːks/。

### 52. aspect ratio /ˈæspekt ˈreɪʃioʊ/ *n.* 长宽比
- 搭配：keep the aspect ratio
- 例句：If the aspect ratio changes, the boxes are distorted.
  - 中文：长宽比变了，框就会变形。
- 易错：aspect 重音在 AS-。

### 53. postprocessing /ˌpoʊstˈproʊsesɪŋ/ *n.* 后处理
- 搭配：decode and postprocess
- 例句：Postprocessing decodes the raw tensors into boxes, scores and classes.
  - 中文：后处理把原始张量解码成框、分数和类别。
- 易错：post- 读 /poʊst/，st 要发；其余同 preprocessing。

### 54. tensor /ˈtensər/ *n.* 张量
- 搭配：an output tensor
- 例句：The network outputs three tensors, one for each detection head.
  - 中文：网络输出三个张量，每个检测头一个。
- 易错：重音在 TEN-。

### 55. structured observation /ˈstrʌktʃərd ˌɑːbzərˈveɪʃən/ *n.* 结构化观测
- 搭配：publish structured observations
- 例句：A structured observation has a class, a confidence and a timestamp.
  - 中文：结构化观测包含类别、置信度和时间戳。
- 易错：structured 读 /ˈstrʌktʃərd/ 三个辅音连读；observation 重音在 -VA-。

### 56. event gate /ɪˈvent ɡeɪt/ *n.* 事件门限
- 搭配：require three consecutive frames

## 本章要点速记

1. training 在 PC 的 GPU 上，inference 在边缘设备上；二者是不同阶段。
2. precision = 检出的里有多少是对的；recall = 真实的里有多少被找到；mAP 把两者按类别汇总。
3. NMS 去重复框，IoU 衡量框重叠，confidence 与 threshold 决定留不留。
4. quantisation 把 FP32 变 INT8，需要 calibration set，会带来小幅 accuracy drop。
5. LLM 只提出 recommendation 或 constrained request，必须通过 whitelist 与 policy check。
6. rule-based fast path 处理极端状态，不等模型；LLM 超时则 fallback。
7. asyncio 靠 event loop 和 coroutine 在一个线程里处理多连接；bounded queue 防止内存被撑爆。
8. 调试四步：reproduce、log、root cause、regression test。
9. 重音易错：inference（IN-）、hallucination（-NA-）、asynchronous（-SYN-）、reproducible（-DU-）。

## 自测题

1. precision 与 recall 的区别？答：precision 看检出的结果里对的比例；recall 看真实物体里找到的比例。
2. training 与 inference 的区别？答：training 更新权重；inference 用固定权重做预测。
3. 为什么 LLM 的输出要有 schema 和 whitelist？答：让输出可校验、可限制，避免模型直接产生不受控的物理动作。
4. 怎么读 YOLOv5？答：YOLO version five，YOLO 读 /ˈjoʊloʊ/。
5. mutex 和 event loop 分别解决什么问题？答：mutex 解决多线程共享数据冲突；event loop 在单线程里调度协程。
