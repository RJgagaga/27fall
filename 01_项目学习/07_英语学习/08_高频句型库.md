# 高频句型库：开场、过渡、解释、举例、承认不会、澄清、争取时间、总结

> **一句话定位**：这是面试里“拿来就能说”的句子仓库。共 220 句，按功能分成 12 类，每句都有中文译文和使用提示；前 9 类是通用口语功能句，后 3 类是技术面试万能句、项目讲述句和答题收尾句。目标是让你在紧张时不必现想语法，只要从仓库里取一句、换几个词。

**本章学完你能……**

- 为面试中的 12 种说话功能各准备 3–5 句可以脱口而出的句子；
- 用“句型 + 替换词”的方式，把同一个骨架用在七个项目上；
- 在听不懂、不会答、需要时间想的时候，用礼貌而不显得慌的句子应对；
- 把一个 90 秒回答拆成“开场—展开—举例—总结”四块，并给每块选句子。

**前置知识**：[01_面试英语基础语法与句型](./01_面试英语基础语法与句型.md) 里的时态与被动语态；已有的口语句型也可对照 [英文口语表达：技术词汇与句型](../04_面试准备/01_面试总指南/07_英文口语表达_技术词汇与句型.md)。

## 1. 使用方法

1. **一次只练一类**：每天选 1–2 类，每句大声读三遍，再遮住英文看中文回译。
2. **句子是骨架**：方括号 `[ ]` 里的内容是可替换位，例如 `[the tilt angle]` 可换成 `[the wheel speed]`。
3. **不要全背**：每类先记 3 句最顺口的，面试时只用这些；记得太多反而容易卡。
4. **和项目绑定**：学完一类后，立刻用 P1–P7 里的一个项目造 2 个新句子（参考 [13_项目口述逐句精讲](./13_项目口述逐句精讲.md)）。
5. 每句后面的“提示”说明适用场景，不是考点。

## 2. 开场与定位（A 类）

用于回答开头的第一句话。**先给结论，再展开**。

1. Let me start with the short answer: [it depends on the load]. — 先说简短答案：[取决于负载]。
2. The main idea is [to keep the tilt angle close to zero]. — 主要思路是[让倾角保持接近零]。
3. In one sentence, [I built a cascade controller for a ballbot]. — 一句话说，[我为一个 ballbot 做了级联控制器]。
4. I'll answer in three parts: the goal, the method, and the result. — 我分三部分回答：目标、方法、结果。
5. My role in this project was [balance control and on-robot tuning]. — 我在这个项目里的角色是[平衡控制和真机调参]。
6. This project was about [navigation for a car-like robot]. — 这个项目是关于[车式机器人的导航]。
7. The problem I was trying to solve was [pose jumps in localisation]. — 我要解决的问题是[定位里的位姿跳变]。
8. I worked on this for about [four months] during [an internship]. — 我在[实习]期间做了大约[四个月]。
9. Briefly, the system has three layers: [perception, decision and execution]. — 简单说，系统有三层：[感知、决策和执行]。
10. The reason I chose this method is [that it handles constraints directly]. — 我选这个方法的原因是[它能直接处理约束]。
11. Let me give you the big picture first, and then the details. — 我先讲整体图景，再讲细节。
12. That's a good question, and the answer has two sides. — 这个问题很好，答案有两个方面。
13. Yes, I did that myself, and here is how. — 是的，这是我自己做的，下面是怎么做的。
14. I was responsible for [the control loops], and a teammate handled [the vision]. — 我负责[控制回路]，队友负责[视觉]。
15. Simply put, [LQR chooses the gain that balances error against control effort]. — 简单说，[LQR 选择在误差和控制量之间取得平衡的增益]。
16. The key point is [timing consistency], not [the filter itself]. — 关键点是[时间一致性]，而不是[滤波器本身]。
17. If I had to summarise it in one line: [measure, estimate, control, protect]. — 如果让我用一行概括：[测量、估计、控制、保护]。
18. Thank you for the question. I'd like to explain it from [the physical side]. — 谢谢你的提问。我想从[物理角度]解释。
19. I can describe it at two levels: the intuition and the equations. — 我可以在两个层面描述：直觉和公式。
20. Let me set the context: [the robot has a dual-arm upper body]. — 我先交代背景：[机器人有双臂上半身]。

## 3. 过渡与结构（B 类）

用于在回答中间换话题，让面试官跟得上。

21. First, … Second, … Finally, … — 第一……第二……最后……
22. Let me move on to [the second part: the outer loop]. — 我接着讲[第二部分：外环]。
23. That brings me to [the safety design]. — 这就引到了[安全设计]。
24. Before I go into detail, let me draw a quick diagram. — 在讲细节之前，我先画个简图。
25. So far I have talked about [modelling]; now let me talk about [tuning]. — 到目前为止我讲了[建模]，现在讲[调参]。
26. Next, I'd like to explain [why we used a bounded reference]. — 接下来，我想解释[为什么用有界参考]。
27. On the other hand, [the integral term can wind up]. — 另一方面，[积分项可能饱和累积]。
28. Moving on to the results, [the drift dropped clearly]. — 接着讲结果，[漂移明显下降]。
29. Let me go back to your earlier question about [the sampling period]. — 让我回到你之前问的[采样周期]的问题。
30. In addition to that, [we added a watchdog]. — 除此之外，[我们加了看门狗]。
31. After that, [we ran the test on the real robot]. — 在那之后，[我们在真机上测试]。
32. Once that was done, [the next step was to tune the gains]. — 做完之后，[下一步是整定增益]。
33. At the same time, [the position loop runs more slowly]. — 同时，[位置环运行得更慢]。
34. As a result, [the command stays smooth]. — 结果是，[指令保持平滑]。
35. That is why [we separate the loops by bandwidth]. — 这就是为什么[我们按带宽分开各回路]。
36. Here is the structure of my answer: [problem, method, evidence]. — 我的回答结构是：[问题、方法、证据]。
37. To connect this with [the next project], [the same idea appears there]. — 为了和[下一个项目]联系起来，[同样的思想在那里也出现]。
38. Let me zoom in on [the estimation step]. — 让我放大讲[估计这一步]。
39. Apart from [the algorithm], there is [an engineering side]. — 除了[算法]，还有[工程方面]。
40. If I may add one more point, [the timestamps matter]. — 如果我可以再补充一点，[时间戳很重要]。

## 4. 解释原理（C 类）

用于把一个概念讲清楚。

41. [X] is a way to [reduce the effect of noise]. — [X]是一种[降低噪声影响]的方法。
42. You can think of [X] as [a spring and a damper]. — 你可以把[X]看成[弹簧加阻尼器]。
43. The idea is simple: [use the gyro for fast changes and the accelerometer for the slow trend]. — 思路很简单：[用陀螺看快变化，用加速度计看慢趋势]。
44. What [X] does is to [convert the target into a bounded reference]. — [X]做的是[把目标转成有界参考]。
45. In practice, [we limit the output so that it never exceeds the actuator range]. — 实际中，[我们限制输出，使其不超过执行器范围]。
46. The intuition is that [a large error needs a large correction, but not an infinite one]. — 直觉是[大误差需要大修正，但不能无限大]。
47. Mathematically, [it minimises a quadratic cost]. — 从数学上讲，[它最小化一个二次代价]。
48. The cost has two parts: [the state error and the control effort]. — 代价有两部分：[状态误差和控制量]。
49. A larger weight on [the tilt] means that [tilt errors are punished more]. — [倾角]的权重越大，意味着[倾角误差被惩罚得越重]。
50. The system is unstable by itself, so we need [active feedback]. — 系统本身不稳定，所以需要[主动反馈]。
51. The controller compares [the measurement] with [the reference] and corrects [the difference]. — 控制器比较[测量值]与[参考值]，并修正[差值]。
52. The inner loop is faster than the outer loop, which keeps them from fighting each other. — 内环比外环快，这样两者不会互相打架。
53. The output is allocated to [three wheels] through [the kinematics]. — 输出通过[运动学]分配给[三个轮子]。
54. In other words, [the robot learns where it is by matching the scan to the map]. — 换句话说，[机器人通过把扫描与地图匹配来知道自己在哪]。
55. To put it differently, [the controller never asks for more than the motor can give]. — 换种说法，[控制器要的从不超过电机能给的]。
56. The assumption here is that [the model is linear around the operating point]. — 这里的假设是[模型在工作点附近是线性的]。
57. This only holds when [the tilt angle is small]. — 这只在[倾角较小时]成立。
58. The trade-off is between [speed of response] and [sensitivity to noise]. — 权衡在于[响应速度]与[对噪声的敏感度]之间。
59. The limitation of this approach is that [it needs a good model]. — 这种方法的局限是[需要好的模型]。
60. Without [the feedforward term], [the feedback has to fight the load]. — 没有[前馈项]，[反馈就得去对抗负载]。
61. The estimate is only as good as [its timestamp]. — 估计的好坏取决于[它的时间戳]。
62. That is the difference between [a path and a trajectory]. — 这就是[路径和轨迹]的区别。
63. At each step, the controller solves [a small optimisation problem] and applies only [the first input]. — 每一步，控制器求解[一个小的优化问题]，只执行[第一个输入]。
64. The filter trusts [the model] when [the sensor is noisy]. — 传感器噪声大时，滤波器更信任[模型]。
65. Here, [stable] means that [the error decays to zero after a disturbance]. — 这里[稳定]指的是[受扰后误差衰减到零]。

## 5. 举例与类比（D 类）

66. For example, [when the arm moves forward, the centre of mass moves too]. — 例如，[手臂前伸时质心也跟着移动]。
67. A good example is [the re-enable overshoot]. — 一个好例子是[重新使能时的冲击]。
68. Take [the wheel speed loop] as an example. — 以[轮速环]为例。
69. For instance, [if the sensor is late by 60 ms, the scan is smeared]. — 比如，[如果传感器晚了 60 毫秒，扫描就会拖影]。
70. Imagine [balancing a broom on your hand]. — 想象[把一把扫帚立在手上]。

## 6. 因果、对比与转折（E 类）

81. Because [the loop was too slow], [the robot oscillated]. — 因为[回路太慢]，[机器人振荡了]。
82. Since [the data was old], [we marked it invalid]. — 由于[数据过期]，[我们把它标为无效]。
83. As a result of [the delay], [the phase margin dropped]. — 由于[延迟]，[相位裕度下降了]。
84. This is why [we limit the rate of change]. — 这就是为什么[我们限制变化率]。
85. That is the reason [the output was clipped]. — 这就是[输出被削波]的原因。
86. The cause was [a sign error in the feedforward]. — 原因是[前馈里的符号错误]。
87. The effect of [that change] was [a lower peak tilt]. — [那个改动]的效果是[倾角峰值更低]。
88. Therefore, [we moved the controller into the odom frame]. — 因此，[我们把控制器放进 odom 坐标系]。
89. So, [we tested at a low gain first]. — 所以，[我们先用低增益测试]。
90. This leads to [a smoother command]. — 这带来[更平滑的指令]。
91. However, [the integral term can wind up]. — 然而，[积分项可能饱和累积]。
92. On the one hand, [LQR is systematic]; on the other hand, [it needs a model]. — 一方面，[LQR 很系统]；另一方面，[它需要模型]。
93. Compared with [PID], [LQR makes the trade-off explicit]. — 与[PID]相比，[LQR 让权衡显式化]。
94. Unlike [EKF], [AMCL uses particles]. — 与[EKF]不同，[AMCL 使用粒子]。
95. While [Hybrid A* plans a global path], [TEB reacts to local obstacles]. — [Hybrid A* 规划全局路径]，而[TEB 应对局部障碍]。
96. In contrast, [the sliding-mode controller recovers faster]. — 相比之下，[滑模控制器恢复得更快]。
97. Although [the model was simple], [it explained the saturation]. — 虽然[模型简单]，[它解释了饱和]。
98. Even though [the gain looked fine in simulation], [it oscillated on the robot]. — 尽管[增益在仿真里看起来没问题]，[它在机器人上振荡了]。
99. Despite [the noise], [the estimate stayed continuous]. — 尽管有[噪声]，[估计保持连续]。
100. Instead of [using the old target], [the driver freezes at the current position]. — [驱动不使用旧目标]，而是[冻结在当前位置]。
101. Rather than [tuning blindly], [I used the model as a reference]. — 我没有[盲目调参]，而是[把模型当作参照]。
102. Otherwise, [the controller would ask for too much torque]. — 否则，[控制器会要求过大的力矩]。
103. If [the data age exceeds the threshold], then [the feedforward is switched off]. — 如果[数据年龄超过阈值]，那么[前馈被关闭]。
104. As long as [the tilt stays small], [the linear model is valid]. — 只要[倾角保持较小]，[线性模型就有效]。
105. Unless [the bus is overloaded], [the frames arrive on time]. — 除非[总线过载]，[帧就会按时到达]。

## 7. 承认不会与诚实回答（F 类）

诚实不丢分。关键是“承认 + 说清楚你知道的 + 说明怎么补”。

106. I'm not sure about the exact number, but it was on the order of [a few milliseconds]. — 确切数字我不太确定，但量级是[几毫秒]。
107. I don't have the exact figure in front of me, but I can tell you how I measured it. — 我手边没有确切数字，但可以告诉你我怎么测的。
108. That part was handled by a teammate, so I can only describe the interface I used. — 那部分是队友负责的，所以我只能讲我用到的接口。
109. I haven't studied that in depth yet, but my understanding is [that it adds a delay-aware term]. — 我还没深入学过，但我的理解是[它加入了考虑延迟的项]。
110. I used it in practice, but I haven't studied the full theory. — 我实践中用过，但没学过完整理论。
111. To be honest, I haven't tried that approach. — 老实说，我没试过那种方法。
112. I'm afraid I don't know the details of [that algorithm], but I can tell you what I do know. — 恐怕我不了解[那个算法]的细节，但可以说说我知道的。
113. I would need to check the data to give you a precise answer. — 我需要查数据才能给你精确答案。
114. I can't remember the exact parameter, but I remember the trend. — 我记不清确切参数，但记得趋势。
115. That is outside what I worked on, but I'd approach it by [looking at the logs first]. — 这超出我做过的范围，但我会[先看日志]来入手。
116. I don't want to guess, so let me say what I am sure about. — 我不想乱猜，所以说说我确定的部分。
117. My experience is mostly practical, and I'd like to strengthen the theory in the master's programme. — 我的经验以实践为主，希望在硕士阶段加强理论。
118. If I remember correctly, [the loop ran at about 100 Hz]. — 如果我没记错，[回路约 100 Hz]。
119. I may be wrong, but I think [the delay was around 15 ms]. — 我可能错了，但我认为[延迟约 15 毫秒]。
120. That is a limitation of my approach, and I would improve it by [adding an observer]. — 这是我方法的局限，我会通过[加观测器]来改进。
121. I didn't have time to test that, so I can't claim it works. — 我没来得及测试，所以不能说它有效。
122. That wasn't part of my role, but I understand the idea. — 那不在我的职责内，但我理解其思想。
123. It was a team effort, and my part was [the control loops]. — 这是团队工作，我的部分是[控制回路]。
124. I haven't measured that directly. What I measured was [the tilt peak]. — 那个我没有直接测过，我测的是[倾角峰值]。
125. Could I answer a related question I know better? — 我能回答一个我更熟悉的相关问题吗？

## 8. 澄清问题与确认理解（G 类）

126. Sorry, could you repeat the question, please? — 抱歉，能请你重复一下问题吗？
127. Could you say that a bit more slowly? — 能说慢一点吗？
128. Just to confirm, you are asking about [the inner loop], right? — 确认一下，你问的是[内环]，对吗？
129. Do you mean [the real robot] or [the simulation]? — 你指的是[真机]还是[仿真]？
130. When you say [stability], do you mean [the mathematical definition] or [the practical behaviour]? — 你说的[稳定性]，是指[数学定义]还是[实际表现]？
131. Let me make sure I understand: [you want the reason for the second loop]. — 我确认一下我的理解：[你想知道为什么要第二个回路]。
132. So the question is [how I handled the delay], correct? — 所以问题是[我怎么处理延迟]，对吗？
133. Could you give me an example of what you mean? — 你能举个例子说明你的意思吗？
134. Are you asking about [the theory] or [my implementation]? — 你问的是[理论]还是[我的实现]？
135. I'm sorry, I didn't catch the last word. — 抱歉，最后那个词我没听清。
136. Could you spell that term for me? — 能帮我拼一下这个术语吗？
137. Is that [A] or [B]? — 那是[A]还是[B]？
138. Which part would you like me to go into more? — 你希望我多讲哪一部分？
139. Would you like me to continue, or move to the next point? — 你希望我继续，还是进入下一点？
140. Does that answer your question? — 这回答了你的问题吗？
141. Shall I explain it with a diagram? — 我用图来解释好吗？
142. Is it okay if I take a moment to organise my thoughts? — 我可以花点时间整理思路吗？
143. Let me rephrase your question to check: [how does the controller avoid saturation]? — 我复述一下你的问题确认：[控制器怎么避免饱和]？
144. By "tuning", do you mean the offline analysis or the on-robot work? — 你说的“调参”是指离线分析还是真机工作？
145. Thanks, that's clear now. — 谢谢，现在清楚了。

150. Let me think about how to explain this clearly. — 让我想想怎么讲清楚。
151. I want to make sure I get this right. — 我想确保说对。
152. How should I put it? — 我该怎么说呢？
153. Let me come at this from a different angle. — 我换个角度来讲。
154. If I understand correctly, [the question is about the delay]. — 如果我理解对的话，[问题是关于延迟的]。
155. Well, there are a few things to consider. — 嗯，有几件事需要考虑。

157. Let me start with what I know best. — 让我从我最熟悉的讲起。
158. Just a second, I'd like to recall the details. — 稍等，我想回忆一下细节。
159. That depends on a few things; let me go through them. — 这取决于几件事，我逐一说。
160. Let me take it step by step. — 让我一步一步来。

## 10. 总结与收尾（I类）

161. To sum up, [the combination of feedback and feedforward gave a stable result]. — 总结一下，[反馈加前馈给出了稳定的结果]。
162. In short, [timing and frames mattered more than the filter]. — 简言之，[时间和坐标系比滤波器更重要]。
163. So the main takeaway is [to trust the data only when it is fresh and valid]. — 所以主要收获是[只在数据新鲜有效时才信任它]。
164. Overall, [the system balanced under arm motion]. — 总体来说，[系统在手臂运动下保持了平衡]。
165. The bottom line is [the controller never asks for more than the actuator can give]. — 底线是[控制器要求的从不超过执行器能给的]。
166. That's how I would summarise it. — 这就是我的总结。
167. I think that covers the main points. — 我想这涵盖了要点。
168. That is basically the whole chain, from [sensing] to [actuation]. — 这基本就是从[传感]到[执行]的整个链路。
169. If I had more time, I would [test it on uneven terrain]. — 如果有更多时间，我会[在不平整地形上测试]。
170. The next step would be [to add an observer for the missing state]. — 下一步是[为缺失的状态加观测器]。
171. What I learned from this project is [to check the basics first]. — 我从这个项目学到的是[先检查基础问题]。
172. This experience is why I want to study [robot learning] in your programme. — 这段经历是我想在贵项目学习[机器人学习]的原因。
173. I hope that answers your question. — 希望这回答了你的问题。
174. I'd be happy to go into more detail if you like. — 如果你愿意，我很乐意讲更多细节。
175. Please let me know if you would like an example. — 如果需要例子请告诉我。

## 11. 技术面试万能句（J类）

这一类句子不依赖具体项目，适用于任何控制、估计、嵌入式、软件问题。

176. The first thing I would check is [the sensor data and the timestamps]. — 我首先会检查[传感器数据和时间戳]。
177. I would start with a simple baseline and then improve it. — 我会先做一个简单基线，再改进。
178. I would test it in simulation first, and then on the robot at low gain. — 我会先在仿真里测试，然后在机器人上用低增益测试。
179. To debug this, I would reproduce the problem, log the key signals, and find the root cause. — 调试时我会复现问题、记录关键信号、找到根因。
180. The signals I would plot are [the reference, the measurement and the command]. — 我会画的信号是[参考、测量和指令]。
181. I would separate the problem into [estimation] and [control]. — 我会把问题分成[估计]和[控制]两部分。
182. I'd look at the saturation first, because it is a common cause. — 我会先看饱和，因为这是常见原因。
183. A sign error would be my first suspect. — 符号错误是我的第一怀疑对象。
184. I'd check the units and the frames before changing any gain. — 改任何增益之前，我会先检查单位和坐标系。
185. The trade-off here is between [accuracy] and [computation time]. — 这里的权衡在[精度]与[计算时间]之间。
186. A simple solution is [to add a low-pass filter], but it adds delay. — 简单方案是[加低通滤波]，但它会增加延迟。
187. To make it robust, I would add [limits, timeouts and a safe state]. — 为使其鲁棒，我会加[限幅、超时和安全状态]。
188. In practice, you always need [a margin]. — 实际上你总需要[余量]。
189. The model is a reference, not the truth. — 模型只是参照，不是真理。
190. We validated it by [toggling the compensation on and off]. — 我们通过[开关补偿]来验证。
191. The result was repeatable over [several runs]. — 结果在[多次运行]中可重复。
192. I would not claim that it is optimal, only that it works within [the tested range]. — 我不会说它是最优的，只说它在[测试范围]内有效。
193. This is a standard approach, and the details depend on the platform. — 这是标准做法，细节取决于平台。
194. You need to choose [the sampling period] carefully. — 你需要仔细选择[采样周期]。
195. The loop must be fast enough, but also deterministic. — 回路必须足够快，也要确定性。
196. The complexity grows with [the horizon length]. — 复杂度随[时域长度]增加。
197. From a safety point of view, [the output must be bounded]. — 从安全角度看，[输出必须有界]。
198. I would add a fallback in case [the model fails]. — 我会加一个回退，以防[模型失败]。
199. It is easier to debug if [every decision is logged]. — 如果[每个决策都有日志]，调试会容易得多。
200. The cleanest way to do it is [to hide the hardware behind one interface]. — 最干净的做法是[把硬件藏在一个接口后面]。

## 12. 项目讲述句与追问回应（K类）

201. I designed and deployed [a PID cascade] on [the real robot]. — 我在[真机]上设计并部署了[PID 级联]。
202. I modelled the system as [a linearised four-state inverted pendulum]. — 我把系统建模为[线性化的四状态倒立摆]。
203. I used LQR to analyse [the trade-off between stability and control effort]. — 我用 LQR 分析[稳定性和控制量之间的权衡]。
204. The model served as a reference for [PID tuning] and [saturation diagnosis]. — 该模型用作[PID 调参]和[饱和诊断]的参照。
205. I estimated [the centre-of-mass offset] from [the arm joint states]. — 我根据[手臂关节状态]估计了[质心偏移]。
206. I verified the effect by [toggling the compensation under a fixed trajectory]. — 我通过[在固定轨迹下开关补偿]来验证效果。
207. I integrated [ROS state processing] with [CAN motor execution]. — 我把[ROS 状态处理]与[CAN 电机执行]集成起来。
208. I implemented [state initialisation, output limiting and fall recovery]. — 我实现了[状态初始化、输出限幅和跌倒恢复]。
209. I scheduled the LQR gains by [leg length]. — 我按[腿长]调度 LQR 增益。
210. We traced the anomaly to [state inconsistency and torque limits]. — 我们把异常追溯到[状态不一致和力矩限制]。
211. I fused [the IMU, the wheel encoders and the 2D LiDAR]. — 我融合了[IMU、轮编码器和二维激光雷达]。
212. The hardest part was [the timing and frame consistency]. — 最难的部分是[时间和坐标系一致性]。
213. I built [a unified capability model] so that [motion code can be reused across hardware]. — 我建立了[统一能力模型]，使[运动代码能跨硬件复用]。
214. Every task plan must pass [an action proposal, a policy check, execution and state feedback]. — 每个任务计划必须经过[动作提案、策略校验、执行和状态回传]。
215. I iterated from [PID] to [variable-gain PID] to [sliding-mode control]. — 我从[PID]迭代到[变增益 PID]再到[滑模控制]。
216. I converted [the remote and vision targets] into [continuous attitude commands]. — 我把[遥控和视觉目标]转成[连续的姿态指令]。
217. The pump is controlled by [a state machine with independent start and stop thresholds]. — 水泵由[带独立启停阈值的状态机]控制。
218. The model can only suggest; [execution is gated by a whitelist]. — 模型只能建议，[执行由白名单把关]。
219. If you asked me to improve it, I would [add an estimator for the disturbance]. — 如果让我改进，我会[加一个扰动估计器]。
220. The numbers I gave are about the right order; the exact values come from the logs. — 我给的数字量级大致正确；确切值来自日志。

## 本章要点速记

1. 每个回答先给**一句结论**（A 类），再用 B 类过渡展开。
2. 解释概念用“idea → intuition → limitation”三步（C 类）。
3. 举例用 for example / take X as an example（D 类）。
4. 因果与转折是技术口语的骨架：because、so、however、compared with、instead of（E 类）。
5. 不会就说不会，但要补一句“我知道的部分”和“我会怎么查”（F 类）。
6. 没听懂就复述确认，比硬答更好（G 类）。
7. 卡壳时用 H 类拖一两秒，不要沉默超过三秒。
8. 收尾用 I 类，一句总结加一句延伸，不要把话讲到半空。
9. 万能句（J 类）适合任何追问；项目句（K 类）要换成自己的项目变量。

## 自测题

1. 用 A 类句型，把 P3 的“发射机构控制”回答成 20 秒的开场。
2. 面试官问“你的延迟是多少？”，你只记得量级。用 F 类写出两句诚实回答。
3. 把“因为数据过期，所以我们关闭了前馈”用 E 类句型说成两个不同的英文句子。
4. 用 B 类写一句从“估计”过渡到“控制”的句子。
5. 用 I 类给 P5 导航写一句总结，加一句“下一步改进”。
