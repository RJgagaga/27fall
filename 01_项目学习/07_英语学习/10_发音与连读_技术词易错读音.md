## 1. 音标与重音符号：最小读法说明

### 1.1 本教材音标约定

- 采用美式 IPA；`ˈ` 标主重音（放在重读音节前），`ˌ` 标次重音。
- 斜线 `/ /` 内是音标，例：`/kənˈtroʊlər/`。
- `ə` 是弱读元音（schwa），比如 about 的 a、controller 的 con-。
- `ː` 表示长元音：`/iː/` 比 `/ɪ/` 长。

### 1.2 最常用的 20 个音

| 音标 | 例词 | 说明 |
|---|---|---|
| /iː/ | feed, speed, steer | 长 i，嘴角向两边 |
| /ɪ/ | bit, limit, sit | 短 i，放松 |
| /e/ | set, test, error | 嘴稍开 |
| /æ/ | task, gap, scan | 嘴张大，像“啊”和“诶”之间（matrix 的 a 读 /eɪ/，不是 /æ/） |
| /ɑː/ | model, probe | 嘴张大，后部 |
| /ʌ/ | bus, jump, current | 短促的“啊” |
| /ə/ | about, system 的 -em | 最放松的元音 |
| /ɜːr/ | learn, work, turn, current | 卷舌的“呃” |
| /ɔː/ | torque 的 /ɔːr/, law | 圆唇 |
| /uː/ | tool, loop, move | 长 u |
| /ʊ/ | foot, put | 短 u |
| /eɪ/ | gain, rate, state | 双元音，从 e 滑向 i |
| /aɪ/ | gyro, pipeline, bias | 双元音 |
| /ɔɪ/ | noise, point, joint | 双元音 |
| /aʊ/ | out, bound, round | 双元音 |
| /oʊ/ | roll, load, pose | 双元音，圆唇 |
| /θ/ | thread, path, length | 咬舌轻音 |

| /ʒ/ | measure, fusion, decision | 浊的“舒” |

## 2. 重音规则：词尾决定重音

英语单词的重音位置，80% 可以用词尾预测。**掌握这一节，比背单词读音更省时间。**

### 2.1 六条规则

| 词尾 | 重音位置 | 例词（技术） | 记忆 |
|---|---|---|---|
| -tion, -sion | 倒数第二个音节（-tion 前一个音节） | estiˈMAtion, preˈDICtion, deˈCIsion | 重音在 -tion 前（两音节词如 FUNCtion、FUsion 重音在前） |
| -ity | -ity 前一个音节 | staˈBILity, veˈLOCity, capaˈBILity | 重音在 -ity 前 |
| -ic, -ical | -ic 前一个音节 | kineˈMATic, dyˈNAMic, ˈdynamical | 重音在 -ic 前 |
| -ate（动词） | 倒数第三个音节 | ˈCALibrate, ˈESTimate, ˈINTegrate | 重音往前移 |
| -ize / -ise | 倒数第三个音节 | ˈLINearise, ˈOPtimise | 往前移 |
| -ical / -ically | -ic- 前一个 | asympˈTOTically | 同 -ic |

### 2.2 规则应用示范

- **-tion**：automation → autoˈMAtion；calibration → caliˈBRAtion；quantisation → quantiˈSAtion。
- **-ity**：stability → staˈBILity；controllability → controllaˈBILity；observability → observaˈBILity。
- **-ic**：kinematic → kineˈMATic；asymptotic → asympˈTOTic；economic → ecoˈNOMic。
- **-ate 动词**：estimate → ˈESTimate；calibrate → ˈCALibrate；integrate → ˈINTegrate。
- **-ize 动词**：linearize → ˈLINearize；optimize → ˈOPtimize；stabilize → ˈSTAbilize。

### 2.3 常见例外

| 词 | 重音 | 备注 |
|---|---|---|
| function | ˈFUNCtion | 重音在第一音节，不是 -tion 前一个字母规则（因为只有两个音节） |
| competition | competiˈTIon | 规则适用 |
| decision | deˈCIsion | -sion，规则适用 |
| television | ˈTELevision | 例外 |
| advertisement | adˈVERtisement | 英式；美式 ˌædvərˈtaɪzmənt |
| economy | eˈCONomy | 重音在第二音节 |

### 2.4 复合名词与复合动词

1. **名词复合词**：重音在第一个词：ˈBLACKboard，ˈFEEDback，ˈFEEDforward，ˈCASCADE controller，ˈLAUNCHER，ˈGIMbal。
2. **动词短语**：重音落在后面的小品词：give ˈUP，set ˈUP，turn ˈOFF；但对应名词重音前移：a ˈSETup，a ˈTAKEoff。
3. **形容词+名词**（不是复合词）：两个词都有重音，后一个更强：a good ˈmodel；a fast ˈloop。

## 7. 难辅音：th、r/l、v/w、-ed、-s

### 7.1 th：/θ/ 与 /ð/

- **/θ/（清）**：舌尖轻咬上齿，送气，不发声：thread，path，length，math，three，throughput，threshold /ˈθreʃhoʊld/。
- **/ð/（浊）**：同一位置，声带振动：the，this，smooth，rather，with。
- **常见错误**：把 th 读成 s（thread → “sread”）或 z。用镜子练：舌尖要看到。

### 7.2 r 与 l

- **r**：舌尖后卷但不碰上颚，嘴唇略圆：error，robot，rotation。
- **l**：舌尖顶上齿龈：load，loop，limit，roll。
- **对比练习**：load–road，light–right，lock–rock，collect–correct。
- 词尾 l：roll，control，model：舌尖顶上颚，不要省略。

### 7.3 v 与 w

- **v**：上齿咬下唇：velocity，version，virtual，value。
- **w**：双唇圆撮，不咬唇：wheel，weight，wait，wide。
- **对比**：vest–west，very–wary，vine–wine。
- **常见错误**：把 velocity 读成 “welocity”。

### 7.4 -ed 的三种读法

| 词尾发音 | 条件 | 例词 |
|---|---|---|
| /t/ | 前面是清辅音（p, k, f, s, ʃ, tʃ） | checked /tʃekt/，stopped /stɑːpt/，fixed /fɪkst/，mapped /mæpt/ |
| /d/ | 前面是浊辅音或元音 | tuned /tuːnd/，filtered /ˈfɪltərd/，controlled /kənˈtroʊld/，designed /dɪˈzaɪnd/ |
| /ɪd/ | 前面是 t 或 d | limited /ˈlɪmɪtɪd/，needed /ˈniːdɪd/，integrated /ˈɪntɪɡreɪtɪd/，adapted /əˈdæptɪd/ |

> **提示**：最常见的错误是**把所有 -ed 都读成 “id”**。tuned 是一个音节，**不是 “tu-ned”**。

### 7.5 -s 的三种读法

| 读音 | 条件 | 例词 |
|---|---|---|
| /s/ | 前面是清辅音（p, t, k, f） | maps /mæps/，sets /sets/，tests /tests/，lengths /leŋkθs/ |
| /z/ | 前面是浊辅音或元音 | gains /ɡeɪnz/，filters /ˈfɪltərz/，errors /ˈerərz/，poles /poʊlz/ |
| /ɪz/ | 前面是 s, z, ʃ, ʒ, tʃ, dʒ | matrices /ˈmeɪtrɪsiːz/，devices /dɪˈvaɪsɪz/，processes /ˈprɑːsesɪz/，switches /ˈswɪtʃɪz/ |

### 7.6 词尾爆破音不要丢

中国学生常把词尾 t/d/k/p 丢掉。需要清晰的词尾：**limit，output，input，target，speed，send，checked，peak，gap**。

## 8. 元音：长短对比

| 对比 | 例词 | 技术例句 |
|---|---|---|
| /iː/ vs /ɪ/ | feed – fid；leave – live；speed – sip | The feed rate is fast. |
| /uː/ vs /ʊ/ | pool – pull；fool – full | The pull and the pool are different. |
| /æ/ vs /e/ | gap – get；sat – set | The gap in the set. |
| /ɑː/ vs /ʌ/ | model – mud；robot – rub | |
| /eɪ/ vs /e/ | gate – get；rate – wrecked | The gate and the rate. |
| /ɔː/ vs /oʊ/ | torque – toque；port – post | |

> **练习方法**：每对词各读 5 遍，录音，对比自己的长短是否有区别。

## 9. 连读、弱读与节奏

### 9.1 连读（linking）

- **辅音 + 元音**：把前面的辅音连到后面：stand up → “stan-dup”；check it → “che-ckit”；an IMU → “a-nIMU”。
- **项目例句**：
  - “The output is limited.” → “The out-put-is lim-i-ted.”
  - “It depends on the load.” → “It de-pen-dzon the load.”
  - “Send a command.” → “Sen-da command.”

### 9.2 弱读（reduction）

功能词在句中弱读：to /tə/，for /fər/，of /əv/，and /ən/，a /ə/，the /ðə/，can /kən/，that /ðət/。

| 完整形式 | 口语形式 | 例句 |
|---|---|---|
| to | /tə/ | I want to go → “I wanna go”（面试不建议） |
| for | /fər/ | It is for tuning. |
| of | /əv/ | A lot of noise. |
| can | /kən/ | We can reduce it. |
| can't | /kænt/ | We can't ignore it. |

> **注意**：can 弱读 /kən/，can't 读 /kænt/ 且重读。听上去的区别在于**元音**和**重音**，所以说否定时一定要强调。

### 9.3 失去爆破（unreleased stops）

两个爆破音相连时，前一个不爆破：

- “fast path” → “fas-path”；
- “next time” → “nex-time”；
- “stop sign”。

### 9.4 句子节奏：重读实词，弱读虚词

英语是**重音节拍**语言。内容词（名词、动词、形容词、副词）重读；功能词（冠词、介词、助动词）弱读。

例：`The CONtroller USES the IMU to ESTimate the TILT.`

**节奏练习**：用手打拍，每个大写音节一拍，保持拍子均匀；弱读音节要快速带过。

### 9.5 停顿与意群

每 5–8 个词停顿一下：

> I designed a PID cascade, // using the IMU and the wheel speeds as feedback, // with a position outer loop // and an attitude inner loop.

停顿处不要拖长；停顿可以代替“um”。

### 9.6 语调

- **陈述句**：降调。 “I used LQR for the analysis. ↘”
- **一般疑问句**：升调。 “Do you mean the real robot? ↗”
- **选择疑问**：前升后降。 “Is it the simulation ↗ or the real robot? ↘”
- **列举**：每项升，最后一项降。 “IMU ↗, encoders ↗, and LiDAR ↘.”

## 本章要点速记

1. 重音是第一优先：-tion/-sion 前、-ity 前、-ic 前，动词 -ate / -ize 往前。
2. 名词重音在前，动词在后：RECord / reCORD；UPdate / upDATE。
3. 缩略词两类：逐字母（PID、LQR、MPC、EKF、IMU、URDF）和当单词读（CAN、SLAM、UART、YOLO、JSON）。
4. FDCAN 读 F-D-CAN；UART 读 you-art；LiDAR 读 LIE-dar。
5. th 咬舌，r 卷舌，l 顶上颚，v 咬唇，w 圆唇。
6. -ed 三种读法：/t/、/d/、/ɪd/；-s 三种读法：/s/、/z/、/ɪz/。
7. 词尾 t/d/k/p 不要丢。
8. 实词重读、虚词弱读；意群之间停顿；陈述句降调。
9. 建立个人错词本，每周更新。

## 自测题

1. 说出 estimation、stability、kinematic、calibrate 的重音位置。（-MA-、-BIL-、-MAT-、CAL-）
2. FDCAN、UART、YOLO、LiDAR 各怎么读？（F-D-CAN；you-art；yo-lo；lie-dar）
3. tuned、limited、checked 的 -ed 分别读什么？（/d/；/ɪd/；/t/）
4. 为什么 “can” 与 “can't” 听上去容易混？怎么避免？（can 弱读 /kən/，can't 重读 /kænt/；说否定时加强元音和重音）
5. 读出 “The controller estimates the velocity of the vehicle.” 并标出重读音节。（The conTROLler ESTimates the veLOcity of the VEhicle.）
