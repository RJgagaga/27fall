# 易混技术词与同义改写表

> **一句话定位**：技术英语里很多词“看起来一样”，用错会让面试官怀疑你没真正理解（比如把 residual 说成 deviation，把 estimate 说成 predict）。本章把 45 组易混词放在一起辨析：每组给出精确区别、项目里的例句和中文译文；后半部分给出“同义改写表”，教你用简单、准确的词替换生僻或过度书面的词，在口语里说得更稳。

**本章学完你能……**

- 区分 error / deviation / residual、estimate / predict、gain / parameter 等 45 组易混词；
- 看到一个想说的中文词，立刻选对英文，不再“差不多就行”；
- 用 3–5 个简单动词替换 20 个书面动词，让口语更自然；
- 避免 10 组“看似同义、实则不同”的陷阱词。

**前置知识**：[02–06 技术词汇表](./02_技术词汇表_控制与建模.md)；[08_高频句型库](./08_高频句型库.md)。

## 1. 使用方法

- 每组表格列：词、核心区别、项目里的例句、中文。
- 先看“核心区别”，再造一个自己的句子，最后和例句对比。
- 面试里如果拿不准，用**更宽泛的词**也不算错，例如不确定 residual 还是 innovation，就说 “the difference between the measurement and the prediction”。

## 2. 控制与建模类易混词（1–15）

### 1. error / deviation / residual

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| error | 参考值与实际值之差（控制里的误差 e = r − y） | The tilt error is the difference between the reference and the measurement. | 倾角误差是参考与测量之差。 |
| deviation | 偏离正常/期望的程度，偏中性、描述性 | The speed shows a small deviation from the target. | 速度相对目标有小的偏离。 |
| residual | 模型预测与测量之差；也指拟合后剩余的误差 | A large residual means the measurement disagrees with the prediction. | 残差大说明测量与预测不一致。 |

> **口语建议**：控制用 error，滤波用 residual / innovation，描述统计用 standard deviation。

### 2. gain / parameter / coefficient

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| gain | 起放大作用的增益（Kp、K） | We reduced the proportional gain. | 我们降低了比例增益。 |
| parameter | 任何可调或模型里的参数 | Parameters are stored in a YAML file. | 参数存在 YAML 文件里。 |
| coefficient | 多项式、公式里的系数 | The cubic polynomial has four coefficients. | 三次多项式有四个系数。 |

### 3. stable / robust

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| stable | 系统受扰后能回到平衡或有界 | The closed loop is stable. | 闭环是稳定的。 |
| robust | 在参数变化、噪声、扰动下仍保持性能 | The controller is robust to payload changes. | 控制器对负载变化是鲁棒的。 |

### 4. accuracy / precision

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| accuracy | 与真值有多接近 | The accuracy of the attitude is about a tenth of a degree. | 姿态精度约零点一度。 |
| precision | 重复性/分辨度；检测里指“检出对的比例” | The readings have high precision but a bias. | 读数精密但有偏置。 |

### 5. feedback / feedforward

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| feedback | 根据测量到的结果修正（闭环） | Feedback corrects the error after it appears. | 反馈在误差出现后修正它。 |
| feedforward | 根据已知量提前补偿（开环成分） | Feedforward cancels the predictable load before the error appears. | 前馈在误差出现前抵消可预测负载。 |

### 6. limit / saturation / clamp

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| limit | 人为设定的上下界（动词/名词） | We limit the output to the motor range. | 我们把输出限制在电机范围内。 |
| saturation | 实际达到上限，导致线性关系失效的现象 | Saturation reduces the effective gain. | 饱和降低了有效增益。 |
| clamp | 把一个值硬性钳在范围内（动词） | We clamp the integral term. | 我们给积分项钳位。 |

### 7. tune / tweak / adjust / calibrate

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| tune | 整定控制参数 | I tuned the gains on the robot. | 我在机器人上整定了增益。 |
| tweak | 小幅微调（口语） | I tweaked the threshold a little. | 我把阈值微调了一点。 |
| adjust | 一般的调整 | We adjust the target speed in small steps. | 我们小步调整目标转速。 |
| calibrate | 校准传感器或模型常数 | We calibrate the gyro bias at start-up. | 启动时我们校准陀螺零偏。 |

### 8. delay / latency / lag / dead time

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| delay | 一般的延迟 | The delay is about 15 ms. | 延迟约 15 毫秒。 |
| latency | 端到端的响应延迟（系统层面） | The end-to-end latency includes the bus. | 端到端延迟包含总线。 |
| lag | 输出落后于输入的滞后（动态特性） | The filter adds lag to the signal. | 滤波给信号带来滞后。 |
| dead time | 输入后完全没有响应的纯滞后 | The servo has a dead time before it starts to move. | 舵机开始动之前有纯滞后。 |

### 9. noise / disturbance / uncertainty

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| noise | 测量中的随机波动 | The accelerometer is noisy. | 加速度计噪声大。 |
| disturbance | 作用在系统上的外界扰动 | A push on the robot is a disturbance. | 推机器人一下是扰动。 |
| uncertainty | 对模型或状态的不确定程度 | The covariance represents the uncertainty. | 协方差表示不确定性。 |

### 10. overshoot / oscillation / chattering

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| overshoot | 超过目标一次再回来 | The step response has little overshoot. | 阶跃响应超调很小。 |
| oscillation | 持续来回摆动 | A low damping term causes oscillation. | 阻尼低会引起振荡。 |
| chattering | 滑模等切换控制的高频抖动 | A boundary layer reduces chattering. | 边界层降低抖振。 |

### 11. model / reference / setpoint / target

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| model | 对系统的数学描述 | The model is a linearised pendulum. | 模型是线性化倒立摆。 |
| reference | 控制器要跟随的信号（可随时间变化） | The tilt reference is bounded. | 倾角参考有界。 |
| setpoint | 固定的设定值 | The temperature setpoint is 40 °C. | 温度设定值是 40 °C。 |
| target | 要到达的目标（日常说法） | The vision gives the target angle. | 视觉给出目标角度。 |

### 12. static / steady-state / equilibrium

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| static | 不随时间变（如静摩擦、静态精度） | Static friction causes a dead zone. | 静摩擦造成死区。 |
| steady state | 系统响应稳定后的状态 | The steady-state error is almost zero. | 稳态误差几乎为零。 |
| equilibrium | 力平衡/系统平衡点 | The upright equilibrium is unstable. | 直立平衡点不稳定。 |

### 13. linear / linearised / nonlinear

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| linear | 本身线性 | A spring with a constant stiffness is linear. | 刚度恒定的弹簧是线性的。 |
| linearised | 在工作点附近近似为线性 | The model is linearised around the upright pose. | 模型在直立位姿附近被线性化。 |
| nonlinear | 非线性（如饱和、摩擦） | The real system is nonlinear. | 真实系统是非线性的。 |

### 14. open loop / closed loop

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| open loop | 不使用输出反馈 | Open-loop control sends a command without checking the result. | 开环控制发出命令而不检查结果。 |
| closed loop | 使用反馈修正 | The wheel speed is closed-loop controlled. | 轮速是闭环控制的。 |

### 15. controller / regulator / compensator

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| controller | 计算控制量的整体模块 | The cascade controller runs at a fixed rate. | 级联控制器以固定频率运行。 |
| regulator | 把量保持在设定值（如 LQR 的 R） | LQR is a linear quadratic regulator. | LQR 是线性二次型调节器。 |
| compensator | 补偿某种效应的环节 | A gravity compensator cancels the load. | 重力补偿器抵消负载。 |

## 3. 估计、定位与规划类易混词（16–27）

### 16. estimate / predict / filter / fuse

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| estimate | 根据数据推出当前未知量 | We estimate the velocity from the encoders. | 我们由编码器估计速度。 |
| predict | 用模型推未来或下一步 | The filter predicts the next state. | 滤波器预测下一状态。 |
| filter | 去噪或滤波处理 | We filter the gyro signal. | 我们对陀螺信号滤波。 |
| fuse | 合并多个来源 | We fuse the IMU and the LiDAR. | 我们融合 IMU 和激光雷达。 |

### 17. position / pose / location / posture

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| position | 位置（x, y, z） | The position of the gripper. | 夹爪的位置。 |
| pose | 位置 + 朝向 | A 2D pose is x, y and heading. | 二维位姿是 x、y 和航向。 |
| location | 日常说法的地点 | The location of the charger. | 充电桩的位置。 |
| posture | 姿态（肢体/腿的构型） | The virtual leg length and posture. | 虚拟腿长和姿态。 |

### 18. attitude / orientation / heading / yaw

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| attitude | 机体相对重力/世界的朝向（航空/机器人） | Attitude estimation uses the gyro and the accelerometer. | 姿态估计用陀螺和加速度计。 |
| orientation | 朝向的一般说法 | The orientation can be a quaternion. | 朝向可以是四元数。 |

### 19. path / trajectory / route / plan

| 词 | 核心区别 | 例句 | 中文 |

| route | 宏观路线（如地图上的路线） | The route goes through the corridor. | 路线穿过走廊。 |
| plan | 规划结果（可指路径、任务） | The task plan is checked by the policy layer. | 任务计划由策略层检查。 |

### 20. localisation / mapping / navigation

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| localisation | 在已知地图中找自己位置 | AMCL does localisation on a known map. | AMCL 在已知地图上定位。 |

| navigation | 定位 + 规划 + 控制的整体 | Navigation includes localisation, planning and tracking. | 导航包括定位、规划和跟踪。 |

### 21. drift / bias / offset

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| drift | 随时间缓慢累积的偏移 | Odometry drifts over distance. | 里程计随距离漂移。 |
| bias | 恒定或缓变的系统偏差 | Gyro bias is estimated at start-up. | 启动时估计陀螺零偏。 |
| offset | 固定偏移量（常指安装/零位） | The mounting offset is a few degrees. | 安装偏差有几度。 |

### 22. jump / jitter / glitch / spike

| 词 | 核心区别 | 例句 | 中文 |

## 4. 嵌入式与通信类易混词（28–36）

## 5. AI 与软件类易混词（37–45）

### 37. training / inference / fine-tuning

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| training | 学习权重 | Training runs on a GPU. | 训练在 GPU 上运行。 |

| command | 命令，被直接执行 | The pump command is sent to the device. | 水泵命令发给设备。 |

### 40. rule-based / learning-based / model-based

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| rule-based | 人工规则 | A rule-based fast path. | 基于规则的快速通道。 |
| learning-based | 从数据学习 | A learning-based controller. | 基于学习的控制器。 |
| model-based | 依赖物理/数学模型 | MPC is model-based. | MPC 是基于模型的。 |

### 41. observation / measurement / event

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| observation | 感知得到的结构化信息 | A structured observation. | 结构化观测。 |
| measurement | 传感器读数 | The measurement is noisy. | 测量带噪声。 |
| event | 满足条件后触发的离散事件 | A wilting event. | 枯萎事件。 |

### 42. state / status / mode

| 词 | 核心区别 | 例句 | 中文 |
|---|---|---|---|
| state | 系统当前的完整状态 | The robot state. | 机器人状态。 |
| status | 简要的运行状态/结果 | The status is OK. | 状态正常。 |
| mode | 工作模式 | Manual mode and auto mode. | 手动模式和自动模式。 |

### 43. test / verify / validate

| 词 | 核心区别 | 例句 | 中文 |

## 6. 常见动词的同义改写（口语化）

口语里优先用**短、常见**的动词。左边是书面或生僻的，右边是更口语且同样准确的。

| 书面/生僻 | 口语替换 | 例句（口语版） | 中文 |
|---|---|---|---|
| utilise | use | We use the IMU as feedback. | 我们用 IMU 作反馈。 |
| implement | build / write / set up | I built the state machine. | 我搭了状态机。 |
| facilitate | help / make it easier | It makes reuse easier. | 它让复用更容易。 |
| commence | start / begin | The controller starts at power-up. | 控制器在上电时启动。 |
| terminate | stop / end | The task stops when the data is old. | 数据过期时任务停止。 |
| obtain | get | We get the pose from the EKF. | 我们从 EKF 得到位姿。 |
| acquire | get / collect | We collect the data at 100 Hz. | 我们以 100 Hz 采集数据。 |
| demonstrate | show | The log shows the improvement. | 日志显示了改善。 |
| ascertain | find out / check | I checked the cause. | 我查了原因。 |
| attempt | try | I tried a lower gain. | 我试了更低的增益。 |
| require | need | The planner needs a costmap. | 规划器需要代价地图。 |
| possess | have | The arm has seven joints. | 手臂有七个关节。 |
| encounter | run into / hit | We ran into a timing problem. | 我们遇到了时序问题。 |
| mitigate | reduce | Damping reduces the velocity near singularities. | 阻尼降低奇异点附近的速度。 |
| exacerbate | make worse | Delay makes oscillation worse. | 延迟使振荡更严重。 |
| alleviate | ease / reduce | A ramp eases the torque peak. | 斜坡缓和力矩峰值。 |
| deploy | put on / run on | I put the controller on the robot. | 我把控制器放到机器人上。 |
| establish | set up | We set up the communication link. | 我们建立了通信链路。 |
| ensure | make sure | We make sure the output is bounded. | 我们确保输出有界。 |
| modify | change | I changed the threshold. | 我改了阈值。 |

> **提示**：CV 里的书面动词（deployed, implemented, integrated）可以保留，但口述时前后用口语动词（built, set up, connected）平衡。

## 8. 不能互换的“假同义词”陷阱

| 陷阱 | 错误用法 | 正确用法 | 说明 |
|---|---|---|---|
| actual / current | the actual speed（实际速度）与 the current speed（当前速度）不同 | actual = 真实，current = 此刻 | 两者都可，但含义不同 |
| eventually / finally | 不要把 eventually 当“最终”随便用 | finally = 最后一步；eventually = 经过一段时间 | |
| economic / economical | economical = 节约的 | an economical design | |
| control / check | check = 检查；control = 控制 | check the sign / control the speed | 不要把“检查”说成 control |
| precise / accurate | precise = 精密；accurate = 准确 | | 见第 4 组 |
| sensitive / sensible | sensible = 明智的 | a sensitive sensor / a sensible choice | |
| historic / historical | historical data | historical data（历史数据） | historic 指有历史意义 |
| continuous / continual | continuous = 不间断；continual = 反复发生 | continuous signal / continual updates | |
| compose / consist | consist of | The system consists of three parts. | |
| lose / loose | loose = 松的 | lose the signal / a loose wire | |

## 本章要点速记

1. 误差三词：error 控制、deviation 描述偏离、residual 预测与测量之差。
2. estimate 是估现在，predict 是推未来；filter 去噪，fuse 融合。
3. path 无时间，trajectory 有时间；pose 含朝向，position 只含位置。
4. limit 是上下界，saturation 是撞到上限的现象，clamp 是动作。
5. delay 泛指，latency 是端到端，lag 是动态滞后，dead time 是纯滞后。
6. frame、packet、message 分别是链路层、网络层、应用层。
7. recommend 是建议，request 需批准，command 被执行。
8. training 更新权重，inference 使用权重。
9. 口语动词：use、build、get、show、need、try，比 utilise、implement、obtain 更自然。

## 自测题

1. residual 与 deviation 区别？（residual 是预测与测量之差；deviation 是偏离期望的程度）
2. “我们把输出限制在电机范围内” 用 limit 还是 saturation？（limit）
3. “积分项一直增大” 对应哪个词？（windup）
4. path 与 trajectory 的区别？（trajectory 有时间）
5. 请把 “We utilised the encoder to obtain the speed” 改成口语。（We used the encoder to get the speed.）
